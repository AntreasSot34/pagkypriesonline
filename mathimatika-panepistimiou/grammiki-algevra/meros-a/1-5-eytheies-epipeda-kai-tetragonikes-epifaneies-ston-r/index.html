1.5

Ευθείες, επίπεδα και τετραγωνικές επιφάνειες στον R³

📘 Ασκήσεις 1 (ασκ. 1) · Πίνακας τετραγωνικών επιφανειών

Θεωρία

Ευθεία

Η ευθεία που διέρχεται από το $\vec a$ με διάνυσμα κατεύθυνσης $\vec d \ne \mathbb{0}$: $\ \vec x = \vec a + t\vec d$, $t \in \mathbb{R}$, δηλαδή (παραμετρικές εξισώσεις) $x = a_1 + td_1$, $y = a_2 + td_2$, $z = a_3 + td_3$.

Επίπεδο

Το επίπεδο από το $\vec p$ με κάθετο διάνυσμα $\vec n = (a, b, c) \ne \mathbb{0}$: $\ \langle \vec n, \vec x - \vec p\rangle = 0 \iff ax + by + cz = \delta$, με $\delta = \langle \vec n, \vec p\rangle$.

  • Επίπεδο από τρία μη συνευθειακά σημεία $A, B, \Gamma$: $\vec n = \vec{AB}\times\vec{A\Gamma}$.
  • Απόσταση σημείου $(x_0, y_0, z_0)$ από το $ax + by + cz = \delta$: $\ \dfrac{|ax_0 + by_0 + cz_0 - \delta|}{\sqrt{a^2 + b^2 + c^2}}$.
  • Γωνία δύο επιπέδων: $\cos\theta = \dfrac{|\langle\vec n_1,\vec n_2\rangle|}{\|\vec n_1\|\,\|\vec n_2\|}$, $\theta\in[0,\pi/2]$.

Στον $\mathbb{R}^3$ μια εξίσωση από την οποία λείπει μια μεταβλητή περιγράφει «κύλινδρο»: π.χ. το $x = y$ είναι επίπεδο (όχι ευθεία!) και το $x^2 + z^2 = 4$ κυκλικός κύλινδρος. Αντίθετα, το σύστημα $x^2 + z^2 = 4,\ y = -5$ είναι κύκλος κέντρου $(0, -5, 0)$ και ακτίνας $2$ στο επίπεδο $y = -5$.

Τετραγωνικές επιφάνειες (κανονικές μορφές)

  • Ελλειψοειδές: $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$
  • Ελλειπτικό παραβολοειδές: $\frac{x^2}{a^2} + \frac{y^2}{b^2} = \frac zc$  ·  Ελλειπτικός κώνος: $\frac{x^2}{a^2} + \frac{y^2}{b^2} = \frac{z^2}{c^2}$
  • Υπερβολοειδές ενός φύλλου: $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$  ·  δύο φύλλων: $\frac{z^2}{c^2} - \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$
  • Υπερβολικό παραβολοειδές (σάγμα): $\frac{y^2}{b^2} - \frac{x^2}{a^2} = \frac zc$

Μέθοδος: αναγνωρίζουμε την επιφάνεια από τα ίχνη της — τις τομές με επίπεδα $x = k$, $y = k$, $z = k$ (ελλείψεις, υπερβολές, παραβολές).

Πειραματίσου

Ελλειψοειδές: x2a2+y2b2+z2c2=1\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1a2x2​+b2y2​+c2z2​=1   (a = 1,5, b = 1, c = 1)
Όλες οι τομές με επίπεδα z = k (|k| < c) είναι ελλείψεις. Γύρισε την επιφάνεια με τη «περιστροφή» για να δεις τις τομές (ίχνη).

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Η ευθεία διέρχεται από το $A(1, -2, 3)$ με διάνυσμα κατεύθυνσης $\vec d = (2, 1, -1)$. Ποιο σημείο της αντιστοιχεί στο $t = 2$;
Υπόδειξη: $\vec a + 2\vec d$.
Λύση: $(1, -2, 3) + 2(2, 1, -1) = (5, 0, 1)$.
Άσκηση 2Βασική
Το επίπεδο από το $P(2, -1, 3)$ με κάθετο διάνυσμα $\vec n = (1, 4, -2)$ έχει εξίσωση $x + 4y - 2z = \delta$. Να βρείτε το $\delta$.
Υπόδειξη: $\delta = \langle \vec n, \vec P\rangle$.
Λύση: $\delta = 2 - 4 - 6 = -8$.
Άσκηση 3Μέτρια
Το επίπεδο που διέρχεται από τα $A(1, 0, 0)$, $B(0, 2, 0)$, $\Gamma(0, 0, 3)$ έχει εξίσωση $6x + \beta y + \gamma z = \delta$. Να βρείτε τα $\beta, \gamma, \delta$.
Υπόδειξη: $\vec n = \vec{AB}\times\vec{A\Gamma}$.
Λύση: $\vec{AB} = (-1, 2, 0)$, $\vec{A\Gamma} = (-1, 0, 3)$, $\vec n = (6, 3, 2)$. Από το $A$: $6\cdot 1 + 0 + 0 = 6$. Άρα $6x + 3y + 2z = 6$.
Άσκηση 4Μέτρια
Να βρείτε την απόσταση του σημείου $(1, 2, 3)$ από το επίπεδο $2x - y + 2z = 1$.
Υπόδειξη: Τύπος απόστασης σημείου από επίπεδο.
Λύση: $d = \dfrac{|2 - 2 + 6 - 1|}{\sqrt{4 + 1 + 4}} = \dfrac53$.
Άσκηση 5Μέτρια
Να βρείτε το σημείο τομής της ευθείας $x = 1 + t,\ y = 2 - t,\ z = -1 + 2t$ με το επίπεδο $x + y + z = 6$.
Υπόδειξη: Αντικαταστήστε τις παραμετρικές στην εξίσωση του επιπέδου.
Λύση: $(1 + t) + (2 - t) + (-1 + 2t) = 2 + 2t = 6 \Rightarrow t = 2$. Σημείο $(3, 0, 3)$.
Άσκηση 6Απαιτητική
Να βρείτε τη γωνία (σε μοίρες) των επιπέδων $x + y = 1$ και $y + z = 2$.
Υπόδειξη: Κάθετα διανύσματα $(1, 1, 0)$ και $(0, 1, 1)$.
Λύση: $\cos\theta = \dfrac{1}{\sqrt2\sqrt2} = \dfrac12 \Rightarrow \theta = 60^\circ$.
Άσκηση 7Βασική
Το σύνολο των σημείων του $\mathbb{R}^3$ με $x^2 + z^2 = 4$ και $y = -5$ είναι:
Υπόδειξη: Η εξίσωση $y = -5$ περιορίζει σε ένα επίπεδο.
Λύση: Στο επίπεδο $y = -5$ η $x^2 + z^2 = 4$ είναι κύκλος ακτίνας $2$ με κέντρο $(0, -5, 0)$. (Χωρίς τη συνθήκη $y = -5$ θα ήταν κύλινδρος.)
Άσκηση 8Βασική
Το σύνολο $\{(x, y, z) \in \mathbb{R}^3 : x = y\}$ είναι ευθεία.
Υπόδειξη: Το $z$ είναι ελεύθερο.
Λύση: Λάθος: είναι επίπεδο (κάθετο διάνυσμα $(1, -1, 0)$), που περιέχει την ευθεία $x = y$ του επιπέδου $xy$ και εκτείνεται κατακόρυφα.
Άσκηση 9Μέτρια
Η επιφάνεια $\dfrac{x^2}{4} + \dfrac{y^2}{9} - z^2 = 1$ είναι:
Υπόδειξη: Δύο θετικά και ένα αρνητικό τετράγωνο, ίσο με $1$.
Λύση: Υπερβολοειδές ενός φύλλου: για κάθε $z = k$ η τομή $\frac{x^2}{4} + \frac{y^2}{9} = 1 + k^2$ είναι έλλειψη (μη κενή), ενώ οι τομές $x = 0$ είναι υπερβολές.
Άσκηση 10Μέτρια
Η επιφάνεια $z = y^2 - x^2$ είναι:
Υπόδειξη: Τομές $x = 0$ και $y = 0$.
Λύση: Στο $x = 0$: $z = y^2$ (παραβολή προς τα πάνω)· στο $y = 0$: $z = -x^2$ (προς τα κάτω)· τομές $z = k$: υπερβολές. Σάγμα.
