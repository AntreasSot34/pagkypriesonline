3.1

Γραμμικοί συνδυασμοί – Υπόχωροι παραγόμενοι από διανύσματα

📘 Σημειώσεις Γεωργίου Κεφ. 3 §3.1 (σελ. 3.1) · Ασκήσεις 3

Θεωρία

Γραμμικός συνδυασμός (Ορισμός 3.1.1)

Για $S = \{u_1, \dots, u_m\} \subseteq V$, κάθε διάνυσμα της μορφής

$$u = \lambda_1 u_1 + \lambda_2 u_2 + \dots + \lambda_m u_m, \qquad \lambda_i \in K$$

λέγεται γραμμικός συνδυασμός των $u_1, \dots, u_m$.

Ο υπόχωρος $L(S) = \operatorname{Span} S$ (Θεώρημα 3.1.2)

Το σύνολο όλων των γραμμικών συνδυασμών $L(S) = \{\sum \lambda_i u_i : \lambda_i \in K\}$ είναι υπόχωρος του $V$ — ο μικρότερος υπόχωρος που περιέχει το $S$. Λέμε ότι το $S$ παράγει τον $V$ αν $L(S) = V$.

  • Στον $\mathbb{R}^3$: $L\{u\}$ ($u \ne \mathbf{0}$) είναι ευθεία από την αρχή· $L\{u, v\}$ με $u, v$ μη συγγραμμικά είναι επίπεδο από την αρχή.
  • Αν $w \in L(S)$, τότε $L(S \cup \{w\}) = L(S)$: η προσθήκη ενός γραμμικού συνδυασμού δεν μεγαλώνει το $L$.
  • Λιγότερα από $n$ διανύσματα δεν μπορούν να παράγουν τον $\mathbb{R}^n$.

Μέθοδος: ανήκει το $b$ στο $L(a_1, \dots, a_m)$;

$b \in L(a_1, \dots, a_m) \iff$ το σύστημα με επαυξημένο πίνακα $[\,a_1\ a_2\ \cdots\ a_m \mid b\,]$ είναι συμβιβαστό ($\iff$ η εξίσωση $A\mathbf{x} = b$ έχει λύση, όπου $A = [a_1 \cdots a_m]$).

Παράδειγμα (σημειώσεις): $u_1 = (1, 1, 1)$, $u_2 = (1, 0, 1)$. Το $(1, 2, 1) = 2u_1 - u_2$ ανήκει στο $L(u_1, u_2)$· το $(3, 2, 2)$ όχι, γιατί προκύπτει $\lambda_1 = 2$, $\lambda_1 + \lambda_2 = 3$ και $\lambda_1 + \lambda_2 = 2$ — αδύνατο.

Περιγραφή του $L(S)$ με εξισώσεις

Κλιμακώνουμε τον $[\,a_1 \cdots a_m \mid b\,]$ με γενικό $b = (b_1, \dots, b_n)$· οι συνθήκες συμβιβαστού (μηδενικές γραμμές αριστερά) δίνουν τις εξισώσεις του υπόχωρου. Π.χ. $L\{(1, -1, 0), (0, 1, -1)\} = \{b : b_1 + b_2 + b_3 = 0\}$.

Πειραματίσου

λu + μv = (1, 3). Τα u, v δεν είναι συγγραμμικά: L(u, v) = ℝ². Ο στόχος γράφεται b = 8/5·u + 1/5·v (μοναδικά).
Ρύθμισε τα λ, μ ώστε η πράσινη κορυφή να πέσει στον κόκκινο κύκλο b.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να γράψετε το $u = (4, 1, 4)$ ως γραμμικό συνδυασμό των $u_1 = (1, 1, 1)$ και $u_2 = (1, 0, 1)$: $u = \lambda_1 u_1 + \lambda_2 u_2$.
Υπόδειξη: Η 2η συντεταγμένη δίνει αμέσως το $\lambda_1$.
Λύση: $(\lambda_1 + \lambda_2, \lambda_1, \lambda_1 + \lambda_2) = (4, 1, 4)$: $\lambda_1 = 1$, $\lambda_2 = 3$.
Άσκηση 2Βασική
Ανήκει το $(2, 5, 3)$ στο $L\{(1, 1, 1), (1, 0, 1)\}$;
Υπόδειξη: Η 1η και η 3η συντεταγμένη κάθε συνδυασμού είναι ίσες.
Λύση: Κάθε συνδυασμός είναι $(\lambda_1 + \lambda_2, \lambda_1, \lambda_1 + \lambda_2)$ με ίσες 1η και 3η συντεταγμένη· όμως $2 \ne 3$. Το σύστημα είναι αδύνατο.
Άσκηση 3Μέτρια
Έστω $a_1 = (1, 2, -1)$, $a_2 = (2, 5, 1)$ και $b = (1, 4, h)$. Για ποια τιμή του $h$ είναι $b \in \operatorname{Span}\{a_1, a_2\}$;
Υπόδειξη: Λύστε από τις δύο πρώτες εξισώσεις.
Λύση: $\lambda_1 + 2\lambda_2 = 1$, $2\lambda_1 + 5\lambda_2 = 4$ $\Rightarrow$ $\lambda_2 = 2$, $\lambda_1 = -3$. Η 3η εξίσωση: $h = -\lambda_1 + \lambda_2 = 3 + 2 = 5$.
Άσκηση 4Μέτρια
Δίνεται ότι $\begin{pmatrix}1&2&0\\0&1&1\\2&0&1\end{pmatrix}\begin{pmatrix}2\\-1\\3\end{pmatrix} = \begin{pmatrix}0\\2\\7\end{pmatrix}$. Να βρείτε $c_1, c_2, c_3$ με $\begin{pmatrix}0\\2\\7\end{pmatrix} = c_1\begin{pmatrix}1\\0\\2\end{pmatrix} + c_2\begin{pmatrix}2\\1\\0\end{pmatrix} + c_3\begin{pmatrix}0\\1\\1\end{pmatrix}$.
Υπόδειξη: $A\mathbf{x}$ είναι γραμμικός συνδυασμός των στηλών του $A$ με συντελεστές τα $x_i$.
Λύση: $A\mathbf{x} = x_1 a_1 + x_2 a_2 + x_3 a_3$, άρα $c_1 = 2$, $c_2 = -1$, $c_3 = 3$ (και είναι μοναδικοί, αφού $\det A = 5 \ne 0$).
Άσκηση 5Βασική
Τρία διανύσματα του $\mathbb{R}^4$ μπορούν να παράγουν τον $\mathbb{R}^4$.
Υπόδειξη: Πόσα οδηγά στοιχεία μπορεί να έχει ένας $4\times 3$ πίνακας;
Λύση: Λάθος: ο πίνακας $[v_1\ v_2\ v_3]$ είναι $4\times 3$ και έχει το πολύ 3 οδηγά στοιχεία, άρα κάποια γραμμή της κλιμακωτής μορφής είναι μηδενική και υπάρχουν $b$ για τα οποία το σύστημα είναι αδύνατο ($\dim L \le 3 < 4$).
Άσκηση 6Μέτρια
Ποια εξίσωση περιγράφει το $L\{(1, -1, 0), (0, 1, -1)\}$ στον $\mathbb{R}^3$;
Υπόδειξη: Ποια γραμμική εξίσωση επαληθεύουν και τα δύο διανύσματα;
Λύση: $\lambda(1, -1, 0) + \mu(0, 1, -1) = (\lambda, \mu - \lambda, -\mu)$, με άθροισμα συντεταγμένων $0$. Είναι επίπεδο (2 μη συγγραμμικά διανύσματα), άρα ακριβώς το $x + y + z = 0$.
Άσκηση 7Απαιτητική
Το $L\{(1, 2, 0), (0, 1, 3)\}$ είναι επίπεδο του $\mathbb{R}^3$ με εξίσωση της μορφής $\alpha x + \beta y + z = 0$. Να βρείτε τα $\alpha, \beta$.
Υπόδειξη: Αντικαταστήστε τα δύο διανύσματα στην εξίσωση.
Λύση: $(1, 2, 0)$: $\alpha + 2\beta = 0$· $(0, 1, 3)$: $\beta + 3 = 0$. Άρα $\beta = -3$, $\alpha = 6$: $6x - 3y + z = 0$ (το $(6, -3, 1)$ είναι το εξωτερικό γινόμενο των δύο διανυσμάτων).
Άσκηση 8Βασική
Αν $w \in L(S)$, τότε $L(S \cup \{w\}) = L(S)$.
Υπόδειξη: Αντικαταστήστε το $w$ με τον γραμμικό συνδυασμό του.
Λύση: Σωστό: κάθε γραμμικός συνδυασμός των $S \cup \{w\}$ γίνεται γραμμικός συνδυασμός των $S$ αντικαθιστώντας το $w$· το αντίστροφο ($\supseteq$) είναι προφανές.
Άσκηση 9Μέτρια
Στον $P_2$ να γράψετε το $p(x) = x^2 + 6x + 1$ ως $\alpha(x^2 + x) + \beta(x - 1) + \gamma(x + 1)$.
Υπόδειξη: Συγκρίνετε συντελεστές $x^2$, $x$ και σταθερούς όρους.
Λύση: $x^2$: $\alpha = 1$. $x$: $\alpha + \beta + \gamma = 6 \Rightarrow \beta + \gamma = 5$. Σταθερός: $-\beta + \gamma = 1$. Άρα $\gamma = 3$, $\beta = 2$.
Άσκηση 10Απαιτητική
Έστω $A = \begin{pmatrix}2&-1\\-6&3\end{pmatrix}$. Για ποια $b = (b_1, b_2)$ έχει λύση η $A\mathbf{x} = b$ (δηλαδή $b \in L(\text{στηλών του } A)$);
Υπόδειξη: Κλιμακώστε τον $[A \mid b]$: $R_2 + 3R_1$.
Λύση: $\left[\begin{array}{cc|c}2&-1&b_1\\-6&3&b_2\end{array}\right] \sim \left[\begin{array}{cc|c}2&-1&b_1\\0&0&b_2 + 3b_1\end{array}\right]$. Συμβιβαστό $\iff 3b_1 + b_2 = 0$: οι στήλες (συγγραμμικές) παράγουν μόνο μια ευθεία.

♾️ Γεννήτρια — γραμμικοί συνδυασμοί και L(S)

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Για ποια τιμή του $h$ το $b = (3, 0, h)$ ανήκει στο $L(a_1, a_2) = \operatorname{Span}\{a_1, a_2\}$, όπου $a_1 = (0, 3, 3)$, $a_2 = (-1, 2, -1)$;
Λύση: Οι δύο πρώτες εξισώσεις του συστήματος $\lambda_1 a_1 + \lambda_2 a_2 = b$ δίνουν μοναδικά $\lambda_1 = 2$, $\lambda_2 = -3$. Για να είναι συμβιβαστό πρέπει $h = 2\cdot 3 + (-3)\cdot (-1) = 9$.
