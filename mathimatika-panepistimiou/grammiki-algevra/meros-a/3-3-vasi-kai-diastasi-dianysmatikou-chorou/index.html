3.3

Βάση και διάσταση διανυσματικού χώρου

📘 Σημειώσεις Γεωργίου Κεφ. 3 §3.3 (σελ. 3.10) · Ασκήσεις 7

Θεωρία

Βάση (Ορισμός 3.3.1) και συντεταγμένες

Ένα πεπερασμένο $A = \{e_1, \dots, e_n\} \subseteq V$ είναι βάση του $V$ αν (i) τα $e_i$ είναι γραμμικώς ανεξάρτητα και (ii) το $A$ παράγει τον $V$.

Πρόταση 3.3.2: το $A$ είναι βάση $\iff$ κάθε $u \in V$ γράφεται κατά μοναδικό τρόπο ως $u = a_1e_1 + \dots + a_ne_n$. Οι $a_i$ είναι οι συντεταγμένες του $u$ ως προς $A$ και $u_A = (a_1, \dots, a_n) \in K^n$ (στοιχείο του $K^n$, όχι του $V$).

Διάσταση

Όλες οι βάσεις ενός (πεπερασμένα παραγόμενου) $V$ έχουν το ίδιο πλήθος στοιχείων: η διάσταση $\dim V$ ($\dim\{\mathbf{0}\} = 0$).

  • $\dim\mathbb{R}^n = n$ (συνήθης βάση $e_1, \dots, e_n$) · $\dim P_n = n + 1$ ($1, x, \dots, x^n$) · $\dim M_{m\times n} = mn$.
  • Αν $\dim V = n$: κάθε $n$ ανεξάρτητα διανύσματα είναι βάση· κάθε $n$ διανύσματα που παράγουν είναι βάση· περισσότερα από $n$ είναι εξαρτημένα· λιγότερα από $n$ δεν παράγουν.
  • Κάθε ανεξάρτητο σύνολο επεκτείνεται σε βάση· κάθε σύνολο που παράγει περιέχει βάση.
  • Αν $W$ υπόχωρος του $V$: (για $V$ πεπερασμένης διάστασης) $\dim W \le \dim V$, με ισότητα αν και μόνο αν $W = V$.

Τύπος διάστασης αθροίσματος

$$\dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2).$$

Ειδικά, για ευθύ άθροισμα: $\dim(W_1 \oplus W_2) = \dim W_1 + \dim W_2$. Π.χ. δύο επίπεδα από την αρχή στον $\mathbb{R}^3$ ($2 + 2 > 3$) τέμνονται πάντα σε τουλάχιστον μια ευθεία.

Μέθοδος: βάση και διάσταση του $L(v_1, \dots, v_k)$ στον $\mathbb{R}^m$

Φέρνουμε τον $[v_1 \cdots v_k]$ σε κλιμακωτή μορφή: $\dim L = $ πλήθος οδηγών στοιχείων ($= \operatorname{rank}$) και βάση αποτελούν τα αρχικά $v_j$ των στηλών με οδηγό. Συντεταγμένες ως προς βάση $B$: λύνουμε το σύστημα $[b_1 \cdots b_n \mid u]$.

Παράδειγμα: $B = \{(2, 1), (1, -1)\}$ βάση του $\mathbb{R}^2$· για $u = (u_1, u_2)$: $u_B = \left(\frac{u_1 + u_2}{3}, \frac{u_1 - 2u_2}{3}\right)$.

Πειραματίσου

B = {b₁, b₂} είναι βάση (det = 3 ≠ 0). u = 2·b₁ + 1·b₂, άρα [u]B = (2, 1).
Το πλέγμα δείχνει τις «συντεταγμένες γραμμές» της βάσης B· στη συνήθη βάση οι συντεταγμένες του u είναι (3, 3).

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Έστω η βάση $B = \{(1, -3), (2, -5)\}$ του $\mathbb{R}^2$. Να βρείτε το $[y]_B$ για $y = (4, -9)$.
Υπόδειξη: $\lambda_1(1, -3) + \lambda_2(2, -5) = (4, -9)$.
Λύση: $\lambda_1 + 2\lambda_2 = 4$, $-3\lambda_1 - 5\lambda_2 = -9$ $\Rightarrow$ $\lambda_1 = 4 - 2\lambda_2$, $-12 + 6\lambda_2 - 5\lambda_2 = -9 \Rightarrow \lambda_2 = 3$, $\lambda_1 = -2$. Έλεγχος: $-2(1, -3) + 3(2, -5) = (4, -9)$ ✓.
Άσκηση 2Βασική
Είναι βάση του $\mathbb{R}^2$ το $\{(4, -1), (6, -2)\}$;
Υπόδειξη: Δύο διανύσματα στον $\mathbb{R}^2$: αρκεί να είναι ανεξάρτητα.
Λύση: $\det\begin{pmatrix}4&6\\-1&-2\end{pmatrix} = -8 + 6 = -2 \ne 0$: ανεξάρτητα, και αφού $\dim\mathbb{R}^2 = 2$, αποτελούν βάση.
Άσκηση 3Βασική
Το σύνολο $\{(1, -6, -7), (3, -4, 7), (-2, 7, 5), (0, 8, 9)\}$ είναι βάση του $\mathbb{R}^3$;
Υπόδειξη: Πλήθος διανυσμάτων.
Λύση: Όχι: 4 διανύσματα στον $\mathbb{R}^3$ ($\dim = 3$) είναι εξαρτημένα, άρα δεν είναι βάση (μια βάση έχει ακριβώς 3 στοιχεία).
Άσκηση 4Βασική
Να δώσετε τις διαστάσεις: (α) $P_3$, (β) $M_{2\times 3}(\mathbb{R})$, (γ) του υπόχωρου των συμμετρικών $2\times 2$ πινάκων.
Υπόδειξη: Μετρήστε τις ελεύθερες παραμέτρους.
Λύση: (α) $\{1, x, x^2, x^3\}$: 4. (β) $2\cdot 3 = 6$. (γ) $\begin{pmatrix}a&b\\b&c\end{pmatrix} = a E_{11} + b(E_{12} + E_{21}) + c E_{22}$: 3.
Άσκηση 5Μέτρια
Να βρείτε τη διάσταση του $W = \{(x, y, z, w) \in \mathbb{R}^4 : x + y + z + w = 0,\ x - y = 0\}$.
Υπόδειξη: Ομογενές σύστημα με 2 ανεξάρτητες εξισώσεις και 4 αγνώστους.
Λύση: $y = x$, $w = -2x - z$: $W = \{(x, x, z, -2x - z)\} = L\{(1, 1, 0, -2), (0, 0, 1, -1)\}$, δύο ανεξάρτητα διανύσματα. $\dim W = 4 - 2 = 2$.
Άσκηση 6Μέτρια
Να βρείτε τη διάσταση του υπόχωρου του $\mathbb{R}^4$ που παράγεται από τα $(1, 2, 0, 1)$, $(2, 4, 1, 3)$, $(3, 6, 1, 4)$, $(0, 0, 1, 2)$.
Υπόδειξη: Παρατηρήστε ότι $v_3 = v_1 + v_2$.
Λύση: $v_3 = v_1 + v_2$, οπότε $L = L(v_1, v_2, v_4)$. Κλιμάκωση: $v_1 = (1, 2, 0, 1)$, $v_2 - 2v_1 = (0, 0, 1, 1)$, $v_4 - (v_2 - 2v_1) = (0, 0, 0, 1)$: τρία οδηγά στοιχεία, άρα ανεξάρτητα και $\dim = 3$.
Άσκηση 7Απαιτητική
Στον $\mathbb{R}^5$, $\dim W_1 = 3$ και $\dim W_2 = 4$. Ποια είναι η ελάχιστη δυνατή διάσταση του $W_1 \cap W_2$;
Υπόδειξη: $\dim(W_1 + W_2) \le 5$.
Λύση: $\dim(W_1 \cap W_2) = 3 + 4 - \dim(W_1 + W_2) \ge 7 - 5 = 2$, και η τιμή $2$ επιτυγχάνεται όταν $W_1 + W_2 = \mathbb{R}^5$.
Άσκηση 8Απαιτητική
Να βρείτε τις συντεταγμένες του $p(x) = 3x^2 - x + 2$ ως προς τη βάση $\{1,\ x - 1,\ (x - 1)^2\}$ του $P_2$.
Υπόδειξη: Θέστε $t = x - 1$, δηλαδή $x = t + 1$.
Λύση: $3(t + 1)^2 - (t + 1) + 2 = 3t^2 + 6t + 3 - t - 1 + 2 = 3t^2 + 5t + 4$. Άρα $p = 4\cdot 1 + 5(x - 1) + 3(x - 1)^2$ και $p_B = (4, 5, 3)$.
Άσκηση 9Βασική
Κάθε σύνολο τριών γραμμικώς ανεξάρτητων διανυσμάτων του $\mathbb{R}^3$ είναι βάση του $\mathbb{R}^3$.
Υπόδειξη: $\dim\mathbb{R}^3 = 3$.
Λύση: Σωστό: σε χώρο διάστασης $n$, κάθε $n$ γραμμικώς ανεξάρτητα διανύσματα αποτελούν βάση (παράγουν αυτόματα).
Άσκηση 10Μέτρια
Για ποια τιμή του $k$ το $\{(1, 1, 0), (0, 1, 1), (1, 0, k)\}$ δεν είναι βάση του $\mathbb{R}^3$;
Υπόδειξη: Βάση $\iff \det \ne 0$.
Λύση: $\det\begin{pmatrix}1&1&0\\0&1&1\\1&0&k\end{pmatrix} = 1(k - 0) - 1(0 - 1) + 0 = k + 1$. Δεν είναι βάση $\iff k = -1$ (τότε $(1, 0, -1) = (1, 1, 0) - (0, 1, 1)$).

♾️ Γεννήτρια — βάση, συντεταγμένες, διάσταση

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Έστω η βάση $B = \{b_1, b_2\}$ του $\mathbb{R}^2$ με $b_1 = (-3, -4)$, $b_2 = (1, 1)$. Να βρείτε το διάνυσμα συντεταγμένων $[u]_B$ του $u = (11, 15)$.
Λύση: Λύνουμε $\lambda_1 b_1 + \lambda_2 b_2 = u$: $\lambda_1 = -4$, $\lambda_2 = -1$ (μοναδική λύση, αφού $\det = 1 \ne 0$). Άρα $[u]_B = (-4, -1)$.
