2.1

Η έννοια του διανυσματικού χώρου

📘 Σημειώσεις Γεωργίου Κεφ. 2 §2.1–2.1.1 (σελ. 2.1–2.12) · Προβλήματα 2ου κεφαλαίου

Θεωρία

Ορισμός (διανυσματικός χώρος πάνω σε σώμα $K$)

Έστω $V \ne \emptyset$ και $K$ ένα σώμα ($\mathbb{R}$, $\mathbb{C}$ ή $\mathbb{Q}$). Στο $V$ ορίζονται δύο πράξεις: η πρόσθεση $u + v \in V$ και ο βαθμωτός πολλαπλασιασμός $\lambda u \in V$ ($\lambda \in K$) — δηλαδή το $V$ είναι κλειστό ως προς αυτές. Το $V$ λέγεται διανυσματικός (γραμμικός) χώρος πάνω στο $K$ αν για κάθε $u, v, w \in V$ και $\lambda, \mu \in K$:

  • (A1) $(u + v) + w = u + (v + w)$   (A2) υπάρχει $\mathbf{0} \in V$ με $u + \mathbf{0} = u$   (A3) για κάθε $u$ υπάρχει $-u$ με $u + (-u) = \mathbf{0}$   (A4) $u + v = v + u$
  • (B1) $\lambda(u + v) = \lambda u + \lambda v$   (B2) $(\lambda + \mu)u = \lambda u + \mu u$   (B3) $(\lambda\mu)u = \lambda(\mu u)$   (B4) $1u = u$

Τα A1–A4 λένε ότι το $(V, +)$ είναι αβελιανή ομάδα· τα B1–B4 περιγράφουν τη «δράση» του σώματος. Αν $K = \mathbb{R}$, ο $V$ λέγεται πραγματικός διανυσματικός χώρος.

Βασικά παραδείγματα (με τις συνήθεις πράξεις)

  • $\mathbb{R}^n$ · ο $\mathbb{C}$ πάνω στο $\mathbb{R}$ · κάθε σώμα πάνω στον εαυτό του.
  • $M_{m\times n}(\mathbb{R})$: οι $m\times n$ πίνακες (πρόσθεση και πολλαπλασιασμός κατά στοιχείο).
  • $P$: όλα τα πολυώνυμα· $P_n$: τα πολυώνυμα βαθμού $\le n$ (μαζί με το μηδενικό).
  • $C[a, b]$: οι συνεχείς συναρτήσεις στο $[a, b]$, με $(f + g)(x) = f(x) + g(x)$, $(\lambda f)(x) = \lambda f(x)$.

Στοιχειώδεις ιδιότητες (Πρόταση 2.1.2 κ.ε.)

Σε κάθε διανυσματικό χώρο: το $\mathbf{0}$ είναι μοναδικό· το $-u$ είναι μοναδικό· νόμος διαγραφής: $u + w = v + w \Rightarrow u = v$· $-(-u) = u$. Επίσης $0u = \mathbf{0}$, $\lambda\mathbf{0} = \mathbf{0}$, $(-1)u = -u$, και

$$\lambda u = \mathbf{0} \iff \lambda = 0 \ \text{ή}\ u = \mathbf{0}.$$

Π.χ. $0u = (0 + 0)u = 0u + 0u$ και με διαγραφή $0u = \mathbf{0}$.

Παράδειγμα με «περίεργες» πράξεις

Στο $V = (0, +\infty)$ με $x \oplus y = xy$ και $\lambda \odot x = x^\lambda$ ισχύουν όλα τα αξιώματα: π.χ. B2: $x^{\lambda + \mu} = x^\lambda x^\mu$. Το μηδενικό στοιχείο είναι το $1$ (αφού $x \oplus 1 = x$) και το αντίθετο του $x$ είναι το $\frac1x$.

Προσοχή: για να δείξουμε ότι κάτι δεν είναι διανυσματικός χώρος αρκεί ένα αντιπαράδειγμα σε ένα αξίωμα (ή στην κλειστότητα)· για να δείξουμε ότι είναι, πρέπει να αποδείξουμε όλα τα αξιώματα γενικά.

Πειραματίσου

Δοκιμή με u = (4, 1), v = (1, -1), w = (1, 4), λ = 2, μ = -1, 0 = (0, 0)
A1(u + v) + w = u + (v + w)✓(6, 4)
A2υπάρχει 0 με u + 0 = u✓(4, 1)
A3υπάρχει −u με u + (−u) = 0✓(0, 0)
A4u + v = v + u✓(5, 0)
B1λ(u + v) = λu + λv✓(10, 0)
B2(λ + μ)u = λu + μu✓(4, 1)
B3(λμ)u = λ(μu)✓(-8, -2)
B41·u = u✓(4, 1)
Όλα τα αξιώματα ισχύουν στη δοκιμή.
Ένα αντιπαράδειγμα αρκεί για να αποτύχει ένα αξίωμα· για να ισχύει, χρειάζεται απόδειξη για όλα τα u, v, w, λ, μ (η δοκιμή απλώς το επιβεβαιώνει).

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Στο $V = (0, +\infty)$ με $x \oplus y = xy$ και $\lambda \odot x = x^\lambda$, να υπολογίσετε (α) $4 \oplus 5$, (β) $3 \odot 2$, (γ) $(-1) \odot 8$.
Υπόδειξη: Το $\oplus$ είναι γινόμενο, το $\odot$ δύναμη.
Λύση: (α) $4\cdot 5 = 20$. (β) $2^3 = 8$. (γ) $8^{-1} = \frac18$ — είναι το αντίθετο στοιχείο του $8$, αφού $8 \oplus \frac18 = 1 = \mathbf{0}$.
Άσκηση 2Βασική
Στο $V = (0, +\infty)$ με $x \oplus y = xy$ και $\lambda \odot x = x^\lambda$, ποιο είναι το μηδενικό στοιχείο $\mathbf{0}$;
Υπόδειξη: Ζητάμε $\mathbf{0}$ με $x \oplus \mathbf{0} = x$ για κάθε $x$.
Λύση: $x \oplus \mathbf{0} = x\cdot\mathbf{0} = x$ για κάθε $x > 0$ $\iff \mathbf{0} = 1$. Το $0$ δεν ανήκει καν στο $V$.
Άσκηση 3Μέτρια
Στο $\mathbb{R}^2$ κρατάμε τη συνήθη πρόσθεση και ορίζουμε $\lambda(x, y) = (\lambda x, 0)$. Ποιο αξίωμα αποτυγχάνει;
Υπόδειξη: Δοκιμάστε $u = (1, 1)$.
Λύση: $1(1, 1) = (1, 0) \ne (1, 1)$, άρα αποτυγχάνει το B4. Τα B1–B3 ισχύουν: π.χ. $(\lambda + \mu)(x, y) = ((\lambda + \mu)x, 0) = (\lambda x, 0) + (\mu x, 0)$.
Άσκηση 4Μέτρια
Στο $\mathbb{R}$ ορίζουμε $x \oplus y = x + y$ και $\lambda \odot x = \lambda^2 x$. Ποιο αξίωμα αποτυγχάνει;
Υπόδειξη: Συγκρίνετε $(\lambda + \mu)^2$ με $\lambda^2 + \mu^2$.
Λύση: $(\lambda + \mu)^2 x \ne (\lambda^2 + \mu^2)x$ εν γένει (π.χ. $\lambda = \mu = 1$, $x = 1$: $4 \ne 2$). Τα B1 ($\lambda^2(x + y) = \lambda^2 x + \lambda^2 y$), B3 ($(\lambda\mu)^2 = \lambda^2\mu^2$) και B4 ισχύουν.
Άσκηση 5Βασική
Το σύνολο των πολυωνύμων βαθμού ακριβώς 2, με τις συνήθεις πράξεις, είναι διανυσματικός χώρος.
Υπόδειξη: Είναι κλειστό ως προς την πρόσθεση;
Λύση: Λάθος: $(x^2 + x) + (-x^2 + 1) = x + 1$ έχει βαθμό 1. Επίσης δεν περιέχει το μηδενικό πολυώνυμο. (Το $P_2$, βαθμού $\le 2$, είναι διανυσματικός χώρος.)
Άσκηση 6Βασική
Σε κάθε διανυσματικό χώρο $V$ ισχύει $0u = \mathbf{0}$ για κάθε $u \in V$ (όπου $0 \in K$).
Υπόδειξη: $0 = 0 + 0$ και νόμος διαγραφής.
Λύση: Σωστό: $0u = (0 + 0)u = 0u + 0u$ (B2), δηλαδή $0u + \mathbf{0} = 0u + 0u$, και από τον νόμο διαγραφής $0u = \mathbf{0}$.
Άσκηση 7Μέτρια
Στον χώρο $M_{2\times 2}(\mathbb{R})$ να λύσετε την εξίσωση $2X + A = 3B$, όπου $A = \begin{pmatrix}1&-3\\4&0\end{pmatrix}$, $B = \begin{pmatrix}1&1\\2&-2\end{pmatrix}$. Δώστε τα στοιχεία του $X$ κατά γραμμές.
Υπόδειξη: $X = \frac12(3B - A)$ — οι ιδιότητες του διανυσματικού χώρου επιτρέπουν τις γνωστές πράξεις.
Λύση: $3B - A = \begin{pmatrix}2&6\\2&-6\end{pmatrix}$, άρα $X = \begin{pmatrix}1&3\\1&-3\end{pmatrix}$.
Άσκηση 8Απαιτητική
Στο $\mathbb{R}^2$ ορίζουμε $(x, y) \oplus (x', y') = (x + x' - 1,\ y + y' + 2)$ και $\lambda \odot (x, y) = (\lambda(x - 1) + 1,\ \lambda(y + 2) - 2)$. Είναι διανυσματικός χώρος. Να βρείτε το μηδενικό στοιχείο $\mathbf{0} = (\alpha, \beta)$ και το αντίθετο $(\gamma, \delta)$ του $u = (4, 1)$.
Υπόδειξη: $(x, y) \oplus (\alpha, \beta) = (x, y)$ για κάθε $(x, y)$.
Λύση: $x + \alpha - 1 = x \Rightarrow \alpha = 1$, $y + \beta + 2 = y \Rightarrow \beta = -2$: $\mathbf{0} = (1, -2)$. Αντίθετο: $4 + \gamma - 1 = 1 \Rightarrow \gamma = -2$, $1 + \delta + 2 = -2 \Rightarrow \delta = -5$. Έλεγχος: $(-1)\odot(4, 1) = (-(3) + 1, -(3) - 2) = (-2, -5)$ ✓. (Ο χώρος είναι ο $\mathbb{R}^2$ «μετατοπισμένος» ώστε η αρχή να είναι το $(1, -2)$.)
Άσκηση 9Απαιτητική
Αν $\lambda u = \mathbf{0}$ και $u \ne \mathbf{0}$, τότε:
Υπόδειξη: Αν $\lambda \ne 0$, πολλαπλασίασε με $\lambda^{-1}$.
Λύση: Αν $\lambda \ne 0$: $u = 1u = (\lambda^{-1}\lambda)u = \lambda^{-1}(\lambda u) = \lambda^{-1}\mathbf{0} = \mathbf{0}$, άτοπο. Άρα $\lambda = 0$ (χρησιμοποιήθηκαν B4, B3 και $\lambda\mathbf{0} = \mathbf{0}$).
Άσκηση 10Μέτρια
Ποιο από τα παρακάτω δεν είναι πραγματικός διανυσματικός χώρος με τις συνήθεις πράξεις;
Υπόδειξη: Κλειστότητα ως προς τον βαθμωτό πολλαπλασιασμό.
Λύση: $(1, 0)$ ανήκει, αλλά $(-1)(1, 0) = (-1, 0)$ όχι: δεν είναι κλειστό ως προς τον βαθμωτό πολλαπλασιασμό (ούτε έχει αντίθετα). Τα άλλα είναι κλασικά παραδείγματα διανυσματικών χώρων.

♾️ Γεννήτρια — αξιώματα διανυσματικού χώρου

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Στο $\mathbb{R}^2$ ορίζουμε $(x, y) \oplus (x', y') = (x + x' + 2, y + y' + 2)$ και $\lambda \odot (x, y) = (\lambda(x + 2) - 2, \lambda(y + 2) - 2)$. Είναι διανυσματικός χώρος. Να βρείτε το μηδενικό στοιχείο $\mathbf{0} = (\alpha, \beta)$ και το αντίθετο $-u = (\gamma, \delta)$ του $u = (3, 1)$.
Λύση: $(x, y) \oplus (\alpha, \beta) = (x, y) \iff x + \alpha + 2 = x,\ y + \beta + 2 = y$, άρα $\mathbf{0} = (-2, -2)$ (όχι το $(0, 0)$!). Για το αντίθετο: $u \oplus (\gamma, \delta) = \mathbf{0} \iff 3 + \gamma + 2 = -2,\ 1 + \delta + 2 = -2$, άρα $-u = (-7, -5)$. (Έλεγχος: $(-1)\odot u$ δίνει το ίδιο.)
