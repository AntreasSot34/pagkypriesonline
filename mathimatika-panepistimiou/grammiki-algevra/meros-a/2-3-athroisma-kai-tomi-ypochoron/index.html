2.3

Άθροισμα και τομή υποχώρων

📘 Σημειώσεις Γεωργίου Κεφ. 2 §2.3 (σελ. 2.23) · Προβλήματα 2.5, 2.7

Θεωρία

Ορισμοί

Για υπόχωρους $W_1, W_2$ του $V$ ορίζουμε την τομή $W_1 \cap W_2$ και το άθροισμα

$$W_1 + W_2 = \{w_1 + w_2 : w_1 \in W_1,\ w_2 \in W_2\}.$$

Θεώρημα 2.3.2: τα $W_1 \cap W_2$ και $W_1 + W_2$ είναι υπόχωροι του $V$ (γενικεύεται σε $k$ υπόχωρους). Το $W_1 + W_2$ είναι ο μικρότερος υπόχωρος που περιέχει και τους δύο· αν $W_1 = L(S_1)$, $W_2 = L(S_2)$, τότε $W_1 + W_2 = L(S_1 \cup S_2)$.

Η ένωση

Η ένωση $W_1 \cup W_2$ είναι υπόχωρος αν και μόνο αν $W_1 \subseteq W_2$ ή $W_2 \subseteq W_1$. Π.χ. η ένωση των δύο αξόνων του $\mathbb{R}^2$ δεν είναι υπόχωρος, ενώ το άθροισμά τους είναι όλος ο $\mathbb{R}^2$.

Ευθύ άθροισμα

Γράφουμε $V = W_1 \oplus W_2$ αν $V = W_1 + W_2$ και $W_1 \cap W_2 = \{\mathbf{0}\}$. Ισοδύναμα: κάθε $v \in V$ γράφεται κατά μοναδικό τρόπο ως $v = w_1 + w_2$, $w_1 \in W_1$, $w_2 \in W_2$.

  • $\mathbb{R}^3 = W_1 \oplus W_2$ με $W_1 = \{(t, t, t)\}$, $W_2 = \{(0, y, z)\}$: $(a, b, c) = (a, a, a) + (0, b - a, c - a)$.
  • $M_{n\times n} = \{\text{συμμετρικοί}\} \oplus \{\text{αντισυμμετρικοί}\}$: $A = \frac{A + A^T}{2} + \frac{A - A^T}{2}$.
  • $C(\mathbb{R}) = \{\text{άρτιες}\} \oplus \{\text{περιττές}\}$: $f(x) = \frac{f(x) + f(-x)}{2} + \frac{f(x) - f(-x)}{2}$.

Παράδειγμα τομής

Στον $\mathbb{R}^3$, $W_1 = \{z = 0\}$ (επίπεδο $xy$) και $W_2 = \{x = 0\}$ (επίπεδο $yz$): $W_1 \cap W_2 = \{(0, y, 0)\}$, ο άξονας $y$. Επίσης $W_1 + W_2 = \mathbb{R}^3$, αλλά το άθροισμα δεν είναι ευθύ, αφού η τομή δεν είναι $\{\mathbf{0}\}$: π.χ. $(0, 1, 0) = (0, 1, 0) + \mathbf{0} = \mathbf{0} + (0, 1, 0)$.

Πειραματίσου

W₁ ∩ W₂ = {0} και W₁ + W₂ = ℝ², άρα ℝ² = W₁ ⊕ W₂ (ευθύ άθροισμα).
Μοναδική ανάλυση: w = (3, 2) = w₁′ + w₂′ με w₁′ = (2,73, 0,99) ∈ W₁ και w₂′ = (0,27, 1,01) ∈ W₂.
Βάλε τις δύο γωνίες ίσες: η ανάλυση παύει να υπάρχει / να είναι μοναδική.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Με $W_1 = \{(t, t, t) : t \in \mathbb{R}\}$ και $W_2 = \{(0, y, z)\}$ ισχύει $\mathbb{R}^3 = W_1 \oplus W_2$. Να γράψετε $(5, 2, -1) = (t, t, t) + (0, y, z)$.
Υπόδειξη: Η 1η συντεταγμένη καθορίζει το $t$.
Λύση: $t = 5$, $y = 2 - 5 = -3$, $z = -1 - 5 = -6$: $(5, 2, -1) = (5, 5, 5) + (0, -3, -6)$.
Άσκηση 2Βασική
Στον $\mathbb{R}^2$, $W_1 = \{(x, 0)\}$ και $W_2 = \{(0, y)\}$. Ποια πρόταση είναι σωστή;
Υπόδειξη: $(x, y) = (x, 0) + (0, y)$.
Λύση: Κάθε $(x, y) = (x, 0) + (0, y)$, άρα $W_1 + W_2 = \mathbb{R}^2$. Η ένωση είναι οι δύο άξονες, όχι υπόχωρος. Η τομή είναι $\{\mathbf{0}\}$ (όχι κενή — κάθε υπόχωρος περιέχει το $\mathbf{0}$).
Άσκηση 3Βασική
Στον $\mathbb{R}^3$, $W_1 = \{(x, y, z) : z = 0\}$ και $W_2 = \{(x, y, z) : x = 0\}$. Τι είναι το $W_1 \cap W_2$;
Υπόδειξη: Ισχύουν ταυτόχρονα $z = 0$ και $x = 0$.
Λύση: $z = 0$ και $x = 0$: μένουν τα $(0, y, 0)$, δηλαδή ο άξονας $y$.
Άσκηση 4Μέτρια
Για τους υπόχωρους $W_1 = \{(x,y,z): z = 0\}$ και $W_2 = \{(x,y,z): x = 0\}$ του $\mathbb{R}^3$, ισχύει $\mathbb{R}^3 = W_1 \oplus W_2$;
Υπόδειξη: Ευθύ άθροισμα απαιτεί τομή $\{\mathbf{0}\}$.
Λύση: $(x, y, z) = (x, y, 0) + (0, 0, z)$, άρα το άθροισμα είναι $\mathbb{R}^3$. Όμως η τομή είναι ο άξονας $y$, οπότε η ανάλυση δεν είναι μοναδική: δεν είναι ευθύ άθροισμα.
Άσκηση 5Μέτρια
Να γράψετε τον $A = \begin{pmatrix}1&4\\-2&3\end{pmatrix}$ ως $A = S + K$ με $S$ συμμετρικό και $K$ αντισυμμετρικό. Δώστε τα στοιχεία $s_{12}$ και $k_{12}$.
Υπόδειξη: $S = \frac{A + A^T}{2}$, $K = \frac{A - A^T}{2}$.
Λύση: $S = \begin{pmatrix}1&1\\1&3\end{pmatrix}$, $K = \begin{pmatrix}0&3\\-3&0\end{pmatrix}$. Άρα $s_{12} = \frac{4 + (-2)}{2} = 1$, $k_{12} = \frac{4 - (-2)}{2} = 3$.
Άσκηση 6Βασική
Η ένωση δύο υποχώρων ενός διανυσματικού χώρου είναι πάντα υπόχωρος.
Υπόδειξη: Οι δύο άξονες του $\mathbb{R}^2$.
Λύση: Λάθος: η ένωση των αξόνων δεν είναι κλειστή ως προς την πρόσθεση. Η ένωση είναι υπόχωρος μόνο αν ο ένας περιέχεται στον άλλο.
Άσκηση 7Βασική
Αν $V = W_1 \oplus W_2$, τότε κάθε $v \in V$ γράφεται κατά μοναδικό τρόπο ως $v = w_1 + w_2$ με $w_1 \in W_1$, $w_2 \in W_2$.
Υπόδειξη: Αν $w_1 + w_2 = w_1' + w_2'$, τότε $w_1 - w_1' = w_2' - w_2 \in W_1 \cap W_2$.
Λύση: Σωστό: η διαφορά δύο αναλύσεων ανήκει στην τομή $W_1 \cap W_2 = \{\mathbf{0}\}$, άρα οι αναλύσεις ταυτίζονται.
Άσκηση 8Απαιτητική
Στον $\mathbb{R}^2$, $W_1 = L\{(1, 2)\}$ και $W_2 = L\{(3, -1)\}$. Να γράψετε το $(5, 3) = w_1 + w_2$ με $w_1 \in W_1$, $w_2 \in W_2$.
Υπόδειξη: $s(1, 2) + t(3, -1) = (5, 3)$.
Λύση: $s + 3t = 5$, $2s - t = 3$ $\Rightarrow$ $t = 1$, $s = 2$. Άρα $w_1 = (2, 4)$, $w_2 = (3, -1)$. Η ανάλυση είναι μοναδική, γιατί $\mathbb{R}^2 = W_1 \oplus W_2$ (μη συγγραμμικά).
Άσκηση 9Μέτρια
Ως άθροισμα άρτιας και περιττής συνάρτησης, το άρτιο μέρος της $f(x) = e^x$ είναι:
Υπόδειξη: $f_{\text{άρτ}}(x) = \frac{f(x) + f(-x)}{2}$.
Λύση: $\frac{e^x + e^{-x}}{2} = \cosh x$ (άρτια) και περιττό μέρος $\frac{e^x - e^{-x}}{2} = \sinh x$. Η ανάλυση είναι μοναδική, γιατί $C(\mathbb{R}) = \{\text{άρτιες}\} \oplus \{\text{περιττές}\}$.
Άσκηση 10Απαιτητική
Στον $\mathbb{R}^3$, $W_1 = \{(x, y, z) : x + y + z = 0\}$ και $W_2 = L\{(1, 1, 1)\}$. Ισχύει $\mathbb{R}^3 = W_1 \oplus W_2$;
Υπόδειξη: Πότε ανήκει το $t(1, 1, 1)$ στο $W_1$;
Λύση: Τομή: $t(1, 1, 1) \in W_1 \iff 3t = 0 \iff t = 0$, άρα $W_1 \cap W_2 = \{\mathbf{0}\}$. Άθροισμα: $(a, b, c) = \left(a - m, b - m, c - m\right) + m(1, 1, 1)$ με $m = \frac{a + b + c}{3}$, όπου το πρώτο ανήκει στο $W_1$. Άρα ναι.

♾️ Γεννήτρια — ευθύ άθροισμα, ανάλυση διανύσματος

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Στον $\mathbb{R}^3$ ισχύει $\mathbb{R}^3 = W_1 \oplus W_2$ με $W_1 = \{(t, t, t) : t \in \mathbb{R}\}$ και $W_2 = \{(0, y, z) : y, z \in \mathbb{R}\}$. Να γράψετε το $(3, -2, -3) = (t, t, t) + (0, y, z)$.
Λύση: Πρώτη συντεταγμένη: $t = 3$. Τότε $y = -2 - 3 = -5$ και $z = -3 - 3 = -6$.
