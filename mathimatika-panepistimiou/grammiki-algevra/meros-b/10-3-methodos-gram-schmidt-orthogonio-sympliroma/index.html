10.3

Μέθοδος Gram–Schmidt – Ορθογώνιο συμπλήρωμα

📘 Σημειώσεις Χ. Σοφοκλέους, Κεφ. 6

Θεωρία

Διαδικασία Gram–Schmidt

Από μια βάση $\{\mathbf x_1, \dots, \mathbf x_p\}$ του $W$ κατασκευάζουμε ορθογώνια βάση:

$$\mathbf v_1 = \mathbf x_1, \quad \mathbf v_2 = \mathbf x_2 - \frac{\langle\mathbf x_2, \mathbf v_1\rangle}{\langle\mathbf v_1, \mathbf v_1\rangle}\mathbf v_1, \quad \mathbf v_3 = \mathbf x_3 - \frac{\langle\mathbf x_3, \mathbf v_1\rangle}{\langle\mathbf v_1, \mathbf v_1\rangle}\mathbf v_1 - \frac{\langle\mathbf x_3, \mathbf v_2\rangle}{\langle\mathbf v_2, \mathbf v_2\rangle}\mathbf v_2, \ \dots$$

Σε κάθε βήμα αφαιρούμε από το $\mathbf x_k$ την προβολή του στον $\operatorname{Span}\{\mathbf v_1, \dots, \mathbf v_{k-1}\} = \operatorname{Span}\{\mathbf x_1, \dots, \mathbf x_{k-1}\}$. Για ορθοκανονική βάση διαιρούμε στο τέλος κάθε $\mathbf v_k$ με $\|\mathbf v_k\|$.

Πρακτικά

  • Μπορούμε να πολλαπλασιάσουμε οποιοδήποτε $\mathbf v_k$ με μη μηδενικό αριθμό (π.χ. για να φύγουν κλάσματα) πριν το επόμενο βήμα — η ορθογωνιότητα δεν αλλάζει.
  • Έλεγχος: $\langle\mathbf v_i, \mathbf v_j\rangle = 0$. Αν κάποιο $\mathbf v_k = \mathbf 0$, τα αρχικά διανύσματα ήταν εξαρτημένα.

Ορθογώνιο συμπλήρωμα

$W^\perp = \{\mathbf z \in V : \langle\mathbf z, \mathbf w\rangle = 0 \ \forall\,\mathbf w \in W\}$ είναι υπόχωρος. Αρκεί το $\mathbf z$ να είναι ορθογώνιο στα διανύσματα μιας βάσης του $W$. Στο $\mathbb R^n$:

  • $\dim W + \dim W^\perp = n$ και $(W^\perp)^\perp = W$·
  • $(\operatorname{Row}A)^\perp = N(A)$ και $(\operatorname{Col}A)^\perp = N(A^T)$.

Π.χ. $W = \operatorname{Span}\{(1, 0, 1), (0, 1, 1)\}$: λύνουμε $x + z = 0$, $y + z = 0$ και βρίσκουμε $W^\perp = \operatorname{Span}\{(-1, -1, 1)\}$.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να εφαρμόσετε Gram–Schmidt στα $\mathbf x_1 = (3, 0, -1)$, $\mathbf x_2 = (8, 5, -6)$. Με $\mathbf v_1 = \mathbf x_1$, να βρείτε το $\mathbf v_2$.
Υπόδειξη: $\frac{\mathbf x_2\cdot\mathbf v_1}{\mathbf v_1\cdot\mathbf v_1} = \frac{30}{10}$.
Λύση: $\mathbf v_2 = \mathbf x_2 - 3\mathbf v_1 = (8, 5, -6) - (9, 0, -3) = (-1, 5, -3)$. Έλεγχος: $\mathbf v_1\cdot\mathbf v_2 = -3 + 0 + 3 = 0$.
Άσκηση 2Βασική
Στο $\mathbb R^2$, Gram–Schmidt στα $\mathbf x_1 = (1, 1)$, $\mathbf x_2 = (1, 3)$: να βρείτε το $\mathbf v_2$.
Υπόδειξη: Συντελεστής $\frac{4}{2}$.
Λύση: $\mathbf v_2 = (1, 3) - 2(1, 1) = (-1, 1)$.
Άσκηση 3Μέτρια
Gram–Schmidt στα $\mathbf x_1 = (1, 2, 2)$, $\mathbf x_2 = (1, 0, 4)$: να βρείτε το $\mathbf v_2$ και το $\|\mathbf v_2\|^2$.
Υπόδειξη: $\mathbf x_2\cdot\mathbf x_1 = 9 = \|\mathbf x_1\|^2$.
Λύση: $\mathbf v_2 = \mathbf x_2 - \frac99\mathbf x_1 = (0, -2, 2)$, $\|\mathbf v_2\|^2 = 8$. Ορθοκανονική βάση: $\frac13(1, 2, 2)$, $\frac{1}{2\sqrt2}(0, -2, 2) = \frac{1}{\sqrt2}(0, -1, 1)$.
Άσκηση 4Απαιτητική
Gram–Schmidt στα $\mathbf x_1 = (1, 1, 1, 1)$, $\mathbf x_2 = (0, 1, 1, 1)$, $\mathbf x_3 = (0, 0, 1, 1)$ του $\mathbb R^4$. Να βρείτε το $\mathbf v_3$ (χωρίς κλιμάκωση).
Υπόδειξη: $\mathbf v_2 = \mathbf x_2 - \frac34\mathbf x_1$, ή κλιμακωμένο $\mathbf v_2' = (-3, 1, 1, 1)$.
Λύση: $\mathbf v_2 = \left(-\frac34, \frac14, \frac14, \frac14\right)$ — κλιμακώνουμε σε $\mathbf v_2' = (-3, 1, 1, 1)$. Τότε $\mathbf v_3 = \mathbf x_3 - \frac{2}{4}\mathbf v_1 - \frac{2}{12}\mathbf v_2' = (0, 0, 1, 1) - \left(\frac12, \frac12, \frac12, \frac12\right) - \left(-\frac12, \frac16, \frac16, \frac16\right) = \left(0, -\frac23, \frac13, \frac13\right)$.
Άσκηση 5Βασική
Αν $W = \operatorname{Span}\{(1, 1, 1)\} \subseteq \mathbb R^3$, ο $W^\perp$ είναι:
Υπόδειξη: $\dim W^\perp = 3 - 1$.
Λύση: $\mathbf z \perp (1, 1, 1) \iff z_1 + z_2 + z_3 = 0$: επίπεδο διάστασης $2 = 3 - 1$.
Άσκηση 6Βασική
Αν $W = \operatorname{Span}\{(1, 2, -1)\}$, τότε το $(3, -1, 1)$ ανήκει στον $W^\perp$.
Υπόδειξη: Εσωτερικό γινόμενο.
Λύση: $3 - 2 - 1 = 0$: ναι, είναι ορθογώνιο στη βάση του $W$, άρα σε όλο τον $W$.
Άσκηση 7Μέτρια
Για κάθε πίνακα $A$ $m\times n$ ισχύει:
Υπόδειξη: $A\mathbf x = \mathbf 0$ σημαίνει ότι κάθε γραμμή είναι ορθογώνια στο $\mathbf x$.
Λύση: $A\mathbf x = \mathbf 0 \iff$ το $\mathbf x$ είναι ορθογώνιο σε κάθε γραμμή του $A$ $\iff \mathbf x \in (\operatorname{Row}A)^\perp$. Αντίστοιχα $(\operatorname{Col}A)^\perp = N(A^T)$.
Άσκηση 8Μέτρια
Να βρείτε βάση του $W^\perp$ για $W = \operatorname{Span}\{(1, 0, 1), (0, 1, 1)\}$, με διάνυσμα της μορφής $(a, b, 1)$.
Υπόδειξη: $a + 1 = 0$, $b + 1 = 0$.
Λύση: $\langle (a, b, 1), (1, 0, 1)\rangle = a + 1 = 0$, $\langle (a, b, 1), (0, 1, 1)\rangle = b + 1 = 0$: $W^\perp = \operatorname{Span}\{(-1, -1, 1)\}$ (διάσταση $3 - 2 = 1$).
Άσκηση 9Απαιτητική
Στο $C[0,1]$ με $\langle f, g\rangle = \int_0^1 fg\,dx$ εφαρμόζουμε Gram–Schmidt στα $1, x$. Το $\mathbf v_2$ είναι της μορφής $x + c$. Να βρείτε το $c$ και το $\|\mathbf v_2\|^2$.
Υπόδειξη: $\frac{\langle x, 1\rangle}{\langle 1, 1\rangle} = \frac12$.
Λύση: $\mathbf v_2 = x - \frac{1/2}{1}\cdot 1 = x - \frac12$. $\|\mathbf v_2\|^2 = \int_0^1 \left(x - \frac12\right)^2 dx = \frac13 - \frac12 + \frac14 = \frac{1}{12}$.

♾️ Γεννήτρια — Gram–Schmidt

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να εφαρμόσετε τη μέθοδο Gram–Schmidt στα $\mathbf x_1 = (-1, 1, 0)$, $\mathbf x_2 = (0, 2, 1)$ ($\mathbf v_1 = \mathbf x_1$). Να βρείτε το $\mathbf v_2$.
Λύση: $\frac{\mathbf x_2\cdot\mathbf v_1}{\mathbf v_1\cdot\mathbf v_1} = \frac{2}{2} = 1$, άρα $\mathbf v_2 = \mathbf x_2 - \mathbf v_1 = (1, 1, 1)$. Έλεγχος: $\mathbf v_1\cdot\mathbf v_2 = 0$.
