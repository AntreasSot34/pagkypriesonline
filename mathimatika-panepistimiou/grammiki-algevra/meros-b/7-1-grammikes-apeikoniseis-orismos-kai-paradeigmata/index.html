7.1

Γραμμικές απεικονίσεις: ορισμός και παραδείγματα

📘 Σημειώσεις Γεωργίου Κεφ. 7 §7.1–7.2 · Ασκήσεις 5

Θεωρία

Ορισμός

Έστω $V, W$ διανυσματικοί χώροι πάνω στο $\mathbb R$. Η απεικόνιση $f: V\to W$ λέγεται γραμμική αν για κάθε $u, v\in V$ και $\lambda\in\mathbb R$:

$$f(u + v) = f(u) + f(v), \qquad f(\lambda u) = \lambda f(u),$$

ισοδύναμα $f(\lambda u + \mu v) = \lambda f(u) + \mu f(v)$. Συνέπειες: $f(0) = 0$, $f(-u) = -f(u)$.

Παραδείγματα

  • $f(X) = AX$, $A$ πίνακας $m\times n$: γραμμική $\mathbb R^n \to\mathbb R^m$.
  • Η παράγωγος $D(p) = p'$ στον χώρο των πολυωνύμων· το ίχνος $\operatorname{tr}: M_n \to\mathbb R$· η ανάστροφη $A\mapsto A^T$.
  • Όχι γραμμικές: η μεταφορά $x\mapsto x + b$ ($b \ne 0$), οι $x\mapsto x^2$, $x\mapsto|x|$, η $(x, y)\mapsto xy$, η ορίζουσα $\det: M_n\to\mathbb R$ ($n \ge 2$).

Καθορίζεται από μια βάση

Μια γραμμική απεικόνιση καθορίζεται πλήρως από τις τιμές της σε μια βάση: αν $v = \lambda_1 v_1 + \dots + \lambda_n v_n$ τότε $f(v) = \lambda_1 f(v_1) + \dots + \lambda_n f(v_n)$. Ειδικά, κάθε γραμμική $T:\mathbb R^n\to\mathbb R^m$ είναι της μορφής $T(x) = Ax$ με κανονικό πίνακα $A = [\,T(e_1)\ \cdots\ T(e_n)\,]$.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Ποια από τις παρακάτω απεικονίσεις είναι γραμμική;
Υπόδειξη: Έλεγξε $T(0) = 0$ και μη γραμμικούς όρους.
Λύση: Η $(x_1, x_2 - x_3)$ είναι γραμμική. Η 2η έχει σταθερό όρο ($T(0) = (0, 4) \ne 0$), οι άλλες περιέχουν $x^2$ ή $xy$.
Άσκηση 2Βασική
Να βρείτε τον κανονικό πίνακα της $T(x, y, z) = (2x - y + 3z,\ x + 4z)$ (κατά γραμμές).
Υπόδειξη: Συντελεστές των $x, y, z$ σε κάθε συνιστώσα.
Λύση: $A = \begin{pmatrix}2 & -1 & 3 \\ 1 & 0 & 4\end{pmatrix}$, με στήλες $T(e_1) = (2,1)$, $T(e_2) = (-1, 0)$, $T(e_3) = (3, 4)$.
Άσκηση 3Βασική
Η γραμμική $T:\mathbb R^2\to\mathbb R^2$ απεικονίζει το $e_1$ στο $(3, -1)$ και το $e_2$ στο $(2, 4)$. Να βρείτε το $T(4, -1)$.
Υπόδειξη: $(4, -1) = 4e_1 - e_2$.
Λύση: $4(3, -1) - (2, 4) = (10, -8)$.
Άσκηση 4Μέτρια
Η γραμμική $T:\mathbb R^2\to\mathbb R^2$ ικανοποιεί $T(1, 1) = (3, 1)$ και $T(1, -1) = (1, 5)$. Να βρείτε τα $T(e_1)$, $T(e_2)$ και το $T(3, 2)$.
Υπόδειξη: $e_1 = \tfrac12[(1,1) + (1,-1)]$, $e_2 = \tfrac12[(1,1) - (1,-1)]$.
Λύση: $T(e_1) = \tfrac12[(3,1) + (1,5)] = (2, 3)$, $T(e_2) = \tfrac12[(3,1) - (1,5)] = (1, -2)$. Άρα $T(3,2) = 3(2,3) + 2(1,-2) = (8, 5)$.
Άσκηση 5Βασική
Η απεικόνιση $T:\mathbb R^n \to\mathbb R^n$, $T(x) = x + b$ με $b \ne 0$, είναι γραμμική.
Υπόδειξη: Τι δίνει η $T(0)$;
Λύση: Λάθος: $T(0) = b \ne 0$, ενώ κάθε γραμμική απεικόνιση στέλνει το $0$ στο $0$.
Άσκηση 6Βασική
Η παράγωγος $D: P_2 \to P_1$, $D(p) = p'$, είναι γραμμική. Αν $D(3x^2 - 2x + 5) = \alpha x + \beta$, να βρείτε τα $\alpha, \beta$.
Υπόδειξη: Παραγώγιση όρο προς όρο.
Λύση: $D(3x^2 - 2x + 5) = 6x - 2$.
Άσκηση 7Μέτρια
Η $f:\mathbb R^2\to\mathbb R$, $f(x, y) = xy$:
Υπόδειξη: Η $f(0) = 0$ είναι αναγκαία, όχι ικανή συνθήκη.
Λύση: $f(2, 2) = 4$ ενώ $2f(1, 1) = 2$: παραβιάζεται η $f(\lambda u) = \lambda f(u)$, άρα δεν είναι γραμμική (παρότι $f(0,0) = 0$).
Άσκηση 8Μέτρια
Για ποιες τιμές του $\kappa$ είναι γραμμική η $T(x, y) = \big(\kappa x + y,\ (\kappa^2 - 1) + 2y\big)$; (Δώστε πρώτα τη μικρότερη.)
Υπόδειξη: Χρειάζεται $T(0, 0) = (0, 0)$.
Λύση: $T(0,0) = (0, \kappa^2 - 1)$, άρα πρέπει $\kappa^2 = 1$. Τότε $T(x, y) = (\kappa x + y, 2y)$ που είναι γραμμική. $\kappa = \pm 1$.
Άσκηση 9Απαιτητική
Η γραμμική $T:\mathbb R^3\to\mathbb R^3$ έχει $T(e_1) = (1, 0, 1)$, $T(e_2) = (0, 2, 1)$, $T(e_3) = (1, 1, 0)$. Να βρείτε το $T(2, -1, 3)$.
Υπόδειξη: $2T(e_1) - T(e_2) + 3T(e_3)$.
Λύση: $(2, 0, 2) - (0, 2, 1) + (3, 3, 0) = (5, 1, 1)$.
Άσκηση 10Μέτρια
Ποια από τις απεικονίσεις $M_2(\mathbb R)\to\mathbb R$ είναι γραμμική;
Υπόδειξη: Σύγκρινε $\det(2A)$ με $2\det A$.
Λύση: Το ίχνος είναι γραμμικό. Η ορίζουσα όχι: $\det(2I_2) = 4 \ne 2\det I_2$.

♾️ Γεννήτρια — γραμμικές απεικονίσεις και κανονικός πίνακας

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Δίνεται η γραμμική απεικόνιση $T:\mathbb R^3 \to \mathbb R^2$, $T(x, y, z) = (4x - y - z,\ 3x + 3z)$. Να βρείτε τον κανονικό της πίνακα (κατά γραμμές).
Υπόδειξη: Οι στήλες του πίνακα είναι οι $T(e_1), T(e_2), T(e_3)$.
Λύση: $A = \begin{pmatrix}4 & -1 & -1 \\ 3 & 0 & 3\end{pmatrix}$: η $j$ στήλη είναι η εικόνα $T(e_j)$.
