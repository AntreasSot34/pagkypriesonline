1.1

Σειρές πραγματικών αριθμών – μερικά αθροίσματα – γεωμετρική σειρά

📘 Σημειώσεις: Τσολομύτης κεφ. 1 (Ορισμός 1.1, Προτάσεις 1.2–1.3) · Ζαφειρίδου §8.1

Τι σημαίνει να «προσθέσουμε άπειρους αριθμούς»; Μια σειρά πραγματικών αριθμών συγκλίνει όταν συγκλίνει η ακολουθία των μερικών αθροισμάτων της.

Θεωρία

Η σειρά πραγματικών αριθμών είναι το βασικό εργαλείο για να δώσουμε νόημα σε «άπειρα αθροίσματα» όπως $1 + \frac12 + \frac14 + \cdots$. Η ιδέα είναι απλή: δεν προσθέτουμε ποτέ άπειρους όρους· προσθέτουμε πεπερασμένους, παίρνουμε τα μερικά αθροίσματα $s_N$ και εξετάζουμε αν η ακολουθία $(s_N)$ συγκλίνει. Έτσι όλη η θεωρία των σειρών στηρίζεται στη θεωρία ορίων ακολουθιών του Απειροστικού Ι.

1.1 · Σειρά, μερικό άθροισμα, σύγκλιση σειράς

Έστω $(a_n)_{n\ge1}$ ακολουθία πραγματικών αριθμών. Το $N$-οστό μερικό άθροισμα είναι $s_N = a_1 + a_2 + \cdots + a_N = \sum_{n=1}^N a_n$. Η ακολουθία $(s_N)$ λέγεται σειρά με γενικό όρο $a_n$ και συμβολίζεται $\sum_{n=1}^\infty a_n$.

Αν $s_N \to s \in \mathbb R$, λέμε ότι η σειρά συγκλίνει και ότι έχει άθροισμα $s$: γράφουμε $\sum_{n=1}^\infty a_n = s$. Αν η $(s_N)$ δεν συγκλίνει, λέμε ότι η σειρά αποκλίνει· ειδικότερα, αν $s_N \to +\infty$ (ή $-\infty$) λέμε ότι απειρίζεται.

Προσοχή στο σύμβολο

Το $\sum_{n=1}^\infty a_n$ σημαίνει δύο πράγματα: την ίδια τη σειρά (την ακολουθία $s_N$) και — μόνο αν συγκλίνει — τον αριθμό $\lim s_N$. Οι αλγεβρικοί κανόνες των πεπερασμένων αθροισμάτων (αντιμετάθεση, προσεταιρισμός) δεν ισχύουν αυτόματα: π.χ. $(1 - 1) + (1 - 1) + \cdots = 0$, ενώ η $\sum (-1)^{n+1}$ αποκλίνει αφού $s_N = 1, 0, 1, 0, \dots$

1.2 · Γεωμετρική σειρά

Για $\lambda \in \mathbb R$ η γεωμετρική σειρά $\sum_{n=0}^\infty \lambda^n = 1 + \lambda + \lambda^2 + \cdots$ συγκλίνει αν και μόνο αν $|\lambda| < 1$, και τότε

$$\sum_{n=0}^{\infty}\lambda^n = \frac{1}{1 - \lambda}, \qquad \sum_{n=k}^{\infty}\lambda^n = \frac{\lambda^k}{1 - \lambda}\quad(|\lambda| < 1).$$

Για $\lambda \ge 1$ απειρίζεται, ενώ για $\lambda \le -1$ αποκλίνει (ταλαντεύεται).

Απόδειξη

Για $\lambda \ne 1$ πολλαπλασιάζοντας το $s_N = 1 + \lambda + \cdots + \lambda^{N}$ με $(1 - \lambda)$ όλοι οι ενδιάμεσοι όροι διαγράφονται: $(1 - \lambda)s_N = 1 - \lambda^{N+1}$, άρα $s_N = \dfrac{1 - \lambda^{N+1}}{1 - \lambda}$. Αν $|\lambda| < 1$, τότε $\lambda^{N+1} \to 0$ και $s_N \to \frac{1}{1 - \lambda}$. Αν $\lambda = 1$, $s_N = N + 1 \to +\infty$· αν $\lambda > 1$, $\lambda^{N+1} \to +\infty$ και $s_N \to +\infty$. Αν $\lambda \le -1$, ο όρος $\lambda^n$ δεν τείνει στο $0$, οπότε (βλ. αναγκαία συνθήκη, ενότητα 1.2) η σειρά δεν συγκλίνει.

1.3 · Πράξεις με σειρές και αρχικοί όροι

(α) Αν $\sum a_n = A$ και $\sum b_n = B$ συγκλίνουν και $c \in \mathbb R$, τότε $\sum (a_n + b_n) = A + B$ και $\sum c\,a_n = cA$.

(β) Η σύγκλιση δεν επηρεάζεται από την αλλαγή, προσθήκη ή αφαίρεση πεπερασμένου πλήθους όρων: η $\sum_{n=1}^\infty a_n$ συγκλίνει αν και μόνο αν συγκλίνει η $\sum_{n=m}^\infty a_n$, και τότε $\sum_{n=1}^\infty a_n = a_1 + \cdots + a_{m-1} + \sum_{n=m}^\infty a_n$. Το άθροισμα όμως αλλάζει.

Απόδειξη

(α) Τα μερικά αθροίσματα ικανοποιούν $\sum_{n\le N}(a_n + b_n) = s_N + t_N \to A + B$ από τις ιδιότητες ορίων ακολουθιών. (β) Για $N \ge m$ ισχύει $\sum_{n=1}^N a_n = (a_1 + \cdots + a_{m-1}) + \sum_{n=m}^N a_n$: οι δύο ακολουθίες μερικών αθροισμάτων διαφέρουν κατά σταθερά.

Περιοδικοί δεκαδικοί ως γεωμετρικές σειρές

$0{,}\overline{36} = \frac{36}{100} + \frac{36}{100^2} + \cdots = \dfrac{36/100}{1 - 1/100} = \dfrac{36}{99} = \dfrac{4}{11}$. Με τον ίδιο τρόπο $0{,}\overline{9} = \frac{9/10}{1 - 1/10} = 1$.

Λύση βήμα-βήμα: $\sum_{n=2}^{\infty} \dfrac{3^{n} + (-2)^n}{5^n}$

1. Από την Πρόταση 1.3(α) σπάμε σε δύο γεωμετρικές: $\sum_{n\ge2}\left(\frac35\right)^n + \sum_{n\ge2}\left(-\frac25\right)^n$, αφού και οι δύο συγκλίνουν ($|\lambda| < 1$).

2. $\sum_{n\ge2}\left(\frac35\right)^n = \dfrac{(3/5)^2}{1 - 3/5} = \dfrac{9/25}{2/5} = \dfrac{9}{10}$.

3. $\sum_{n\ge2}\left(-\frac25\right)^n = \dfrac{(-2/5)^2}{1 + 2/5} = \dfrac{4/25}{7/5} = \dfrac{4}{35}$.

4. Άθροισμα: $\frac{9}{10} + \frac{4}{35} = \frac{63 + 8}{70} = \frac{71}{70}$.

Στον εξερευνητή

Μετακίνησε το $\lambda$ της γεωμετρικής σειράς πέρα από το $1$ ή κάτω από το $-1$ και δες πώς τα μερικά αθροίσματα απειρίζονται ή ταλαντεύονται. Σύγκρινε επίσης την αρμονική $\sum\frac1n$ με τη $\sum\frac1{n^2}$.

Πειραματίσου

▮ aₙ · ● s_N = a₁ + … + a_N · a_N = 0, s_N = 1 · |s − s_N| = 0,00003
|λ| < 1: s_N = λ(1 − λᴺ)/(1 − λ) → λ/(1 − λ) = 1

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το άθροισμα $\displaystyle\sum_{n=0}^{\infty}\left(\frac23\right)^n$.
Υπόδειξη: Γεωμετρική με $\lambda = \frac23$.
Λύση: $\dfrac{1}{1 - 2/3} = 3$.
Άσκηση 2Βασική
Να υπολογίσετε το $\displaystyle\sum_{n=1}^{\infty}\frac{3}{4^n}$.
Υπόδειξη: Βγάλτε το $3$ έξω· η σειρά ξεκινά από $n = 1$.
Λύση: $3\cdot\dfrac{1/4}{1 - 1/4} = 3\cdot\dfrac13 = 1$.
Άσκηση 3Βασική
Να υπολογίσετε το $\displaystyle\sum_{n=2}^{\infty}\left(-\frac12\right)^n$ (ως κλάσμα).
Υπόδειξη: $\sum_{n\ge k}\lambda^n = \frac{\lambda^k}{1 - \lambda}$.
Λύση: $\dfrac{(-1/2)^2}{1 + 1/2} = \dfrac{1/4}{3/2} = \dfrac16$.
Άσκηση 4Μέτρια
Να γράψετε τον περιοδικό δεκαδικό $0{,}272727\ldots$ ως ανάγωγο κλάσμα, βλέποντάς τον ως γεωμετρική σειρά.
Υπόδειξη: $0{,}\overline{27} = \sum_{n\ge1} 27\cdot 100^{-n}$.
Λύση: $\dfrac{27/100}{1 - 1/100} = \dfrac{27}{99} = \dfrac{3}{11}$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\displaystyle\sum_{n=1}^{\infty}\frac{2^n + 3^n}{6^n}$ (ως κλάσμα).
Υπόδειξη: $\frac{2^n}{6^n} = \left(\frac13\right)^n$ και $\frac{3^n}{6^n} = \left(\frac12\right)^n$.
Λύση: $\sum\left(\frac13\right)^n + \sum\left(\frac12\right)^n = \dfrac{1/3}{2/3} + \dfrac{1/2}{1/2} = \dfrac12 + 1 = \dfrac32$.
Άσκηση 6Μέτρια
Να υπολογίσετε το $\displaystyle\sum_{n=1}^{\infty}\frac{2^{n+1}}{5^{n}}$ (ως κλάσμα).
Υπόδειξη: $\frac{2^{n+1}}{5^n} = 2\left(\frac25\right)^n$.
Λύση: $2\cdot\dfrac{2/5}{1 - 2/5} = 2\cdot\dfrac{2}{3} = \dfrac43$.
Άσκηση 7Μέτρια
Τα μερικά αθροίσματα της $\sum_{n=1}^\infty (-1)^n$ είναι $-1, 0, -1, 0, \dots$ Τι ισχύει για τη σειρά;
Υπόδειξη: Έχει όριο η ακολουθία $(s_N)$;
Λύση: Οι υπακολουθίες $s_{2k} = 0$ και $s_{2k-1} = -1$ έχουν διαφορετικά όρια, οπότε η $(s_N)$ δεν συγκλίνει· είναι φραγμένη, άρα ούτε απειρίζεται. Η σειρά αποκλίνει χωρίς να απειρίζεται.
Άσκηση 8Απαιτητική
Τα μερικά αθροίσματα μιας σειράς $\sum_{n=1}^\infty a_n$ είναι $s_N = \dfrac{3N}{N + 2}$. Να βρείτε τον όρο $a_5$ και το άθροισμα της σειράς.
Υπόδειξη: $a_N = s_N - s_{N-1}$ και άθροισμα $= \lim s_N$.
Λύση: $a_5 = s_5 - s_4 = \frac{15}{7} - \frac{12}{6} = \frac{15}{7} - 2 = \frac17$. Άθροισμα: $\lim \frac{3N}{N + 2} = 3$.
Άσκηση 9Απαιτητική
Η σειρά $\sum_{n=0}^\infty (x - 1)^n$ συγκλίνει για $0 < x < 2$. Να βρείτε το άθροισμά της για $x = \frac12$ (ως κλάσμα).
Υπόδειξη: Γεωμετρική με $\lambda = x - 1$.
Λύση: $\lambda = -\frac12$, άρα $\sum = \dfrac{1}{1 - (-1/2)} = \dfrac{1}{3/2} = \dfrac23$. Γενικά $\sum = \frac{1}{2 - x}$ για $|x - 1| < 1$.

♾️ Γεννήτρια — γεωμετρικές σειρές

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\sum_{n=1}^{\infty} \frac{2^n + 1}{4^n}$ (ως κλάσμα).
Υπόδειξη: Σπάστε σε δύο γεωμετρικές σειρές (Πρόταση: πράξεις με συγκλίνουσες σειρές).
Λύση: $\displaystyle\sum\left(\tfrac{2}{4}\right)^n + \sum\left(\tfrac{1}{4}\right)^n = \frac{2/4}{1 - 2/4} + \frac{1/4}{1 - 1/4} = 1 + \frac{1}{3} = \frac{4}{3}$.
