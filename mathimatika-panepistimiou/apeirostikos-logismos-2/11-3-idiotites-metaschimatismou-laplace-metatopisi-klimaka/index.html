11.3

Ιδιότητες μετασχηματισμού Laplace: μετατόπιση, κλίμακα, παράγωγοι

📘 Σημειώσεις: Ζαφειρίδου §7.2 (Πρόταση 7.2.1, Θεώρημα 7.2.4) και §7.5 (Θεώρημα 7.5.2, Πόρισμα 7.5.4)

Πώς βρίσκουμε τον μετασχηματισμό Laplace του e^(ax) sin bx ή του x² cos x χωρίς ολοκληρώματα; Με τις ιδιότητες μετατόπισης, κλίμακας και παραγώγισης.

Θεωρία

7.2.1 · Μετατόπιση και κλίμακα

Αν $L\{f\}(p) = F(p)$ για $p > \alpha$, τότε (το (i) της πρότασης στις σημειώσεις είναι η γραμμικότητα):

$$\text{(ii)}\ \ L\{e^{ax}f(x)\}(p) = F(p - a),\ \ p > \alpha + a;\qquad \text{(iii)}\ \ L\{f(ax)\}(p) = \frac1a F\!\left(\frac pa\right),\ \ a > 0,\ p > a\alpha.$$
Απόδειξη

(ii) $\int_0^\infty e^{-px}e^{ax}f(x)\,dx = \int_0^\infty e^{-(p-a)x}f(x)\,dx = F(p - a)$. (iii) Με $u = ax$: $\int_0^\infty e^{-px}f(ax)\,dx = \frac1a\int_0^\infty e^{-(p/a)u}f(u)\,du = \frac1aF\!\left(\frac pa\right)$.

Παράδειγμα · μετατόπιση

$L\{e^{2x}\sin 3x\}$ – Λύση

$L\{\sin 3x\} = \frac{3}{p^2 + 9}$, άρα $L\{e^{2x}\sin 3x\} = \frac{3}{(p - 2)^2 + 9}$, $p > 2$. Ομοίως $L\{x^ne^{ax}\} = \frac{n!}{(p - a)^{n+1}}$.

7.2.4 · Πολλαπλασιασμός με $x^n$

Αν η $f$ είναι κατά τμήματα συνεχής και εκθετικής τάξης $\alpha$, για $p > \alpha$:

$$L\{x^nf(x)\}(p) = (-1)^n F^{(n)}(p).$$
Απόδειξη για $n = 1$

Παραγωγίζοντας υπό το ολοκλήρωμα (επιτρέπεται για συναρτήσεις εκθετικής τάξης): $F'(p) = \int_0^\infty\frac{\partial}{\partial p}e^{-px}f(x)\,dx = -\int_0^\infty xe^{-px}f(x)\,dx = -L\{xf\}$. Επαγωγικά για κάθε $n$.

Π.χ. $L\{x\sin x\} = -\frac{d}{dp}\frac{1}{p^2 + 1} = \frac{2p}{(p^2 + 1)^2}$.

7.5.2 · Μετασχηματισμός παραγώγου

Αν η $f$ είναι συνεχής στο $[0, \infty)$, η $f'$ κατά τμήματα συνεχής και $|f(x)| \le Me^{ax}$ για $x \ge X_0$, τότε για $p > a$:

$$L\{f'\}(p) = p\,L\{f\}(p) - f(0).$$
Απόδειξη

Παραγοντική ολοκλήρωση: $\int_0^X e^{-px}f'(x)\,dx = \left[e^{-px}f(x)\right]_0^X + p\int_0^X e^{-px}f(x)\,dx$. Για $p > a$: $|e^{-pX}f(X)| \le Me^{-(p-a)X}\to 0$, οπότε απομένει $-f(0) + pL\{f\}$.

7.5.4 · Ανώτερες παράγωγοι

Αν οι $f, f', \dots, f^{(n-1)}$ είναι συνεχείς στο $[0, \infty)$ και εκθετικής τάξης, και η $f^{(n)}$ κατά τμήματα συνεχής, τότε για $p$ αρκετά μεγάλο:

$$L\{f''\} = p^2L\{f\} - pf(0) - f'(0),\qquad L\{f^{(n)}\} = p^nL\{f\} - \sum_{k=1}^{n}p^{n-k}f^{(k-1)}(0).$$

Αυτό είναι το «μυστικό» του μετασχηματισμού: η παραγώγιση γίνεται πολλαπλασιασμός με $p$, οπότε οι γραμμικές ΔΕ γίνονται αλγεβρικές εξισώσεις (11.5).

Παράδειγμα · $L\{x^2\cos x\}$

Λύση βήμα-βήμα

$F(p) = \frac{p}{p^2 + 1}$, $F'(p) = \frac{1 - p^2}{(p^2 + 1)^2}$, $F''(p) = \frac{2p^3 - 6p}{(p^2 + 1)^3}$. Άρα $L\{x^2\cos x\} = F''(p)$ και στο $p = 1$: $\frac{2 - 6}{8} = -\frac12$.

Συχνά λάθη

Στη μετατόπιση γράφουμε $F(p + a)$ αντί για $F(p - a)$ (το $e^{2x}$ μετατοπίζει δεξιά, $p\mapsto p - 2$)· ξεχνάμε το $(-1)^n$ στο 7.2.4· ξεχνάμε τους όρους $f(0)$, $f'(0)$ στον μετασχηματισμό παραγώγων.

Πειραματίσου

γκρι: f(x) και F(p) · e−0,5xf(x) · F(p − −0,5)
Πολλαπλασιάζοντας την f με eax, η μετασχηματισμένη απλώς μετατοπίζεται κατά a (δεξιά αν a > 0, αριστερά αν a < 0 — Πρόταση 7.2.1(ii)) — και το διάστημα σύγκλισης γίνεται p > −0,5.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να βρείτε το $L\{e^{2x}\sin 3x\}(p)$ για $p = 3$.
Υπόδειξη: $\frac{3}{(p - 2)^2 + 9}$, $p > 2$.
Λύση: Στο $p = 3$ (ανήκει στην περιοχή σύγκλισης $p > 2$): $\frac{3}{1 + 9} = \frac{3}{10}$.
Άσκηση 2Βασική
Να βρείτε το $L\{x^2e^{-x}\}(p)$ για $p = 1$.
Υπόδειξη: $\frac{2!}{(p + 1)^3}$.
Λύση: $\frac{2}{8} = \frac14$.
Άσκηση 3Μέτρια
Να βρείτε το $L\{x\sin x\}(p)$ για $p = 1$.
Υπόδειξη: Θεώρημα 7.2.4: $-\frac{d}{dp}\frac{1}{p^2 + 1}$.
Λύση: $\frac{2p}{(p^2 + 1)^2}$ στο $p = 1$: $\frac24 = \frac12$.
Άσκηση 4Βασική
Να βρείτε το $L\{xe^{2x}\}(p)$ για $p = 4$.
Υπόδειξη: $\frac{1}{(p - 2)^2}$.
Λύση: $\frac{1}{4}$.
Άσκηση 5Μέτρια
Για $f(x) = 3e^{-2x}$ να βρείτε το $L\{f'\}(p)$ στο $p = 1$ με τον τύπο $L\{f'\} = pL\{f\} - f(0)$.
Υπόδειξη: $L\{f\} = \frac{3}{p + 2}$, $f(0) = 3$.
Λύση: $1\cdot\frac33 - 3 = -2$. (Έλεγχος: $f' = -6e^{-2x}$, $L\{f'\}(1) = -\frac63 = -2$ ✓.)
Άσκηση 6Μέτρια
Δεδομένου ότι $L\{\sin x\} = \frac{1}{p^2 + 1}$, με την ιδιότητα κλίμακας να βρείτε το $L\{\sin 3x\}(p)$ για $p = 3$.
Υπόδειξη: $L\{f(ax)\} = \frac1aF\!\left(\frac pa\right)$.
Λύση: $\frac13\cdot\frac{1}{(p/3)^2 + 1} = \frac{3}{p^2 + 9}$· στο $p = 3$: $\frac{3}{18} = \frac16$.
Άσκηση 7Απαιτητική
Να βρείτε το $L\{x^2\cos x\}(p)$ για $p = 1$.
Υπόδειξη: $L\{x^2f\} = F''(p)$ με $F(p) = \frac{p}{p^2 + 1}$.
Λύση: $F''(p) = \frac{2p^3 - 6p}{(p^2 + 1)^3}$, στο $p = 1$: $\frac{-4}{8} = -\frac12$.
Άσκηση 8Μέτρια
Αν $L\{f\}(p) = F(p)$, τότε $L\{e^{-3x}f(x)\}(p)$ ισούται με:
Υπόδειξη: $L\{e^{ax}f\} = F(p - a)$ με $a = -3$.
Λύση: $F(p - (-3)) = F(p + 3)$.
Άσκηση 9Απαιτητική
Αν $f$ συνεχής με κατά τμήματα συνεχή $f''$ (και εκθετικής τάξης μαζί με την $f'$), ο $L\{f''\}$ ισούται με:
Υπόδειξη: Εφαρμόστε δύο φορές το 7.5.2.
Λύση: $L\{f''\} = pL\{f'\} - f'(0) = p(pL\{f\} - f(0)) - f'(0)$.

♾️ Γεννήτρια — ιδιότητες του μετασχηματισμού Laplace

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Αν $L\{f\}(p) = \dfrac{5}{p + 1}$ και $f(0) = 5$, να βρείτε το $L\{f'\}(p)$ για $p = 1$.
Υπόδειξη: $L\{f'\} = p\,L\{f\} - f(0)$.
Λύση: $1\cdot\frac{5}{2} - 5 = \frac{5 - 10}{2} = -\frac{5}{2}$. (Πράγματι $f = 5e^{-x}$.)
