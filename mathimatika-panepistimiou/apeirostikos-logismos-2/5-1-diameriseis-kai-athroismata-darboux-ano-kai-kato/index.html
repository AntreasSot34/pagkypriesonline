5.1

Διαμερίσεις και αθροίσματα Darboux (άνω και κάτω αθροίσματα)

📘 Σημειώσεις: Τσολομύτης κεφ. 7 §7.1 (Ορ. 7.1–7.5, Πρ. 7.6, Πόρ. 7.7) · Ζαφειρίδου §4.1–4.2

Πώς ορίζεται αυστηρά το εμβαδόν κάτω από μια καμπύλη; Διαμερίσεις, λεπτότητα, εκλέπτυνση και τα άνω και κάτω αθροίσματα Darboux L(f, 𝒫) και U(f, 𝒫) με λυμένα παραδείγματα.

Θεωρία

Το ολοκλήρωμα Riemann κατασκευάζεται με τον τρόπο του Darboux: προσεγγίζουμε το εμβαδόν κάτω από τη γραφική παράσταση μιας φραγμένης συνάρτησης από κάτω και από πάνω με αθροίσματα εμβαδών ορθογωνίων. Τα αθροίσματα Darboux είναι τα δομικά στοιχεία όλης της θεωρίας ολοκλήρωσης στον Απειροστικό ΙΙ.

Διαμέριση, λεπτότητα, εκλέπτυνση

Μια διαμέριση του $[a, b]$ είναι ένα πεπερασμένο σύνολο $\mathcal P = \{x_0, x_1, \dots, x_n\}$ με $a = x_0 < x_1 < \dots < x_n = b$. Γράφουμε $\Delta x_j = x_j - x_{j-1}$.

Η λεπτότητα (ή πλάτος) της $\mathcal P$ είναι $\|\mathcal P\| = \max_j \Delta x_j$. Η ισαπέχουσα διαμέριση $\mathcal P_n$ έχει $x_j = a + j\frac{b - a}{n}$ και $\|\mathcal P_n\| = \frac{b - a}{n}$.

Μια διαμέριση $\mathcal Q$ λέγεται εκλέπτυνση της $\mathcal P$ αν $\mathcal P \subseteq \mathcal Q$ (προσθέτουμε σημεία).

Άνω και κάτω αθροίσματα Darboux

Έστω $f: [a, b] \to \mathbb R$ φραγμένη και $\mathcal P$ διαμέριση. Σε κάθε υποδιάστημα θέτουμε

$$m_j = \inf_{[x_{j-1}, x_j]} f, \qquad M_j = \sup_{[x_{j-1}, x_j]} f,$$ $$L(f, \mathcal P) = \sum_{j=1}^{n} m_j\,\Delta x_j, \qquad U(f, \mathcal P) = \sum_{j=1}^{n} M_j\,\Delta x_j.$$

Το $L(f, \mathcal P)$ είναι το κάτω άθροισμα και το $U(f, \mathcal P)$ το άνω άθροισμα Darboux. Προφανώς $m(b - a) \le L(f, \mathcal P) \le U(f, \mathcal P) \le M(b - a)$, όπου $m = \inf f$, $M = \sup f$.

$f(x) = x^2$ στο $[0, 1]$, ισαπέχουσα με $n$ υποδιαστήματα

Η $f$ είναι αύξουσα, άρα $m_j = f(x_{j-1}) = \frac{(j-1)^2}{n^2}$ και $M_j = f(x_j) = \frac{j^2}{n^2}$, με $\Delta x_j = \frac1n$. Με τον τύπο $\sum_{k=1}^{m} k^2 = \frac{m(m+1)(2m+1)}{6}$:

$$L(f, \mathcal P_n) = \frac{(n-1)n(2n-1)}{6n^3}, \qquad U(f, \mathcal P_n) = \frac{n(n+1)(2n+1)}{6n^3}.$$

Για $n = 4$: $L = \frac{3\cdot4\cdot7}{384} = \frac7{32}$, $U = \frac{4\cdot5\cdot9}{384} = \frac{15}{32}$, $U - L = \frac14 = \frac1n$. Καθώς $n \to \infty$ και τα δύο τείνουν στο $\frac13$.

Μονοτονία ως προς την εκλέπτυνση

Αν η $\mathcal Q$ είναι εκλέπτυνση της $\mathcal P$, τότε

$$L(f, \mathcal P) \le L(f, \mathcal Q) \le U(f, \mathcal Q) \le U(f, \mathcal P).$$
Απόδειξη

Αρκεί να προσθέσουμε ένα σημείο $y \in (x_{j-1}, x_j)$. Τα $\inf$ στα δύο νέα υποδιαστήματα $[x_{j-1}, y]$, $[y, x_j]$ είναι $\ge m_j$ (inf σε μικρότερο σύνολο), οπότε $m_j\Delta x_j \le m'(y - x_{j-1}) + m''(x_j - y)$. Οι υπόλοιποι όροι μένουν ίδιοι, άρα το $L$ αυξάνεται (ή μένει ίδιο). Συμμετρικά για το $U$. Για περισσότερα σημεία, επαγωγή.

Κάθε κάτω άθροισμα ≤ κάθε άνω άθροισμα

Για οποιεσδήποτε διαμερίσεις $\mathcal P_1, \mathcal P_2$ του $[a, b]$: $L(f, \mathcal P_1) \le U(f, \mathcal P_2)$.

Απόδειξη

Η κοινή εκλέπτυνση $\mathcal Q = \mathcal P_1 \cup \mathcal P_2$ δίνει $L(f, \mathcal P_1) \le L(f, \mathcal Q) \le U(f, \mathcal Q) \le U(f, \mathcal P_2)$.

Λύση βήμα-βήμα: $f(x) = \frac1x$ στο $[1, 2]$, $\mathcal P = \{1, 1{,}5, 2\}$

1. Η $\frac1x$ είναι φθίνουσα: $m_j$ στο δεξί άκρο, $M_j$ στο αριστερό.

2. $[1, 1{,}5]$: $m_1 = \frac23$, $M_1 = 1$. $[1{,}5, 2]$: $m_2 = \frac12$, $M_2 = \frac23$.

3. $L = \frac12\left(\frac23 + \frac12\right) = \frac7{12}$, $U = \frac12\left(1 + \frac23\right) = \frac56$.

4. Πράγματι $\frac7{12} \approx 0{,}583 \le \ln 2 \approx 0{,}693 \le \frac56 \approx 0{,}833$.

Μη μονότονες συναρτήσεις

Για μη μονότονη $f$ τα $m_j, M_j$ δεν βρίσκονται απαραίτητα στα άκρα. Π.χ. $\sin x$ στο $[0, \pi]$ με $\mathcal P = \{0, \frac\pi2, \pi\}$: σε κάθε μισό, $m_j = 0$ και $M_j = 1$ (στο $\frac\pi2$), άρα $L = 0$ και $U = \pi$.

Στο διαδραστικό αλλάξτε το $n$ και πατήστε «εκλέπτυνση»: το πράσινο εμβαδόν (κάτω άθροισμα) μόνο μεγαλώνει, το πορτοκαλί (άνω άθροισμα) μόνο μικραίνει.

Πειραματίσου

Διαμέριση με 4 υποδιαστήματα, λεπτότητα ‖𝒫‖ = 0,25.
L(f, 𝒫) = 0,21875 ≤ ∫ = 0,33333 ≤ U(f, 𝒫) = 0,46875 · U − L = 0,25
Πάτα «εκλέπτυνση»: το L μπορεί μόνο να αυξηθεί και το U μόνο να μειωθεί (Πρόταση μονοτονίας ως προς την εκλέπτυνση).

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Για την $f(x) = x$ στο $[0, 1]$ και την ισαπέχουσα διαμέριση με $n = 4$, να βρείτε $L(f, \mathcal P)$ και $U(f, \mathcal P)$.
Υπόδειξη: $\Delta x = \frac14$, $m_j = \frac{j-1}{4}$, $M_j = \frac j4$.
Λύση: $L = \frac14\left(0 + \frac14 + \frac24 + \frac34\right) = \frac{6}{16} = \frac38$, $U = \frac14\left(\frac14 + \frac24 + \frac34 + 1\right) = \frac{10}{16} = \frac58$.
Άσκηση 2Βασική
Για την $f(x) = x^2$ στο $[0, 2]$ και $\mathcal P = \{0, 1, 2\}$, να βρείτε $L$ και $U$.
Υπόδειξη: Αύξουσα στο $[0, 2]$.
Λύση: $L = 1\cdot0 + 1\cdot1 = 1$, $U = 1\cdot1 + 1\cdot4 = 5$.
Άσκηση 3Βασική
Ποια είναι η λεπτότητα της διαμέρισης $\mathcal P = \{0;\ 0{,}5;\ 1{,}2;\ 2;\ 3\}$ του $[0, 3]$;
Υπόδειξη: Μέγιστο μήκος υποδιαστήματος.
Λύση: Μήκη: $0{,}5$, $0{,}7$, $0{,}8$, $1$. Άρα $\|\mathcal P\| = 1$.
Άσκηση 4Μέτρια
Για την $f(x) = x^2$ στο $[0, 1]$ και την ισαπέχουσα $\mathcal P_4$, να βρείτε $L$, $U$ και $U - L$.
Υπόδειξη: $L = \frac{1}{64}(0 + 1 + 4 + 9)$.
Λύση: $L = \frac14\cdot\frac{0 + 1 + 4 + 9}{16} = \frac{14}{64} = \frac7{32}$, $U = \frac14\cdot\frac{1 + 4 + 9 + 16}{16} = \frac{30}{64} = \frac{15}{32}$, $U - L = \frac{16}{64} = \frac14$.
Άσκηση 5Μέτρια
Για την $f(x) = \frac1x$ στο $[1, 2]$ και $\mathcal P = \{1;\ 1{,}5;\ 2\}$, να βρείτε $L$ και $U$.
Υπόδειξη: Φθίνουσα: $M_j$ στο αριστερό άκρο.
Λύση: $L = \frac12\left(\frac23 + \frac12\right) = \frac7{12}$, $U = \frac12\left(1 + \frac23\right) = \frac56$.
Άσκηση 6Μέτρια
Για την $f(x) = \sin x$ στο $[0, \pi]$ και $\mathcal P = \{0, \frac\pi2, \pi\}$, να βρείτε $L$ και $U$ (το $U$ με 5 δεκαδικά).
Υπόδειξη: Σε κάθε μισό το inf είναι 0 και το sup 1.
Λύση: $L = \frac\pi2(0 + 0) = 0$, $U = \frac\pi2(1 + 1) = \pi$.
Άσκηση 7Μέτρια
Για την $f(x) = x^3$ στο $[0, 1]$ και την ισαπέχουσα $\mathcal P_{10}$, να βρείτε το $U(f, \mathcal P_{10})$.
Υπόδειξη: $\sum_{k=1}^{n} k^3 = \left(\frac{n(n+1)}{2}\right)^2$.
Λύση: $U = \frac{1}{10^4}\sum_{k=1}^{10}k^3 = \frac{55^2}{10^4} = \frac{3025}{10000} = \frac{121}{400}$.
Άσκηση 8Μέτρια
Αν η $\mathcal Q$ είναι εκλέπτυνση της $\mathcal P$, τότε πάντα $U(f, \mathcal Q) \le U(f, \mathcal P)$.
Υπόδειξη: Το sup σε μικρότερο σύνολο είναι μικρότερο ή ίσο.
Λύση: Προσθέτοντας σημεία, κάθε $M_j\Delta x_j$ αντικαθίσταται από $M'(y - x_{j-1}) + M''(x_j - y)$ με $M', M'' \le M_j$.
Άσκηση 9Απαιτητική
Για οποιεσδήποτε διαμερίσεις $\mathcal P_1, \mathcal P_2$ του $[a, b]$ ισχύει $L(f, \mathcal P_1) \le U(f, \mathcal P_2)$, ακόμη κι αν καμία δεν είναι εκλέπτυνση της άλλης.
Υπόδειξη: Κοινή εκλέπτυνση.
Λύση: Με $\mathcal Q = \mathcal P_1 \cup \mathcal P_2$: $L(f, \mathcal P_1) \le L(f, \mathcal Q) \le U(f, \mathcal Q) \le U(f, \mathcal P_2)$.

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Για την $f(x) = x$ στο $[0, 1]$ και την ισαπέχουσα διαμέριση με $n = 3$ υποδιαστήματα, να βρείτε $L(f, \mathcal P)$ και $U(f, \mathcal P)$.
Υπόδειξη: Αύξουσα: $m_j = f(x_{j-1})$, $M_j = f(x_j)$, $\Delta x = \frac{1}{3}$.
Λύση: $L = \sum_{j=1}^{3} f(x_{j-1})\Delta x = \frac{1}{3}$, $U = \sum f(x_j)\Delta x = \frac{2}{3}$ (και $U - L = \frac{1}{3}$).
