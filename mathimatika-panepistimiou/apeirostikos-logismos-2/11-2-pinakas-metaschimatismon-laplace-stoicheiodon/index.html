11.2

Πίνακας μετασχηματισμών Laplace στοιχειωδών συναρτήσεων

📘 Σημειώσεις: Ζαφειρίδου §7.1 (Πρόταση 7.1.1) και γραμμικότητα (Πρόταση 7.2.1)

Ποιος είναι ο μετασχηματισμός Laplace των 1, xⁿ, e^(ax), sin ax, cos ax; Ένας μικρός πίνακας και η γραμμικότητα αρκούν για τις περισσότερες ασκήσεις.

Θεωρία

7.1.1 · Βασικοί μετασχηματισμοί

$f(x)$$F(p) = L\{f\}(p)$για
$1$$\dfrac1p$$p > 0$
$x^n$, $n \in \mathbb N$$\dfrac{n!}{p^{n+1}}$$p > 0$
$e^{ax}$$\dfrac{1}{p - a}$$p > a$
$\sin ax$$\dfrac{a}{p^2 + a^2}$$p > 0$
$\cos ax$$\dfrac{p}{p^2 + a^2}$$p > 0$
$\sinh ax$$\dfrac{a}{p^2 - a^2}$$p > |a|$
$\cosh ax$$\dfrac{p}{p^2 - a^2}$$p > |a|$
Απόδειξη για $x^n$ (επαγωγή)

Με παραγοντική ολοκλήρωση: $\int_0^\infty x^ne^{-px}\,dx = \left[-\frac{x^n e^{-px}}{p}\right]_0^\infty + \frac np\int_0^\infty x^{n-1}e^{-px}\,dx = \frac np L\{x^{n-1}\}$, για $p > 0$. Με $L\{1\} = \frac1p$ προκύπτει $L\{x^n\} = \frac{n}{p}\cdot\frac{n-1}{p}\cdots\frac1p\cdot\frac1p = \frac{n!}{p^{n+1}}$.

Απόδειξη για $\sin ax$, $\cos ax$

Θέτουμε $S = L\{\sin ax\}$, $C = L\{\cos ax\}$. Δύο παραγοντικές ολοκληρώσεις δίνουν $S = \frac ap C$ και $C = \frac1p - \frac ap S$. Λύνοντας το σύστημα: $S = \frac{a}{p^2 + a^2}$, $C = \frac{p}{p^2 + a^2}$. (Εναλλακτικά: $L\{e^{iax}\} = \frac{1}{p - ia} = \frac{p + ia}{p^2 + a^2}$ και παίρνουμε πραγματικό/φανταστικό μέρος.)

Γραμμικότητα

$$L\{\lambda f + \mu g\} = \lambda L\{f\} + \mu L\{g\}$$

στο κοινό διάστημα σύγκλισης· προκύπτει αμέσως από τη γραμμικότητα του ολοκληρώματος. Π.χ. $\sinh ax = \frac{e^{ax} - e^{-ax}}{2}$ δίνει $L\{\sinh ax\} = \frac12\left(\frac{1}{p - a} - \frac{1}{p + a}\right) = \frac{a}{p^2 - a^2}$.

Παράδειγμα

$L\{5 - 2x + 3e^{-x}\}$.

Λύση βήμα-βήμα

Γραμμικότητα: $5\cdot\frac1p - 2\cdot\frac{1}{p^2} + 3\cdot\frac{1}{p + 1}$, για $p > 0$. Στο $p = 1$: $5 - 2 + \frac32 = 4{,}5$.

Παράδειγμα · τριγωνομετρική ταυτότητα

$L\{\cos^2 x\}$.

Λύση βήμα-βήμα

$\cos^2x = \frac{1 + \cos 2x}{2}$, άρα $L\{\cos^2x\} = \frac{1}{2p} + \frac{p}{2(p^2 + 4)} = \frac{p^2 + 2}{p(p^2 + 4)}$. Στο $p = 1$: $\frac35$.

Συχνά λάθη

$L\{f g\} \ne L\{f\}\cdot L\{g\}$ — ο μετασχηματισμός γινομένου δεν είναι γινόμενο μετασχηματισμών· μπερδεύουμε $a$ και $p$ στους αριθμητές των $\sin$, $\cos$· γράφουμε $L\{x^n\} = \frac{n!}{p^n}$ (ο εκθέτης είναι $n + 1$).

Πειραματίσου

αριστερά: f(x) = x^n με n = 2 · δεξιά: F(p) = L{f}(p) = n!/p^(n+1)
στο p = 3: τύπος F(p) = 0,0741 · αριθμητικά ∫₀^∞ e−pxf(x)dx ≈ 0,0741
Ο μετασχηματισμός μετατρέπει συναρτήσεις του x σε (απλές, ρητές) συναρτήσεις του p, που ορίζονται για p μεγαλύτερο από κάποιο a.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να βρείτε το $L\{e^{3x}\}(p)$ για $p = 5$.
Υπόδειξη: $L\{e^{ax}\} = \frac{1}{p - a}$.
Λύση: $\frac{1}{5 - 3} = \frac12$.
Άσκηση 2Βασική
Να βρείτε το $L\{x^2\}(p)$ για $p = 2$.
Υπόδειξη: $\frac{2!}{p^3}$.
Λύση: $\frac{2}{8} = \frac14$.
Άσκηση 3Βασική
Να βρείτε το $L\{\sin 2x\}(p)$ για $p = 1$.
Υπόδειξη: $\frac{a}{p^2 + a^2}$.
Λύση: $\frac{2}{1 + 4} = \frac25$.
Άσκηση 4Βασική
Να βρείτε το $L\{\cos 3x\}(p)$ για $p = 4$.
Υπόδειξη: $\frac{p}{p^2 + a^2}$.
Λύση: $\frac{4}{16 + 9} = \frac{4}{25}$.
Άσκηση 5Μέτρια
Να βρείτε το $L\{5 - 2x + 3e^{-x}\}(p)$ για $p = 1$.
Υπόδειξη: Γραμμικότητα.
Λύση: $\frac51 - \frac21 + \frac32 = 4{,}5$.
Άσκηση 6Μέτρια
Να βρείτε το $L\{x^3\}(p)$ για $p = 3$.
Υπόδειξη: $\frac{3!}{p^4}$.
Λύση: $\frac{6}{81} = \frac{2}{27}$.
Άσκηση 7Μέτρια
Να βρείτε το $L\{(x + 1)^2\}(p)$ για $p = 1$.
Υπόδειξη: Αναπτύξτε: $x^2 + 2x + 1$.
Λύση: $\frac{2}{p^3} + \frac{2}{p^2} + \frac1p$ στο $p = 1$: $2 + 2 + 1 = 5$.
Άσκηση 8Μέτρια
Να βρείτε το $L\{\sinh 2x\}(p)$ για $p = 3$.
Υπόδειξη: $\sinh 2x = \frac{e^{2x} - e^{-2x}}{2}$.
Λύση: $\frac{2}{p^2 - 4}$ στο $p = 3$: $\frac25$.
Άσκηση 9Απαιτητική
Να βρείτε το $L\{\cos^2 x\}(p)$ για $p = 1$.
Υπόδειξη: $\cos^2x = \frac{1 + \cos 2x}{2}$.
Λύση: $\frac{1}{2p} + \frac{p}{2(p^2 + 4)}$ στο $p = 1$: $\frac12 + \frac{1}{10} = \frac35$.
Άσκηση 10Βασική
Ισχύει $L\{f\cdot g\} = L\{f\}\cdot L\{g\}$ για κάθε $f, g$ που έχουν μετασχηματισμό.
Υπόδειξη: Δοκιμάστε $f = g = 1$.
Λύση: Λάθος: $L\{1\cdot 1\} = \frac1p$, ενώ $L\{1\}\cdot L\{1\} = \frac{1}{p^2}$.
