4.4

Θεώρημα σταθερού σημείου και συστολές

📘 Σημειώσεις: Τσολομύτης κεφ. 6 §6.2 (Ορ. 6.7, Θ. 6.8)

Τι είναι μια συστολή και γιατί έχει ακριβώς ένα σταθερό σημείο; Πώς η επανάληψη $x_{n+1} = f(x_n)$ υπολογίζει λύσεις εξισώσεων όπως $\cos x = x$ — με εκτίμηση σφάλματος;

Θεωρία

Το θεώρημα σταθερού σημείου για συστολές (θεώρημα Banach) είναι μία από τις πιο χρήσιμες εφαρμογές της συνθήκης Lipschitz. Εγγυάται ύπαρξη και μοναδικότητα λύσης της εξίσωσης $f(x) = x$ και, επιπλέον, δίνει έναν αλγόριθμο για να την υπολογίσουμε με όση ακρίβεια θέλουμε.

Συστολή

Έστω $A \subseteq \mathbb R$ κλειστό και μη κενό. Η $f: A \to A$ λέγεται συστολή αν υπάρχει $0 \le L < 1$ τέτοιο ώστε

$$|f(x) - f(t)| \le L\,|x - t| \qquad \text{για όλα τα } x, t \in A.$$

Δηλαδή η $f$ είναι Lipschitz με σταθερά μικρότερη του 1: «φέρνει πιο κοντά» οποιαδήποτε δύο σημεία. Ένα $t_0$ με $f(t_0) = t_0$ λέγεται σταθερό σημείο της $f$.

Θεώρημα σταθερού σημείου

Κάθε συστολή $f: A \to A$ ($A \subseteq \mathbb R$ κλειστό, μη κενό — π.χ. $A = \mathbb R$ ή $A = [a, b]$) έχει ακριβώς ένα σταθερό σημείο $t_0 \in A$. Επιπλέον, για οποιοδήποτε $x_1 \in A$, η ακολουθία $x_{n+1} = f(x_n)$ συγκλίνει στο $t_0$ και

$$|x_m - t_0| \le \frac{L^{m-1}}{1 - L}\,|x_2 - x_1|.$$
Απόδειξη

Μοναδικότητα. Αν $f(t_0) = t_0$ και $f(s_0) = s_0$ με $t_0 \ne s_0$, τότε $|t_0 - s_0| = |f(t_0) - f(s_0)| \le L|t_0 - s_0| < |t_0 - s_0|$, άτοπο.

Βήμα 1. Επαγωγικά $|x_{n+1} - x_n| = |f(x_n) - f(x_{n-1})| \le L|x_n - x_{n-1}| \le \dots \le L^{n-1}|x_2 - x_1|$.

Βήμα 2 (Cauchy). Για $m > n$: $|x_m - x_n| \le \sum_{k=n}^{m-1}|x_{k+1} - x_k| \le (L^{n-1} + \dots + L^{m-2})|x_2 - x_1| \le \frac{L^{n-1}}{1 - L}|x_2 - x_1| \to 0$. Άρα η $(x_n)$ είναι Cauchy και συγκλίνει σε κάποιο $t_0$· αφού $x_n \in A$ και το $A$ είναι κλειστό, $t_0 \in A$.

Βήμα 3. Η $f$ είναι συνεχής (Lipschitz), άρα από $x_{n+1} = f(x_n)$ με $n \to \infty$: $t_0 = f(t_0)$. Η εκτίμηση σφάλματος προκύπτει από το Βήμα 2 με $m \to \infty$ (αλλάζοντας ρόλους $n \leftrightarrow m$).

Η εξίσωση $\cos x = x$

Η $\cos$ δεν είναι συστολή σε όλο το $\mathbb R$ ($|\sin x|$ φτάνει το 1), αλλά από $x_2 = \cos x_1 \in [-1, 1]$ και $x_3 \in [\cos 1, 1] \subseteq [0{,}54, 1]$ οι επαναλήψεις μένουν στο $[0{,}54, 1]$, όπου $|\sin x| \le \sin 1 \approx 0{,}84 < 1$. Η απόδειξη περνά αυτούσια, οπότε $x_n \to t_0 \approx 0{,}739085$, η μοναδική λύση της $\cos x = x$.

Ομοίως η $g(x) = \frac{\cos x}{2}$ είναι συστολή σε όλο το $\mathbb R$ ($|g'| \le \frac12$) με σταθερό σημείο $\approx 0{,}450184$.

Λύση βήμα-βήμα: η $f(x) = \frac x2 + 1$ με $x_1 = 0$

1. $|f(x) - f(t)| = \frac12|x - t|$, άρα συστολή με $L = \frac12$.

2. Σταθερό σημείο: $t = \frac t2 + 1 \iff t_0 = 2$.

3. Επαναλήψεις: $x_2 = 1$, $x_3 = 1{,}5$, $x_4 = 1{,}75$, $x_5 = 1{,}875$ — το σφάλμα υποδιπλασιάζεται σε κάθε βήμα.

4. Εκτίμηση: $|x_m - 2| \le \frac{(1/2)^{m-1}}{1/2}\cdot|x_2 - x_1| = \frac{1}{2^{m-2}}$· για $m = 4$ δίνει $\frac14$, ενώ το πραγματικό σφάλμα είναι $0{,}25$ — η εκτίμηση είναι ακριβής εδώ.

Υπολογισμός του $\sqrt2$

Η $f(x) = x - \frac{x^2 - 2}{4}$ απεικονίζει το $[1, 2]$ στον εαυτό του και $f'(x) = 1 - \frac x2 \in [0, \frac12]$, άρα είναι συστολή εκεί με $L = \frac12$. Σταθερό σημείο: $f(t) = t \iff t^2 = 2 \iff t_0 = \sqrt2 \approx 1{,}41421$.

Η συνθήκη $L < 1$ είναι απαραίτητη

• Η $f(x) = x + 1$ έχει $L = 1$ και κανένα σταθερό σημείο.

• Η $f(x) = x + \frac{1}{1 + e^x}$ ικανοποιεί $|f(x) - f(t)| < |x - t|$ για $x \ne t$, αλλά $f(x) > x$ πάντα: κανένα σταθερό σημείο. Χρειάζεται ομοιόμορφη σταθερά $L < 1$.

Πόσες επαναλήψεις χρειάζομαι;

Για ακρίβεια $\eta$ αρκεί $\frac{L^{m-1}}{1 - L}|x_2 - x_1| < \eta$. Με $L = \frac12$ και $|x_2 - x_1| = 1$: $\frac{1}{2^{m-2}} < 10^{-3} \iff 2^{m-2} > 1000 \iff m - 2 \ge 10$, άρα $m = 12$.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να βρείτε το σταθερό σημείο της συστολής $f(x) = \frac x3 + 4$.
Υπόδειξη: Λύστε $t = \frac t3 + 4$.
Λύση: $\frac{2t}{3} = 4 \iff t_0 = 6$.
Άσκηση 2Βασική
Για την $f(x) = \frac x2 + 1$ και $x_1 = 0$ με $x_{n+1} = f(x_n)$, να βρείτε (α) το $x_4$ και (β) το σταθερό σημείο.
Υπόδειξη: $x_2 = 1$, $x_3 = 1{,}5$.
Λύση: (α) $x_4 = \frac{1{,}5}{2} + 1 = 1{,}75$. (β) $t = \frac t2 + 1 \iff t_0 = 2$.
Άσκηση 3Βασική
Η $f(x) = x + 1$ είναι συστολή στο $\mathbb R$.
Υπόδειξη: $|f(x) - f(t)| = |x - t|$.
Λύση: Η σταθερά είναι $L = 1$, όχι $< 1$. Και πράγματι η $f$ δεν έχει σταθερό σημείο.
Άσκηση 4Μέτρια
Η $g(x) = \frac{\cos x}{2}$ είναι συστολή στο $\mathbb R$. Να βρείτε (α) μια σταθερά $L$ από την παράγωγο και (β) το σταθερό σημείο της (6 δεκαδικά, με επαναλήψεις).
Υπόδειξη: $|g'(x)| = \frac{|\sin x|}{2} \le \frac12$.
Λύση: (α) $L = \frac12$. (β) Ξεκινώντας από $x_1 = 0$: $0{,}5$, $0{,}4388$, $0{,}4526$, … $\to 0{,}450184$.
Άσκηση 5Μέτρια
Η $h(x) = \frac{e^{-x}}{3}$ είναι συστολή στο $[0, \infty)$. Να βρείτε το σταθερό σημείο της (6 δεκαδικά).
Υπόδειξη: $|h'(x)| = \frac{e^{-x}}{3} \le \frac13$ στο $[0, \infty)$· επαναλάβετε από $x_1 = 0$.
Λύση: $x_2 = 0{,}3333$, $x_3 = 0{,}2388$, $x_4 = 0{,}2625$, … $\to 0{,}257628$, η μοναδική λύση της $3x = e^{-x}$.
Άσκηση 6Μέτρια
Η $f(x) = x - \frac{x^2 - 2}{4}$ είναι συστολή στο $[1, 2]$. Να βρείτε το σταθερό σημείο της (5 δεκαδικά).
Υπόδειξη: $f(t) = t \iff t^2 = 2$.
Λύση: $t_0 = \sqrt2 \approx 1{,}41421$.
Άσκηση 7Μέτρια
Συστολή με $L = \frac12$ και $|x_2 - x_1| = 1$. Ποιο άνω φράγμα δίνει η εκτίμηση $|x_m - t_0| \le \frac{L^{m-1}}{1 - L}|x_2 - x_1|$ για $m = 6$;
Υπόδειξη: $\frac{(1/2)^5}{1/2}$.
Λύση: $\frac{1/32}{1/2} = \frac1{16}$.
Άσκηση 8Απαιτητική
Συστολή με $L = \frac12$ και $|x_2 - x_1| = 1$. Ποιο είναι το μικρότερο $m$ ώστε η εκτίμηση $|x_m - t_0| \le \frac{L^{m-1}}{1 - L}|x_2 - x_1|$ να εγγυάται $|x_m - t_0| < 10^{-3}$;
Υπόδειξη: Θέλουμε $\frac{1}{2^{m-2}} < \frac{1}{1000}$.
Λύση: $2^{m-2} > 1000$· $2^9 = 512$, $2^{10} = 1024$. Άρα $m - 2 = 10$, $m = 12$.
Άσκηση 9Απαιτητική
Αν $|f(x) - f(t)| < |x - t|$ για όλα τα $x \ne t$ στο $\mathbb R$, τότε η $f$ έχει σταθερό σημείο.
Υπόδειξη: Δοκιμάστε $f(x) = x + \frac{1}{1 + e^x}$.
Λύση: Για αυτή την $f$, $0 < f'(x) = 1 - \frac{e^x}{(1 + e^x)^2} < 1$, άρα $|f(x) - f(t)| < |x - t|$, αλλά $f(x) - x = \frac{1}{1 + e^x} > 0$: κανένα σταθερό σημείο. Χρειάζεται μια ενιαία σταθερά $L < 1$.

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Η $f(x) = \frac{2}{3}x + 6$ είναι συστολή στο $\mathbb R$. Να βρείτε (α) τη σταθερά $L$ και (β) το μοναδικό σταθερό σημείο της.
Υπόδειξη: Λύστε $t = f(t)$.
Λύση: (α) $|f(x) - f(t)| = \frac{2}{3}|x - t|$, $L = \frac{2}{3} < 1$. (β) $t\left(1 - \frac{2}{3}\right) = 6 \Rightarrow t_0 = 18$.
