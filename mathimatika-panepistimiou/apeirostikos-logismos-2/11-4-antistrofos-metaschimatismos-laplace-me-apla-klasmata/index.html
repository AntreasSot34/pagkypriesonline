11.4

Αντίστροφος μετασχηματισμός Laplace με απλά κλάσματα

📘 Σημειώσεις: Ζαφειρίδου §7.3–7.4 (αντίστροφος μετασχηματισμός και ιδιότητές του)

Πώς βρίσκουμε τη συνάρτηση f(x) όταν ξέρουμε τον μετασχηματισμό της F(p); Αναλύουμε την F σε απλά κλάσματα και διαβάζουμε τον πίνακα ανάποδα.

Θεωρία

Αντίστροφος μετασχηματισμός

Αν $L\{f\} = F$, γράφουμε $f = L^{-1}\{F\}$. Για συνεχείς συναρτήσεις ο αντίστροφος είναι μοναδικός (θεώρημα Lerch): δύο συνεχείς συναρτήσεις με τον ίδιο μετασχηματισμό ταυτίζονται. Έτσι ο πίνακας της 11.2 διαβάζεται και από δεξιά προς τα αριστερά:

$$L^{-1}\!\left\{\frac1{p - a}\right\} = e^{ax},\quad L^{-1}\!\left\{\frac{1}{p^{n+1}}\right\} = \frac{x^n}{n!},\quad L^{-1}\!\left\{\frac{p}{p^2 + k^2}\right\} = \cos kx,\quad L^{-1}\!\left\{\frac{k}{p^2 + k^2}\right\} = \sin kx.$$

Ιδιότητες του $L^{-1}$

(α) Γραμμικότητα: $L^{-1}\{\lambda F + \mu G\} = \lambda L^{-1}\{F\} + \mu L^{-1}\{G\}$.
(β) Μετατόπιση: $L^{-1}\{F(p - a)\} = e^{ax}L^{-1}\{F\}$.
(γ) $L^{-1}\{F^{(n)}(p)\} = (-1)^nx^nL^{-1}\{F\}$.

Μέθοδος απλών κλασμάτων

Για ρητή $F = \frac{P(p)}{Q(p)}$ με $\deg P < \deg Q$ παραγοντοποιούμε τον $Q$:
• απλή ρίζα $a$: όρος $\frac{A}{p - a}$, με $A = \left.\frac{P(p)}{Q(p)/(p - a)}\right|_{p=a}$ («κάλυψη»)· δίνει $Ae^{ax}$.
• διπλή ρίζα $a$: $\frac{A}{p - a} + \frac{B}{(p - a)^2}$· δίνει $Ae^{ax} + Bxe^{ax}$.
• μη αναλύσιμο τριώνυμο: συμπληρώνουμε τετράγωνο $(p + \alpha)^2 + k^2$ και γράφουμε τον αριθμητή ως $A(p + \alpha) + Bk$· δίνει $e^{-\alpha x}(A\cos kx + B\sin kx)$.

Παράδειγμα · πραγματικές ρίζες

$L^{-1}\left\{\frac{1}{(p - 1)(p - 2)}\right\}$.

Λύση βήμα-βήμα

$\frac{1}{(p - 1)(p - 2)} = \frac{A}{p - 1} + \frac{B}{p - 2}$. Κάλυψη: $A = \frac{1}{1 - 2} = -1$, $B = \frac{1}{2 - 1} = 1$. Άρα $f(x) = e^{2x} - e^x$.

Παράδειγμα · συμπλήρωση τετραγώνου

$L^{-1}\left\{\frac{p + 1}{p^2 + 2p + 10}\right\}$.

Λύση βήμα-βήμα

$p^2 + 2p + 10 = (p + 1)^2 + 9$. Άρα $F(p) = G(p + 1)$ με $G(p) = \frac{p}{p^2 + 9}$, $L^{-1}\{G\} = \cos 3x$. Από τη μετατόπιση: $f(x) = e^{-x}\cos 3x$.

Παράδειγμα · μικτή ανάλυση

$L^{-1}\left\{\frac{p^2 + 2}{p(p^2 + 1)}\right\}$.

Λύση βήμα-βήμα

$\frac{p^2 + 2}{p(p^2 + 1)} = \frac Ap + \frac{Bp + C}{p^2 + 1}$, δηλαδή $p^2 + 2 = A(p^2 + 1) + Bp^2 + Cp$. Για $p = 0$: $A = 2$· συντελεστής $p^2$: $A + B = 1 \Rightarrow B = -1$· συντελεστής $p$: $C = 0$. Άρα $f(x) = 2 - \cos x$.

Συχνά λάθη

$L^{-1}\left\{\frac{1}{p^2 + 9}\right\} = \frac13\sin 3x$ — όχι $\sin 3x$ (λείπει το $k = 3$ στον αριθμητή)· στη μετατόπιση το $(p + 1)$ σημαίνει $e^{-x}$, όχι $e^{x}$· δεν ξεχνάμε ότι για $\deg P \ge \deg Q$ η $F$ δεν είναι μετασχηματισμός συνάρτησης ($F\not\to 0$).

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Η $L^{-1}\left\{\dfrac{5}{p + 2}\right\}$ έχει τη μορφή $Ae^{kx}$. Να βρείτε τα $A$, $k$.
Υπόδειξη: $L^{-1}\left\{\frac{1}{p - a}\right\} = e^{ax}$.
Λύση: $5e^{-2x}$: $A = 5$, $k = -2$.
Άσκηση 2Βασική
Αν $f = L^{-1}\left\{\dfrac{4}{p^3}\right\}$, να βρείτε το $f(1)$.
Υπόδειξη: $L^{-1}\left\{\frac{2}{p^3}\right\} = x^2$.
Λύση: $\frac{4}{p^3} = 2\cdot\frac{2!}{p^3}$, άρα $f(x) = 2x^2$ και $f(1) = 2$.
Άσκηση 3Βασική
Η $L^{-1}\left\{\dfrac{2p + 3}{p^2 + 9}\right\}$ γράφεται $a\cos 3x + b\sin 3x$. Να βρείτε τα $a$, $b$.
Υπόδειξη: $\frac{3}{p^2 + 9}\to\sin 3x$.
Λύση: $2\frac{p}{p^2 + 9} + \frac{3}{p^2 + 9}$, άρα $2\cos 3x + \sin 3x$.
Άσκηση 4Μέτρια
Να βρείτε την $L^{-1}\left\{\dfrac{1}{(p - 1)(p - 2)}\right\}$ στη μορφή $Ae^{2x} + Be^x$.
Υπόδειξη: Απλά κλάσματα με «κάλυψη».
Λύση: $\frac{-1}{p - 1} + \frac{1}{p - 2}$, άρα $e^{2x} - e^x$.
Άσκηση 5Μέτρια
Αν $f = L^{-1}\left\{\dfrac{1}{p^2 + 4p + 5}\right\}$, να βρείτε το $f\!\left(\frac\pi2\right)$ (5 δεκαδικά).
Υπόδειξη: $p^2 + 4p + 5 = (p + 2)^2 + 1$.
Λύση: $f(x) = e^{-2x}\sin x$, $f\!\left(\frac\pi2\right) = e^{-\pi} \approx 0{,}04321$.
Άσκηση 6Μέτρια
Η $L^{-1}\left\{\dfrac{p + 1}{p^2 + 2p + 10}\right\}$ είναι της μορφής $e^{-x}\cos kx$. Να βρείτε το $k > 0$.
Υπόδειξη: Συμπληρώστε τετράγωνο.
Λύση: $(p + 1)^2 + 9$, άρα $e^{-x}\cos 3x$, $k = 3$.
Άσκηση 7Μέτρια
Αν $f = L^{-1}\left\{\dfrac{3}{p(p + 3)}\right\}$, να βρείτε το $f(1)$ (4 δεκαδικά).
Υπόδειξη: $\frac{3}{p(p + 3)} = \frac1p - \frac{1}{p + 3}$.
Λύση: $f(x) = 1 - e^{-3x}$, $f(1) = 1 - e^{-3} \approx 0{,}9502$.
Άσκηση 8Βασική
Ο αντίστροφος μετασχηματισμός Laplace είναι γραμμικός: $L^{-1}\{\lambda F + \mu G\} = \lambda L^{-1}\{F\} + \mu L^{-1}\{G\}$.
Υπόδειξη: Ο $L$ είναι γραμμικός.
Λύση: Σωστό: αν $L\{f\} = F$, $L\{g\} = G$, τότε $L\{\lambda f + \mu g\} = \lambda F + \mu G$.
Άσκηση 9Απαιτητική
Αν $f = L^{-1}\left\{\dfrac{p^2 + 2}{p(p^2 + 1)}\right\}$, να βρείτε το $f(\pi)$.
Υπόδειξη: $\frac Ap + \frac{Bp + C}{p^2 + 1}$.
Λύση: $A = 2$, $B = -1$, $C = 0$, άρα $f(x) = 2 - \cos x$ και $f(\pi) = 3$.
Άσκηση 10Απαιτητική
Αν $f = L^{-1}\left\{\dfrac{p + 2}{(p + 1)^2}\right\}$, να βρείτε το $f(1)$ (4 δεκαδικά).
Υπόδειξη: $\frac{p + 2}{(p + 1)^2} = \frac{1}{p + 1} + \frac{1}{(p + 1)^2}$.
Λύση: $f(x) = e^{-x} + xe^{-x} = (1 + x)e^{-x}$, $f(1) = \frac2e \approx 0{,}7358$.

♾️ Γεννήτρια — αντίστροφος μετασχηματισμός Laplace

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε την $f(x) = L^{-1}\left\{\dfrac{1}{(p + 2)(p - 1)}\right\}$ στη μορφή $A e^{x} + B e^{-2x}$.
Υπόδειξη: Απλά κλάσματα: $\frac{1}{(p - a)(p - b)} = \frac{1}{b - a}\left(\frac{1}{p - b} - \frac{1}{p - a}\right)$.
Λύση: $\frac{1}{3}\left(\frac{1}{p - 1} - \frac{1}{p + 2}\right)$, άρα $A = \frac{1}{3}$, $B = -\frac{1}{3}$.
