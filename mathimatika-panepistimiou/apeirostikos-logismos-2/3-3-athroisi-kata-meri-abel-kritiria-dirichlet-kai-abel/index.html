3.3

Άθροιση κατά μέρη (Abel) – κριτήρια Dirichlet και Abel

📘 Σημειώσεις: Τσολομύτης κεφ. 4 (κριτήριο Dirichlet) · Ζαφειρίδου §8.3–8.4

Πώς μελετάμε σειρές όπως η $\sum\frac{\sin n}{n}$, όπου τα πρόσημα δεν εναλλάσσονται κανονικά; Με την άθροιση κατά μέρη και τα κριτήρια Dirichlet και Abel.

Θεωρία

Το κριτήριο Leibniz καλύπτει μόνο κανονικά εναλλασσόμενα πρόσημα. Για σειρές όπως $\sum\frac{\sin n}{n}$ ή $\sum\frac{\cos(nx)}{\ln n}$ χρειαζόμαστε κάτι γενικότερο: την άθροιση κατά μέρη (τύπο του Abel), το διακριτό ανάλογο της ολοκλήρωσης κατά μέρη. Από αυτήν προκύπτουν τα κριτήρια Dirichlet και Abel, που αφορούν σειρές της μορφής $\sum a_n b_n$.

Τύπος άθροισης κατά μέρη (Abel)

Έστω $A_n = a_1 + \cdots + a_n$ ($A_0 = 0$). Για κάθε $N$:

$$\sum_{n=1}^{N} a_n b_n = A_N b_N + \sum_{n=1}^{N-1} A_n\,(b_n - b_{n+1}).$$
Απόδειξη

Αφού $a_n = A_n - A_{n-1}$: $\sum_{n=1}^N a_n b_n = \sum_{n=1}^N A_n b_n - \sum_{n=1}^{N} A_{n-1}b_n = \sum_{n=1}^N A_n b_n - \sum_{n=1}^{N-1}A_n b_{n+1}$, που ισούται με $A_N b_N + \sum_{n=1}^{N-1}A_n(b_n - b_{n+1})$.

Κριτήριο Dirichlet

Αν (α) τα μερικά αθροίσματα $A_N = \sum_{n\le N} a_n$ είναι φραγμένα ($|A_N| \le M$) και (β) η $(b_n)$ είναι μονότονη με $b_n \to 0$, τότε η $\sum a_n b_n$ συγκλίνει.

Απόδειξη

Στον τύπο του Abel: $|A_N b_N| \le M|b_N| \to 0$. Για το άθροισμα, $|A_n(b_n - b_{n+1})| \le M|b_n - b_{n+1}|$ και, επειδή η $(b_n)$ είναι μονότονη, $\sum_{n=1}^{N-1}|b_n - b_{n+1}| = |b_1 - b_N| \to |b_1|$. Άρα η $\sum A_n(b_n - b_{n+1})$ συγκλίνει απόλυτα. Και οι δύο όροι συγκλίνουν, άρα συγκλίνει και το $\sum_{n\le N}a_n b_n$.

Κριτήριο Abel

Αν η $\sum a_n$ συγκλίνει και η $(b_n)$ είναι μονότονη και φραγμένη, τότε η $\sum a_n b_n$ συγκλίνει.

Απόδειξη

Η $(b_n)$ συγκλίνει σε κάποιο $b$. Γράφουμε $a_n b_n = a_n(b_n - b) + b\,a_n$. Η $\sum b\,a_n$ συγκλίνει, και η $\sum a_n(b_n - b)$ συγκλίνει από Dirichlet (τα μερικά αθροίσματα της $\sum a_n$ είναι φραγμένα αφού συγκλίνουν, και $b_n - b$ μονότονη με όριο $0$).

Τριγωνομετρικά αθροίσματα

Για $x \notin 2\pi\mathbb Z$, πολλαπλασιάζοντας με $2\sin\frac x2$ και χρησιμοποιώντας $2\sin\frac x2\sin(kx) = \cos\left(k - \frac12\right)x - \cos\left(k + \frac12\right)x$ (τηλεσκοπικό!):

$$\left|\sum_{k=1}^N \sin(kx)\right| \le \frac{1}{|\sin(x/2)|}, \qquad \left|\sum_{k=1}^N \cos(kx)\right| \le \frac{1}{|\sin(x/2)|}.$$

Άρα από Dirichlet οι $\sum\frac{\sin(nx)}{n}$, $\sum\frac{\cos(nx)}{n^p}$ ($p > 0$) συγκλίνουν για κάθε $x \notin 2\pi\mathbb Z$. Μάλιστα $\sum_{n=1}^\infty\frac{\sin(nx)}{n} = \frac{\pi - x}{2}$ για $0 < x < 2\pi$ (σειρά Fourier).

Ο Leibniz ως ειδική περίπτωση

Με $a_n = (-1)^{n+1}$ (μερικά αθροίσματα $1, 0, 1, 0, \dots$, φραγμένα) και $b_n \downarrow 0$, το κριτήριο Dirichlet δίνει ακριβώς το κριτήριο Leibniz.

Λύση βήμα-βήμα: $\sum\dfrac{(-1)^n}{n}\left(1 + \dfrac1n\right)^n$

1. Η $\sum\frac{(-1)^n}{n}$ συγκλίνει (Leibniz).

2. Η $\left(1 + \frac1n\right)^n$ είναι αύξουσα και φραγμένη από $e$.

3. Κριτήριο Abel: η σειρά συγκλίνει. Δεν συγκλίνει απόλυτα, αφού $\frac1n\left(1 + \frac1n\right)^n \ge \frac{2}{n}$.

Πειραματίσου

● Σ sin(kx): τα μερικά αθροίσματα μένουν φραγμένα (|·| ≤ 1/|sin(x/2)|), ενώ bₙ = 1/n φθίνει στο 0 ⇒ (Dirichlet) η Σ sin(nx)/n συγκλίνει.
s_80 = 1,066 · άθροισμα της σειράς για 0 < x < 2π: (π − x)/2 = 1,0708.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το φράγμα $\dfrac{1}{|\sin(x/2)|}$ των μερικών αθροισμάτων $\sum_{k=1}^N\sin(kx)$ για $x = \frac{\pi}{3}$.
Υπόδειξη: $\sin\frac{\pi}{6} = \frac12$.
Λύση: $\frac{1}{\sin(\pi/6)} = 2$, δηλαδή $\left|\sum_{k=1}^N\sin\frac{k\pi}{3}\right| \le 2$ για κάθε $N$.
Άσκηση 2Βασική
Να υπολογίσετε το $\sum_{k=1}^{6}\sin\frac{k\pi}{2}$.
Υπόδειξη: Οι τιμές επαναλαμβάνονται: $1, 0, -1, 0, \dots$
Λύση: $1 + 0 - 1 + 0 + 1 + 0 = 1$. Τα μερικά αθροίσματα παίρνουν μόνο τις τιμές $0$ και $1$: είναι φραγμένα.
Άσκηση 3Μέτρια
Να υπολογίσετε το φράγμα $\dfrac{1}{|\sin(x/2)|}$ για τα μερικά αθροίσματα της $\sum\cos(kx)$ στο $x = \frac{\pi}{2}$ (3 δεκαδικά).
Υπόδειξη: $\sin\frac\pi4 = \frac{\sqrt2}{2}$.
Λύση: $\frac{1}{\sqrt2/2} = \sqrt2 \approx 1{,}414$. (Πράγματι τα μερικά αθροίσματα είναι $0, -1, -1, 0, \dots$)
Άσκηση 4Μέτρια
Χρησιμοποιώντας τον τύπο $\sum_{n=1}^\infty\frac{\sin(nx)}{n} = \frac{\pi - x}{2}$ ($0 < x < 2\pi$), να υπολογίσετε το άθροισμα για $x = \frac{\pi}{2}$ (3 δεκαδικά).
Υπόδειξη: Για $x = \frac\pi2$ η σειρά είναι $1 - \frac13 + \frac15 - \cdots$
Λύση: $\frac{\pi - \pi/2}{2} = \frac{\pi}{4} \approx 0{,}785$ — η σειρά Leibniz.
Άσκηση 5Βασική
Η σειρά $\displaystyle\sum_{n=2}^\infty\frac{\cos n}{\ln n}$:
Υπόδειξη: Dirichlet με $a_n = \cos n$.
Λύση: $\left|\sum_{k\le N}\cos k\right| \le \frac{1}{\sin(1/2)}$ και $\frac{1}{\ln n} \downarrow 0$: από Dirichlet η σειρά συγκλίνει.
Άσκηση 6Μέτρια
Η σειρά $\displaystyle\sum_{n=1}^\infty\frac{(-1)^n\arctan n}{n}$:
Υπόδειξη: Κριτήριο Abel.
Λύση: Η $\sum\frac{(-1)^n}{n}$ συγκλίνει και η $\arctan n$ είναι αύξουσα και φραγμένη (από $\frac\pi2$): από Abel η σειρά συγκλίνει.
Άσκηση 7Βασική
Η σειρά $\sum_{n=1}^\infty\sin n$:
Υπόδειξη: Αναγκαία συνθήκη.
Λύση: $\sin n \not\to 0$ (π.χ. άπειρα $n$ έχουν $|\sin n| > \frac12$), άρα η σειρά αποκλίνει, παρότι τα μερικά αθροίσματα είναι φραγμένα.
Άσκηση 8Μέτρια
Στο κριτήριο Dirichlet αρκεί $b_n \to 0$, χωρίς να απαιτείται μονοτονία.
Υπόδειξη: Ο Leibniz είναι ειδική περίπτωση του Dirichlet.
Λύση: Λάθος: με $a_n = (-1)^{n+1}$ το Dirichlet γίνεται Leibniz, και ξέρουμε σειρά με $b_n \to 0$ όχι μονότονα που αποκλίνει. Στην απόδειξη η μονοτονία κάνει την $\sum|b_n - b_{n+1}|$ τηλεσκοπική.
Άσκηση 9Απαιτητική
Για $a = (1, -1, 1)$ και $b = (3, 2, 1)$ να υπολογίσετε το $A_3 b_3 + \sum_{n=1}^{2}A_n(b_n - b_{n+1})$, όπου $A_n = a_1 + \cdots + a_n$.
Υπόδειξη: $A_1 = 1$, $A_2 = 0$, $A_3 = 1$.
Λύση: $A_3b_3 + A_1(b_1 - b_2) + A_2(b_2 - b_3) = 1 + 1 + 0 = 2$, ίσο με $\sum a_nb_n = 3 - 2 + 1 = 2$: ο τύπος του Abel.

♾️ Γεννήτρια — κριτήρια Dirichlet και Abel

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Η σειρά $\displaystyle \sum_{n=1}^\infty \frac{(-1)^n \arctan n}{n}$:
Υπόδειξη: Γράψτε τον όρο ως $a_n b_n$ με φραγμένα μερικά αθροίσματα της $\sum a_n$ και $b_n \downarrow 0$ (Dirichlet) ή με συγκλίνουσα $\sum a_n$ και μονότονη φραγμένη $b_n$ (Abel).
Λύση: Abel: η $\sum\frac{(-1)^n}{n}$ συγκλίνει και η $\arctan n$ είναι μονότονη και φραγμένη. Άρα η σειρά συγκλίνει.
