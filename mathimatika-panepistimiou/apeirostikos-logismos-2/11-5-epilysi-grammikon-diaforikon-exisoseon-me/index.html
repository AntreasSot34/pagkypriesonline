11.5

Επίλυση γραμμικών διαφορικών εξισώσεων με μετασχηματισμό Laplace

📘 Σημειώσεις: Ζαφειρίδου §7.5 (Θεώρημα 7.5.2, Πόρισμα 7.5.4 και εφαρμογές σε ΔΕ)

Πώς λύνουμε ένα πρόβλημα αρχικών τιμών όπως y″ + 4y = 8, y(0) = 0, y′(0) = 0 χωρίς να μαντέψουμε μερική λύση; Ο μετασχηματισμός Laplace το κάνει αλγεβρικό πρόβλημα.

Θεωρία

Η μέθοδος σε 4 βήματα

Για ΔΕ με σταθερούς συντελεστές $y'' + ay' + by = g(x)$, $\ y(0) = y_0$, $y'(0) = y_1$:

1. Παίρνουμε $L$ και στα δύο μέλη, με $Y = L\{y\}$ και (Πόρισμα 7.5.4) $L\{y'\} = pY - y_0$, $L\{y''\} = p^2Y - py_0 - y_1$.
2. Λύνουμε την αλγεβρική εξίσωση ως προς $Y$:

$$(p^2 + ap + b)\,Y = G(p) + (p + a)y_0 + y_1 \ \Longrightarrow\ Y(p) = \frac{G(p) + (p + a)y_0 + y_1}{p^2 + ap + b}.$$

Η χρήση του $L$ στα $y, y', y''$ προϋποθέτει ότι είναι εκθετικής τάξης· αυτό ισχύει αυτόματα για γραμμικές ΔΕ με σταθερούς συντελεστές όταν το δεξί μέλος είναι εκθετικής τάξης.

3. Αναλύουμε το $Y$ σε απλά κλάσματα. 4. Βρίσκουμε $y = L^{-1}\{Y\}$ από τον πίνακα.

Οι αρχικές συνθήκες μπαίνουν αυτόματα — δεν χρειάζεται να βρούμε γενική λύση και μετά σταθερές. Ο παρονομαστής $p^2 + ap + b$ είναι το χαρακτηριστικό πολυώνυμο της ΔΕ.

Παράδειγμα · 1ης τάξης

$y' + 2y = 0$, $y(0) = 3$.

Λύση βήμα-βήμα

$pY - 3 + 2Y = 0 \Rightarrow Y = \frac{3}{p + 2} \Rightarrow y = 3e^{-2x}$.

Παράδειγμα · με εξωτερική δύναμη

$y'' + 4y = 8$, $y(0) = 0$, $y'(0) = 0$.

Λύση βήμα-βήμα

$p^2Y + 4Y = \frac8p \Rightarrow Y = \frac{8}{p(p^2 + 4)}$. Απλά κλάσματα: $\frac{8}{p(p^2 + 4)} = \frac2p - \frac{2p}{p^2 + 4}$ (έλεγχος: $2(p^2 + 4) - 2p^2 = 8$ ✓). Άρα $y = 2 - 2\cos 2x$, και $y\!\left(\frac\pi4\right) = 2$.

Παράδειγμα · διπλή ρίζα

$y'' + 2y' + y = 0$, $y(0) = 1$, $y'(0) = 1$.

Λύση βήμα-βήμα

$(p^2Y - p - 1) + 2(pY - 1) + Y = 0 \Rightarrow (p + 1)^2Y = p + 3 \Rightarrow Y = \frac{p + 3}{(p + 1)^2} = \frac{1}{p + 1} + \frac{2}{(p + 1)^2}$. Άρα $y = e^{-x} + 2xe^{-x} = (1 + 2x)e^{-x}$.

Παράδειγμα · διπλός πόλος από το δεξί μέλος

$y' + y = e^{-x}$, $y(0) = 1$.

Λύση βήμα-βήμα

$pY - 1 + Y = \frac{1}{p + 1} \Rightarrow Y = \frac{1}{p + 1} + \frac{1}{(p + 1)^2} \Rightarrow y = (1 + x)e^{-x}$. Ο διπλός πόλος $(p + 1)^2$ δημιουργεί τον παράγοντα $x$.

Συχνά λάθη

Ξεχνάμε τους όρους των αρχικών τιμών στο $L\{y''\}$· γράφουμε $L\{8\} = 8$ αντί για $\frac8p$· η μέθοδος δίνει λύση για $x \ge 0$ (εκεί ορίζεται ο μετασχηματισμός).

Πειραματίσου

y″ + 2y′ + 5y = 0,   y(0) = 1, y′(0) = 0
Laplace: (p²Y − p·y(0) − y′(0)) + a(pY − y(0)) + bY = c/p  ⟹  Y(p) = [ (p + a)·y(0) + y′(0) + c/p ] / (p² + a p + b)
Παρονομαστής p² + 2p + 5: μιγαδικές ρίζες (ταλάντωση).
Η ΔΕ γίνεται αλγεβρική εξίσωση για το Y(p)· τη λύνουμε, σπάμε σε απλά κλάσματα και επιστρέφουμε με τον αντίστροφο μετασχηματισμό.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Με τον μετασχηματισμό Laplace να λύσετε την $y' + 2y = 0$, $y(0) = 3$, και να δώσετε το $y(1)$ (4 δεκαδικά).
Υπόδειξη: $Y = \frac{3}{p + 2}$.
Λύση: $y = 3e^{-2x}$, $y(1) = 3e^{-2} \approx 0{,}4060$.
Άσκηση 2Βασική
Να λύσετε την $y' - y = 1$, $y(0) = 0$, και να δώσετε το $y(1)$ (4 δεκαδικά).
Υπόδειξη: $(p - 1)Y = \frac1p$, και $\frac{1}{p(p - 1)} = \frac{1}{p - 1} - \frac1p$.
Λύση: $y = e^x - 1$, $y(1) = e - 1 \approx 1{,}7183$.
Άσκηση 3Βασική
Να λύσετε την $y'' + y = 0$, $y(0) = 0$, $y'(0) = 2$, και να δώσετε το $y\!\left(\frac\pi2\right)$.
Υπόδειξη: $(p^2 + 1)Y = 2$.
Λύση: $Y = \frac{2}{p^2 + 1}$, $y = 2\sin x$, $y\!\left(\frac\pi2\right) = 2$.
Άσκηση 4Μέτρια
Να λύσετε την $y'' - 3y' + 2y = 0$, $y(0) = 0$, $y'(0) = 1$, και να δώσετε το $y(1)$ (4 δεκαδικά).
Υπόδειξη: $Y = \frac{1}{(p - 1)(p - 2)}$.
Λύση: $y = e^{2x} - e^x$, $y(1) = e^2 - e \approx 4{,}6708$.
Άσκηση 5Μέτρια
Να λύσετε την $y'' + 4y = 8$, $y(0) = 0$, $y'(0) = 0$, και να δώσετε το $y\!\left(\frac\pi4\right)$.
Υπόδειξη: $Y = \frac{8}{p(p^2 + 4)} = \frac2p - \frac{2p}{p^2 + 4}$.
Λύση: $y = 2 - 2\cos 2x$, $y\!\left(\frac\pi4\right) = 2 - 0 = 2$.
Άσκηση 6Βασική
Αν $Y = L\{y\}$, ποιος είναι ο $L\{y''\}$;
Υπόδειξη: Πόρισμα 7.5.4 για $n = 2$.
Λύση: $L\{y''\} = pL\{y'\} - y'(0) = p(pY - y(0)) - y'(0)$.
Άσκηση 7Μέτρια
Να λύσετε την $y' + y = e^{-x}$, $y(0) = 1$, και να δώσετε το $y(1)$ (4 δεκαδικά).
Υπόδειξη: $(p + 1)Y = 1 + \frac{1}{p + 1}$.
Λύση: $Y = \frac{1}{p + 1} + \frac{1}{(p + 1)^2}$, $y = (1 + x)e^{-x}$, $y(1) = \frac2e \approx 0{,}7358$.
Άσκηση 8Απαιτητική
Να λύσετε την $y'' + 2y' + y = 0$, $y(0) = 1$, $y'(0) = 1$, και να δώσετε το $y(1)$ (4 δεκαδικά).
Υπόδειξη: $(p + 1)^2Y = p + 3$.
Λύση: $Y = \frac{1}{p + 1} + \frac{2}{(p + 1)^2}$, $y = (1 + 2x)e^{-x}$, $y(1) = \frac3e \approx 1{,}1036$.
Άσκηση 9Απαιτητική
Να λύσετε την $y'' + y = x$, $y(0) = 1$, $y'(0) = 0$, και να δώσετε το $y(\pi)$ (4 δεκαδικά).
Υπόδειξη: $(p^2 + 1)Y = \frac{1}{p^2} + p$· $\frac{1}{p^2(p^2 + 1)} = \frac{1}{p^2} - \frac{1}{p^2 + 1}$.
Λύση: $Y = \frac{1}{p^2} - \frac{1}{p^2 + 1} + \frac{p}{p^2 + 1}$, άρα $y = x - \sin x + \cos x$ και $y(\pi) = \pi - 1 \approx 2{,}1416$.

♾️ Γεννήτρια — επίλυση ΔΕ με μετασχηματισμό Laplace

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Με τον μετασχηματισμό Laplace να λύσετε την $y' + y = 0$, $y(0) = 2$, και να δώσετε το $y(2)$ (4 δεκαδικά).
Υπόδειξη: $pY - y(0) + Y = 0$.
Λύση: $(p + 1)Y = 2 \Rightarrow Y = \frac{2}{p + 1} \Rightarrow y = 2e^{-x}$, άρα $y(2) = 2e^{-2} \approx 0{,}2707$.
