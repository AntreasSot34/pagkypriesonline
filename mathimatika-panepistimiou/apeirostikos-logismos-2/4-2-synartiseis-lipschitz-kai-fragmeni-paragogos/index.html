4.2

Συναρτήσεις Lipschitz και φραγμένη παράγωγος

📘 Σημειώσεις: Τσολομύτης κεφ. 6 §6.1 (Πρ. 6.3, Πόρ. 6.4, Παρ. 6.5) · Ζαφειρίδου §3 (συνθήκη Lipschitz)

Τι είναι μια συνάρτηση Lipschitz και γιατί κάθε Lipschitz συνάρτηση είναι ομοιόμορφα συνεχής; Πώς βρίσκουμε τη σταθερά Lipschitz από την παράγωγο;

Θεωρία

Ο πιο συνηθισμένος τρόπος για να αποδείξουμε ότι μια συνάρτηση είναι ομοιόμορφα συνεχής είναι να δείξουμε ότι ικανοποιεί τη συνθήκη Lipschitz: οι μεταβολές της τιμής φράσσονται από ένα σταθερό πολλαπλάσιο της μεταβολής της μεταβλητής. Για παραγωγίσιμες συναρτήσεις η συνθήκη αυτή ελέγχεται εύκολα μέσω της παραγώγου.

Συνάρτηση Lipschitz

Η $f: A \to \mathbb R$ λέγεται Lipschitz (ικανοποιεί συνθήκη Lipschitz) αν υπάρχει σταθερά $L > 0$ τέτοια ώστε

$$|f(x) - f(t)| \le L\,|x - t| \qquad \text{για όλα τα } x, t \in A.$$

Η μικρότερη τέτοια σταθερά είναι $\displaystyle\sup_{x \ne t}\frac{|f(x) - f(t)|}{|x - t|}$: το supremum των κλίσεων όλων των χορδών.

Γεωμετρικά: από κάθε σημείο $(t, f(t))$ της γραφικής παράστασης φέρνουμε τις ευθείες κλίσης $\pm L$. Η γραφική παράσταση πρέπει να μένει μέσα στον «διπλό κώνο» $|y - f(t)| \le L|x - t|$ — και αυτό για κάθε κορυφή $t$.

Lipschitz ⇒ ομοιόμορφα συνεχής

Κάθε συνάρτηση Lipschitz $f: A \to \mathbb R$ είναι ομοιόμορφα συνεχής στο $A$.

Απόδειξη

Έστω $\varepsilon > 0$. Θέτουμε $\delta = \varepsilon / L$. Αν $x, t \in A$ με $|x - t| < \delta$, τότε $|f(x) - f(t)| \le L|x - t| < L\delta = \varepsilon$. Το $\delta$ εξαρτάται μόνο από το $\varepsilon$.

Φραγμένη παράγωγος ⇒ Lipschitz

Έστω $I$ διάστημα και $f$ παραγωγίσιμη στο $I$ με $|f'(x)| \le M$ για κάθε $x \in I$. Τότε η $f$ είναι Lipschitz με σταθερά $M$, άρα ομοιόμορφα συνεχής στο $I$.

Απόδειξη

Για $x < t$ στο $I$, από το θεώρημα μέσης τιμής υπάρχει $\xi \in (x, t)$ με $f(t) - f(x) = f'(\xi)(t - x)$. Άρα $|f(t) - f(x)| = |f'(\xi)|\,|t - x| \le M|t - x|$.

Παραδείγματα

• $\sin x$, $\cos x$ στο $\mathbb R$: $|f'| \le 1$, άρα Lipschitz με $L = 1$: $|\sin x - \sin t| \le |x - t|$.

• $\arctan x$ στο $\mathbb R$: $f'(x) = \frac{1}{1 + x^2} \le 1$, άρα ομοιόμορφα συνεχής, παρότι το $\mathbb R$ δεν είναι φραγμένο.

• $x^2$ στο $[-1, 4]$: $|f'(x)| = 2|x| \le 8$, άρα $L = 8$. Στο $\mathbb R$ όμως η παράγωγος δεν είναι φραγμένη.

• $\ln x$ στο $[2, \infty)$: $f'(x) = \frac1x \le \frac12$, άρα $L = \frac12$.

Το αντίστροφο δεν ισχύει: η $\sqrt{x}$

Η $\sqrt x$ στο $[0, 1]$: ομοιόμορφα συνεχής αλλά όχι Lipschitz

Όχι Lipschitz. Αν $|\sqrt x - \sqrt t| \le L|x - t|$ για όλα τα $x, t \in [0, 1]$, πάρτε $x = \frac{4}{n^2}$, $t = \frac{1}{n^2}$ (για $n \ge 2$). Τότε $\sqrt x - \sqrt t = \frac1n$ και $x - t = \frac{3}{n^2}$, οπότε $\frac1n \le \frac{3L}{n^2}$, δηλαδή $n \le 3L$ για κάθε $n$ — άτοπο. Ο λόγος $\frac{|\sqrt x - \sqrt t|}{|x - t|} = \frac n3$ γίνεται αυθαίρετα μεγάλος.

Ομοιόμορφα συνεχής. Ισχύει $|\sqrt x - \sqrt t| \le \sqrt{|x - t|}$ (για $x \ge t$: $\sqrt x \le \sqrt t + \sqrt{x - t}$). Άρα αρκεί $\delta = \varepsilon^2$. Επίσης προκύπτει από το θεώρημα Cantor–Heine.

Λύση βήμα-βήμα: σταθερά Lipschitz της $\frac{1}{1 + x^2}$

1. $f'(x) = -\frac{2x}{(1 + x^2)^2}$.

2. Μεγιστοποιούμε $g(x) = \frac{2x}{(1 + x^2)^2}$ για $x > 0$: $g'(x) = \frac{2(1 + x^2) - 8x^2}{(1 + x^2)^3} = 0 \iff 3x^2 = 1 \iff x = \frac{1}{\sqrt3}$.

3. $g\left(\tfrac{1}{\sqrt3}\right) = \frac{2/\sqrt3}{(4/3)^2} = \frac{3\sqrt3}{8} \approx 0{,}6495$.

4. Άρα $L = \frac{3\sqrt3}{8}$ και η $\frac{1}{1 + x^2}$ είναι ομοιόμορφα συνεχής στο $\mathbb R$.

Ιεραρχία

Για συναρτήσεις σε διάστημα: φραγμένη παράγωγος ⇒ Lipschitz ⇒ ομοιόμορφα συνεχής ⇒ συνεχής. Καμία συνεπαγωγή δεν αντιστρέφεται: η $|x|$ είναι Lipschitz χωρίς να είναι παραγωγίσιμη στο 0, η $\sqrt x$ είναι ομοιόμορφα συνεχής χωρίς να είναι Lipschitz, η $x^2$ είναι συνεχής στο $\mathbb R$ χωρίς να είναι ομοιόμορφα συνεχής.

Πειραματίσου

Ο κώνος ∣y−f(t)∣≤L∣x−t∣|y - f(t)| \le L|x - t|∣y−f(t)∣≤L∣x−t∣ με L = 1. Μέγιστη κλίση χορδής από το t: 1. Η γραφική μένει μέσα στον κώνο.
Η f είναι Lipschitz αν ένα L κάνει για κάθε κορυφή t. Εδώ η βέλτιστη σταθερά είναι L=1L = 1L=1 (= sup|f′|).

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να βρείτε τη μικρότερη σταθερά Lipschitz της $f(x) = 3x - 7$ στο $\mathbb R$.
Υπόδειξη: $|f(x) - f(t)| = 3|x - t|$.
Λύση: $|(3x - 7) - (3t - 7)| = 3|x - t|$, άρα $L = 3$ και δεν μπορεί να μικρύνει.
Άσκηση 2Βασική
Να βρείτε τη μικρότερη σταθερά Lipschitz της $f(x) = x^2$ στο $[-1, 4]$.
Υπόδειξη: $L = \max_{[-1, 4]}|f'(x)|$.
Λύση: $|f'(x)| = 2|x| \le 8$, με ισότητα στο $x = 4$. Άρα $L = 8$.
Άσκηση 3Βασική
Να βρείτε τη μικρότερη σταθερά Lipschitz της $f(x) = \sin(2x)$ στο $\mathbb R$.
Υπόδειξη: $f'(x) = 2\cos 2x$.
Λύση: $\sup|f'| = 2$, άρα $|\sin 2x - \sin 2t| \le 2|x - t|$ και η σταθερά $2$ είναι βέλτιστη (κλίση στο 0).
Άσκηση 4Μέτρια
Να βρείτε τη μικρότερη σταθερά Lipschitz της $f(x) = \frac{1}{1 + x^2}$ στο $\mathbb R$ (5 δεκαδικά).
Υπόδειξη: Μεγιστοποιήστε το $|f'(x)| = \frac{2|x|}{(1 + x^2)^2}$.
Λύση: Το μέγιστο είναι στο $x = \frac1{\sqrt3}$: $L = \frac{3\sqrt3}{8} \approx 0{,}64952$.
Άσκηση 5Μέτρια
Για την $\sqrt x$ πάρτε $x = \frac{4}{n^2}$, $t = \frac{1}{n^2}$. Ο λόγος $\frac{\sqrt x - \sqrt t}{x - t}$ ισούται με $\frac n3$. Πόσο είναι για $n = 30$;
Υπόδειξη: $\sqrt x - \sqrt t = \frac1n$, $x - t = \frac{3}{n^2}$.
Λύση: $\frac{1/30}{3/900} = 10$. Αφού ο λόγος γίνεται αυθαίρετα μεγάλος, η $\sqrt x$ δεν είναι Lipschitz στο $[0, 1]$.
Άσκηση 6Μέτρια
Η $f(x) = \ln x$ στο $[2, \infty)$: (α) η μικρότερη σταθερά Lipschitz, (β) το $\delta = \varepsilon/L$ για $\varepsilon = 0{,}01$.
Υπόδειξη: $f'(x) = \frac1x \le \frac12$.
Λύση: (α) $\sup_{x \ge 2}\frac1x = \frac12$. (β) $\delta = 0{,}01 / \frac12 = 0{,}02$.
Άσκηση 7Μέτρια
Ποια από τις παρακάτω συναρτήσεις δεν είναι Lipschitz στο πεδίο που δίνεται;
Υπόδειξη: Κοιτάξτε κλίσεις χορδών κοντά στο 0.
Λύση: Η $\sqrt x$ έχει κατακόρυφη εφαπτομένη στο 0: οι κλίσεις χορδών $\frac n3$ δεν φράσσονται. Η $|x|$ έχει $L = 1$, η $\arctan$ έχει $|f'| \le 1$ και η $x^3$ στο $[-5, 5]$ έχει $|f'| \le 75$.
Άσκηση 8Μέτρια
Αν μια συνάρτηση είναι Lipschitz σε ένα διάστημα, τότε είναι παραγωγίσιμη σε κάθε σημείο του.
Υπόδειξη: Σκεφτείτε την $|x|$.
Λύση: Η $|x|$ είναι Lipschitz με $L = 1$ (από την τριγωνική ανισότητα $\big||x| - |t|\big| \le |x - t|$) αλλά δεν παραγωγίζεται στο 0.
Άσκηση 9Απαιτητική
Η $f(x) = x\sin x$ είναι ομοιόμορφα συνεχής στο $\mathbb R$.
Υπόδειξη: Δοκιμάστε $x_n = 2n\pi + \frac1n$, $t_n = 2n\pi$.
Λύση: $f(x_n) - f(t_n) = \left(2n\pi + \tfrac1n\right)\sin\tfrac1n \to 2\pi \ne 0$, ενώ $x_n - t_n = \frac1n \to 0$. Προσοχή: η μη φραγμένη παράγωγος $\sin x + x\cos x$ μόνη της δεν αποδεικνύει τίποτα (π.χ. η $\sqrt x$ στο $(0,1]$ έχει μη φραγμένη παράγωγο και είναι ομοιόμορφα συνεχής)· την απόδειξη τη δίνει το ζεύγος ακολουθιών.

♾️ Γεννήτρια — σταθερά Lipschitz

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε τη μικρότερη σταθερά Lipschitz της $f(x) = 3x^2$ στο $[-3, 2]$.
Υπόδειξη: $|f'(x)| = 6|x|$, μέγιστο στο άκρο με τη μεγαλύτερη απόλυτη τιμή.
Λύση: $L = \max_{[-3, 2]} 6|x| = 6\cdot 3 = 18$.
