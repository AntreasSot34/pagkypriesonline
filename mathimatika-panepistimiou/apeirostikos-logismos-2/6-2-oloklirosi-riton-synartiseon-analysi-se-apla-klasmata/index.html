6.2

Ολοκλήρωση ρητών συναρτήσεων – Ανάλυση σε απλά κλάσματα

📘 Σημειώσεις: Τσολομύτης κεφ. 8 §8.2 (Τεχνικές 8.5–8.6) · Ζαφειρίδου §3.6

Πώς ολοκληρώνουμε μια ρητή συνάρτηση $P(x)/Q(x)$; Η απάντηση είναι η ανάλυση σε απλά κλάσματα.

Θεωρία

Κάθε ρητή συνάρτηση $\frac{P(x)}{Q(x)}$ έχει αντιπαράγωγο που εκφράζεται με ρητές συναρτήσεις, λογαρίθμους και τόξα εφαπτομένης. Το εργαλείο είναι η ανάλυση σε απλά κλάσματα (μερικά κλάσματα): γράφουμε την ρητή συνάρτηση ως άθροισμα απλών όρων που ολοκληρώνονται άμεσα.

Ανάλυση σε απλά κλάσματα

Κάθε πραγματικό πολυώνυμο γράφεται ως γινόμενο παραγόντων $(x - a)^k$ και $(x^2 + bx + c)^m$ με $b^2 - 4c < 0$. Αν $\deg P < \deg Q$, τότε το $\frac{P}{Q}$ γράφεται μοναδικά ως άθροισμα όρων

$$\frac{A_j}{(x - a)^j}\ (1\le j\le k)\qquad\text{και}\qquad \frac{B_jx + C_j}{(x^2 + bx + c)^j}\ (1\le j\le m).$$

Αν $\deg P \ge \deg Q$, κάνουμε πρώτα διαίρεση πολυωνύμων: $\frac PQ = \Pi(x) + \frac{\Upsilon(x)}{Q(x)}$ με $\deg\Upsilon < \deg Q$.

Τα απλά κλάσματα και τα ολοκληρώματά τους

  • $\int\frac{dx}{x - a} = \ln|x - a| + c$, $\ \int\frac{dx}{(x - a)^k} = \frac{-1}{(k - 1)(x - a)^{k-1}} + c$ $(k\ge2)$.
  • $\int\frac{dx}{x^2 + bx + c}$: συμπληρώνουμε το τετράγωνο, $x^2 + bx + c = \left(x + \frac b2\right)^2 + \beta^2$, και παίρνουμε $\frac1\beta\arctan\frac{x + b/2}{\beta}$.
  • $\int\frac{Bx + C}{x^2 + bx + c}dx$: γράφουμε τον αριθμητή ως $\frac B2(2x + b) + \left(C - \frac{Bb}2\right)$ — το πρώτο κομμάτι δίνει λογάριθμο.
  • Για $I_k = \int\frac{dx}{(x^2 + 1)^k}$: $\ I_{k+1} = \frac{x}{2k(x^2 + 1)^k} + \frac{2k - 1}{2k}I_k$.

Μέθοδος «κάλυψης» (Heaviside)

Για $\frac{5x - 1}{(x - 1)(x + 1)} = \frac A{x - 1} + \frac B{x + 1}$: πολλαπλασιάζουμε επί $(x - 1)(x + 1)$ και θέτουμε τις ρίζες.

Λύση βήμα-βήμα

$5x - 1 = A(x + 1) + B(x - 1)$. Για $x = 1$: $4 = 2A$, $A = 2$. Για $x = -1$: $-6 = -2B$, $B = 3$. Άρα $\int\frac{5x - 1}{x^2 - 1}dx = 2\ln|x - 1| + 3\ln|x + 1| + c$.

Τετραγωνικός παράγοντας: $x^4 + 1$

Το $x^4 + 1$ δεν έχει πραγματικές ρίζες, αλλά γράφεται $x^4 + 1 = (x^2 + \sqrt2x + 1)(x^2 - \sqrt2x + 1)$ — παράδειγμα των σημειώσεων για το ότι κάθε πολυώνυμο αναλύεται σε γραμμικούς και τετραγωνικούς παράγοντες.

Συχνά λάθη

Ανάλυση χωρίς προηγούμενη διαίρεση όταν $\deg P\ge\deg Q$· παράλειψη όρων για πολλαπλές ρίζες (για $x^2$ στον παρονομαστή χρειάζονται και $\frac Ax$ και $\frac B{x^2}$)· αριθμητής σταθερός αντί $Bx + C$ πάνω από τετραγωνικό παράγοντα.

Πειραματίσου

f(x) = (3x − 3) / ((x + 1)(x − 2)) = 2/(x + 1) + 1/(x − 2)
∫ f(x) dx = 2 ln|x + 1| + ln|x − 2| + c
Μέθοδος «κάλυψης» (Heaviside): A = (αριθμητής)/(x − b) στο x = a, B = (αριθμητής)/(x − a) στο x = b. Η μπλε καμπύλη είναι το άθροισμα της πορτοκαλί και της μωβ.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να βρείτε τα $A$, $B$ ώστε $\displaystyle\frac{5x - 1}{(x - 1)(x + 1)} = \frac{A}{x - 1} + \frac{B}{x + 1}$.
Υπόδειξη: Θέστε $x = 1$ και $x = -1$ στην $5x - 1 = A(x + 1) + B(x - 1)$.
Λύση: $x = 1$: $4 = 2A$, $A = 2$. $x = -1$: $-6 = -2B$, $B = 3$.
Άσκηση 2Μέτρια
Να υπολογίσετε το $\displaystyle\int_2^3\frac{dx}{x^2 - 1}$ με 4 δεκαδικά.
Υπόδειξη: $\frac1{x^2 - 1} = \frac12\left(\frac1{x - 1} - \frac1{x + 1}\right)$.
Λύση: $\frac12\left[\ln\frac{x - 1}{x + 1}\right]_2^3 = \frac12\left(\ln\frac12 - \ln\frac13\right) = \frac12\ln\frac32 \approx 0{,}2027$.
Άσκηση 3Βασική
Να βρείτε μια αντιπαράγωγο της $\displaystyle\frac{2x + 3}{x^2 + 3x + 2}$ για $x > 0$.
Υπόδειξη: Ο αριθμητής είναι η παράγωγος του παρονομαστή.
Λύση: $\int\frac{(x^2 + 3x + 2)'}{x^2 + 3x + 2}dx = \ln(x^2 + 3x + 2) + c$.
Άσκηση 4Μέτρια
Να βρείτε μια αντιπαράγωγο της $\displaystyle\frac{1}{x^2 + 2x + 5}$.
Υπόδειξη: Συμπλήρωση τετραγώνου: $x^2 + 2x + 5 = (x + 1)^2 + 4$.
Λύση: $\int\frac{dx}{(x + 1)^2 + 2^2} = \frac12\arctan\frac{x + 1}{2} + c$.
Άσκηση 5Μέτρια
Να βρείτε τα $A, B, C$ ώστε $\displaystyle\frac1{x^2(x + 1)} = \frac Ax + \frac B{x^2} + \frac C{x + 1}$.
Υπόδειξη: $1 = Ax(x + 1) + B(x + 1) + Cx^2$· θέστε $x = 0$, $x = -1$ και συγκρίνετε συντελεστές του $x^2$.
Λύση: $x = 0$: $B = 1$. $x = -1$: $C = 1$. Συντελεστής του $x^2$: $A + C = 0$, άρα $A = -1$.
Άσκηση 6Απαιτητική
Να υπολογίσετε το $\displaystyle\int_0^1\frac{dx}{(x^2 + 1)^2}$ με 4 δεκαδικά.
Υπόδειξη: Αναγωγικός τύπος: $I_2 = \frac{x}{2(x^2 + 1)} + \frac12 I_1$, με $I_1 = \arctan x$.
Λύση: $\left[\frac{x}{2(x^2 + 1)} + \frac12\arctan x\right]_0^1 = \frac14 + \frac\pi8 \approx 0{,}6427$.
Άσκηση 7Βασική
Για να ολοκληρώσουμε το $\displaystyle\frac{x^3 + 1}{x^2 - 1}$, το πρώτο βήμα είναι:
Υπόδειξη: Συγκρίνετε τους βαθμούς αριθμητή και παρονομαστή.
Λύση: Ο αριθμητής έχει βαθμό $3 \ge 2$: πρώτα διαίρεση, $\frac{x^3 + 1}{x^2 - 1} = x + \frac{x + 1}{x^2 - 1} = x + \frac1{x - 1}$. Η άμεση ανάλυση θα ήταν λάθος.
Άσκηση 8Μέτρια
Να γράψετε το $\displaystyle\int_0^1\frac{x^3}{x^2 + 1}dx$ στη μορφή $\alpha + \beta\ln2$.
Υπόδειξη: Διαίρεση: $\frac{x^3}{x^2 + 1} = x - \frac{x}{x^2 + 1}$.
Λύση: $\left[\frac{x^2}2 - \frac12\ln(x^2 + 1)\right]_0^1 = \frac12 - \frac12\ln2$.
Άσκηση 9Απαιτητική
Να βρείτε τα $A, B, C$ ώστε $\displaystyle\frac1{x^3 + x} = \frac Ax + \frac{Bx + C}{x^2 + 1}$.
Υπόδειξη: $1 = A(x^2 + 1) + (Bx + C)x$· θέστε $x = 0$ και συγκρίνετε συντελεστές.
Λύση: $x = 0$: $A = 1$. Συντελεστής $x^2$: $A + B = 0$, $B = -1$. Συντελεστής $x$: $C = 0$. Άρα $\int\frac{dx}{x^3 + x} = \ln|x| - \frac12\ln(x^2 + 1) + c$.

♾️ Γεννήτρια — ανάλυση σε απλά κλάσματα

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε τα $A$, $B$ ώστε $\displaystyle\frac{-x}{(x - 1)(x - 2)} = \frac{A}{x - 1} + \frac{B}{x - 2}$.
Υπόδειξη: Πολλαπλασιάστε επί $(x - 1)(x - 2)$ και θέστε $x = 1$, έπειτα $x = 2$.
Λύση: $-x = A(x - 2) + B(x - 1)$. Για $x = 1$: $-1 = -A$, άρα $A = 1$. Για $x = 2$: $-2 = B$, άρα $B = -2$.
