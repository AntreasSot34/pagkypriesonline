5.2

Μερικές παράγωγοι – Εφαπτόμενο επίπεδο – Γραμμική προσέγγιση

📘 Αντίστοιχο κεφάλαιο: Κεφ. 5 · Βλ. και Stewart, Λογισμός, «Μερικές παράγωγοι»

Θεωρία

Μερικές παράγωγοι

$$f_x(a, b) = \lim_{h\to 0}\frac{f(a + h, b) - f(a, b)}{h}, \qquad f_y(a, b) = \lim_{h\to 0}\frac{f(a, b + h) - f(a, b)}{h}.$$ Για την $f_x$ παραγωγίζουμε ως προς $x$ θεωρώντας το $y$ σταθερά. Γεωμετρικά, η $f_x(a, b)$ είναι η κλίση της τομής της επιφάνειας με το επίπεδο $y = b$.

Π.χ. $f = x^3y^2 + 4xy$: $\ f_x = 3x^2y^2 + 4y$, $\ f_y = 2x^3y + 4x$.

Παράγωγοι ανώτερης τάξης

$f_{xx},\ f_{xy} = (f_x)_y,\ f_{yx},\ f_{yy}$. Θεώρημα Schwarz (Clairaut): αν οι $f_{xy}, f_{yx}$ είναι συνεχείς σε ανοικτό δίσκο γύρω από το $(a, b)$, τότε $f_{xy}(a, b) = f_{yx}(a, b)$.

Εφαπτόμενο επίπεδο – γραμμική προσέγγιση

Αν η $f$ είναι διαφορίσιμη στο $(a, b)$ (αρκεί οι $f_x, f_y$ να είναι συνεχείς κοντά στο $(a, b)$), το εφαπτόμενο επίπεδο στο $(a, b, f(a, b))$ είναι $$z = f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b),$$ και για $(x, y)$ κοντά στο $(a, b)$: $f(x, y) \approx L(x, y)$ (η ίδια έκφραση).

Π.χ. $f = \sqrt{x^2 + y^2}$ στο $(3, 4)$: $f = 5$, $f_x = \frac35$, $f_y = \frac45$, άρα $f(3{,}1;\ 3{,}9) \approx 5 + 0{,}06 - 0{,}08 = 4{,}98$.

Προσοχή

Η ύπαρξη των μερικών παραγώγων σε ένα σημείο δεν εξασφαλίζει ούτε συνέχεια ούτε διαφορισιμότητα: η $\frac{xy}{x^2 + y^2}$ (με $f(0, 0) = 0$) έχει $f_x(0, 0) = f_y(0, 0) = 0$, αλλά δεν είναι συνεχής στο $(0, 0)$.

Πειραματίσου

Μπλε: τομή y = 0,5, δηλαδή z = f(x, 0,5) — κλίση στο x = 1: fx(1, 0,5) = 1 (κόκκινη εφαπτομένη)
Πορτοκαλί: τομή x = 1, z = f(1, y) — κλίση στο y = 0,5: fy = 2 (γκρι εφαπτομένη)
Εφαπτόμενο επίπεδο: z = 0,75 + 1(x − 1) + 2(y − 0,5)
Ο οριζόντιος άξονας είναι το x για τη μπλε τομή και το y για την πορτοκαλί.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Για την $f(x, y) = x^3y^2 + 4xy$ να βρείτε τις $f_x(1, 2)$ και $f_y(1, 2)$.
Υπόδειξη: $f_x = 3x^2y^2 + 4y$, $f_y = 2x^3y + 4x$.
Λύση: $f_x(1, 2) = 3\cdot 4 + 8 = 20$, $f_y(1, 2) = 2\cdot 2 + 4 = 8$.
Άσκηση 2Βασική
Για την $f(x, y) = e^{xy}$ να βρείτε τις $f_x(0, 3)$ και $f_{xy}(0, 3)$.
Υπόδειξη: $f_x = y e^{xy}$· παραγωγίστε το γινόμενο ως προς $y$.
Λύση: $f_x = ye^{xy} \Rightarrow f_x(0, 3) = 3$. $f_{xy} = e^{xy} + xye^{xy} \Rightarrow f_{xy}(0, 3) = 1$.
Άσκηση 3Βασική
Για την $f(x, y) = \ln(x^2 + y^2)$ να βρείτε την $f_x(1, 1)$.
Υπόδειξη: Κανόνας αλυσίδας: $(\ln u)' = \frac{u'}{u}$.
Λύση: $f_x = \frac{2x}{x^2 + y^2} = \frac{2}{2} = 1$.
Άσκηση 4Μέτρια
Για την $f(x, y) = \sin x\cos y$ να βρείτε την $f_{xy}\left(0, \frac\pi2\right)$.
Υπόδειξη: $f_x = \cos x\cos y$.
Λύση: $f_x = \cos x\cos y$, $f_{xy} = -\cos x\sin y$. Στο $(0, \frac\pi2)$: $-1\cdot 1 = -1$.
Άσκηση 5Μέτρια
Να βρείτε το εφαπτόμενο επίπεδο $z = \alpha x + \beta y + \gamma$ της επιφάνειας $z = x^2 + y^2$ στο σημείο $(1, 2, 5)$.
Υπόδειξη: $z = f(1, 2) + f_x(1, 2)(x - 1) + f_y(1, 2)(y - 2)$.
Λύση: $f_x = 2x = 2$, $f_y = 2y = 4$: $z = 5 + 2(x - 1) + 4(y - 2) = 2x + 4y - 5$.
Άσκηση 6Μέτρια
Με γραμμική προσέγγιση της $f(x, y) = \sqrt{x^2 + y^2}$ γύρω από το $(3, 4)$, να εκτιμήσετε την τιμή $f(3{,}1;\ 3{,}9)$.
Υπόδειξη: $f_x = \frac{x}{\sqrt{x^2 + y^2}}$, $f_y = \frac{y}{\sqrt{x^2 + y^2}}$.
Λύση: $L = 5 + \frac35(0{,}1) + \frac45(-0{,}1) = 5 + 0{,}06 - 0{,}08 = 4{,}98$ (πραγματική τιμή $\approx 4{,}9820$).
Άσκηση 7Μέτρια
Για την $f(x, y) = x^2y - y^3$ να υπολογίσετε το $f_{xx} + f_{yy}$ στο σημείο $(1, 2)$.
Υπόδειξη: $f_{xx} = 2y$, $f_{yy} = -6y$.
Λύση: $f_{xx} + f_{yy} = 2y - 6y = -4y = -8$ στο $(1, 2)$ (άρα η $f$ δεν είναι αρμονική).
Άσκηση 8Μέτρια
Το θεώρημα Schwarz εξασφαλίζει $f_{xy}(a, b) = f_{yx}(a, b)$ όταν:
Υπόδειξη: Χρειάζεται υπόθεση για τις μικτές παραγώγους.
Λύση: Η υπόθεση είναι η συνέχεια των μικτών παραγώγων σε περιοχή του σημείου· χωρίς αυτήν υπάρχουν αντιπαραδείγματα με $f_{xy} \ne f_{yx}$.
Άσκηση 9Απαιτητική
Αν υπάρχουν οι $f_x(a, b)$ και $f_y(a, b)$, τότε η $f$ είναι συνεχής στο $(a, b)$.
Υπόδειξη: Σκεφτείτε την $\frac{xy}{x^2 + y^2}$ με $f(0, 0) = 0$.
Λύση: Λάθος: για αυτή τη συνάρτηση $f_x(0, 0) = f_y(0, 0) = 0$ (είναι $0$ πάνω στους άξονες), αλλά η $f$ δεν είναι συνεχής στο $(0, 0)$.

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Για τη συνάρτηση $f(x, y) = -x^{2}y^{2} - 4xy - y^2$ να βρείτε τις $f_x(2, 2)$ και $f_y(2, 2)$.
Υπόδειξη: Για την $f_x$ το $y$ θεωρείται σταθερά, και αντίστροφα.
Λύση: $f_x = -2xy^{2} - 4y$, $f_y = -2x^{2}y - 4x - 2y$. Στο $(2, 2)$: $f_x = -24$, $f_y = -28$.
