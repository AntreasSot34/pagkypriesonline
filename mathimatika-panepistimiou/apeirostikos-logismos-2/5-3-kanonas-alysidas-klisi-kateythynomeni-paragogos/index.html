5.3

Κανόνας αλυσίδας – Κλίση – Κατευθυνόμενη παράγωγος

📘 Αντίστοιχο κεφάλαιο: Κεφ. 5 · Βλ. και Stewart, Λογισμός, «Κανόνας αλυσίδας», «Κατευθυνόμενες παράγωγοι»

Θεωρία

Κανόνας αλυσίδας

Αν η $z = f(x, y)$ είναι διαφορίσιμη και $x = x(t),\ y = y(t)$ παραγωγίσιμες: $$\frac{dz}{dt} = f_x\frac{dx}{dt} + f_y\frac{dy}{dt}.$$ Αν $x = x(s, t),\ y = y(s, t)$: $\ \frac{\partial z}{\partial s} = f_x\frac{\partial x}{\partial s} + f_y\frac{\partial y}{\partial s}$, ομοίως για το $t$.

Πεπλεγμένη παραγώγιση: αν η $F$ έχει συνεχείς μερικές παραγώγους, η $F(x, y) = 0$ ορίζει την $y = y(x)$ και $F_y \ne 0$, τότε $\frac{dy}{dx} = -\frac{F_x}{F_y}$.

Κλίση και κατευθυνόμενη παράγωγος

Η κλίση (gradient) είναι το διάνυσμα $\nabla f = (f_x, f_y)$. Για μοναδιαίο διάνυσμα $\vec u = (u_1, u_2)$, η κατευθυνόμενη παράγωγος ορίζεται ως $D_{\vec u}f(a, b) = \lim_{h\to0}\frac{f(a + hu_1,\, b + hu_2) - f(a, b)}{h}$. Αν η $f$ είναι διαφορίσιμη στο $(a, b)$, τότε $$D_{\vec u}f(a, b) = \nabla f(a, b)\cdot\vec u.$$ Αν δίνεται μη μοναδιαίο $\vec v$, χρησιμοποιούμε $\vec u = \vec v/\|\vec v\|$.

Ιδιότητες της κλίσης

  • (Για διαφορίσιμη $f$ με $\nabla f(a, b)\ne\vec 0$.) $D_{\vec u}f = \|\nabla f\|\cos\theta$: μέγιστη τιμή $\|\nabla f\|$ στην κατεύθυνση του $\nabla f$, ελάχιστη $-\|\nabla f\|$ στην κατεύθυνση του $-\nabla f$.
  • Για διαφορίσιμη $f$ με $\nabla f(a, b)\ne\vec 0$, το $\nabla f(a, b)$ είναι κάθετο στην ισοϋψή που περνά από το $(a, b)$· έτσι η εφαπτομένη της $f(x, y) = c$ στο $(a, b)$ είναι $f_x(a, b)(x - a) + f_y(a, b)(y - b) = 0$.

Π.χ. $f = x^2 + y^2$ στο $(1, 2)$, $\vec v = (3, 4)$: $\nabla f = (2, 4)$, $\vec u = (\frac35, \frac45)$, $D_{\vec u}f = \frac65 + \frac{16}{5} = \frac{22}{5}$.

Πειραματίσου

Στο (1, 1): f = 2 · ∇f = (2, 2), ‖∇f‖ = 2,828
u = (cos φ, sin φ) = (0,866, 0,5) ⇒ Duf = ∇f · u = 2,732 (μέγιστη τιμή 2,828 στην κατεύθυνση του ∇f)
Η σκούρα καμπύλη είναι η ισοϋψής που περνά από το σημείο· η κλίση ∇f είναι πάντα κάθετη σε αυτήν.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Αν $z = x^2y$ με $x = t^2$, $y = t^3$, να βρείτε το $\frac{dz}{dt}$ για $t = 1$ με τον κανόνα αλυσίδας.
Υπόδειξη: $\frac{dz}{dt} = 2xy\cdot 2t + x^2\cdot 3t^2$.
Λύση: Για $t = 1$: $x = y = 1$, άρα $\frac{dz}{dt} = 2\cdot 1\cdot 1\cdot 2 + 1\cdot 3 = 7$. (Έλεγχος: $z = t^7$, $z' = 7t^6 = 7$.)
Άσκηση 2Βασική
Να βρείτε την κλίση $\nabla f(1, 2)$ της $f(x, y) = x^2 + 3xy$.
Υπόδειξη: $\nabla f = (2x + 3y,\ 3x)$.
Λύση: $\nabla f(1, 2) = (2 + 6,\ 3) = (8, 3)$.
Άσκηση 3Βασική
Να βρείτε την κατευθυνόμενη παράγωγο της $f(x, y) = x^2 + y^2$ στο $(1, 2)$ προς την κατεύθυνση του $\vec v = (3, 4)$.
Υπόδειξη: Κανονικοποιήστε το $\vec v$ πρώτα.
Λύση: $\nabla f = (2, 4)$, $\vec u = (\frac35, \frac45)$: $D_{\vec u}f = \frac65 + \frac{16}{5} = \frac{22}{5}$.
Άσκηση 4Μέτρια
Ποιος είναι ο μέγιστος ρυθμός μεταβολής της $f(x, y) = xe^y$ στο $(2, 0)$; (3 δεκαδικά)
Υπόδειξη: Ο μέγιστος ρυθμός είναι $\|\nabla f\|$.
Λύση: $\nabla f = (e^y,\ xe^y) = (1, 2)$ στο $(2, 0)$· μέγιστος ρυθμός $\|\nabla f\| = \sqrt5 \approx 2{,}236$, στην κατεύθυνση του $(1, 2)$.
Άσκηση 5Βασική
Η $x^2 + y^2 = 25$ ορίζει πεπλεγμένα την $y = y(x)$ κοντά στο $(3, 4)$. Να βρείτε το $\frac{dy}{dx}$ στο $(3, 4)$.
Υπόδειξη: $\frac{dy}{dx} = -\frac{F_x}{F_y}$.
Λύση: $F = x^2 + y^2 - 25$: $\frac{dy}{dx} = -\frac{2x}{2y} = -\frac34$.
Άσκηση 6Μέτρια
Το «φύλλο του Descartes» $x^3 + y^3 = 6xy$ περνά από το $(3, 3)$. Να βρείτε την κλίση της εφαπτομένης εκεί.
Υπόδειξη: $F = x^3 + y^3 - 6xy$, $F_x = 3x^2 - 6y$, $F_y = 3y^2 - 6x$.
Λύση: $F_x(3, 3) = 27 - 18 = 9$, $F_y(3, 3) = 27 - 18 = 9$, άρα $\frac{dy}{dx} = -\frac99 = -1$.
Άσκηση 7Μέτρια
Αν $z = xy$ με $x = s + t$, $y = s - t$, να βρείτε τα $\frac{\partial z}{\partial s}$ και $\frac{\partial z}{\partial t}$ στο $(s, t) = (3, 1)$.
Υπόδειξη: $z_s = y\cdot 1 + x\cdot 1$, $z_t = y\cdot 1 + x\cdot(-1)$.
Λύση: Για $(s, t) = (3, 1)$: $x = 4$, $y = 2$. $z_s = y + x = 6$, $z_t = y - x = -2$. (Έλεγχος: $z = s^2 - t^2$.)
Άσκηση 8Βασική
Σε ένα σημείο με $\nabla f \ne \vec 0$, η $f$ ελαττώνεται ταχύτερα προς την κατεύθυνση:
Υπόδειξη: $D_{\vec u}f = \|\nabla f\|\cos\theta$.
Λύση: Η $D_{\vec u}f$ είναι ελάχιστη ($= -\|\nabla f\|$) όταν $\theta = \pi$, δηλαδή $\vec u$ αντίρροπο του $\nabla f$. Κάθετα στο $\nabla f$ ο ρυθμός είναι $0$ (εφαπτομένη ισοϋψούς).
Άσκηση 9Απαιτητική
Η εφαπτομένη της έλλειψης $x^2 + 2y^2 = 9$ στο σημείο $(1, 2)$ γράφεται $x + \lambda y = c$. Να βρείτε τα $\lambda, c$.
Υπόδειξη: Το $\nabla f(1, 2)$ είναι κάθετο στην εφαπτομένη.
Λύση: $\nabla f = (2x, 4y) = (2, 8)$: $2(x - 1) + 8(y - 2) = 0 \iff 2x + 8y = 18 \iff x + 4y = 9$.

♾️ Γεννήτρια — κλίση και κατευθυνόμενη παράγωγος

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Δίνεται $f(x, y) = -x^2 + y^2 + 3xy$. Να βρείτε την κλίση $\nabla f(-2, 1)$ και την κατευθυνόμενη παράγωγο στο $(-2, 1)$ προς την κατεύθυνση του $\vec v = (-3, 4)$.
Υπόδειξη: Πρώτα κανονικοποιούμε: $\vec u = \vec v/\|\vec v\|$ με $\|\vec v\| = 5$.
Λύση: $\nabla f = (-2x + 3y,\ 2y + 3x) = (7, -4)$. $\vec u = \left(-\frac{3}{5}, \frac{4}{5}\right)$, $D_{\vec u}f = \nabla f\cdot\vec u = -\frac{37}{5}$.
