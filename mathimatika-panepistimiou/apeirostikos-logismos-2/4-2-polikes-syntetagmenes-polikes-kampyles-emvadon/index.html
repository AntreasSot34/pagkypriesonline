4.2

Πολικές συντεταγμένες – Πολικές καμπύλες – Εμβαδόν

📘 Αντίστοιχο κεφάλαιο: Κεφ. 4 · Βλ. και Stewart, Λογισμός, «Πολικές συντεταγμένες»

Θεωρία

Πολικές συντεταγμένες

Το σημείο με πολικές συντεταγμένες $(r, \theta)$ έχει καρτεσιανές $$x = r\cos\theta, \qquad y = r\sin\theta, \qquad\text{και}\qquad r^2 = x^2 + y^2,\ \ \tan\theta = \frac yx\ (x \ne 0).$$ Το $\theta$ επιλέγεται σύμφωνα με το τεταρτημόριο του σημείου (το $\arctan\frac yx$ μόνο δεν αρκεί). Η αναπαράσταση δεν είναι μοναδική: $(r, \theta) = (r, \theta + 2\pi) = (-r, \theta + \pi)$.

Βασικές πολικές καμπύλες

  • $r = a$: κύκλος κέντρου $O$, ακτίνας $|a|$ · $\ \theta = \alpha$: ευθεία από το $O$.
  • $r = 2a\cos\theta$: κύκλος $x^2 + y^2 = 2ax$ (κέντρο $(a, 0)$) · $\ r = 2a\sin\theta$: κύκλος κέντρου $(0, a)$.
  • $r = a(1 + \cos\theta)$: καρδιοειδής · $\ r = a\cos(n\theta)$ ή $a\sin(n\theta)$: ρόδο με $n$ φύλλα αν $n$ περιττός, $2n$ αν $n$ άρτιος.

Κλίση εφαπτομένης της $r = f(\theta)$: $\ \frac{dy}{dx} = \frac{f'(\theta)\sin\theta + f(\theta)\cos\theta}{f'(\theta)\cos\theta - f(\theta)\sin\theta}$.

Εμβαδόν σε πολικές

Το εμβαδόν του χωρίου που σαρώνει η $r = f(\theta)$, $\alpha \le \theta \le \beta$ (με $0 < \beta - \alpha \le 2\pi$), είναι $$A = \frac12\int_\alpha^\beta [f(\theta)]^2\,d\theta.$$ Παράδειγμα: καρδιοειδής $r = 1 + \cos\theta$: $\ A = \frac12\int_0^{2\pi}(1 + \cos\theta)^2 d\theta = \frac12\left(2\pi + 0 + \pi\right) = \frac{3\pi}{2}$.

Προσοχή

Σε ρόδα και σε καμπύλες με $r < 0$, ολοκληρώνουμε σε διάστημα που σαρώνει κάθε κομμάτι μία φορά (π.χ. ένα φύλλο του $r = \cos 2\theta$: $-\frac\pi4 \le \theta \le \frac\pi4$) και πολλαπλασιάζουμε με το πλήθος των φύλλων.

Πειραματίσου

θ = 1,2π, r(θ) = 0,191 ⇒ (x, y) = (r cos θ, r sin θ) = (-0,155, -0,112)
Σαρωμένο εμβαδόν ½∫₀^θ r² dθ ≈ 2,359 · για όλη την καμπύλη: 3π/2
Όταν r < 0 το σημείο σχεδιάζεται στην αντίθετη κατεύθυνση (θ + π)· ένα κομμάτι μπορεί να σαρωθεί δύο φορές — γι' αυτό διαλέγουμε προσεκτικά τα όρια του θ.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να μετατρέψετε σε καρτεσιανές συντεταγμένες το σημείο με πολικές συντεταγμένες $\left(2, \frac{\pi}{3}\right)$ (το $y$ με 3 δεκαδικά).
Υπόδειξη: $x = r\cos\theta$, $y = r\sin\theta$.
Λύση: $x = 2\cos\frac\pi3 = 1$, $y = 2\sin\frac\pi3 = \sqrt3 \approx 1{,}732$.
Άσκηση 2Βασική
Το σημείο $(-1, 1)$ έχει πολικές συντεταγμένες $(r, \theta)$ με $r > 0$, $0 \le \theta < 2\pi$. Να δώσετε το $r^2$ και τον λόγο $\theta/\pi$.
Υπόδειξη: Το σημείο βρίσκεται στο 2ο τεταρτημόριο.
Λύση: $r^2 = 1 + 1 = 2$ ($r = \sqrt2$). $\tan\theta = -1$ στο 2ο τεταρτημόριο ⇒ $\theta = \frac{3\pi}{4}$.
Άσκηση 3Βασική
Η πολική καμπύλη $r\cos\theta = 2$ είναι:
Υπόδειξη: $r\cos\theta = x$.
Λύση: $r\cos\theta = x$, άρα η καμπύλη είναι η κατακόρυφη ευθεία $x = 2$.
Άσκηση 4Μέτρια
Η καμπύλη $r = 4\sin\theta$ είναι κύκλος. Να βρείτε την τεταγμένη $y_0$ του κέντρου του $(0, y_0)$ και την ακτίνα του.
Υπόδειξη: Πολλαπλασιάστε με $r$: $r^2 = 4r\sin\theta$.
Λύση: $r^2 = 4r\sin\theta \Rightarrow x^2 + y^2 = 4y \Rightarrow x^2 + (y - 2)^2 = 4$: κέντρο $(0, 2)$, ακτίνα $2$.
Άσκηση 5Μέτρια
Πόσα φύλλα έχει το ρόδο $r = \sin 3\theta$ και πόσα το $r = \sin 4\theta$;
Υπόδειξη: $n$ περιττός: $n$ φύλλα· $n$ άρτιος: $2n$ φύλλα.
Λύση: $n = 3$ (περιττός) ⇒ $3$ φύλλα· $n = 4$ (άρτιος) ⇒ $8$ φύλλα.
Άσκηση 6Μέτρια
Να βρείτε το εμβαδόν που περικλείει η καρδιοειδής $r = 1 + \cos\theta$. Αν $A = \kappa\pi$, πόσο είναι το $\kappa$;
Υπόδειξη: $\cos^2\theta = \frac{1 + \cos 2\theta}{2}$.
Λύση: $A = \frac12\int_0^{2\pi}(1 + 2\cos\theta + \cos^2\theta)\,d\theta = \frac12\left(2\pi + 0 + \pi\right) = \frac{3\pi}{2}$, άρα $\kappa = \frac32$.
Άσκηση 7Μέτρια
Να βρείτε το εμβαδόν ενός φύλλου του ρόδου $r = \cos 2\theta$. Αν $A = \kappa\pi$, πόσο είναι το $\kappa$;
Υπόδειξη: Ένα φύλλο: $-\frac\pi4 \le \theta \le \frac\pi4$.
Λύση: $A = \frac12\int_{-\pi/4}^{\pi/4}\cos^2 2\theta\,d\theta = \frac12\int_{-\pi/4}^{\pi/4}\frac{1 + \cos 4\theta}{2}\,d\theta = \frac12\cdot\frac{\pi}{4} = \frac{\pi}{8}$.
Άσκηση 8Απαιτητική
Να βρείτε την κλίση της εφαπτομένης της σπείρας $r = \theta$ στο σημείο με $\theta = \frac\pi2$ (3 δεκαδικά).
Υπόδειξη: $\frac{dy}{dx} = \frac{r'\sin\theta + r\cos\theta}{r'\cos\theta - r\sin\theta}$ με $r' = 1$.
Λύση: Στο $\theta = \frac\pi2$: αριθμητής $1\cdot 1 + \frac\pi2\cdot 0 = 1$, παρονομαστής $1\cdot 0 - \frac\pi2\cdot 1 = -\frac\pi2$. Άρα $\frac{dy}{dx} = -\frac2\pi \approx -0{,}637$.
Άσκηση 9Βασική
Τα ζεύγη $(2, \frac\pi6)$ και $(-2, \frac{7\pi}{6})$ παριστάνουν το ίδιο σημείο του επιπέδου.
Υπόδειξη: $(r, \theta) = (-r, \theta + \pi)$.
Λύση: Σωστό: $(-2, \frac{7\pi}{6}) = (-2, \frac\pi6 + \pi)$, που είναι το ίδιο σημείο με το $(2, \frac\pi6)$.

♾️ Γεννήτρια — πολικές συντεταγμένες

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να μετατρέψετε σε καρτεσιανές συντεταγμένες το σημείο με πολικές συντεταγμένες $(r, \theta) = \left(2, \frac{3\pi}{2}\right)$.
Υπόδειξη: $x = r\cos\theta$, $y = r\sin\theta$.
Λύση: $x = 2\cos \frac{3\pi}{2} = 0$, $y = 2\sin \frac{3\pi}{2} = -2$.
