1.1

Ακολουθίες πραγματικών αριθμών – Όριο ακολουθίας

📘 Αντίστοιχο κεφάλαιο: Κεφ. 1 · Βλ. και Stewart, Απειροστικός Λογισμός, §11.1

Θεωρία

Ακολουθία και όριο

Ακολουθία είναι μια συνάρτηση $a: \mathbb N \to \mathbb R$, $n \mapsto a_n$. Λέμε ότι η $(a_n)$ συγκλίνει στο $L \in \mathbb R$ και γράφουμε $\lim_{n\to\infty} a_n = L$ ή $a_n \to L$, αν $$\forall \varepsilon > 0\ \ \exists N \in \mathbb N:\ \ n \ge N \Rightarrow |a_n - L| < \varepsilon.$$ Δηλαδή από κάποιον όρο και μετά, όλοι οι όροι βρίσκονται στη ζώνη $(L - \varepsilon, L + \varepsilon)$, όσο στενή κι αν είναι. Αν δεν υπάρχει τέτοιο $L$, η ακολουθία αποκλίνει (π.χ. $a_n \to +\infty$ ή ταλαντεύεται, όπως η $(-1)^n$).

Βασικές ιδιότητες

  • Το όριο, αν υπάρχει, είναι μοναδικό· κάθε συγκλίνουσα ακολουθία είναι φραγμένη.
  • Αν $a_n \to a$, $b_n \to b$: $a_n \pm b_n \to a \pm b$, $a_nb_n \to ab$, $\frac{a_n}{b_n} \to \frac ab$ (όταν $b \ne 0$).
  • Αν $\lim_{x\to\infty} f(x) = L$ και $a_n = f(n)$, τότε $a_n \to L$ (έτσι μπορούμε να χρησιμοποιούμε και de l'Hôpital στη συνάρτηση $f$).
  • Κριτήριο παρεμβολής: αν $b_n \le a_n \le c_n$ για $n \ge n_0$ και $b_n \to L$, $c_n \to L$, τότε $a_n \to L$. Συνέπεια: αν $|a_n| \to 0$ τότε $a_n \to 0$.

Χρήσιμα όρια

$\frac{1}{n^p} \to 0$ ($p > 0$) · $q^n \to 0$ για $|q| < 1$ · $\sqrt[n]{a} \to 1$ ($a > 0$) · $\sqrt[n]{n} \to 1$ · $\frac{\ln n}{n} \to 0$ · $\frac{a^n}{n!} \to 0$.
Λόγος πολυωνύμων: διαιρούμε με τη μεγαλύτερη δύναμη του παρονομαστή — ίδιοι βαθμοί δίνουν τον λόγο των μεγιστοβάθμιων συντελεστών.

Παράδειγμα και παγίδα

$\lim(\sqrt{n^2 + 3n} - n) = \lim \frac{3n}{\sqrt{n^2 + 3n} + n} = \lim \frac{3}{\sqrt{1 + 3/n} + 1} = \frac32$ (πολλαπλασιάζουμε με τη συζυγή παράσταση· η μορφή $\infty - \infty$ δεν είναι $0$).
Η $\frac{\sin n}{n}$: $-\frac1n \le \frac{\sin n}{n} \le \frac1n$, άρα τείνει στο $0$ — ενώ η $\sin n$ μόνη της δεν συγκλίνει.

Πειραματίσου

$a_n = \dfrac{3n+2}{n+1}$ · πρώτοι όροι: 2,5, 2,67, 2,75, 2,8, 2,83, …
Όριο $L = 3$. Για $\varepsilon = 0{,}2$: από τον όρο $n = 5$ και μετά όλοι οι όροι (πράσινοι) μένουν στη ζώνη $(L-\varepsilon, L+\varepsilon)$.
Μικραίνοντας το ε, το N μεγαλώνει — αλλά υπάρχει πάντα: αυτός είναι ο ορισμός $a_n \to L$.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\lim_{n\to\infty} \dfrac{3n^2 - n + 2}{5n^2 + 4}$.
Υπόδειξη: Διαιρέστε με $n^2$.
Λύση: $\dfrac{3 - \frac1n + \frac{2}{n^2}}{5 + \frac{4}{n^2}} \to \dfrac35$.
Άσκηση 2Βασική
Να υπολογίσετε το $\lim_{n\to\infty} \dfrac{2n + 1}{n^2 + 3}$.
Υπόδειξη: Μεγαλύτερος βαθμός στον παρονομαστή.
Λύση: Διαιρώντας με $n^2$: $\dfrac{\frac2n + \frac{1}{n^2}}{1 + \frac{3}{n^2}} \to \dfrac{0}{1} = 0$.
Άσκηση 3Μέτρια
Για την ακολουθία $a_n = \dfrac{3n + 2}{n + 1}$ ισχύει $a_n \to 3$. Για $\varepsilon = 0{,}01$, ποιο είναι το μικρότερο $N$ ώστε $|a_n - 3| < \varepsilon$ για κάθε $n \ge N$;
Υπόδειξη: $|a_n - 3| = \left|\frac{3n + 2 - 3n - 3}{n + 1}\right| = \frac{1}{n + 1}$.
Λύση: $\frac{1}{n + 1} < 0{,}01 \iff n + 1 > 100 \iff n > 99$. Άρα $N = 100$ (για $n = 99$: $|a_{99} - 3| = 0{,}01$, όχι γνήσια μικρότερο).
Άσκηση 4Μέτρια
Να υπολογίσετε το $\lim_{n\to\infty} \left(\sqrt{n^2 + 5n} - n\right)$.
Υπόδειξη: Πολλαπλασιάστε και διαιρέστε με τη συζυγή $\sqrt{n^2 + 5n} + n$.
Λύση: $\sqrt{n^2 + 5n} - n = \dfrac{5n}{\sqrt{n^2 + 5n} + n} = \dfrac{5}{\sqrt{1 + \frac5n} + 1} \to \dfrac{5}{2}$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\lim_{n\to\infty} \dfrac{2n + \cos n}{n + 1}$.
Υπόδειξη: $-1 \le \cos n \le 1$· κριτήριο παρεμβολής.
Λύση: $\dfrac{2n - 1}{n + 1} \le \dfrac{2n + \cos n}{n + 1} \le \dfrac{2n + 1}{n + 1}$ και τα δύο άκρα τείνουν στο $2$, άρα το όριο είναι $2$.
Άσκηση 6Μέτρια
Να υπολογίσετε το $\lim_{n\to\infty} \dfrac{2^n + 3^n}{3^{n+1}}$.
Υπόδειξη: Κοινός παράγοντας $3^n$.
Λύση: $\dfrac{3^n\left(\left(\frac23\right)^n + 1\right)}{3\cdot 3^n} = \dfrac{\left(\frac23\right)^n + 1}{3} \to \dfrac{0 + 1}{3} = \dfrac13$.
Άσκηση 7Βασική
Κάθε φραγμένη ακολουθία συγκλίνει.
Υπόδειξη: Σκεφτείτε την $(-1)^n$.
Λύση: Λάθος: η $a_n = (-1)^n$ είναι φραγμένη ($|a_n| \le 1$) αλλά δεν συγκλίνει. Ισχύει μόνο το αντίστροφο: κάθε συγκλίνουσα ακολουθία είναι φραγμένη.
Άσκηση 8Μέτρια
Για την ακολουθία $a_n = (-1)^n\dfrac{n}{n+1}$ ισχύει:
Υπόδειξη: Εξετάστε χωριστά τους άρτιους και τους περιττούς όρους.
Λύση: $a_{2k} = \frac{2k}{2k+1} \to 1$ ενώ $a_{2k+1} = -\frac{2k+1}{2k+2} \to -1$. Δύο υπακολουθίες με διαφορετικά όρια: η ακολουθία αποκλίνει (είναι όμως φραγμένη).
Άσκηση 9Απαιτητική
Να υπολογίσετε το $\lim_{n\to\infty} n\sin\dfrac1n$.
Υπόδειξη: Θέστε $x = \frac1n \to 0^+$ και χρησιμοποιήστε το $\lim_{x\to0}\frac{\sin x}{x}$.
Λύση: $n\sin\frac1n = \dfrac{\sin(1/n)}{1/n}$ και, αφού $\lim_{x\to 0}\frac{\sin x}{x} = 1$, το όριο είναι $1$ (μορφή $\infty\cdot 0$, όχι $0$).
Άσκηση 10Απαιτητική
Να υπολογίσετε το $\lim_{n\to\infty} \dfrac{\sqrt{9n^2 + n}}{2n - 5}$.
Υπόδειξη: Βγάλτε το $n$ από τη ρίζα: $\sqrt{9n^2 + n} = n\sqrt{9 + \frac1n}$ για $n > 0$.
Λύση: $\dfrac{n\sqrt{9 + \frac1n}}{n\left(2 - \frac5n\right)} = \dfrac{\sqrt{9 + \frac1n}}{2 - \frac5n} \to \dfrac{3}{2}$.

♾️ Γεννήτρια — όρια ακολουθιών

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\lim_{n\to\infty} \dfrac{3n + 2}{5n^{2} + 4}$.
Υπόδειξη: Μεγαλύτερος βαθμός στον παρονομαστή.
Λύση: Διαιρώντας με $n^2$: $\dfrac{\frac{3}{n} + \frac{2}{n^2}}{5 + \frac{4}{n^2}} \to \dfrac{0}{5} = 0$.
