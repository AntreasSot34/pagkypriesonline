6.3

Διωνυμικά ολοκληρώματα (Chebyshev) – Ολοκληρώματα με ριζικά – Αντικαταστάσεις Euler

📘 Σημειώσεις: Ζαφειρίδου §3.7–3.9 · Τσολομύτης κεφ. 8 §8.2 (Τεχνικές 8.2–8.3)

Πότε ένα ολοκλήρωμα με ριζικά, όπως το $\int x^m(a + bx^n)^p\,dx$, υπολογίζεται με στοιχειώδεις συναρτήσεις; Το θεώρημα του Chebyshev δίνει την απάντηση.

Θεωρία

Τα διωνυμικά ολοκληρώματα $\int x^m(a + bx^n)^p\,dx$ και τα ολοκληρώματα της μορφής $\int R\big(x, \sqrt{ax^2 + bx + c}\big)\,dx$ ανάγονται σε ολοκληρώματα ρητών συναρτήσεων με κατάλληλη αντικατάσταση. Το θεώρημα του Chebyshev λέει ακριβώς πότε αυτό είναι δυνατό· οι αντικαταστάσεις του Euler χειρίζονται την τετραγωνική ρίζα.

Θεώρημα Chebyshev για το διωνυμικό ολοκλήρωμα

Έστω $m, n, p\in\mathbb Q$, $a, b \ne 0$. Το $\int x^m(a + bx^n)^p\,dx$ εκφράζεται με στοιχειώδεις συναρτήσεις αν και μόνο αν ισχύει μία από τις περιπτώσεις:

  1. $p\in\mathbb Z$: θέτουμε $x = t^s$, $s$ = ΕΚΠ των παρονομαστών των $m, n$.
  2. $\frac{m+1}{n}\in\mathbb Z$: θέτουμε $a + bx^n = t^s$, $s$ = παρονομαστής του $p$.
  3. $\frac{m+1}{n} + p\in\mathbb Z$: θέτουμε $ax^{-n} + b = t^s$, $s$ = παρονομαστής του $p$.

Σε κάθε περίπτωση προκύπτει ολοκλήρωμα ρητής συνάρτησης του $t$.

$\int x^3\sqrt{1 + x^2}\,dx$

$m = 3$, $n = 2$, $p = \frac12$: $\frac{m+1}{n} = 2\in\mathbb Z$ (περίπτωση 2). Θέτουμε $1 + x^2 = t^2$, $x\,dx = t\,dt$:

Λύση βήμα-βήμα

$\int x^2\sqrt{1 + x^2}\,x\,dx = \int(t^2 - 1)t\cdot t\,dt = \frac{t^5}5 - \frac{t^3}3 + c = \frac{(1 + x^2)^{5/2}}5 - \frac{(1 + x^2)^{3/2}}3 + c$.

Αντικαταστάσεις Euler για $\int R\big(x, \sqrt{ax^2 + bx + c}\big)dx$

  • Αν $a > 0$: $\sqrt{ax^2 + bx + c} = t - \sqrt a\,x$.
  • Αν $c > 0$: $\sqrt{ax^2 + bx + c} = xt + \sqrt c$.
  • Αν το τριώνυμο έχει πραγματική ρίζα $\lambda$: $\sqrt{ax^2 + bx + c} = t(x - \lambda)$.

Γεωμετρικά, η ευθεία $y = t - x$ τέμνει την υπερβολή $y = \sqrt{1 + x^2}$ σε ένα μόνο σημείο, οπότε $x$ και $\sqrt{1 + x^2}$ είναι ρητές συναρτήσεις του $t$.

Ρητές συναρτήσεις των $\sin x$, $\cos x$

Η αντικατάσταση $t = \tan\frac x2$ δίνει $\sin x = \frac{2t}{1 + t^2}$, $\cos x = \frac{1 - t^2}{1 + t^2}$, $dx = \frac{2\,dt}{1 + t^2}$ και μετατρέπει κάθε $\int R(\sin x, \cos x)\,dx$ σε ολοκλήρωμα ρητής συνάρτησης.

Προσοχή

Το $\int\sqrt{1 + x^3}\,dx$ ($m = 0$, $n = 3$, $p = \frac12$) δεν ικανοποιεί καμία περίπτωση: δεν είναι στοιχειώδες, όσο κι αν προσπαθήσουμε.

Πειραματίσου

∫ x (a + b x2)1/2 dx
Περίπτωση 2: (m + 1)/n = 1 ακέραιος. Θέτουμε a + b xn = ts, όπου s = παρονομαστής του p = 2. Ολοκλήρωμα ρητής συνάρτησης του t.
Θεώρημα Chebyshev: το διωνυμικό ολοκλήρωμα (m, n, p ρητοί, a, b ≠ 0) είναι στοιχειώδες αν και μόνο αν ένας από τους p, (m+1)/n, (m+1)/n + p είναι ακέραιος.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Για το $\int x^3\sqrt{1 + x^2}\,dx$, ποια περίπτωση του θεωρήματος Chebyshev ισχύει;
Υπόδειξη: $m = 3$, $n = 2$, $p = \frac12$.
Λύση: $p = \frac12\notin\mathbb Z$, ενώ $\frac{m+1}{n} = \frac42 = 2\in\mathbb Z$· θέτουμε $1 + x^2 = t^2$.
Άσκηση 2Βασική
Γράψτε το $\displaystyle\int\frac{dx}{x^2\sqrt{1 + x^2}}$ ως διωνυμικό ολοκλήρωμα και υπολογίστε την ποσότητα $\frac{m+1}{n} + p$.
Υπόδειξη: $\frac1{x^2\sqrt{1 + x^2}} = x^{-2}(1 + x^2)^{-1/2}$.
Λύση: $m = -2$, $n = 2$, $p = -\frac12$: $\frac{-1}{2} - \frac12 = -1\in\mathbb Z$ (περίπτωση 3, θέτουμε $x^{-2} + 1 = t^2$).
Άσκηση 3Μέτρια
Να υπολογίσετε το $\displaystyle\int_0^1 x^3\sqrt{1 + x^2}\,dx$ με 4 δεκαδικά.
Υπόδειξη: Θέστε $u = 1 + x^2$: $\frac12\int_1^2(u - 1)\sqrt u\,du$.
Λύση: $\frac12\left[\frac25u^{5/2} - \frac23u^{3/2}\right]_1^2 = \frac{2\sqrt2 + 2}{15} \approx 0{,}3219$.
Άσκηση 4Μέτρια
Με την αντικατάσταση Euler $\sqrt{x^2 + 1} = t - x$, να βρείτε μια αντιπαράγωγο της $\displaystyle\frac1{\sqrt{x^2 + 1}}$.
Υπόδειξη: Από $\sqrt{x^2 + 1} = t - x$: $x = \frac{t^2 - 1}{2t}$, $dx = \frac{t^2 + 1}{2t^2}dt$, $\sqrt{x^2 + 1} = \frac{t^2 + 1}{2t}$.
Λύση: Το ολοκλήρωμα γίνεται $\int\frac{dt}{t} = \ln|t| + c = \ln\big(x + \sqrt{x^2 + 1}\big) + c$.
Άσκηση 5Μέτρια
Να γράψετε το $\displaystyle\int_0^1\frac{dx}{1 + \sqrt x}$ στη μορφή $\alpha + \beta\ln2$.
Υπόδειξη: Θέστε $x = t^2$, $dx = 2t\,dt$.
Λύση: $\int_0^1\frac{2t}{1 + t}dt = 2\int_0^1\left(1 - \frac1{1 + t}\right)dt = 2 - 2\ln2$.
Άσκηση 6Μέτρια
Με την αντικατάσταση $t = \tan\frac x2$, να υπολογίσετε το $\displaystyle\int_0^{\pi/2}\frac{dx}{1 + \cos x}$.
Υπόδειξη: $1 + \cos x = \frac{2}{1 + t^2}$ και $dx = \frac{2dt}{1 + t^2}$.
Λύση: $\int_0^1\frac{1 + t^2}{2}\cdot\frac{2}{1 + t^2}dt = \int_0^1dt = 1$.
Άσκηση 7Βασική
Το $\int\sqrt{1 + x^3}\,dx$:
Υπόδειξη: $m = 0$, $n = 3$, $p = \frac12$· ελέγξτε $p$, $\frac{m+1}{n}$, $\frac{m+1}n + p$.
Λύση: $p = \frac12$, $\frac{m+1}{n} = \frac13$, $\frac13 + \frac12 = \frac56$ — κανένας ακέραιος. Από το θεώρημα Chebyshev το ολοκλήρωμα δεν είναι στοιχειώδες.
Άσκηση 8Απαιτητική
Να υπολογίσετε το $\displaystyle\int_0^{\pi/2}\frac{dx}{2 + \cos x}$ με 4 δεκαδικά.
Υπόδειξη: Με $t = \tan\frac x2$: $2 + \cos x = \frac{3 + t^2}{1 + t^2}$.
Λύση: $\int_0^1\frac{2\,dt}{3 + t^2} = \frac{2}{\sqrt3}\arctan\frac{1}{\sqrt3} = \frac2{\sqrt3}\cdot\frac\pi6 = \frac{\pi}{3\sqrt3} \approx 0{,}6046$.
Άσκηση 9Απαιτητική
Αν $\displaystyle\int_{\sqrt2}^{2}\frac{dx}{x\sqrt{x^2 - 1}} = \kappa\pi$, να βρείτε το $\kappa$.
Υπόδειξη: Διωνυμικό με $\frac{m+1}{n} = 0$· ή θέστε $x = \frac1{\cos t}$.
Λύση: Με $x = \frac1{\cos t}$: $\int\frac{dx}{x\sqrt{x^2 - 1}} = \int dt = t$. Τα άκρα: $x = \sqrt2 \Rightarrow t = \frac\pi4$, $x = 2 \Rightarrow t = \frac\pi3$. Άρα $\frac\pi3 - \frac\pi4 = \frac\pi{12}$, $\kappa = \frac1{12}$.

♾️ Γεννήτρια — διωνυμικά ολοκληρώματα (Chebyshev)

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Γράφουμε το $\int x^{1/3}(2 + x^{2/3})^{1/4}\,dx$ ως διωνυμικό $\int x^m(a + bx^n)^p\,dx$. Ποια περίπτωση του θεωρήματος Chebyshev ισχύει (ελέγχοντας με τη σειρά $p$, $\frac{m+1}{n}$, $\frac{m+1}{n}+p$);
Υπόδειξη: Βρείτε πρώτα τα $m$, $n$, $p$ (π.χ. $\frac{1}{x^2} = x^{-2}$, $\sqrt[3]{x} = x^{1/3}$).
Λύση: Ο $\frac{m+1}{n}$ είναι ακέραιος· θέτουμε $a + bx^n = t^s$, $s$ ο παρονομαστής του $p$.
