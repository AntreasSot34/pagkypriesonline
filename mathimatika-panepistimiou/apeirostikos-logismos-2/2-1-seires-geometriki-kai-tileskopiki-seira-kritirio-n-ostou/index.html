2.1

Σειρές – Γεωμετρική και τηλεσκοπική σειρά – Κριτήριο n-οστού όρου

📘 Αντίστοιχο κεφάλαιο: Κεφ. 2 · Βλ. και Stewart, §11.2

Θεωρία

Σειρά και μερικά αθροίσματα

Για μια ακολουθία $(a_n)$ ορίζουμε τα μερικά αθροίσματα $S_N = a_1 + a_2 + \dots + a_N$. Η σειρά $\sum_{n=1}^\infty a_n$ συγκλίνει με άθροισμα $S$ αν $S_N \to S$· αλλιώς αποκλίνει. Αν $\sum a_n = A$, $\sum b_n = B$, τότε $\sum(\lambda a_n + \mu b_n) = \lambda A + \mu B$.

Γεωμετρική σειρά

$$\sum_{n=0}^{\infty} a r^n = a + ar + ar^2 + \dots = \frac{a}{1 - r}\quad\text{αν } |r| < 1,$$ ενώ για $|r| \ge 1$ (και $a \ne 0$) αποκλίνει. Αιτία: $S_N = a\frac{1 - r^{N+1}}{1 - r}$ και $r^{N+1} \to 0$ μόνο όταν $|r| < 1$. «Άθροισμα = πρώτος όρος / (1 − λόγος)».

Τηλεσκοπική σειρά

Αν $a_n = b_n - b_{n+1}$, τότε $S_N = b_1 - b_{N+1}$, οπότε η σειρά συγκλίνει ανν η $b_n$ συγκλίνει. Π.χ. $\frac{1}{n(n+1)} = \frac1n - \frac{1}{n+1}$, άρα $S_N = 1 - \frac{1}{N+1} \to 1$.

Κριτήριο n-οστού όρου (απόκλισης)

Αν η $\sum a_n$ συγκλίνει, τότε $a_n \to 0$. Ισοδύναμα: αν $a_n \not\to 0$, η σειρά αποκλίνει. Το αντίστροφο δεν ισχύει: η αρμονική $\sum \frac1n$ έχει $\frac1n \to 0$ αλλά αποκλίνει.

Πειραματίσου

■ όροι $a_n$ · ● μερικά αθροίσματα $S_n$
$\sum \left(\tfrac12\right)^{n}$: $S_{30} \approx 1$, άθροισμα σειράς $\approx 1$ · λόγος $a_{30}/a_{29} \approx 0{,}5$
γεωμετρική με λόγο ½: συγκλίνει στο ½ / (1 − ½) = 1.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το άθροισμα $\sum_{n=1}^{\infty} 3\left(\frac12\right)^{n-1}$.
Υπόδειξη: Πρώτος όρος $3$, λόγος $\frac12$.
Λύση: $\frac{3}{1 - \frac12} = 6$.
Άσκηση 2Βασική
Να υπολογίσετε το άθροισμα $\sum_{n=0}^{\infty} \left(-\frac23\right)^{n}$.
Υπόδειξη: $|r| = \frac23 < 1$.
Λύση: $\dfrac{1}{1 - \left(-\frac23\right)} = \dfrac{1}{\frac53} = \dfrac35$.
Άσκηση 3Βασική
Να υπολογίσετε το άθροισμα $\sum_{n=1}^{\infty} \dfrac{1}{n(n+1)}$.
Υπόδειξη: $\frac{1}{n(n+1)} = \frac1n - \frac{1}{n+1}$.
Λύση: Τηλεσκοπική: $S_N = 1 - \frac{1}{N+1} \to 1$.
Άσκηση 4Μέτρια
Να υπολογίσετε το άθροισμα $\sum_{n=1}^{\infty} \dfrac{1}{(n+1)(n+3)}$.
Υπόδειξη: $\frac{1}{(n+1)(n+3)} = \frac12\left(\frac{1}{n+1} - \frac{1}{n+3}\right)$.
Λύση: Στο $S_N$ απαλείφονται οι όροι εκτός από τους δύο πρώτους θετικούς και τους δύο τελευταίους αρνητικούς: $S_N = \frac12\left(\frac12 + \frac13 - \frac{1}{N+2} - \frac{1}{N+3}\right) \to \frac12\cdot\frac56 = \frac{5}{12}$.
Άσκηση 5Μέτρια
Να γράψετε τον περιοδικό αριθμό $0{,}\overline{36}$ ως άθροισμα γεωμετρικής σειράς και να τον μετατρέψετε σε ανάγωγο κλάσμα.
Υπόδειξη: $0{,}\overline{36} = \frac{36}{100} + \frac{36}{100^2} + \dots$
Λύση: Γεωμετρική με $a = \frac{36}{100}$, $r = \frac{1}{100}$: $\dfrac{36/100}{1 - 1/100} = \dfrac{36}{99} = \dfrac{4}{11}$.
Άσκηση 6Βασική
Η σειρά $\sum_{n=1}^\infty \dfrac{n}{2n+1}$:
Υπόδειξη: Κριτήριο n-οστού όρου.
Λύση: $a_n = \frac{n}{2n+1} \to \frac12 \ne 0$, άρα η σειρά αποκλίνει. (Το $\frac12$ είναι το όριο του όρου, όχι το άθροισμα.)
Άσκηση 7Βασική
Αν $a_n \to 0$, τότε η σειρά $\sum a_n$ συγκλίνει.
Υπόδειξη: Αρμονική σειρά.
Λύση: Λάθος: $\frac1n \to 0$ αλλά $\sum\frac1n = \infty$. Η συνθήκη $a_n \to 0$ είναι αναγκαία, όχι ικανή.
Άσκηση 8Μέτρια
Η σειρά $\sum_{n=0}^\infty (x-1)^n$ συγκλίνει ακριβώς για $a < x < b$. Να βρείτε τα $a, b$ και το άθροισμα για $x = \frac12$.
Υπόδειξη: Γεωμετρική με λόγο $r = x - 1$.
Λύση: Συγκλίνει ανν $|x - 1| < 1 \iff 0 < x < 2$. Το άθροισμα είναι $\frac{1}{1 - (x - 1)} = \frac{1}{2 - x}$· για $x = \frac12$: $\frac{1}{3/2} = \frac23$.
Άσκηση 9Απαιτητική
Να υπολογίσετε το άθροισμα $\sum_{n=1}^\infty \dfrac{2^n + 3^n}{6^n}$.
Υπόδειξη: Σπάστε σε δύο γεωμετρικές: $\left(\frac13\right)^n + \left(\frac12\right)^n$.
Λύση: $\sum_{n\ge1}\left(\frac13\right)^n = \frac{1/3}{1 - 1/3} = \frac12$ και $\sum_{n\ge1}\left(\frac12\right)^n = 1$. Αφού συγκλίνουν και οι δύο, το άθροισμα είναι $\frac12 + 1 = \frac32$.
Άσκηση 10Απαιτητική
Για τη σειρά $\sum_{n=1}^\infty \ln\dfrac{n}{n+1}$ ισχύει:
Υπόδειξη: $\ln\frac{n}{n+1} = \ln n - \ln(n+1)$: τηλεσκοπική.
Λύση: $S_N = (\ln 1 - \ln 2) + (\ln 2 - \ln 3) + \dots + (\ln N - \ln(N+1)) = -\ln(N+1) \to -\infty$. Αποκλίνει, παρότι ο γενικός όρος τείνει στο $0$.

♾️ Γεννήτρια — γεωμετρικές και τηλεσκοπικές σειρές

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το άθροισμα $\sum_{n=3}^{\infty} \dfrac{1}{n(n+1)}$.
Υπόδειξη: Απλά κλάσματα: $\frac{1}{n(n+1)} = \frac{1}{1}\left(\frac1n - \frac{1}{n+1}\right)$ — τηλεσκοπική.
Λύση: Τηλεσκοπική: $S_N = \frac{1}{3} - \frac{1}{N + 1} \to \frac{1}{3}$.
