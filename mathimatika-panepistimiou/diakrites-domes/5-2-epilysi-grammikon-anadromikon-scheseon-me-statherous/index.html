5.2

Επίλυση γραμμικών αναδρομικών σχέσεων με σταθερούς συντελεστές

📘 Αντίστοιχο κεφάλαιο: Κεφ. 5 · Βλ. και Rosen, κεφ. «Advanced Counting Techniques» (§ Solving Linear Recurrence Relations)

Θεωρία

Ομογενείς σχέσεις 2ης τάξης

Για τη γραμμική ομογενή σχέση με σταθερούς συντελεστές $a_n = c_1a_{n-1} + c_2a_{n-2}$ ($c_2 \ne 0$) η χαρακτηριστική εξίσωση είναι $r^2 - c_1r - c_2 = 0$.

  • Δύο διαφορετικές ρίζες $r_1 \ne r_2$: η γενική λύση είναι $a_n = \alpha_1 r_1^n + \alpha_2 r_2^n$.
  • Διπλή ρίζα $r_0$: $a_n = (\alpha_1 + \alpha_2 n)\,r_0^n$.

Οι σταθερές $\alpha_1, \alpha_2$ προσδιορίζονται από τις αρχικές συνθήκες ($n = 0, 1$). Γενικά, για τάξη $k$ η χαρακτηριστική εξίσωση είναι $r^k - c_1r^{k-1} - \cdots - c_k = 0$, και κάθε ρίζα $r_i$ πολλαπλότητας $m_i$ συνεισφέρει στη γενική λύση τον όρο $(\alpha_{i,0} + \alpha_{i,1}n + \dots + \alpha_{i,m_i-1}n^{m_i-1})\,r_i^n$.

Μη ομογενείς σχέσεις

Για $a_n = c_1a_{n-1} + c_2a_{n-2} + F(n)$: κάθε λύση είναι $a_n = a_n^{(h)} + a_n^{(p)}$, όπου $a_n^{(h)}$ η γενική λύση της ομογενούς και $a_n^{(p)}$ μια μερική λύση. Αν $F(n) = d$ σταθερά, δοκιμάζουμε $a_n^{(p)} = C$ (αν το $1$ δεν είναι ρίζα)· αν $F(n) = d\,s^n$ με $s$ όχι ρίζα, δοκιμάζουμε $a_n^{(p)} = C s^n$. Αν το $s$ (ή το $1$ για σταθερό $F$) είναι ρίζα πολλαπλότητας $m$, δοκιμάζουμε $a_n^{(p)} = C\,n^m s^n$ (π.χ. $F(n) = d$ και ρίζα $1$: $a_n^{(p)} = Cn$). Γενικά, για $F(n) = (b_tn^t + \dots + b_0)\,s^n$ η μερική λύση έχει τη μορφή $n^m(p_tn^t + \dots + p_0)\,s^n$, όπου $m$ η πολλαπλότητα του $s$ ως ρίζας ($m = 0$ αν δεν είναι ρίζα).

Παράδειγμα

$a_n = a_{n-1} + 2a_{n-2}$, $a_0 = 2$, $a_1 = 7$. Χαρακτηριστική: $r^2 - r - 2 = 0 \Rightarrow r = 2, -1$. Άρα $a_n = \alpha_1 2^n + \alpha_2(-1)^n$, με $\alpha_1 + \alpha_2 = 2$, $2\alpha_1 - \alpha_2 = 7$ ⇒ $\alpha_1 = 3$, $\alpha_2 = -1$: $a_n = 3\cdot 2^n - (-1)^n$.

Προσοχή

Στη χαρακτηριστική εξίσωση τα πρόσημα αλλάζουν: η $a_n = 5a_{n-1} - 6a_{n-2}$ δίνει $r^2 - 5r + 6 = 0$. Στη μη ομογενή περίπτωση οι αρχικές συνθήκες εφαρμόζονται στη συνολική λύση $a_n^{(h)} + a_n^{(p)}$, όχι μόνο στην ομογενή.

Πειραματίσου

Πρώτοι όροι ($a_0, a_1$ = αρχικές συνθήκες): $2,\ 7,\ 11,\ 25,\ 47,\ 97,\ 191,\ 385,\ 767,\ 1537,\ 3071$
Χαρακτηριστική $r^2 - r - 2 = 0$: ρίζες $-1, 2$, άρα $a_n = \alpha_1(-1)^n + \alpha_22^n$.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Να βρείτε τις ρίζες της χαρακτηριστικής εξίσωσης της $a_n = 7a_{n-1} - 10a_{n-2}$.
Υπόδειξη: $r^2 - 7r + 10 = 0$.
Λύση: $r^2 - 7r + 10 = (r - 2)(r - 5) = 0$, άρα $r = 2$ και $r = 5$.
Άσκηση 2Βασική
Ποια είναι η μορφή της γενικής λύσης της $a_n = 4a_{n-1} - 4a_{n-2}$;
Υπόδειξη: $r^2 - 4r + 4 = 0$.
Λύση: $(r - 2)^2 = 0$: διπλή ρίζα $2$, άρα $a_n = (\alpha_1 + \alpha_2 n)2^n$. Το $\alpha_1 2^n + \alpha_2 2^n$ είναι απλώς $c\,2^n$ και δεν μπορεί να ικανοποιήσει κάθε ζεύγος αρχικών συνθηκών.
Άσκηση 3Μέτρια
Να λύσετε την $a_n = 5a_{n-1} - 6a_{n-2}$ με $a_0 = 1$, $a_1 = 0$, γράφοντας τη λύση στη μορφή $a_n = \alpha\cdot 2^n + \beta\cdot 3^n$.
Υπόδειξη: $\alpha + \beta = 1$, $2\alpha + 3\beta = 0$.
Λύση: Ρίζες $2, 3$. Από τις αρχικές: $\alpha + \beta = 1$, $2\alpha + 3\beta = 0 \Rightarrow \beta = -2$, $\alpha = 3$. Άρα $a_n = 3\cdot 2^n - 2\cdot 3^n$ (έλεγχος: $a_2 = 12 - 18 = -6 = 5\cdot 0 - 6\cdot 1$ ✓).
Άσκηση 4Μέτρια
Να λύσετε την $a_n = 6a_{n-1} - 9a_{n-2}$ με $a_0 = 1$, $a_1 = 6$, στη μορφή $a_n = (\alpha + \beta n)3^n$.
Υπόδειξη: $r^2 - 6r + 9 = (r - 3)^2$: διπλή ρίζα.
Λύση: Διπλή ρίζα $3$. $a_0 = \alpha = 1$, $a_1 = 3(\alpha + \beta) = 6 \Rightarrow \beta = 1$. Άρα $a_n = (1 + n)3^n$.
Άσκηση 5Μέτρια
Να βρείτε τη λύση της $a_n = 2a_{n-1} + 3$, $a_0 = 1$, στη μορφή $a_n = \alpha\cdot 2^n + \gamma$.
Υπόδειξη: Μερική λύση σταθερή: $C = 2C + 3$.
Λύση: Μερική: $C = 2C + 3 \Rightarrow C = -3$. Γενική: $a_n = \alpha 2^n - 3$, και $a_0 = \alpha - 3 = 1 \Rightarrow \alpha = 4$. Άρα $a_n = 4\cdot 2^n - 3 = 2^{n+2} - 3$.
Άσκηση 6Μέτρια
Ο κλειστός τύπος (Binet) των αριθμών Fibonacci $f_0 = 0$, $f_1 = 1$ είναι:
Υπόδειξη: Ρίζες της $r^2 - r - 1 = 0$· από $f_0 = 0$ οι σταθερές είναι αντίθετες.
Λύση: Ρίζες $\frac{1\pm\sqrt5}2$. Το $f_0 = \alpha_1 + \alpha_2 = 0$ δίνει $\alpha_2 = -\alpha_1$ και το $f_1 = 1$ δίνει $\alpha_1\sqrt5 = 1$. Άρα ο τύπος με τη διαφορά και συντελεστή $\frac{1}{\sqrt5}$.
Άσκηση 7Απαιτητική
Να λύσετε την $a_n = 3a_{n-1} + 2^n$, $a_0 = 1$, στη μορφή $a_n = \alpha\cdot 3^n + C\cdot 2^n$.
Υπόδειξη: Μερική $C2^n$: $C2^n = 3C2^{n-1} + 2^n$.
Λύση: Διαιρώντας με $2^{n-1}$: $2C = 3C + 2 \Rightarrow C = -2$. Τότε $a_n = \alpha 3^n - 2\cdot 2^n$ και $a_0 = \alpha - 2 = 1 \Rightarrow \alpha = 3$. Άρα $a_n = 3^{n+1} - 2^{n+1}$ (έλεγχος: $a_1 = 3 + 2 = 5 = 9 - 4$ ✓).
Άσκηση 8Απαιτητική
Να λύσετε την $a_n = a_{n-1} + 6a_{n-2}$, $a_0 = 3$, $a_1 = 4$, στη μορφή $a_n = \alpha 3^n + \beta(-2)^n$, και να υπολογίσετε τον $a_5$.
Υπόδειξη: $r^2 - r - 6 = (r - 3)(r + 2)$.
Λύση: $\alpha + \beta = 3$, $3\alpha - 2\beta = 4 \Rightarrow 5\alpha = 10$, $\alpha = 2$, $\beta = 1$. $a_5 = 2\cdot 243 + (-32) = 454$.

♾️ Γεννήτρια — επίλυση γραμμικών αναδρομικών σχέσεων

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να λύσετε την $a_n = 4a_{n-1} - 4a_{n-2}$ με $a_0 = 3$, $a_1 = 10$, γράφοντας $a_n = (\alpha + \beta n)2^n$.
Λύση: Χαρακτηριστική $r^2 - 4r + 4 = (r - 2)^2$: διπλή ρίζα $2$. $a_0 = \alpha = 3$, $a_1 = 2(\alpha + \beta) = 10 \Rightarrow \beta = 2$.
