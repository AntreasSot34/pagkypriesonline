3.4

Συνεχείς τυχαίες μεταβλητές

📘 Σημειώσεις ΜΑΣ055 (Χριστοφίδης): Τυχαίες μεταβλητές (συνάρτηση πυκνότητας) · Φυλλάδιο ασκήσεων 5

Θεωρία

Συνάρτηση πυκνότητας

Η $X$ είναι συνεχής αν υπάρχει $f_X \ge 0$ με $\int_{-\infty}^\infty f_X(x)\,dx = 1$ ώστε $F_X(x) = \int_{-\infty}^x f_X(u)\,du$ για κάθε $x$. Τότε $P(a \le X \le b) = \int_a^b f(x)\,dx$, $P(X = x) = 0$ για κάθε $x$ (!) και $F'(x) = f(x)$ όπου η $f$ είναι συνεχής.

Μέση τιμή και διασπορά

$E(X) = \int x f(x)\,dx$ (αν $\int |x| f(x)\,dx \lt \infty$), $\ E[g(X)] = \int g(x) f(x)\,dx$, $\ \mathrm{Var}(X) = E(X^2) - (E(X))^2$. Το $p$-ποσοστιαίο σημείο $x_p$ ορίζεται από $F(x_p) = p$· για $p = 0{,}5$ η διάμεσος.

Παράδειγμα και παγίδες

Αν $f(x) = cx$ στο $[0, 2]$: $2c = 1 \Rightarrow c = \frac12$, $E(X) = \frac43$, $E(X^2) = 2$, $\mathrm{Var}(X) = \frac29$. Η τιμή $f(x)$ δεν είναι πιθανότητα και μπορεί να ξεπερνά το $1$· πιθανότητα δίνει μόνο το εμβαδόν.

Στην R

f <- function(x) x^2 / 9 · integrate(f, 1, 2) → 0.2592593 with absolute error < 2.9e-15 ($= 7/27$· το integrate(f, 1, 2)$value δίνει μόνο τον αριθμό) · integrate(function(x) x * f(x), 0, 3) → 2.25 ($E(X)$).

Πειραματίσου

P(0,5 ≤ X ≤ 1,5) = F(b) − F(a) = 0,5 (το σκιασμένο εμβαδόν)
E(X) = 1,3333 · Var(X) = 0,2222 · διάμεσος m = 1,4142 (F(m) = 0,5)
Το συνολικό εμβαδόν κάτω από την f είναι 1· η f(x) δεν είναι πιθανότητα — μπορεί να είναι και μεγαλύτερη του 1.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Η $X$ έχει πυκνότητα $f(x) = c\,x^2$ για $0 \le x \le 3$ και $0$ αλλού. Να βρείτε τη σταθερά $c$ και την $P(1 \le X \le 2)$.
Υπόδειξη: $\int_0^3 cx^2\,dx = 9c$.
Λύση: $9c = 1 \Rightarrow c = \frac19$. $P(1 \le X \le 2) = \int_1^2 \frac{x^2}{9}dx = \frac{8 - 1}{27} = \frac{7}{27}$.
Άσκηση 2Μέτρια
Ο χρόνος $X$ (σε ms) για τη μεταφορά ενός αρχείου έχει πυκνότητα $f(x) = \frac{2 - |2 - x|}{4}$ για $0 \le x \le 4$ (τριγωνική). Να βρείτε την $P(X \le 1)$, τη μέση τιμή και τη διασπορά της $X$.
Υπόδειξη: Στο $[0, 2]$ είναι $f(x) = x/4$· η $f$ είναι συμμετρική γύρω από το $2$.
Λύση: $P(X \le 1) = \int_0^1 \frac x4 dx = \frac18$. Συμμετρία: $E(X) = 2$. $E\big[(X - 2)^2\big] = 2\int_0^2 (x - 2)^2\frac x4\,dx = \frac12\int_0^2 (x^3 - 4x^2 + 4x)dx = \frac12\left(4 - \frac{32}{3} + 8\right) = \frac23$.
Άσκηση 3Βασική
Η $X$ έχει πυκνότητα $f(x) = \frac{x}{2}$, $0 \le x \le 2$. Να υπολογίσετε τα $E(X)$ και $\mathrm{Var}(X)$.
Υπόδειξη: $E(X^2) = \int_0^2 x^2\cdot\frac x2\,dx$.
Λύση: $E(X) = \frac43$, $E(X^2) = 2$, άρα $\mathrm{Var}(X) = 2 - \frac{16}{9} = \frac29$.
Άσκηση 4Βασική
Ποια από τις παρακάτω συναρτήσεις (ίση με $0$ εκτός του διαστήματος που δίνεται) είναι συνάρτηση πυκνότητας;
Υπόδειξη: Χρειάζεται $f \ge 0$ και ολοκλήρωμα $1$.
Λύση: $\int_0^1 3x^2dx = 1$ και $3x^2 \ge 0$. Η $2x$ στο $[0, 2]$ έχει ολοκλήρωμα $4$, η $\frac12$ στο $[0, 3]$ έχει $\frac32$, και η $x - 1$ παίρνει αρνητικές τιμές (και επιπλέον ολοκλήρωμα $0 \ne 1$).
Άσκηση 5Μέτρια
Η συνάρτηση κατανομής της $X$ είναι $F(x) = 0$ για $x \lt 0$, $F(x) = x^2$ για $0 \le x \le 1$ και $F(x) = 1$ για $x > 1$. Να υπολογίσετε την $P(0{,}5 \lt X \le 0{,}8)$ και τη διάμεσο $m$ (4 δεκαδικά).
Υπόδειξη: $P(a \lt X \le b) = F(b) - F(a)$, και $F(m) = \frac12$.
Λύση: $P = 0{,}64 - 0{,}25 = 0{,}39$. $m^2 = \frac12 \Rightarrow m = \frac{1}{\sqrt2} \approx 0{,}7071$. (Η πυκνότητα είναι $f(x) = F'(x) = 2x$ στο $[0, 1]$.)
Άσκηση 6Βασική
Για μια συνεχή τυχαία μεταβλητή $X$ ισχύει $P(X \le a) = P(X \lt a)$ για κάθε $a$.
Υπόδειξη: Πόσο είναι το $P(X = a)$;
Λύση: Σωστό: για συνεχή $X$ είναι $P(X = a) = 0$, άρα η ισότητα στο άκρο δεν αλλάζει την πιθανότητα.
Άσκηση 7Μέτρια
Μια συνάρτηση πυκνότητας δεν μπορεί να πάρει τιμή μεγαλύτερη του $1$.
Υπόδειξη: Ομοιόμορφη σε μικρό διάστημα.
Λύση: Λάθος: η $f(x) = 4$ για $0 \le x \le \frac14$ είναι πυκνότητα (εμβαδόν $1$) και παίρνει την τιμή $4$.
Άσκηση 8Βασική
Στην R ορίζουμε f <- function(x) 3 * x^2. Ποιες τιμές (4 δεκαδικά) δίνουν οι integrate(f, 0, 0.5)$value και integrate(function(x) x * f(x), 0, 1)$value;
Υπόδειξη: $P(X \le 0{,}5)$ και $E(X)$ για $f(x) = 3x^2$ στο $[0, 1]$.
Λύση: $\int_0^{0{,}5} 3x^2dx = 0{,}5^3 = 0{,}125$ και $\int_0^1 3x^3dx = \frac34 = 0{,}75$.
Άσκηση 9Απαιτητική
Η $X$ έχει πυκνότητα $f(x) = \frac34(1 - x^2)$ για $-1 \le x \le 1$. Να υπολογίσετε τη διασπορά $\mathrm{Var}(X)$ και την $P\!\left(X > \frac12\right)$.
Υπόδειξη: Η $f$ είναι άρτια: $E(X) = 0$.
Λύση: $E(X) = 0$, $E(X^2) = \frac34\left(\frac23 - \frac25\right) = \frac15$. $P(X > \frac12) = \frac34\left[x - \frac{x^3}{3}\right]_{1/2}^{1} = \frac34\cdot\frac{5}{24} = \frac{5}{32}$.

♾️ Γεννήτρια — συνεχής τυχαία μεταβλητή f(x) = cxⁿ

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Η $X$ έχει πυκνότητα $f(x) = \frac{3}{8}\,x^2$, $0 \le x \le 2$. Να υπολογίσετε την $P(X \le 1)$.
Υπόδειξη: $F(x) = \left(\frac{x}{2}\right)^{3}$ για $0 \le x \le 2$.
Λύση: $P(X \le 1) = \int_0^{1} \frac{3}{8}\,x^2\,dx = \frac{1^{3}}{2^{3}} = \frac{1}{8}$.
