3.1

Τυχαίες μεταβλητές – Διακριτές – Μέση τιμή και διασπορά

📘 Σημειώσεις ΜΑΣ055 (Χριστοφίδης): Τυχαίες μεταβλητές (συνάρτηση κατανομής, μάζας πιθανότητας, αναμενόμενη τιμή, διασπορά) · Φυλλάδιο ασκήσεων 5

Θεωρία

Τυχαία μεταβλητή – συνάρτηση κατανομής

Τυχαία μεταβλητή είναι μια συνάρτηση $X: \Omega \to \mathbb R$ (π.χ. το άθροισμα δύο ζαριών). Η συνάρτηση κατανομής $F_X(x) = P(X \le x)$ είναι μη φθίνουσα, δεξιά συνεχής, με $\lim_{x\to\infty}F(x) = 1$ και $\lim_{x\to-\infty}F(x) = 0$.

Διακριτή τ.μ. – συνάρτηση μάζας πιθανότητας

Η $X$ είναι διακριτή αν παίρνει πεπερασμένο ή αριθμήσιμο σύνολο τιμών $\{x_1, x_2, \dots\}$. Συνάρτηση μάζας πιθανότητας: $p_X(x_k) = P(X = x_k)$, με $p(x) \ge 0$, $\sum_x p(x) = 1$ και $F(x) = \sum_{x_k \le x} p(x_k)$.

Αναμενόμενη τιμή και διασπορά

$E(X) = \sum_x x\,P(X = x)$ (αν η σειρά συγκλίνει απόλυτα), $\ E[g(X)] = \sum_x g(x)P(X = x)$.

$\mathrm{Var}(X) = E\big[(X - E(X))^2\big] = E(X^2) - (E(X))^2$· τυπική απόκλιση $\sqrt{\mathrm{Var}(X)}$.

Γραμμικότητα: $E(aX + bY) = aE(X) + bE(Y)$ (πάντα) και $\mathrm{Var}(aX + b) = a^2\mathrm{Var}(X)$.

Παγίδες

Γενικά $E(X^2) \ne (E(X))^2$ και $E[g(X)] \ne g(E(X))$. Η μετατόπιση δεν αλλάζει τη διασπορά: $\mathrm{Var}(X + 3) = \mathrm{Var}(X)$.

Στην R

x <- 1:4; p <- x / 10 · sum(x * p) → 3 ($E(X)$) · sum(x^2 * p) - sum(x * p)^2 → 1 ($\mathrm{Var}(X)$) · cumsum(p) → 0.1 0.3 0.6 1.0 (τιμές της $F$).

Πειραματίσου

Πάνω: συνάρτηση μάζας πιθανότητας. Κάτω: η κλιμακωτή συνάρτηση κατανομής — κάθε «σκαλί» έχει ύψος p(x)p(x)p(x).

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Η διακριτή τ.μ. $X$ έχει συνάρτηση μάζας πιθανότητας $p(x) = c\,x$ για $x = 1, 2, 3, 4$ (και $0$ αλλού). Να βρείτε τη σταθερά $c$ και την τιμή $F(2{,}5) = P(X \le 2{,}5)$.
Υπόδειξη: $\sum p(x) = 1$.
Λύση: $c(1 + 2 + 3 + 4) = 10c = 1 \Rightarrow c = \frac{1}{10}$. $F(2{,}5) = p(1) + p(2) = \frac{3}{10}$.
Άσκηση 2Βασική
Η τ.μ. $X$ έχει $p(x) = x/10$ για $x = 1, 2, 3, 4$. Να βρείτε τα $E(X)$, $E(X^2)$ και $\mathrm{Var}(X)$.
Υπόδειξη: $E(X) = \sum x^2/10$, $E(X^2) = \sum x^3/10$.
Λύση: $E(X) = \frac{1 + 4 + 9 + 16}{10} = 3$, $E(X^2) = \frac{1 + 8 + 27 + 64}{10} = 10$, $\mathrm{Var}(X) = 10 - 9 = 1$.
Άσκηση 3Μέτρια
Ο υπολογιστής $A$ στέλνει πακέτα στον $\Gamma$ μέσω του $B$. Η αποστολή $A \to B$ διαρκεί $3$ ms με πιθανότητα $0{,}6$ και $6$ ms με $0{,}4$· η $B \to \Gamma$ διαρκεί $5$ ms με πιθανότητα $0{,}8$ και $9$ ms με $0{,}2$, ανεξάρτητα. Ποια είναι η μέση τιμή του συνολικού χρόνου $X$, και ποια η $P(X \le 11)$;
Υπόδειξη: Γραμμικότητα της μέσης τιμής· για την πιθανότητα, απαριθμήστε τους $4$ συνδυασμούς.
Λύση: $E(X) = (0{,}6\cdot 3 + 0{,}4\cdot 6) + (0{,}8\cdot 5 + 0{,}2\cdot 9) = 4{,}2 + 5{,}8 = 10$ ms. Τιμές: $8$ $(0{,}48)$, $12$ $(0{,}12)$, $11$ $(0{,}32)$, $15$ $(0{,}08)$. $P(X \le 11) = 0{,}48 + 0{,}32 = 0{,}8$.
Άσκηση 4Μέτρια
Ένας αριθμός επιλέγεται τυχαία (ομοιόμορφα) από το σύνολο $\{1, 2, \dots, 10\}$. Να βρείτε τη μέση τιμή και τη διασπορά του.
Υπόδειξη: $E(X) = \frac{n+1}{2}$, $E(X^2) = \frac{(n+1)(2n+1)}{6}$.
Λύση: $E(X) = 5{,}5$. $E(X^2) = \frac{11\cdot 21}{6} = 38{,}5$, άρα $\mathrm{Var}(X) = 38{,}5 - 30{,}25 = 8{,}25 = \frac{n^2 - 1}{12}$.
Άσκηση 5Μέτρια
Σε ένα λαχείο κυκλοφορούν $40000$ λαχνοί. Ένας κερδίζει $50000$ €, ένας $20000$ €, ένας $5000$ € και τέσσερις από $500$ €. Κάποιος αγοράζει έναν λαχνό προς $3$ €. Ποιο είναι το αναμενόμενο καθαρό κέρδος του;
Υπόδειξη: $E(\text{έπαθλο}) = \frac{\text{σύνολο επάθλων}}{40000}$.
Λύση: Σύνολο επάθλων $50000 + 20000 + 5000 + 4\cdot 500 = 77000$ €. $E(\text{έπαθλο}) = 77000/40000 = 1{,}925$ €, άρα $E(\text{κέρδος}) = 1{,}925 - 3 = -1{,}075$ €.
Άσκηση 6Βασική
Η $X$ παίρνει τις τιμές $0, 1, 2$ με πιθανότητες $0{,}25$, $0{,}5$, $0{,}25$. Αν $Y = 3X - 2$, να βρείτε τα $E(Y)$ και $\mathrm{Var}(Y)$.
Υπόδειξη: Πρώτα $E(X)$ και $\mathrm{Var}(X)$.
Λύση: $E(X) = 1$, $E(X^2) = 1{,}5$, $\mathrm{Var}(X) = 0{,}5$. Άρα $E(Y) = 1$ και $\mathrm{Var}(Y) = 9\cdot 0{,}5 = 4{,}5$.
Άσκηση 7Βασική
Ποια από τις παρακάτω είναι έγκυρη συνάρτηση μάζας πιθανότητας για τις τιμές $x = 1, 2, 3$;
Υπόδειξη: Μη αρνητικές τιμές με άθροισμα $1$.
Λύση: Μόνο η $0{,}2 + 0{,}5 + 0{,}3 = 1$ με όλες τις τιμές μη αρνητικές. Οι άλλες έχουν άθροισμα $1{,}5$ ή $0{,}6$, ή αρνητική τιμή.
Άσκηση 8Βασική
Για κάθε τ.μ. $X$ ισχύει $\mathrm{Var}(X + 3) = \mathrm{Var}(X) + 3$.
Υπόδειξη: $\mathrm{Var}(aX + b) = a^2\mathrm{Var}(X)$.
Λύση: Λάθος: $\mathrm{Var}(X + 3) = \mathrm{Var}(X)$· η μετατόπιση δεν αλλάζει τη διασπορά.
Άσκηση 9Βασική
Στην R δίνουμε x <- c(0, 1, 2, 3); p <- c(0.1, 0.3, 0.4, 0.2). Τι επιστρέφουν οι sum(x * p) και sum(x^2 * p) - sum(x * p)^2;
Υπόδειξη: Μέση τιμή και διασπορά.
Λύση: $E(X) = 0 + 0{,}3 + 0{,}8 + 0{,}6 = 1{,}7$. $E(X^2) = 0{,}3 + 1{,}6 + 1{,}8 = 3{,}7$, άρα $\mathrm{Var}(X) = 3{,}7 - 2{,}89 = 0{,}81$.

♾️ Γεννήτρια — μέση τιμή και διασπορά διακριτής τ.μ.

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Η τ.μ. $X$ έχει συνάρτηση μάζας πιθανότητας $\ \begin{array}{c|ccc} x & 1 & 2 & 4 \\ \hline p(x) & \frac{1}{2} & \frac{3}{10} & \frac{1}{5} \end{array}$. Αν $Y = 3X - 4$, να βρείτε τα $E(Y)$ και $\mathrm{Var}(Y)$ (ως κλάσματα).
Υπόδειξη: $E(aX + b) = aE(X) + b$, $\mathrm{Var}(aX + b) = a^2\mathrm{Var}(X)$.
Λύση: $E(X) = \frac{19}{10}$, $\mathrm{Var}(X) = \frac{129}{100}$. Άρα $E(Y) = 3\cdot \frac{19}{10} - 4 = \frac{17}{10}$ και $\mathrm{Var}(Y) = 9\cdot \frac{129}{100} = \frac{1161}{100}$.
