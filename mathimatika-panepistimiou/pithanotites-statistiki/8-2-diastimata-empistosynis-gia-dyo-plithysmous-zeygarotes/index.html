8.2

Διαστήματα εμπιστοσύνης για δύο πληθυσμούς – Ζευγαρωτές παρατηρήσεις

📘 Σημειώσεις ΜΑΣ055 (Χριστοφίδης): Διαστήματα εμπιστοσύνης για δύο πληθυσμούς, μικρά δείγματα

Θεωρία

Μεγάλα δείγματα

Από ανεξάρτητα τυχαία δείγματα μεγέθους $n_1$, $n_2$ (μεγάλα), διάστημα εμπιστοσύνης $1 - \alpha$:

  • για τη διαφορά μέσων $\mu_1 - \mu_2$: $\ \bar X - \bar Y \pm z_{\alpha/2}\sqrt{\frac{S_1^2}{n_1} + \frac{S_2^2}{n_2}}$ (με $\sigma_1^2, \sigma_2^2$ στη θέση των $S_1^2, S_2^2$ αν είναι γνωστές)·
  • για τη διαφορά ποσοστών $p_1 - p_2$: $\ \hat p_1 - \hat p_2 \pm z_{\alpha/2}\sqrt{\frac{\hat p_1(1 - \hat p_1)}{n_1} + \frac{\hat p_2(1 - \hat p_2)}{n_2}}$.

Μικρά δείγματα από κανονικούς πληθυσμούς

Αν τα δείγματα είναι ανεξάρτητα, οι πληθυσμοί κανονικοί και με ίσες (άγνωστες) διασπορές, χρησιμοποιούμε τη συγκεντρωτική τυπική απόκλιση $$S = \sqrt{\frac{(n_1 - 1)S_1^2 + (n_2 - 1)S_2^2}{n_1 + n_2 - 2}}, \qquad \bar X - \bar Y \pm t_{n_1 + n_2 - 2}(\alpha/2)\, S\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}.$$

Ζευγαρωτές παρατηρήσεις

Όταν και οι δύο μετρήσεις γίνονται στα ίδια άτομα/αντικείμενα (π.χ. πριν και μετά από ένα φάρμακο), δουλεύουμε με τις διαφορές $D_k = X_k - Y_k$: $\ \bar D \pm t_{n-1}(\alpha/2)\frac{S_D}{\sqrt n}$ (κανονικές διαφορές) ή $\bar D \pm z_{\alpha/2}\frac{S_D}{\sqrt n}$ για μεγάλο $n$.

Ερμηνεία: αν το διάστημα για τη διαφορά περιέχει το $0$, τα δεδομένα δεν δείχνουν σημαντική διαφορά στο αντίστοιχο επίπεδο.

Στην R

t.test(x, y, var.equal = TRUE)$conf.int (συγκεντρωτική διασπορά) · t.test(x, y, paired = TRUE)$conf.int (ζευγαρωτές) · qt(0.975, df = 20) → 2.085963 · prop.test(c(120, 125), c(200, 250), correct = FALSE)$conf.int. Προσοχή: χωρίς var.equal = TRUE η t.test(x, y) κάνει τη μέθοδο Welch (μη συγκεντρωτική διασπορά, β.ε. κατά Welch–Satterthwaite), όχι τη μέθοδο των σημειώσεων.

Πειραματίσου

t5(0,025) = 2,571 έναντι z0,025 = 1,96 (μπλε: κατανομή t με ν = 5· μωβ: N(0, 1)).
Η κατανομή t είναι συμμετρική όπως η κανονική αλλά με «βαρύτερες ουρές», άρα για μικρά δείγματα τα διαστήματα είναι φαρδύτερα. Όσο αυξάνει το ν, η t πλησιάζει την N(0, 1). Στην R: qt(0.975, df = 5).

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Δύο ανεξάρτητα δείγματα έδωσαν $n_1 = 100$, $\bar x_1 = 52$, $s_1 = 8$ και $n_2 = 150$, $\bar x_2 = 48$, $s_2 = 10$. Να κατασκευάσετε διάστημα εμπιστοσύνης $95\%$ για τη διαφορά $\mu_1 - \mu_2$ ($z_{0{,}025} = 1{,}96$, 3 δεκαδικά).
Υπόδειξη: $\sqrt{\frac{64}{100} + \frac{100}{150}}$.
Λύση: $\sqrt{0{,}64 + 0{,}6667} \approx 1{,}1431$, περιθώριο $1{,}96\cdot 1{,}1431 \approx 2{,}240$: $4 \pm 2{,}240 = (1{,}760;\ 6{,}240)$. Δεν περιέχει το $0$: η διαφορά είναι σημαντική σε επίπεδο $5\%$.
Άσκηση 2Μέτρια
Σε δημοσκόπηση, $120$ από $200$ άνδρες και $125$ από $250$ γυναίκες υποστηρίζουν μια πρόταση. Να κατασκευάσετε διάστημα εμπιστοσύνης $95\%$ για τη διαφορά $p_1 - p_2$ ($z_{0{,}025} = 1{,}96$, 4 δεκαδικά).
Υπόδειξη: $\hat p_1 = 0{,}6$, $\hat p_2 = 0{,}5$.
Λύση: $\sqrt{\frac{0{,}6\cdot 0{,}4}{200} + \frac{0{,}5\cdot 0{,}5}{250}} = \sqrt{0{,}0022} \approx 0{,}0469$, περιθώριο $\approx 0{,}0919$: $0{,}1 \pm 0{,}0919 = (0{,}0081;\ 0{,}1919)$.
Άσκηση 3Μέτρια
Δύο ανεξάρτητα δείγματα από κανονικούς πληθυσμούς με ίσες διασπορές έδωσαν $n_1 = 10$, $\bar x_1 = 25$, $s_1 = 4$ και $n_2 = 12$, $\bar x_2 = 21$, $s_2 = 5$. Να βρείτε τη συγκεντρωτική διασπορά $S^2$ και διάστημα εμπιστοσύνης $95\%$ για τη $\mu_1 - \mu_2$ (δίνεται $t_{20}(0{,}025) = 2{,}086$, 3 δεκαδικά).
Υπόδειξη: $S^2 = \frac{9\cdot 16 + 11\cdot 25}{20}$.
Λύση: $S^2 = \frac{144 + 275}{20} = 20{,}95$, $S \approx 4{,}5771$. $S\sqrt{\frac{1}{10} + \frac{1}{12}} \approx 1{,}9598$, περιθώριο $2{,}086\cdot 1{,}9598 \approx 4{,}088$: $4 \pm 4{,}088 = (-0{,}088;\ 8{,}088)$. Περιέχει το $0$: δεν φαίνεται σημαντική διαφορά σε επίπεδο $5\%$.
Άσκηση 4Μέτρια
Για $8$ ασθενείς μετρήθηκε μια ποσότητα πριν και μετά από θεραπεία· οι διαφορές (πριν − μετά) είναι $5, 3, 8, -1, 6, 4, 2, 5$. Υποθέτοντας κανονικότητα, να βρείτε τον μέσο $\bar d$ των διαφορών και διάστημα εμπιστοσύνης $95\%$ για τη μέση διαφορά (δίνεται $t_7(0{,}025) = 2{,}365$, 3 δεκαδικά).
Υπόδειξη: $s_D^2 = \frac{1}{7}\sum (d_k - \bar d)^2$.
Λύση: $\bar d = 32/8 = 4$, $\sum (d_k - 4)^2 = 1 + 1 + 16 + 25 + 4 + 0 + 4 + 1 = 52$, $s_D = \sqrt{52/7} \approx 2{,}7255$. Περιθώριο $2{,}365\cdot\frac{2{,}7255}{\sqrt 8} \approx 2{,}279$: $(1{,}721;\ 6{,}279)$.
Άσκηση 5Βασική
Ένα διάστημα εμπιστοσύνης $95\%$ για τη διαφορά $\mu_1 - \mu_2$ βρέθηκε $(-1{,}2;\ 3{,}4)$. Τι συμπεραίνουμε;
Υπόδειξη: Περιέχει το διάστημα το $0$;
Λύση: Το $0$ ανήκει στο διάστημα, άρα η τιμή $\mu_1 - \mu_2 = 0$ είναι συμβατή με τα δεδομένα: δεν υπάρχει σημαντική διαφορά. Αυτό όμως δεν αποδεικνύει ότι οι μέσοι είναι ίσοι.
Άσκηση 6Βασική
Σε ποια περίπτωση χρησιμοποιούμε διάστημα εμπιστοσύνης για ζευγαρωτές παρατηρήσεις;
Υπόδειξη: Οι δύο μετρήσεις κάθε μονάδας είναι εξαρτημένες.
Λύση: Στις ζευγαρωτές παρατηρήσεις κάθε μονάδα δίνει δύο μετρήσεις (π.χ. πριν και μετά), οπότε δουλεύουμε με τις διαφορές $D_k$. Για ανεξάρτητες ομάδες χρησιμοποιούμε τα διαστήματα δύο ανεξάρτητων δειγμάτων.
Άσκηση 7Βασική
Το διάστημα με τη συγκεντρωτική τυπική απόκλιση $S$ και την κατανομή $t_{n_1 + n_2 - 2}$ προϋποθέτει κανονικούς πληθυσμούς με ίσες διασπορές και ανεξάρτητα δείγματα.
Υπόδειξη: Δείτε τις προϋποθέσεις στη θεωρία.
Λύση: Σωστό: για μικρά δείγματα το διάστημα ισχύει μόνο κάτω από αυτές τις υποθέσεις.
Άσκηση 8Απαιτητική
Δύο κανονικοί πληθυσμοί έχουν γνωστές τυπικές αποκλίσεις $\sigma_1 = 6$ και $\sigma_2 = 8$. Ανεξάρτητα δείγματα μεγέθους $n_1 = 36$ και $n_2 = 64$ έδωσαν $\bar x_1 = 70$ και $\bar x_2 = 65$. Να κατασκευάσετε διάστημα εμπιστοσύνης $99\%$ για τη $\mu_1 - \mu_2$ ($z_{0{,}005} = 2{,}576$, 3 δεκαδικά).
Υπόδειξη: $\sqrt{\frac{36}{36} + \frac{64}{64}} = \sqrt 2$.
Λύση: Τυπικό σφάλμα $\sqrt 2 \approx 1{,}4142$, περιθώριο $2{,}576\cdot 1{,}4142 \approx 3{,}643$: $5 \pm 3{,}643 = (1{,}357;\ 8{,}643)$.
Άσκηση 9Βασική
Ποια εντολή της R δίνει διάστημα εμπιστοσύνης για τη μέση διαφορά σε ζευγαρωτές παρατηρήσεις x, y;
Υπόδειξη: Το όρισμα που δηλώνει ζεύγη.
Λύση: Το paired = TRUE κάνει την ανάλυση στις διαφορές x - y. Το var.equal = TRUE αφορά δύο ανεξάρτητα δείγματα με συγκεντρωτική διασπορά, η prop.test ποσοστά και η cor.test συσχέτιση.

Εξάσκηση #1
Σε δύο ανεξάρτητα δείγματα, $50$ από $100$ και $28$ από $100$ άτομα αντίστοιχα έχουν ένα χαρακτηριστικό. Να κατασκευάσετε διάστημα εμπιστοσύνης $95\%$ για τη διαφορά $p_1 - p_2$ ($z_{0{,}025} = 1{,}96$, 4 δεκαδικά).
Υπόδειξη: $\hat p_1 - \hat p_2 \pm z_{\alpha/2}\sqrt{\frac{\hat p_1(1 - \hat p_1)}{n_1} + \frac{\hat p_2(1 - \hat p_2)}{n_2}}$.
Λύση: $\hat p_1 = 0{,}5$, $\hat p_2 = 0{,}28$, τυπικό σφάλμα $0{,}0672$, περιθώριο $0{,}1317$: $(0{,}0883;\ 0{,}3517)$.
