4.2

Το πρόβλημα των κουπονιών

📘 Σημειώσεις ΜΑΣ055 (Χριστοφίδης): Κλασικά προβλήματα πιθανοτήτων · Βλ. και Ross, Κεφ. 7

Θεωρία

Το πρόβλημα

Σε κάθε κουτί ενός προϊόντος υπάρχει ένα από $n$ διαφορετικά κουπόνια, καθένα με πιθανότητα $\frac1n$, ανεξάρτητα. Ποιος είναι ο αναμενόμενος αριθμός $X$ κουτιών που πρέπει να αγοράσουμε για να συμπληρώσουμε τη σειρά;

Λύση με άθροισμα γεωμετρικών

Έστω ότι έχουμε ήδη $k - 1$ διαφορετικά κουπόνια και $X_k$ ο αριθμός κουτιών μέχρι να βρούμε ένα νέο. Κάθε κουτί δίνει νέο κουπόνι με πιθανότητα $p_k = 1 - \frac{k-1}{n} = \frac{n-k+1}{n}$, άρα η $X_k$ ακολουθεί γεωμετρική κατανομή με παράμετρο $p_k$ και $$E(X_k) = \frac{1}{p_k} = \frac{n}{n-k+1}.$$ Αφού $X = X_1 + X_2 + \dots + X_n$, $$E(X) = \sum_{k=1}^n \frac{n}{n-k+1} = n\sum_{k=1}^n\frac1k = n\left(1 + \frac12 + \dots + \frac1n\right).$$

Ασυμπτωτική συμπεριφορά

Για μεγάλο $n$: $\sum_{k=1}^n\frac1k \approx \ln n + \frac{1}{2n} + C$, όπου $C \approx 0{,}57722$ η σταθερά του Euler, άρα $$E(X) \approx n\ln n + nC + \frac12.$$ Π.χ. για $n = 20$ χρειάζονται κατά μέσο όρο περίπου $72$ κουτιά. Τα τελευταία κουπόνια είναι τα «ακριβά»: για το τελευταίο $E(X_n) = n$.

(Εμπλουτισμός) Επειδή οι $X_k$ είναι ανεξάρτητες, $\text{Var}(X) = \sum_k \frac{1 - p_k}{p_k^2}$.

Στην R

n <- 50; n * sum(1/(1:n)) → 224.9603.

Προσομοίωση μίας συλλογής: s <- 0; got <- c(); while (length(unique(got)) < n) { got <- c(got, sample(1:n, 1)); s <- s + 1 } και επανάληψη με replicate() για τον μέσο όρο.

Πειραματίσου

Αυτή η συλλογή χρειάστηκε 44 κουτιά · μέσος όρος σε 400 προσομοιώσεις: 29,2
E(X) = n(1 + 1/2 + ⋯ + 1/n) = 29,29 ≈ n·ln n + nC + 1/2 = 29,3
Τα τελευταία κουπόνια είναι τα «ακριβά»: με k − 1 ήδη, το επόμενο νέο χρειάζεται κατά μέσο όρο n/(n − k + 1) κουτιά (γεωμετρική).

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Υπάρχουν $4$ διαφορετικά κουπόνια, ισοπίθανα σε κάθε κουτί. Πόσα κουτιά αναμένεται να αγοράσουμε για να συμπληρώσουμε τη σειρά;
Υπόδειξη: $4\left(1 + \frac12 + \frac13 + \frac14\right)$.
Λύση: $E(X) = 4\cdot\frac{25}{12} = \frac{25}{3} \approx 8{,}33$.
Άσκηση 2Βασική
Συλλέγουμε $5$ διαφορετικά κουπόνια και έχουμε ήδη $3$ διαφορετικά. Πόσα κουτιά αναμένεται να αγοράσουμε μέχρι να βρούμε ένα νέο κουπόνι;
Υπόδειξη: Γεωμετρική με $p = \frac25$.
Λύση: Κάθε κουτί δίνει νέο κουπόνι με πιθανότητα $p = \frac{5 - 3}{5} = \frac25$, άρα $E = \frac1p = \frac52$.
Άσκηση 3Μέτρια
Ρίχνουμε ένα αμερόληπτο ζάρι μέχρι να εμφανιστούν όλες οι ενδείξεις $1, \dots, 6$ τουλάχιστον μία φορά. Πόσες ρίψεις αναμένονται;
Υπόδειξη: Πρόβλημα κουπονιών με $n = 6$.
Λύση: $E(X) = 6\left(1 + \frac12 + \frac13 + \frac14 + \frac15 + \frac16\right) = 6\cdot\frac{49}{20} = 14{,}7$.
Άσκηση 4Μέτρια
Για $n = 20$ κουπόνια, να υπολογίσετε προσεγγιστικά το $E(X)$ με τον τύπο $n\ln n + nC + \frac12$, όπου $C = 0{,}57722$ (με 2 δεκαδικά).
Υπόδειξη: $\ln 20 \approx 2{,}9957$.
Λύση: $20\cdot 2{,}9957 + 20\cdot 0{,}57722 + 0{,}5 \approx 59{,}91 + 11{,}54 + 0{,}5 = 71{,}96$ (ακριβής τιμή $20H_{20} \approx 71{,}95$).
Άσκηση 5Μέτρια
Αν έχουμε ήδη $k - 1$ από τα $n$ διαφορετικά κουπόνια, ο αριθμός $X_k$ κουτιών μέχρι να βρούμε ένα νέο ακολουθεί:
Υπόδειξη: Ανεξάρτητες δοκιμές μέχρι την πρώτη επιτυχία.
Λύση: Κάθε κουτί είναι μια ανεξάρτητη δοκιμή με πιθανότητα «επιτυχίας» (νέο κουπόνι) $\frac{n-k+1}{n}$, και μετράμε δοκιμές μέχρι την πρώτη επιτυχία: γεωμετρική.
Άσκηση 6Μέτρια
Υπάρχουν $5$ διαφορετικά κουπόνια και έχουμε ήδη τα $4$. Αν $X_5$ είναι ο αριθμός κουτιών μέχρι το τελευταίο κουπόνι, να βρείτε τα $E(X_5)$ και $\text{Var}(X_5)$.
Υπόδειξη: Γεωμετρική με $p = \frac15$: $E = \frac1p$, $\text{Var} = \frac{1-p}{p^2}$.
Λύση: $E(X_5) = 5$ και $\text{Var}(X_5) = \frac{4/5}{1/25} = 20$: μεγάλη μεταβλητότητα — η συμπλήρωση της σειράς μπορεί να αργήσει πολύ.
Άσκηση 7Απαιτητική
Υπάρχουν $3$ διαφορετικά κουπόνια, ισοπίθανα σε κάθε κουτί. Ποια η πιθανότητα, αγοράζοντας ακριβώς $3$ κουτιά, να έχουμε συμπληρώσει τη σειρά;
Υπόδειξη: Ευνοϊκά: όλες οι μεταθέσεις των τριών κουπονιών.
Λύση: $P = \frac{3!}{3^3} = \frac{6}{27} = \frac29$.
Άσκηση 8Απαιτητική
Υπάρχουν $3$ διαφορετικά κουπόνια, ισοπίθανα σε κάθε κουτί. Ποια η πιθανότητα να χρειαστούμε περισσότερα από $4$ κουτιά για να συμπληρώσουμε τη σειρά;
Υπόδειξη: $P(X > 4) = 1 - P(\text{όλα τα κουπόνια στα πρώτα } 4 \text{ κουτιά})$· εγκλεισμός–αποκλεισμός.
Λύση: Ευνοϊκές τετράδες με όλα τα κουπόνια: $3^4 - 3\cdot 2^4 + 3 = 81 - 48 + 3 = 36$, άρα $P(X \le 4) = \frac{36}{81} = \frac49$ και $P(X > 4) = \frac59$.
Άσκηση 9Βασική
Ο αναμενόμενος αριθμός κουτιών για $n$ κουπόνια αυξάνει περίπου όπως $n\ln n$.
Υπόδειξη: $\sum_{k\le n}\frac1k \approx \ln n$.
Λύση: Σωστό: $E(X) = n\sum_{k=1}^n \frac1k \approx n\ln n + 0{,}577n + \frac12$.
Άσκηση 10Μέτρια
Τι επιστρέφει η εντολή της R n <- 10; n * sum(1/(1:n)) (με 2 δεκαδικά);
Υπόδειξη: $10\left(1 + \frac12 + \dots + \frac1{10}\right)$.
Λύση: $10H_{10} = 10\cdot 2{,}928968 \approx 29{,}29$: ο αναμενόμενος αριθμός κουτιών για $10$ κουπόνια.

♾️ Γεννήτρια — το πρόβλημα των κουπονιών

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Συλλέγουμε $7$ διαφορετικά κουπόνια και έχουμε ήδη $6$ διαφορετικά. Πόσα κουτιά αναμένεται να αγοράσουμε μέχρι να βρούμε ένα νέο κουπόνι;
Υπόδειξη: Γεωμετρική με πιθανότητα επιτυχίας $p = \frac{7 - 6}{7}$.
Λύση: Κάθε κουτί δίνει νέο κουπόνι με πιθανότητα $p = \frac{1}{7}$, άρα $E = \frac1p = 7$.
