7.2

Κατανομή του δειγματικού μέσου – Σημειοεκτιμητική

📘 Σημειώσεις ΜΑΣ055 (Χριστοφίδης): Στατιστική – Κανονική κατανομή, ΚΟΘ, Εκτιμητική

Θεωρία

Ο δειγματικός μέσος

Αν $X_1, \dots, X_n$ τυχαίο δείγμα από κατανομή με μέσο $\mu$ και διασπορά $\sigma^2$, τότε $$E(\bar X) = \frac{1}{n}\sum_{k=1}^{n} E(X_k) = \mu, \qquad Var(\bar X) = \frac{1}{n^2}\sum_{k=1}^{n} Var(X_k) = \frac{\sigma^2}{n}.$$ Ο $\bar X$ έχει την ίδια μέση τιμή με τις παρατηρήσεις, αλλά μικρότερη διασπορά. Η ποσότητα $\sigma/\sqrt n$ λέγεται τυπικό σφάλμα (ΣΕ) του $\bar X$.

Κανονική κατανομή και ΚΟΘ

  • Αν $X \sim N(\mu, \sigma^2)$ τότε $Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$, και γενικά $aX + b \sim N(a\mu + b,\ a^2\sigma^2)$.
  • Ο πίνακας των σημειώσεων δίνει $P(0 < Z < z)$· λόγω συμμετρίας $P(Z > z) = 0{,}5 - P(0 < Z < z)$ για $z > 0$.
  • Αν ο πληθυσμός είναι κανονικός, $\bar X \sim N\!\left(\mu, \frac{\sigma^2}{n}\right)$ ακριβώς.
  • Κεντρικό Οριακό Θεώρημα: για μεγάλο $n$ (πρακτικά $n \ge 30$), $\frac{\bar X - \mu}{\sigma/\sqrt n} \approx N(0, 1)$, όποια κι αν είναι η κατανομή των παρατηρήσεων, αρκεί να έχει πεπερασμένη διασπορά $\sigma^2$.

Εκτιμήτριες – αμεροληψία

Μια εκτιμήτρια $\hat\theta$ μιας άγνωστης παραμέτρου $\theta$ είναι μια στατιστική συνάρτηση. Λέγεται αμερόληπτη αν $E(\hat\theta) = \theta$. Επιθυμούμε επίσης όσο το δυνατό μικρότερη διασπορά.

  • $\bar X$: αμερόληπτη εκτιμήτρια του $\mu$.
  • $S^2 = \frac{1}{n - 1}\sum (X_k - \bar X)^2$: αμερόληπτη εκτιμήτρια του $\sigma^2$. Η $\hat\sigma^2 = \frac{1}{n}\sum (X_k - \bar X)^2$ δεν είναι: $E(\hat\sigma^2) = \frac{n - 1}{n}\sigma^2$ (για μεγάλο $n$ οι δύο σχεδόν ταυτίζονται).
  • Δειγματικό ποσοστό $\hat p$: είναι ο δειγματικός μέσος των δεικτών $X_k \in \{0, 1\}$, άρα αμερόληπτη εκτιμήτρια του πληθυσμιακού ποσοστού $p$, με $Var(\hat p) = \frac{p(1 - p)}{n}$.

Στην R

pnorm(12, mean = 10, sd = 4) - pnorm(10, 10, 4) → 0.1914625 ($P(10 < X < 12)$ για $X \sim N(10, 16)$) · qnorm(0.975) → 1.959964.

Προσομοίωση της κατανομής του $\bar X$: m <- replicate(10000, mean(rnorm(25, 50, 10)))· τότε mean(m) ≈ 50 και sd(m) ≈ $10/\sqrt{25} = 2$.

Πειραματίσου

3000 δείγματα μεγέθους n = 5 από N(50, 10²). Μέσος όρος των X̄: 49,86 (θεωρητικά μ = 50)· μέσος όρος των S²: 99,2· μέσος όρος των σ̂²: 79,4.
Η S² (διαίρεση με n − 1) «πέφτει» κατά μέσο όρο πάνω στο σ² = 100: είναι αμερόληπτη. Η σ̂² (διαίρεση με n) υποεκτιμά συστηματικά, με μέση τιμή (n − 1)σ²/n· η μεροληψία χάνεται όσο μεγαλώνει το n.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Από πληθυσμό με μέση τιμή $\mu = 50$ και τυπική απόκλιση $\sigma = 12$ παίρνουμε τυχαίο δείγμα μεγέθους $n = 36$. Να βρείτε τη μέση τιμή, τη διασπορά και την τυπική απόκλιση του $\bar X$.
Υπόδειξη: $Var(\bar X) = \sigma^2/n$.
Λύση: $E(\bar X) = 50$, $Var(\bar X) = \frac{144}{36} = 4$ και τυπική απόκλιση $\frac{12}{6} = 2$.
Άσκηση 2Βασική
Έστω $X \sim N(10, 16)$. Να υπολογίσετε την $P(10 < X < 12)$. Δίνεται $P(0 < Z < 0{,}5) = 0{,}1915$.
Υπόδειξη: Τυποποίηση με $\sigma = 4$.
Λύση: $P(10 < X < 12) = P\!\left(\frac{10 - 10}{4} < Z < \frac{12 - 10}{4}\right) = P(0 < Z < 0{,}5) = 0{,}1915$.
Άσκηση 3Μέτρια
Έστω $X \sim N(10, 16)$. Να υπολογίσετε τις πιθανότητες $P(X \ge 16)$ και $P(7 < X < 14)$. Δίνονται $P(0 < Z < 1{,}5) = 0{,}4332$, $P(0 < Z < 0{,}75) = 0{,}2734$ και $P(0 < Z < 1) = 0{,}3413$.
Υπόδειξη: $\frac{16 - 10}{4} = 1{,}5$, $\frac{7 - 10}{4} = -0{,}75$, $\frac{14 - 10}{4} = 1$.
Λύση: $P(X \ge 16) = P(Z \ge 1{,}5) = 0{,}5 - 0{,}4332 = 0{,}0668$. $P(7 < X < 14) = P(-0{,}75 < Z < 1) = 0{,}2734 + 0{,}3413 = 0{,}6147$.
Άσκηση 4Μέτρια
Το βάρος των πακέτων μιας μηχανής ακολουθεί $N(500, 40^2)$ γραμμάρια. Παίρνουμε τυχαίο δείγμα $16$ πακέτων. Να βρείτε την $P(\bar X > 520)$. Δίνεται $\Phi(2) = 0{,}9772$.
Υπόδειξη: Κανονικός πληθυσμός: $\bar X \sim N(500, 40^2/16)$.
Λύση: $\sigma_{\bar X} = 40/4 = 10$, $z = \frac{520 - 500}{10} = 2$, άρα $P(\bar X > 520) = 1 - 0{,}9772 = 0{,}0228$.
Άσκηση 5Μέτρια
Έστω $X_1, \dots, X_n$ τυχαίο δείγμα με διασπορά $\sigma^2$ και $\hat\sigma^2 = \frac{1}{n}\sum_{k=1}^{n}(X_k - \bar X)^2$. Ποια είναι η $E(\hat\sigma^2)$;
Υπόδειξη: $\hat\sigma^2 = \frac{n - 1}{n}S^2$ και $E(S^2) = \sigma^2$.
Λύση: $E(\hat\sigma^2) = \frac{n - 1}{n}E(S^2) = \frac{n - 1}{n}\sigma^2$: η $\hat\sigma^2$ είναι μεροληπτική (υποεκτιμά). Το $\frac{\sigma^2}{n}$ είναι η διασπορά του $\bar X$.
Άσκηση 6Βασική
Η δειγματική διασπορά $S^2$ (με παρονομαστή $n - 1$) είναι αμερόληπτη εκτιμήτρια της πληθυσμιακής διασποράς $\sigma^2$.
Υπόδειξη: Ορισμός αμεροληψίας: $E(\hat\theta) = \theta$.
Λύση: Σωστό: $E(S^2) = \sigma^2$· γι' αυτό διαιρούμε με $n - 1$ και όχι με $n$.
Άσκηση 7Μέτρια
Σε τυχαίο δείγμα $400$ χρηστών, οι $92$ χρησιμοποιούν το διαδίκτυο για τις τραπεζικές τους συναλλαγές. Να βρείτε την εκτίμηση $\hat p$ του πληθυσμιακού ποσοστού και την εκτίμηση του τυπικού του σφάλματος $\sqrt{\hat p(1 - \hat p)/n}$ (4 δεκαδικά).
Υπόδειξη: $\hat p = 92/400$.
Λύση: $\hat p = 0{,}23$ και $\sqrt{\frac{0{,}23\cdot 0{,}77}{400}} = \sqrt{0{,}00044275} \approx 0{,}0210$.
Άσκηση 8Απαιτητική
Έστω $X_1, X_2$ ανεξάρτητες με μέση τιμή $\mu$ και διασπορά $\sigma^2$. Θεωρούμε τις εκτιμήτριες $\hat\mu_1 = \frac{X_1 + X_2}{2}$ και $\hat\mu_2 = \frac{X_1 + 2X_2}{3}$ του $\mu$. Και οι δύο είναι αμερόληπτες· να βρείτε τους λόγους $Var(\hat\mu_1)/\sigma^2$ και $Var(\hat\mu_2)/\sigma^2$.
Υπόδειξη: $Var(aX_1 + bX_2) = (a^2 + b^2)\sigma^2$ για ανεξάρτητες.
Λύση: $E(\hat\mu_2) = \frac{\mu + 2\mu}{3} = \mu$. $Var(\hat\mu_1) = \frac{1}{4}\cdot 2\sigma^2 = \frac{\sigma^2}{2}$ και $Var(\hat\mu_2) = \frac{1 + 4}{9}\sigma^2 = \frac{5}{9}\sigma^2$. Αφού $\frac12 < \frac59$, προτιμάμε την $\hat\mu_1$ (μικρότερη διασπορά).
Άσκηση 9Μέτρια
Ο πληθυσμός έχει $\sigma = 4$. Πόσο μεγάλο πρέπει να είναι τουλάχιστον το δείγμα ώστε η τυπική απόκλιση του $\bar X$ να μην ξεπερνά το $0{,}5$;
Υπόδειξη: $\frac{4}{\sqrt n} \le 0{,}5$.
Λύση: $\sqrt n \ge 8 \iff n \ge 64$.
Άσκηση 10Βασική
Τι επιστρέφει στην R η εντολή pnorm(52, mean = 50, sd = 2) (4 δεκαδικά); Δίνεται $\Phi(1) = 0{,}8413$.
Υπόδειξη: Η pnorm δίνει τη συνάρτηση κατανομής $P(X \le x)$.
Λύση: $P(X \le 52) = \Phi\!\left(\frac{52 - 50}{2}\right) = \Phi(1) \approx 0{,}8413$.

Εξάσκηση #1
Από πληθυσμό με μέση τιμή $\mu = 40$ και τυπική απόκλιση $\sigma = 12$ παίρνουμε τυχαίο δείγμα μεγέθους $n = 36$. Να βρείτε τη μέση τιμή, τη διασπορά και την τυπική απόκλιση του δειγματικού μέσου $\bar X$.
Υπόδειξη: $E(\bar X) = \mu$, $Var(\bar X) = \frac{\sigma^2}{n}$.
Λύση: $E(\bar X) = 40$, $Var(\bar X) = \frac{144}{36} = 4$ και $\frac{\sigma}{\sqrt n} = \frac{12}{6} = 2$.
