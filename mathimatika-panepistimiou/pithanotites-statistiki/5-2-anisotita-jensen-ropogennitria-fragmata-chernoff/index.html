5.2

Ανισότητα Jensen – Ροπογεννήτρια – Φράγματα Chernoff

📘 Σημειώσεις ΜΑΣ055 (Χριστοφίδης): Ανισότητες

Θεωρία

Κυρτές συναρτήσεις και ανισότητα Jensen

Η $f: \mathbb R \to \mathbb R$ λέγεται κυρτή αν $f(\lambda x_1 + (1 - \lambda)x_2) \le \lambda f(x_1) + (1 - \lambda)f(x_2)$ για κάθε $x_1, x_2$ και $0 \le \lambda \le 1$ (κοίλη, αν η $-f$ είναι κυρτή). Αν η $f$ είναι δύο φορές παραγωγίσιμη με $f''(x) \ge 0$, είναι κυρτή.

Jensen: αν η $f$ είναι κυρτή, τότε $f\big(E(X)\big) \le E\big(f(X)\big)$ (όταν υπάρχουν οι μέσες τιμές). Συνέπειες, με $|x|$, $x^2$ και $e^{tx}$: $$|E(X)| \le E(|X|), \qquad \big(E(X)\big)^2 \le E(X^2), \qquad e^{tE(X)} \le E\big(e^{tX}\big),\ t > 0.$$

Ροπογεννήτρια

$M_X(t) = E\big(e^{tX}\big)$. Αν είναι πεπερασμένη σε ένα διάστημα $(-h, h)$, τότε $E(X^k) = M_X^{(k)}(0)$. Χαρακτηρίζει την κατανομή, και για ανεξάρτητες $X_1, \dots, X_n$: $M_{X_1 + \dots + X_n}(t) = \prod_i M_{X_i}(t)$.

  • $X \sim b(n, p)$: $M_X(t) = (1 - p + pe^t)^n$, οπότε $E(X) = np$, $\text{Var}(X) = np(1 - p)$.
  • $X \sim \text{Poisson}(\lambda)$: $M_X(t) = e^{\lambda(e^t - 1)}$, οπότε $E(X) = \lambda$, $E(X^2) = \lambda^2 + \lambda$.
  • $X \sim \mathcal E(\lambda)$: $M_X(t) = \frac{\lambda}{\lambda - t}$ για $t < \lambda$, οπότε $E(X) = \frac1\lambda$, $E(X^2) = \frac{2}{\lambda^2}$.

Φράγματα Chernoff

Εφαρμόζοντας τη Markov στην $e^{tX}$: $P(X > \epsilon) \le \inf_{t>0}\frac{E(e^{tX})}{e^{t\epsilon}}$ (και ανάλογα για $t < 0$· οι σημειώσεις ονομάζουν την $P(X > \epsilon) \le E(e^{tX})/e^{t\epsilon}$ ανισότητα Bernstein). Για άθροισμα $X = X_1 + \dots + X_n$ ανεξάρτητων δίτιμων μεταβλητών με $P(X_i = 1) = p_i$ και $\mu = \sum_i p_i$: $$P(X - \mu > \mu\epsilon) \le e^{-\mu\epsilon^2/3}\ \ (0 < \epsilon \le 1), \qquad P(X - \mu < -\mu\epsilon) \le e^{-\mu\epsilon^2/2}\ \ (0 < \epsilon < 1),$$ $$P(|X - \mu| > \mu\epsilon) \le 2e^{-\mu\epsilon^2/3}\ \ (0 < \epsilon < 1).$$ Π.χ. για $n$ ρίψεις αμερόληπτου νομίσματος, με $\epsilon = \sqrt{6\ln n/n}$ (για $n$ ώστε $\epsilon < 1$, δηλαδή $n \ge 19$): $P\left(\left|X - \frac n2\right| > \frac12\sqrt{6n\ln n}\right) \le \frac2n$.

Chernoff ή Chebyshev;

Η Chebyshev δίνει φράγμα που φθίνει ως $\frac1n$, ενώ το Chernoff φθίνει εκθετικά στο $\mu\epsilon^2$: για μεγάλες αποκλίσεις και μεγάλο $n$ είναι πολύ καλύτερο.

Στην R

exp(-500 * 0.2^2 / 3) → 0.001272634 (φράγμα Chernoff για $1000$ ρίψεις, $\epsilon = 0{,}2$). Ροπές από ροπογεννήτρια με συμβολική παράγωγο: D(quote((0.7 + 0.3*exp(t))^10), "t") και υπολογισμός στο t = 0.

Πειραματίσου

X = αριθμός κορωνών σε n = 1000 ρίψεις, μ = 500: P(|X − μ| > με) = P(|X − 500| > 100)
ακριβής 1.80e-10 · Chebyshev Var/(με)² = 0,025 · Chernoff 2e−με²/3 = 0,0025
Για μεγάλο n το φράγμα Chernoff φθίνει εκθετικά, ενώ το Chebyshev μόνο ως 1/n.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Αν $E(X) = 3$, ποια είναι η ελάχιστη δυνατή τιμή του $E(X^2)$ σύμφωνα με την ανισότητα Jensen;
Υπόδειξη: $f(x) = x^2$ είναι κυρτή.
Λύση: $(E(X))^2 \le E(X^2)$, άρα $E(X^2) \ge 9$ (ισότητα αν η $X$ είναι σταθερή).
Άσκηση 2Βασική
Αν $M_X(t) = (0{,}7 + 0{,}3e^t)^{10}$, να βρείτε τα $E(X)$ και $\text{Var}(X)$.
Υπόδειξη: Ροπογεννήτρια της $b(10;\ 0{,}3)$.
Λύση: $X \sim b(10;\ 0{,}3)$: $E(X) = 3$, $\text{Var}(X) = 10\cdot 0{,}3\cdot 0{,}7 = 2{,}1$.
Άσκηση 3Μέτρια
Αν $M_X(t) = e^{4(e^t - 1)}$, να βρείτε τα $E(X)$ και $E(X^2)$.
Υπόδειξη: $X \sim \text{Poisson}(4)$.
Λύση: $E(X) = M_X'(0) = 4$ και $E(X^2) = M_X''(0) = 4 + 16 = 20$.
Άσκηση 4Μέτρια
Αν $M_X(t) = \frac{2}{2 - t}$ για $t < 2$, να βρείτε τα $E(X)$ και $E(X^2)$.
Υπόδειξη: $M_X'(t) = \frac{2}{(2-t)^2}$, $M_X''(t) = \frac{4}{(2-t)^3}$.
Λύση: $E(X) = M_X'(0) = \frac24 = \frac12$, $E(X^2) = M_X''(0) = \frac48 = \frac12$ (εκθετική $E(2)$: $\frac1\lambda$ και $\frac{2}{\lambda^2}$).
Άσκηση 5Μέτρια
Ρίχνουμε ένα αμερόληπτο νόμισμα $1000$ φορές και $X$ είναι ο αριθμός των κορωνών ($\mu = 500$). Με το φράγμα Chernoff $P(X - \mu > \mu\epsilon) \le e^{-\mu\epsilon^2/3}$, να βρείτε άνω φράγμα για την $P(X > 550)$ (με 4 δεκαδικά).
Υπόδειξη: $\mu\epsilon = 50 \Rightarrow \epsilon = 0{,}1$.
Λύση: $e^{-500\cdot 0{,}01/3} = e^{-5/3} \approx 0{,}1889$.
Άσκηση 6Μέτρια
Με τα δεδομένα $1000$ ρίψεων αμερόληπτου νομίσματος ($\mu = 500$) και το φράγμα $P(X - \mu < -\mu\epsilon) \le e^{-\mu\epsilon^2/2}$, να βρείτε άνω φράγμα για την $P(X < 450)$ (με 4 δεκαδικά).
Υπόδειξη: $\epsilon = 0{,}1$.
Λύση: $e^{-500\cdot 0{,}01/2} = e^{-2{,}5} \approx 0{,}0821$.
Άσκηση 7Απαιτητική
Για $1000$ ρίψεις αμερόληπτου νομίσματος ($\mu = 500$, $\text{Var}(X) = 250$), να συγκρίνετε τα φράγματα για την $P(|X - 500| > 100)$: της Chebyshev και του Chernoff $2e^{-\mu\epsilon^2/3}$ (με 4 δεκαδικά).
Υπόδειξη: $\mu\epsilon = 100 \Rightarrow \epsilon = 0{,}2$.
Λύση: Chebyshev: $\frac{250}{100^2} = 0{,}025$. Chernoff: $2e^{-500\cdot 0{,}04/3} = 2e^{-6{,}667} \approx 0{,}0025$ — δέκα φορές καλύτερο φράγμα.
Άσκηση 8Μέτρια
Η ανισότητα $\big(E(X)\big)^2 \le E(X^2)$ προκύπτει από την ανισότητα Jensen με τη συνάρτηση:
Υπόδειξη: Χρειάζεται κυρτή συνάρτηση.
Λύση: $f(x) = x^2$ είναι κυρτή ($f'' = 2 \ge 0$), άρα $f(E(X)) \le E(f(X))$. Οι $\ln x$, $\sqrt x$, $-x^2$ είναι κοίλες και δίνουν την αντίθετη ανισότητα.
Άσκηση 9Βασική
Αν οι $X$ και $Y$ είναι ανεξάρτητες, τότε $M_{X+Y}(t) = M_X(t)\,M_Y(t)$.
Υπόδειξη: $e^{t(X+Y)} = e^{tX}e^{tY}$.
Λύση: Σωστό: $E(e^{tX}e^{tY}) = E(e^{tX})E(e^{tY})$ λόγω ανεξαρτησίας.
Άσκηση 10Μέτρια
Τι επιστρέφει η εντολή της R exp(-200 * 0.3^2 / 2) (με 7 δεκαδικά); Ποιο φράγμα υπολογίζει, αν $\mu = 200$;
Υπόδειξη: $200\cdot 0{,}09/2 = 9$.
Λύση: $e^{-9} \approx 0{,}0001234$: το φράγμα Chernoff $P(X - \mu < -0{,}3\mu) \le e^{-\mu\epsilon^2/2}$ για $\mu = 200$, $\epsilon = 0{,}3$.

♾️ Γεννήτρια — ροπογεννήτρια και φράγματα Chernoff

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Ρίχνουμε ένα αμερόληπτο νόμισμα $200$ φορές και $X$ είναι ο αριθμός των κορωνών. Με το φράγμα Chernoff $P(X - \mu > \mu\varepsilon) \le e^{-\mu\varepsilon^2/3}$, να βρείτε άνω φράγμα για την $P(X > 130)$ (με 4 δεκαδικά).
Υπόδειξη: $\mu = 100$, $\mu\varepsilon = 30$ ⇒ $\varepsilon = 0{,}3$.
Λύση: $\mu = 100$, $\varepsilon = 0{,}3$: $e^{-100\cdot 0{,}09/3} = e^{-3} = 0{,}0498$.
