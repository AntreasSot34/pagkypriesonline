1.2

Πολυωνυμικοί συντελεστές – Κατανομή σφαιριδίων σε δοχεία

📘 Σημειώσεις ΜΑΣ055 (Χριστοφίδης): Συνδυαστική (πολυωνυμικοί συντελεστές, Προτάσεις 1–2) · Φυλλάδιο ασκήσεων 1

Θεωρία

Πολυωνυμικοί συντελεστές

Χωρίζουμε $n$ αντικείμενα σε $k$ (διακεκριμένες) ομάδες μεγέθους $n_1, \dots, n_k$ με $n_1 + \dots + n_k = n$. Από τη βασική αρχή μέτρησης:

$$\binom{n}{n_1}\binom{n - n_1}{n_2}\cdots = \frac{n!}{n_1!\,n_2!\cdots n_k!} =: \binom{n}{n_1, n_2, \dots, n_k}.$$

Αν οι ομάδες δεν έχουν ονόματα και είναι ισομεγέθεις, διαιρούμε με το πλήθος των αναδιατάξεών τους: π.χ. $10$ παίκτες σε δύο ομάδες των $5$ χωρίς ονόματα: $\frac{1}{2!}\binom{10}{5, 5} = 126$.

Πολυωνυμικό θεώρημα: $(x_1 + \dots + x_k)^n = \sum_{n_1 + \dots + n_k = n} \binom{n}{n_1, \dots, n_k} x_1^{n_1}\cdots x_k^{n_k}$.

Σφαιρίδια σε δοχεία

  • $n$ διακεκριμένα σφαιρίδια σε $k$ διακεκριμένα δοχεία: $k^n$ τρόποι (κάθε σφαιρίδιο διαλέγει δοχείο).
  • $n$ όμοια σφαιρίδια σε $k$ δοχεία: το αποτέλεσμα είναι το διάνυσμα $(x_1, \dots, x_k)$, όπου $x_i$ τα σφαιρίδια στο δοχείο $i$. Με $n$ σφαιρίδια και $k - 1$ διαχωριστικά σε $n + k - 1$ θέσεις:

Πρόταση 1. Η $x_1 + \dots + x_k = n$ έχει $\binom{n+k-1}{k-1} = \binom{n+k-1}{n}$ μη αρνητικές ακέραιες λύσεις.

Πρόταση 2. Έχει $\binom{n-1}{k-1}$ θετικές ακέραιες λύσεις (θέτουμε $y_i = x_i - 1 \ge 0$).

Παράδειγμα – παγίδα

Επενδυτής με $30$ εκατομμύρια σε μονάδες του $1$ εκατ. και $4$ επενδύσεις: αν επενδύει όλα τα χρήματα, $\binom{33}{3} = 5456$ στρατηγικές· αν όχι υποχρεωτικά όλα, προσθέτουμε μια μεταβλητή $x_5$ για το υπόλοιπο: $\binom{34}{4} = 46376$. Τα $\binom{n+k-1}{k-1}$ αποτελέσματα με όμοια σφαιρίδια δεν είναι ισοπίθανα όταν τα σφαιρίδια ρίχνονται τυχαία ένα-ένα.

Στην R

factorial(10) / (factorial(5) * factorial(3) * factorial(2)) → 2520 · choose(33, 3) → 5456 (λύσεις της $x_1 + \dots + x_4 = 30$) · table(sample(1:4, 30, replace = TRUE)) ρίχνει $30$ σφαιρίδια τυχαία σε $4$ δοχεία.

Πειραματίσου

Κωδικοποίηση: ○○○ | | ○○ — 5 σφαιρίδια και 2 διαχωριστικά σε 7 θέσεις.
Πλήθος δυνατών τοποθετήσεων: (n+k−1k−1)=(72)=21\binom{n+k-1}{k-1} = \binom{7}{2} = 21(k−1n+k−1​)=(27​)=21 — ίσο με το πλήθος των μη αρνητικών ακέραιων λύσεων της x1+⋯+x3=5x_1 + \dots + x_{3} = 5x1​+⋯+x3​=5.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Ένα τμήμα $12$ υπαλλήλων πρέπει να χωριστεί σε τρεις ομάδες: $6$ στην εξυπηρέτηση, $4$ στο λογιστήριο και $2$ στην αποθήκη. Με πόσους τρόπους γίνεται ο χωρισμός;
Υπόδειξη: Πολυωνυμικός συντελεστής.
Λύση: $\binom{12}{6, 4, 2} = \frac{12!}{6!\,4!\,2!} = 13860$.
Άσκηση 2Βασική
$8$ παίκτες χωρίζονται σε δύο ομάδες των $4$. Πόσοι είναι οι χωρισμοί αν η μία ομάδα παίζει στην Α΄ και η άλλη στη Β΄ κατηγορία; Πόσοι, αν απλώς παίζουν μεταξύ τους (οι ομάδες δεν έχουν ονόματα);
Υπόδειξη: Χωρίς ονόματα κάθε χωρισμός μετρήθηκε $2!$ φορές.
Λύση: $\binom{8}{4, 4} = \frac{8!}{4!\,4!} = 70$. Χωρίς ονόματα: $70/2! = 35$.
Άσκηση 3Βασική
Πόσες μη αρνητικές και πόσες θετικές ακέραιες λύσεις έχει η εξίσωση $x_1 + x_2 + x_3 + x_4 = 10$;
Υπόδειξη: Προτάσεις 1 και 2 με $n = 10$, $k = 4$.
Λύση: Μη αρνητικές: $\binom{13}{3} = 286$. Θετικές: $\binom{9}{3} = 84$.
Άσκηση 4Μέτρια
Ένας επενδυτής έχει $20$ εκατομμύρια ευρώ για $4$ επενδύσεις, σε ακέραιες μονάδες του $1$ εκατομμυρίου. Πόσες στρατηγικές υπάρχουν αν επενδύσει όλα τα χρήματα; Πόσες αν δεν είναι υποχρεωτικό να επενδύσει όλα;
Υπόδειξη: Για το δεύτερο, μια επιπλέον μεταβλητή $x_5$ για τα χρήματα που μένουν.
Λύση: $x_1 + \dots + x_4 = 20$: $\binom{23}{3} = 1771$. Με $x_5$: $x_1 + \dots + x_5 = 20$: $\binom{24}{4} = 10626$.
Άσκηση 5Μέτρια
Ποιος είναι ο συντελεστής του $x^2y^3z$ στο ανάπτυγμα του $(x + y + z)^6$, και ποιο είναι το άθροισμα όλων των πολυωνυμικών συντελεστών $\binom{6}{n_1, n_2, n_3}$;
Υπόδειξη: Πολυωνυμικό θεώρημα· για το άθροισμα θέστε $x = y = z = 1$.
Λύση: $\binom{6}{2, 3, 1} = \frac{6!}{2!\,3!\,1!} = 60$ και $\sum \binom{6}{n_1, n_2, n_3} = (1 + 1 + 1)^6 = 3^6 = 729$.
Άσκηση 6Μέτρια
Πόσες μη αρνητικές ακέραιες λύσεις της $x_1 + x_2 + x_3 + x_4 = 6$ έχουν ακριβώς ένα $x_i$ ίσο με μηδέν;
Υπόδειξη: Διαλέξτε ποια μεταβλητή είναι $0$· οι άλλες τρεις είναι θετικές.
Λύση: $\binom41$ επιλογές για τη μηδενική μεταβλητή και $\binom{5}{2} = 10$ θετικές λύσεις της $y_1 + y_2 + y_3 = 6$: $4\cdot 10 = 40$. (Γενικά $\binom{r}{k}\binom{n-1}{n-r+k}$ — Φυλλάδιο 1.)
Άσκηση 7Βασική
Ρίχνουμε $5$ διακεκριμένα σφαιρίδια σε $3$ διακεκριμένα δοχεία. Πόσες είναι οι δυνατές τοποθετήσεις; Αν τα σφαιρίδια είναι όμοια, πόσες είναι οι δυνατές «εικόνες» $(x_1, x_2, x_3)$;
Υπόδειξη: $k^n$ και $\binom{n+k-1}{k-1}$.
Λύση: $3^5 = 243$ και $\binom{7}{2} = 21$.
Άσκηση 8Μέτρια
Πόσες διαφορετικές «λέξεις» σχηματίζονται με όλα τα γράμματα της λέξης ΣΤΑΤΙΣΤΙΚΗ (Σ, Τ, Α, Τ, Ι, Σ, Τ, Ι, Κ, Η);
Υπόδειξη: $10$ γράμματα: Σ δύο φορές, Τ τρεις, Ι δύο.
Λύση: $\binom{10}{2, 3, 2, 1, 1, 1} = \frac{10!}{2!\,3!\,2!} = \frac{3\,628\,800}{24} = 151\,200$.
Άσκηση 9Βασική
Τοποθετούμε τυχαία $n$ όμοια σφαιρίδια ένα-ένα σε $k$ δοχεία (κάθε σφαιρίδιο ανεξάρτητα, ισοπίθανα σε κάθε δοχείο). Τότε οι $\binom{n+k-1}{k-1}$ δυνατές εικόνες $(x_1, \dots, x_k)$ είναι ισοπίθανες.
Υπόδειξη: Δοκιμάστε $n = 2$, $k = 2$.
Λύση: Λάθος: για $n = k = 2$ οι εικόνες $(2, 0)$, $(1, 1)$, $(0, 2)$ έχουν πιθανότητες $\frac14, \frac12, \frac14$· η $(1, 1)$ προκύπτει με δύο τρόπους. Ισοπίθανα είναι τα $k^n$ αποτελέσματα με διακεκριμένα σφαιρίδια.

♾️ Γεννήτρια — πολυωνυμικοί συντελεστές και σφαιρίδια σε δοχεία

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Πόσες θετικές ακέραιες λύσεις έχει η εξίσωση $x_1 + x_2 + x_3 + x_4 = 8$;
Υπόδειξη: Θέτουμε $y_i = x_i - 1 \ge 0$.
Λύση: Με $y_i = x_i - 1$: $y_1 + \dots + y_{4} = 4$, άρα $\binom{4 + 4 - 1}{4 - 1} = \binom{7}{3} = 35$.
