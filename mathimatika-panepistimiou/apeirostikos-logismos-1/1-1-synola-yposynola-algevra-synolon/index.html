1.1

Σύνολα – Υποσύνολα – Άλγεβρα συνόλων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 1 §1.1, §1.1.1, §1.1.2 · 1η σειρά ασκήσεων (άσκ. 1)

Η γλώσσα των συνόλων είναι το «λεξιλόγιο» όλου του Λογισμού: πεδία ορισμού, διαστήματα, λύσεις ανισώσεων είναι όλα σύνολα.

Θεωρία

Σύνολο – στοιχείο

Η έννοια του συνόλου είναι αρχική (δεν ορίζεται): ένα σύνολο είναι ένα σαφώς καθορισμένο πλήθος διακεκριμένων αντικειμένων, τα στοιχεία του. Γράφουμε $x \in A$ («το $x$ ανήκει στο $A$») ή $x \notin A$. Ένα σύνολο ορίζεται είτε με αναγραφή των στοιχείων του, π.χ. $\Phi = \{\alpha, \varepsilon, \eta, \iota, o, \upsilon, \omega\}$, είτε με μια συνθήκη (προτασιακό τύπο) $P(x)$:

$$A = \{\, x : P(x) \,\}, \qquad \text{π.χ. } \{x : x \text{ περιττός φυσικός}\} = \{1, 3, 5, \dots\}.$$

Το σύνολο χωρίς στοιχεία είναι το κενό σύνολο $\varnothing$ (π.χ. $\{x : x \ne x\} = \varnothing$).

1.1.1.1 – 1.1.1.3 · Υποσύνολο, ισότητα, γνήσιο υποσύνολο

Μέσα σε ένα βασικό σύνολο $\Omega$: $\ A \subseteq B \iff (x \in A \Rightarrow x \in B)$. Τα $A, B$ είναι ίσα αν $A \subseteq B$ και $B \subseteq A$. Αν $A \subseteq B$ και $A \ne B$, το $A$ είναι γνήσιο υποσύνολο του $B$, $A \subset B$ (π.χ. $\mathbb{Z} \subset \mathbb{R}$).

Ισχύουν: $\varnothing \subseteq A$, $\ A \subseteq A$, $\ (A \subseteq B \text{ και } B \subseteq \Gamma) \Rightarrow A \subseteq \Gamma$.

1.1.2.1 – 1.1.2.4 · Ένωση, τομή, ξένα σύνολα, διαφορά

$A \cup B = \{x \in \Omega : x \in A \text{ ή } x \in B\}$, $\quad A \cap B = \{x \in \Omega : x \in A \text{ και } x \in B\}$, $\quad A - B = \{x \in \Omega : x \in A \text{ και } x \notin B\}$. Τα $A, B$ λέγονται ξένα αν $A \cap B = \varnothing$.

Ιδιότητες: αντιμεταθετικές, προσεταιριστικές, $A \cup A = A \cap A = A$, $A \cup \varnothing = A$, $A \cap \varnothing = \varnothing$, και $\ A \subseteq B \iff A \cup B = B \iff A \cap B = A$. Επίσης $A - A = \varnothing$, $A - \varnothing = A$, $A - B \subseteq A$.

Πράξεις με απαρίθμηση

$A = \{1,2,3,4,5\}$, $B = \{2,5,7,8\}$: $\ A \cup B = \{1,2,3,4,5,7,8\}$, $\ A \cap B = \{2,5\}$, $\ A - B = \{1,3,4\}$, $\ B - A = \{7,8\}$.

Γιατί $A \cap B \subseteq A$;

Αν $x \in A \cap B$, τότε από τον ορισμό $x \in A$ και $x \in B$· ειδικά $x \in A$. Άρα κάθε στοιχείο της τομής ανήκει στο $A$.

Προσοχή

Το $\varnothing$ δεν είναι το ίδιο με το $\{0\}$ ή το $\{\varnothing\}$ (αυτά έχουν ένα στοιχείο). Η διαφορά δεν είναι αντιμεταθετική: γενικά $A - B \ne B - A$.

Πειραματίσου

Ω = {1, 2, …, 20}, A = {x : x άρτιοι}, B = {x : x πολλαπλάσια του 3}.
A ∪ B = {2, 3, 4, 6, 8, 9, 10, 12, 14, 15, 16, 18, 20} (13 στοιχεία)
|A ∪ B| = |A| + |B| − |A ∩ B| = 10 + 6 − 3 = 13

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Δίνονται $A = \{1, 2, 3, 4, 5\}$ και $B = \{2, 5, 7, 8\}$. Πόσα στοιχεία έχουν τα $A \cup B$, $A \cap B$ και $A - B$;
Υπόδειξη: Γράψτε τα σύνολα με αναγραφή.
Λύση: $A \cup B = \{1,2,3,4,5,7,8\}$ (7 στοιχεία), $A \cap B = \{2,5\}$ (2), $A - B = \{1,3,4\}$ (3).
Άσκηση 2Βασική
Ποια σχέση είναι λανθασμένη;
Υπόδειξη: Είναι το $\frac12$ ακέραιος;
Λύση: Το $\frac12 \in \mathbb{Q}$ αλλά $\frac12 \notin \mathbb{Z}$, άρα $\mathbb{Q} \not\subseteq \mathbb{Z}$. Οι άλλες ισχύουν (το κενό είναι υποσύνολο κάθε συνόλου).
Άσκηση 3Βασική
Δίνεται $A = \{x \in \mathbb{N} : x \text{ διαιρεί τον } 12\}$. Πόσα στοιχεία έχει το $A$ και ποιο είναι το άθροισμά τους;
Υπόδειξη: Οι διαιρέτες του 12.
Λύση: $A = \{1, 2, 3, 4, 6, 12\}$: 6 στοιχεία με άθροισμα $28$.
Άσκηση 4Μέτρια
Αν $A \cup B = B$, τότε αναγκαστικά:
Υπόδειξη: Ιδιότητα IX της §1.1.2.
Λύση: $A \subseteq A \cup B = B$. (Αντίστροφα, αν $A \subseteq B$ τότε $A \cup B = B$.) Το $A = B$ δεν είναι αναγκαίο: π.χ. $A = \varnothing$.
Άσκηση 5Μέτρια
Στο $\Omega = \{1, 2, \dots, 20\}$ θεωρούμε $A = \{x : x \text{ άρτιος}\}$ και $B = \{x : x \text{ πολλαπλάσιο του } 3\}$. Πόσα στοιχεία έχουν τα $A \cap B$, $A \cup B$ και $B - A$;
Υπόδειξη: $A \cap B$: πολλαπλάσια του 6.
Λύση: $A$ έχει 10 στοιχεία, $B = \{3,6,9,12,15,18\}$ έχει 6, $A \cap B = \{6, 12, 18\}$ (3). Άρα $|A \cup B| = 10 + 6 - 3 = 13$ και $B - A = \{3, 9, 15\}$ (3).
Άσκηση 6Βασική
Τα σύνολα $A = \{x : x \text{ φωνήεν}\}$ και $B = \{x : x \text{ σύμφωνο}\}$ (γράμματα του ελληνικού αλφαβήτου) είναι:
Υπόδειξη: Υπάρχει γράμμα που να είναι και φωνήεν και σύμφωνο;
Λύση: $A \cap B = \varnothing$, άρα είναι ξένα.
Άσκηση 7Μέτρια
Για τυχαία σύνολα $A, B$ ισχύει πάντα $(A - B) \cap B = \varnothing$.
Υπόδειξη: Ένα στοιχείο της $A - B$ ανήκει στο $B$;
Λύση: Σωστό: αν $x \in A - B$ τότε $x \notin B$, άρα κανένα στοιχείο της $A - B$ δεν ανήκει στο $B$.
Άσκηση 8Απαιτητική
Ένα σύνολο $A$ έχει $7$ στοιχεία, ένα σύνολο $B$ έχει $5$ στοιχεία και η ένωσή τους $A \cup B$ έχει $9$ στοιχεία. Πόσα στοιχεία έχουν τα $A \cap B$, $A - B$ και $B - A$;
Υπόδειξη: Στο $|A| + |B|$ τα κοινά στοιχεία μετριούνται δύο φορές.
Λύση: $|A \cap B| = |A| + |B| - |A \cup B| = 7 + 5 - 9 = 3$. $|A - B| = 7 - 3 = 4$, $|B - A| = 5 - 3 = 2$ (έλεγχος: $4 + 3 + 2 = 9$).

♾️ Γεννήτρια — πράξεις συνόλων

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Έστω $A = \{1, 2, 4, 8, 9, 11\}$ και $B = \{1, 6, 9, 10\}$. Να βρείτε το πλήθος στοιχείων των $A \cup B$, $A \cap B$ και $A - B$.
Λύση: $A \cup B = \{1, 2, 4, 6, 8, 9, 10, 11\}$, $A \cap B = \{1, 9\}$, $A - B = \{2, 4, 8, 11\}$. Έλεγχος: $|A \cup B| = |A| + |B| - |A \cap B| = 6 + 4 - 2 = 8$.
