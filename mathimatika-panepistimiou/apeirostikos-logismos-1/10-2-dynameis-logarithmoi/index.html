10.2

Δυνάμεις – Λογάριθμοι

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 10 §10.2 · 10η σειρά ασκήσεων

Ο λογάριθμος είναι απλώς η αντίστροφη της εκθετικής: $\log_a x$ είναι ο εκθέτης στον οποίο υψώνουμε το $a$ για να πάρουμε $x$.

Θεωρία

Δυνάμεις

$a^n = \underbrace{a\cdot a\cdots a}_{n}$ ($n \in \mathbb{N}$), $\ a^{-n} = \frac{1}{a^n}$ ($a \ne 0$), $\ a^{m/n} = \sqrt[n]{a^m}$ ($a > 0$).

Ιδιότητες ($a, \beta > 0$, $x, y \in \mathbb{R}$): $a^0 = 1$, $a^x a^y = a^{x+y}$, $\frac{a^x}{a^y} = a^{x-y}$, $a^x\beta^x = (a\beta)^x$, $\frac{a^x}{\beta^x} = \left(\frac a\beta\right)^x$, $(a^x)^y = a^{xy}$.

Εκθετική και λογαριθμική συνάρτηση

Εκθετική με βάση $a > 0$: $f(x) = a^x$, με πεδίο ορισμού $\mathbb{R}$ και (για $a \ne 1$) πεδίο τιμών $\mathbb{R}^+$. Για $a \ne 1$ είναι ένα προς ένα, άρα έχει αντίστροφη, τον λογάριθμο με βάση $a$:

$y = \log_a x \iff x = a^y, \qquad x > 0.$

Ιδιότητες λογαρίθμων

Για $a, x, y > 0$, $a \ne 1$, $n \in \mathbb{Q}$:

$\log_a 1 = 0,\quad \log_a a = 1,\quad \log_a(xy) = \log_a x + \log_a y,\quad \log_a\frac xy = \log_a x - \log_a y,\quad \log_a x^n = n\log_a x$

Δεκαδικός λογάριθμος: $\log x = \log_{10}x$· φυσικός: $\ln x = \log_e x$, όπου $e \approx 2{,}718281828$, $\ e = \lim_{h\to 0}(1 + h)^{1/h} = \lim_{n\to\infty}\left(1 + \frac1n\right)^n$. Αλλαγή βάσης: $\log_a c = \frac{\log_b c}{\log_b a}$.

Λογαριθμικές και εκθετικές εξισώσεις

(i) $\log x^{5/2} + \log\sqrt x = 9 \Rightarrow \frac52\log x + \frac12\log x = 9 \Rightarrow 3\log x = 9 \Rightarrow x = 10^3 = 1000$.

(ii) $\ln x^4 - \ln 2x - \ln 4 = 0 \Rightarrow \ln\frac{x^4}{8x} = \ln 1 \Rightarrow x^3 = 8 \Rightarrow x = 2$.

(iii) $x^2e^x - 2xe^x + e^x = 0 \Rightarrow (x - 1)^2 e^x = 0 \Rightarrow x = 1$, αφού $e^x > 0$.

(iv) $e^{2x} - 5e^x + 6 = 0 \Rightarrow (e^x - 2)(e^x - 3) = 0 \Rightarrow x = \ln 2$ ή $x = \ln 3$.

Συχνά λάθη

$\log(x + y) \ne \log x + \log y$ · $\ \frac{\ln x}{\ln y} \ne \ln\frac xy$ · πάντα ελέγχουμε ότι οι λύσεις κάνουν θετικά τα ορίσματα των λογαρίθμων.

Πειραματίσου

y = aˣ και y = logax με a = 5,15: συμμετρικές ως προς την y = x (αντίστροφες). Για a > 1 και οι δύο είναι αύξουσες.
loga(3,1) = ln(3,1) / ln(5,15) = 0,691 · πάντα loga1 = 0, logaa = 1.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να λυθεί η εξίσωση $\ln(x^2) = 4$, $x > 0$ (4 δεκαδικά).
Υπόδειξη: $2\ln x = 4$.
Λύση: $2\ln x = 4 \Rightarrow \ln x = 2 \Rightarrow x = e^2 \approx 7{,}3891$.
Άσκηση 2Βασική
Να λυθεί η εξίσωση $3^x = 2$ (4 δεκαδικά).
Υπόδειξη: Λογαριθμίστε.
Λύση: $x\ln 3 = \ln 2 \Rightarrow x = \frac{\ln 2}{\ln 3} = \log_3 2 \approx 0{,}6309$.
Άσκηση 3Μέτρια
Να λυθεί η εξίσωση $e^{2x} - e^x = 6$ (4 δεκαδικά).
Υπόδειξη: $u = e^x > 0$.
Λύση: $u^2 - u - 6 = 0 \Rightarrow (u - 3)(u + 2) = 0$. Επειδή $u = e^x > 0$, μόνο $e^x = 3$, δηλαδή $x = \ln 3 \approx 1{,}0986$.
Άσκηση 4Μέτρια
Να λυθεί η εξίσωση $\ln 4x - 3\ln x^2 = \ln 2$, $x > 0$ (4 δεκαδικά).
Υπόδειξη: $\ln 4x - \ln x^6 = \ln\frac{4x}{x^6}$.
Λύση: $\ln\frac{4}{x^5} = \ln 2 \Rightarrow x^5 = 2 \Rightarrow x = 2^{1/5} \approx 1{,}1487$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $(\log_2 81)(\log_3 32)$.
Υπόδειξη: $81 = 3^4$, $32 = 2^5$ και $\log_a b\cdot\log_b a = 1$.
Λύση: $(4\log_2 3)(5\log_3 2) = 20\,\log_2 3\cdot\log_3 2 = 20$, αφού $\log_2 3 = \frac{\ln 3}{\ln 2}$ και $\log_3 2 = \frac{\ln 2}{\ln 3}$.
Άσκηση 6Βασική
Για $a, b > 0$, $a, b \ne 1$, το γινόμενο $\log_a b\cdot\log_b a$ ισούται με:
Υπόδειξη: Αλλαγή βάσης.
Λύση: $\log_a b = \frac{\ln b}{\ln a}$ και $\log_b a = \frac{\ln a}{\ln b}$, άρα το γινόμενο είναι $1$.
Άσκηση 7Μέτρια
Να λυθεί η εξίσωση $\log x^2 + \log x = 30$ (δεκαδικοί λογάριθμοι).
Υπόδειξη: $3\log x = 30$.
Λύση: $2\log x + \log x = 3\log x = 30 \Rightarrow \log x = 10 \Rightarrow x = 10^{10}$.
Άσκηση 8Απαιτητική
Να λυθεί η εξίσωση $\dfrac{e^x}{1 - e^x} = 2$ (4 δεκαδικά).
Υπόδειξη: $e^x = 2 - 2e^x$.
Λύση: $e^x = 2(1 - e^x) \Rightarrow 3e^x = 2 \Rightarrow x = \ln\frac23 \approx -0{,}4055$ (και $e^x \ne 1$ ✓).
Άσκηση 9Βασική
Ισχύει $\ln(x + y) = \ln x + \ln y$ για κάθε $x, y > 0$.
Υπόδειξη: $x = y = 1$.
Λύση: Λάθος: για $x = y = 1$, $\ln 2 \ne 0 = \ln 1 + \ln 1$. Ο σωστός κανόνας είναι $\ln(xy) = \ln x + \ln y$.

♾️ Γεννήτρια — λογαριθμικές και εκθετικές εξισώσεις

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να λυθεί η εξίσωση $\log x^{4} + \log\sqrt{x} = 4{,}5$ (δεκαδικοί λογάριθμοι).
Υπόδειξη: Χρησιμοποιήστε $\log a^k = k\log a$ και $\log a + \log b = \log(ab)$· προσοχή στο πεδίο ορισμού.
Λύση: $4\log x + \frac12\log x = 4{,}5 \Rightarrow \frac{9}{2}\log x = 4{,}5 \Rightarrow \log x = 1 \Rightarrow x = 10^{1} = 10$.
