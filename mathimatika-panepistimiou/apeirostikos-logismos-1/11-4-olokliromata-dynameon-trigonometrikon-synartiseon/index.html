11.4

Ολοκληρώματα δυνάμεων τριγωνομετρικών συναρτήσεων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 11 §11.4 · 1η σειρά ασκήσεων (Κεφ. 11)

Για $\int\sin^m x\cos^n x\,dx$ αρκεί να κοιτάξουμε αν κάποιος εκθέτης είναι περιττός — αυτό ορίζει την αντικατάσταση.

Θεωρία

$\int\sin^m x\cos^n x\,dx$

(α) $n$ περιττός: κρατάμε ένα $\cos x$, τα υπόλοιπα $\cos^{n-1}x = (1 - \sin^2x)^{\frac{n-1}2}$ και θέτουμε $u = \sin x$.

(β) $m$ περιττός: κρατάμε ένα $\sin x$, $\sin^{m-1}x = (1 - \cos^2x)^{\frac{m-1}2}$ και $u = \cos x$.

(γ) Και οι δύο άρτιοι: τύποι αποτετραγωνισμού

$\sin^2x = \frac{1 - \cos 2x}{2}, \qquad \cos^2x = \frac{1 + \cos 2x}{2}, \qquad \sin x\cos x = \frac12\sin 2x.$

Παραδείγματα

(i) $\int\sin^3x\,dx = \int(1 - \cos^2x)\sin x\,dx \overset{u = \cos x}{=} -\cos x + \frac{\cos^3x}{3} + C$.

(ii) $\int\sin^5x\cos^2x\,dx = -\int(1 - u^2)^2u^2du = -\frac{\cos^3x}{3} + \frac{2\cos^5x}{5} - \frac{\cos^7x}{7} + C$.

(iii) $\int\sin^2x\cos^2x\,dx = \frac14\int\sin^22x\,dx = \frac18\int(1 - \cos 4x)dx = \frac x8 - \frac{\sin 4x}{32} + C$.

$\int\tan^m x\sec^n x\,dx$

(α) $n$ άρτιος: κρατάμε $\sec^2x$, τα υπόλοιπα με $\sec^2x = 1 + \tan^2x$, και $u = \tan x$.

(β) $m$ περιττός: κρατάμε $\sec x\tan x$, τα υπόλοιπα με $\tan^2x = \sec^2x - 1$, και $u = \sec x$.

(γ) Αλλιώς: ταυτότητες και κατά παράγοντες, π.χ. $\int\sec^3x\,dx = \frac12\sec x\tan x + \frac12\ln|\sec x + \tan x| + C$.

Παράδειγμα

$\int\tan x\sec^5x\,dx = \int\sec^4x\,(\sec x\tan x)\,dx \overset{u = \sec x}{=} \int u^4du = \frac{\sec^5x}{5} + C$.

Πειραματίσου

$\int \sin^{5}x\cos^{2}x\,dx$: m περιττός → κρατάμε ένα sin x, γράφουμε sin4x = (1 − cos²x)2 και θέτουμε u = cos x, du = −sin x dx.
Πράσινο εμβαδόν: $\int_0^{\pi/2}\sin^{5}x\cos^{2}x\,dx$ ≈ 0,07619.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\int\sin^3x\,dx$.
Υπόδειξη: $\sin^3x = (1 - \cos^2x)\sin x$, $u = \cos x$.
Λύση: $-\int(1 - u^2)du = -\cos x + \frac{\cos^3x}{3} + C$.
Άσκηση 2Βασική
Να υπολογίσετε το $\displaystyle\int\cos^5x\,dx$.
Υπόδειξη: $\cos^5x = (1 - \sin^2x)^2\cos x$.
Λύση: $u = \sin x$: $\int(1 - 2u^2 + u^4)du = \sin x - \frac23\sin^3x + \frac15\sin^5x + C$.
Άσκηση 3Μέτρια
Να υπολογίσετε το $\displaystyle\int\sin^5x\cos^2x\,dx$.
Υπόδειξη: $m = 5$ περιττός: $u = \cos x$.
Λύση: $-\int(1 - u^2)^2u^2du = -\frac{\cos^3x}{3} + \frac{2\cos^5x}{5} - \frac{\cos^7x}{7} + C$.
Άσκηση 4Μέτρια
Να υπολογίσετε το $\displaystyle\int\sin^2x\cos^2x\,dx$.
Υπόδειξη: $\sin x\cos x = \frac12\sin 2x$.
Λύση: $\frac14\int\sin^22x\,dx = \frac18\int(1 - \cos 4x)dx = \frac x8 - \frac{\sin 4x}{32} + C$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\displaystyle\int_0^{\pi/4}\sin^4x\,dx$ (4 δεκαδικά).
Υπόδειξη: $\sin^4x = \frac38 - \frac12\cos 2x + \frac18\cos 4x$.
Λύση: $\left[\frac{3x}{8} - \frac{\sin 2x}{4} + \frac{\sin 4x}{32}\right]_0^{\pi/4} = \frac{3\pi}{32} - \frac14 \approx 0{,}0445$.
Άσκηση 6Βασική
Να υπολογίσετε το $\displaystyle\int_0^{\pi/2}\cos^6x\,dx$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: Ίδιος αναγωγικός τύπος με το $\sin^6$.
Λύση: $\frac56\cdot\frac34\cdot\frac12\cdot\frac\pi2 = \frac{5\pi}{32}$.
Άσκηση 7Μέτρια
Να υπολογίσετε το $\displaystyle\int\tan x\sec^5x\,dx$ στο $\left(-\frac\pi2, \frac\pi2\right)$ (γράψτε το $\sec$ ως 1/cos).
Υπόδειξη: $u = \sec x$, $du = \sec x\tan x\,dx$.
Λύση: $\int u^4du = \frac{\sec^5x}{5} + C = \frac{1}{5\cos^5x} + C$.
Άσκηση 8Απαιτητική
Να υπολογίσετε το $\displaystyle\int\tan^2x\sec x\,dx$ στο $\left(-\frac\pi2, \frac\pi2\right)$.
Υπόδειξη: $\tan^2x = \sec^2x - 1$ και ο τύπος για $\int\sec^3x$.
Λύση: $\int\sec^3x - \int\sec x = \frac12\sec x\tan x + \frac12\ln|\sec x + \tan x| - \ln|\sec x + \tan x| = \frac12\sec x\tan x - \frac12\ln|\sec x + \tan x| + C$.
Άσκηση 9Μέτρια
Να υπολογίσετε το $\displaystyle\int_0^{\pi/6}\sec^3x\tan x\,dx$ (4 δεκαδικά).
Υπόδειξη: $u = \sec x$.
Λύση: $\left[\frac{\sec^3x}{3}\right]_0^{\pi/6} = \frac13\left(\frac{8}{3\sqrt3} - 1\right) \approx 0{,}1799$.
Άσκηση 10Βασική
Για το $\displaystyle\int\sin^4x\cos^3x\,dx$ η κατάλληλη αντικατάσταση είναι:
Υπόδειξη: Ποιος εκθέτης είναι περιττός;
Λύση: Ο εκθέτης του $\cos$ είναι περιττός: κρατάμε ένα $\cos x$, γράφουμε $\cos^2x = 1 - \sin^2x$ και θέτουμε $u = \sin x$.

♾️ Γεννήτρια — ολοκληρώματα δυνάμεων sin και cos

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\int_0^{\pi/2}\sin x\cos x\,dx$.
Υπόδειξη: Κρατήστε έναν παράγοντα της περιττής δύναμης και χρησιμοποιήστε $\sin^2x + \cos^2x = 1$.
Λύση: Η δύναμη του $\sin$ είναι περιττή: κρατάμε έναν $\sin x$ και θέτουμε $u = \cos x$, $du = -\sin x\,dx$, με $u: 1 \to 0$ (το $-$ αντιστρέφει τα όρια σε $0 \to 1$). Προκύπτει $\displaystyle\int_0^1 u\,du = \int_0^1\left(u\right)du = \frac{1}{2}$.
