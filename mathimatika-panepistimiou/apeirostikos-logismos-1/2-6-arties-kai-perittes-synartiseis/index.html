2.6

Άρτιες και περιττές συναρτήσεις

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 2 §2.6 · Ασκήσεις 2ου κεφαλαίου (2.4–2.6, 2.11)

Η συμμετρία μισοποιεί τη δουλειά: αρκεί να ξέρουμε τη συνάρτηση για $x \ge 0$.

Θεωρία

2.6.1 · Άρτια – περιττή

Έστω $f$ με πεδίο ορισμού $A$ τέτοιο ώστε $x \in A \Rightarrow -x \in A$.

$$\text{άρτια: } f(-x) = f(x)\ \ \forall x \in A, \qquad \text{περιττή: } f(-x) = -f(x)\ \ \forall x \in A.$$

Η γραφική παράσταση άρτιας συνάρτησης έχει άξονα συμμετρίας τον άξονα $y$· της περιττής, κέντρο συμμετρίας την αρχή.

Υπερβολικές

$\sinh(-x) = \frac{e^{-x} - e^{x}}{2} = -\sinh x$ (περιττή), $\ \cosh(-x) = \cosh x$ (άρτια).

Ανάλυση σε άρτιο + περιττό μέρος

Κάθε $f$ (με συμμετρικό πεδίο ορισμού) γράφεται μοναδικά ως άθροισμα άρτιας και περιττής:

$$f(x) = \underbrace{\tfrac12\big[f(x) + f(-x)\big]}_{\text{άρτια}} + \underbrace{\tfrac12\big[f(x) - f(-x)\big]}_{\text{περιττή}}.$$

Π.χ. $e^x = \frac12(e^x + e^{-x}) + \frac12(e^x - e^{-x}) = \cosh x + \sinh x$.

Απόδειξη ότι τα μέρη είναι άρτιο/περιττό

Για $E(x) = \frac12[f(x) + f(-x)]$: $E(-x) = \frac12[f(-x) + f(x)] = E(x)$. Για $O(x) = \frac12[f(x) - f(-x)]$: $O(-x) = \frac12[f(-x) - f(x)] = -O(x)$.

Χρήσιμα

περιττή·περιττή = άρτια, άρτια·άρτια = άρτια, περιττή·άρτια = περιττή. Αν η $f$ είναι περιττή και ορίζεται στο $0$, τότε $f(0) = 0$ (αφού $f(0) = -f(0)$).

Πειραματίσου

f(1,5) = 1,875, f(−1,5) = −1,875 · μωβ διακεκομμένη: f(−x) (κατοπτρισμός ως προς τον άξονα y)
Περιττή: f(−x) = −f(x) — συμμετρική ως προς την αρχή O.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Η συνάρτηση $f(x) = x^5 + 1$ είναι:
Υπόδειξη: $f(-x) = -x^5 + 1$.
Λύση: $f(-x) = -x^5 + 1$, που δεν είναι ούτε $f(x)$ ούτε $-f(x) = -x^5 - 1$ (π.χ. $f(1) = 2$, $f(-1) = 0$).
Άσκηση 2Βασική
Η συνάρτηση $f(x) = \sin x + x$ είναι:
Υπόδειξη: Άθροισμα περιττών.
Λύση: $f(-x) = -\sin x - x = -f(x)$: περιττή. (Δεν είναι περιοδική, λόγω του όρου $x$.)
Άσκηση 3Βασική
Η συνάρτηση $f(x) = \sin^2 x$ είναι:
Υπόδειξη: $(\sin(-x))^2$.
Λύση: $\sin^2(-x) = (-\sin x)^2 = \sin^2 x$: άρτια.
Άσκηση 4Μέτρια
Το άρτιο μέρος της $f(x) = 3x^3 - 2x^2$ είναι $E(x)$ και το περιττό $O(x)$. Να βρείτε τα $E(2)$ και $O(2)$.
Υπόδειξη: Οι άρτιες δυνάμεις πάνε στο άρτιο μέρος.
Λύση: $E(x) = -2x^2$, $O(x) = 3x^3$· $E(2) = -8$, $O(2) = 24$ (έλεγχος: $f(2) = 24 - 8 = 16$).
Άσκηση 5Μέτρια
Το άρτιο μέρος της $f(x) = e^{2x}$ είναι $E(x) = \cosh(ax)$. Να βρείτε το $a$ και την τιμή $E(0)$.
Υπόδειξη: $\frac12(e^{2x} + e^{-2x})$.
Λύση: $E(x) = \frac{e^{2x} + e^{-2x}}{2} = \cosh 2x$, $E(0) = 1$.
Άσκηση 6Μέτρια
Το γινόμενο δύο περιττών συναρτήσεων είναι άρτια συνάρτηση.
Υπόδειξη: $f(-x)g(-x) = (-f(x))(-g(x))$.
Λύση: Σωστό: $(fg)(-x) = (-f(x))(-g(x)) = f(x)g(x)$.
Άσκηση 7Μέτρια
Αν $f(-x) = -f(x)$ για κάθε $x \in \mathbb{R}$, τότε:
Υπόδειξη: Θέστε $x = 0$.
Λύση: $f(0) = -f(0) \Rightarrow 2f(0) = 0 \Rightarrow f(0) = 0$.
Άσκηση 8Απαιτητική
Η $f(x) = 10^x + 2x$ γράφεται $f = E + O$ με $E$ άρτια και $O$ περιττή. Να βρείτε τα $E(1)$ και $O(1)$.
Υπόδειξη: $E(1) = \frac{f(1) + f(-1)}{2}$.
Λύση: $f(1) = 12$, $f(-1) = 0{,}1 - 2 = -1{,}9$. $E(1) = \frac{12 - 1{,}9}{2} = 5{,}05 = \frac{101}{20}$, $O(1) = \frac{12 + 1{,}9}{2} = 6{,}95 = \frac{139}{20}$.

♾️ Γεννήτρια — άρτιες και περιττές

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Η $f$ είναι περιττή με πεδίο ορισμού το $\mathbb R$ και $f(2) = 1$. Να βρείτε τα $f(-2)$ και $f(0)$.
Λύση: Περιττή: $f(-2) = -f(2) = -1$. Επίσης για $x = 0$: $f(0) = -f(0) \Rightarrow 2f(0) = 0 \Rightarrow f(0) = 0$.
