7.2.1

Ολοκλήρωση με αντικατάσταση — πρώτη μέθοδος

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 7 §7.2–7.2.1 · Προβλήματα 7.4–7.6

Ο κανόνας της αλυσίδας «ανάποδα»: αν η συνάρτηση έχει τη μορφή f(u)·u′, η ολοκλήρωση γίνεται ως προς u.

Θεωρία

Πρώτη μέθοδος ολοκλήρωσης με αντικατάσταση

Αν η προς ολοκλήρωση συνάρτηση είναι της μορφής $f(u)\frac{du}{dx}$, όπου $u = u(x)$, τότε

$$\int \left[f(u)\,\frac{du}{dx}\right]dx = \int f(u)\,du.$$
Γιατί ισχύει;

Αν $F' = f$, τότε από τον κανόνα της αλυσίδας $\frac{d}{dx}F(u(x)) = F'(u)\,u'(x) = f(u)\frac{du}{dx}$. Άρα η $F(u(x))$ είναι παράγουσα της $f(u)\frac{du}{dx}$, δηλαδή το αριστερό μέλος ισούται με $F(u) + c = \int f(u)\,du$.

Πρακτικά: ο «διαφορικός» συμβολισμός

  1. Επιλέγουμε $u = u(x)$ (συνήθως το «εσωτερικό» μιας σύνθετης συνάρτησης).
  2. Υπολογίζουμε $du = u'(x)\,dx$ και εκφράζουμε όλο το ολοκλήρωμα με το $u$.
  3. Ολοκληρώνουμε ως προς $u$ και επιστρέφουμε στο $x$.

Συχνά γράφουμε απευθείας: $\int \frac{\sin\sqrt x}{\sqrt x}\,dx = 2\int \sin\sqrt x\;d(\sqrt x) = -2\cos\sqrt x + c$.

Τυπικές περιπτώσεις

(α) $\int (ax + b)^n dx = \frac1a\int u^n du = \frac{(ax + b)^{n+1}}{a(n+1)} + c$, $n \ne -1$, με $u = ax + b$.

(β) $\int (x^2 + 1)^5\,2x\,dx = \int u^5 du = \frac{(x^2+1)^6}{6} + c$, με $u = x^2 + 1$.

(γ) $\int \frac{g'(x)}{g(x)}\,dx = \ln|g(x)| + c$, π.χ. $\int \frac{x\,dx}{x^2+1} = \frac12\ln(x^2 + 1) + c$.

(δ) $\int \sin^3\theta\,d\theta = -\int (1 - \cos^2\theta)\,d(\cos\theta) = -\cos\theta + \frac{\cos^3\theta}{3} + c$.

Προσοχή

Μετά την αντικατάσταση δεν πρέπει να μείνει κανένα $x$. Αν το $du$ «δεν ταιριάζει» (π.χ. $\int e^{x^2}dx$, όπου λείπει ο παράγοντας $x$), η αντικατάσταση δεν δουλεύει.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να βρείτε το $\displaystyle\int (5x - 2)^4\,dx$.
Υπόδειξη: $u = 5x - 2$, $du = 5\,dx$.
Λύση: $\frac15\int u^4 du = \frac{u^5}{25} + c = \frac{(5x - 2)^5}{25} + c$.
Άσκηση 2Βασική
Να βρείτε το $\displaystyle\int 3x^2(x^3 + 2)^5\,dx$.
Υπόδειξη: $u = x^3 + 2$, $du = 3x^2dx$.
Λύση: $\int u^5du = \frac{u^6}{6} + c = \frac{(x^3 + 2)^6}{6} + c$.
Άσκηση 3Μέτρια
Να βρείτε το $\displaystyle\int \frac{\cos\sqrt x}{\sqrt x}\,dx$.
Υπόδειξη: $u = \sqrt x$, $du = \frac{dx}{2\sqrt x}$.
Λύση: $\frac{dx}{\sqrt x} = 2\,du$: $2\int\cos u\,du = 2\sin u + c = 2\sin\sqrt x + c$.
Άσκηση 4Μέτρια
Να βρείτε το $\displaystyle\int x^2\sqrt{x^3 + 1}\,dx$.
Υπόδειξη: $u = x^3 + 1$, $du = 3x^2dx$.
Λύση: $\frac13\int u^{1/2}du = \frac13\cdot\frac23u^{3/2} + c = \frac29(x^3 + 1)^{3/2} + c$.
Άσκηση 5Μέτρια
Να βρείτε το $\displaystyle\int \cos^3x\sin x\,dx$.
Υπόδειξη: $u = \cos x$, $du = -\sin x\,dx$.
Λύση: $-\int u^3du = -\frac{u^4}{4} + c = -\frac{\cos^4x}{4} + c$.
Άσκηση 6Μέτρια
Να βρείτε το $\displaystyle\int \frac{x}{x^2 + 4}\,dx$.
Υπόδειξη: $u = x^2 + 4$, $du = 2x\,dx$.
Λύση: $\frac12\int\frac{du}{u} = \frac12\ln|u| + c = \frac12\ln(x^2 + 4) + c$ (αφού $x^2 + 4 > 0$).
Άσκηση 7Μέτρια
Να βρείτε το $\displaystyle\int \frac{(\ln x)^2}{x}\,dx$.
Υπόδειξη: $u = \ln x$, $du = \frac{dx}{x}$.
Λύση: $\int u^2du = \frac{u^3}{3} + c = \frac{(\ln x)^3}{3} + c$.
Άσκηση 8Απαιτητική
Να βρείτε το $\displaystyle\int \sin^3x\,dx$.
Υπόδειξη: $\sin^3x = \sin^2x\cdot\sin x = (1 - \cos^2x)\sin x$ και $u = \cos x$.
Λύση: $\int (1 - \cos^2x)\sin x\,dx = -\int (1 - u^2)\,du = -u + \frac{u^3}{3} + c = -\cos x + \frac{\cos^3x}{3} + c$.
Άσκηση 9Απαιτητική
Να βρείτε το $\displaystyle\int \frac{dx}{\sin^2x\cos^2x}$ για $0 < x < \frac\pi2$.
Υπόδειξη: $\sin x\cos x = \frac12\sin 2x$, άρα $\frac{1}{\sin^2x\cos^2x} = \frac{4}{\sin^2 2x}$.
Λύση: $4\int\csc^2(2x)\,dx = 2\int\csc^2(2x)\,d(2x) = -2\cot 2x + c$ (ισοδύναμα $\tan x - \cot x + c$).
Άσκηση 10Βασική
Ποια αντικατάσταση μετατρέπει το $\displaystyle\int \frac{e^x}{1 + e^x}\,dx$ σε $\int \frac{du}{u}$;
Υπόδειξη: Ποια ποσότητα έχει παράγωγο τον αριθμητή;
Λύση: Με $u = 1 + e^x$ είναι $du = e^x dx$, οπότε $\int\frac{du}{u} = \ln(1 + e^x) + c$.

♾️ Γεννήτρια — πρώτη μέθοδος αντικατάστασης

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε το $\displaystyle\int \cos^{3}x\sin x\,dx$.
Υπόδειξη: $u = \cos x$, $du = -\sin x\,dx$.
Λύση: $-\int u^{3}du = -\frac{\cos^{4}x}{4} + c$.
