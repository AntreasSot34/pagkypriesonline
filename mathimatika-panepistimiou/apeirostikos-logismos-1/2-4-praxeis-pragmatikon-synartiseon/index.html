2.4

Πράξεις πραγματικών συναρτήσεων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 2 §2.4 · Ασκήσεις 2ου κεφαλαίου (2.7, 2.8)

Προσθέτουμε, πολλαπλασιάζουμε, διαιρούμε συναρτήσεις «σημείο-σημείο» — αλλά προσοχή στο πεδίο ορισμού.

Θεωρία

2.4.1 · Άθροισμα, διαφορά, γινόμενο, πηλίκο

Για $f, g$ με πεδία ορισμού $A_f$, $A_g$:

$$(f \pm g)(x) = f(x) \pm g(x), \quad (f\cdot g)(x) = f(x)\,g(x), \quad \left(\frac fg\right)(x) = \frac{f(x)}{g(x)}.$$

Τα $f \pm g$, $f\cdot g$ έχουν πεδίο ορισμού την τομή $A_f \cap A_g$· το $\frac fg$ έχει $A_f \cap A_g - \{x : g(x) = 0\}$.

Παράδειγμα · $f(x) = 1 + \sqrt{x - 2}$, $g(x) = x - 1$

$A_f = [2, +\infty)$, $A_g = \mathbb{R}$. $(f + g)(x) = x + \sqrt{x - 2}$, $(f - g)(x) = 2 - x + \sqrt{x - 2}$, $(f\cdot g)(x) = (1 + \sqrt{x - 2})(x - 1)$ με πεδίο $[2, +\infty)$· και $\left(\frac fg\right)(x) = \frac{1 + \sqrt{x - 2}}{x - 1}$ με πεδίο $[2, +\infty) - \{1\} = [2, +\infty)$.

Το πεδίο ορισμού δεν «απλοποιείται»

$f(x) = 3\sqrt x$, $g(x) = \sqrt x$: $(f\cdot g)(x) = 3x$ με πεδίο $[0, +\infty)$, όχι $\mathbb{R}$! Ο τύπος $3x$ «ξεχνά» από πού προήλθε.

Αντίθετη, βαθμωτό γινόμενο, δυνάμεις

$(-f)(x) = -f(x)$ (συμμετρική ως προς τον άξονα $x$), $(\lambda f)(x) = \lambda f(x)$, $f^2 = f\cdot f$, $f^3 = f\cdot f^2$. Π.χ. για $f(x) = 8x$: $f^2(x) = 64x^2$. Προσοχή: $\sin^2 x = (\sin x)^2$.

Πειραματίσου

f(x) = √x, Df = [0, +∞) · g(x) = x² − 1, Dg = (−∞, +∞)
(f / g)(x) = (√x)/(x² − 1), πεδίο ορισμού D = [0, 1) ∪ (1, +∞)
D = Df ∩ Dg, αφαιρώντας τα x με g(x) = 0 (εδώ 1).

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Για $f(x) = 2x$ και $g(x) = x^2 + 1$ να βρείτε τα $(f + g)(3)$, $(f\cdot g)(1)$ και $\left(\frac fg\right)(2)$.
Υπόδειξη: Υπολογίστε τις τιμές χωριστά.
Λύση: $6 + 10 = 16$· $2 \cdot 2 = 4$· $\frac{4}{5}$.
Άσκηση 2Βασική
Για $f_1(x) = \sqrt{x - 2}$ και $f_2(x) = \sqrt{x - 3}$, το πεδίο ορισμού του $\frac{f_1}{f_2}$ είναι:
Υπόδειξη: Τομή των πεδίων χωρίς τις ρίζες του παρονομαστή.
Λύση: $A_{f_1} \cap A_{f_2} = [3, +\infty)$ και $f_2(3) = 0$, άρα $(3, +\infty)$.
Άσκηση 3Μέτρια
Για $f(x) = 3\sqrt x$ και $g(x) = \sqrt x$ ισχύει $(f\cdot g)(x) = 3x$ με πεδίο ορισμού $\mathbb{R}$.
Υπόδειξη: Ορίζεται το $f(-1)$;
Λύση: Λάθος: ο τύπος είναι $3x$, αλλά το πεδίο είναι $A_f \cap A_g = [0, +\infty)$.
Άσκηση 4Βασική
Για $f(x) = 8x$ να βρείτε τα $f^2(1)$ και $f^3\left(\frac12\right)$.
Υπόδειξη: $f^n(x) = (f(x))^n$.
Λύση: $f^2(1) = 8^2 = 64$, $f^3\left(\frac12\right) = 4^3 = 64$.
Άσκηση 5Μέτρια
Για $f(x) = \sqrt{1 - x^2}$ και $g(x) = \sin 3x$, το κοινό πεδίο ορισμού των $f + g$, $f\cdot g$ είναι $[\alpha, \beta]$. Να βρείτε τα $\alpha, \beta$ και την τιμή $(f\cdot g)(0)$.
Υπόδειξη: $1 - x^2 \ge 0$.
Λύση: $A_f = [-1, 1]$, $A_g = \mathbb{R}$, τομή $[-1, 1]$. $(f\cdot g)(0) = 1\cdot \sin 0 = 0$.
Άσκηση 6Μέτρια
Για $f(x) = \sqrt{3 - x}$ να υπολογίσετε την παράσταση $f(x^2) - [f(x)]^2$ στο $x = 1$ και την $f\!\left(\frac1x\right) - \frac{1}{f(x)}$ στο $x = \frac12$ (με τρία δεκαδικά).
Υπόδειξη: $f(1) = \sqrt2$, $f(2) = 1$, $f\left(\frac12\right) = \sqrt{\frac52}$.
Λύση: $f(x^2) - [f(x)]^2 = \sqrt{3 - x^2} - (3 - x)$· στο $x = 1$: $\sqrt2 - 2 \approx -0{,}586$.
Στο $x = \frac12$: $f(2) - \frac{1}{f(1/2)} = 1 - \sqrt{\frac25} \approx 1 - 0{,}632 = 0{,}368$.
Άσκηση 7Μέτρια
Το γράφημα της $-f$ προκύπτει από αυτό της $f$ με:
Υπόδειξη: Το σημείο $(x, y)$ γίνεται $(x, -y)$.
Λύση: $(-f)(x) = -f(x)$: κάθε σημείο $(x, y)$ πηγαίνει στο $(x, -y)$, συμμετρία ως προς τον άξονα $x$.
Άσκηση 8Απαιτητική
Για $f(x) = \dfrac{x + \sqrt x}{\sqrt x}$ (απλοποίηση) γράφουμε $f(x) = \sqrt x + c$. Να βρείτε το $c$ και το αριστερό άκρο $\alpha$ του πεδίου ορισμού $(\alpha, +\infty)$ της απλοποιημένης έκφρασης ώστε να ταυτίζεται με την αρχική.
Υπόδειξη: Διαιρέστε κάθε όρο με $\sqrt x$· πότε ορίζεται η αρχική;
Λύση: $\frac{x}{\sqrt x} + \frac{\sqrt x}{\sqrt x} = \sqrt x + 1$. Η αρχική ορίζεται για $x > 0$ (το $\sqrt x$ στον παρονομαστή), άρα $f(x) = \sqrt x + 1$ με πεδίο $(0, +\infty)$ — όχι $[0, +\infty)$.

♾️ Γεννήτρια — πράξεις συναρτήσεων

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Το πεδίο ορισμού της $\frac{f}{g}$, όπου $f(x) = \sqrt{x^2 + 1}$ και $g(x) = x + 6$, είναι $\mathbb R - \{\alpha\}$. Να βρείτε το $\alpha$.
Λύση: $D_f = D_g = \mathbb R$ ($x^2 + 1 > 0$). Εξαιρούμε τις ρίζες του παρονομαστή: $g(x) = 0 \iff x = -6$. Άρα $D = \mathbb R - \{-6\}$.
