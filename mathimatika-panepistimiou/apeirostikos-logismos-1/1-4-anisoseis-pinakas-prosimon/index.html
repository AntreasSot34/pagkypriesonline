1.4

Ανισώσεις – Πίνακας προσήμων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 1 §1.4 · 1η σειρά ασκήσεων (άσκ. 7, 12)

Πολλαπλασιάζουμε μια ανίσωση με κάτι που δεν ξέρουμε το πρόσημό του; Ποτέ — φτιάχνουμε πίνακα προσήμων.

Θεωρία

1.4.1 · Ιδιότητες ανισοτήτων

Για $x, y, z, w \in \mathbb{R}$:

  • $x < y$ και $y < w \Rightarrow x < w$,
  • $x < y \Rightarrow x \pm z < y \pm z$,
  • $x < y$ και $z > 0 \Rightarrow xz < yz$,   $x < y$ και $z < 0 \Rightarrow xz > yz$ (αλλάζει η φορά!),
  • $x < y$ και $z < w \Rightarrow x + z < y + w$,
  • αν $x, y$ ομόσημοι: $x < y \Rightarrow \frac1x > \frac1y$.

Παράδειγμα 1 · $\dfrac{2x - 3}{x + 2} < \dfrac13$

Λύση με πίνακα προσήμων (2ος τρόπος των σημειώσεων)

$\dfrac{2x-3}{x+2} - \dfrac13 < 0 \iff \dfrac{6x - 9 - x - 2}{3(x+2)} < 0 \iff \dfrac{5x - 11}{3(x + 2)} < 0 \iff (5x - 11)(x + 2) < 0$ (για $x \ne -2$).

Λύση: $x \in \left(-2, \frac{11}{5}\right)$.

Παράδειγμα 2 · $x^2 + 3x - 10 \ge 0$

$x^2 + 3x - 10 = (x + 5)(x - 2) \ge 0 \iff x \in (-\infty, -5] \cup [2, +\infty)$.

Συνηθισμένο λάθος

Στο $\frac2x < \frac{3}{x - 4}$ δεν κάνουμε «χιαστί»: τα $x$ και $x - 4$ μπορεί να είναι αρνητικά. Φέρνουμε όλα στο ένα μέλος, κάνουμε ομώνυμα και μελετούμε πρόσημο. (Λύση: $(-8, 0) \cup (4, +\infty)$.)

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Η λύση της ανίσωσης $x^2 + 3x - 10 \ge 0$ είναι:
Υπόδειξη: $(x + 5)(x - 2)$.
Λύση: Ρίζες $-5$ και $2$· το τριώνυμο (θετικός συντελεστής) είναι $\ge 0$ έξω από τις ρίζες: $(-\infty, -5] \cup [2, +\infty)$.
Άσκηση 2Βασική
Η λύση της ανίσωσης $(x - 3)(x + 4) < 0$ είναι διάστημα $(\alpha, \beta)$. Να βρείτε τα $\alpha, \beta$.
Υπόδειξη: Ετερόσημοι παράγοντες.
Λύση: Το γινόμενο είναι αρνητικό ανάμεσα στις ρίζες: $(-4, 3)$.
Άσκηση 3Μέτρια
Η λύση της $\dfrac{2x - 3}{x + 2} < \dfrac13$ είναι διάστημα $(\alpha, \beta)$. Να βρείτε τα $\alpha, \beta$.
Υπόδειξη: Μεταφέρετε το $\frac13$ και κάντε ομώνυμα.
Λύση: $\dfrac{5x - 11}{3(x + 2)} < 0 \iff (5x - 11)(x+2) < 0 \iff -2 < x < \frac{11}{5}$.
Άσκηση 4Μέτρια
Η λύση της $\dfrac{x}{8 - x} \ge -2$ είναι:
Υπόδειξη: $\frac{x}{8 - x} + 2 = \frac{16 - x}{8 - x}$.
Λύση: $\dfrac{x + 2(8 - x)}{8 - x} \ge 0 \iff \dfrac{16 - x}{8 - x} \ge 0$. Αριθμητής και παρονομαστής ομόσημοι: $x < 8$ (και οι δύο θετικοί) ή $x \ge 16$ (και οι δύο $\le 0$, με $x \ne 8$). Λύση $(-\infty, 8) \cup [16, +\infty)$.
Άσκηση 5Μέτρια
Η λύση της $\dfrac{2}{x} < \dfrac{3}{x + 4}$ είναι:
Υπόδειξη: $\frac2x - \frac{3}{x+4} = \frac{8 - x}{x(x+4)}$.
Λύση: $\dfrac{2(x+4) - 3x}{x(x+4)} < 0 \iff \dfrac{8 - x}{x(x + 4)} < 0$. Κρίσιμα σημεία $-4, 0, 8$. Πρόσημα: για $x < -4$: $\frac{+}{+} > 0$· για $-4 < x < 0$: $\frac{+}{-} < 0$ ✓· για $0 < x < 8$: $\frac{+}{+} > 0$· για $x > 8$: $\frac{-}{+} < 0$ ✓. Λύση $(-4, 0) \cup (8, +\infty)$.
Άσκηση 6Βασική
Αν $x < y$ και $z < 0$, τότε:
Υπόδειξη: Πολλαπλασιασμός με αρνητικό.
Λύση: Ο πολλαπλασιασμός με αρνητικό αριθμό αντιστρέφει τη φορά: $xz > yz$. (Το ίδιο και η διαίρεση: $\frac xz > \frac yz$.)
Άσκηση 7Μέτρια
Να βρείτε τα $x$ που ικανοποιούν $-1 < \dfrac{3x + 4}{x - 6} < 1$. Η λύση είναι διάστημα $(\alpha, \beta)$.
Υπόδειξη: Λύστε χωριστά τις δύο ανισώσεις και πάρτε τομή.
Λύση: $\dfrac{3x+4}{x-6} < 1 \iff \dfrac{2x + 10}{x - 6} < 0 \iff -5 < x < 6$. $\ \dfrac{3x + 4}{x - 6} > -1 \iff \dfrac{4x - 2}{x - 6} > 0 \iff x < \frac12$ ή $x > 6$. Τομή: $\left(-5, \frac12\right)$.
Άσκηση 8Απαιτητική
Η λύση της $x^3 - x^2 - x - 2 > 0$ είναι:
Υπόδειξη: Το $x = 2$ είναι ρίζα.
Λύση: $x^3 - x^2 - x - 2 = (x - 2)(x^2 + x + 1)$ και $x^2 + x + 1 > 0$ για κάθε $x$ (διακρίνουσα $-3 < 0$). Άρα το πρόσημο είναι αυτό του $x - 2$: λύση $(2, +\infty)$.

♾️ Γεννήτρια — ανισώσεις με πίνακα προσήμων

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να λύσετε την ανίσωση $\dfrac{x + 3}{x - 2} \ge 0$. Η λύση είναι της μορφής $x \le \alpha$ ή $x > \beta$· δώστε τα $\alpha, \beta$.
Λύση: Κρίσιμα σημεία $-3$ (ρίζα αριθμητή, περιλαμβάνεται λόγω $\ge$) και $2$ (ρίζα παρονομαστή, εξαιρείται). Το κλάσμα είναι $+$ για $x < -3$, $-$ στο $(-3, 2)$, $+$ για $x > 2$. Λύση: $(-\infty, -3] \cup (2, +\infty)$.
