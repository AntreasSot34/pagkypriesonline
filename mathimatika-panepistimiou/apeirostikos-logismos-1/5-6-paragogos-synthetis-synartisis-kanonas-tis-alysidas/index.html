5.6

Παράγωγος σύνθετης συνάρτησης – Κανόνας της αλυσίδας

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 5 §5.6 (σελ. 5.25–5.30) · Πίνακας 1 · Προβλήματα 5.22, 5.25, 5.51

Όταν μια συνάρτηση είναι «μέσα» σε άλλη, οι ρυθμοί μεταβολής πολλαπλασιάζονται.

Θεωρία

5.6.1 · Κανόνας της αλυσίδας

Αν η $g$ είναι παραγωγίσιμη στο $x$ και η $f$ είναι παραγωγίσιμη στο $g(x)$, τότε η σύνθεσή τους $(f\circ g)(x) = f(g(x))$ είναι παραγωγίσιμη στο $x$ και

$$\big[f(g(x))\big]' = f'(g(x))\,g'(x).$$

Με $u = g(x)$ και $y = f(u)$ ο τύπος γράφεται (συμβολισμός Leibniz)

$$\frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx}.$$

Για τρεις συναρτήσεις $y = f(g(h(x)))$, με $v = h(x)$, $u = g(v)$: $\ \frac{dy}{dx} = \frac{dy}{du}\frac{du}{dv}\frac{dv}{dx}$.

Γενικευμένοι τύποι (Πίνακας 1)

$\frac{d}{dx}u^n = nu^{n - 1}\frac{du}{dx}$, $\ \frac{d}{dx}\sin u = \cos u\frac{du}{dx}$, $\ \frac{d}{dx}\cos u = -\sin u\frac{du}{dx}$, $\ \frac{d}{dx}e^u = e^u\frac{du}{dx}$, $\ \frac{d}{dx}\ln u = \frac1u\frac{du}{dx}$, $\ \frac{d}{dx}a^u = a^u\ln a\frac{du}{dx}$.

Παραδείγματα

(1) $y = \sin(x^2 + 5x + 1)$: $\ u = x^2 + 5x + 1$, $\frac{dy}{dx} = \cos u\cdot(2x + 5) = (2x + 5)\cos(x^2 + 5x + 1)$.

(2) $y = \sqrt{x^2 + 1}$: $\ \frac{dy}{dx} = \frac{1}{2\sqrt u}\cdot 2x = \frac{x}{\sqrt{x^2 + 1}}$.

(3) $y = [\sin(x^2 + 1)]^3$ με τρεις συναρτήσεις

$y = u^3$, $u = \sin v$, $v = x^2 + 1$: $\ \frac{dy}{dx} = 3u^2\cdot\cos v\cdot 2x = 6x\sin^2(x^2 + 1)\cos(x^2 + 1)$.

(4) $y = \ln(\cos^2\sqrt x)$

$\frac{dy}{dx} = \frac{1}{\cos^2\sqrt x}\cdot 2\cos\sqrt x\cdot(-\sin\sqrt x)\cdot\frac{1}{2\sqrt x} = -\frac{\tan\sqrt x}{\sqrt x}$.

Άρτιες και περιττές συναρτήσεις

Από την αλυσίδα: $\frac{d}{dx}f(-x) = -f'(-x)$. Αν η $f$ είναι άρτια ($f(-x) = f(x)$), παραγωγίζοντας: $-f'(-x) = f'(x)$, δηλαδή η $f'$ είναι περιττή· αν η $f$ είναι περιττή, η $f'$ είναι άρτια.

Πειραματίσου

Το διάστημα μήκους Δx «τεντώνεται» κατά Δu/Δx ≈ 1,9 (g′(x) = 1,75) και μετά κατά Δy/Δu ≈ 0,613 (f′(u) = 0,721).
Συνολικά Δy/Δx = (Δy/Δu)(Δu/Δx) ≈ 1,165 → dy/dx = f′(g(x))·g′(x) = 1,262 στο x = 0,875.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να βρείτε την παράγωγο της $y = \sin(x^2 + 5x + 1)$.
Υπόδειξη: $u = x^2 + 5x + 1$.
Λύση: $y' = \cos(x^2 + 5x + 1)\cdot(2x + 5)$.
Άσκηση 2Βασική
Να βρείτε την παράγωγο της $y = \sqrt{x^2 + 1}$ (γράψτε π.χ. x/sqrt(x^2+1)).
Υπόδειξη: $\frac{d}{dx}\sqrt u = \frac{1}{2\sqrt u}\frac{du}{dx}$.
Λύση: $y' = \dfrac{2x}{2\sqrt{x^2 + 1}} = \dfrac{x}{\sqrt{x^2 + 1}}$.
Άσκηση 3Μέτρια
Για $y = (x^2 + 2x + 3)^{5/3}$ να υπολογίσετε την $y'(0)$ (δεκαδικός, 3 ψηφία).
Υπόδειξη: $\frac{dy}{dx} = \frac53(x^2 + 2x + 3)^{2/3}(2x + 2)$.
Λύση: $y'(0) = \frac53\cdot 3^{2/3}\cdot 2 = \frac{10}{3}\sqrt[3]9 \approx 6{,}934$.
Άσκηση 4Μέτρια
Για $y = [\sin(x^2 + 1)]^3$ να υπολογίσετε την $y'(1)$ (δεκαδικός, 3 ψηφία).
Υπόδειξη: $y' = 6x\sin^2(x^2 + 1)\cos(x^2 + 1)$.
Λύση: $y'(1) = 6\sin^2 2\cos 2 \approx 6\cdot0{,}8268\cdot(-0{,}4161) \approx -2{,}064$.
Άσκηση 5Απαιτητική
Να βρείτε την παράγωγο της $y = \ln(\cos^2\sqrt x)$ για $0 < x < \frac{\pi^2}{4}$.
Υπόδειξη: Τρία «στρώματα»: $\ln$, τετράγωνο, $\cos\sqrt x$.
Λύση: $y' = \dfrac{1}{\cos^2\sqrt x}\cdot 2\cos\sqrt x\cdot(-\sin\sqrt x)\cdot\dfrac{1}{2\sqrt x} = -\dfrac{\tan\sqrt x}{\sqrt x}$.
Άσκηση 6Βασική
Η παράγωγος μιας παραγωγίσιμης άρτιας συνάρτησης είναι:
Υπόδειξη: Παραγωγίστε την $f(-x) = f(x)$ με την αλυσίδα.
Λύση: $\frac{d}{dx}f(-x) = -f'(-x)$, άρα $-f'(-x) = f'(x)$: η $f'$ είναι περιττή.
Άσκηση 7Μέτρια
Αν $\dfrac{d}{dx}\big[f(3x)\big] = 6x$, να βρείτε την $f'(3)$.
Υπόδειξη: Με $u = 3x$: $\frac{d}{dx}f(3x) = 3f'(u)$.
Λύση: $3f'(u) = 6x = 2u$, άρα $f'(u) = \frac23u$ και $f'(3) = 2$.
Άσκηση 8Μέτρια
Αν $f'(x) = \sqrt{3x + 4}$, $g(x) = x^2 - 1$ και $F(x) = f(g(x))$, να υπολογίσετε την $F'(1)$ (Πρόβλημα 5.25).
Υπόδειξη: $F'(x) = f'(g(x))\,g'(x)$.
Λύση: $F'(x) = \sqrt{3(x^2 - 1) + 4}\cdot 2x = 2x\sqrt{3x^2 + 1}$, άρα $F'(1) = 2\cdot2 = 4$.
Άσκηση 9Μέτρια
Αν $\dfrac{d f(x)}{dx} = \dfrac1x$ και $y = f(\sin x)$, να υπολογίσετε το $\dfrac{dy}{dx}$ στο $x = \frac\pi4$ (Πρόβλημα 5.51).
Υπόδειξη: $\frac{dy}{dx} = f'(\sin x)\cos x$.
Λύση: $\frac{dy}{dx} = \frac{1}{\sin x}\cos x = \cot x$, στο $\frac\pi4$: $1$.
Άσκηση 10Βασική
Για $f(x) = \cos^5x$ να υπολογίσετε την $f'(\frac\pi2)$ και την $f'(0)$.
Υπόδειξη: $\frac{d}{dx}\cos^nx = -n\cos^{n - 1}x\sin x$.
Λύση: $f'(x) = -5\cos^4x\sin x$: στο $\frac\pi2$ ο $\cos$ μηδενίζεται, στο $0$ ο $\sin$· και οι δύο τιμές είναι $0$.

♾️ Γεννήτρια — κανόνας της αλυσίδας

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε την $f'(2)$ για $f(x) = (2x - 2)^{3}$.
Λύση: $f'(x) = 3(2x - 2)^{2}\cdot 2$, άρα $f'(2) = 3\cdot 2^{2}\cdot 2 = 24$.
