2.5

Ειδικές συναρτήσεις: πολυώνυμα, ρητές, αλγεβρικές, υπερβατικές

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 2 §2.5

Ένας «κατάλογος» των συναρτήσεων που θα μελετήσουμε σε όλο το μάθημα.

Θεωρία

Σταθερές – μονώνυμα – πολυώνυμα

Σταθερή: $f(x) = a$.   Μονώνυμο βαθμού $n$: $f(x) = cx^n$ με $n$ μη αρνητικό ακέραιο (π.χ. $2x^3$, $\pi x^7$, $4x^0 = 4$· όχι τα $4x^{1/2}$, $x^{-3}$).   Πολυώνυμο: άθροισμα πεπερασμένου πλήθους μονωνύμων,

$$P_n(x) = a_n x^n + a_{n-1}x^{n-1} + \dots + a_1 x + a_0, \qquad n = \text{βαθμός } (a_n \ne 0).$$

Ρητές – αλγεβρικές

Ρητή: $f(x) = \frac{P(x)}{Q(x)}$ με $P, Q$ πολυώνυμα, ορισμένη όπου $Q(x) \ne 0$.  Αλγεβρική: ικανοποιεί εξίσωση $P(x)y^m + Q(x)y^{m-1} + \dots + V(x) = 0$ με πολυωνυμικούς συντελεστές· π.χ. $y = \sqrt x$ (αφού $y^2 - x = 0$) και γενικά $y = x^{m/n}$.

Υπερβατικές

Όσες δεν είναι αλγεβρικές. Οι σημαντικότερες: εκθετικές $a^x$, λογαριθμικές $\log_a x$ ($\ln x = \log_e x$), τριγωνομετρικές, αντίστροφες τριγωνομετρικές ($\sin^{-1}x, \dots$), υπερβολικές $\sinh x = \frac{e^x - e^{-x}}{2}$, $\cosh x = \frac{e^x + e^{-x}}{2}$, και οι αντίστροφες υπερβολικές.

Ταξινόμηση

Πολυώνυμα ⊂ ρητές ⊂ αλγεβρικές. Οι $e^x$, $\ln x$, $\sin x$ δεν είναι αλγεβρικές (υπερβατικές).

Πειραματίσου

y = x3: περιττή, γνησίως αύξουσα, D = ℝ

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Ποια από τις παρακάτω είναι μονώνυμο;
Υπόδειξη: Εκθέτης μη αρνητικός ακέραιος, ένας όρος.
Λύση: $\pi x^7$: σταθερά επί $x^7$. Οι $x^{1/2}$, $x^{-3}$ δεν έχουν μη αρνητικό ακέραιο εκθέτη· το $x^2 + 1$ έχει δύο όρους.
Άσκηση 2Βασική
Ποιος είναι ο βαθμός του πολυωνύμου $P(x) = 1 - x + 3x^3 - 5x^2$ και ποιος ο σταθερός όρος $a_0$;
Υπόδειξη: Μεγαλύτερη δύναμη του $x$.
Λύση: Η μεγαλύτερη δύναμη είναι $x^3$: βαθμός $3$· σταθερός όρος $1$.
Άσκηση 3Βασική
Η συνάρτηση $y = x^{2/3}$ είναι:
Υπόδειξη: $y^3 = x^2$.
Λύση: Ικανοποιεί $y^3 - x^2 = 0$, εξίσωση με πολυωνυμικούς συντελεστές: αλγεβρική (όχι πολυώνυμο, αφού ο εκθέτης δεν είναι ακέραιος).
Άσκηση 4Βασική
Να υπολογίσετε τα $\sinh 0$, $\cosh 0$ και $\cosh^2 1 - \sinh^2 1$.
Υπόδειξη: Ορισμοί με εκθετικά· $(\cosh x - \sinh x)(\cosh x + \sinh x) = e^{-x} e^{x}$.
Λύση: $\sinh 0 = \frac{1 - 1}{2} = 0$, $\cosh 0 = 1$. Γενικά $\cosh^2x - \sinh^2x = (\cosh x - \sinh x)(\cosh x + \sinh x) = e^{-x}e^{x} = 1$.
Άσκηση 5Μέτρια
Να υπολογίσετε τα $\sinh(\ln 2)$ και $\cosh(\ln 2)$.
Υπόδειξη: $e^{\ln 2} = 2$, $e^{-\ln 2} = \frac12$.
Λύση: $\sinh(\ln2) = \frac{2 - \frac12}{2} = \frac34$, $\cosh(\ln 2) = \frac{2 + \frac12}{2} = \frac54$.
Άσκηση 6Μέτρια
Η ρητή συνάρτηση $f(x) = \dfrac{x^2 - 4}{x^2 - 5x + 6}$ δεν ορίζεται στα σημεία:
Υπόδειξη: Ρίζες του παρονομαστή.
Λύση: $x^2 - 5x + 6 = (x - 2)(x - 3)$: εξαιρούνται τα $2$ και $3$. (Το ότι ο αριθμητής μηδενίζεται στο $2$ δεν αλλάζει το πεδίο ορισμού.)
Άσκηση 7Βασική
Η συνάρτηση $f(x) = \ln x$ είναι αλγεβρική.
Υπόδειξη: Κατηγορίες των σημειώσεων.
Λύση: Λάθος: η λογαριθμική είναι υπερβατική συνάρτηση.
Άσκηση 8Απαιτητική
Για ποια τιμή του $x$ ισχύει $\sinh x = \frac34$; (Λύστε την $e^{2x} - \frac32 e^x - 1 = 0$ ως προς $u = e^x > 0$.) Δώστε το $e^x$ και το $x$ με τρία δεκαδικά.
Υπόδειξη: $e^x - e^{-x} = \frac32$, πολλαπλασιάστε με $e^x$.
Λύση: $u - \frac1u = \frac32 \Rightarrow u^2 - \frac32u - 1 = 0 \Rightarrow u = 2$ ή $u = -\frac12$ (απορρίπτεται). Άρα $e^x = 2$, $x = \ln 2 \approx 0{,}693$.
