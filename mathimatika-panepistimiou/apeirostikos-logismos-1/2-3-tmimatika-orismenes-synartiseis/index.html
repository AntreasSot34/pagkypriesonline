2.3

Τμηματικά ορισμένες συναρτήσεις

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 2 §2.3 · Ασκήσεις 2ου κεφαλαίου (2.1, 2.3, 2.14)

Διαφορετικός τύπος σε κάθε κομμάτι του πεδίου ορισμού: η απόλυτη τιμή, οι φορολογικές κλίμακες, τα τιμολόγια.

Θεωρία

Τμηματικά ορισμένη συνάρτηση

Συναρτήσεις που ορίζονται με διαφορετικούς τύπους σε διάφορα υποδιαστήματα του πεδίου ορισμού τους. Π.χ. η $|x|$ είναι τμηματικά ορισμένη: $|x| = -x$ για $x < 0$ και $|x| = x$ για $x \ge 0$.

Απαλοιφή απόλυτων · $f(x) = |x - 5| - |x - 3|$

Πίνακας περιπτώσεων
$x$$x - 5$$x - 3$$f(x)$
$x \le 3$$-$$-$$-x + 5 + x - 3 = 2$
$3 \le x \le 5$$-$$+$$-x + 5 - x + 3 = -2x + 8$
$x \ge 5$$+$$+$$x - 5 - x + 3 = -2$

Από το γράφημα στον τύπο

Αν το γράφημα αποτελείται από την ευθεία μέσα από τα $(-2, 0)$, $(0, -1)$ για $x \le 0$ και από την ευθεία κλίσης $1$ μέσα από το $(0, -1)$ για $x \ge 0$, τότε $f(x) = -\frac x2 - 1$ για $x \le 0$ και $f(x) = x - 1$ για $x \ge 0$.

Προσοχή στα άκρα

Κάθε $x$ πρέπει να ανήκει σε έναν κλάδο (ή σε δύο που δίνουν την ίδια τιμή, όπως το $x = 1$ παραπάνω). Αλλιώς η «συνάρτηση» δεν είναι μονοσήμαντη.

Πειραματίσου

x + 2x < 0
x²0 ≤ x ≤ 2
6 − xx > 2
x₀ = 1 ικανοποιεί τη συνθήκη «0 ≤ x ≤ 2» ⇒ f(1) = (1)² = 1
Κενός κύκλος: το σημείο δεν ανήκει στη γραφική παράσταση· γεμάτος: ανήκει. Σε κάθε x αντιστοιχεί ακριβώς ένας κλάδος.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Για $f(x) = |x - 5| - |x - 3|$ να βρείτε τα $f(0)$, $f(4)$ και $f(10)$.
Υπόδειξη: Κάθε τιμή στον κατάλληλο κλάδο.
Λύση: $f(0) = 5 - 3 = 2$, $f(4) = 1 - 1 = 0$, $f(10) = 5 - 7 = -2$.
Άσκηση 2Βασική
Η $f(x) = |x| + 3x + 1$ γράφεται $f(x) = \alpha x + 1$ για $x < 0$ και $f(x) = \beta x + 1$ για $x \ge 0$. Να βρείτε τα $\alpha, \beta$.
Υπόδειξη: $|x| = -x$ για $x < 0$.
Λύση: $x < 0$: $-x + 3x + 1 = 2x + 1$. $x \ge 0$: $x + 3x + 1 = 4x + 1$.
Άσκηση 3Μέτρια
Η $g(x) = |x| + |x - 1|$ είναι σταθερή σε ένα διάστημα $[\alpha, \beta]$ με τιμή $c$. Να βρείτε τα $\alpha, \beta, c$.
Υπόδειξη: Για $0 \le x \le 1$: $x + (1 - x)$.
Λύση: $x < 0$: $1 - 2x$· $0 \le x \le 1$: $x + 1 - x = 1$· $x > 1$: $2x - 1$. Σταθερή $= 1$ στο $[0, 1]$.
Άσκηση 4Μέτρια
Η $f(x) = 3 + |2x - 5|$ έχει ελάχιστη τιμή $m$ στο σημείο $x_0$. Να βρείτε τα $x_0, m$ καθώς και το $f(0)$.
Υπόδειξη: Το απόλυτο μηδενίζεται στο $\frac52$.
Λύση: $|2x - 5| \ge 0$ με ισότητα στο $x_0 = \frac52$, άρα $m = 3$. $f(0) = 3 + 5 = 8$.
Άσκηση 5Βασική
Με συντελεστή φορολογίας $0$ για εισόδημα έως $2000$, $0{,}2$ για $2000 < x \le 10000$ και $0{,}4$ για $x > 10000$, ποιος είναι ο συντελεστής για εισόδημα $10000$;
Υπόδειξη: Σε ποιο υποδιάστημα ανήκει το $10000$;
Λύση: $10000 \in (2000, 10000]$, άρα $0{,}2$. Το $0{,}4$ ισχύει μόνο για $x > 10000$.
Άσκηση 6Μέτρια
Η $g(x) = 3|x - 2| - |x + 1|$ για $x \ge 2$ γράφεται $g(x) = \alpha x + \beta$. Να βρείτε τα $\alpha, \beta$ και το $g(-3)$.
Υπόδειξη: Για $x \ge 2$ και τα δύο απόλυτα είναι μη αρνητικά.
Λύση: $x \ge 2$: $3(x - 2) - (x + 1) = 2x - 7$. $g(-3) = 3\cdot 5 - |-2| = 15 - 2 = 13$.
Άσκηση 7Μέτρια
Ποια συνάρτηση έχει γράφημα την ευθεία μέσα από τα $(-2, 0)$ και $(0, -1)$ για $x \le 0$ και την ευθεία με κλίση $1$ μέσα από το $(0, -1)$ για $x \ge 0$;
Υπόδειξη: Κλίση από $(-2,0)$ σε $(0,-1)$: $\frac{-1 - 0}{0 + 2}$.
Λύση: Κλίση $-\frac12$ και τεταγμένη $-1$: $y = -\frac x2 - 1$. Δεξιά $y = x - 1$. (Η $|x| - 1$ θα είχε κλίση $-1$ αριστερά.)
Άσκηση 8Απαιτητική
Η $g(x) = 3|x - 2| - |x + 1|$ έχει ελάχιστη τιμή $m$. Να βρείτε το σημείο $x_0$ όπου πετυχαίνεται και το $m$.
Υπόδειξη: Κλάδοι: $x < -1$, $-1 \le x < 2$, $x \ge 2$.
Λύση: $x < -1$: $3(2 - x) + (x + 1) = -2x + 7$ (φθίνουσα). $-1 \le x < 2$: $3(2 - x) - (x + 1) = -4x + 5$ (φθίνουσα). $x \ge 2$: $2x - 7$ (αύξουσα). Ελάχιστο στο $x_0 = 2$: $m = -3$.

♾️ Γεννήτρια — τμηματικά ορισμένες

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Δίνεται $f(x) = \begin{cases} 3x + 2, & x < -2 \\ x^2 + 2, & x \ge -2 \end{cases}$. Να υπολογίσετε τα $f(-4)$, $f(-2)$, $f(1)$.
Λύση: $-4 < -2$: πρώτος κλάδος, $f(-4) = -10$. Για $x = -2$ ισχύει $x \ge -2$: δεύτερος κλάδος, $f(-2) = 6$. Για $1$: $f(1) = 3$.
