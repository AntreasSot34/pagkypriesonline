10.3

Ο φυσικός λογάριθμος (ln x)

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 10 §10.3 · 10η σειρά ασκήσεων

Ορίζουμε τον $\ln x$ ως ένα εμβαδόν — και από τον ορισμό αυτό βγαίνουν αμέσως όλες οι ιδιότητές του και η παράγωγος $\frac1x$.

Θεωρία

Φυσικός λογάριθμος

Ο φυσικός λογάριθμος, $\ln x$, ορίζεται από τον τύπο

$\displaystyle \ln x = \int_1^x \frac{dt}{t}, \qquad x > 0.$

Για $x > 1$ είναι το εμβαδόν κάτω από την $y = \frac1t$ από το $1$ έως το $x$· για $0 < x < 1$ είναι το αντίθετο του εμβαδού από το $x$ έως το $1$.

$\frac12 < \ln 2 < 1$

$\ln 2 = \int_1^2\frac{dt}{t}$. Στο $[1, 2]$ ισχύει $\frac12 \le \frac1t \le 1$, άρα $(2 - 1)\cdot\frac12 < \int_1^2\frac{dt}{t} < (2 - 1)\cdot 1$.

Ιδιότητες

Ο $\ln$ έχει όλες τις ιδιότητες των λογαρίθμων (§10.2). Για παράδειγμα:

Απόδειξη ότι $\ln(a\beta) = \ln a + \ln\beta$

Με $x = au$, $dx = a\,du$: $\int_a^{a\beta}\frac{dx}{x} = \int_1^\beta\frac{a\,du}{au} = \int_1^\beta\frac{du}{u}$. Άρα $\ln a\beta = \int_1^{a\beta}\frac{dx}{x} = \int_1^a\frac{dx}{x} + \int_a^{a\beta}\frac{dx}{x} = \ln a + \ln\beta$.

Παράγωγος του $\ln$

Από τον ορισμό και το θεμελιώδες θεώρημα του Λογισμού:

$\displaystyle \frac{d}{dx}\ln x = \frac1x\ (x > 0), \qquad \frac{d}{dx}\ln|x| = \frac1x\ (x \ne 0), \qquad \frac{d}{dx}\ln u = \frac1u\frac{du}{dx}\ (u > 0).$

Αντίστροφα: $\displaystyle\int\frac{dx}{x} = \ln|x| + c$ και, γενικότερα, $\displaystyle\int\frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + c$.

Παραδείγματα

(i) $y = \ln(x\ln x)$: $u = x\ln x$, $u' = \ln x + 1$, άρα $y' = \frac{\ln x + 1}{x\ln x}$.

(ii) $\int\cot x\,dx = \int\frac{(\sin x)'}{\sin x}dx = \ln|\sin x| + c$ · $\ \int\frac{dx}{x\ln x} = \int\frac{(\ln x)'}{\ln x}dx = \ln|\ln x| + c$.

Λογαριθμική παραγώγιση

Για γινόμενα, πηλίκα και δυνάμεις της μορφής $f(x)^{g(x)}$ λογαριθμίζουμε πρώτα και μετά παραγωγίζουμε. Π.χ. $y = x^{\sqrt x}$: $\ln y = \sqrt x\ln x \Rightarrow \frac{y'}{y} = \frac{\ln x}{2\sqrt x} + \frac{1}{\sqrt x}$, άρα $y' = x^{\sqrt x}\left(\frac{1}{\sqrt x} + \frac{\ln x}{2\sqrt x}\right)$.

Πειραματίσου

$\ln x = \displaystyle\int_1^x \frac{dt}{t}$ = 1,1362
Η κλίση της $\ln$ στο x είναι το ύψος της 1/t εκεί: $(\ln x)' = \frac1x$ = 0,321.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Αν $y = \ln(x\ln x)$, να βρείτε το $y'(e)$ (4 δεκαδικά).
Υπόδειξη: $y' = \frac{\ln x + 1}{x\ln x}$.
Λύση: $y'(e) = \frac{1 + 1}{e\cdot 1} = \frac2e \approx 0{,}7358$.
Άσκηση 2Βασική
Να βρείτε την παράγωγο της $y = \ln|x^3 - 7x^2 - 3|$.
Υπόδειξη: $(\ln|u|)' = \frac{u'}{u}$.
Λύση: $y' = \frac{3x^2 - 14x}{x^3 - 7x^2 - 3}$.
Άσκηση 3Βασική
Να υπολογίσετε το $\displaystyle\int\cot x\,dx$ στο $(0, \pi)$.
Υπόδειξη: $\cot x = \frac{(\sin x)'}{\sin x}$.
Λύση: $\int\frac{\cos x}{\sin x}dx = \ln|\sin x| + c = \ln(\sin x) + c$ στο $(0, \pi)$.
Άσκηση 4Βασική
Να υπολογίσετε το $\displaystyle\int\frac{5x^4}{x^5 + 1}\,dx$ για $x > 0$.
Υπόδειξη: $\int\frac{f'}{f} = \ln|f| + c$.
Λύση: Ο αριθμητής είναι η παράγωγος του παρονομαστή: $\ln(x^5 + 1) + c$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{dx}{x\ln x}$ για $x > 1$.
Υπόδειξη: $\frac{1}{x\ln x} = \frac{(\ln x)'}{\ln x}$.
Λύση: $\ln|\ln x| + c = \ln(\ln x) + c$ για $x > 1$.
Άσκηση 6Μέτρια
Με λογαριθμική παραγώγιση, να βρείτε το $y'(4)$ για $y = x^{\sqrt x}$ (3 δεκαδικά).
Υπόδειξη: $\ln y = \sqrt x\ln x$.
Λύση: $\frac{y'}{y} = \frac{\ln x}{2\sqrt x} + \frac{1}{\sqrt x}$. Στο $x = 4$: $y = 4^2 = 16$ και $\frac{y'}{y} = \frac{\ln 4}{4} + \frac12$, οπότε $y'(4) = 16\left(\frac12 + \frac{\ln 4}{4}\right) = 8 + 4\ln 4 \approx 13{,}545$.
Άσκηση 7Μέτρια
Να υπολογίσετε το $\displaystyle\int_1^4\frac{3}{1 - 2x}\,dx$ (4 δεκαδικά).
Υπόδειξη: $\int\frac{dx}{1 - 2x} = -\frac12\ln|1 - 2x| + c$.
Λύση: $-\frac32\Big[\ln|1 - 2x|\Big]_1^4 = -\frac32(\ln 7 - \ln 1) = -\frac32\ln 7 \approx -2{,}9189$.
Άσκηση 8Βασική
Η παράγωγος της $y = \ln|x|$, $x \ne 0$, είναι:
Υπόδειξη: Για $x < 0$: $\ln|x| = \ln(-x)$.
Λύση: Για $x > 0$: $(\ln x)' = \frac1x$. Για $x < 0$: $(\ln(-x))' = \frac{1}{-x}(-1) = \frac1x$. Άρα πάντα $\frac1x$.
Άσκηση 9Απαιτητική
Η $y = \dfrac{\sqrt[3]{x^4 + 6x^2}\,(8x + 3)^5}{(2x^2 + 7)^{2/3}}$ έχει παράγωγο $y' = y\cdot g(x)$. Με λογαριθμική παραγώγιση, να βρείτε το $g(1)$ (4 δεκαδικά).
Υπόδειξη: $\ln|y| = \frac13\ln(x^4 + 6x^2) + 5\ln|8x + 3| - \frac23\ln(2x^2 + 7)$.
Λύση: $g(x) = \frac{4x^3 + 12x}{3(x^4 + 6x^2)} + \frac{40}{8x + 3} - \frac{8x}{3(2x^2 + 7)}$. Στο $x = 1$: $\frac{16}{21} + \frac{40}{11} - \frac{8}{27} \approx 0{,}7619 + 3{,}6364 - 0{,}2963 = 4{,}1020$.

♾️ Γεννήτρια — παράγωγος του ln και λογαριθμική παραγώγιση

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Αν $y = \ln(x^2 + 1)$, να βρείτε το $y'(1)$ (ακριβές κλάσμα ή δεκαδικός).
Υπόδειξη: $(\ln u)' = \frac{u'}{u}$· για $f^g$ πάρτε λογάριθμο και παραγωγίστε πεπλεγμένα.
Λύση: $y' = \frac{(x^2 + 1)'}{x^2 + 1} = \frac{2x}{x^2 + 1}$, οπότε $y'(1) = \frac{2}{2} = 1$.
