1.7.5

Κύκλος και παραβολή

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 1 §1.7.5, §1.7.6 · 1η σειρά ασκήσεων (άσκ. 24–27)

Δύο καμπύλες που θα συναντάμε συνέχεια: από την εξίσωση στο κέντρο, την ακτίνα και την κορυφή.

Θεωρία

Κύκλος

Κύκλος είναι ο γεωμετρικός τόπος των σημείων που απέχουν σταθερή απόσταση $R$ (ακτίνα) από σταθερό σημείο $K(x_0, y_0)$ (κέντρο):

$$(x - x_0)^2 + (y - y_0)^2 = R^2, \qquad \text{και για κέντρο } O:\ x^2 + y^2 = R^2.$$

1.7.5.1 · Γενική εξίσωση κύκλου $x^2 + y^2 + Ax + By + \Gamma = 0$

  • Αν $A^2 + B^2 - 4\Gamma > 0$: κύκλος με κέντρο $K\left(-\frac A2, -\frac B2\right)$ και ακτίνα $R = \dfrac{\sqrt{A^2 + B^2 - 4\Gamma}}{2}$.
  • Αν $A^2 + B^2 - 4\Gamma = 0$: μόνο το σημείο $K\left(-\frac A2, -\frac B2\right)$.
  • Αν $A^2 + B^2 - 4\Gamma < 0$: καμία λύση.

Παραμετρικές εξισώσεις: $x = x_0 + R\cos\theta$, $\ y = y_0 + R\sin\theta$, $\ 0 \le \theta < 2\pi$.

1.7.6 · Παραβολή

$y = a(x - x_0)^2 + y_0$: κορυφή $(x_0, y_0)$, συμμετρική ως προς την $x = x_0$. Η γενική $y = Ax^2 + Bx + \Gamma$ ($A \ne 0$) γράφεται

$$y = A\left(x + \frac{B}{2A}\right)^2 + \left(\Gamma - \frac{B^2}{4A}\right) \ \Rightarrow\ \text{κορυφή } K\left(-\frac{B}{2A},\ \Gamma - \frac{B^2}{4A}\right).$$

Τι παριστάνουν;

(α) $x^2 + y^2 - 2x - 4y - 11 = 0$: $A^2 + B^2 - 4\Gamma = 4 + 16 + 44 = 64 > 0$ → κύκλος, κέντρο $(1, 2)$, $R = 4$.  (β) $x^2 + y^2 + 2x + 2y + 2 = 0$: $= 0$ → μόνο το σημείο $(-1, -1)$.  (γ) $x^2 + y^2 + 10y + 26 = 0$: $= -4 < 0$ → κενό.

Κορυφή της $y = 3x^2 - 2x + 1$: $3\left(x - \frac13\right)^2 + \frac23$ → $\left(\frac13, \frac23\right)$.

Πειραματίσου

A² + B² − 4Γ = 36 > 0 ⇒ κύκλος, κέντρο K(−A/2, −B/2) = (1, 2), ακτίνα R = √36/2 ≈ 3
Παραμετρικά: x = 1 + R·cosθ, y = 2 + R·sinθ (θ = 45°).

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Ο κύκλος $x^2 + y^2 - 2x - 4y - 11 = 0$ έχει κέντρο $(x_0, y_0)$ και ακτίνα $R$. Να τα βρείτε.
Υπόδειξη: $K\left(-\frac A2, -\frac B2\right)$.
Λύση: $A = -2$, $B = -4$, $\Gamma = -11$: κέντρο $(1, 2)$, $R = \frac{\sqrt{4 + 16 + 44}}{2} = \frac82 = 4$.
Άσκηση 2Βασική
Η εξίσωση $x^2 + y^2 + 10y + 26 = 0$ παριστάνει:
Υπόδειξη: $A^2 + B^2 - 4\Gamma$.
Λύση: $0 + 100 - 104 = -4 < 0$· ισοδύναμα $x^2 + (y + 5)^2 = -1$, αδύνατο. Κανένα σημείο.
Άσκηση 3Βασική
Να βρείτε την κορυφή της παραβολής $y = 3x^2 - 2x + 1$.
Υπόδειξη: $x = -\frac{B}{2A}$.
Λύση: $x = \frac{2}{6} = \frac13$, $y = 3\cdot\frac19 - \frac23 + 1 = \frac23$.
Άσκηση 4Μέτρια
Να βρείτε τον κύκλο που περνά από τα σημεία $P(-1, 3)$, $Q(0, 2)$ και $S(1, -1)$, στη μορφή $x^2 + y^2 + Ax + By + \Gamma = 0$.
Υπόδειξη: Αντικαταστήστε τα τρία σημεία: γραμμικό σύστημα για $A, B, \Gamma$.
Λύση: Σημείο $P(-1,3)$: $10 - A + 3B + \Gamma = 0$. Σημείο $Q(0,2)$: $4 + 2B + \Gamma = 0 \Rightarrow \Gamma = -4 - 2B$. Σημείο $S(1,-1)$: $2 + A - B + \Gamma = 0$. Αντικαθιστώντας: $-A + B = -6$ και $A - 3B = 2$, άρα $B = 2$, $A = 8$, $\Gamma = -8$. Κύκλος $x^2 + y^2 + 8x + 2y - 8 = 0$, δηλαδή $(x + 4)^2 + (y + 1)^2 = 25$.
Άσκηση 5Μέτρια
Ο κύκλος με κέντρο $(2, -3)$ που περνά από την αρχή των αξόνων έχει εξίσωση $x^2 + y^2 + Ax + By + \Gamma = 0$. Να βρείτε τα $A, B, \Gamma$.
Υπόδειξη: $R^2 = 2^2 + 3^2$.
Λύση: $(x - 2)^2 + (y + 3)^2 = 13 \iff x^2 + y^2 - 4x + 6y + 13 = 13 \iff x^2 + y^2 - 4x + 6y = 0$.
Άσκηση 6Μέτρια
Η εξίσωση $x^2 + y^2 + 2x + 2y + 2 = 0$ παριστάνει:
Υπόδειξη: $(x + 1)^2 + (y + 1)^2 = ?$
Λύση: $(x + 1)^2 + (y + 1)^2 = 0$: μόνο το σημείο $(-1, -1)$ ($A^2 + B^2 - 4\Gamma = 0$).
Άσκηση 7Βασική
Οι παραμετρικές εξισώσεις του κύκλου $(x - 1)^2 + (y + 2)^2 = 9$ είναι $x = x_0 + R\cos\theta$, $y = y_0 + R\sin\theta$. Για $\theta = \frac{\pi}{2}$ ποιο σημείο παίρνουμε;
Υπόδειξη: $\cos\frac\pi2 = 0$, $\sin\frac\pi2 = 1$.
Λύση: $x = 1 + 3\cdot 0 = 1$, $y = -2 + 3\cdot 1 = 1$: το «ψηλότερο» σημείο του κύκλου.
Άσκηση 8Απαιτητική
Ένα σημείο $(x, y)$ κινείται ώστε το άθροισμα των τετραγώνων των αποστάσεών του από τα $(4, 1)$ και $(2, -5)$ να είναι πάντα $45$. Η τροχιά είναι κύκλος· να βρείτε το κέντρο και την ακτίνα του.
Υπόδειξη: Αναπτύξτε και διαιρέστε με $2$.
Λύση: $(x - 4)^2 + (y - 1)^2 + (x - 2)^2 + (y + 5)^2 = 45 \iff 2x^2 + 2y^2 - 12x + 8y + 46 = 45 \iff x^2 + y^2 - 6x + 4y + \frac12 = 0$. Κέντρο $(3, -2)$, $R^2 = 9 + 4 - \frac12 = \frac{25}{2}$, $R = \frac{5}{\sqrt2} \approx 3{,}536$.

♾️ Γεννήτρια — κύκλος και παραβολή

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε το κέντρο $K(h, k)$ και την ακτίνα $R$ του κύκλου $x^2 + y^2 + 8y = 0$.
Λύση: Συμπλήρωση τετραγώνων: $x^2 + (y + 4)^2 = 0 + 16 + 0 = 16$. Κέντρο $(0, -4)$, $R = \sqrt{16} = 4$ (ή $R = \frac{\sqrt{A^2 + B^2 - 4\Gamma}}{2}$).
