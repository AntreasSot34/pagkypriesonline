8.7

Ορισμένα ολοκληρώματα με μεταβλητά όρια — Β΄ ΘΘΟΛ

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 8 §8.7 · Προβλήματα 8.24–8.32

Αν το άνω όριο του ολοκληρώματος κινείται, το ολοκλήρωμα γίνεται συνάρτηση του x — και η παράγωγός της είναι η ίδια η f.

Θεωρία

Η συνάρτηση $F(x) = \int_a^x f(t)\,dt$

Θεωρούμε το ολοκλήρωμα $\int_a^x f(t)\,dt$, όπου το άνω όριο ολοκλήρωσης δεν είναι σταθερά αλλά η μεταβλητή $x$. Αν $F$ είναι παράγουσα της $f$, από το Α΄ ΘΘΟΛ: $\int_a^x f(t)\,dt = F(x) - F(a)$, και παραγωγίζοντας ως προς $x$:

$$\frac{d}{dx}\int_a^x f(t)\,dt = f(x).$$

8.7.1 · Β΄ Θεμελιώδες Θεώρημα (Β΄ ΘΘΟΛ)

Έστω μια συνάρτηση $f$ συνεχής στο διάστημα $I$ και ένα σημείο $a \in I$. Αν η συνάρτηση $F(x)$ ορίζεται ως $F(x) = \int_a^x f(t)\,dt$, τότε $F'(x) = f(x)$ $\forall x \in I$.

Άρα κάθε συνεχής συνάρτηση σε διάστημα έχει παράγουσα· η $F(x) = \int_a^x f(t)\,dt$ είναι εκείνη η παράγουσα για την οποία $F(a) = 0$.

Παραδείγματα

$\frac{d}{dx}\int_1^x t^3dt = x^3$ · $\frac{d}{dx}\int_2^x\frac{\sin\theta}{\theta}d\theta = \frac{\sin x}{x}$.

Αν $F(x) = \int_2^x\sqrt{3t^2 + 1}\,dt$: $F(2) = 0$, $F'(x) = \sqrt{3x^2 + 1}$, $F'(2) = \sqrt{13}$, $F''(x) = \frac{3x}{\sqrt{3x^2 + 1}}$, $F''(2) = \frac{6}{\sqrt{13}}$.

Μεταβλητά όρια με συναρτήσεις (κανόνας αλυσίδας)

Αν $g, h$ παραγωγίσιμες και η $f$ συνεχής σε διάστημα που περιέχει τις τιμές των $g, h$ (και το $a$):

$$\frac{d}{dx}\int_a^{g(x)} f(t)\,dt = f(g(x))\,g'(x), \qquad \frac{d}{dx}\int_{h(x)}^{g(x)} f(t)\,dt = f(g(x))\,g'(x) - f(h(x))\,h'(x).$$

Π.χ. $\frac{d}{dx}\int_1^{x^3}\frac{dt}{t} = \frac{1}{x^3}\cdot 3x^2 = \frac3x$.

Πειραματίσου

F(x) = ∫0x f(t) dt = 0,8415 · κλίση F′(x) ≈ 0,5403 και f(x) = 0,5403
Β΄ ΘΘΟΛ: d/dx ∫ax f(t) dt = f(x). Με άνω όριο g(x): d/dx ∫ag(x) f(t) dt = f(g(x))·g′(x) (κανόνας αλυσίδας).

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Αν $F(x) = \displaystyle\int_1^x t^3\,dt$, να βρείτε το $F'(2)$.
Υπόδειξη: Β΄ ΘΘΟΛ.
Λύση: $F'(x) = x^3$, άρα $F'(2) = 8$.
Άσκηση 2Μέτρια
Για την $F(x) = \displaystyle\int_2^x \sqrt{3t^2 + 1}\,dt$ να βρείτε τα $F(2)$, $F'(2)$, $F''(2)$ (4 δεκαδικά).
Υπόδειξη: $F'(x) = \sqrt{3x^2 + 1}$.
Λύση: $F(2) = \int_2^2 = 0$, $F'(2) = \sqrt{13} \approx 3{,}6056$, $F''(x) = \frac{3x}{\sqrt{3x^2 + 1}}$, $F''(2) = \frac{6}{\sqrt{13}} \approx 1{,}6641$.
Άσκηση 3Μέτρια
Αν $F(x) = \displaystyle\int_1^{x^3} \frac{dt}{t}$, να βρείτε το $F'(2)$.
Υπόδειξη: $\frac{d}{dx}\int_a^{g(x)} f = f(g(x))g'(x)$.
Λύση: $F'(x) = \frac{1}{x^3}\cdot 3x^2 = \frac3x$, $F'(2) = \frac32$.
Άσκηση 4Μέτρια
Αν $F(x) = \displaystyle\int_x^{2x} \frac{dt}{t}$, $x > 0$, πόση είναι η $F'(x)$;
Υπόδειξη: Και τα δύο όρια μεταβάλλονται.
Λύση: $F'(x) = \frac{1}{2x}\cdot 2 - \frac1x\cdot 1 = 0$· πράγματι $F(x) = \ln 2x - \ln x = \ln 2$ σταθερή.
Άσκηση 5Μέτρια
Αν $F(x) = \displaystyle\int_0^x \frac{\cos t}{t^2 + 3}\,dt$, να βρείτε τα $F(0)$, $F'(0)$, $F''(0)$.
Υπόδειξη: $F''(x) = \frac{d}{dx}\frac{\cos x}{x^2 + 3}$.
Λύση: $F(0) = 0$, $F'(x) = \frac{\cos x}{x^2 + 3} \Rightarrow F'(0) = \frac13$, $F''(x) = \frac{-\sin x(x^2 + 3) - 2x\cos x}{(x^2 + 3)^2} \Rightarrow F''(0) = 0$.
Άσκηση 6Απαιτητική
Αν $F(x) = \displaystyle\int_{-x}^{x} \frac{dt}{1 + t^4}$, να βρείτε το $F'(1)$.
Υπόδειξη: $F'(x) = f(x)\cdot 1 - f(-x)\cdot(-1)$.
Λύση: $F'(x) = \frac{1}{1 + x^4} + \frac{1}{1 + x^4} = \frac{2}{1 + x^4}$, $F'(1) = 1$.
Άσκηση 7Απαιτητική
Για την $F(x) = \displaystyle\int_0^x t(t - 2)\,dt$ να βρείτε τη θέση του τοπικού ελαχίστου και την τιμή του.
Υπόδειξη: $F'(x) = x(x - 2)$· πρόσημο της $F'$.
Λύση: $F'(x) = x(x - 2)$: $+$ για $x < 0$, $-$ στο $(0, 2)$, $+$ για $x > 2$. Τοπικό ελάχιστο στο $x = 2$: $F(2) = \int_0^2 (t^2 - 2t)\,dt = \frac83 - 4 = -\frac43$.
Άσκηση 8Βασική
Αν η $f$ είναι συνεχής στο διάστημα $I$ και $a \in I$, η $F(x) = \int_a^x f(t)\,dt$ είναι η παράγουσα της $f$ με $F(a) = 0$.
Υπόδειξη: Β΄ ΘΘΟΛ και $\int_a^a = 0$.
Λύση: Σωστό: $F' = f$ (Β΄ ΘΘΟΛ) και $F(a) = \int_a^a f = 0$.
Άσκηση 9Μέτρια
Ποιο είναι το μεγαλύτερο ανοικτό διάστημα που περιέχει το $1$ στο οποίο η $F(x) = \displaystyle\int_1^x \frac{dt}{t}$ είναι παράγουσα της $f(x) = \frac1x$;
Υπόδειξη: Το διάστημα πρέπει να περιέχει το $1$ και η $f$ να είναι συνεχής σε αυτό.
Λύση: Η $\frac1t$ είναι συνεχής στο $(0, +\infty)$, που περιέχει το $a = 1$, άρα εκεί $F' = \frac1x$ (η $F$ είναι η $\ln x$). Στο $(1, +\infty)$ ισχύει επίσης, αλλά δεν είναι το μέγιστο διάστημα.

Εξάσκηση #1
Αν $F(x) = \displaystyle\int_{0}^{x^{3}} (t + 1)\,dt$, να βρείτε το $F'(1)$.
Υπόδειξη: $\frac{d}{dx}\int_a^{g(x)} f(t)\,dt = f(g(x))\,g'(x)$.
Λύση: $F'(x) = (x^{3} + 1)\cdot 3x^{2}$, $F'(1) = 2\cdot 3 = 6$.
