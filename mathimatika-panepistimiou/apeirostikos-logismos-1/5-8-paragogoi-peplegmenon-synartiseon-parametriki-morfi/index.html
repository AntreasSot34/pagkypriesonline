5.8

Παράγωγοι πεπλεγμένων συναρτήσεων – Παραμετρική μορφή

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 5 §5.8–5.8.1 (σελ. 5.39–5.42) · Προβλήματα 5.27–5.30, 5.38

Πώς βρίσκουμε την κλίση ενός κύκλου ή μιας καμπύλης όπως $x^3 + y^3 = 6xy$, χωρίς να λύσουμε ως προς $y$;

Θεωρία

Πεπλεγμένη παραγώγιση

Μια συνάρτηση $y = y(x)$ μπορεί να ορίζεται σε πεπλεγμένη μορφή $f(x, y) = 0$. Όταν η λύση ως προς $y$ δεν είναι δυνατή ή είναι πολύπλοκη, παραγωγίζουμε τους δύο όρους ως προς $x$, θεωρώντας $y = y(x)$ (άρα, π.χ., $\frac{d}{dx}y^2 = 2yy'$), και λύνουμε την εξίσωση που προκύπτει ως προς $y' = \frac{dy}{dx}$.

Παρατήρηση: $\dfrac{dx}{dy} = \dfrac{1}{dy/dx}$ (όπου $\frac{dy}{dx} \ne 0$).

Παραδείγματα των σημειώσεων

(1) $xy + 3y - x + 2 = 0$: $\ y + xy' + 3y' - 1 = 0 \Rightarrow y' = \frac{1 - y}{x + 3}$· επειδή $y = \frac{x - 2}{x + 3}$, τελικά $y' = \frac{5}{(x + 3)^2}$ (ίδιο αποτέλεσμα με την άμεση παραγώγιση).

(2) $xy + \cos y = 0$: $\ y + xy' - \sin y\,y' = 0 \Rightarrow \frac{dy}{dx} = \frac{y}{\sin y - x}$.

(3) Εφαπτομένη της $7y^4 + x^3y + x = 4$ στο $(4, 0)$

$28y^3y' + 3x^2y + x^3y' + 1 = 0 \Rightarrow y' = -\dfrac{3x^2y + 1}{28y^3 + x^3}$. Στο $(4, 0)$: $m = -\frac{1}{64}$, εφαπτομένη $y - 0 = -\frac{1}{64}(x - 4)$, δηλ. $y = -\frac{1}{64}x + \frac{1}{16}$.

(4) Δεύτερη παράγωγος: $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$

$\frac{2x}{a^2} - \frac{2y}{b^2}y' = 0 \Rightarrow y' = \frac{b^2}{a^2}\frac xy$. Ξανά ως προς $x$: $y'' = \frac{b^2}{a^2}\frac{y - xy'}{y^2} = \dots = -\frac{b^4}{a^2y^3}$ (χρησιμοποιώντας την εξίσωση της καμπύλης).

5.8.1 · Παράγωγος συνάρτησης σε παραμετρική μορφή

Αν η $y = y(x)$ δίνεται παραμετρικά, $x = f(t)$, $y = g(t)$, τότε

$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{g'(t)}{f'(t)}\qquad (f'(t) \ne 0).$$

Π.χ. $x = e^t + 1$, $y = \sin(2t + 1)$: $\ \frac{dy}{dx} = \frac{2\cos(2t + 1)}{e^t} = 2e^{-t}\cos(2t + 1)$.

Πειραματίσου

y′ = −x / y
Στο σημείο (1,763, 2,427): κλίση εφαπτομένης = −0,727.
Παραγωγίζουμε την εξίσωση ως προς x θεωρώντας y = y(x) και λύνουμε ως προς y′ (πεπλεγμένη παραγώγιση).

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Στον κύκλο $x^2 + y^2 = 25$, να βρείτε την κλίση της εφαπτομένης στο σημείο $(3, -4)$.
Υπόδειξη: $2x + 2yy' = 0$.
Λύση: $y' = -\frac xy = -\frac{3}{-4} = \frac34$.
Άσκηση 2Μέτρια
Για την καμπύλη $7y^4 + x^3y + x = 4$, να βρείτε την κλίση $y'$ στο σημείο $(4, 0)$ και την τεταγμένη $\beta$ της εφαπτομένης $y = y'(4)\,x + \beta$.
Υπόδειξη: $y' = -\frac{3x^2y + 1}{28y^3 + x^3}$.
Λύση: Στο $(4, 0)$: $y' = -\frac{1}{64}$. $y = -\frac{1}{64}(x - 4) = -\frac{1}{64}x + \frac{1}{16}$.
Άσκηση 3Μέτρια
Η καμπύλη $x^3y^2 - 5x^2y + x = 1$ διέρχεται από το $(1, 0)$. Να βρείτε την κλίση $y'$ εκεί.
Υπόδειξη: Παραγωγίστε όρο-όρο: $(x^3y^2)' = 3x^2y^2 + 2x^3yy'$.
Λύση: $3x^2y^2 + 2x^3yy' - 10xy - 5x^2y' + 1 = 0$. Στο $(1, 0)$: $-5y' + 1 = 0 \Rightarrow y' = \frac15$.
Άσκηση 4Απαιτητική
Σε ποιο σημείο (με $x \ne 0$) η εφαπτομένη της καμπύλης $y^2 = 2x^3$ είναι κάθετη στην ευθεία $4x - 3y + 1 = 0$; (Πρόβλημα 5.28)
Υπόδειξη: Η ευθεία έχει κλίση $\frac43$· ζητάμε $y' = -\frac34$, με $y' = \frac{3x^2}{y}$.
Λύση: $2yy' = 6x^2 \Rightarrow y' = \frac{3x^2}{y} = -\frac34 \Rightarrow y = -4x^2$. Τότε $16x^4 = 2x^3 \Rightarrow x = \frac18$, $y = -\frac{4}{64} = -\frac1{16}$.
Άσκηση 5Μέτρια
Να βρείτε τα $a, b$ ώστε το $(1, 1)$ να ανήκει στην καμπύλη $x^2y + ay^2 = b$ και η εφαπτομένη εκεί να είναι η $4x + 3y = 7$ (Πρόβλημα 5.29).
Υπόδειξη: Η εφαπτομένη έχει κλίση $-\frac43$.
Λύση: $2xy + x^2y' + 2ayy' = 0$, στο $(1, 1)$: $y' = -\frac{2}{1 + 2a} = -\frac43 \Rightarrow a = \frac14$. Και $b = 1 + a = \frac54$.
Άσκηση 6Βασική
Η καμπύλη δίνεται παραμετρικά: $x = t^2$, $y = t^3 - 3t$. Να υπολογίσετε το $\frac{dy}{dx}$ για $t = 2$.
Υπόδειξη: $\frac{dy}{dx} = \frac{dy/dt}{dx/dt}$.
Λύση: $\frac{dy}{dx} = \frac{3t^2 - 3}{2t}$, για $t = 2$: $\frac{9}{4}$.
Άσκηση 7Βασική
Για την κυκλοειδή $x = t - \sin t$, $y = 1 - \cos t$ να υπολογίσετε το $\frac{dy}{dx}$ για $t = \frac\pi2$.
Υπόδειξη: $\frac{dy}{dx} = \frac{\sin t}{1 - \cos t}$.
Λύση: Στο $t = \frac\pi2$: $\frac{1}{1 - 0} = 1$.
Άσκηση 8Απαιτητική
Οι εφαπτομένες της $x^2 - 4x + y^2 + 3 = 0$ που διέρχονται από την αρχή των αξόνων έχουν κλίσεις $\pm m$. Να βρείτε το $m^2$ (Πρόβλημα 5.30).
Υπόδειξη: Είναι ο κύκλος $(x - 2)^2 + y^2 = 1$· η ευθεία $y = mx$ εφάπτεται όταν απέχει $1$ από το κέντρο.
Λύση: Απόσταση του $(2, 0)$ από την $mx - y = 0$: $\frac{|2m|}{\sqrt{1 + m^2}} = 1 \Rightarrow 4m^2 = 1 + m^2 \Rightarrow m^2 = \frac13$. (Με πεπλεγμένη παραγώγιση: $y' = \frac{2 - x}{y}$ στο σημείο επαφής $(x, mx)$, δίνει το ίδιο.)
Άσκηση 9Βασική
Για μια καμπύλη που δίνεται πεπλεγμένα, όπου $\frac{dy}{dx} \ne 0$, ισχύει:
Υπόδειξη: Παρατήρηση της §5.8.
Λύση: $\frac{dx}{dy} = 1\Big/\frac{dy}{dx}$ (π.χ. στην $xy + \cos y = 0$: $\frac{dx}{dy} = \frac{\sin y - x}{y}$).
Άσκηση 10Απαιτητική
Για $x^2 + y^2 = 25$ να υπολογίσετε την $y''$ στο σημείο $(3, 4)$.
Υπόδειξη: $y' = -\frac xy$, και ξανά παραγώγιση: $y'' = -\frac{y - xy'}{y^2}$.
Λύση: $y'' = -\dfrac{y - x(-x/y)}{y^2} = -\dfrac{y^2 + x^2}{y^3} = -\dfrac{25}{y^3}$. Στο $(3, 4)$: $-\frac{25}{64}$.

♾️ Γεννήτρια — πεπλεγμένη παραγώγιση

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Η καμπύλη $2x^2 - 3xy + y^2 = 20$ διέρχεται από το σημείο $(1, -3)$. Να βρείτε την κλίση $y'$ της εφαπτομένης εκεί.
Λύση: Παραγωγίζουμε ως προς $x$ με $y = y(x)$: $4x - 3(y + xy') + 2yy' = 0$, άρα $y' = -\dfrac{4x - 3y}{-3x + 2y}$. Στο $(1, -3)$: $y' = \frac{13}{9}$.
