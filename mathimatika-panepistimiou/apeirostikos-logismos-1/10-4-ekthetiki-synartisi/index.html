10.4

Εκθετική συνάρτηση

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 10 §10.4 · 10η σειρά ασκήσεων

Η $e^x$ είναι η μόνη (εκτός από τα πολλαπλάσιά της) συνάρτηση που είναι ίση με την παράγωγό της.

Θεωρία

Φυσική εκθετική συνάρτηση

Ο αριθμός $e$ ορίζεται και από τη σχέση $\ln e = 1$. Η $f(x) = e^x$ (ή $\exp(x)$) είναι η αντίστροφη της $\ln x$:

$\ln e^x = x\ \ \forall x \in \mathbb{R}, \qquad e^{\ln x} = x\ \ \forall x > 0.$

Με βάση $a > 0$: $a^x = e^{x\ln a}$, η αντίστροφη της $\log_a x$.

Παράγωγοι

Από $y = e^x \iff \ln y = x$ παραγωγίζουμε: $\frac{1}{y}\frac{dy}{dx} = 1$, δηλαδή $\frac{dy}{dx} = y = e^x$.

$\displaystyle \frac{d}{dx}e^x = e^x, \quad \frac{d}{dx}e^u = e^u\frac{du}{dx}, \quad \frac{d}{dx}a^x = a^x\ln a, \quad \frac{d}{dx}a^u = a^u\ln a\,\frac{du}{dx}.$

Η $y = ce^x$ είναι η μόνη συνάρτηση που ικανοποιεί τη διαφορική εξίσωση $\frac{dy}{dx} = y$.

Ολοκληρώματα

$\displaystyle \int e^x dx = e^x + c, \qquad \int a^x dx = \frac{a^x}{\ln a} + c, \qquad \int f'(x)e^{f(x)}dx = e^{f(x)} + c.$

Παραδείγματα

(i) $\frac{d}{dx}e^{x + e^x} = (1 + e^x)e^{x + e^x}$ · (ii) $\frac{d}{dx}e^{\tan x} = \sec^2x\,e^{\tan x}$.

(iii) $\int\frac{e^{1/x^3}}{x^4}dx$: $u = \frac1{x^3}$, $du = -\frac3{x^4}dx$, άρα $-\frac13\int e^u du = -\frac13e^{1/x^3} + c$.

(iv) $\int\sin 2x\;2^{-\cos 2x}dx$: $u = -\cos 2x$, $du = 2\sin 2x\,dx$: $\frac12\int 2^u du = \frac{2^{-\cos 2x}}{2\ln 2} + c$.

Όγκος στερεού

Το χωρίο κάτω από την $y = e^{-x^2}$ για $0 \le x \le 1$ περιστρέφεται γύρω από τον άξονα $y$. Με κυλινδρικούς φλοιούς: $V = 2\pi\int_0^1 x e^{-x^2}dx = -\pi e^{-x^2}\Big]_0^1 = \pi(1 - e^{-1})$.

Πειραματίσου

Στο x₀ = -0,1: τιμή e^x₀ = 0,905 και κλίση εφαπτομένης 0,905 — ίδιες! Γι' αυτό $(e^x)' = e^x$.
Πορτοκαλί: $\left(1 + \frac{x}{n}\right)^n$ με n = 4 → στο x = 1 δίνει 2,44141, ενώ e = 2,71828.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να βρείτε την παράγωγο της $y = e^{x^2}\sin x$.
Υπόδειξη: Κανόνας γινομένου και $(e^{u})' = e^u u'$.
Λύση: $y' = 2xe^{x^2}\sin x + e^{x^2}\cos x = e^{x^2}(2x\sin x + \cos x)$.
Άσκηση 2Μέτρια
Να βρεθεί η κλίση της εφαπτομένης της καμπύλης $y = e^{2\sqrt x}\ln 3x$ στο σημείο με $x = 1$ (3 δεκαδικά).
Υπόδειξη: $y' = e^{2\sqrt x}\left(\frac1x + \frac{\ln 3x}{\sqrt x}\right)$.
Λύση: $y' = e^{2\sqrt x}\cdot\frac{1}{\sqrt x}\ln 3x + e^{2\sqrt x}\cdot\frac{3}{3x}$. Στο $x = 1$: $(1 + \ln 3)e^2 \approx 15{,}507$.
Άσκηση 3Μέτρια
Αν $y = 5^{x^3}e^{-x^2}$, να βρείτε το $y'(1)$ (3 δεκαδικά).
Υπόδειξη: $(5^{x^3})' = 5^{x^3}\ln 5\cdot 3x^2$.
Λύση: $y' = 5^{x^3}e^{-x^2}(3x^2\ln 5 - 2x)$. Στο $x = 1$: $5e^{-1}(3\ln 5 - 2) \approx 5{,}202$.
Άσκηση 4Βασική
Να υπολογίσετε το $\displaystyle\int\frac{e^{1/x^3}}{x^4}\,dx$.
Υπόδειξη: $u = \frac{1}{x^3}$.
Λύση: $du = -\frac{3}{x^4}dx$: $-\frac13\int e^u du = -\frac13e^{1/x^3} + c$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\displaystyle\int\sin 2x\;2^{-\cos 2x}\,dx$.
Υπόδειξη: $u = -\cos 2x$.
Λύση: $du = 2\sin 2x\,dx$: $\frac12\int 2^u du = \frac{2^u}{2\ln 2} + c = \frac{2^{-\cos 2x}}{\ln 4} + c$.
Άσκηση 6Βασική
Να υπολογίσετε το $\displaystyle\int_0^{\ln 2}e^{-3x}\,dx$.
Υπόδειξη: $\int e^{-3x}dx = -\frac13e^{-3x}$.
Λύση: $-\frac13\left(e^{-3\ln 2} - 1\right) = -\frac13\left(\frac18 - 1\right) = \frac{7}{24}$.
Άσκηση 7Μέτρια
Το χωρίο που περικλείεται από τις $y = e^{-x^2}$, $y = 0$, $x = 0$ και $x = 1$ περιστρέφεται γύρω από τον άξονα $y$. Να βρείτε τον όγκο (4 δεκαδικά).
Υπόδειξη: Κυλινδρικοί φλοιοί: $V = 2\pi\int_0^1 x e^{-x^2}dx$.
Λύση: $V = 2\pi\left[-\frac12e^{-x^2}\right]_0^1 = \pi(1 - e^{-1}) \approx 1{,}9859$.
Άσκηση 8Μέτρια
Για ποια θετική τιμή του $k$ η $y = e^{kx}$ ικανοποιεί την εξίσωση $y'' + 2y' - 8y = 0$;
Υπόδειξη: $y' = ke^{kx}$, $y'' = k^2e^{kx}$.
Λύση: $(k^2 + 2k - 8)e^{kx} = 0 \Rightarrow k^2 + 2k - 8 = 0 \Rightarrow k = 2$ ή $k = -4$. Η θετική είναι $k = 2$ — άρα κάθε $y = Ae^{2x} + Be^{-4x}$ είναι λύση.
Άσκηση 9Βασική
Οι μόνες παραγωγίσιμες συναρτήσεις με $y' = y$ (σε όλο το $\mathbb{R}$) είναι οι $y = ce^x$.
Υπόδειξη: Παραγωγίστε το $ye^{-x}$.
Λύση: Σωστό: αν $y' = y$, τότε $(ye^{-x})' = y'e^{-x} - ye^{-x} = 0$, άρα $ye^{-x} = c$, δηλαδή $y = ce^x$.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\int_0^{2} e^{x}\,dx$ (4 δεκαδικά).
Υπόδειξη: $(e^{u})' = e^{u}u'$ και $(a^x)' = a^x\ln a$.
Λύση: $\int e^{x}dx = e^{x} + c$, άρα $(e^{2} - 1) \approx 6{,}3891$.
