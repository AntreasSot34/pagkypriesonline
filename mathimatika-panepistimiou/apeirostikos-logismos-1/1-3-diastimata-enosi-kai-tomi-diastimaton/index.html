1.3

Διαστήματα – Ένωση και τομή διαστημάτων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 1 §1.3, §1.3.1 · 1η σειρά ασκήσεων (άσκ. 1θ–1κ, 2)

Η ευθεία των πραγματικών αριθμών και τα «κομμάτια» της: εκεί ζουν τα πεδία ορισμού και οι λύσεις των ανισώσεων.

Θεωρία

1.3.1 · Φραγμένα διαστήματα

Για $a, b \in \mathbb{R}$ με $a < b$:

$$(a,b) = \{x : a < x < b\},\quad [a,b] = \{x : a \le x \le b\},\quad [a,b) = \{x : a \le x < b\},\quad (a,b] = \{x : a < x \le b\}.$$

Ανοικτό, κλειστό, κλειστό από αριστερά, κλειστό από δεξιά. Στην ευθεία: γεμάτος κύκλος = το άκρο ανήκει, κενός κύκλος = δεν ανήκει.

1.3.2 · Μη φραγμένα διαστήματα

$(a, +\infty) = \{x : x > a\}$, $\ [a, +\infty) = \{x : x \ge a\}$, $\ (-\infty, a) = \{x : x < a\}$, $\ (-\infty, a] = \{x : x \le a\}$, $\ (-\infty, +\infty) = \mathbb{R}$.

Το σύμβολο $\infty$

Το $+\infty$ (ή $-\infty$) δεν είναι πραγματικός αριθμός· σημαίνει ότι το $x$ παίρνει οσοδήποτε μεγάλες (μικρές) τιμές. Γι' αυτό στο $\pm\infty$ η αγκύλη είναι πάντα ανοικτή.

Ένωση και τομή

$[1,4] \cup (2,5) = [1,5)$, $\ [1,4] \cap (2,5) = (2,4]$, $\ (1,+\infty) \cup [-1,2] = [-1,+\infty)$, $\ (1, +\infty) \cap [-1, 2] = (1, 2]$.

Πώς το βλέπουμε γρήγορα

Σχεδιάζουμε τα δύο διαστήματα το ένα κάτω από το άλλο. Η τομή είναι το κοινό κομμάτι: αριστερό άκρο το μεγαλύτερο από τα αριστερά άκρα, δεξί το μικρότερο από τα δεξιά. Για κάθε άκρο ελέγχουμε αν ανήκει και στα δύο.

Πειραματίσου

I₁ = [−2, 3), I₂ = (1, 5] ⇒ I₁ ∩ I₂ = (1, 3)
Γεμάτος κύκλος: το άκρο ανήκει· κενός: δεν ανήκει. Ένα άκρο ανήκει στην τομή μόνο αν ανήκει και στα δύο διαστήματα.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Η τομή $[1, 4] \cap (2, 5)$ είναι:
Υπόδειξη: Το $2$ ανήκει στο $(2,5)$; Το $4$ ανήκει στο $[1,4]$;
Λύση: Κοινά στοιχεία: $2 < x \le 4$, δηλαδή $(2, 4]$.
Άσκηση 2Βασική
Η ένωση $(-5, -2) \cup [-4, -3)$ είναι:
Υπόδειξη: Το ένα περιέχεται στο άλλο;
Λύση: $[-4,-3) \subseteq (-5,-2)$, άρα η ένωση είναι το μεγαλύτερο, $(-5,-2)$.
Άσκηση 3Βασική
Η τομή $(-\infty, 1) \cap [0, 2]$ είναι:
Υπόδειξη: $x < 1$ και $0 \le x \le 2$.
Λύση: $0 \le x < 1$: το $[0, 1)$.
Άσκηση 4Μέτρια
Η τομή $[-1, 2] \cap (0, 3) \cap (-\infty, 1{,}5]$ είναι διάστημα $(\alpha, \beta]$. Να βρείτε τα $\alpha, \beta$.
Υπόδειξη: Μεγαλύτερο αριστερό άκρο, μικρότερο δεξί.
Λύση: Αριστερά: $\max(-1, 0) = 0$ (το $0$ δεν ανήκει στο $(0,3)$). Δεξιά: $\min(2, 3, 1{,}5) = 1{,}5$, που ανήκει και στα τρία. Άρα $(0, 1{,}5]$.
Άσκηση 5Βασική
Το σύνολο $\{x \in \mathbb{R} : x \ge -2\}$ γράφεται ως:
Υπόδειξη: Το $-2$ ανήκει· στο $+\infty$ η αγκύλη είναι πάντα ανοικτή.
Λύση: $[-2, +\infty)$· το $+\infty$ δεν είναι αριθμός, άρα δεν «κλείνει».
Άσκηση 6Μέτρια
Η ένωση $(-5, 1) \cup (2, +\infty)$ είναι διάστημα.
Υπόδειξη: Ανήκει το $1{,}5$;
Λύση: Λάθος: το $1{,}5$ λείπει, ενώ υπάρχουν στοιχεία και αριστερά και δεξιά του. Είναι ένωση δύο ξένων διαστημάτων.
Άσκηση 7Μέτρια
Το σύνολο $A = \{x : 1 < x < 3\}$ και το $B = \{x : 1 \le x < 2\}$. Η ένωση $A \cup B$ είναι διάστημα $[\alpha, \beta)$ και η τομή $(\gamma, \delta)$. Να βρείτε τα $\alpha, \beta, \gamma, \delta$.
Υπόδειξη: Ποιο άκρο ανήκει σε ποιο σύνολο;
Λύση: $A \cup B = [1, 3)$ (το $1$ ανήκει στο $B$). $A \cap B = (1, 2)$ (το $1$ δεν ανήκει στο $A$, το $2$ δεν ανήκει στο $B$).
Άσκηση 8Απαιτητική
Για ποια $a$ ισχύει $[a, a + 2] \cap [3, 4] = \varnothing$;
Υπόδειξη: Ξένα: ή $a + 2 < 3$ ή $a > 4$.
Λύση: Τα κλειστά διαστήματα είναι ξένα όταν $a + 2 < 3$ (δηλ. $a < 1$) ή $a > 4$. Για $a = 1$ ή $a = 4$ έχουν κοινό το $3$ ή το $4$.

♾️ Γεννήτρια — διαστήματα

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Ο αριθμός $-2$ ανήκει στο διάστημα $[-2, 1)$.
Λύση: Το $-2$ είναι αριστερό άκρο· η αγκύλη δείχνει ότι ανήκει (Σωστό).
