2.4.1

Σύνθεση συναρτήσεων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 2 §2.4.1 · Ασκήσεις 2ου κεφαλαίου (2.8, 2.9, 2.12, 2.17)

Βάζουμε την έξοδο μιας συνάρτησης ως είσοδο σε μια άλλη — η βάση του κανόνα της αλυσίδας και της αντικατάστασης στα ολοκληρώματα.

Θεωρία

2.4.1.1 · Σύνθεση

$$(f \circ g)(x) = f\big(g(x)\big)$$

Το πεδίο ορισμού της $f\circ g$ είναι το σύνολο των $x \in A_g$ για τα οποία $g(x) \in A_f$. Άρα $A_{f\circ g} \subseteq A_g$.

Παραδείγματα

$f(x) = \sqrt{x - 1}$, $g(x) = x^2$: $(f\circ g)(x) = \sqrt{x^2 - 1}$, ορίζεται για $x^2 \ge 1$: $A_{f\circ g} = (-\infty, -1] \cup [1, +\infty)$.

$f_1(x) = x^2 + 3$, $f_2(x) = \sqrt x$: $(f_1\circ f_2)(x) = x + 3$, αλλά με πεδίο $[0, +\infty)$ (όχι $\mathbb{R}$).

$f(x) = x^2 + 1$, $g(x) = \sqrt{1 - x}$: $(f\circ g)(x) = (1 - x) + 1 = 2 - x$ στο $(-\infty, 1]$, ενώ $(g\circ f)(x) = \sqrt{-x^2}$ ορίζεται μόνο στο $x = 0$.

Ιδιότητες

(1) Δεν ισχύει γενικά η αντιμεταθετική: $f\circ g \ne g\circ f$ (π.χ. $f = x + 1$, $g = x^2$: $x^2 + 1$ έναντι $(x + 1)^2$).

(2) Ισχύει η προσεταιριστική: $f\circ(g\circ h) = (f\circ g)\circ h$, αφού και τα δύο δίνουν $f(g(h(x)))$.

Ανάλυση σε σύνθεση

$\sin^3(x^2 - 1) = f(g(h(x)))$ με $h(x) = x^2 - 1$, $g(x) = \sin x$, $f(x) = x^3$. Αν $f(x + 1) = x^2 + 3x + 5$: θέτουμε $u = x + 1$ και παίρνουμε $f(u) = u^2 + u + 3$.

Πειραματίσου

(f∘g)(x) = f(g(x)) = 2(x²) + 1  ·  (g∘f)(x) = g(f(x)) = (2x + 1)²
Στο x₀ = 2: f(g(x₀)) = f(4) = 9, ενώ g(f(x₀)) = g(5) = 25
Γενικά f∘g ≠ g∘f: η σύνθεση δεν είναι αντιμεταθετική.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Για $f(x) = x + 1$ και $g(x) = x^2$ να βρείτε τα $(f\circ g)(3)$ και $(g\circ f)(3)$.
Υπόδειξη: Πρώτα η εσωτερική.
Λύση: $(f\circ g)(3) = f(9) = 10$, $(g\circ f)(3) = g(4) = 16$: η σύνθεση δεν είναι αντιμεταθετική.
Άσκηση 2Βασική
Το πεδίο ορισμού της $f\circ g$ για $f(x) = \sqrt{x - 1}$, $g(x) = x^2$ είναι:
Υπόδειξη: $g(x) \in A_f \iff x^2 \ge 1$.
Λύση: $x^2 - 1 \ge 0 \iff |x| \ge 1$.
Άσκηση 3Μέτρια
Αν $f(x + 1) = x^2 + 3x + 5$ για κάθε $x$, τότε $f(x) = x^2 + bx + c$. Να βρείτε τα $b, c$.
Υπόδειξη: Θέστε $u = x + 1$, δηλαδή $x = u - 1$.
Λύση: $f(u) = (u - 1)^2 + 3(u - 1) + 5 = u^2 - 2u + 1 + 3u - 3 + 5 = u^2 + u + 3$.
Άσκηση 4Μέτρια
Αν $f(x) = \sqrt{x + 5}$ και $(f\circ g)(x) = 3|x|$, τότε $g(x) = ax^2 + b$. Να βρείτε τα $a, b$.
Υπόδειξη: $\sqrt{g(x) + 5} = 3|x|$.
Λύση: Υψώνουμε στο τετράγωνο: $g(x) + 5 = 9x^2 \Rightarrow g(x) = 9x^2 - 5$.
Άσκηση 5Μέτρια
Για $f_1(x) = 3x + 6$ ισχύει $(f_1\circ f_1\circ f_1)(x) = ax + b$. Να βρείτε τα $a, b$.
Υπόδειξη: $f_1(f_1(x)) = 9x + 24$.
Λύση: $f_1(f_1(x)) = 3(3x + 6) + 6 = 9x + 24$· $f_1(9x + 24) = 27x + 72 + 6 = 27x + 78$.
Άσκηση 6Μέτρια
Για $f_1(x) = 3x + 6$ και $f_2(x) = 4x + k$, να βρείτε την τιμή του $k$ ώστε $f_1\circ f_2 = f_2\circ f_1$.
Υπόδειξη: Συγκρίνετε τους σταθερούς όρους.
Λύση: $f_1(f_2(x)) = 12x + 3k + 6$, $f_2(f_1(x)) = 12x + 24 + k$. Ίσες $\iff 3k + 6 = 24 + k \iff k = 9$.
Άσκηση 7Βασική
Η $F(x) = \sin(x^3 + 1)$ γράφεται ως $f_1\circ f_2$ με:
Υπόδειξη: Ποια πράξη γίνεται τελευταία;
Λύση: Πρώτα υπολογίζουμε $x^3 + 1$ (εσωτερική $f_2$) και μετά το ημίτονο (εξωτερική $f_1$).
Άσκηση 8Απαιτητική
Για $f(x) = x^2 + 1$ και $g(x) = \sqrt{1 - x}$ ισχύει:
Υπόδειξη: Πεδίο της $g$: $x \le 1$. Για τη $g\circ f$: $1 - (x^2 + 1) \ge 0$.
Λύση: $(f\circ g)(x) = (\sqrt{1 - x})^2 + 1 = 2 - x$ με πεδίο $(-\infty, 1]$. $(g\circ f)(x) = \sqrt{-x^2}$, που ορίζεται μόνο όταν $x = 0$.

♾️ Γεννήτρια — σύνθεση

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Για $f(x) = 2x - 4$ και $g(x) = x^2 + 3$ ισχύει $(f\circ g)(x) = px^2 + q$. Να βρείτε τα $p, q$.
Λύση: $(f\circ g)(x) = f(x^2 + 3) = 2(x^2 + 3) - 4 = 2x^2 + 2$.
