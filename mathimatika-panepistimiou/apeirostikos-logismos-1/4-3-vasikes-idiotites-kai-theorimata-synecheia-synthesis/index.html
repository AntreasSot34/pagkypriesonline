4.3

Βασικές ιδιότητες και θεωρήματα – Συνέχεια σύνθεσης

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 4 §4.3 · Φυλλάδιο ασκήσεων 4

Πολυώνυμα, sin, cos είναι συνεχή· τα αθροίσματα, γινόμενα και συνθέσεις τους επίσης. Και οι συνεχείς συναρτήσεις «αντιμετατίθενται» με τα όρια.

Θεωρία

4.3.1 · Βασικές συνεχείς συναρτήσεις

  1. Τα πολυώνυμα είναι συνεχείς συναρτήσεις.
  2. Οι $\sin x$ και $\cos x$ είναι συνεχείς.
  3. Μια ρητή συνάρτηση είναι ασυνεχής μόνο στα σημεία όπου μηδενίζεται ο παρονομαστής.

4.3.2 · Πράξεις

Αν οι $f$, $g$ είναι συνεχείς στο $c$, τότε οι $f + g$, $f - g$, $f\cdot g$ είναι συνεχείς στο $c$. Αν επιπλέον $g(c) \ne 0$, και η $\frac fg$ είναι συνεχής στο $c$· αν $g(c) = 0$, η $\frac fg$ είναι ασυνεχής στο $c$.

Πού είναι ασυνεχείς;

  • $\frac{x^2}{x^2 - 5x + 6} = \frac{x^2}{(x - 2)(x - 3)}$: σημεία ασυνέχειας $x = 2$ και $x = 3$.
  • $\frac{1}{1 - 2\cos x}$: όπου $\cos x = \frac12$, δηλαδή $x = \pm\frac\pi3, \pm\frac{5\pi}{3}, \dots$
  • $\tan x = \frac{\sin x}{\cos x}$ και $\sec x = \frac{1}{\cos x}$: όπου $\cos x = 0$, $x = \pm\frac\pi2, \pm\frac{3\pi}{2}, \dots$ · η $\sin x + \cos x$ είναι συνεχής παντού.

4.3.3 · Συνέχεια σύνθεσης

  1. Αν η $g$ είναι συνεχής στο $c$ και η $f$ συνεχής στο $g(c)$, τότε η $f\circ g$ είναι συνεχής στο $c$.
  2. Αν «$\lim$» είναι οποιοδήποτε από τα $\lim_{x\to c}$, $\lim_{x\to c^\pm}$, $\lim_{x\to\pm\infty}$, $\lim g(x) = L$ και η $f$ είναι συνεχής στο $L$, τότε
$$\lim f(g(x)) = f\left(\lim g(x)\right) = f(L)$$

Γι' αυτό λέμε ότι οι συνεχείς συναρτήσεις αντιμετατίθενται με τα όρια. Π.χ. $\lim_{x\to+\infty}\sin\frac{\pi x - 1}{6x + 3} = \sin\left[\lim\frac{\pi x - 1}{6x + 3}\right] = \sin\frac\pi6 = \frac12$, $\lim_{x\to1}|x + \sin x| = 1 + \sin 1$.

4.3.4 · Εναλλακτικός ορισμός συνέχειας

Η $f$ είναι συνεχής στο $c$ αν: (α) ορίζεται στο $c$, (β) υπάρχει το $\lim_{h\to0} f(c + h)$, (γ) $\lim_{h\to0} f(c + h) = f(c)$.

Εφαρμογή: η $\sin x$ είναι συνεχής

$\lim_{h\to0}\sin(c + h) = \lim_{h\to0}(\sin c\cos h + \cos c\sin h) = \sin c\cdot 1 + \cos c\cdot 0 = \sin c$.

Πειραματίσου

g(x) = (πx − 1)/(6x + 3): g(5) = 0,446 → L = π/6 · sin(g(5)) = 0,431 → sin(L) = 0,5
Θεώρημα 4.3.3(β): αφού η sin είναι συνεχής στο L, $\lim f(g(x)) = f(\lim g(x))$.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να βρείτε τα σημεία ασυνέχειας της $f(x) = \dfrac{x^2}{x^2 - 5x + 6}$.
Υπόδειξη: Ρίζες του παρονομαστή.
Λύση: $x^2 - 5x + 6 = (x - 2)(x - 3)$: ασυνεχής μόνο στα $2$ και $3$ (Θεώρημα 4.3.1γ).
Άσκηση 2Βασική
Να βρείτε τα σημεία ασυνέχειας της $f(x) = \dfrac{x^2 - 4}{x^2 - 16}$.
Υπόδειξη: $x^2 - 16 = 0$.
Λύση: $x = \pm4$.
Άσκηση 3Μέτρια
Να βρείτε τα σημεία ασυνέχειας της $f(x) = \dfrac5x + \dfrac{2x}{x + 4}$.
Υπόδειξη: Κάθε όρος είναι ρητή συνάρτηση.
Λύση: Ο πρώτος όρος είναι ασυνεχής στο $0$ και ο δεύτερος στο $-4$· παντού αλλού το άθροισμα είναι συνεχές (Θεώρημα 4.3.2).
Άσκηση 4Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to+\infty}\cos\left(\frac1x\right)$.
Υπόδειξη: Θεώρημα 4.3.3(β) με $g(x) = \frac1x \to 0$.
Λύση: $\cos\left(\lim\frac1x\right) = \cos 0 = 1$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\displaystyle\lim_{x\to+\infty}\sin\left(\frac{\pi x - 3}{2x + 7}\right)$.
Υπόδειξη: $\frac{\pi x - 3}{2x + 7} \to \frac\pi2$.
Λύση: $\sin\frac\pi2 = 1$.
Άσκηση 6Μέτρια
Να υπολογίσετε το $\displaystyle\lim_{x\to+\infty}\sin\left(\frac{\pi x}{2 - 3x}\right)$ (με $3$ δεκαδικά).
Υπόδειξη: $\frac{\pi x}{2 - 3x} \to -\frac\pi3$.
Λύση: $\sin\left(-\frac\pi3\right) = -\frac{\sqrt3}{2} \approx -0{,}866$.
Άσκηση 7Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to2}\sqrt{x^2 + x + 3}$.
Υπόδειξη: Η $\sqrt{\cdot}$ είναι συνεχής στο $9$.
Λύση: $\sqrt{\lim(x^2 + x + 3)} = \sqrt{9} = 3$.
Άσκηση 8Βασική
Η $f(x) = \dfrac{3}{5 + 2\cos x}$ είναι συνεχής σε όλο το $\mathbb{R}$.
Υπόδειξη: Μπορεί να μηδενιστεί ο παρονομαστής;
Λύση: Σωστό: $\cos x \ge -1$ ⇒ $5 + 2\cos x \ge 3 > 0$. Πηλίκο συνεχών με μη μηδενικό παρονομαστή.
Άσκηση 9Μέτρια
Πόσα σημεία ασυνέχειας έχει η $f(x) = \dfrac{1}{1 - 2\sin x}$ στο διάστημα $[0, 2\pi)$;
Υπόδειξη: $\sin x = \frac12$.
Λύση: $\sin x = \frac12$ για $x = \frac\pi6$ και $x = \frac{5\pi}{6}$: δύο σημεία.
Άσκηση 10Βασική
Αν οι $f$, $g$ είναι συνεχείς στο $c$, τότε η $\frac fg$ είναι πάντα συνεχής στο $c$.
Υπόδειξη: Τι γίνεται αν $g(c) = 0$;
Λύση: Λάθος: χρειάζεται $g(c) \ne 0$. Π.χ. $f = 1$, $g = x$ στο $0$.

Εξάσκηση #1
Να βρείτε τα σημεία ασυνέχειας της $f(x) = \frac{x + 6}{x^{2} + 3x - 10}$.
Υπόδειξη: Θεώρημα 4.3.1(γ): ρίζες του παρονομαστή.
Λύση: $x^{2} + 3x - 10 = (x + 5)(x - 2) = 0 \iff x = -5$ ή $x = 2$ (ο αριθμητής δεν μηδενίζεται εκεί).
