11.1

Εισαγωγή – βασικοί τύποι και πίνακες ολοκληρωμάτων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 11 §11.1 · 1η σειρά ασκήσεων (Κεφ. 11)

Πριν από κάθε τεχνική: ένας καλός πίνακας ολοκληρωμάτων και η συνήθεια να ελέγχουμε κάθε αποτέλεσμα με παραγώγιση.

Θεωρία

Το πρόβλημα

Ολοκλήρωση σημαίνει: δοθείσης της $f$, να βρεθεί $F$ με $F' = f$. Αντίθετα με την παραγώγιση, δεν υπάρχει αλγόριθμος που δουλεύει πάντα — υπάρχουν τεχνικές (αντικατάσταση, κατά παράγοντες, μερικά κλάσματα, …) και πίνακες έτοιμων τύπων.

Βασικός πίνακας

$\begin{aligned} \int u^n du &= \tfrac{u^{n+1}}{n+1} + C\ (n \ne -1) & \int\tfrac{du}{u} &= \ln|u| + C & \int e^u du &= e^u + C \\ \int\sin u\,du &= -\cos u + C & \int\cos u\,du &= \sin u + C & \int\tan u\,du &= \ln|\sec u| + C \\ \int\sec u\,du &= \ln|\sec u + \tan u| + C & \int\tfrac{du}{a^2 + u^2} &= \tfrac1a\tan^{-1}\tfrac ua + C & \int\tfrac{du}{\sqrt{a^2 - u^2}} &= \sin^{-1}\tfrac ua + C \end{aligned}$

Χρήσιμοι τύποι από πίνακες

$\int\frac{\sqrt{a^2 + u^2}}{u^2}du = -\frac{\sqrt{a^2 + u^2}}{u} + \ln\left(u + \sqrt{a^2 + u^2}\right) + C$ · $\int\frac{du}{u^2\sqrt{u^2 - a^2}} = \frac{\sqrt{u^2 - a^2}}{a^2u} + C$ · $\int\frac{\sqrt{a^2 - u^2}}{u^2}du = -\frac{\sqrt{a^2 - u^2}}{u} - \sin^{-1}\frac ua + C$.

Γινόμενα ημιτόνων/συνημιτόνων: $\sin A\sin B = \frac12[\cos(A - B) - \cos(A + B)]$, $\sin A\cos B = \frac12[\sin(A - B) + \sin(A + B)]$, $\cos A\cos B = \frac12[\cos(A - B) + \cos(A + B)]$.

Παράδειγμα με πίνακα

$\int\sin 3x\sin 2x\,dx = \frac12\int(\cos x - \cos 5x)\,dx = \frac{\sin x}{2} - \frac{\sin 5x}{10} + C$.

Πάντα επαλήθευση

Κάθε αντιπαράγωγος ελέγχεται παραγωγίζοντας: π.χ. $\frac{d}{dx}\left(\frac{\sin x}{2} - \frac{\sin 5x}{10}\right) = \frac{\cos x - \cos 5x}{2} = \sin 3x\sin 2x$ ✓. Αυτό ακριβώς κάνει και το διαδραστικό σχήμα: συγκρίνει την κλίση της $F$ με το ύψος της $f$.

Πειραματίσου

F (αποτέλεσμα του τύπου) και f (ολοκληρωτέα). Στο x = 3,45: κλίση της F = 0,02662, f(x) = 0,02662 — ίσες, άρα F' = f ✓
Κάθε τύπος πίνακα ελέγχεται παραγωγίζοντας.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\int\sin 3x\sin 2x\,dx$.
Υπόδειξη: $\sin A\sin B = \frac12[\cos(A - B) - \cos(A + B)]$.
Λύση: $\frac12\int(\cos x - \cos 5x)dx = \frac{\sin x}{2} - \frac{\sin 5x}{10} + C$.
Άσκηση 2Βασική
Να υπολογίσετε το $\displaystyle\int\sin 2x\cos 5x\,dx$.
Υπόδειξη: $\sin A\cos B = \frac12[\sin(A - B) + \sin(A + B)]$.
Λύση: $\frac12\int(\sin(-3x) + \sin 7x)dx = \frac{\cos 3x}{6} - \frac{\cos 7x}{14} + C$.
Άσκηση 3Μέτρια
Με τη βοήθεια πίνακα, να υπολογίσετε το $\displaystyle\int\frac{\sqrt{x^2 + 5}}{x^2}\,dx$, $x > 0$.
Υπόδειξη: Τύπος για $\int\frac{\sqrt{a^2 + u^2}}{u^2}du$ με $a^2 = 5$.
Λύση: $-\frac{\sqrt{x^2 + 5}}{x} + \ln\left(x + \sqrt{x^2 + 5}\right) + C$.
Άσκηση 4Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{dx}{x^2\sqrt{x^2 - 2}}$, $x > \sqrt2$.
Υπόδειξη: $\int\frac{du}{u^2\sqrt{u^2 - a^2}} = \frac{\sqrt{u^2 - a^2}}{a^2u}$.
Λύση: Με $a^2 = 2$: $\frac{\sqrt{x^2 - 2}}{2x} + C$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{\sqrt{4 - x^2}}{x^2}\,dx$, $0 < x < 2$.
Υπόδειξη: Τύπος για $\int\frac{\sqrt{a^2 - u^2}}{u^2}du$.
Λύση: $-\frac{\sqrt{4 - x^2}}{x} - \sin^{-1}\frac x2 + C$.
Άσκηση 6Απαιτητική
Με τον τύπο $\displaystyle\int\frac{du}{u\sqrt{2au - u^2}} = -\frac{\sqrt{2au - u^2}}{au} + C$, να υπολογίσετε το $\displaystyle\int\frac{dx}{x\sqrt{6x - x^2}}$.
Υπόδειξη: $2a = 6$.
Λύση: $a = 3$: $-\frac{\sqrt{6x - x^2}}{3x} + C$.
Άσκηση 7Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{\ln x}{\sqrt x}\,dx$.
Υπόδειξη: $\int u^n\ln u\,du = \frac{u^{n+1}}{n+1}\ln u - \frac{u^{n+1}}{(n+1)^2}$ με $n = -\frac12$.
Λύση: $2\sqrt x\ln x - 4\sqrt x + C$.
Άσκηση 8Μέτρια
Με τον τύπο $\int e^{au}\cos bu\,du = \frac{e^{au}}{a^2 + b^2}(a\cos bu + b\sin bu) + C$, να υπολογίσετε το $\displaystyle\int e^x\cos 2x\,dx$.
Υπόδειξη: $a = 1$, $b = 2$.
Λύση: $\frac{e^x}{5}(\cos 2x + 2\sin 2x) + C$.
Άσκηση 9Μέτρια
Να υπολογίσετε το $\displaystyle\int_1^e x^3\ln x\,dx$ (4 δεκαδικά).
Υπόδειξη: $\int x^3\ln x = \frac{x^4}{4}\ln x - \frac{x^4}{16}$.
Λύση: $\left[\frac{x^4}{4}\ln x - \frac{x^4}{16}\right]_1^e = \frac{e^4}{4} - \frac{e^4}{16} + \frac1{16} = \frac{3e^4 + 1}{16} \approx 10{,}2997$.

♾️ Γεννήτρια — βασικά ολοκληρώματα (πίνακας)

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\int_1^{4} \frac{dx}{x}$ (4 δεκαδικά).
Υπόδειξη: Γράψτε την ολοκληρωτέα ως άθροισμα βασικών όρων και ολοκληρώστε όρο-όρο.
Λύση: $\int\frac{dx}{x} = \ln|x| + c$: $\ln 4 - \ln 1 = \ln 4 \approx 1{,}3863$.
