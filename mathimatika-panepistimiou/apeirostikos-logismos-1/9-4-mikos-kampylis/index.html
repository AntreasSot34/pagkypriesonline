9.4

Μήκος καμπύλης

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 9 §9.4

Προσεγγίζουμε την καμπύλη με τεθλασμένη γραμμή· κάθε κομμάτι έχει μήκος √(1 + f′(x)²)·Δx και το όριο δίνει ένα ολοκλήρωμα.

Θεωρία

Μήκος καμπύλης

Αν η $f$ είναι λεία στο $[a, b]$ (δηλαδή η $f'$ είναι συνεχής), το μήκος της καμπύλης $y = f(x)$ από $x = a$ έως $x = b$ είναι

$$L = \int_a^b \sqrt{1 + \big[f'(x)\big]^2}\,dx.$$
Από πού προκύπτει

Για διαμέριση $a = x_0 < \dots < x_n = b$, το ευθύγραμμο τμήμα από $(x_{k-1}, f(x_{k-1}))$ έως $(x_k, f(x_k))$ έχει μήκος $\sqrt{\Delta x_k^2 + \Delta y_k^2}$. Από το Θεώρημα Μέσης Τιμής $\Delta y_k = f'(x_k^*)\Delta x_k$, άρα το μήκος είναι $\sqrt{1 + f'(x_k^*)^2}\,\Delta x_k$ — όρος αθροίσματος Riemann της $\sqrt{1 + f'^2}$.

Παράδειγμα

$y = \frac23x^{3/2}$, $0 \le x \le 3$: $y' = x^{1/2}$, $1 + y'^2 = 1 + x$. $\ L = \int_0^3\sqrt{1 + x}\,dx = \frac23\left[(1 + x)^{3/2}\right]_0^3 = \frac23(8 - 1) = \frac{14}{3}$.

Τέλεια τετράγωνα

Πολλές ασκήσεις είναι φτιαγμένες ώστε το $1 + f'^2$ να είναι τέλειο τετράγωνο: π.χ. για $y = \frac{x^2}{2} - \frac{\ln x}{4}$ είναι $f' = x - \frac{1}{4x}$ και $1 + f'^2 = \left(x + \frac{1}{4x}\right)^2$. Τότε η ρίζα «φεύγει».

Πειραματίσου

y = x^(3/2), 0 ≤ x ≤ 4: πολυγωνική γραμμή με n = 3 τμήματα, μήκος Ln = Σ√(Δx² + Δy²) = 9,0331 · ακριβές L = ∫ab√(1 + f′(x)²) dx = (8/27)(10√10 − 1) ≈ 9,0734
Από το ΘΜΤ, Δy = f′(ξk)Δx, άρα κάθε τμήμα έχει μήκος √(1 + f′(ξk)²)Δx: το Ln είναι άθροισμα Riemann του τύπου (9.4).

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Να βρείτε το μήκος της καμπύλης $y = \frac23x^{3/2}$ για $0 \le x \le 3$.
Υπόδειξη: $1 + y'^2 = 1 + x$.
Λύση: $L = \int_0^3\sqrt{1 + x}\,dx = \frac23(8 - 1) = \frac{14}{3}$.
Άσκηση 2Μέτρια
Να βρείτε το μήκος της καμπύλης $y = x^{3/2}$ για $0 \le x \le 4$ (4 δεκαδικά).
Υπόδειξη: $y' = \frac32x^{1/2}$, $1 + y'^2 = 1 + \frac94x$· αντικατάσταση $u = 1 + \frac94x$.
Λύση: $L = \int_0^4\sqrt{1 + \tfrac94x}\,dx = \frac49\cdot\frac23\left[u^{3/2}\right]_1^{10} = \frac{8}{27}\left(10\sqrt{10} - 1\right) \approx 9{,}0734$.
Άσκηση 3Βασική
Να βρείτε με τον τύπο του μήκους καμπύλης το μήκος της $y = 3x + 1$ για $0 \le x \le 2$ (4 δεκαδικά).
Υπόδειξη: $y' = 3$.
Λύση: $L = \int_0^2\sqrt{10}\,dx = 2\sqrt{10} \approx 6{,}3246$ — όσο η απόσταση των σημείων $(0, 1)$ και $(2, 7)$.
Άσκηση 4Μέτρια
Να βρείτε το μήκος της καμπύλης $y = \dfrac{x^2}{2} - \dfrac{\ln x}{4}$ για $1 \le x \le 2$ (4 δεκαδικά).
Υπόδειξη: $1 + y'^2 = \left(x + \frac{1}{4x}\right)^2$.
Λύση: $L = \int_1^2\left(x + \frac{1}{4x}\right)dx = \frac32 + \frac{\ln 2}{4} \approx 1{,}6733$.
Άσκηση 5Μέτρια
Να βρείτε το μήκος της καμπύλης $y = \dfrac{x^3}{6} + \dfrac{1}{2x}$ για $1 \le x \le 2$.
Υπόδειξη: $y' = \frac{x^2}{2} - \frac{1}{2x^2}$, $1 + y'^2 = \left(\frac{x^2}{2} + \frac{1}{2x^2}\right)^2$.
Λύση: $L = \int_1^2\left(\frac{x^2}{2} + \frac{1}{2x^2}\right)dx = \left[\frac{x^3}{6} - \frac{1}{2x}\right]_1^2 = \frac{13}{12} + \frac13 = \frac{17}{12}$.
Άσκηση 6Απαιτητική
Να βρείτε το μήκος του τόξου $y = \sqrt{1 - x^2}$ για $0 \le x \le \frac{1}{\sqrt2}$ (4 δεκαδικά).
Υπόδειξη: $1 + y'^2 = \frac{1}{1 - x^2}$ και $\int\frac{dx}{\sqrt{1 - x^2}} = \arcsin x$.
Λύση: $L = \int_0^{1/\sqrt2}\frac{dx}{\sqrt{1 - x^2}} = \arcsin\frac{1}{\sqrt2} = \frac\pi4 \approx 0{,}7854$ — το $\frac18$ του μοναδιαίου κύκλου.
Άσκηση 7Απαιτητική
Να βρείτε το μήκος της καμπύλης $y = \ln(\cos x)$ για $0 \le x \le \frac\pi4$ (4 δεκαδικά).
Υπόδειξη: $y' = -\tan x$, $1 + \tan^2x = \sec^2x$ και $\int\sec x\,dx = \ln|\sec x + \tan x|$.
Λύση: $L = \int_0^{\pi/4}\sec x\,dx = \ln\left(\sqrt2 + 1\right) \approx 0{,}8814$.
Άσκηση 8Βασική
Για να εφαρμόσουμε τον τύπο $L = \int_a^b\sqrt{1 + f'(x)^2}\,dx$, αρκεί η $f$ να είναι συνεχής στο $[a, b]$ (χωρίς υπόθεση για την $f'$).
Υπόδειξη: Ο τύπος περιέχει την $f'$.
Λύση: Λάθος: απαιτείται η $f$ να είναι λεία, δηλαδή η $f'$ να υπάρχει και να είναι συνεχής στο $[a, b]$, ώστε το ολοκλήρωμα να έχει νόημα.

Εξάσκηση #1
Να βρείτε με τον τύπο του μήκους καμπύλης το μήκος της $y = -4x + 1$ για $0 \le x \le 1$ (4 δεκαδικά).
Υπόδειξη: $y' = -4$, σταθερή.
Λύση: $L = \int_0^{1} \sqrt{1 + 16}\,dx = 1\sqrt{17} \approx 4{,}1231$ — όσο και η απόσταση των άκρων.
