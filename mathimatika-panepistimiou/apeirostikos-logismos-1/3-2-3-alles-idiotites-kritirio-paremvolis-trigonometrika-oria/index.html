3.2.3

Άλλες ιδιότητες – Κριτήριο παρεμβολής – Τριγωνομετρικά όρια

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 3 §3.2.3 · Φυλλάδιο ασκήσεων 3

Όταν δεν μπορούμε να υπολογίσουμε ένα όριο απευθείας, το «παγιδεύουμε» ανάμεσα σε δύο γνωστά.

Θεωρία

3.2.3.1 · Διάταξη και παρεμβολή

Για οποιοδήποτε από τα όρια $\lim_{x\to a}$, $\lim_{x\to a^\pm}$, $\lim_{x\to\pm\infty}$:

  1. Αν $f(x) \le g(x)$ (κοντά στο σημείο) και υπάρχουν τα όρια, τότε $\lim f(x) \le \lim g(x)$.
  2. Αν $f(x) \le h(x) \le g(x)$ για $x$ κοντά στο σημείο (εκτός ίσως από αυτό) και $\lim f(x) = \lim g(x) = L$, τότε $\lim h(x) = L$ («ιδιότητα σάντουιτς»).

3.2.3.2 · Βασικά τριγωνομετρικά όρια

$$\text{(a)}\ \lim_{x\to0}\frac{\sin x}{x} = 1 \qquad\qquad \text{(b)}\ \lim_{x\to0}\frac{1 - \cos x}{x} = 0$$
Απόδειξη

(a) Χρησιμοποιούμε την ανισότητα $\cos x \le \frac{\sin x}{x} \le 1$ (1) κοντά στο $0$. Παίρνοντας όρια, $1 \le \lim\frac{\sin x}{x} \le 1$, άρα $\lim_{x\to0}\frac{\sin x}{x} = 1$.

Απόδειξη της (1). Στον μοναδιαίο κύκλο με γωνία $x \in (0, \frac\pi2)$ είναι $\tan x = BQ$ και (εμβαδόν τριγώνου $OPB$) $\le$ (εμβαδόν τομέα $OPB$) $\le$ (εμβαδόν τριγώνου $OQB$): $\frac12\sin x \le \frac12 x \le \frac12\tan x$. Διαιρώντας με $\frac12\sin x > 0$: $1 \le \frac{x}{\sin x} \le \frac{1}{\cos x}$, δηλαδή $\cos x \le \frac{\sin x}{x} \le 1$. Για $x < 0$ ισχύει επίσης, αφού και οι δύο πλευρές είναι άρτιες συναρτήσεις.

(b) $\frac{1 - \cos x}{x} = \frac{1 - \cos^2x}{x(1 + \cos x)} = \frac{\sin x}{x}\cdot\frac{\sin x}{1 + \cos x} \to 1\cdot\frac02 = 0$.

Παραδείγματα

  • $0 \le x^2\sin^2\frac1x \le x^2$ και $x^2 \to 0$ ⇒ $\lim_{x\to0}x^2\sin^2\frac1x = 0$ (παρεμβολή).
  • $\lim_{x\to0}\frac{\tan x}{x} = \lim\frac{\sin x}{x}\cdot\frac{1}{\cos x} = 1$ · $\lim_{x\to0}\frac{\sin 2x}{x} = 2\lim_{u\to0}\frac{\sin u}{u} = 2$ (με $u = 2x$).
  • $\lim_{x\to0}\frac{\sin 3x}{\sin 5x} = \frac{3\lim\frac{\sin 3x}{3x}}{5\lim\frac{\sin 5x}{5x}} = \frac35$ · $\lim_{x\to0}\frac{2x + \sin x}{x} = 2 + 1 = 3$.
  • $\lim_{x\to0}\frac{x\sin x}{1 - \cos x} = \lim\frac{x\cdot 2\sin\frac x2\cos\frac x2}{2\sin^2\frac x2} = \lim\frac{x}{\sin\frac x2}\cos\frac x2 = 2$.

Αλλαγή μεταβλητής

Όρια όπως $\lim_{x\to+\infty}x\sin\frac1x$ γίνονται βασικά με $t = \frac1x$: $\lim_{t\to0^+}\frac{\sin t}{t} = 1$. Για $\lim_{x\to1}\frac{\sin\pi x}{x - 1}$ θέτουμε $u = x - 1$: $\sin(\pi u + \pi) = -\sin\pi u$, άρα το όριο είναι $-\pi$.

Πειραματίσου

Εμβαδά: τρίγωνο OPB = ½ sin x = 0,392 ≤ τομέας OPB = ½ x = 0,45 ≤ τρίγωνο OQB = ½ tan x = 0,63
⇒ $\cos x \le \dfrac{\sin x}{x} \le 1$:   0,622 ≤ 0,87 ≤ 1. Καθώς x → 0⁺ το cos x → 1, άρα (παρεμβολή) $\dfrac{\sin x}{x} \to 1$.

Ασκήσεις — 0/11 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to0}\frac{\sin x}{2x}$.
Υπόδειξη: $\frac12\cdot\frac{\sin x}{x}$.
Λύση: $\frac12\cdot 1 = \frac12$.
Άσκηση 2Μέτρια
Να υπολογίσετε το $\displaystyle\lim_{x\to0}\frac{\tan 7x}{\sin 3x}$.
Υπόδειξη: $\frac{\sin 7x}{\cos 7x\,\sin 3x} = \frac73\cdot\frac{\sin 7x}{7x}\cdot\frac{3x}{\sin 3x}\cdot\frac{1}{\cos 7x}$.
Λύση: $\frac73\cdot 1\cdot 1\cdot 1 = \frac73$.
Άσκηση 3Απαιτητική
Να υπολογίσετε το $\displaystyle\lim_{h\to0}\frac{1 - \cos 5h}{\cos 7h - 1}$.
Υπόδειξη: Πολλαπλασιάστε με $(1 + \cos 5h)(1 + \cos 7h)$.
Λύση: $\frac{\sin^2 5h}{-\sin^2 7h}\cdot\frac{1 + \cos 7h}{1 + \cos 5h} = -\left[\frac{5}{7}\cdot\frac{\sin 5h}{5h}\cdot\frac{7h}{\sin 7h}\right]^2\cdot\frac22 \to -\frac{25}{49}$.
Άσκηση 4Μέτρια
Να υπολογίσετε το $\displaystyle\lim_{\theta\to0}\frac{\theta^2}{1 - \cos\theta}$.
Υπόδειξη: $1 - \cos\theta = 2\sin^2\frac\theta2$.
Λύση: $\frac{\theta^2}{2\sin^2(\theta/2)} = 2\left(\frac{\theta/2}{\sin(\theta/2)}\right)^2 \to 2$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\displaystyle\lim_{x\to+\infty}\frac{\sin 3x}{x}$.
Υπόδειξη: $-\frac1x \le \frac{\sin 3x}{x} \le \frac1x$ για $x > 0$.
Λύση: Παρεμβολή: $\pm\frac1x \to 0$, άρα το όριο είναι $0$. (Προσοχή: εδώ $x \to +\infty$, όχι $x \to 0$.)
Άσκηση 6Μέτρια
Να βρείτε το $\displaystyle\lim_{x\to0^+}\frac{\sin x}{x^2}$.
Υπόδειξη: $\frac{\sin x}{x^2} = \frac{\sin x}{x}\cdot\frac1x$.
Λύση: $\frac{\sin x}{x} \to 1$ και $\frac1x \to +\infty$, άρα το γινόμενο τείνει στο $+\infty$.
Άσκηση 7Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to0^-}\frac{\sin x}{|x|}$.
Υπόδειξη: Για $x < 0$ είναι $|x| = -x$.
Λύση: $\frac{\sin x}{-x} = -\frac{\sin x}{x} \to -1$.
Άσκηση 8Μέτρια
Με τον μετασχηματισμό $t = \frac1x$ να υπολογίσετε το $\displaystyle\lim_{x\to+\infty}x\sin\frac1x$.
Υπόδειξη: Όταν $x \to +\infty$, τότε $t \to 0^+$.
Λύση: $x\sin\frac1x = \frac{\sin t}{t} \to 1$.
Άσκηση 9Απαιτητική
Το $\displaystyle\lim_{x\to1}\frac{\sin(\pi x)}{x - 1}$ είναι της μορφής $\kappa\pi$. Να βρείτε το $\kappa$.
Υπόδειξη: Θέστε $u = x - 1$ και χρησιμοποιήστε $\sin(\theta + \pi) = -\sin\theta$.
Λύση: $\sin(\pi u + \pi) = -\sin\pi u$, άρα $\lim_{u\to0}\frac{-\sin\pi u}{u} = -\pi\lim\frac{\sin\pi u}{\pi u} = -\pi$: $\kappa = -1$.
Άσκηση 10Μέτρια
Για τη συνάρτηση $f$ ισχύει $1 - x^2 \le f(x) \le \cos x$ για κάθε $x \in \left(-\frac\pi2, \frac\pi2\right)$. Να βρείτε το $\lim_{x\to0} f(x)$.
Υπόδειξη: Κριτήριο παρεμβολής.
Λύση: $\lim_{x\to0}(1 - x^2) = 1 = \lim_{x\to0}\cos x$, άρα (Θεώρημα 3.2.3.1β) $\lim_{x\to0} f(x) = 1$.
Άσκηση 11Μέτρια
Να υπολογίσετε το $\displaystyle\lim_{x\to0}\frac{3x - \sin 5x}{x}$.
Υπόδειξη: Χωρίστε σε δύο κλάσματα.
Λύση: $3 - 5\cdot\frac{\sin 5x}{5x} \to 3 - 5 = -2$.

♾️ Γεννήτρια — τριγωνομετρικά όρια

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\lim_{x\to0}\frac{1 - \cos(2x)}{x^2}$.
Υπόδειξη: Πολλαπλασιάστε με $1 + \cos(2x)$.
Λύση: $\frac{\sin^2(2x)}{x^2(1 + \cos 2x)} = 4\left(\frac{\sin 2x}{2x}\right)^2\frac{1}{1 + \cos 2x} \to 4\cdot\frac12 = 2$.
