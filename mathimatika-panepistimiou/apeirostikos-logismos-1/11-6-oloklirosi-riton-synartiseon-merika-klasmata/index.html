11.6

Ολοκλήρωση ρητών συναρτήσεων – μερικά κλάσματα

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 11 §11.6 · 1η σειρά ασκήσεων (Κεφ. 11)

Κάθε ρητή συνάρτηση «σπάει» σε απλά κλάσματα που ολοκληρώνονται σε λογαρίθμους και τόξα εφαπτομένης.

Θεωρία

Ρητή συνάρτηση

$R(x) = \frac{P(x)}{Q(x)}$ με $P, Q$ πολυώνυμα. Αν $\deg P \ge \deg Q$, κάνουμε πρώτα διαίρεση: $\frac PQ = \Pi(x) + \frac{\Upsilon(x)}{Q(x)}$ με $\deg\Upsilon < \deg Q$.

Ανάλυση σε μερικά κλάσματα

Παραγοντοποιούμε τον $Q$ σε γραμμικούς και ανάγωγους δευτεροβάθμιους παράγοντες:

$\begin{array}{ll} (x - a) & \dfrac{A}{x - a} \\ (x - a)^k & \dfrac{A_1}{x - a} + \dfrac{A_2}{(x - a)^2} + \cdots + \dfrac{A_k}{(x - a)^k} \\ (x^2 + px + q),\ p^2 < 4q & \dfrac{Bx + C}{x^2 + px + q} \\ (x^2 + px + q)^k & \dfrac{B_1x + C_1}{x^2 + px + q} + \cdots + \dfrac{B_kx + C_k}{(x^2 + px + q)^k} \end{array}$

Τους συντελεστές τους βρίσκουμε εξισώνοντας αριθμητές, ή θέτοντας κατάλληλες τιμές του $x$ (τις ρίζες του $Q$).

$\int\frac{2x + 1}{(x - 1)(x + 3)}dx$

$\frac{2x + 1}{(x - 1)(x + 3)} = \frac{A}{x - 1} + \frac{B}{x + 3} \Rightarrow 2x + 1 = A(x + 3) + B(x - 1)$. Για $x = 1$: $3 = 4A$· για $x = -3$: $-5 = -4B$. Άρα $A = \frac34$, $B = \frac54$ και

$\int = \frac34\ln|x - 1| + \frac54\ln|x + 3| + C$.

Τα απλά κλάσματα ολοκληρώνονται

$\int\frac{dx}{x - a} = \ln|x - a| + C$ · $\int\frac{dx}{(x - a)^k} = -\frac{1}{(k - 1)(x - a)^{k-1}} + C$ ($k \ge 2$) · $\int\frac{Bx + C}{x^2 + px + q}dx$: συμπλήρωση τετραγώνου ⇒ λογάριθμος + $\tan^{-1}$.

Πειραματίσου

$\dfrac{2x + 1}{(x - 1)(x + 3)} = \dfrac{A}{x - 1} + \dfrac{B}{x + 3}$ με A = 0,75, B = 1,25.
«Κάλυψη» (θέτουμε x = p): A = (αp + β)/(p − q) = 0,75. Η μπλε καμπύλη είναι το άθροισμα της μωβ και της πορτοκαλί.
$\int f = 0,75\ln|x - 1| + 1,25\ln|x + 3| + c$

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\int\frac{2x + 1}{(x - 1)(x + 3)}\,dx$ για $x > 1$.
Υπόδειξη: $A = \frac34$, $B = \frac54$.
Λύση: $\frac34\ln|x - 1| + \frac54\ln|x + 3| + C$.
Άσκηση 2Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{dx}{(x + 1)(x + 2)(x + 3)}$ για $x > -1$.
Υπόδειξη: Θέστε $x = -1, -2, -3$.
Λύση: $\frac{1/2}{x + 1} - \frac{1}{x + 2} + \frac{1/2}{x + 3}$, άρα $\frac12\ln|x + 1| - \ln|x + 2| + \frac12\ln|x + 3| + C$.
Άσκηση 3Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{x^2 + 2x + 4}{(x + 1)^3}\,dx$ για $x > -1$.
Υπόδειξη: $x^2 + 2x + 4 = (x + 1)^2 + 3$.
Λύση: $\frac{1}{x + 1} + \frac{3}{(x + 1)^3}$, άρα $\ln|x + 1| - \frac{3}{2(x + 1)^2} + C$.
Άσκηση 4Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{x^3 - 2x}{x^2 + 3x + 2}\,dx$ για $x > -1$.
Υπόδειξη: Πρώτα διαίρεση: $x^3 - 2x = (x^2 + 3x + 2)(x - 3) + 5x + 6$.
Λύση: $x - 3 + \frac{5x + 6}{(x + 1)(x + 2)} = x - 3 + \frac{1}{x + 1} + \frac{4}{x + 2}$. Άρα $\frac{x^2}{2} - 3x + \ln|x + 1| + 4\ln|x + 2| + C$.
Άσκηση 5Απαιτητική
Να υπολογίσετε το $\displaystyle\int\frac{x^2}{(x^2 + 4)^2}\,dx$.
Υπόδειξη: $\frac{x^2}{(x^2 + 4)^2} = \frac{1}{x^2 + 4} - \frac{4}{(x^2 + 4)^2}$ και $x = 2\tan\theta$.
Λύση: $\frac14\tan^{-1}\frac x2 - \frac{x}{2(x^2 + 4)} + C$.
Άσκηση 6Απαιτητική
Να υπολογίσετε το $\displaystyle\int\frac{x + 3}{x^4 + 9x^2}\,dx$ για $x > 0$.
Υπόδειξη: $\frac{A}{x} + \frac{B}{x^2} + \frac{Cx + D}{x^2 + 9}$.
Λύση: $A = \frac19$, $B = \frac13$, $C = -\frac19$, $D = -\frac13$: $\frac19\ln|x| - \frac{1}{3x} - \frac{1}{18}\ln(x^2 + 9) - \frac19\tan^{-1}\frac x3 + C$.
Άσκηση 7Απαιτητική
Να υπολογίσετε το $\displaystyle\int\frac{dx}{x(x^2 + x + 1)}$ για $x > 0$.
Υπόδειξη: $\frac1x - \frac{x + 1}{x^2 + x + 1}$.
Λύση: $\ln|x| - \frac12\ln(x^2 + x + 1) - \frac{1}{\sqrt3}\tan^{-1}\frac{2x + 1}{\sqrt3} + C$.
Άσκηση 8Μέτρια
Να βρείτε το εμβαδόν του χωρίου ανάμεσα στην $y = \dfrac{x - 3}{x^3 + x^2}$ και τον άξονα $x$ για $1 \le x \le 2$ (4 δεκαδικά).
Υπόδειξη: $\frac{x - 3}{x^2(x + 1)} = \frac{4}{x} - \frac{3}{x^2} - \frac{4}{x + 1}$· η συνάρτηση είναι αρνητική στο $[1, 2]$.
Λύση: $\int_1^2 = \left[4\ln x + \frac3x - 4\ln(x + 1)\right]_1^2 = 4\ln\frac43 - \frac32 \approx -0{,}3493$. Εμβαδόν $\frac32 - 4\ln\frac43 \approx 0{,}3493$.
Άσκηση 9Μέτρια
Να υπολογίσετε το $\displaystyle\int_0^1\frac{x}{x^4 + 1}\,dx$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: $u = x^2$.
Λύση: $\frac12\int_0^1\frac{du}{u^2 + 1} = \frac12\cdot\frac\pi4 = \frac\pi8$.

♾️ Γεννήτρια — ανάλυση σε μερικά κλάσματα

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\int_{1}^{2}\frac{6x + 6}{x(x + 3)}\,dx$ (4 δεκαδικά).
Υπόδειξη: Παραγοντοποιήστε τον παρονομαστή και βρείτε τα $A$, $B$ θέτοντας $x$ ίσο με κάθε ρίζα.
Λύση: Μερικά κλάσματα: $\frac{2}{x} + \frac{4}{x + 3}$. Άρα $\left[2\ln|x| + 4\ln|x + 3|\right]_{1}^{2} \approx 2{,}2789$.
