5.7

Παράγωγοι ανώτερης τάξης – Ο τύπος του Leibniz

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 5 §5.7–5.7.1 (σελ. 5.31–5.38) · Προβλήματα 5.10, 5.12, 5.20, 5.42–5.44, 5.54

Η παράγωγος της παραγώγου μετρά πώς αλλάζει η κλίση· ο τύπος του Leibniz δίνει τη νιοστή παράγωγο ενός γινομένου.

Θεωρία

Παράγωγος τάξης $n$

Αν η $f'$ είναι παραγωγίσιμη, η παράγωγός της συμβολίζεται $f''$ ή $f^{(2)}$ ή $\frac{d^2f}{dx^2} = \frac{d}{dx}\left(\frac{df}{dx}\right)$ και λέγεται δεύτερη παράγωγος. Γενικά

$$f^{(n)}(x) = \frac{d}{dx}\left(\frac{d^{n - 1}f}{dx^{n - 1}}\right) = \frac{d^nf}{dx^n}.$$

Όταν υπάρχει η $f^{(n)}$, η $f$ ονομάζεται $n$ φορές παραγωγίσιμη· οι $f^{(n)}$ με $n \ge 2$ λέγονται παράγωγοι ανώτερης τάξης.

Χρήσιμες νιοστές παράγωγοι

$\dfrac{d^n}{dx^n}(x^m) = \begin{cases}\frac{m!}{(m - n)!}x^{m - n}, & n < m\\ m!, & n = m\\ 0, & n > m\end{cases}$   (π.χ. όλες οι παράγωγοι του $x^6$ τάξης $\ge 7$ είναι μηδέν).

$(e^{-ax})^{(n)} = (-1)^na^ne^{-ax}$, $\ (\ln x)^{(n)} = (-1)^{n + 1}\frac{(n - 1)!}{x^n}$, $\ (\sin x)^{(n)} = \sin\left(x + \frac{n\pi}{2}\right)$, $\ (\cos x)^{(n)} = \cos\left(x + \frac{n\pi}{2}\right)$.

5.7.1 · Ο τύπος του Leibniz

Αν οι $f, g$ είναι $n$ φορές παραγωγίσιμες, τότε

$$(fg)^{(n)} = \sum_{k = 0}^{n}\binom nk f^{(n - k)}g^{(k)}, \qquad \binom nk = \frac{n!}{k!\,(n - k)!}.$$

Για $n = 2$: $(fg)'' = f''g + 2f'g' + fg''$· για $n = 3$: $(fg)''' = f'''g + 3f''g' + 3f'g'' + fg'''$. Ο τύπος αποδεικνύεται επαγωγικά.

Παράδειγμα: νιοστή παράγωγος της $y = (x^2 + 1)e^{2x}$

Με $f = e^{2x}$ ($f^{(n)} = 2^ne^{2x}$) και $g = x^2 + 1$ ($g' = 2x$, $g'' = 2$, $g^{(k)} = 0$ για $k \ge 3$), μένουν τρεις όροι:

$y^{(n)} = 2^ne^{2x}(x^2 + 1) + n\,2^{n - 1}e^{2x}\cdot 2x + \frac{n(n - 1)}{2}2^{n - 2}e^{2x}\cdot 2 = 2^{n - 2}e^{2x}\big(4x^2 + 4nx + n^2 - n + 4\big)$.

Πειραματίσου

Στο x₀ = 0: f(x₀) = 0 · f′(x₀) = 0 · f″(x₀) = −8 · f‴(x₀) = 0
Όπου f′ > 0 η f ανεβαίνει· όπου f″ > 0 η f′ ανεβαίνει (η f «κυρτώνει προς τα πάνω»). Κάθε παράγωγος είναι η κλίση της προηγούμενης.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Για $f(x) = x^5 + 3x^4 + x^2 + 2$ να υπολογίσετε τις $f'''(1)$ και $f^{(6)}(1)$.
Υπόδειξη: $f''' = 60x^2 + 72x$.
Λύση: $f' = 5x^4 + 12x^3 + 2x$, $f'' = 20x^3 + 36x^2 + 2$, $f''' = 60x^2 + 72x$, άρα $f'''(1) = 132$. Οι παράγωγοι τάξης $\ge 6$ πολυωνύμου 5ου βαθμού είναι μηδέν.
Άσκηση 2Βασική
Για $f(x) = e^{-2x}$ να υπολογίσετε την $f^{(4)}(0)$.
Υπόδειξη: $(e^{-ax})^{(n)} = (-1)^na^ne^{-ax}$.
Λύση: $f^{(4)}(x) = (-1)^4 2^4e^{-2x}$, άρα $f^{(4)}(0) = 16$.
Άσκηση 3Βασική
Για $f(x) = \sin x$ να υπολογίσετε την $f^{(23)}(0)$.
Υπόδειξη: $f^{(n)}(x) = \sin\left(x + \frac{n\pi}{2}\right)$.
Λύση: $f^{(23)}(0) = \sin\frac{23\pi}{2} = \sin\left(10\pi + \frac{3\pi}{2}\right) = -1$.
Άσκηση 4Μέτρια
Να βρείτε τη δεύτερη παράγωγο της $y = x\sin x$.
Υπόδειξη: $y' = \sin x + x\cos x$.
Λύση: $y' = \sin x + x\cos x$, $y'' = \cos x + \cos x - x\sin x = 2\cos x - x\sin x$.
Άσκηση 5Βασική
Η $y = x\sin x$ ικανοποιεί τη διαφορική εξίσωση $y'' + y = 2\cos x$.
Υπόδειξη: Χρησιμοποιήστε τη $y''$.
Λύση: Σωστό: $y'' + y = 2\cos x - x\sin x + x\sin x = 2\cos x$.
Άσκηση 6Μέτρια
Αν $F(x) = xf(x)$, $f'(1) = 3$ και $f''(1) = -1$, να υπολογίσετε την $F''(1)$ (Πρόβλημα 5.12).
Υπόδειξη: $F' = f + xf'$, $F'' = 2f' + xf''$.
Λύση: $F''(x) = 2f'(x) + xf''(x)$, άρα $F''(1) = 6 - 1 = 5$.
Άσκηση 7Μέτρια
Με τον τύπο του Leibniz, για $y = (x^2 + 1)e^{2x}$ να υπολογίσετε την $y'''(0)$.
Υπόδειξη: $y^{(n)} = 2^{n - 2}e^{2x}(4x^2 + 4nx + n^2 - n + 4)$.
Λύση: Για $n = 3$, $x = 0$: $2\cdot(9 - 3 + 4) = 20$.
Άσκηση 8Βασική
Για $f(x) = \ln x$ να υπολογίσετε την $f^{(4)}(1)$.
Υπόδειξη: $(\ln x)^{(n)} = (-1)^{n + 1}\frac{(n - 1)!}{x^n}$.
Λύση: $f' = \frac1x$, $f'' = -\frac1{x^2}$, $f''' = \frac{2}{x^3}$, $f^{(4)} = -\frac{6}{x^4}$, άρα $f^{(4)}(1) = -6$.
Άσκηση 9Μέτρια
Η $y = x^3 + 3x + 1$ ικανοποιεί την εξίσωση $y''' + xy'' - 2y' = 0$ (Πρόβλημα 5.10).
Υπόδειξη: $y' = 3x^2 + 3$, $y'' = 6x$, $y''' = 6$.
Λύση: Σωστό: $6 + 6x^2 - 2(3x^2 + 3) = 0$.
Άσκηση 10Απαιτητική
Για $f(x) = \dfrac{1}{1 - x^2}$ να υπολογίσετε τις $f^{(4)}(0)$ και $f^{(5)}(0)$ (Πρόβλημα 5.43).
Υπόδειξη: $\frac{1}{1 - x^2} = \frac12\left[\frac{1}{1 - x} + \frac{1}{1 + x}\right]$.
Λύση: $f^{(n)}(x) = \frac{n!}{2}\left[\frac{1}{(1 - x)^{n + 1}} + \frac{(-1)^n}{(1 + x)^{n + 1}}\right]$, άρα $f^{(n)}(0) = \frac{n!}{2}\big[1 + (-1)^n\big]$: $n! = 24$ για $n = 4$ και $0$ για $n = 5$.

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Για $f(x) = \sin x$ να υπολογίσετε την $f^{(8)}(0)$.
Λύση: $f^{(n)}(x) = \sin\left(x + \frac{n\pi}{2}\right)$, άρα $f^{(8)}(0) = \sin\frac{8\pi}{2} = 0$.
