10.1

Αντίστροφη συνάρτηση

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 10 §10.1 · 10η σειρά ασκήσεων

Πότε μπορούμε να «γυρίσουμε ανάποδα» μια συνάρτηση — και πώς βρίσκουμε την κλίση της αντίστροφης χωρίς να έχουμε τον τύπο της;

Θεωρία

Αμφιμονοσήμαντη (ένα προς ένα) συνάρτηση

Η $f$ είναι αμφιμονοσήμαντη ή ένα προς ένα (1–1) αν σε κάθε στοιχείο του πεδίου τιμών αντιστοιχεί ένα μόνο στοιχείο του πεδίου ορισμού $A$:

$\forall x_1, x_2 \in A:\ x_1 \ne x_2 \Rightarrow f(x_1) \ne f(x_2)$, ισοδύναμα $f(x_1) = f(x_2) \Rightarrow x_1 = x_2$.

Γεωμετρικά: κάθε οριζόντια ευθεία $y = c$ τέμνει τη γραφική παράσταση το πολύ μία φορά.

Μονοτονία ⇒ 1–1

Αν η $f$ είναι γνησίως μονότονη (αύξουσα ή φθίνουσα), τότε είναι ένα προς ένα. Επίσης: η $f$ έχει αντίστροφη αν και μόνο αν είναι ένα προς ένα.

Αντίστροφη συνάρτηση

Έστω $f$ ένα προς ένα με πεδίο ορισμού $A$ και πεδίο τιμών $B$. Η αντίστροφη $f^{-1}: B \to A$ είναι η συνάρτηση για την οποία

$f\big(f^{-1}(x)\big) = x,\ \forall x \in B \qquad\text{και}\qquad f^{-1}\big(f(x)\big) = x,\ \forall x \in A.$

Υπολογισμός: (1) λύνουμε την $y = f(x)$ ως προς $x$· (2) εναλλάσσουμε $x$ και $y$.

Προσοχή στον συμβολισμό

Γενικά $[f(x)]^{-1} = \frac{1}{f(x)} \ne f^{-1}(x)$. Και δεν μπορούμε πάντα να βρούμε τύπο: η $f(x) = 3x^5 + 4x^3 + 2x + 1$ είναι αύξουσα (άρα αντιστρέψιμη), αλλά η $f^{-1}$ δεν γράφεται με κλειστό τύπο.

Η $f(x) = \frac{1}{2x - 3}$

$y = \frac{1}{2x - 3} \iff 2x - 3 = \frac1y \iff x = \frac{3y + 1}{2y}$. Άρα $f^{-1}(x) = \frac{3x + 1}{2x}$, με πεδίο ορισμού $\mathbb{R} - \{0\}$ και πεδίο τιμών $\mathbb{R} - \{\frac32\}$ (ακριβώς ανάποδα από την $f$).

Γραφική παράσταση της $f^{-1}$

Αν το $(a, b)$ ανήκει στη γραφική της $f$, τότε το $(b, a)$ ανήκει στη γραφική της $f^{-1}$. Άρα οι γραφικές των $f$, $f^{-1}$ είναι συμμετρικές ως προς την ευθεία $y = x$.

Συνέχεια και παράγωγος της αντίστροφης

(α) Αν η $f$ είναι συνεχής στο $[\alpha, \beta]$ και έχει αντίστροφη, τότε η $f^{-1}$ είναι συνεχής στο κλειστό διάστημα με άκρα $f(\alpha)$ και $f(\beta)$ (δηλαδή $[f(\alpha), f(\beta)]$ αν η $f$ είναι αύξουσα, $[f(\beta), f(\alpha)]$ αν είναι φθίνουσα).

(β) Αν η $f$ είναι παραγωγίσιμη και 1–1 σε διάστημα $I$ με $f'(x)\ne0$ για κάθε $x \in I$, τότε η $f^{-1}$ είναι παραγωγίσιμη στο $f(I)$ και

$\displaystyle (f^{-1})'(x) = \frac{1}{f'\big(f^{-1}(x)\big)}, \qquad\text{δηλαδή}\qquad \frac{dy}{dx} = \frac{1}{\;dx/dy\;}.$
Παράδειγμα: $f(x) = x^5 + 4x^3 + 5x + 8$

$f'(x) = 5x^4 + 12x^2 + 5 > 0$, άρα η $f^{-1}$ υπάρχει και είναι παραγωγίσιμη. Με $y = f^{-1}(x) \iff x = y^5 + 4y^3 + 5y + 8$ παραγωγίζουμε πεπλεγμένα ως προς $x$: $1 = (5y^4 + 12y^2 + 5)\frac{dy}{dx}$, άρα $\frac{dy}{dx} = \frac{1}{5y^4 + 12y^2 + 5}$.

Πειραματίσου

f(x) = x³ + x · Η ευθεία y = 2,25 τέμνει τη γραφική 1 φορά → (κριτήριο οριζόντιας ευθείας ✓).
Κλίση της f στο (a, b): 1,836 · κλίση της f⁻¹ στο (b, a): 0,545 = 1 / 1,836 — $(f^{-1})'(b) = \dfrac{1}{f'(a)}$

Σύρε πάνω στο γράφημα για να μετακινήσεις το σημείο (a, f(a)).

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να βρείτε την αντίστροφη της $f(x) = \dfrac{x + 1}{x - 1}$, $x \ne 1$. Γράψτε τον τύπο της $f^{-1}(x)$.
Υπόδειξη: Λύστε την $y = \frac{x + 1}{x - 1}$ ως προς $x$.
Λύση: $y(x - 1) = x + 1 \Rightarrow x(y - 1) = y + 1 \Rightarrow x = \frac{y + 1}{y - 1}$. Άρα $f^{-1}(x) = \frac{x + 1}{x - 1}$: η $f$ είναι αντίστροφη του εαυτού της (η γραφική της είναι συμμετρική ως προς $y = x$).
Άσκηση 2Βασική
Να βρείτε τον τύπο της $f^{-1}$ για $f(x) = 3x^3 - 5$ (γράψτε π.χ. ((x+5)/3)^(1/3)).
Υπόδειξη: $x^3 = \frac{y + 5}{3}$.
Λύση: $y = 3x^3 - 5 \iff x = \sqrt[3]{\frac{y + 5}{3}}$, άρα $f^{-1}(x) = \sqrt[3]{\frac{x + 5}{3}}$.
Άσκηση 3Μέτρια
Η $f(x) = \dfrac{5}{x^2 + 1}$, $x > 0$, είναι ένα προς ένα. Να βρείτε τον τύπο της $f^{-1}(x)$ για $0 < x < 5$.
Υπόδειξη: $x^2 + 1 = \frac5y$ και κρατάμε τη θετική ρίζα.
Λύση: $x^2 = \frac5y - 1 \Rightarrow x = \sqrt{\frac5y - 1}$ (αφού $x > 0$). Άρα $f^{-1}(x) = \sqrt{\frac{5}{x} - 1}$, $0 < x < 5$.
Άσκηση 4Μέτρια
Για την $f(x) = 2x^3 + 5x + 3$ να βρείτε το $(f^{-1})'(10)$.
Υπόδειξη: Βρείτε πρώτα $a$ με $f(a) = 10$.
Λύση: $f(1) = 2 + 5 + 3 = 10$, άρα $f^{-1}(10) = 1$. $f'(x) = 6x^2 + 5$, $f'(1) = 11$. Επομένως $(f^{-1})'(10) = \frac{1}{f'(1)} = \frac{1}{11}$.
Άσκηση 5Μέτρια
Για την $f(x) = x^7 + 2x^5 + x^3$ να βρείτε το $(f^{-1})'(4)$.
Υπόδειξη: $f(1) = 4$.
Λύση: $f(1) = 4 \Rightarrow f^{-1}(4) = 1$· $f'(x) = 7x^6 + 10x^4 + 3x^2$, $f'(1) = 20$. Άρα $(f^{-1})'(4) = \frac{1}{20}$.
Άσκηση 6Βασική
Ποια από τις παρακάτω συναρτήσεις είναι ένα προς ένα στο $\mathbb{R}$;
Υπόδειξη: Μονοτονία.
Λύση: $(x^3 + x)' = 3x^2 + 1 > 0$: γνησίως αύξουσα, άρα 1–1. Οι $x^2$, $|x|$ παίρνουν ίδια τιμή στα $\pm x$ και η $\cos x$ είναι περιοδική.
Άσκηση 7Μέτρια
Αν $f(x) = \dfrac{x^3}{x^2 + 1}$, να βρεθεί η τιμή του $x$ για την οποία $f^{-1}(x) = 2$.
Υπόδειξη: $f^{-1}(x) = 2 \iff x = f(2)$.
Λύση: $f^{-1}(x) = 2 \iff f(2) = x$, δηλαδή $x = \frac{8}{5}$.
Άσκηση 8Απαιτητική
Η $f(x) = x^4 - 2x^3$ δεν είναι ένα προς ένα στο $\mathbb{R}$. Να βρείτε τη μικρότερη τιμή του $k$ ώστε η $f$ να είναι ένα προς ένα στο $[k, +\infty)$.
Υπόδειξη: Πρόσημο της $f'(x) = 4x^3 - 6x^2$.
Λύση: $f'(x) = 2x^2(2x - 3)$: αρνητική για $x < \frac32$ ($x \ne 0$), θετική για $x > \frac32$. Η $f$ είναι γνησίως φθίνουσα στο $(-\infty, \frac32]$ και γνησίως αύξουσα στο $[\frac32, +\infty)$. Άρα $k = \frac32$.
Άσκηση 9Βασική
Για κάθε αντιστρέψιμη $f$ ισχύει $f^{-1}(x) = \dfrac{1}{f(x)}$.
Υπόδειξη: Δοκιμάστε $f(x) = x + 1$.
Λύση: Λάθος: για $f(x) = x + 1$ είναι $f^{-1}(x) = x - 1$, ενώ $\frac{1}{f(x)} = \frac{1}{x + 1}$. Το $f^{-1}$ συμβολίζει την αντίστροφη συνάρτηση, όχι το αντίστροφο του αριθμού $f(x)$.

♾️ Γεννήτρια — αντίστροφη συνάρτηση

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Η $f(x) = x^3 + 3x + 2$ είναι γνησίως αύξουσα, άρα αντιστρέψιμη. Να βρείτε το $(f^{-1})'(2)$.
Υπόδειξη: Λύστε την $y = f(x)$ ως προς $x$, ή χρησιμοποιήστε $(f^{-1})'(f(x_0)) = \frac{1}{f'(x_0)}$.
Λύση: $f(0) = 2$, οπότε $f^{-1}(2) = 0$. $f'(x) = 3x^2 + 3$, $f'(0) = 3$. Άρα $(f^{-1})'(2) = \frac{1}{f'(0)} = \frac{1}{3}$.
