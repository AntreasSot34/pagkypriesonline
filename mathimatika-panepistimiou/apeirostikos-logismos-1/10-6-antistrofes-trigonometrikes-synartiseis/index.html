10.6

Αντίστροφες τριγωνομετρικές συναρτήσεις

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 10 §10.6 · 10η σειρά ασκήσεων

Οι τριγωνομετρικές δεν είναι 1–1· περιορίζοντάς τες σε κατάλληλο διάστημα αποκτούν αντίστροφες, που μας δίνουν γωνίες από αριθμούς.

Θεωρία

Αντίστροφο ημίτονο

Η $y = \sin x$ είναι αμφιμονοσήμαντη όταν $x \in [-\frac\pi2, \frac\pi2]$. Το αντίστροφο ημίτονο, $\sin^{-1}x$ (ή $\arcsin x$), ορίζεται ως

$y = \sin^{-1}x \iff x = \sin y, \qquad -1 \le x \le 1,\ \ -\tfrac\pi2 \le y \le \tfrac\pi2.$

Δηλαδή είναι η γωνία (σε ακτίνια) του $[-\frac\pi2, \frac\pi2]$ της οποίας το ημίτονο είναι $x$. Ισχύουν $\sin(\sin^{-1}x) = x$ για $-1 \le x \le 1$ και $\sin^{-1}(\sin x) = x$ για $-\frac\pi2 \le x \le \frac\pi2$.

Οι υπόλοιπες αντίστροφες

$y = \cos^{-1}x \iff x = \cos y$, $-1 \le x \le 1$, $0 \le y \le \pi$ · $\ y = \tan^{-1}x \iff x = \tan y$, $x \in \mathbb{R}$, $-\frac\pi2 < y < \frac\pi2$.

$y = \cot^{-1}x \iff x = \cot y$, $0 < y < \pi$ · $y = \sec^{-1}x \iff x = \sec y$, $|x| \ge 1$, $y \in [0, \frac\pi2) \cup [\pi, \frac{3\pi}2)$ · $y = \csc^{-1}x \iff x = \csc y$, $|x| \ge 1$, $y \in (0, \frac\pi2] \cup (\pi, \frac{3\pi}2]$.

Ταυτότητες

Αν $a + \beta = \frac\pi2$, τότε $\sin a = \cos\beta$· θέτοντας $x = \sin a = \cos\beta$ παίρνουμε:

$\sin^{-1}x + \cos^{-1}x = \frac\pi2, \qquad \tan^{-1}x + \cot^{-1}x = \frac\pi2, \qquad \sec^{-1}x + \csc^{-1}x = \frac\pi2\ (x \ge 1)$

Επίσης $\cot^{-1}x = \tan^{-1}\frac1x$ ($x > 0$), $\sec^{-1}x = \cos^{-1}\frac1x$ και $\csc^{-1}x = \sin^{-1}\frac1x$ ($x \ge 1$).

Οι ταυτότητες του $\sec^{-1}$ για $x \le -1$

Με τη σύμβαση $\sec^{-1}x \in [0, \frac\pi2) \cup [\pi, \frac{3\pi}2)$ οι ταυτότητες που περιέχουν $\sec^{-1}$ ή $\csc^{-1}$ ισχύουν μόνο για $x \ge 1$ (στις σημειώσεις γράφονται χωρίς αυτόν τον περιορισμό). Για $x \le -1$: $\sec^{-1}x = 2\pi - \cos^{-1}\frac1x$ και $\csc^{-1}x = \pi - \sin^{-1}\frac1x$· π.χ. $\sec^{-1}(-2) = \frac{4\pi}3$, ενώ $\cos^{-1}(-\frac12) = \frac{2\pi}3$.

Η μέθοδος του τριγώνου: $\cos\left(\tan^{-1}\frac23\right)$

Θέτουμε $y = \tan^{-1}\frac23$, άρα $\tan y = \frac23$. Σε ορθογώνιο τρίγωνο με απέναντι κάθετη $2$ και προσκείμενη $3$, η υποτείνουσα είναι $\sqrt{13}$, οπότε $\cos y = \frac{3}{\sqrt{13}}$.

Πειραματίσου

Μπλε έντονο: η sin περιορισμένη στο [−π/2, π/2] (εκεί είναι ένα προς ένα). Μωβ: η αντίστροφή της sin⁻¹.
sin⁻¹(0,58) = 0,6138 rad (= 35,17°) και πράγματι sin(0,614) = 0,576.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να βρείτε την ακριβή τιμή του $\sin\left[2\cos^{-1}\left(\frac35\right)\right]$.
Υπόδειξη: $\theta = \cos^{-1}\frac35$, $\sin\theta = \frac45$.
Λύση: $\sin 2\theta = 2\sin\theta\cos\theta = 2\cdot\frac45\cdot\frac35 = \frac{24}{25}$.
Άσκηση 2Βασική
Να υπολογίσετε το $\tan^{-1}\left[\sin\left(-\frac\pi2\right)\right]$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: $\sin(-\frac\pi2) = -1$.
Λύση: $\tan^{-1}(-1) = -\frac\pi4$ (η γωνία του $(-\frac\pi2, \frac\pi2)$ με εφαπτομένη $-1$).
Άσκηση 3Βασική
Να υπολογίσετε το $\sin^{-1}\left[\cot\frac\pi4\right]$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: $\cot\frac\pi4 = 1$.
Λύση: $\sin^{-1}1 = \frac\pi2$.
Άσκηση 4Μέτρια
Να υπολογίσετε το $\sec\left[\sin^{-1}\left(-\frac34\right)\right]$ (4 δεκαδικά).
Υπόδειξη: Η γωνία είναι στο $[-\frac\pi2, 0]$, όπου $\cos > 0$.
Λύση: $\theta = \sin^{-1}(-\frac34)$: $\cos\theta = \sqrt{1 - \frac9{16}} = \frac{\sqrt7}{4}$, άρα $\sec\theta = \frac{4}{\sqrt7} \approx 1{,}5119$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\sin\left[\sin^{-1}\frac23 + \cos^{-1}\frac13\right]$ (4 δεκαδικά).
Υπόδειξη: $\sin(A + B) = \sin A\cos B + \cos A\sin B$.
Λύση: $\sin A = \frac23$, $\cos A = \frac{\sqrt5}{3}$, $\cos B = \frac13$, $\sin B = \frac{2\sqrt2}{3}$: $\frac29 + \frac{2\sqrt{10}}{9} = \frac{2 + 2\sqrt{10}}{9} \approx 0{,}9250$.
Άσκηση 6Απαιτητική
Να υπολογίσετε το $\tan\left[2\sec^{-1}\left(\frac32\right)\right]$ (4 δεκαδικά).
Υπόδειξη: $\sec\theta = \frac32 \Rightarrow \cos\theta = \frac23$, $\tan\theta = \frac{\sqrt5}{2}$.
Λύση: $\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta} = \frac{\sqrt5}{1 - \frac54} = -4\sqrt5 \approx -8{,}9443$.
Άσκηση 7Βασική
Η τιμή του $\sin^{-1}\left(\sin\frac{3\pi}{4}\right)$ είναι:
Υπόδειξη: Το αποτέλεσμα πρέπει να ανήκει στο $[-\frac\pi2, \frac\pi2]$.
Λύση: $\sin\frac{3\pi}4 = \frac{\sqrt2}2$ και η γωνία του $[-\frac\pi2, \frac\pi2]$ με αυτό το ημίτονο είναι $\frac\pi4$. Η ισότητα $\sin^{-1}(\sin x) = x$ ισχύει μόνο για $|x| \le \frac\pi2$.
Άσκηση 8Μέτρια
Με τη βοήθεια της $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\frac{x + y}{1 - xy}$, να υπολογίσετε το $\tan^{-1}\frac12 + \tan^{-1}\frac13$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: $\frac{\frac12 + \frac13}{1 - \frac16} = 1$.
Λύση: $\tan^{-1}\frac{5/6}{5/6} = \tan^{-1}1 = \frac\pi4$ (και το άθροισμα βρίσκεται στο $(-\frac\pi2, \frac\pi2)$).
Άσκηση 9Μέτρια
Ποια ταυτότητα ισχύει για κάθε $x \in [-1, 1]$;
Υπόδειξη: Συμπληρωματικές γωνίες.
Λύση: Αν $a = \sin^{-1}x$, τότε $\sin a = x = \cos(\frac\pi2 - a)$ με $\frac\pi2 - a \in [0, \pi]$, άρα $\cos^{-1}x = \frac\pi2 - a$.

♾️ Γεννήτρια — αντίστροφες τριγωνομετρικές

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Αν $y = \tan^{-1}(3x)$, να βρείτε το $y'(1)$.
Υπόδειξη: Θυμηθείτε τα πεδία τιμών: $\sin^{-1}x \in [-\frac\pi2,\frac\pi2]$, $\cos^{-1}x \in [0,\pi]$· σχεδιάστε τρίγωνο αναφοράς.
Λύση: $y' = \frac{1}{1 + (3x)^2}\cdot 3 = \frac{3}{1 + 9x^2}$, οπότε $y'(1) = \frac{3}{10}$.
