5.5.1

Παράγωγοι τριγωνομετρικών, λογαριθμικών και εκθετικών συναρτήσεων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 5 §5.5.1–5.5.2 (σελ. 5.21–5.24) · Προβλήματα 5.19, 5.20

Η κλίση της $\sin x$ σε κάθε σημείο είναι η $\cos x$ — δες το «ζωντανά» στον ιχνηλάτη παραγώγου πιο κάτω.

Θεωρία

Παράγωγοι τριγωνομετρικών συναρτήσεων

(α) $(\sin x)' = \cos x$   (β) $(\cos x)' = -\sin x$   (γ) $(\tan x)' = \sec^2x$   (δ) $(\cot x)' = -\csc^2x$   (ε) $(\sec x)' = \sec x\tan x$   (στ) $(\csc x)' = -\csc x\cot x$.

Σημείωση: οι τύποι ισχύουν μόνο όπου οι συναρτήσεις ορίζονται.

Απόδειξη του (α)

$\displaystyle(\sin x)' = \lim_{h\to0}\frac{\sin(x + h) - \sin x}{h} = \lim_{h\to0}\left[\sin x\,\frac{\cos h - 1}{h} + \cos x\,\frac{\sin h}{h}\right] = \sin x\cdot 0 + \cos x\cdot 1 = \cos x$.

(2ος τρόπος: $\sin(x + h) - \sin x = 2\sin\frac h2\cos\left(x + \frac h2\right)$.) Το (γ) προκύπτει με τον κανόνα του πηλίκου: $\left(\frac{\sin x}{\cos x}\right)' = \frac{\cos^2x + \sin^2x}{\cos^2x} = \sec^2x$.

Παράγωγοι λογαριθμικών και εκθετικών

$$(\ln x)' = \frac1x\ (x > 0), \qquad (e^x)' = e^x, \qquad (a^x)' = a^x\ln a\ (a > 0).$$

Π.χ. $(e^{-x})' = \left(\frac{1}{e^x}\right)' = -\frac{e^x}{(e^x)^2} = -e^{-x}$. Για τις υπερβολικές $\sinh x = \frac{e^x - e^{-x}}{2}$, $\cosh x = \frac{e^x + e^{-x}}{2}$: $(\sinh x)' = \cosh x$, $(\cosh x)' = \sinh x$.

Όρια μέσω παραγώγου

$\displaystyle\lim_{x\to0}\frac{1 - \cos x}{x} = -\lim_{x\to0}\frac{\cos x - \cos0}{x} = -\left.\frac{d}{dx}\cos x\right|_{x = 0} = \sin0 = 0$,   $\displaystyle\lim_{x\to0}\frac{\tan(3 + x) - \tan3}{x} = \left.\frac{d}{dx}\tan x\right|_{x = 3} = \sec^2 3$.

Πειραματίσου

Στο x = −2,496: κλίση της εφαπτομένης = −0,799. Το μωβ σημείο έχει τεταγμένη ίση με την κλίση και, καθώς κινείται, γράφει το γράφημα της παραγώγου: (sin x)′ = cos x.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να βρείτε την παράγωγο της $y = x^2\tan x$ (γράψτε π.χ. tan(x), 1/cos(x)^2).
Υπόδειξη: Κανόνας γινομένου, $(\tan x)' = \sec^2x$.
Λύση: $y' = 2x\tan x + x^2\sec^2x = 2x\tan x + \dfrac{x^2}{\cos^2x}$.
Άσκηση 2Βασική
Για $f(x) = \dfrac{\sin x}{1 + \cos x}$ να υπολογίσετε την $f'(0)$.
Υπόδειξη: Κανόνας πηλίκου και $\sin^2x + \cos^2x = 1$.
Λύση: $f'(x) = \dfrac{\cos x(1 + \cos x) + \sin^2x}{(1 + \cos x)^2} = \dfrac{1 + \cos x}{(1 + \cos x)^2} = \dfrac{1}{1 + \cos x}$, άρα $f'(0) = \frac12$.
Άσκηση 3Μέτρια
Να υπολογίσετε την παράγωγο της $\sec x$ στο $x = \frac\pi4$ (δεκαδικός, 4 ψηφία).
Υπόδειξη: $(\sec x)' = \sec x\tan x$.
Λύση: $\sec\frac\pi4\tan\frac\pi4 = \sqrt2\cdot1 \approx 1{,}4142$.
Άσκηση 4Μέτρια
Αναγνωρίζοντας παράγωγο, να υπολογίσετε (α) $\displaystyle\lim_{x\to0}\frac{1 - \cos x}{x}$ και (β) $\displaystyle\lim_{x\to0}\frac{\tan(3 + x) - \tan3}{x}$ (δεκαδικός, 4 ψηφία).
Υπόδειξη: (α) $-\frac{\cos x - \cos0}{x}$· (β) η παράγωγος της $\tan x$ στο $3$.
Λύση: (α) $-\left.(\cos x)'\right|_0 = \sin 0 = 0$. (β) $\sec^23 = \frac{1}{\cos^23} \approx \frac{1}{0{,}98010} \approx 1{,}0203$.
Άσκηση 5Βασική
Να βρείτε την παράγωγο της $y = e^x\sin x$ (γράψτε π.χ. e^x*sin(x)).
Υπόδειξη: Κανόνας γινομένου.
Λύση: $y' = e^x\sin x + e^x\cos x = e^x(\sin x + \cos x)$.
Άσκηση 6Βασική
Για $f(x) = x\ln x - x$ ($x > 0$) να υπολογίσετε την $f'(e)$.
Υπόδειξη: $(x\ln x)' = \ln x + 1$.
Λύση: $f'(x) = \ln x + x\cdot\frac1x - 1 = \ln x$, άρα $f'(e) = 1$.
Άσκηση 7Μέτρια
Να υπολογίσετε την παράγωγο της $2^x$ στο $x = 3$ (δεκαδικός, 3 ψηφία).
Υπόδειξη: $(a^x)' = a^x\ln a$.
Λύση: $2^3\ln2 = 8\cdot0{,}6931 \approx 5{,}545$.
Άσκηση 8Βασική
Η παράγωγος της $\cosh x$ είναι:
Υπόδειξη: $\cosh x = \frac{e^x + e^{-x}}{2}$.
Λύση: $\left(\frac{e^x + e^{-x}}{2}\right)' = \frac{e^x - e^{-x}}{2} = \sinh x$ (χωρίς αλλαγή προσήμου, σε αντίθεση με την $\cos x$).
Άσκηση 9Μέτρια
Να υπολογίσετε τις παραγώγους στο $x = 0$ των (α) $f(x) = \sin^2x + \cos^2x$ και (β) την παράγωγο της $g(x) = \dfrac{1}{\cot x}$ στο $x = \frac\pi4$ (Πρόβλημα 5.19).
Υπόδειξη: (α) η $f$ είναι σταθερή. (β) $\frac{1}{\cot x} = \tan x$.
Λύση: (α) $f \equiv 1$, άρα $f' = 0$ (ή $2\sin x\cos x - 2\cos x\sin x = 0$). (β) Όπου ορίζεται, $g = \tan x$, άρα $g' = \sec^2x$ και $g'\!\left(\frac\pi4\right) = \frac{1}{\cos^2(\pi/4)} = 2$.
Άσκηση 10Βασική
Ισχύει $\dfrac{d}{dx}\left(e^{-x}\right) = -e^{-x}$.
Υπόδειξη: $e^{-x} = \frac{1}{e^x}$.
Λύση: Σωστό: $\left(\frac{1}{e^x}\right)' = -\frac{e^x}{e^{2x}} = -e^{-x}$.

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε την $f'(0)$ για $f(x) = (x + 2)\,e^{-x}$.
Λύση: $f'(x) = e^{-x} + (x + 2)\cdot (-1)e^{-x}$, άρα $f'(0) = 1 + 2\cdot (-1) = -1$.
