11.3

Ολοκλήρωση κατά παράγοντες και αναγωγικοί τύποι

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 11 §11.3 · 1η σειρά ασκήσεων (Κεφ. 11)

Ο κανόνας του γινομένου «ανάποδα»: μεταφέρουμε την παράγωγο από τον έναν παράγοντα στον άλλο.

Θεωρία

Ολοκλήρωση κατά παράγοντες

$\displaystyle\int u\,dv = uv - \int v\,du, \qquad \int_a^b u\,dv = \Big[uv\Big]_a^b - \int_a^b v\,du.$
Απόδειξη

$(uv)' = u'v + uv'$, άρα $uv = \int u'v\,dx + \int uv'\,dx$, δηλαδή $\int u\,dv = uv - \int v\,du$.

Επιλογή του $u$: παίρνουμε ως $u$ αυτό που «απλοποιείται» με την παραγώγιση — με σειρά προτίμησης Λογάριθμος, Αντίστροφη τριγωνομετρική, Πολυώνυμο, Τριγωνομετρική, Εκθετική.

Παραδείγματα

(i) $\int x\cos x\,dx$: $u = x$, $dv = \cos x\,dx$ ⇒ $x\sin x - \int\sin x\,dx = x\sin x + \cos x + C$.

(ii) $\int\ln x\,dx$: $u = \ln x$, $dv = dx$ ⇒ $x\ln x - \int x\cdot\frac1x dx = x\ln x - x + C$.

(iii) $\int x^2e^{-x}dx$: δύο φορές κατά παράγοντες ⇒ $-e^{-x}(x^2 + 2x + 2) + C$.

(iv) Κυκλικό: $I = \int e^{-3x}\sin 3x\,dx$. Δύο φορές κατά παράγοντες ξαναδίνουν το $I$: $I = -\frac{e^{-3x}}{3}\sin 3x - \frac{e^{-3x}}{3}\cos 3x - I$, άρα $I = -\frac{e^{-3x}}{6}(\sin 3x + \cos 3x) + C$.

Αναγωγικοί τύποι

Με $u = \sin^{n-1}x$, $dv = \sin x\,dx$ και $\cos^2x = 1 - \sin^2x$:

$\displaystyle\int\sin^n x\,dx = -\frac{\sin^{n-1}x\cos x}{n} + \frac{n - 1}{n}\int\sin^{n-2}x\,dx, \qquad I_n = \int_0^{\pi/2}\sin^n x\,dx = \frac{n - 1}{n}I_{n-2}.$

Ανάλογα: $\int\cos^n x\,dx = \frac{\cos^{n-1}x\sin x}{n} + \frac{n-1}{n}\int\cos^{n-2}x\,dx$ · $\int(\ln x)^n dx = x(\ln x)^n - n\int(\ln x)^{n-1}dx$ · $\int x^ne^x dx = x^ne^x - n\int x^{n-1}e^x dx$.

Π.χ. $I_6 = \frac56\cdot\frac34\cdot\frac12\cdot\frac\pi2 = \frac{5\pi}{32}$.

Π.χ. $\int_0^1 x^{3}e^x\,dx$ ≈ 0,56344.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\int x\cos x\,dx$.
Υπόδειξη: $u = x$, $dv = \cos x\,dx$.
Λύση: $x\sin x - \int\sin x\,dx = x\sin x + \cos x + C$.
Άσκηση 2Βασική
Να υπολογίσετε το $\displaystyle\int_1^e\ln x\,dx$.
Υπόδειξη: $\int\ln x = x\ln x - x$.
Λύση: $[x\ln x - x]_1^e = (e - e) - (0 - 1) = 1$.
Άσκηση 3Μέτρια
Να υπολογίσετε το $\displaystyle\int x\tan^{-1}x\,dx$.
Υπόδειξη: $u = \tan^{-1}x$, $dv = x\,dx$ και $\frac{x^2}{1 + x^2} = 1 - \frac{1}{1 + x^2}$.
Λύση: $\frac{x^2}{2}\tan^{-1}x - \frac12\int\frac{x^2}{1 + x^2}dx = \frac{x^2}{2}\tan^{-1}x - \frac x2 + \frac12\tan^{-1}x + C$.
Άσκηση 4Μέτρια
Να υπολογίσετε το $\displaystyle\int x^2e^{-x}\,dx$.
Υπόδειξη: Δύο φορές κατά παράγοντες με $u = x^2$, μετά $u = x$.
Λύση: $-x^2e^{-x} + 2\int xe^{-x}dx = -x^2e^{-x} - 2xe^{-x} - 2e^{-x} + C = -e^{-x}(x^2 + 2x + 2) + C$.
Άσκηση 5Απαιτητική
Να υπολογίσετε το $\displaystyle\int e^{-3x}\sin 3x\,dx$.
Υπόδειξη: Κυκλικό ολοκλήρωμα: δύο φορές κατά παράγοντες και λύσιμο ως προς $I$.
Λύση: $2I = -\frac{e^{-3x}}{3}(\sin 3x + \cos 3x)$, άρα $I = -\frac{e^{-3x}}{6}(\sin 3x + \cos 3x) + C$.
Άσκηση 6Μέτρια
Να υπολογίσετε το $\displaystyle\int\cos^{-1}2x\,dx$.
Υπόδειξη: $u = \cos^{-1}2x$, $dv = dx$.
Λύση: $x\cos^{-1}2x + \int\frac{2x}{\sqrt{1 - 4x^2}}dx = x\cos^{-1}2x - \frac12\sqrt{1 - 4x^2} + C$.
Άσκηση 7Βασική
Με τον αναγωγικό τύπο, να υπολογίσετε το $\displaystyle\int_0^{\pi/2}\sin^6x\,dx$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: $I_n = \frac{n - 1}{n}I_{n-2}$, $I_0 = \frac\pi2$.
Λύση: $I_6 = \frac56\cdot\frac34\cdot\frac12\cdot\frac\pi2 = \frac{15\pi}{96} = \frac{5\pi}{32}$.
Άσκηση 8Μέτρια
Το χωρίο κάτω από την $y = \ln x$, $1 \le x \le 5$, περιστρέφεται γύρω από τον άξονα $x$. Να βρείτε τον όγκο (4 δεκαδικά).
Υπόδειξη: $\int(\ln x)^2dx = x(\ln x)^2 - 2x\ln x + 2x$.
Λύση: $V = \pi\int_1^5(\ln x)^2dx = \pi\left[x(\ln x)^2 - 2x\ln x + 2x\right]_1^5 = \pi\left(5\ln^25 - 10\ln 5 + 8\right) \approx 15{,}2589$.
Άσκηση 9Απαιτητική
Με τον αναγωγικό τύπο $\displaystyle\int x^m(\ln x)^n dx = \frac{x^{m+1}(\ln x)^n}{m + 1} - \frac{n}{m + 1}\int x^m(\ln x)^{n-1}dx$, να υπολογίσετε το $\displaystyle\int_1^e x^3(\ln x)^3dx$ (4 δεκαδικά).
Υπόδειξη: Τρεις εφαρμογές με $m = 3$.
Λύση: Η αντιπαράγωγος είναι $\frac{x^4}{4}(\ln x)^3 - \frac{3x^4}{16}(\ln x)^2 + \frac{3x^4}{32}\ln x - \frac{3x^4}{128}$. Από $1$ έως $e$: $e^4\left(\frac14 - \frac3{16} + \frac3{32} - \frac3{128}\right) + \frac3{128} = \frac{17e^4 + 3}{128} \approx 7{,}2748$.

♾️ Γεννήτρια — ολοκλήρωση κατά παράγοντες

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\int_0^1 x\,e^{3x}\,dx$ (4 δεκαδικά).
Υπόδειξη: $\int u\,dv = uv - \int v\,du$· διαλέξτε για $u$ τον πολυωνυμικό ή λογαριθμικό παράγοντα.
Λύση: $u = x$, $dv = e^{3x}dx$ ⇒ $du = dx$, $v = \frac13e^{3x}$. $\int x e^{3x}dx = \frac13xe^{3x} - \frac1{9}e^{3x} + c$. Από 0 έως 1: $\frac{e^{3}(3 - 1) + 1}{9} \approx 4{,}5746$.
