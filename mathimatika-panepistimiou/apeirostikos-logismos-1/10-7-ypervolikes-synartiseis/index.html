10.7

Υπερβολικές συναρτήσεις

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 10 §10.7 · 10η σειρά ασκήσεων

Συνδυασμοί των $e^x$ και $e^{-x}$ που συμπεριφέρονται σχεδόν σαν το ημίτονο και το συνημίτονο — με την υπερβολή στη θέση του κύκλου.

Θεωρία

Υπερβολικό ημίτονο και συνημίτονο

$\displaystyle \sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}, \qquad x \in \mathbb{R}.$

Οι υπόλοιπες υπερβολικές

$\tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ · $\coth x = \frac{\cosh x}{\sinh x}$ ($x \ne 0$) · $\operatorname{sech}x = \frac{1}{\cosh x}$ · $\operatorname{csch}x = \frac{1}{\sinh x}$ ($x \ne 0$).

Ταυτότητες

Από τις γραφικές: $\cosh(-x) = \cosh x$ (άρτια), $\sinh(-x) = -\sinh x$ (περιττή). Η βασική ταυτότητα, αντίστοιχη της $\cos^2x + \sin^2x = 1$:

$\cosh^2 x - \sinh^2 x = 1$
Απόδειξη

$\cosh^2x - \sinh^2x = \frac{(e^x + e^{-x})^2 - (e^x - e^{-x})^2}{4} = \frac14\left(e^{2x} + 2 + e^{-2x} - e^{2x} + 2 - e^{-2x}\right) = \frac14\cdot 4 = 1$.

Με τον ίδιο τρόπο: $1 - \tanh^2x = \operatorname{sech}^2x$ · $\coth^2x - 1 = \operatorname{csch}^2x$ · $\sinh(x \pm y) = \sinh x\cosh y \pm \cosh x\sinh y$ · $\cosh(x \pm y) = \cosh x\cosh y \pm \sinh x\sinh y$ · $\sinh 2x = 2\sinh x\cosh x$ · $\cosh 2x = \cosh^2x + \sinh^2x$ · $\cosh^2x = \frac12(1 + \cosh 2x)$ · $\sinh^2x = \frac12(-1 + \cosh 2x)$.

Αν $\sinh x = -\frac12$

$\cosh x = \sqrt{1 + \sinh^2x} = \sqrt{1 + \frac14} = \frac{\sqrt5}{2}$ (το $\cosh$ είναι πάντα θετικό). Τότε $\tanh x = -\frac{1}{\sqrt5}$, $\coth x = -\sqrt5$, $\operatorname{sech}x = \frac{2}{\sqrt5}$, $\operatorname{csch}x = -2$.

Γιατί «υπερβολικές»;

Το σημείο $(\cosh t, \sinh t)$ βρίσκεται πάνω στην υπερβολή $x^2 - y^2 = 1$, όπως το $(\cos t, \sin t)$ βρίσκεται στον κύκλο $x^2 + y^2 = 1$ — δείτε το διαδραστικό σχήμα.

Πειραματίσου

cosh 0,72 = 1,271, sinh 0,72 = 0,784, tanh = 0,617.
Έλεγχος ταυτότητας: cosh²t − sinh²t = 1 · Το μωβ εμβαδόν είναι t/2 = 0,36 — όπως στον κύκλο ο τομέας γωνίας t έχει εμβαδόν t/2 (από εκεί το όνομα «υπερβολικές»).

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Αν $\sinh x = -\frac12$, να βρείτε τα $\cosh x$ και $\tanh x$ (4 δεκαδικά).
Υπόδειξη: $\cosh x = \sqrt{1 + \sinh^2x}$.
Λύση: $\cosh x = \frac{\sqrt5}{2} \approx 1{,}1180$ και $\tanh x = \frac{-1/2}{\sqrt5/2} = -\frac{1}{\sqrt5} \approx -0{,}4472$.
Άσκηση 2Βασική
Να υπολογίσετε ακριβώς το $\tanh(\ln 3)$.
Υπόδειξη: $e^{\ln 3} = 3$, $e^{-\ln 3} = \frac13$.
Λύση: $\tanh(\ln 3) = \frac{3 - \frac13}{3 + \frac13} = \frac{8/3}{10/3} = \frac45$.
Άσκηση 3Μέτρια
Αν $\cosh x = \frac54$ και $x > 0$, να βρείτε τα $\sinh x$ και $\cosh 2x$.
Υπόδειξη: $\sinh x = \sqrt{\cosh^2x - 1}$ (θετικό για $x > 0$).
Λύση: $\sinh x = \sqrt{\frac{25}{16} - 1} = \frac34$. $\cosh 2x = \cosh^2x + \sinh^2x = \frac{25}{16} + \frac{9}{16} = \frac{17}{8}$.
Άσκηση 4Μέτρια
Να υπολογίσετε το $\displaystyle\int_{-1}^{1}e^{2x}\,dx$ και να επαληθεύσετε ότι ισούται με $\sinh 2$ (4 δεκαδικά).
Υπόδειξη: $\int_{-a}^a e^{bx}dx = \frac{2\sinh ab}{b}$.
Λύση: $\frac12(e^2 - e^{-2}) = \sinh 2 \approx 3{,}6269$.
Άσκηση 5Μέτρια
Με τη βοήθεια της $(\sinh x + \cosh x)^n = \sinh nx + \cosh nx$, να υπολογίσετε το $(\sinh x + \cosh x)^3$ για $x = \ln 2$.
Υπόδειξη: $\sinh x + \cosh x = e^x$.
Λύση: $\sinh x + \cosh x = e^x = 2$, άρα $2^3 = 8$ (και $\sinh(3\ln 2) + \cosh(3\ln 2) = e^{3\ln 2} = 8$).
Άσκηση 6Βασική
Για κάθε $x \in \mathbb{R}$ ισχύει $-1 < \tanh x < 1$.
Υπόδειξη: $|e^x - e^{-x}| < e^x + e^{-x}$.
Λύση: Σωστό: $|\sinh x| < \cosh x$ αφού $\cosh^2x - \sinh^2x = 1 > 0$ και $\cosh x > 0$.
Άσκηση 7Βασική
Να βρείτε το $\displaystyle\lim_{x\to+\infty}\tanh x$.
Υπόδειξη: Διαιρέστε με $e^x$.
Λύση: $\frac{1 - e^{-2x}}{1 + e^{-2x}} \to 1$.
Άσκηση 8Βασική
Ποια ταυτότητα είναι σωστή;
Υπόδειξη: Ορισμοί μέσω $e^{\pm x}$.
Λύση: $\cosh^2x - \sinh^2x = 1$. Οι άλλες: $\cosh^2x + \sinh^2x = \cosh 2x$, $\sinh 2x = 2\sinh x\cosh x$ και το $\cosh$ είναι άρτια.
Άσκηση 9Απαιτητική
Το χωρίο ανάμεσα στις $y = \cosh 2x$ και $y = \sinh 2x$ για $0 \le x \le 1$ περιστρέφεται γύρω από τον άξονα $x$. Να βρείτε τον όγκο ως $k\pi$: δώστε το $k$.
Υπόδειξη: $V = \pi\int_0^1(\cosh^2 2x - \sinh^2 2x)\,dx$.
Λύση: Η ολοκληρωτέα είναι $\cosh^2 2x - \sinh^2 2x = 1$, άρα $V = \pi\int_0^1 1\,dx = \pi$.

♾️ Γεννήτρια — υπερβολικές συναρτήσεις

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Αν $y = \cosh(2x)$, να βρείτε το $y'(1)$ (4 δεκαδικά).
Υπόδειξη: $\cosh^2x - \sinh^2x = 1$, $\cosh x > 0$, $\sinh$ περιττή, $\cosh$ άρτια.
Λύση: $(\cosh u)' = \sinh u\cdot u'$: $y' = 2\sinh(2x)$, $y'(1) = 2\sinh 2 \approx 7{,}2537$.
