1.5

Απόλυτη τιμή – Εξισώσεις και ανισώσεις – Τριγωνική ανισότητα

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 1 §1.5 · 1η σειρά ασκήσεων (άσκ. 8–11, 13–15)

Η απόλυτη τιμή μετρά απόσταση· η τριγωνική ανισότητα θα είναι το βασικό εργαλείο στα όρια με ε–δ.

Θεωρία

1.5.1 · Απόλυτη τιμή (μέτρο)

$$|x| = \begin{cases} \ \ x, & x \ge 0 \\ -x, & x < 0 \end{cases}$$

Είναι ο αριθμός «χωρίς το πρόσημό του»: $|3| = 3$, $|-6| = 6$, $|x^2| = x^2$. Η $|x - a|$ είναι η απόσταση των $x$ και $a$ στην ευθεία.

Ιδιότητες

(α) $|x| \ge 0$   (β) $|x| = 0 \iff x = 0$   (γ) $|xy| = |x||y|$   (δ) $|x + y| \le |x| + |y|$ (τριγωνική ανισότητα)

(ε) $|x| = |-x|$   (στ) $-|x| \le x \le |x|$   (ζ) $|x - y| \le |x| + |y|$   (θ) $\big||x| - |y|\big| \le |x - y|$

$$|x| \le \lambda \iff -\lambda \le x \le \lambda \qquad (\lambda \ge 0)$$

Γενίκευση (με επαγωγή): $|x_1 + x_2 + \dots + x_n| \le |x_1| + |x_2| + \dots + |x_n|$.

Απόδειξη της τριγωνικής ανισότητας

Από την (στ): $-|x| \le x \le |x|$ και $-|y| \le y \le |y|$. Προσθέτοντας: $-(|x| + |y|) \le x + y \le |x| + |y|$, και από την τελευταία ιδιότητα με $\lambda = |x| + |y|$ παίρνουμε $|x + y| \le |x| + |y|$.

Εξίσωση με δύο απόλυτα · $|x - 5| + |x - 2| = 3x + 4$

Λύση με περιπτώσεις (πίνακας)

Κρίσιμα σημεία $2$ και $5$.

  • $x < 2$: $-x + 5 - x + 2 = 3x + 4 \Rightarrow x = \frac35$ ✓ (ανήκει στο $(-\infty, 2)$).
  • $2 \le x < 5$: $-x + 5 + x - 2 = 3x + 4 \Rightarrow x = -\frac13$ ✗.
  • $x \ge 5$: $2x - 7 = 3x + 4 \Rightarrow x = -11$ ✗.

Μοναδική λύση $x = \frac35$.

Φράγμα με την τριγωνική ανισότητα

Για $x \in [-1, 2]$: $|x^2 - 2x - 4| \le |x|^2 + 2|x| + 4 \le 2^2 + 2\cdot 2 + 4 = 12$. Άρα αρκεί $M = 12$.

Πειραματίσου

f(x) = |x − 2| − |x − 4| = 1
Κλάδοι: x < 2: f(x) = −2 · 2 ≤ x < 4: f(x) = 2x − 6 · x ≥ 4: f(x) = 2
Λύσεις: 3,5

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Να λύσετε την εξίσωση $7|x| + 4 = 5|x| + 8$ (δύο λύσεις).
Υπόδειξη: Λύστε ως προς $|x|$.
Λύση: $2|x| = 4 \Rightarrow |x| = 2 \Rightarrow x = \pm 2$.
Άσκηση 2Βασική
Να λύσετε την εξίσωση $|x^2 - 3x + 2| = 2$ στους πραγματικούς (δύο λύσεις).
Υπόδειξη: $x^2 - 3x + 2 = 2$ ή $= -2$.
Λύση: $x^2 - 3x + 2 = 2 \Rightarrow x(x - 3) = 0 \Rightarrow x = 0, 3$. $\ x^2 - 3x + 2 = -2 \Rightarrow x^2 - 3x + 4 = 0$, διακρίνουσα $9 - 16 < 0$: καμία πραγματική λύση.
Άσκηση 3Μέτρια
Να λύσετε την εξίσωση $|x - 5| + |x - 2| = 3x + 4$.
Υπόδειξη: Περιπτώσεις $x < 2$, $2 \le x < 5$, $x \ge 5$.
Λύση: Για $x < 2$: $7 - 2x = 3x + 4 \Rightarrow x = \frac35$ ✓. Για $2 \le x < 5$: $3 = 3x + 4 \Rightarrow x = -\frac13$ ✗. Για $x \ge 5$: $2x - 7 = 3x + 4 \Rightarrow x = -11$ ✗.
Άσκηση 4Βασική
Η λύση της ανίσωσης $2|x| - 8 < |x| - 4$ είναι διάστημα $(\alpha, \beta)$. Να βρείτε τα $\alpha, \beta$.
Υπόδειξη: Ανίσωση ως προς $|x|$.
Λύση: $|x| < 4 \iff -4 < x < 4$.
Άσκηση 5Μέτρια
Η λύση της ανίσωσης $|x - 4|^2 + |x - 4| - 12 \ge 0$ είναι:
Υπόδειξη: Θέστε $u = |x - 4| \ge 0$.
Λύση: $u^2 + u - 12 = (u + 4)(u - 3) \ge 0$ και $u + 4 > 0$, άρα $u \ge 3$: $|x - 4| \ge 3 \iff x \le 1$ ή $x \ge 7$.
Άσκηση 6Μέτρια
Να βρείτε τον μικρότερο θετικό αριθμό $M$ που δίνει η τριγωνική ανισότητα (με $|x| \le 5$) ώστε $|x^3 - 1| \le M$ για κάθε $x \in [-5, 3)$.
Υπόδειξη: $|x^3 - 1| \le |x|^3 + 1$.
Λύση: $|x^3 - 1| \le |x^3| + |-1| = |x|^3 + 1 \le 5^3 + 1 = 126$, αφού στο $[-5, 3)$ ισχύει $|x| \le 5$.
Άσκηση 7Βασική
Για όλους τους πραγματικούς $x, y$ ισχύει $|x - y| \le |x| - |y|$.
Υπόδειξη: Δοκιμάστε $x = 0$, $y = 1$.
Λύση: Λάθος: για $x = 0$, $y = 1$: $|0 - 1| = 1 > |0| - |1| = -1$. Ισχύει η $\big||x| - |y|\big| \le |x - y|$.
Άσκηση 8Απαιτητική
Να λύσετε την ανίσωση $|x - 3| + 2|x - 1| < 2x + 8$. Η λύση είναι διάστημα $(\alpha, \beta)$.
Υπόδειξη: Περιπτώσεις $x < 1$, $1 \le x < 3$, $x \ge 3$.
Λύση: $x < 1$: $-3x + 5 < 2x + 8 \Rightarrow x > -\frac35$, άρα $\left(-\frac35, 1\right)$. $\ 1 \le x < 3$: $x + 1 < 2x + 8 \Rightarrow x > -7$, άρα $[1, 3)$. $\ x \ge 3$: $3x - 5 < 2x + 8 \Rightarrow x < 13$, άρα $[3, 13)$. Ένωση: $\left(-\frac35, 13\right)$.

♾️ Γεννήτρια — απόλυτη τιμή

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να λύσετε την εξίσωση $|x - 4| = 7$. Δώστε τη μικρότερη και τη μεγαλύτερη λύση.
Λύση: $|u| = 7 \iff u = 7$ ή $u = -7$: $x - 4 = \pm 7$, άρα $x = -3$ ή $x = 11$.
