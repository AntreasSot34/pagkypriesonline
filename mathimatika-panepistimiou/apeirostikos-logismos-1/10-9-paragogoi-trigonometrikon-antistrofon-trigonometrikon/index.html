10.9

Παράγωγοι τριγωνομετρικών, αντίστροφων τριγωνομετρικών, υπερβολικών και αντίστροφων υπερβολικών

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 10 §10.9 · 10η σειρά ασκήσεων

Όλοι οι τύποι προκύπτουν με δύο εργαλεία: τον ορισμό μέσω $e^x$ και την πεπλεγμένη παραγώγιση.

Θεωρία

Τριγωνομετρικές (υπενθύμιση)

$\frac{d}{dx}\sin x = \cos x$, $\frac{d}{dx}\cos x = -\sin x$, $\frac{d}{dx}\tan x = \sec^2x$, $\frac{d}{dx}\cot x = -\csc^2x$, $\frac{d}{dx}\sec x = \sec x\tan x$, $\frac{d}{dx}\csc x = -\csc x\cot x$.

Αντίστροφες τριγωνομετρικές

$\begin{aligned} \tfrac{d}{dx}\sin^{-1}x &= \tfrac{1}{\sqrt{1 - x^2}} & \tfrac{d}{dx}\cos^{-1}x &= -\tfrac{1}{\sqrt{1 - x^2}} & \tfrac{d}{dx}\tan^{-1}x &= \tfrac{1}{1 + x^2} \\ \tfrac{d}{dx}\cot^{-1}x &= -\tfrac{1}{1 + x^2} & \tfrac{d}{dx}\sec^{-1}x &= \tfrac{1}{x\sqrt{x^2 - 1}} & \tfrac{d}{dx}\csc^{-1}x &= -\tfrac{1}{x\sqrt{x^2 - 1}} \end{aligned}$
Απόδειξη για τον $\sin^{-1}$

$y = \sin^{-1}x \iff x = \sin y$, $-\frac\pi2 \le y \le \frac\pi2$. Παραγωγίζουμε ως προς $x$: $1 = \cos y\,\frac{dy}{dx}$, άρα $\frac{dy}{dx} = \frac{1}{\cos y} = \frac{1}{\sqrt{1 - \sin^2y}} = \frac{1}{\sqrt{1 - x^2}}$ (θετική ρίζα, αφού $\cos y \ge 0$ στο διάστημα αυτό).

Υπερβολικές

$\tfrac{d}{dx}\sinh x = \cosh x,\ \ \tfrac{d}{dx}\cosh x = \sinh x,\ \ \tfrac{d}{dx}\tanh x = \operatorname{sech}^2x,\ \ \tfrac{d}{dx}\coth x = -\operatorname{csch}^2x,\ \ \tfrac{d}{dx}\operatorname{sech}x = -\operatorname{sech}x\tanh x,\ \ \tfrac{d}{dx}\operatorname{csch}x = -\operatorname{csch}x\coth x$
Απόδειξη για τον $\cosh$

$\frac{d}{dx}\cosh x = \frac12\left[\frac{d}{dx}e^x + \frac{d}{dx}e^{-x}\right] = \frac12(e^x - e^{-x}) = \sinh x$.

Αντίστροφες υπερβολικές

$\begin{aligned} \tfrac{d}{dx}\sinh^{-1}x &= \tfrac{1}{\sqrt{1 + x^2}} & \tfrac{d}{dx}\cosh^{-1}x &= \tfrac{1}{\sqrt{x^2 - 1}}\ (x > 1) & \tfrac{d}{dx}\tanh^{-1}x &= \tfrac{1}{1 - x^2}\ (|x| < 1) \\ \tfrac{d}{dx}\coth^{-1}x &= \tfrac{1}{1 - x^2}\ (|x| > 1) & \tfrac{d}{dx}\operatorname{sech}^{-1}x &= -\tfrac{1}{x\sqrt{1 - x^2}}\ (0 < x < 1) & \tfrac{d}{dx}\operatorname{csch}^{-1}x &= -\tfrac{1}{|x|\sqrt{1 + x^2}}\ (x \ne 0) \end{aligned}$
Δύο αποδείξεις: $\cosh^{-1}$ (πεπλεγμένα) και $\tanh^{-1}$ (με λογαρίθμους)

$y = \cosh^{-1}x \iff x = \cosh y$: $1 = \sinh y\frac{dy}{dx} \Rightarrow \frac{dy}{dx} = \frac{1}{\sinh y} = \frac{1}{\sqrt{\cosh^2y - 1}} = \frac{1}{\sqrt{x^2 - 1}}$.

$y = \tanh^{-1}x = \frac12[\ln(1 + x) - \ln(1 - x)]$: $y' = \frac12\left[\frac1{1 + x} + \frac1{1 - x}\right] = \frac12\cdot\frac{2}{1 - x^2} = \frac{1}{1 - x^2}$.

Πειραματίσου

f(x) = tan⁻¹x · f′(x) = 1/(1 + x²) · Η κλίση της πορτοκαλί εφαπτομένης στο x₀ = 1,13 ισούται με το ύψος της μωβ καμπύλης: 0,4401.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να βρείτε την παράγωγο της $y = \tan^{-1}\left(xe^{2x}\right)$.
Υπόδειξη: $(\tan^{-1}u)' = \frac{u'}{1 + u^2}$.
Λύση: $u = xe^{2x}$, $u' = e^{2x} + 2xe^{2x}$, άρα $y' = \frac{e^{2x}(1 + 2x)}{1 + x^2e^{4x}}$.
Άσκηση 2Βασική
Να βρείτε την παράγωγο της $y = \tan^{-1}\left(\dfrac{1 - x}{1 + x}\right)$ και να την απλοποιήσετε.
Υπόδειξη: $u' = \frac{-2}{(1 + x)^2}$.
Λύση: $y' = \frac{1}{1 + \frac{(1 - x)^2}{(1 + x)^2}}\cdot\frac{-2}{(1 + x)^2} = \frac{-2}{(1 + x)^2 + (1 - x)^2} = \frac{-2}{2 + 2x^2} = -\frac{1}{1 + x^2}$.
Άσκηση 3Βασική
Να βρείτε την παράγωγο της $y = \sin^{-1}x + \cos^{-1}x$.
Υπόδειξη: Ταυτότητα της §10.6.
Λύση: $y' = \frac{1}{\sqrt{1 - x^2}} - \frac{1}{\sqrt{1 - x^2}} = 0$ — αναμενόμενο, αφού $y = \frac\pi2$ σταθερή.
Άσκηση 4Μέτρια
Αν $y = \sin^{-1}\left(e^{-3x}\right)$, $x > 0$, να βρείτε το $y'(1)$ (4 δεκαδικά).
Υπόδειξη: $u = e^{-3x}$, $u' = -3e^{-3x}$.
Λύση: $y' = \frac{-3e^{-3x}}{\sqrt{1 - e^{-6x}}}$, $y'(1) = \frac{-3e^{-3}}{\sqrt{1 - e^{-6}}} \approx -0{,}1495$.
Άσκηση 5Μέτρια
Αν $y = \ln(\tanh 2x)$, $x > 0$, να βρείτε το $y'\!\left(\frac14\right)$ (4 δεκαδικά).
Υπόδειξη: $y' = \frac{2\operatorname{sech}^2 2x}{\tanh 2x} = \frac{2}{\sinh 2x\cosh 2x} = \frac{4}{\sinh 4x}$.
Λύση: $y' = \frac{4}{\sinh 4x}$, άρα $y'(\frac14) = \frac{4}{\sinh 1} \approx 3{,}4037$.
Άσκηση 6Μέτρια
Αν $y = \sinh^3(2x)$, να βρείτε το $y'\!\left(\frac12\right)$ (3 δεκαδικά).
Υπόδειξη: $y' = 3\sinh^2(2x)\cosh(2x)\cdot 2$.
Λύση: $y' = 6\sinh^2 2x\cosh 2x$, $y'(\frac12) = 6\sinh^2 1\cosh 1 \approx 12{,}787$.
Άσκηση 7Μέτρια
Αν $y = (\tanh^{-1}x)^2$, να βρείτε το $y'\!\left(\frac12\right)$ (4 δεκαδικά).
Υπόδειξη: $y' = 2\tanh^{-1}x\cdot\frac{1}{1 - x^2}$.
Λύση: $y'(\frac12) = \frac{2\tanh^{-1}(1/2)}{3/4} = \frac83\cdot\frac12\ln 3 = \frac43\ln 3 \approx 1{,}4648$.
Άσκηση 8Μέτρια
Αν $y = \sinh^{-1}(\tanh x)$, να βρείτε το $y'(0)$.
Υπόδειξη: $y' = \frac{\operatorname{sech}^2x}{\sqrt{1 + \tanh^2x}}$.
Λύση: $y'(0) = \frac{1}{\sqrt{1 + 0}} = 1$.
Άσκηση 9Βασική
Η παράγωγος της $\cosh^{-1}x$, $x > 1$, είναι:
Υπόδειξη: Πεπλεγμένη παραγώγιση της $x = \cosh y$.
Λύση: $\frac{dy}{dx} = \frac1{\sinh y} = \frac{1}{\sqrt{x^2 - 1}}$. Ο τύπος $\frac1{\sqrt{1 - x^2}}$ είναι του $\sin^{-1}$, και ο $\frac1{\sqrt{x^2 + 1}}$ του $\sinh^{-1}$.
