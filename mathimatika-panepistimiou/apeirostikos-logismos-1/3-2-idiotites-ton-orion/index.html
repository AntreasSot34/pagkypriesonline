3.2

Ιδιότητες των ορίων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 3 §3.2 · Φυλλάδιο ασκήσεων 3

Τα όρια σέβονται τις πράξεις: το όριο αθροίσματος είναι το άθροισμα των ορίων — με λίγες, σημαντικές προϋποθέσεις.

Θεωρία

Όρια βασικών συναρτήσεων

3.2.1 · Ιδιότητες των ορίων

Έστω ότι «$\lim$» είναι οποιοδήποτε από τα $\lim_{x\to a}$, $\lim_{x\to a^-}$, $\lim_{x\to a^+}$, $\lim_{x\to+\infty}$, $\lim_{x\to-\infty}$ και ότι υπάρχουν τα $\lim f(x) = L_1$ και $\lim g(x) = L_2$. Τότε:

  1. $\lim\,[f(x) \pm g(x)] = L_1 \pm L_2$
  2. $\lim\,[f(x)\,g(x)] = L_1 L_2$
  3. $\lim\dfrac{f(x)}{g(x)} = \dfrac{L_1}{L_2}$, αν $L_2 \ne 0$
  4. $\lim\sqrt[n]{f(x)} = \sqrt[n]{L_1}$, όπου $n \in \mathbb{N}$ και, όταν ο $n$ είναι άρτιος, $L_1 \ge 0$.

Συνέπειες: $\lim\,[\kappa f(x)] = \kappa L_1$ ($\kappa$ σταθερά) και $\lim\,[f(x)]^n = L_1^n$. Οι (a), (b) γενικεύονται για πεπερασμένο πλήθος συναρτήσεων, εφόσον όλα τα όρια υπάρχουν.

Όταν η μία συνάρτηση απειρίζεται

Αν $\lim f(x) = L_1$ και $\lim g(x) = +\infty$, τότε $\lim\,[f(x) + g(x)] = +\infty$, ενώ $\lim\,[f(x)g(x)] = +\infty$ αν $L_1 > 0$ και $-\infty$ αν $L_1 < 0$.

Υπολογισμοί

$\lim_{x\to2}(x^3 + x^2 - 1) = 8 + 4 - 1 = 11$ · $\lim_{x\to1}[(x - 1)(x^2 + 1)] = 0\cdot 2 = 0$ · $\lim_{x\to-1}\frac{x^2 + 1}{x + 2} = \frac{2}{1} = 2$ · $\lim_{x\to1}\sqrt{x^3 + x^2 - 1} = \sqrt{1} = 1$.

Προσοχή

Οι ιδιότητες απαιτούν να υπάρχουν και τα δύο όρια. Π.χ. για $f = \frac1x$, $g = -\frac1x$ στο $0$ υπάρχει το $\lim(f + g) = 0$, ενώ τα $\lim f$, $\lim g$ δεν υπάρχουν. Και στο πηλίκο χρειάζεται $L_2 \ne 0$: η περίπτωση $\frac00$ θέλει άλλη αντιμετώπιση (§3.2.2).

Πειραματίσου

$f(x) = x^2 + 1 \to L_1 = 5$, $g(x) = x - 3 \to L_2 = -1$ όταν $x \to 2$.
Για x = 1: (f + g)(x) = 0 · για x = 3: 10
Θεώρημα 3.2.1: $\lim_{x\to 2}$ (f + g) = L₁ + L₂ = 5 + (−1) = 4.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to-1}(2x^3 - x + 4)$.
Υπόδειξη: Αντικαταστήστε $x = -1$.
Λύση: $2(-1)^3 - (-1) + 4 = -2 + 1 + 4 = 3$.
Άσκηση 2Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to3}\frac{x^2 + 1}{x + 2}$.
Υπόδειξη: Ο παρονομαστής δεν μηδενίζεται στο $3$.
Λύση: $\frac{9 + 1}{3 + 2} = \frac{10}{5} = 2$ (Θεώρημα 3.2.1γ).
Άσκηση 3Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to1}\sqrt{x^3 + 3x + 5}$.
Υπόδειξη: Ιδιότητα (δ): η ρίζα «βγαίνει» έξω από το όριο.
Λύση: $\sqrt{\lim_{x\to1}(x^3 + 3x + 5)} = \sqrt{9} = 3$.
Άσκηση 4Μέτρια
Αν $\lim_{x\to a} f(x) = 3$ και $\lim_{x\to a} g(x) = -2$, να υπολογίσετε το $\displaystyle\lim_{x\to a}\frac{2f(x) - g(x)^2}{f(x) + g(x)}$.
Υπόδειξη: Ο παρονομαστής έχει όριο $1 \ne 0$.
Λύση: $\frac{2\cdot 3 - (-2)^2}{3 + (-2)} = \frac{6 - 4}{1} = 2$.
Άσκηση 5Βασική
Ποια ιδιότητα του Θεωρήματος 3.2.1 απαιτεί επιπλέον υπόθεση για το όριο $L_2 = \lim g(x)$;
Υπόδειξη: Πότε δεν ορίζεται ένα κλάσμα;
Λύση: Για το πηλίκο χρειάζεται $L_2 \ne 0$.
Άσκηση 6Μέτρια
Αν $\lim_{x\to a} f(x) = -2$ και $\lim_{x\to a} g(x) = +\infty$, τότε $\lim_{x\to a}[f(x)\,g(x)]$ είναι:
Υπόδειξη: Αρνητικός αριθμός επί κάτι που μεγαλώνει απεριόριστα.
Λύση: $L_1 = -2 < 0$, άρα $f g \to -\infty$.
Άσκηση 7Μέτρια
Αν $\lim_{x\to a} f(x) = 4$ και $\lim_{x\to a} g(x) = +\infty$, τότε $\lim_{x\to a}[f(x) + g(x)]$ είναι:
Υπόδειξη: Ένα πεπερασμένο κομμάτι συν κάτι που απειρίζεται.
Λύση: $f + g \to +\infty$.
Άσκηση 8Βασική
Αν υπάρχει το $\lim_{x\to a}[f(x) + g(x)]$, τότε υπάρχουν και τα $\lim_{x\to a} f(x)$, $\lim_{x\to a} g(x)$.
Υπόδειξη: Δοκιμάστε $f = \frac1x$, $g = -\frac1x$.
Λύση: Λάθος: για $f = \frac1x$, $g = -\frac1x$ είναι $f + g = 0 \to 0$, ενώ τα όρια των $f$, $g$ στο $0$ δεν υπάρχουν.
Άσκηση 9Απαιτητική
Αν $\lim_{x\to a} f(x) = 2$ και $\lim_{x\to a}[f(x)\,g(x)] = 6$, να βρείτε το $\lim_{x\to a} g(x)$.
Υπόδειξη: Κοντά στο $a$ είναι $f(x) \ne 0$, οπότε $g = \frac{fg}{f}$.
Λύση: Αφού $\lim f = 2 \ne 0$, κοντά στο $a$ ισχύει $f(x) \ne 0$ και $g(x) = \frac{f(x)g(x)}{f(x)}$. Από το (γ): $\lim g = \frac62 = 3$.
Άσκηση 10Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to2}[(x^3 - 1)(x + 1)]$.
Υπόδειξη: Όριο γινομένου.
Λύση: $(8 - 1)(2 + 1) = 7\cdot 3 = 21$.
