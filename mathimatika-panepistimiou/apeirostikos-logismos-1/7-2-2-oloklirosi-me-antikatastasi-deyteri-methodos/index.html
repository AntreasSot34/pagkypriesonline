7.2.2

Ολοκλήρωση με αντικατάσταση — δεύτερη μέθοδος

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 7 §7.2.2, Πίνακας 1 · Προβλήματα 7.6

Όταν το ολοκλήρωμα δεν έχει «έτοιμη» τη μορφή f(u)·u′, θέτουμε x = g(u) και μετασχηματίζουμε ολόκληρο το ολοκλήρωμα.

Θεωρία

Δεύτερη μέθοδος ολοκλήρωσης με αντικατάσταση

Θεωρούμε το αόριστο ολοκλήρωμα $\int f(x)\,dx$ και τον μετασχηματισμό $x = g(u)$, όπου η $g(u)$ είναι παραγωγίσιμη, γνησίως μονότονη και φραγμένη σε κάποιο διάστημα που μας ενδιαφέρει. Τότε $dx = g'(u)\,du$ και

$$\int f(x)\,dx = \int f(g(u))\,g'(u)\,du.$$

Η δεύτερη μέθοδος είναι πιο γενική από την πρώτη. Στο τέλος επιστρέφουμε στο $x$ μέσω της αντίστροφης $u = g^{-1}(x)$ — γι' αυτό χρειάζεται η μονοτονία της $g$.

Υπολογισμός του $\int x^2\sqrt{x-1}\,dx$

Λύση βήμα-βήμα

Θέτουμε $u = x - 1 \Rightarrow x = u + 1$ και $dx = du$:

$$\int x^2\sqrt{x-1}\,dx = \int (u+1)^2u^{1/2}\,du = \int \left(u^{5/2} + 2u^{3/2} + u^{1/2}\right)du$$ $$= \frac27 u^{7/2} + \frac45 u^{5/2} + \frac23 u^{3/2} + c = \frac27(x-1)^{7/2} + \frac45(x-1)^{5/2} + \frac23(x-1)^{3/2} + c.$$

Ποια αντικατάσταση;

  • $\sqrt{ax + b}$ μέσα στο ολοκλήρωμα: $u = ax + b$ (ή $u = \sqrt{ax+b}$).
  • $\sqrt x$ σε παρονομαστή αθροίσματος, π.χ. $\frac{1}{1+\sqrt x}$: $x = u^2$.
  • $\sqrt{1 - x^2}$: $x = \sin t$ (θα το δούμε στο Κεφ. 11).

Υπάρχουν και άλλες μέθοδοι: ανάλυση σε απλά κλάσματα, παραγοντική ολοκλήρωση, αναγωγικοί τύποι (Κεφ. 11). Ο Πίνακας 1 των σημειώσεων δίνει τα ολοκληρώματα των βασικών συναρτήσεων.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να βρείτε το $\displaystyle\int x\sqrt{x - 2}\,dx$.
Υπόδειξη: $u = x - 2$, οπότε $x = u + 2$, $dx = du$.
Λύση: $\int (u + 2)u^{1/2}du = \int (u^{3/2} + 2u^{1/2})\,du = \frac25u^{5/2} + \frac43u^{3/2} + c = \frac25(x - 2)^{5/2} + \frac43(x - 2)^{3/2} + c$.
Άσκηση 2Βασική
Να βρείτε το $\displaystyle\int \frac{x}{\sqrt{x + 3}}\,dx$.
Υπόδειξη: $u = x + 3$, $x = u - 3$.
Λύση: $\int \frac{u - 3}{\sqrt u}\,du = \int (u^{1/2} - 3u^{-1/2})\,du = \frac23u^{3/2} - 6u^{1/2} + c = \frac23(x + 3)^{3/2} - 6\sqrt{x + 3} + c$.
Άσκηση 3Μέτρια
Να βρείτε το $\displaystyle\int x^2\sqrt{x + 1}\,dx$.
Υπόδειξη: $u = x + 1$, $x^2 = (u - 1)^2 = u^2 - 2u + 1$.
Λύση: $\int (u^2 - 2u + 1)u^{1/2}du = \frac27u^{7/2} - \frac45u^{5/2} + \frac23u^{3/2} + c$ με $u = x + 1$.
Άσκηση 4Μέτρια
Να βρείτε το $\displaystyle\int x(2x + 1)^4\,dx$.
Υπόδειξη: $u = 2x + 1$: $x = \frac{u - 1}{2}$, $dx = \frac{du}{2}$.
Λύση: $\int \frac{u - 1}{2}\,u^4\,\frac{du}{2} = \frac14\int (u^5 - u^4)\,du = \frac{u^6}{24} - \frac{u^5}{20} + c = \frac{(2x + 1)^6}{24} - \frac{(2x + 1)^5}{20} + c$.
Άσκηση 5Μέτρια
Να βρείτε το $\displaystyle\int \frac{dx}{1 + \sqrt x}$.
Υπόδειξη: $x = u^2$ $(u \ge 0)$, $dx = 2u\,du$, και $\frac{2u}{1 + u} = 2 - \frac{2}{1 + u}$.
Λύση: $\int\frac{2u\,du}{1 + u} = \int\left(2 - \frac{2}{1 + u}\right)du = 2u - 2\ln(1 + u) + c = 2\sqrt x - 2\ln(1 + \sqrt x) + c$.
Άσκηση 6Απαιτητική
Να βρείτε το $\displaystyle\int x^3\sqrt{x^2 + 1}\,dx$.
Υπόδειξη: $u = x^2 + 1$: $x^2 = u - 1$ και $x\,dx = \frac{du}{2}$.
Λύση: $\int x^2\sqrt{x^2 + 1}\,x\,dx = \frac12\int (u - 1)u^{1/2}du = \frac15u^{5/2} - \frac13u^{3/2} + c = \frac15(x^2 + 1)^{5/2} - \frac13(x^2 + 1)^{3/2} + c$.
Άσκηση 7Μέτρια
Να βρείτε το $\displaystyle\int \frac{x}{(x + 1)^3}\,dx$.
Υπόδειξη: $u = x + 1$, $\frac{u - 1}{u^3} = u^{-2} - u^{-3}$.
Λύση: $\int (u^{-2} - u^{-3})\,du = -\frac1u + \frac{1}{2u^2} + c = -\frac{1}{x + 1} + \frac{1}{2(x + 1)^2} + c$.
Άσκηση 8Βασική
Για το $\displaystyle\int x\sqrt{x + 5}\,dx$ ποια αντικατάσταση είναι η κατάλληλη;
Υπόδειξη: Τι «ενοχλεί» μέσα στη ρίζα;
Λύση: Με $u = x + 5$ το ολοκλήρωμα γίνεται $\int (u - 5)u^{1/2}du$, άθροισμα δυνάμεων του $u$.
Άσκηση 9Απαιτητική
Έστω $F$ η παράγουσα της $f(x) = \dfrac{x}{\sqrt{x + 1}}$ με $F(0) = 0$. Να βρείτε το $F(3)$.
Υπόδειξη: Βρείτε πρώτα το $\int\frac{x}{\sqrt{x+1}}dx$ με $u = x + 1$ και μετά τη σταθερά.
Λύση: $F(x) = \frac23(x + 1)^{3/2} - 2(x + 1)^{1/2} + c$, $F(0) = \frac23 - 2 + c = 0 \Rightarrow c = \frac43$. $F(3) = \frac23\cdot 8 - 2\cdot 2 + \frac43 = \frac{16}{3} - 4 + \frac43 = \frac83$.

♾️ Γεννήτρια — δεύτερη μέθοδος αντικατάστασης

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε το $\displaystyle\int \frac{x}{\sqrt{x + 4}}\,dx$.
Υπόδειξη: $u = x + 4$, οπότε $x = u - 4$.
Λύση: $\int (u^{1/2} - 4u^{-1/2})du = \frac23 u^{3/2} - 8u^{1/2} + c = \frac23(x + 4)^{3/2} - 8\sqrt{x + 4} + c$.
