4.2

Είδη ασυνεχειών

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 4 §4.2 · Φυλλάδιο ασκήσεων 4

Δεν είναι όλες οι ασυνέχειες ίδιες: κάποιες «διορθώνονται» αλλάζοντας μία τιμή, άλλες όχι.

Θεωρία

Ασυνέχειες πρώτου είδους (απλές)

Η $f$ παρουσιάζει ασυνέχεια στο $c$, αλλά υπάρχουν τα πλευρικά όρια $\lim_{x\to c^-} f(x)$ και $\lim_{x\to c^+} f(x)$.

  • Αν είναι ίσα, η ασυνέχεια λέγεται διορθώσιμη ή αιρόμενη: την αίρουμε θέτοντας $f(c) = \lim_{x\to c} f(x)$.
  • Αν είναι διαφορετικά, η $f$ παρουσιάζει πεπερασμένο πήδημα με μήκος $\left|\lim_{x\to c^-} f(x) - \lim_{x\to c^+} f(x)\right|$.

Ασυνέχειες δεύτερου είδους (ουσιώδεις)

Η $f$ παρουσιάζει ασυνέχεια στο $c$ και τουλάχιστον ένα από τα πλευρικά όρια δεν υπάρχει. Διακρίνουμε, για παράδειγμα: (α) άπειρο πήδημα, (β) η $f$ απειρίζεται θετικά ή αρνητικά στο $c$, (γ) ταλάντωση: το πλευρικό όριο δεν υπάρχει ούτε ως $\pm\infty$, π.χ. $\sin\frac1x$ στο $0$.

Άρση ασυνέχειας

Η $f(x) = \frac{\sin x}{x}$ δεν ορίζεται στο $0$, άρα είναι ασυνεχής εκεί· η ασυνέχεια είναι αιρόμενη αφού $\lim_{x\to0}\frac{\sin x}{x} = 1$. Θέτουμε $f(0) = 1$.

Η $f(x) = \frac{x^2 - 4}{x - 2}$: $\lim_{x\to2}\frac{x^2-4}{x-2} = \lim(x + 2) = 4$, άρα θέτουμε $f(2) = 4$.

Πειραματίσου

Υπάρχουν τα πλευρικά όρια και είναι ίσα (= 1): ασυνέχεια 1ου είδους, αιρόμενη. Τσέκαρε την «άρση» για να οριστεί f(c) = lim f.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Η $f(x) = \dfrac{x^2 - 4}{x - 2}$ στο $x = 2$ παρουσιάζει:
Υπόδειξη: Υπάρχει το όριο στο $2$;
Λύση: Δεν ορίζεται στο $2$ (ασυνεχής), αλλά $\lim_{x\to2} f = 4$: αιρόμενη, με $f(2) = 4$.
Άσκηση 2Βασική
Να βρείτε το μήκος του πηδήματος της $f(x) = \begin{cases} x + 1, & x < 0 \\ x + 3, & x \ge 0\end{cases}$ στο $0$.
Υπόδειξη: $\left|\lim_{x\to0^-} f - \lim_{x\to0^+} f\right|$.
Λύση: $|1 - 3| = 2$.
Άσκηση 3Βασική
Η $f(x) = \dfrac{1}{(x - 1)^2}$ στο $x = 1$ παρουσιάζει:
Υπόδειξη: Πλευρικά όρια;
Λύση: Και τα δύο πλευρικά όρια είναι $+\infty$, δηλαδή δεν υπάρχουν: ουσιώδης ασυνέχεια (απειρίζεται θετικά).
Άσκηση 4Βασική
Πώς πρέπει να οριστεί το $f(0)$ ώστε η $f(x) = \dfrac{\sin 3x}{x}$ $(x \ne 0)$ να γίνει συνεχής;
Υπόδειξη: $3\cdot\frac{\sin 3x}{3x}$.
Λύση: $\lim_{x\to0}\frac{\sin 3x}{x} = 3$, άρα $f(0) = 3$.
Άσκηση 5Μέτρια
Η $f(x) = \dfrac{2x^4 - 6x^3 + x^2 + 3}{x - 1}$ είναι ασυνεχής στο $1$. Ποια τιμή $f(1)$ αίρει την ασυνέχεια;
Υπόδειξη: Ο αριθμητής έχει παράγοντα $x - 1$.
Λύση: $\frac{(x - 1)(2x^3 - 4x^2 - 3x - 3)}{x - 1} \to 2 - 4 - 3 - 3 = -8$. Θέτουμε $f(1) = -8$.
Άσκηση 6Μέτρια
Η $F(x) = \begin{cases} |x - 3|, & x \ne 3 \\ 2, & x = 3\end{cases}$ στο $3$ παρουσιάζει:
Υπόδειξη: $\lim_{x\to3}|x - 3|$;
Λύση: $\lim_{x\to3}F = 0 \ne 2 = F(3)$. Το όριο υπάρχει, άρα η ασυνέχεια αίρεται θέτοντας $F(3) = 0$.
Άσκηση 7Μέτρια
Η $f(x) = \dfrac{x - |x|}{x}$ ορίζεται για $x \ne 0$. Να βρείτε το μήκος του πηδήματος στο $0$.
Υπόδειξη: Για $x > 0$: $f = 0$. Για $x < 0$: $|x| = -x$.
Λύση: $x > 0$: $\frac{x - x}{x} = 0$. $x < 0$: $\frac{x + x}{x} = 2$. Μήκος $|2 - 0| = 2$.
Άσκηση 8Βασική
Μια ασυνέχεια πεπερασμένου πηδήματος αίρεται αν αλλάξουμε κατάλληλα την τιμή $f(c)$.
Υπόδειξη: Υπάρχει το $\lim_{x\to c} f$;
Λύση: Λάθος: τα πλευρικά όρια διαφέρουν, άρα το όριο δεν υπάρχει· καμία τιμή $f(c)$ δεν ικανοποιεί τη συνθήκη (β) του ορισμού.
Άσκηση 9Μέτρια
Η $g(x) = \begin{cases} \dfrac{1}{x - 2}, & x \ne 2 \\ 3, & x = 2\end{cases}$ στο $2$ παρουσιάζει:
Υπόδειξη: Πλευρικά όρια $\pm\infty$.
Λύση: $\lim_{x\to2^\pm}\frac{1}{x-2} = \pm\infty$: τα πλευρικά όρια δεν υπάρχουν (άπειρο πήδημα).
Άσκηση 10Απαιτητική
Δίνεται $f(x) = \dfrac{x^5 - 1}{x - 1}$ για $x \ne 1$. Να οριστεί το $f(1)$ ώστε η $f$ να είναι συνεχής.
Υπόδειξη: $\lim_{x\to1}\frac{x^m - 1}{x - 1} = m$.
Λύση: $x^5 - 1 = (x - 1)(x^4 + x^3 + x^2 + x + 1)$, άρα το όριο είναι $5$: $f(1) = 5$.

♾️ Γεννήτρια — είδος ασυνέχειας

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Τι είδους σημείο είναι για την $f(x) = \frac{x^{2} - 2x}{x}$ στο $x = 0$;
Υπόδειξη: Εξετάστε αν υπάρχουν και αν είναι ίσα τα πλευρικά όρια.
Λύση: Δεν ορίζεται στο $0$, αλλά $\lim_{x\to 0} f = \lim (x - 2) = -2$: αιρόμενη ασυνέχεια (θέτουμε $f(0) = -2$).
