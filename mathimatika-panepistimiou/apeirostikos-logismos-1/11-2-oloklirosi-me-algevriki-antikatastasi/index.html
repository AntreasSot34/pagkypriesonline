11.2

Ολοκλήρωση με αλγεβρική αντικατάσταση

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 11 §11.2 · 1η σειρά ασκήσεων (Κεφ. 11)

Ο κανόνας της αλυσίδας «ανάποδα»: αλλάζουμε μεταβλητή ώστε το ολοκλήρωμα να γίνει κάποιο του πίνακα.

Θεωρία

Μέθοδος της αντικατάστασης

Αν $u = g(x)$ έχει συνεχή παράγωγο $g'$ (στο $[a,b]$ για το ορισμένο) και η $f$ είναι συνεχής στο $g([a,b])$, τότε

$\displaystyle\int f\big(g(x)\big)g'(x)\,dx = \int f(u)\,du, \qquad \int_a^b f\big(g(x)\big)g'(x)\,dx = \int_{g(a)}^{g(b)}f(u)\,du.$

Στο ορισμένο ολοκλήρωμα αλλάζουμε και τα όρια — έτσι δεν χρειάζεται να επιστρέψουμε στο $x$.

Γιατί ισχύει

Αν $F' = f$, τότε από τον κανόνα της αλυσίδας $\frac{d}{dx}F(g(x)) = f(g(x))g'(x)$. Άρα $\int f(g(x))g'(x)dx = F(g(x)) + C = F(u) + C$.

Παραδείγματα

(i) $\int x^2\sqrt{x^3 + 1}\,dx$: $u = x^3 + 1$, $du = 3x^2dx$: $\frac13\int u^{1/2}du = \frac29(x^3 + 1)^{3/2} + C$.

(ii) $\int_0^{\sqrt\pi}x\sin x^2\,dx$: $u = x^2$, όρια $0 \to \pi$: $\frac12\int_0^\pi\sin u\,du = \frac12[-\cos u]_0^\pi = 1$.

(iii) $\int\frac{dx}{x + \sqrt x}$: $u = \sqrt x$, $x = u^2$, $dx = 2u\,du$: $\int\frac{2u\,du}{u^2 + u} = 2\int\frac{du}{u + 1} = 2\ln(\sqrt x + 1) + C$.

Τριώνυμα $ax^2 + bx + c$: συμπλήρωση τετραγώνου

Γράφουμε $x^2 + bx + c = \left(x + \frac b2\right)^2 + \left(c - \frac{b^2}4\right)$ και θέτουμε $u = x + \frac b2$. Π.χ.

$\int\frac{x + 4}{x^2 + 6x + 18}dx = \int\frac{x + 4}{(x + 3)^2 + 9}dx \overset{u = x + 3}{=} \int\frac{u + 1}{u^2 + 9}du = \frac12\ln(u^2 + 9) + \frac13\tan^{-1}\frac u3 + C.$

Πειραματίσου

Εμβαδόν στο x-επίπεδο από 0 έως 1,1: 2,36532 · στο u-επίπεδο από u = 0 έως u = 1,214: 2,36532.
Η αντικατάσταση αλλάζει το σχήμα αλλά όχι το εμβαδόν — αρκεί να αλλάξουμε και τα όρια: $\int_a^b f(g(x))g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du$.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\int x^2\sqrt{x^3 + 1}\,dx$.
Υπόδειξη: $u = x^3 + 1$.
Λύση: $du = 3x^2dx$: $\frac13\int u^{1/2}du = \frac29(x^3 + 1)^{3/2} + C$.
Άσκηση 2Βασική
Να υπολογίσετε το $\displaystyle\int_0^{\sqrt\pi}x\sin x^2\,dx$.
Υπόδειξη: $u = x^2$, νέα όρια $0$ και $\pi$.
Λύση: $\frac12\int_0^\pi\sin u\,du = \frac12[-\cos u]_0^\pi = \frac12(1 + 1) = 1$.
Άσκηση 3Μέτρια
Να υπολογίσετε το $\displaystyle\int_{-1}^{1/2}\frac{x}{\sqrt{2 - x^2}}\,dx$ (4 δεκαδικά).
Υπόδειξη: $u = 2 - x^2$.
Λύση: $\left[-\sqrt{2 - x^2}\right]_{-1}^{1/2} = -\sqrt{\frac74} + 1 = 1 - \frac{\sqrt7}{2} \approx -0{,}3229$.
Άσκηση 4Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{\cos 4x}{9 + \sin^2 4x}\,dx$.
Υπόδειξη: $u = \sin 4x$.
Λύση: $du = 4\cos 4x\,dx$: $\frac14\int\frac{du}{9 + u^2} = \frac1{12}\tan^{-1}\frac{\sin 4x}{3} + C$.
Άσκηση 5Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{\cos 2x}{\sin 2x\,(3 - \sin 2x)}\,dx$ για $0 < x < \frac\pi2$.
Υπόδειξη: $u = \sin 2x$ και $\frac{1}{u(3 - u)} = \frac13\left(\frac1u + \frac1{3 - u}\right)$.
Λύση: $\frac12\int\frac{du}{u(3 - u)} = \frac16[\ln u - \ln(3 - u)] = \frac16\ln\frac{\sin 2x}{3 - \sin 2x} + C$.
Άσκηση 6Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{dx}{x + \sqrt x}$.
Υπόδειξη: $u = \sqrt x$.
Λύση: $dx = 2u\,du$: $\int\frac{2u}{u^2 + u}du = 2\ln(u + 1) = 2\ln(\sqrt x + 1) + C$.
Άσκηση 7Απαιτητική
Να υπολογίσετε το $\displaystyle\int x^2\sqrt{x + 1}\,dx$.
Υπόδειξη: $u = x + 1$, $x^2 = (u - 1)^2$.
Λύση: $\int(u - 1)^2u^{1/2}du = \int(u^{5/2} - 2u^{3/2} + u^{1/2})du = \frac27u^{7/2} - \frac45u^{5/2} + \frac23u^{3/2} + C$, με $u = x + 1$.
Άσκηση 8Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{x + 4}{x^2 + 6x + 18}\,dx$.
Υπόδειξη: $x^2 + 6x + 18 = (x + 3)^2 + 9$.
Λύση: $u = x + 3$: $\int\frac{u + 1}{u^2 + 9}du = \frac12\ln(u^2 + 9) + \frac13\tan^{-1}\frac u3 + C$.
Άσκηση 9Απαιτητική
Να υπολογίσετε το $\displaystyle\int\frac{2x + 5}{\sqrt{16 - 6x - x^2}}\,dx$.
Υπόδειξη: $16 - 6x - x^2 = 25 - (x + 3)^2$.
Λύση: $u = x + 3$: $\int\frac{2u - 1}{\sqrt{25 - u^2}}du = -2\sqrt{25 - u^2} - \sin^{-1}\frac u5 + C = -2\sqrt{16 - 6x - x^2} - \sin^{-1}\frac{x + 3}{5} + C$.

♾️ Γεννήτρια — ολοκλήρωση με αντικατάσταση

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\int_0^1 2x\,e^{x^2}\,dx$ (4 δεκαδικά).
Υπόδειξη: Θέστε $u$ ίσο με την «εσωτερική» συνάρτηση της οποίας η παράγωγος εμφανίζεται (ως παράγοντας).
Λύση: $u = x^2$, $du = 2x\,dx$, $u: 0 \to 1$: $\int_0^{1} e^u du = e^{1} - 1 \approx 1{,}7183$.
