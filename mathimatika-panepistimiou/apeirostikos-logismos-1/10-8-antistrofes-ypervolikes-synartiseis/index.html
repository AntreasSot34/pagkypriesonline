10.8

Αντίστροφες υπερβολικές συναρτήσεις

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 10 §10.8 · 10η σειρά ασκήσεων

Αφού οι υπερβολικές φτιάχνονται από το $e^x$, οι αντίστροφές τους γράφονται με φυσικούς λογαρίθμους.

Θεωρία

Ορισμοί

Η $\sinh x$ είναι συνεχής και αύξουσα στο $\mathbb{R}$, άρα έχει αντίστροφη $\sinh^{-1}$. Η $\cosh x$ δεν είναι 1–1 στο $\mathbb{R}$· την περιορίζουμε στο $x \ge 0$:

(i) $y = \sinh^{-1}x \iff x = \sinh y$ · (ii) $y = \cosh^{-1}x \iff x = \cosh y$, $x \ge 1$, $y \ge 0$ · (iii) $y = \tanh^{-1}x \iff x = \tanh y$, $|x| < 1$ · (iv) $y = \coth^{-1}x \iff x = \coth y$, $|x| > 1$ · (v) $y = \operatorname{sech}^{-1}x \iff x = \operatorname{sech}y$, $0 < x \le 1$, $y \ge 0$ · (vi) $y = \operatorname{csch}^{-1}x \iff x = \operatorname{csch}y$, $x \ne 0$.

Αντίστροφες υπερβολικές ως λογάριθμοι

$\begin{aligned} \sinh^{-1}x &= \ln\left(x + \sqrt{x^2 + 1}\right) & \cosh^{-1}x &= \ln\left(x + \sqrt{x^2 - 1}\right),\ x \ge 1 \\ \tanh^{-1}x &= \tfrac12\ln\frac{1 + x}{1 - x},\ |x| < 1 & \coth^{-1}x &= \tfrac12\ln\frac{x + 1}{x - 1},\ |x| > 1 \\ \operatorname{sech}^{-1}x &= \ln\left(\tfrac1x + \tfrac{\sqrt{1 - x^2}}{x}\right),\ 0 < x \le 1 & \operatorname{csch}^{-1}x &= \ln\left(\tfrac1x + \tfrac{\sqrt{1 + x^2}}{|x|}\right),\ x \ne 0 \end{aligned}$
Απόδειξη για τον $\cosh^{-1}$

$x = \cosh y = \frac{e^y + e^{-y}}{2} \Rightarrow (e^y)^2 - 2xe^y + 1 = 0 \Rightarrow e^y = x \pm \sqrt{x^2 - 1}$. Η λύση με το «−» απορρίπτεται: αφού $y \ge 0$ πρέπει $e^y \ge 1$, ενώ $x - \sqrt{x^2 - 1} < 1$ για $x > 1$. Άρα $e^y = x + \sqrt{x^2 - 1}$, δηλαδή $y = \ln(x + \sqrt{x^2 - 1})$.

Απόδειξη για τον $\coth^{-1}$

$x = \frac{e^y + e^{-y}}{e^y - e^{-y}} \Rightarrow e^y(x - 1) = e^{-y}(x + 1) \Rightarrow e^{2y} = \frac{x + 1}{x - 1} \Rightarrow y = \frac12\ln\frac{x + 1}{x - 1}$.

Παραδείγματα

(i) $\cosh^{-1}3 = \ln(3 + \sqrt8)$ · (ii) $\tanh^{-1}\frac34 = \frac12\ln\frac{1 + 3/4}{1 - 3/4} = \frac12\ln 7$.

(iii) $\sinh^{-1}\frac34 + \sinh^{-1}\frac{5}{12} - \sinh^{-1}\frac43 = \ln\left(\frac34 + \frac54\right) + \ln\left(\frac{5}{12} + \frac{13}{12}\right) - \ln\left(\frac43 + \frac53\right) = \ln 2 + \ln\frac32 - \ln 3 = 0$.

Πειραματίσου

sinh⁻¹ x = ln(x + √(x² + 1))
sinh⁻¹(1,6) = 1,24898 · από τον λογαριθμικό τύπο: 1,24898 ✓

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\cosh^{-1}(3)$ (4 δεκαδικά).
Υπόδειξη: $\cosh^{-1}x = \ln(x + \sqrt{x^2 - 1})$.
Λύση: $\ln(3 + \sqrt8) \approx 1{,}7627$.
Άσκηση 2Βασική
Να υπολογίσετε το $\tanh^{-1}\left(\frac34\right)$ (4 δεκαδικά).
Υπόδειξη: $\frac12\ln\frac{1 + x}{1 - x}$.
Λύση: $\frac12\ln 7 \approx 0{,}9730$.
Άσκηση 3Βασική
Να υπολογίσετε ακριβώς το $e^{\sinh^{-1}(3/4)}$.
Υπόδειξη: $\sinh^{-1}x = \ln(x + \sqrt{x^2 + 1})$.
Λύση: $\sinh^{-1}\frac34 = \ln\left(\frac34 + \sqrt{\frac{9}{16} + 1}\right) = \ln\left(\frac34 + \frac54\right) = \ln 2$, άρα $e^{\ln 2} = 2$.
Άσκηση 4Μέτρια
Αν $u = \operatorname{csch}^{-1}\left(-\frac{5}{12}\right)$, να βρείτε τα $\cosh u$ και $\coth u$.
Υπόδειξη: $\operatorname{csch}u = -\frac5{12} \Rightarrow \sinh u = -\frac{12}{5}$.
Λύση: $\sinh u = -\frac{12}{5}$, $\cosh u = \sqrt{1 + \frac{144}{25}} = \frac{13}{5}$, $\coth u = \frac{\cosh u}{\sinh u} = -\frac{13}{12}$.
Άσκηση 5Μέτρια
Αν $u = \tanh^{-1}\left(-\frac35\right)$, να βρείτε τα $\cosh u$ και $\cosh 2u$.
Υπόδειξη: $\operatorname{sech}^2u = 1 - \tanh^2u$.
Λύση: $\operatorname{sech}^2u = 1 - \frac{9}{25} = \frac{16}{25}$, άρα $\cosh u = \frac54$, $\sinh u = \tanh u\cosh u = -\frac34$. $\cosh 2u = \frac{25}{16} + \frac{9}{16} = \frac{17}{8}$.
Άσκηση 6Βασική
Να υπολογίσετε το $\sinh^{-1}(2)$ (4 δεκαδικά).
Υπόδειξη: $\ln(2 + \sqrt5)$.
Λύση: $\ln(2 + \sqrt5) \approx 1{,}4436$.
Άσκηση 7Βασική
Το πεδίο ορισμού της $\cosh^{-1}x$ είναι:
Υπόδειξη: Ποιες τιμές παίρνει η $\cosh$;
Λύση: Το πεδίο τιμών της $\cosh$ είναι $[1, +\infty)$, άρα αυτό είναι το πεδίο ορισμού της αντίστροφης (και το σύνολο τιμών της είναι $[0, +\infty)$).
Άσκηση 8Μέτρια
Ο τύπος $\tanh^{-1}x = \frac12\ln\dfrac{1 + x}{1 - x}$ ισχύει για:
Υπόδειξη: Το πεδίο τιμών της $\tanh$.
Λύση: Η $\tanh$ παίρνει τιμές στο $(-1, 1)$, οπότε η $\tanh^{-1}$ ορίζεται για $|x| < 1$ — εκεί ακριβώς είναι θετικό το $\frac{1 + x}{1 - x}$.
Άσκηση 9Απαιτητική
Να λυθεί η εξίσωση $\cosh x = 2$, $x > 0$ (4 δεκαδικά).
Υπόδειξη: $x = \cosh^{-1}2$.
Λύση: $x = \cosh^{-1}2 = \ln(2 + \sqrt3) \approx 1{,}3170$.
