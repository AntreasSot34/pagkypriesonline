3.3

Όρια συναρτήσεων – Αυστηρή προσέγγιση (ε–δ)

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 3 §3.3 · Φυλλάδιο ασκήσεων 4

Τι ακριβώς σημαίνει «πλησιάζει όσο θέλουμε»; Ο ορισμός ε–δ το μετατρέπει σε ανισότητες.

Θεωρία

Από τη διαίσθηση στον ορισμό

«Η $f(x)$ πλησιάζει όσο θέλουμε την τιμή $L$» μεταφράζεται: για κάθε $\varepsilon > 0$, όσο μικρό θέλουμε, $L - \varepsilon < f(x) < L + \varepsilon \iff |f(x) - L| < \varepsilon$, αρκεί το $x$ να είναι αρκετά κοντά στο $a$: υπάρχει $\delta > 0$ ώστε αυτό να ισχύει για $0 < |x - a| < \delta$. «Το $x$ πλησιάζει αρκούντως το $a$» μεταφράζεται: υπάρχει $\delta > 0$ ώστε $|x - a| < \delta$.

Στο σχήμα: αν $|f(x) - L| < \varepsilon$ ισχύει για $a - \delta_1 < x < a + \delta_2$, παίρνουμε $\delta = \min\{\delta_1, \delta_2\}$.

3.3.1 · Όριο

Δίνεται η $f(x)$ και ένα ανοικτό διάστημα που περιέχει τον αριθμό $a$· η $f$ ορίζεται σε όλα τα σημεία του διαστήματος με πιθανή εξαίρεση το $a$. Λέμε ότι η $f(x)$ τείνει στο όριο $L$ καθώς το $x$ τείνει στο $a$, $\displaystyle\lim_{x\to a} f(x) = L$, αν

$\forall\varepsilon > 0$ (όσο θέλουμε μικρό) $\exists\,\delta > 0$ τέτοιο ώστε $|f(x) - L| < \varepsilon$ όταν $0 < |x - a| < \delta$

Παρατήρηση. Η συνθήκη $0 < |x - a|$ (δηλαδή $x \ne a$) είναι απαραίτητη: το όριο δεν εξαρτάται από την τιμή $f(a)$, που μπορεί να μην υπάρχει ή να διαφέρει από το $L$. Στις χειρόγραφες σημειώσεις γράφεται σύντομα «$|x-a|<\delta$»· εννοείται $0<|x-a|<\delta$.

3.3.2 – 3.3.3 · Πλευρικά όρια

Αριστερό όριο: $\lim_{x\to a^-} f(x) = L$ αν $\forall\varepsilon > 0\ \exists\delta > 0$: $|f(x) - L| < \varepsilon$ όταν $0 < a - x < \delta$. Δεξιό όριο: το ίδιο με $0 < x - a < \delta$.

3.3.4 – 3.3.7 · Όρια στο άπειρο και μη πεπερασμένα

  • $\lim_{x\to+\infty} f(x) = L$: $\forall\varepsilon > 0\ \exists N > 0$: $|f(x) - L| < \varepsilon$ όταν $x > N$.
  • $\lim_{x\to-\infty} f(x) = L$: $\forall\varepsilon > 0\ \exists N > 0$: $|f(x) - L| < \varepsilon$ όταν $x < -N$.
  • $\lim_{x\to a} f(x) = +\infty$: $\forall N > 0$ (όσο θέλουμε μεγάλο) $\exists\delta > 0$: $f(x) > N$ όταν $0 < |x - a| < \delta$. Για $-\infty$: $f(x) < -N$.

Επαλήθευση ορίων με τον ορισμό

  • $\lim_{x\to1}(3x - 1) = 2$: $|3x - 1 - 2| = 3|x - 1| < \varepsilon \iff |x - 1| < \frac\varepsilon3$. Ο ορισμός ικανοποιείται με $\delta = \frac\varepsilon3$.
  • $\lim_{x\to2}(x^2 + 1) = 5$, $\varepsilon = 0{,}1$: $|x^2 - 4| < 0{,}1 \iff 3{,}9 < x^2 < 4{,}1 \iff \sqrt{3{,}9} - 2 < x - 2 < \sqrt{4{,}1} - 2$, δηλαδή $-0{,}025158\ldots < x - 2 < 0{,}024845\ldots$. Παίρνουμε $\delta = \min\{2 - \sqrt{3{,}9},\ \sqrt{4{,}1} - 2\} = \sqrt{4{,}1} - 2 \approx 0{,}024845$ (ή οποιοδήποτε μικρότερο θετικό $\delta$· στρογγυλεύουμε προς τα κάτω, αλλιώς το $\delta$ ίσως δεν ικανοποιεί τον ορισμό).
  • $\lim_{x\to+\infty}\frac1x = 0$: $\left|\frac1x\right| < \varepsilon \iff x > \frac1\varepsilon$ (για $x > 0$), άρα $N = \frac1\varepsilon$.
  • $\lim_{x\to0}\frac{1}{|x|} = +\infty$: $\frac{1}{|x|} > N \iff |x| < \frac1N$, άρα $\delta = \frac1N$ (π.χ. $N = 1000$, $\delta = 10^{-3}$).

Πειραματίσου

Από την ανίσωση |f(x) − L| < ε: δ₁ = 0,167 (αριστερά), δ₂ = 0,167 (δεξιά) — πορτοκαλί γραμμές. δ = ε/3 = 0,167.
Με δ = 0,167: ✓ για κάθε x με |x − a| < δ ισχύει |f(x) − L| < ε.
Ό,τι κι αν διαλέξεις για ε, υπάρχει δ: αυτό σημαίνει lim f(x) = L (ορισμός 3.3.1).

Ασκήσεις — 0/11 λυμένες

Άσκηση 1Βασική
Για το $\lim_{x\to4} 2x = 8$ και $\varepsilon = 0{,}1$, ποιο είναι το μεγαλύτερο $\delta > 0$ που ικανοποιεί τον ορισμό;
Υπόδειξη: $|2x - 8| = 2|x - 4|$.
Λύση: $2|x - 4| < 0{,}1 \iff |x - 4| < 0{,}05$: $\delta = 0{,}05$.
Άσκηση 2Βασική
Για το $\lim_{x\to5} 3x = 15$, ο ορισμός ικανοποιείται με $\delta = \frac\varepsilon3$. Ποιο $\delta$ αντιστοιχεί στο $\varepsilon = 0{,}6$;
Υπόδειξη: $\frac{0{,}6}{3}$.
Λύση: $|3x - 15| = 3|x - 5| < 0{,}6 \iff |x - 5| < 0{,}2$.
Άσκηση 3Βασική
Για το $\lim_{x\to0}|x| = 0$ και $\varepsilon = 0{,}05$, ποιο είναι το μεγαλύτερο κατάλληλο $\delta$;
Υπόδειξη: $\big||x| - 0\big| = |x - 0|$.
Λύση: $|x| < 0{,}05$ όταν $|x - 0| < 0{,}05$: $\delta = \varepsilon = 0{,}05$.
Άσκηση 4Μέτρια
Για το $\lim_{x\to2}(x^2 + 1) = 5$ με $\varepsilon = 0{,}1$, να βρείτε το $\delta = \min\{\delta_1, \delta_2\}$ (με $6$ δεκαδικά, στρογγυλεμένο προς τα κάτω).
Υπόδειξη: $3{,}9 < x^2 < 4{,}1$.
Λύση: $\delta_1 = 2 - \sqrt{3{,}9} \approx 0{,}025158$, $\delta_2 = \sqrt{4{,}1} - 2 = 0{,}0248456\ldots$. Άρα $\delta = \sqrt{4{,}1} - 2 \approx 0{,}024845$ (προς τα κάτω: το $0{,}024846$ θα ήταν ήδη μεγαλύτερο από το επιτρεπτό).
Άσκηση 5Απαιτητική
Για το $\lim_{x\to9}\sqrt{x} = 3$ και $\varepsilon = 0{,}001$, να βρείτε το μεγαλύτερο κατάλληλο $\delta$ (με $6$ δεκαδικά).
Υπόδειξη: $2{,}999 < \sqrt{x} < 3{,}001 \iff 2{,}999^2 < x < 3{,}001^2$.
Λύση: $2{,}999^2 = 8{,}994001$ και $3{,}001^2 = 9{,}006001$, άρα $\delta_1 = 0{,}005999$ και $\delta_2 = 0{,}006001$. $\delta = \min = 0{,}005999$.
Άσκηση 6Βασική
Για το $\lim_{x\to+\infty}\frac1x = 0$ και $\varepsilon = 0{,}01$, να βρείτε το $N = \frac1\varepsilon$ του ορισμού 3.3.4.
Υπόδειξη: $\frac1x < 0{,}01 \iff x > 100$.
Λύση: $N = \frac{1}{0{,}01} = 100$.
Άσκηση 7Μέτρια
Για το $\lim_{x\to0}\frac{1}{|x|} = +\infty$ και $N = 1000$, ποιο είναι το μεγαλύτερο $\delta$ ώστε $\frac{1}{|x|} > N$ όταν $0 < |x| < \delta$;
Υπόδειξη: $\frac{1}{|x|} > N \iff |x| < \frac1N$.
Λύση: $\delta = \frac{1}{1000} = 10^{-3}$.
Άσκηση 8Βασική
Ποια είναι η σωστή διατύπωση του $\lim_{x\to a} f(x) = L$;
Υπόδειξη: Πρώτα δίνεται η ακρίβεια $\varepsilon$.
Λύση: Για κάθε ακρίβεια $\varepsilon$ πρέπει να υπάρχει απόσταση $\delta$ από το $a$ μέσα στην οποία $|f(x) - L| < \varepsilon$.
Άσκηση 9Μέτρια
Στον ορισμό του αριστερού ορίου $\lim_{x\to a^-} f(x) = L$, η συνθήκη για το $x$ είναι:
Υπόδειξη: Το $x$ βρίσκεται αριστερά του $a$.
Λύση: Από αριστερά: $x < a$ και κοντά στο $a$, δηλαδή $0 < a - x < \delta$ (ορισμός 3.3.2).
Άσκηση 10Βασική
Αν για κάποιο $\varepsilon$ ένα $\delta$ ικανοποιεί τον ορισμό του ορίου, τότε τον ικανοποιεί και κάθε μικρότερο $\delta' \in (0, \delta)$.
Υπόδειξη: Αν $|x - a| < \delta'$, τι ισχύει για το $|x - a|$ σε σχέση με το $\delta$;
Λύση: Σωστό: $|x - a| < \delta' < \delta$ ⇒ $|f(x) - L| < \varepsilon$. Γι' αυτό αρκεί να βρούμε ένα κατάλληλο $\delta$.
Άσκηση 11Απαιτητική
Για την $f(x) = 1 - \frac{1}{x + 2}$ είναι $\left|f(x) - \frac23\right| = \frac{|x - 1|}{3|x + 2|}$, και για $|x - 1| < 1$ ισχύει $|x + 2| > 2$. Έτσι $\left|f(x) - \frac23\right| < \frac{|x - 1|}{6}$ και μπορούμε να πάρουμε $\delta = \min\{1, 6\varepsilon\}$. Ποιο $\delta$ προκύπτει για $\varepsilon = 0{,}05$;
Υπόδειξη: $6\cdot 0{,}05$.
Λύση: $\delta = \min\{1;\ 0{,}3\} = 0{,}3$. Τότε $\left|f(x) - \frac23\right| < \frac{0{,}3}{6} = 0{,}05$: επαληθεύεται ότι $\lim_{x\to1}f(x) = \frac23$.

♾️ Γεννήτρια — εύρεση δ ή N από τον ορισμό

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Για το $\displaystyle\lim_{x\to+\infty}\frac{7}{x} = 0$ και $\varepsilon = 0{,}02$, ποιο είναι το μικρότερο $N > 0$ ώστε $x > N \Rightarrow \left|\frac{7}{x}\right| < \varepsilon$;
Υπόδειξη: Για $x > 0$: $\frac{7}{x} < \varepsilon \iff x > \frac{7}{\varepsilon}$.
Λύση: $N = \frac{7}{\varepsilon} = 350$ (ορισμός 3.3.4).
