3.2.1

Όρια πολυωνύμων και ρητών συναρτήσεων

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 3 §3.2.1–3.2.2 · Φυλλάδιο ασκήσεων 3

Πολυώνυμα και ρητές: τι κάνουμε όταν η αντικατάσταση δίνει 0/0, και ποιος όρος «κερδίζει» στο άπειρο;

Θεωρία

3.2.1.1 · Πολυώνυμο όταν $x \to a$

Για κάθε πολυώνυμο $P_n(x) = c_0 + c_1x + \dots + c_nx^n$ και κάθε $a \in \mathbb{R}$: $\displaystyle\lim_{x\to a} P_n(x) = P_n(a)$. Αρκεί να υπολογίσουμε την τιμή στο σημείο: $\lim_{x\to1}(-2 + 2x^2 - x^4 + 5x^5) = 4$.

Πολυώνυμο όταν $x \to \pm\infty$

$$\lim_{x\to+\infty} x^n = +\infty, \quad \lim_{x\to-\infty} x^n = \begin{cases}+\infty, & n \text{ άρτιος}\\ -\infty, & n \text{ περιττός}\end{cases}, \quad \lim_{x\to\pm\infty}\frac{1}{x^n} = 0$$

Βγάζοντας κοινό παράγοντα το $x^n$: $P_n(x) = \left(\frac{c_0}{x^n} + \dots + \frac{c_{n-1}}{x} + c_n\right)x^n$, οπότε

$$\lim_{x\to\pm\infty} P_n(x) = c_n\lim_{x\to\pm\infty} x^n$$

Μετράει μόνο ο μεγιστοβάθμιος όρος: $\lim_{x\to-\infty}(1 + x - x^2 + 3x^3) = 3\lim_{x\to-\infty}x^3 = -\infty$.

Ρητή $\frac{P_n}{Q_m}$ όταν $x \to a$

Αν $Q_m(a) \ne 0$: $\displaystyle\lim_{x\to a}\frac{P_n(x)}{Q_m(x)} = \frac{P_n(a)}{Q_m(a)}$, π.χ. $\lim_{x\to3}\frac{x+2}{x-2} = 5$. Αν $Q_m(a) = 0$ εξετάζουμε τον αριθμητή:

  • $P_n(a) \ne 0$: πλευρικά όρια $\pm\infty$ (μελετάμε το πρόσημο). Π.χ. $\lim_{x\to1^-}\frac{x^2}{x-1} = \frac{1}{0^-} = -\infty$, $\lim_{x\to1^+}\frac{x^2}{x-1} = +\infty$.
  • $P_n(a) = 0$ (μορφή $\frac00$): παραγοντοποιούμε, απλοποιούμε τον κοινό παράγοντα $(x - a)$ και ξαναϋπολογίζουμε.

$\lim_{x\to1}\frac{x^m - 1}{x - 1} = m$

Για $m \in \mathbb{N}$: $x^m - 1 = (x - 1)(1 + x + \dots + x^{m-1})$, οπότε το όριο είναι $1 + 1 + \dots + 1 = m$.

Και για αρνητικό ακέραιο $m = -k$

$\frac{x^{-k} - 1}{x - 1} = -\frac{x^k - 1}{x - 1}\cdot\frac{1}{x^k} \to -k\cdot 1 = -k = m$. (Ισχύει και για ρητό $m$.)

Ρητή όταν $x \to \pm\infty$

$$\lim_{x\to\pm\infty}\frac{c_0 + c_1x + \dots + c_nx^n}{d_0 + d_1x + \dots + d_mx^m} = \frac{c_n}{d_m}\lim_{x\to\pm\infty} x^{n-m}$$

Ίδιος βαθμός: $\frac{c_n}{d_m}$ · μικρότερος βαθμός αριθμητή: $0$ · μεγαλύτερος: $\pm\infty$. Π.χ. $\lim_{x\to+\infty}\frac{2x^2 - 1}{3x^2 + x + 3} = \frac23$, $\lim_{x\to+\infty}\frac{2x^2 - 1}{x^3 + 1} = 0$.

Ρίζες και $x \to -\infty$

$\sqrt{x^2} = |x|$, και για $x < 0$ είναι $|x| = -x$. Έτσι $\displaystyle\lim_{x\to-\infty}\frac{\sqrt{x^2 + 2}}{3x - 6} = \lim\frac{|x|\sqrt{1 + 2/x^2}}{(3 - 6/x)x} = \frac13\cdot(-1) = -\frac13$.

Πειραματίσου

0/0 στο x = 2: απλοποιούμε, (x − 2)(x + 2)/(x − 2) = x + 2 → 4. Οπή στο (2, 4).
Πορτοκαλί διακεκομμένη: ο λόγος των μεγιστοβάθμιων όρων x²/x = x. Κάνε zoom out: στο ±∞ η ρητή «κολλάει» πάνω του.

Ασκήσεις — 0/11 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to3}\frac{x + 2}{x - 2}$.
Υπόδειξη: $Q(3) \ne 0$.
Λύση: $\frac{3 + 2}{3 - 2} = 5$.
Άσκηση 2Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to2}\frac{x^2 - 4x + 4}{x^2 + x - 6}$.
Υπόδειξη: $\frac00$: $x^2 - 4x + 4 = (x-2)^2$, $x^2 + x - 6 = (x-2)(x+3)$.
Λύση: $\frac{(x - 2)^2}{(x - 2)(x + 3)} = \frac{x - 2}{x + 3} \to \frac05 = 0$.
Άσκηση 3Βασική
Να υπολογίσετε το $\displaystyle\lim_{t\to-2}\frac{t^3 + 8}{t + 2}$.
Υπόδειξη: $t^3 + 8 = (t + 2)(t^2 - 2t + 4)$.
Λύση: $\lim_{t\to-2}(t^2 - 2t + 4) = 4 + 4 + 4 = 12$.
Άσκηση 4Βασική
Να υπολογίσετε το $\displaystyle\lim_{x\to+\infty}\frac{5x^2 + 7}{3x^2 - x}$.
Υπόδειξη: Ίδιος βαθμός.
Λύση: $\frac{5 + 7/x^2}{3 - 1/x} \to \frac53$.
Άσκηση 5Μέτρια
Το $\displaystyle\lim_{x\to+\infty}\frac{\sqrt{5x^2 - 2}}{x + 3}$ είναι της μορφής $\sqrt{\alpha}$. Να βρείτε το $\alpha$.
Υπόδειξη: Για $x > 0$: $\sqrt{5x^2 - 2} = x\sqrt{5 - 2/x^2}$.
Λύση: $\frac{x\sqrt{5 - 2/x^2}}{x(1 + 3/x)} = \frac{\sqrt{5 - 2/x^2}}{1 + 3/x} \to \sqrt5$, άρα $\alpha = 5$.
Άσκηση 6Μέτρια
Να υπολογίσετε το $\displaystyle\lim_{x\to0}\frac{\sqrt{x + 4} - 2}{x}$.
Υπόδειξη: Πολλαπλασιάστε αριθμητή και παρονομαστή με $\sqrt{x + 4} + 2$.
Λύση: $\frac{(x + 4) - 4}{x(\sqrt{x+4} + 2)} = \frac{1}{\sqrt{x + 4} + 2} \to \frac14$.
Άσκηση 7Μέτρια
Να υπολογίσετε το $\displaystyle\lim_{x\to+\infty}\left(\sqrt{x^2 + 5x} - x\right)$.
Υπόδειξη: Μορφή $\infty - \infty$: συζυγής παράσταση.
Λύση: $\frac{(x^2 + 5x) - x^2}{\sqrt{x^2 + 5x} + x} = \frac{5x}{x\left(\sqrt{1 + 5/x} + 1\right)} \to \frac52$.
Άσκηση 8Μέτρια
Να υπολογίσετε το $\displaystyle\lim_{x\to6}\frac{x^3 - 6x^2}{x^2 - 36}$.
Υπόδειξη: $x^3 - 6x^2 = x^2(x - 6)$.
Λύση: $\frac{x^2(x - 6)}{(x - 6)(x + 6)} = \frac{x^2}{x + 6} \to \frac{36}{12} = 3$.
Άσκηση 9Μέτρια
Να βρείτε το $\displaystyle\lim_{x\to2^+}\frac{x}{x^2 - 4}$.
Υπόδειξη: Για $x > 2$ είναι $x^2 - 4 > 0$.
Λύση: Αριθμητής $\to 2$, παρονομαστής $\to 0^+$: όριο $+\infty$.
Άσκηση 10Απαιτητική
Να δείξετε ότι υπάρχει και να υπολογίσετε το $\displaystyle\lim_{x\to1}\frac{2x^4 - 6x^3 + x^2 + 3}{x - 1}$.
Υπόδειξη: Ο αριθμητής μηδενίζεται στο $1$, άρα έχει παράγοντα $x - 1$ (διαίρεση πολυωνύμων).
Λύση: $2x^4 - 6x^3 + x^2 + 3 = (x - 1)(2x^3 - 4x^2 - 3x - 3)$. Άρα το όριο είναι $2 - 4 - 3 - 3 = -8$.
Άσκηση 11Μέτρια
Να βρείτε το $\displaystyle\lim_{x\to-\infty}\frac{1 - 3x^3}{1 + x^2}$.
Υπόδειξη: $\frac{-3x^3}{x^2} = -3x$.
Λύση: $= -3\lim_{x\to-\infty} x = +\infty$.

♾️ Γεννήτρια — όρια ρητών συναρτήσεων

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\lim_{x\to -4} \frac{x^{2} + 8x + 16}{x^{2} + 2x - 8}$.
Υπόδειξη: Μορφή $\frac00$: και οι δύο μηδενίζονται στο $-4$, άρα έχουν παράγοντα $(x + 4)$.
Λύση: $\frac{(x + 4)(x + 4)}{(x + 4)(x - 2)} = \frac{x + 4}{x - 2} \to \frac{0}{-6} = 0$.
