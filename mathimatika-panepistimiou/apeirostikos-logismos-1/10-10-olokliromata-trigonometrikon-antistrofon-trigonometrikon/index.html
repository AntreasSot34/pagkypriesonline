10.10

Ολοκληρώματα τριγωνομετρικών, αντίστροφων τριγωνομετρικών, υπερβολικών και αντίστροφων υπερβολικών

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 10 §10.10 · 10η σειρά ασκήσεων

Διαβάζοντας «ανάποδα» τους τύπους παραγώγισης, κερδίζουμε έναν πίνακα ολοκληρωμάτων που καταλήγουν σε τόξα και υπερβολικές συναρτήσεις.

Θεωρία

Τριγωνομετρικά

$\int\cos x\,dx = \sin x + C$, $\int\sin x\,dx = -\cos x + C$, $\int\sec^2x\,dx = \tan x + C$, $\int\csc^2x\,dx = -\cot x + C$, $\int\sec x\tan x\,dx = \sec x + C$, $\int\csc x\cot x\,dx = -\csc x + C$.

Υπερβολικά

$\int\sinh u\,du = \cosh u + C$, $\int\cosh u\,du = \sinh u + C$, $\int\operatorname{sech}^2u\,du = \tanh u + C$, $\int\operatorname{csch}^2u\,du = -\coth u + C$, $\int\operatorname{sech}u\tanh u\,du = -\operatorname{sech}u + C$, $\int\operatorname{csch}u\coth u\,du = -\operatorname{csch}u + C$.

Αντίστροφες τριγωνομετρικές και υπερβολικές

$\begin{aligned} \int\tfrac{du}{\sqrt{1 - u^2}} &= \sin^{-1}u + C & \int\tfrac{du}{1 + u^2} &= \tan^{-1}u + C & \int\tfrac{du}{u\sqrt{u^2 - 1}} &= \sec^{-1}u + C \\ \int\tfrac{du}{\sqrt{1 + u^2}} &= \sinh^{-1}u + C & \int\tfrac{du}{\sqrt{u^2 - 1}} &= \cosh^{-1}u + C\ (u > 1) & \int\tfrac{du}{1 - u^2} &= \begin{cases}\tanh^{-1}u + C, & |u| < 1 \\ \coth^{-1}u + C, & |u| > 1\end{cases} \end{aligned}$

και $\int\frac{du}{u\sqrt{1 - u^2}} = -\operatorname{sech}^{-1}|u| + C$, $\int\frac{du}{u\sqrt{1 + u^2}} = -\operatorname{csch}^{-1}|u| + C$. Με $u = \frac xa$ ($a > 0$): $\int\frac{dx}{\sqrt{a^2 - x^2}} = \sin^{-1}\frac xa + C$, $\int\frac{dx}{a^2 + x^2} = \frac1a\tan^{-1}\frac xa + C$.

Παραδείγματα

(i) $\int\cosh(2x - 3)\,dx = \frac12\sinh(2x - 3) + C$ · (ii) $\int\frac{e^x}{4 + e^{2x}}dx$: $u = e^x$, $\int\frac{du}{4 + u^2} = \frac12\tan^{-1}\frac{e^x}{2} + C$.

(iii) $\int_1^2\frac{dx}{\sqrt x\sqrt{4 - x}}$: με $u = \sqrt x$, $dx = 2u\,du$: $2\int_1^{\sqrt2}\frac{du}{\sqrt{4 - u^2}} = 2\left[\sin^{-1}\frac u2\right]_1^{\sqrt2} = 2\left(\frac\pi4 - \frac\pi6\right) = \frac\pi6$.

Πώς γράφουμε τις απαντήσεις εδώ

Στα πεδία αντιπαραγώγων μπορείτε να χρησιμοποιήσετε arcsin, arctan, exp, ln, sqrt. Τις υπερβολικές τις γράφετε μέσω εκθετικών, π.χ. $\sinh u$ = (exp(u)-exp(-u))/2, και τις αντίστροφες υπερβολικές μέσω λογαρίθμων.

Πειραματίσου

$\displaystyle\int_{-1,2}^{2,4} 1/(1 + x^2)\,dx$: αριθμητικά (Simpson) 2,05206 · με αντιπαράγωγο F(x) = tan⁻¹x: F(b) − F(a) = 2,05206.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\int\cosh(2x - 3)\,dx$ (γράψτε το $\sinh$ μέσω εκθετικών).
Υπόδειξη: $\int\cosh u\,du = \sinh u$ με $u = 2x - 3$.
Λύση: $\frac12\sinh(2x - 3) + C = \frac{e^{2x-3} - e^{3-2x}}{4} + C$.
Άσκηση 2Βασική
Να υπολογίσετε το $\displaystyle\int\frac{e^x}{4 + e^{2x}}\,dx$.
Υπόδειξη: $u = e^x$.
Λύση: $\int\frac{du}{4 + u^2} = \frac12\tan^{-1}\frac u2 + C = \frac12\tan^{-1}\frac{e^x}{2} + C$.
Άσκηση 3Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{e^x - e^{-x}}{e^x + e^{-x}}\,dx$.
Υπόδειξη: Ο αριθμητής είναι η παράγωγος του παρονομαστή.
Λύση: $\ln(e^x + e^{-x}) + C$ — ισοδύναμα $\ln(\cosh x) + C'$, αφού $\int\tanh x\,dx = \ln\cosh x + C$.
Άσκηση 4Βασική
Να υπολογίσετε το $\displaystyle\int\frac{dx}{\sqrt{9 - 4x^2}}$.
Υπόδειξη: $u = 2x$, $a = 3$.
Λύση: $\frac12\int\frac{du}{\sqrt{9 - u^2}} = \frac12\sin^{-1}\frac{2x}{3} + C$.
Άσκηση 5Βασική
Να υπολογίσετε το $\displaystyle\int_0^{1/\sqrt2}\frac{dx}{\sqrt{1 - x^2}}$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: $\sin^{-1}\frac{1}{\sqrt2}$.
Λύση: $\sin^{-1}\frac{1}{\sqrt2} - \sin^{-1}0 = \frac\pi4$.
Άσκηση 6Μέτρια
Να υπολογίσετε το $\displaystyle\int_{\sqrt2}^{2}\frac{dx}{x\sqrt{x^2 - 1}}$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: $\int\frac{du}{u\sqrt{u^2 - 1}} = \sec^{-1}u$.
Λύση: $\sec^{-1}2 - \sec^{-1}\sqrt2 = \frac\pi3 - \frac\pi4 = \frac{\pi}{12}$.
Άσκηση 7Μέτρια
Να υπολογίσετε το $\displaystyle\int_1^{2}\frac{dx}{\sqrt x\,\sqrt{4 - x}}$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: $u = \sqrt x$, $dx = 2u\,du$.
Λύση: $2\int_1^{\sqrt2}\frac{du}{\sqrt{4 - u^2}} = 2\left(\sin^{-1}\frac{\sqrt2}{2} - \sin^{-1}\frac12\right) = 2\left(\frac\pi4 - \frac\pi6\right) = \frac\pi6$.
Άσκηση 8Μέτρια
Να υπολογίσετε το $\displaystyle\int_0^{\sqrt3}\frac{x}{3 + x^4}\,dx$ (4 δεκαδικά).
Υπόδειξη: $u = x^2$.
Λύση: $\frac12\int_0^3\frac{du}{3 + u^2} = \frac12\cdot\frac{1}{\sqrt3}\tan^{-1}\frac{3}{\sqrt3} = \frac{1}{2\sqrt3}\cdot\frac\pi3 = \frac{\pi}{6\sqrt3} \approx 0{,}3023$.
Άσκηση 9Μέτρια
Να υπολογίσετε το $\displaystyle\int_0^{\sqrt3}\frac{dx}{\sqrt{1 + x^2}}$ (4 δεκαδικά).
Υπόδειξη: $\sinh^{-1}x = \ln(x + \sqrt{x^2 + 1})$.
Λύση: $\sinh^{-1}\sqrt3 = \ln(\sqrt3 + 2) \approx 1{,}3170$.
Άσκηση 10Απαιτητική
Το χωρίο κάτω από την $y = \dfrac{1}{\sqrt{1 + x^2}}$, $0 \le x \le 1$, περιστρέφεται γύρω από τον άξονα $x$. Ο όγκος είναι $V = k\pi^2$: δώστε το $k$.
Υπόδειξη: $V = \pi\int_0^1 y^2dx = \pi\int_0^1\frac{dx}{1 + x^2}$.
Λύση: $V = \pi\int_0^1\frac{dx}{1 + x^2} = \pi\tan^{-1}1 = \pi\cdot\frac\pi4 = \frac{\pi^2}{4}$, άρα $k = \frac14$.

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το $\displaystyle\int_0^{2}\cosh x\,dx$ (4 δεκαδικά).
Υπόδειξη: Αναγνωρίστε τον βασικό τύπο ($\int\frac{du}{1+u^2}$, $\int\frac{du}{\sqrt{1-u^2}}$, $\int\cosh u\,du$ …) μετά από κατάλληλη αντικατάσταση.
Λύση: $\int\cosh x\,dx = \sinh x + c$: $\sinh 2 - \sinh 0 = \frac{e^{2} - e^{-2}}{2} \approx 3{,}6269$.
