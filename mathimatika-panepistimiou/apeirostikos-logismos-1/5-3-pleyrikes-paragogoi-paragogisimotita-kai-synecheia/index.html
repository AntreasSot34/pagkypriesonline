5.3

Πλευρικές παράγωγοι – Παραγωγισιμότητα και συνέχεια

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 5 §5.3 (σελ. 5.7–5.12) · Προβλήματα 5.5, 5.6, 5.17, 5.18, 5.35, 5.41

Όπως τα πλευρικά όρια, έτσι και οι πλευρικές παράγωγοι μάς λένε αν μια συνάρτηση «σπάει» σε ένα σημείο.

Θεωρία

Πλευρικές παράγωγοι

Η δεξιά παράγωγος και η αριστερή παράγωγος της $f$ στο $x_0$ είναι

$$f'_+(x_0) = \lim_{h\to0^+}\frac{f(x_0 + h) - f(x_0)}{h}, \qquad f'_-(x_0) = \lim_{h\to0^-}\frac{f(x_0 + h) - f(x_0)}{h},$$

αν τα όρια υπάρχουν. Τότε λέμε ότι η $f$ είναι παραγωγίσιμη δεξιά (αντίστοιχα αριστερά) στο $x_0$.

$$f'(x_0) \text{ υπάρχει} \iff f'_+(x_0),\ f'_-(x_0) \text{ υπάρχουν και } f'_+(x_0) = f'_-(x_0).$$

Η $f$ λέγεται παραγωγίσιμη στο κλειστό $[a, b]$ αν είναι παραγωγίσιμη στο $(a, b)$, δεξιά στο $a$ και αριστερά στο $b$.

5.3.1 · Παραγωγίσιμη ⇒ συνεχής

Αν η $f$ είναι παραγωγίσιμη στο σημείο $x_0$, τότε η $f$ είναι συνεχής στο $x_0$.

Απόδειξη

Αρκεί $\lim_{x\to x_0}\big[f(x) - f(x_0)\big] = 0$. Για $x \ne x_0$: $\ f(x) - f(x_0) = \dfrac{f(x) - f(x_0)}{x - x_0}\,(x - x_0)$, οπότε $\displaystyle\lim_{x\to x_0}\big[f(x) - f(x_0)\big] = f'(x_0)\cdot\lim_{x\to x_0}(x - x_0) = f'(x_0)\cdot 0 = 0$. Άρα $\lim_{x\to x_0}f(x) = f(x_0)$.

Παρατηρήσεις. (1) Μια συνάρτηση δεν είναι παραγωγίσιμη σε σημεία ασυνέχειας. (2) Το αντίστροφο δεν ισχύει: συνέχεια στο $x_0$ δεν συνεπάγεται ύπαρξη της $f'(x_0)$.

Παραδείγματα των σημειώσεων

(1) $f(x) = x^2\sin\frac1x$, $f(0) = 0$: $\ f'(0) = \lim_{h\to0}\frac{h^2\sin(1/h)}{h} = \lim_{h\to0}h\sin\frac1h = 0$ (κριτήριο παρεμβολής: $|h\sin\frac1h| \le |h|$).

(2) $f(x) = |x|$: $f'_+(0) = \lim_{h\to0^+}\frac{|h|}{h} = 1$, $f'_-(0) = -1$: η $f'(0)$ δεν υπάρχει. (3) $f(x) = x + |x|$: $f'_+(0) = 2$, $f'_-(0) = 0$.

(4) Να βρεθούν $a, b$ ώστε η $f(x) = \begin{cases} ax^2 + 1, & x \le 1 \\ x + b, & x > 1\end{cases}$ να είναι παραγωγίσιμη στο $1$

Συνέχεια (απαραίτητη, Θ. 5.3.1): $\lim_{x\to1^-}f = a + 1$, $\lim_{x\to1^+}f = 1 + b$ ⇒ $a + 1 = 1 + b$, δηλ. $a = b$.

Ίσες πλευρικές παράγωγοι: $f'_-(1) = \lim_{h\to0^-}\frac{a(1 + h)^2 + 1 - (a + 1)}{h} = 2a$, $f'_+(1) = \lim_{h\to0^+}\frac{(1 + h) + b - (a + 1)}{h} = 1$ (με $a = b$). Άρα $2a = 1$: $a = b = \frac12$.

Πειραματίσου

f′₋(0) = −1 (αριστερή)  ·  f′₊(0) = 1 (δεξιά)
f′₋ ≠ f′₊ ⇒ η f δεν είναι παραγωγίσιμη στο 0 (γωνιακό σημείο).

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να βρείτε τις πλευρικές παραγώγους της $f(x) = |x - 2|$ στο $x_0 = 2$.
Υπόδειξη: $\frac{|h|}{h}$ για $h \to 0^\pm$.
Λύση: $\dfrac{f(2 + h) - f(2)}{h} = \dfrac{|h|}{h}$, που ισούται με $1$ για $h > 0$ και $-1$ για $h < 0$. Άρα $f'_-(2) = -1$, $f'_+(2) = 1$· η $f'(2)$ δεν υπάρχει.
Άσκηση 2Βασική
Να βρείτε τις πλευρικές παραγώγους της $f(x) = x + |x|$ στο $0$.
Υπόδειξη: Για $x > 0$ είναι $f(x) = 2x$, για $x < 0$ είναι $f(x) = 0$.
Λύση: $f'_+(0) = \lim_{h\to0^+}\frac{h + h}{h} = 2$, $f'_-(0) = \lim_{h\to0^-}\frac{h - h}{h} = 0$.
Άσκηση 3Μέτρια
Η $f(x) = \begin{cases} x^2 + 2, & x \le 1 \\ x + 2, & x > 1\end{cases}$ στο $x_0 = 1$ είναι:
Υπόδειξη: Ελέγξτε πρώτα τη συνέχεια και μετά τις πλευρικές παραγώγους.
Λύση: $\lim_{x\to1^\pm}f(x) = 3 = f(1)$: συνεχής. $f'_-(1) = 2$ (από $x^2 + 2$), $f'_+(1) = 1$ (από $x + 2$): διαφορετικές, άρα όχι παραγωγίσιμη.
Άσκηση 4Μέτρια
Να βρείτε τα $a, b$ ώστε η $f(x) = \begin{cases} ax^2 + 1, & x \le 1 \\ x + b, & x > 1\end{cases}$ να είναι παραγωγίσιμη στο $x = 1$.
Υπόδειξη: Συνέχεια και ίσες πλευρικές παράγωγοι.
Λύση: Συνέχεια: $a + 1 = 1 + b$. Παράγωγοι: $2a = 1$. Άρα $a = b = \frac12$.
Άσκηση 5Μέτρια
Για $f(x) = x^2\sin\frac1x$ ($x \ne 0$), $f(0) = 0$, να υπολογίσετε την $f'(0)$.
Υπόδειξη: $\frac{f(h) - f(0)}{h} = h\sin\frac1h$.
Λύση: $|h\sin\frac1h| \le |h| \to 0$, άρα (κριτήριο παρεμβολής) $f'(0) = 0$.
Άσκηση 6Μέτρια
Για $g(x) = x\sin\frac1x$ ($x \ne 0$), $g(0) = 0$ (Πρόβλημα 5.41), στο $x = 0$ ισχύει:
Υπόδειξη: $\frac{g(h) - g(0)}{h} = \sin\frac1h$.
Λύση: $|x\sin\frac1x| \le |x| \to 0 = g(0)$: συνεχής. Όμως $\frac{g(h) - g(0)}{h} = \sin\frac1h$, που δεν έχει όριο όταν $h \to 0$: δεν υπάρχει $g'(0)$.
Άσκηση 7Βασική
Αν η $f$ είναι συνεχής στο $x_0$, τότε είναι παραγωγίσιμη στο $x_0$.
Υπόδειξη: Αντιπαράδειγμα: $|x|$.
Λύση: Λάθος: η $|x|$ είναι συνεχής στο $0$ αλλά όχι παραγωγίσιμη (Παρατήρηση 2 του Θεωρήματος 5.3.1).
Άσκηση 8Βασική
Αν η $f$ δεν είναι συνεχής στο $x_0$, τότε δεν είναι παραγωγίσιμη στο $x_0$.
Υπόδειξη: Θεώρημα 5.3.1 (αντιθετοαντιστροφή).
Λύση: Σωστό: αν ήταν παραγωγίσιμη, θα ήταν συνεχής (Θεώρημα 5.3.1).
Άσκηση 9Μέτρια
Για ποια τιμή του $k$ η $f(x) = \begin{cases} x^2 - 1, & x \le 1 \\ k(x - 1), & x > 1\end{cases}$ είναι παραγωγίσιμη στο $1$; (Πρόβλημα 5.35)
Υπόδειξη: Η $f$ είναι συνεχής στο $1$ για κάθε $k$· συγκρίνετε τις πλευρικές παραγώγους.
Λύση: $f(1) = 0$ και $\lim_{x\to1^+}k(x - 1) = 0$: συνεχής για κάθε $k$. $f'_-(1) = 2\cdot1 = 2$, $f'_+(1) = k$. Παραγωγίσιμη ⇔ $k = 2$.
Άσκηση 10Απαιτητική
Η $f$ ικανοποιεί $f(x + y) = f(x) + f(y) + 5xy$ για κάθε $x, y$ και $\displaystyle\lim_{x\to0}\frac{f(x)}{x} = 3$. Να βρείτε τα $f(0)$ και $f'(2)$.
Υπόδειξη: Βάλτε $x = y = 0$. Μετά $\frac{f(x + h) - f(x)}{h} = \frac{f(h)}{h} + 5x$.
Λύση: Με $x = y = 0$: $f(0) = 2f(0) \Rightarrow f(0) = 0$. $\dfrac{f(x + h) - f(x)}{h} = \dfrac{f(h) + 5xh}{h} = \dfrac{f(h)}{h} + 5x \to 3 + 5x$. Άρα $f'(x) = 5x + 3$ και $f'(2) = 13$.

♾️ Γεννήτρια — παραγωγισιμότητα κλαδικής συνάρτησης

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρεθούν τα $a, b \in \mathbb R$ ώστε η $f(x) = \begin{cases} x^{2}, & x \le 1 \\ ax + b, & x > 1\end{cases}$ να είναι παραγωγίσιμη στο $x_0 = 1$.
Λύση: Πρέπει $f'_-(1) = f'_+(1)$: $2\cdot 1 = a$, άρα $a = 2$. Και συνέχεια (Θεώρημα 5.3.1): $f(1) = 1 = 2\cdot 1 + b$, άρα $b = -1$.
