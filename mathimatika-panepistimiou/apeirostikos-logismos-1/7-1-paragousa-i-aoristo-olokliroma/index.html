7.1

Παράγουσα ή αόριστο ολοκλήρωμα

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 7 §7.1–7.1.1 · Προβλήματα 7.1–7.3, 7.7–7.10

Αν ξέρουμε την κλίση μιας καμπύλης σε κάθε σημείο, μπορούμε να βρούμε την ίδια την καμπύλη; Η ολοκλήρωση είναι η αντίστροφη πράξη της παραγώγισης.

Θεωρία

7.1.1 · Παράγουσα

Η συνάρτηση $F(x)$ είναι μια παράγουσα (ή αντιπαράγωγος ή ένα αόριστο ολοκλήρωμα) της συνάρτησης $f(x)$ σε κάποιο διάστημα $I$, αν υπάρχει η παράγωγος $F'(x)$ στο $I$ και ισχύει

$$F'(x) = f(x), \quad \forall x \in I.$$

Π.χ. η $F(x) = \frac13 x^3$ είναι παράγουσα της $f(x) = x^2$, αφού $\left(\frac13x^3\right)' = x^2$. Το ίδιο και κάθε $\frac13x^3 + c$.

7.1.1 · Όλες οι παράγουσες

Αν η $F(x)$ είναι παράγουσα της $f(x)$ σε κάποιο διάστημα $I$, τότε η συνάρτηση $F(x) + c$, όπου $c$ σταθερά, είναι επίσης παράγουσα της $f(x)$ για κάθε τιμή της σταθεράς $c$. Επιπλέον, δύο παράγουσες $F_1, F_2$ της $f$ στο $I$ διαφέρουν κατά μια σταθερά.

Απόδειξη

$(F + c)' = F' + 0 = f$. Αν $F_1' = F_2' = f$ στο $I$, τότε $(F_1 - F_2)' = 0$ στο διάστημα $I$, άρα (συνέπεια του Θεωρήματος Μέσης Τιμής) η $F_1 - F_2$ είναι σταθερή.

7.1.2 · Αόριστο ολοκλήρωμα

Καλούμε αόριστο ολοκλήρωμα της $f(x)$ στο διάστημα $I$ και το συμβολίζουμε με $\int f(x)\,dx$ κάθε παράγουσα $F(x) + c$, όπου $c$ αυθαίρετη σταθερά:

$$\int f(x)\,dx = F(x) + c \iff F'(x) = f(x).$$

Η $f(x)$ λέγεται συνάρτηση προς ολοκλήρωση, το $\int$ σύμβολο ολοκληρώσεως και η $c$ σταθερά ολοκληρώσεως. Μια $f$ είναι ολοκληρώσιμη (επί αόριστο ολοκλήρωμα) στο $[a, b]$ αν σ' αυτό υπάρχει παράγουσά της.

Βασικά αόριστα ολοκληρώματα

$\int a\,dx = ax + c$
$\int x^n dx = \frac{x^{n+1}}{n+1} + c,\ n \ne -1$
$\int \frac{dx}{x} = \ln|x| + c$
$\int e^x dx = e^x + c$
$\int \sqrt x\,dx = \frac23 x^{3/2} + c$
$\int \frac{dx}{\sqrt x} = 2\sqrt x + c$
$\int \sin x\,dx = -\cos x + c$
$\int \cos x\,dx = \sin x + c$
$\int \sec^2 x\,dx = \tan x + c$
$\int \csc^2 x\,dx = -\cot x + c$
$\int \sec x\tan x\,dx = \sec x + c$
$\int \csc x\cot x\,dx = -\csc x + c$

7.1.1 · Ιδιότητες του αόριστου ολοκληρώματος

(α) $\displaystyle\frac{d}{dx}\left[\int f(x)\,dx\right] = f(x)$   (β) $\int a f(x)\,dx = a\int f(x)\,dx$, $a$ σταθερά   (γ) $\int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx$.

Γενικεύονται σε περισσότερους όρους: $\int [a_1f_1 + \dots + a_nf_n]\,dx = a_1\int f_1\,dx + \dots + a_n\int f_n\,dx$.

Καμπύλη από την κλίση της

Να βρεθεί η καμπύλη που περνά από το $(-3, 0)$ και η εφαπτομένη της έχει κλίση $2x + 1$.

Λύση βήμα-βήμα

$\frac{dy}{dx} = 2x + 1 \Rightarrow y = \int (2x + 1)\,dx = x^2 + x + c$. Για $x = -3$: $0 = 9 - 3 + c \Rightarrow c = -6$. Άρα $y = x^2 + x - 6$.

Συχνά λάθη

Ξεχνάμε τη σταθερά $c$ · γράφουμε $\int x^{-1}dx = \frac{x^0}{0}$ (ο τύπος δεν ισχύει για $n = -1$!) · $\int f g\,dx \ne \int f\,dx\cdot\int g\,dx$. Κάθε απάντηση ελέγχεται παραγωγίζοντας.

Πειραματίσου

f(x) = 2x · μία παράγουσα: F(x) = x² · όλες οι παράγουσες: F(x) + c
Από το σημείο (1, 2) περνά η F(x) + c με c = 1 και εκεί έχει κλίση F′(x₀) = f(x₀) = 2.
Κάθε μικρό ευθύγραμμο τμήμα έχει κλίση f(x): οι παράγουσες «ακολουθούν» το πεδίο κλίσεων και διαφέρουν μόνο κατά σταθερά (Θεώρημα 7.1.1).

👆 Σύρε το πορτοκαλί σημείο: η λύση περνά από αυτό (αρχική συνθήκη F(x₀) = y₀).

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να βρείτε το $\displaystyle\int (3x^2 - 4x + 5)\,dx$.
Υπόδειξη: Ολοκλήρωση όρο-όρο με $\int x^n dx = \frac{x^{n+1}}{n+1} + c$.
Λύση: $\int (3x^2 - 4x + 5)\,dx = x^3 - 2x^2 + 5x + c$. Έλεγχος: $(x^3 - 2x^2 + 5x)' = 3x^2 - 4x + 5$ ✓.
Άσκηση 2Βασική
Να βρείτε το $\displaystyle\int \left(x^5 + \frac{2}{x^3} - 3\sqrt x\right)dx$, $x > 0$.
Υπόδειξη: Γράψτε $\frac2{x^3} = 2x^{-3}$ και $\sqrt x = x^{1/2}$.
Λύση: $\frac{x^6}{6} + 2\cdot\frac{x^{-2}}{-2} - 3\cdot\frac{x^{3/2}}{3/2} + c = \frac{x^6}{6} - \frac{1}{x^2} - 2x^{3/2} + c$.
Άσκηση 3Βασική
Να βρείτε το $\displaystyle\int \frac{2x^3 - x^5}{x^5}\,dx$, $x > 0$.
Υπόδειξη: Διαιρέστε όρο-όρο: $\frac{2x^3 - x^5}{x^5} = 2x^{-2} - 1$.
Λύση: $\int (2x^{-2} - 1)\,dx = 2\cdot\frac{x^{-1}}{-1} - x + c = -\frac2x - x + c$.
Άσκηση 4Μέτρια
Να βρείτε το $\displaystyle\int \sec x\,(\sec x + \tan x)\,dx$ στο $\left(-\frac\pi2, \frac\pi2\right)$. (Γράψτε $\sec x$ ως 1/cos(x).)
Υπόδειξη: Κάντε την επιμεριστική: $\sec^2x + \sec x\tan x$.
Λύση: $\int (\sec^2 x + \sec x\tan x)\,dx = \tan x + \sec x + c$.
Άσκηση 5Μέτρια
Να βρείτε το $\displaystyle\int \tan^2 x\,dx$ στο $\left(-\frac\pi2, \frac\pi2\right)$.
Υπόδειξη: Ταυτότητα: $\tan^2x = \sec^2x - 1$.
Λύση: $\int (\sec^2x - 1)\,dx = \tan x - x + c$.
Άσκηση 6Μέτρια
Να βρείτε τη συνάρτηση $f$ αν $f'(x) = 3x^2 - 2$ και $f(1) = 4$.
Υπόδειξη: $f(x) = \int f'(x)\,dx = x^3 - 2x + c$· η συνθήκη δίνει το $c$.
Λύση: $f(x) = x^3 - 2x + c$, $\ f(1) = 1 - 2 + c = 4 \Rightarrow c = 5$. Άρα $f(x) = x^3 - 2x + 5$.
Άσκηση 7Μέτρια
Να βρείτε την εξίσωση της καμπύλης που περνά από το σημείο $(2, 1)$ και της οποίας η εφαπτομένη σε κάθε σημείο $(x, y)$ έχει κλίση $4x - 3$.
Υπόδειξη: $\frac{dy}{dx} = 4x - 3$.
Λύση: $y = \int (4x - 3)\,dx = 2x^2 - 3x + c$. Για $x = 2$: $1 = 8 - 6 + c \Rightarrow c = -1$, άρα $y = 2x^2 - 3x - 1$.
Άσκηση 8Απαιτητική
Να λύσετε τη διαφορική εξίσωση $x\,\dfrac{dy}{dx} = 2$, $x > 0$, με $y(1) = 3$.
Υπόδειξη: Χωρίστε τις μεταβλητές: $dy = \frac{2}{x}\,dx$.
Λύση: $dy = \frac{2\,dx}{x} \Rightarrow y = 2\ln x + c$ (για $x > 0$). $y(1) = c = 3$, άρα $y = 2\ln x + 3$.
Άσκηση 9Βασική
Αν $\displaystyle\int f(x)\,dx = 4x^3 - x^2 + c$, να βρείτε το $f(2)$.
Υπόδειξη: Ιδιότητα (α): $\frac{d}{dx}\int f(x)\,dx = f(x)$.
Λύση: $f(x) = (4x^3 - x^2 + c)' = 12x^2 - 2x$, άρα $f(2) = 48 - 4 = 44$.
Άσκηση 10Βασική
Αν οι $F$ και $G$ είναι δύο παράγουσες της ίδιας συνάρτησης $f$ στο ίδιο διάστημα $I$, τότε η $F - G$ είναι σταθερή στο $I$.
Υπόδειξη: Πόση είναι η $(F - G)'$;
Λύση: Σωστό (Θεώρημα 7.1.1): $(F - G)' = f - f = 0$ σε διάστημα, άρα η $F - G$ είναι σταθερή.

Εξάσκηση #1
Να βρείτε την καμπύλη $y = f(x)$ που περνά από το σημείο $(-1, 0)$ και της οποίας η εφαπτομένη σε κάθε σημείο έχει κλίση $4x + 3$.
Υπόδειξη: $f(x) = \int f'(x)\,dx$ και μετά $f(-1) = 0$ για τη σταθερά.
Λύση: $f(x) = 2x^2 + 3x + c$, $\ f(-1) = -1 + c = 0 \Rightarrow c = 1$: $\ y = 2x^2 + 3x + 1$.
