11.5

Τριγωνομετρικές και υπερβολικές αντικαταστάσεις

📘 Σημειώσεις ΜΑΣ012 · Κεφ. 11 §11.5 · 1η σειρά ασκήσεων (Κεφ. 11)

Οι ρίζες $\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$, $\sqrt{x^2 - a^2}$ «εξαφανίζονται» αν το $x$ γίνει πλευρά ενός ορθογωνίου τριγώνου.

Θεωρία

Ο πίνακας των αντικαταστάσεων

$\begin{array}{lll} \sqrt{a^2 - x^2} & x = a\sin\theta & a^2 - a^2\sin^2\theta = a^2\cos^2\theta \\ \sqrt{a^2 + x^2} & x = a\tan\theta\ \ (\text{ή } x = a\sinh t) & a^2 + a^2\tan^2\theta = a^2\sec^2\theta \\ \sqrt{x^2 - a^2} & x = a\sec\theta\ \ (\text{ή } x = a\cosh t) & a^2\sec^2\theta - a^2 = a^2\tan^2\theta \end{array}$

Στο τέλος επιστρέφουμε στο $x$ με τη βοήθεια ενός τριγώνου αναφοράς.

$\int\frac{x^2}{\sqrt{9 - x^2}}dx$

$x = 3\sin\theta$, $dx = 3\cos\theta\,d\theta$, $\sqrt{9 - x^2} = 3\cos\theta$: $\int\frac{9\sin^2\theta\cdot 3\cos\theta}{3\cos\theta}d\theta = 9\int\sin^2\theta\,d\theta = \frac92(\theta - \sin\theta\cos\theta) + C$.

Από το τρίγωνο: $\sin\theta = \frac x3$, $\cos\theta = \frac{\sqrt{9 - x^2}}{3}$, άρα $= \frac92\sin^{-1}\frac x3 - \frac x2\sqrt{9 - x^2} + C$.

Εμβαδόν κύκλου

$\int_0^2\sqrt{4 - x^2}\,dx$ με $x = 2\sin\theta$: $4\int_0^{\pi/2}\cos^2\theta\,d\theta = 4\cdot\frac\pi4 = \pi$ — το ένα τέταρτο του δίσκου ακτίνας $2$.

Υπερβολικές αντικαταστάσεις

Αφού $1 + \sinh^2t = \cosh^2t$ και $\cosh^2t - 1 = \sinh^2t$, οι $x = a\sinh t$ και $x = a\cosh t$ παίζουν τον ίδιο ρόλο με τις $a\tan\theta$, $a\sec\theta$. Π.χ. $\int\frac{dx}{\sqrt{1 + x^2}} \overset{x = \sinh t}{=} \int dt = \sinh^{-1}x + C$.

Πειραματίσου

θ = 0,5764 rad (33°). Ταυτότητα που «σβήνει» τη ρίζα: $a^2 - a^2\sin^2\theta = a^2\cos^2\theta$.
Από το τρίγωνο διαβάζουμε όλους τους τριγωνομετρικούς αριθμούς του θ συναρτήσει του x, π.χ. sinθ = 0,545, cosθ = 0,8384, tanθ = 0,65.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε το $\displaystyle\int\frac{x^2}{\sqrt{9 - x^2}}\,dx$.
Υπόδειξη: $x = 3\sin\theta$.
Λύση: $9\int\sin^2\theta\,d\theta = \frac92(\theta - \sin\theta\cos\theta) = \frac92\sin^{-1}\frac x3 - \frac x2\sqrt{9 - x^2} + C$.
Άσκηση 2Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{dx}{x^2\sqrt{16 - x^2}}$, $0 < x < 4$.
Υπόδειξη: $x = 4\sin\theta$ και $\int\csc^2\theta = -\cot\theta$.
Λύση: $\frac1{16}\int\csc^2\theta\,d\theta = -\frac{\cot\theta}{16} + C = -\frac{\sqrt{16 - x^2}}{16x} + C$.
Άσκηση 3Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{dx}{x^2\sqrt{1 + x^2}}$, $x > 0$.
Υπόδειξη: $x = \tan\theta$: προκύπτει $\int\frac{\cos\theta}{\sin^2\theta}d\theta$.
Λύση: $\int\frac{\sec^2\theta}{\tan^2\theta\sec\theta}d\theta = \int\frac{\cos\theta}{\sin^2\theta}d\theta = -\frac{1}{\sin\theta} + C = -\frac{\sqrt{1 + x^2}}{x} + C$.
Άσκηση 4Μέτρια
Να υπολογίσετε το $\displaystyle\int\frac{dx}{x^2\sqrt{9 + x^2}}$, $x > 0$.
Υπόδειξη: $x = 3\tan\theta$.
Λύση: $\frac19\int\frac{\cos\theta}{\sin^2\theta}d\theta = -\frac{1}{9\sin\theta} + C = -\frac{\sqrt{9 + x^2}}{9x} + C$.
Άσκηση 5Απαιτητική
Να υπολογίσετε το $\displaystyle\int\frac{\sqrt{x^2 - 16}}{x^4}\,dx$, $x > 4$.
Υπόδειξη: $x = 4\sec\theta$: προκύπτει $\frac1{16}\int\sin^2\theta\cos\theta\,d\theta$.
Λύση: $\frac{1}{16}\cdot\frac{\sin^3\theta}{3} + C$ με $\sin\theta = \frac{\sqrt{x^2 - 16}}{x}$: $\frac{(x^2 - 16)^{3/2}}{48x^3} + C$.
Άσκηση 6Απαιτητική
Να υπολογίσετε το $\displaystyle\int\frac{dx}{(x^2 + 8x + 25)^{3/2}}$.
Υπόδειξη: $x^2 + 8x + 25 = (x + 4)^2 + 9$, $x + 4 = 3\tan\theta$.
Λύση: $\frac19\int\cos\theta\,d\theta = \frac{\sin\theta}{9} + C = \frac{x + 4}{9\sqrt{x^2 + 8x + 25}} + C$.
Άσκηση 7Βασική
Να υπολογίσετε το $\displaystyle\int_0^2\sqrt{4 - x^2}\,dx$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: Τέταρτο κύκλου ακτίνας 2.
Λύση: $x = 2\sin\theta$: $4\int_0^{\pi/2}\cos^2\theta\,d\theta = \pi$.
Άσκηση 8Μέτρια
Να υπολογίσετε το $\displaystyle\int_0^1\frac{dx}{(1 + x^2)^{3/2}}$ (4 δεκαδικά).
Υπόδειξη: $x = \tan\theta$, όρια $0 \to \frac\pi4$.
Λύση: $\int_0^{\pi/4}\cos\theta\,d\theta = \sin\frac\pi4 = \frac{\sqrt2}{2} \approx 0{,}7071$.
Άσκηση 9Βασική
Για το $\displaystyle\int\frac{\sqrt{x^2 - 25}}{x}\,dx$ η κατάλληλη αντικατάσταση είναι:
Υπόδειξη: $\sec^2\theta - 1 = \tan^2\theta$.
Λύση: Με $x = 5\sec\theta$: $\sqrt{25\sec^2\theta - 25} = 5\tan\theta$.

♾️ Γεννήτρια — τριγωνομετρικές αντικαταστάσεις

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Με την αντικατάσταση $x = 4\sin\theta$, να υπολογίσετε το $\displaystyle\int_0^{4}\sqrt{16 - x^2}\,dx$ ως $k\pi$: δώστε το $k$.
Υπόδειξη: $\sqrt{a^2 - x^2}$: $x = a\sin\theta$ · $\sqrt{a^2 + x^2}$: $x = a\tan\theta$ · $\sqrt{x^2 - a^2}$: $x = a\sec\theta$.
Λύση: $dx = 4\cos\theta\,d\theta$, $\theta: 0 \to \frac\pi2$: $\int_0^{\pi/2} 16\cos^2\theta\,d\theta = 16\cdot\frac\pi4 = 4\pi$ (τεταρτοκύκλιο ακτίνας 4).
