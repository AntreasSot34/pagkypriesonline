7.2.3

Άθροισμα – γινόμενο λύσεων (Vieta)

📘 Β΄ Τεύχος §7.2 · Δραστηριότητες σελ. 131

Θεωρία

Τύποι Vieta

Αν $x_1, x_2$ είναι οι λύσεις της $\alpha x^2 + \beta x + \gamma = 0$ ($\Delta \ge 0$):

$$S = x_1 + x_2 = -\frac{\beta}{\alpha} \qquad P = x_1 x_2 = \frac{\gamma}{\alpha}$$

Χρήσιμες ταυτότητες: $\;x_1^2 + x_2^2 = S^2 - 2P$, $\;\dfrac{1}{x_1} + \dfrac{1}{x_2} = \dfrac{S}{P}$.

Εφαρμογές

  • Σχηματισμός εξίσωσης με λύσεις $\rho_1, \rho_2$: $\;x^2 - Sx + P = 0$.
  • Παραγοντοποίηση: $\alpha x^2 + \beta x + \gamma = \alpha(x - x_1)(x - x_2)$.
  • Λύσεις αντίθετες ⇔ $S = 0$ · αντίστροφες ⇔ $P = 1$ (με $\Delta > 0$).

Πειραματίσου

f(x) = x² − 2x − 3 · Δ = β² − 4αγ = 16 ⇒ δύο ρίζες: -1, 3
Κορυφή (−β/2α, −Δ/4α) = (1, -4) · ελάχιστο -4 · S = −β/α = 2, P = γ/α = -3
Λύσεις της ανίσωσης f(x) > 0: x < -1 ή x > 3 (πράσινη σκίαση)
Κανόνας: έξω από τις ρίζες το τριώνυμο έχει το πρόσημο του α, ανάμεσα στις ρίζες το αντίθετο.

Ασκήσεις — 0/7 λυμένες

Άσκηση 1Βασική
Αν $x_1, x_2$ οι λύσεις της $x^2 - 7x + 3 = 0$, χωρίς να τη λύσετε, να υπολογίσετε: $x_1 + x_2$, $x_1x_2$, $3x_1 + 2x_1x_2 + 3x_2$, $\frac{1}{x_1} + \frac{1}{x_2}$, $x_1^2 + x_2^2$.
Υπόδειξη: $S = 7$, $P = 3$. Γράψε κάθε παράσταση με τα $S$ και $P$.
Λύση: $S = 7$, $P = 3$. $3S + 2P = 21 + 6 = 27$. $\frac{S}{P} = \frac73$. $S^2 - 2P = 49 - 6 = 43$.
Άσκηση 2Μέτρια
Δίνεται η εξίσωση $x^2 - (\lambda - 2)x + 2\lambda - 8 = 0$. Να βρείτε το $\lambda$ ώστε η εξίσωση να έχει: (α) λύση τον $-2$, (β) λύσεις αντίστροφες, (γ) λύσεις με άθροισμα $10$.
Υπόδειξη: (α) Αντικατάστησε $x = -2$. (β) $P = 1$. (γ) $S = 10$. Έλεγξε ότι $\Delta > 0$!
Λύση: (α) $4 + 2(\lambda - 2) + 2\lambda - 8 = 4\lambda - 8 = 0 \Rightarrow \lambda = 2$.
(β) $2\lambda - 8 = 1 \Rightarrow \lambda = \frac92$ (τότε $x^2 - \frac52x + 1 = 0$, $\Delta = \frac{9}{4} > 0$ ✓).
(γ) $\lambda - 2 = 10 \Rightarrow \lambda = 12$ (τότε $x^2 - 10x + 16 = 0$, $\Delta = 36 > 0$ ✓).
Άσκηση 3Μέτρια
Δίνεται η εξίσωση $4x^2 + 3\mu x + 3\mu - 5 = 0$. Για ποια τιμή του $\mu$: (α) έχει λύσεις αντίστροφες, (β) ισχύει $x_1 + x_2 = x_1x_2$;
Υπόδειξη: $S = -\frac{3\mu}{4}$, $P = \frac{3\mu - 5}{4}$.
Λύση: (α) $\frac{3\mu - 5}{4} = 1 \Rightarrow \mu = 3$ (τότε $4x^2 + 9x + 4 = 0$, $\Delta = 17 > 0$ ✓).
(β) $-3\mu = 3\mu - 5 \Rightarrow \mu = \frac56$.
Άσκηση 4Βασική
Να σχηματίσετε εξίσωση 2ου βαθμού με ακέραιους συντελεστές, της μορφής $x^2 + \beta x + \gamma = 0$, που έχει λύσεις: (α) $2$ και $-3$, (β) $7 + \sqrt3$ και $7 - \sqrt3$.
Υπόδειξη: $x^2 - Sx + P = 0$.
Λύση: (α) $S = -1$, $P = -6$: $x^2 + x - 6 = 0$. (β) $S = 14$, $P = 49 - 3 = 46$: $x^2 - 14x + 46 = 0$.
Άσκηση 5Μέτρια
Να σχηματίσετε εξίσωση με ακέραιους συντελεστές, της μορφής $15x^2 + \beta x + \gamma = 0$, με λύσεις $\frac13$ και $-\frac25$.
Υπόδειξη: $S = \frac13 - \frac25 = -\frac{1}{15}$, $P = -\frac{2}{15}$. Πολλαπλασίασε την $x^2 - Sx + P = 0$ με 15.
Λύση: $x^2 + \frac{1}{15}x - \frac{2}{15} = 0 \Rightarrow 15x^2 + x - 2 = 0$.
Άσκηση 6Μέτρια
Να παραγοντοποιήσετε: $2x^2 - x - 21 = 2(x - \rho_1)(x - \rho_2)$ με $\rho_1 < \rho_2$.
Υπόδειξη: Βρες τις ρίζες του τριωνύμου: $\Delta = 1 + 168 = 169$.
Λύση: $x = \frac{1 \pm 13}{4}$ ⇒ $-3$ και $\frac72$. Άρα $2x^2 - x - 21 = 2(x + 3)\left(x - \frac72\right) = (x + 3)(2x - 7)$.
Άσκηση 7Μέτρια
Να απλοποιήσετε το κλάσμα $\dfrac{2x^2 - 3x - 2}{x^2 - 4x + 4}$ (για $x \ne 2$) και να το γράψετε στη μορφή $\dfrac{\alpha x + \beta}{x + \gamma}$.
Υπόδειξη: Αριθμητής: ρίζες $2$ και $-\frac12$. Παρονομαστής: $(x - 2)^2$.
Λύση: $2x^2 - 3x - 2 = (x - 2)(2x + 1)$ και $x^2 - 4x + 4 = (x - 2)^2$. Άρα $\dfrac{(x-2)(2x+1)}{(x-2)^2} = \dfrac{2x + 1}{x - 2}$.

♾️ Γεννήτρια — άθροισμα και γινόμενο λύσεων

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Αν $x_1, x_2$ είναι οι λύσεις της $3x^2 + 3x - 8 = 0$, χωρίς να τη λύσετε, να υπολογίσετε τα $S = x_1 + x_2$, $P = x_1x_2$ και $x_1^2 + x_2^2$.
Λύση: $\Delta = 105 > 0$. $S = -\frac{\beta}{\alpha} = -1$, $P = \frac{\gamma}{\alpha} = -\frac{8}{3}$.
$x_1^2 + x_2^2 = S^2 - 2P = \frac{19}{3}$.
