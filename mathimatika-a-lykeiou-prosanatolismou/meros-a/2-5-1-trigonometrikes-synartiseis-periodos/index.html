2.5.1

Τριγωνομετρικές συναρτήσεις – περίοδος

📘 Α΄ Τεύχος §2.5 · Δραστηριότητες σελ. 108

Θεωρία

Οι συναρτήσεις ημ, συν, εφ

  • $f(x) = \text{ημ}x$ και $g(x) = \text{συν}x$: πεδίο ορισμού $\mathbb{R}$, σύνολο τιμών $[-1, 1]$, περίοδος $2\pi$.
  • $h(x) = \text{εφ}x$: ορίζεται για $x \ne \kappa\pi + \frac\pi2$, σύνολο τιμών $\mathbb{R}$, περίοδος $\pi$ (κατακόρυφες ασύμπτωτες στα $\frac\pi2 + \kappa\pi$).

Περιοδική: $f(x + T) = f(x)$ για κάθε $x$. Π.χ. $\text{ημ}(x + 2\pi) = \text{ημ}x$, $\text{εφ}(x + \pi) = \text{εφ}x$.

Η $y = \alpha\cdot\text{ημ}(\kappa x)$

Μέγιστο $|\alpha|$, ελάχιστο $-|\alpha|$, περίοδος $T = \dfrac{2\pi}{\kappa}$ ($\kappa > 0$). Το ίδιο για το συν. Για $y = \alpha\,\text{εφ}(\kappa x)$: $T = \dfrac{\pi}{\kappa}$.

Άρτια – περιττή

$\text{συν}(-x) = \text{συν}x$ (άρτια, συμμετρική ως προς $y'y$) · $\text{ημ}(-x) = -\text{ημ}x$, $\text{εφ}(-x) = -\text{εφ}x$ (περιττές, συμμετρικές ως προς $O$).

Πειραματίσου

y = ημ(x)  ·  περίοδος T = 2π/κ = 2π  ·  μέγιστο 1, ελάχιστο -1
Γκρι: y = ημx. Το α τεντώνει κατακόρυφα (και αναποδογυρίζει αν α < 0), το κ «συμπιέζει» οριζόντια και αλλάζει την περίοδο.

Ασκήσεις — 0/6 λυμένες

Άσκηση 1Βασική
Να βρείτε την περίοδο των συναρτήσεων: (α) $f(x) = \text{ημ}(2x)$, (β) $g(x) = 2\,\text{συν}x$, (γ) $h(x) = \text{εφ}(3x)$. (π.χ. π/3)
Υπόδειξη: $T = \frac{2\pi}{\kappa}$ για ημ/συν, $\frac\pi\kappa$ για εφ. Το $\alpha$ δεν αλλάζει την περίοδο.
Λύση: (α) $\frac{2\pi}{2} = \pi$. (β) $2\pi$ (το 2 μπροστά αλλάζει μόνο το πλάτος). (γ) $\frac\pi3$.
Άσκηση 2Βασική
Για τη συνάρτηση $f(x) = 2\,\text{ημ}(3x)$ να βρείτε τη μέγιστη τιμή, την ελάχιστη τιμή και την περίοδο.
Υπόδειξη: $-1 \le \text{ημ}(3x) \le 1$.
Λύση: $-2 \le 2\,\text{ημ}(3x) \le 2$, $T = \frac{2\pi}{3}$.
Άσκηση 3Βασική
Το σύνολο τιμών της $y = -3\,\text{συν}x$ είναι:
Υπόδειξη: Πολλαπλασίασε το $[-1, 1]$ με $-3$.
Λύση: $-1 \le \text{συν}x \le 1 \Rightarrow -3 \le -3\,\text{συν}x \le 3$. Σύνολο τιμών $[-3, 3]$.
Άσκηση 4Μέτρια
Ποια πρόταση είναι σωστή;
Υπόδειξη: Το $10\pi$ είναι 5 περίοδοι του συνημιτόνου.
Λύση: $10\pi = 5\cdot 2\pi$, άρα $f(x + 10\pi) = f(x)$ ✓. Τα άλλα: $\text{ημ}(-\theta) = -0{,}76$· $\text{συν}(x + 3\pi) = \text{συν}(x + \pi) = -\alpha$· η εφ έχει περίοδο $\pi$.
Άσκηση 5Μέτρια
Χωρίς υπολογιστική μηχανή: $\text{ημ}\frac{13\pi}{6}$, $\text{συν}\left(-\frac\pi3\right)$, $\text{εφ}\frac{5\pi}{4}$.
Υπόδειξη: $\frac{13\pi}{6} = 2\pi + \frac\pi6$, το συν είναι άρτια, $\frac{5\pi}{4} = \pi + \frac\pi4$.
Λύση: $\text{ημ}\frac\pi6 = \frac12$, $\text{συν}\frac\pi3 = \frac12$, $\text{εφ}\frac\pi4 = 1$ (περίοδος $\pi$).
Άσκηση 6Μέτρια
Τα σημεία $A\left(\frac{3\pi}{8}, \alpha\right)$ και $B\left(-\frac{13\pi}{8}, \beta\right)$ ανήκουν στη γραφική παράσταση της $f(x) = \text{ημ}x$. Τότε:
Υπόδειξη: $\frac{3\pi}{8} - \left(-\frac{13\pi}{8}\right) = 2\pi$.
Λύση: Οι τετμημένες διαφέρουν κατά $2\pi$, μία περίοδο, άρα $\alpha = \beta$.
