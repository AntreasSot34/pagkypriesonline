1.2

Ιδιότητες της νιοστής ρίζας

📘 Α΄ Τεύχος §1.2 · Δραστηριότητες σελ. 30

Θεωρία

Ιδιότητες ($\alpha, \beta \ge 0$, $\nu \in \mathbb{N}$)

$$\left(\sqrt[\nu]{\alpha}\right)^\nu = \alpha \qquad \sqrt[\nu]{\alpha\beta} = \sqrt[\nu]{\alpha}\cdot\sqrt[\nu]{\beta} \qquad \sqrt[\nu]{\frac{\alpha}{\beta}} = \frac{\sqrt[\nu]{\alpha}}{\sqrt[\nu]{\beta}}\ (\beta > 0)$$

Με αυτές «βγάζουμε» παράγοντες έξω από τη ρίζα:

$$\sqrt{18} = \sqrt{9\cdot 2} = 3\sqrt{2} \qquad \sqrt[4]{32} = \sqrt[4]{16\cdot 2} = 2\sqrt[4]{2} \qquad \sqrt[3]{\tfrac{24}{27}} = \tfrac{2\sqrt[3]{3}}{3}$$

Προσοχή — δεν ισχύουν!

$\sqrt{\alpha + \beta} \ne \sqrt{\alpha} + \sqrt{\beta}$ και $\sqrt{\alpha - \beta} \ne \sqrt{\alpha} - \sqrt{\beta}$.

Αντιπαράδειγμα: $\sqrt{9 + 16} = 5$, ενώ $\sqrt9 + \sqrt{16} = 7$.

Πράξεις με ρίζες

Προσθέτουμε μόνο όμοιες ρίζες, όπως όμοιους όρους: $\sqrt{12} + \sqrt{27} = 2\sqrt3 + 3\sqrt3 = 5\sqrt3$.

Στους πολλαπλασιασμούς χρησιμοποιούμε επιμεριστική και ταυτότητες: $(5 - \sqrt{x})^2 = 25 - 10\sqrt{x} + x$.

Ασκήσεις — 0/11 λυμένες

Άσκηση 1Βασική
Να απλοποιήσετε: (α) $\sqrt3\cdot\sqrt{27}$, (β) $\sqrt[4]{32} : \sqrt[4]{2}$, (γ) $\left(\sqrt2\right)^{14}$.
Υπόδειξη: Ένωσε τις ρίζες σε μία: $\sqrt{3\cdot 27}$, $\sqrt[4]{32 : 2}$. Για το (γ): $(\sqrt2)^{14} = \left[(\sqrt2)^2\right]^7$.
Λύση: (α) $\sqrt{81} = 9$. (β) $\sqrt[4]{16} = 2$. (γ) $\left[(\sqrt2)^2\right]^7 = 2^7 = 128$.
Άσκηση 2Βασική
Να γράψετε στη μορφή $\alpha\sqrt{\beta}$ με $\beta$ όσο γίνεται μικρότερο: (α) $\sqrt{200}$, (β) $\sqrt{48}$, (γ) $\sqrt{150}$.
Υπόδειξη: Βρες τον μεγαλύτερο τέλειο τετράγωνο παράγοντα: $200 = 100\cdot 2$.
Λύση: $\sqrt{200} = \sqrt{100}\sqrt2 = 10\sqrt2$, $\;\sqrt{48} = \sqrt{16}\sqrt3 = 4\sqrt3$, $\;\sqrt{150} = \sqrt{25}\sqrt6 = 5\sqrt6$.
Άσκηση 3Βασική
Να κάνετε τις πράξεις: (α) $\sqrt{50} - \sqrt2$, (β) $\sqrt{12} + \sqrt{27}$.
Υπόδειξη: Πρώτα κάθε ρίζα σε απλή μορφή, μετά πρόσθεση όμοιων ριζών.
Λύση: (α) $5\sqrt2 - \sqrt2 = 4\sqrt2$. (β) $2\sqrt3 + 3\sqrt3 = 5\sqrt3$.
Άσκηση 4Μέτρια
Να κάνετε τις πράξεις: (α) $\sqrt[3]{4}\cdot\left(\sqrt[3]{16} - \sqrt[3]{2}\right)$, (β) $\left(2\sqrt{75} + 3\sqrt{48} - 6\sqrt{27}\right) : \sqrt3$.
Υπόδειξη: (α) Επιμεριστική: $\sqrt[3]{64} - \sqrt[3]{8}$. (β) $\sqrt{75} = 5\sqrt3$, $\sqrt{48} = 4\sqrt3$, $\sqrt{27} = 3\sqrt3$.
Λύση: (α) $\sqrt[3]{64} - \sqrt[3]{8} = 4 - 2 = 2$.
(β) $(10\sqrt3 + 12\sqrt3 - 18\sqrt3) : \sqrt3 = 4\sqrt3 : \sqrt3 = 4$.
Άσκηση 5Μέτρια
Να κάνετε τις πράξεις: $\left(\sqrt3 + 2\sqrt5\right)\left(\sqrt3 - 4\sqrt5\right)$.
Υπόδειξη: Επιμεριστική: τέσσερα γινόμενα. $(\sqrt5)^2 = 5$ και $\sqrt3\cdot\sqrt5 = \sqrt{15}$.
Λύση: $3 - 4\sqrt{15} + 2\sqrt{15} - 8\cdot 5 = -37 - 2\sqrt{15}$.
Άσκηση 6Μέτρια
Να γράψετε την παράσταση $A = 4\sqrt{18} + \sqrt{50} - \sqrt{200}$ στη μορφή $\kappa\sqrt2$.
Υπόδειξη: $\sqrt{18} = 3\sqrt2$, $\sqrt{50} = 5\sqrt2$, $\sqrt{200} = 10\sqrt2$.
Λύση: $A = 12\sqrt2 + 5\sqrt2 - 10\sqrt2 = 7\sqrt2$, άρα $\kappa = 7$.
Άσκηση 7Μέτρια
Αν $x = 1 + \sqrt2$ και $y = 1 - \sqrt2$, να υπολογίσετε: (α) $x + y$, (β) $xy$, (γ) $x^2 - y^2$.
Υπόδειξη: (β) Διαφορά τετραγώνων. (γ) $x^2 - y^2 = (x+y)(x-y)$.
Λύση: (α) $2$. (β) $1^2 - (\sqrt2)^2 = 1 - 2 = -1$. (γ) $(x+y)(x-y) = 2\cdot 2\sqrt2 = 4\sqrt2$.
Άσκηση 8Βασική
Ποια από τις πιο κάτω ισότητες είναι σωστή;
Υπόδειξη: Έλεγξε την καθεμία: τι κάνει $\sqrt{12}$; Τι κάνει $\sqrt{90}$;
Λύση: $\sqrt{12} - \sqrt3 = 2\sqrt3 - \sqrt3 = \sqrt3$ ✓. Οι άλλες είναι λάθος: η ρίζα δεν «σπάει» σε αθροίσματα ($\sqrt{25} = 5 \ne 7$), και $\sqrt{90} = 3\sqrt{10}$.
Άσκηση 9Μέτρια
Για $x > 0$, να απλοποιήσετε την παράσταση $\sqrt[3]{16x^5 : (2x^2)}$.
Υπόδειξη: Κάνε πρώτα τη διαίρεση μέσα στη ρίζα: $16x^5 : (2x^2) = 8x^3$.
Λύση: $\sqrt[3]{8x^3} = \sqrt[3]{(2x)^3} = 2x$.
Άσκηση 10Μέτρια
Οι κάθετες πλευρές ορθογωνίου τριγώνου έχουν μήκη $(4 + \sqrt2)$ μ και $(4 - \sqrt2)$ μ. Να υπολογίσετε το μήκος της υποτείνουσας.
Υπόδειξη: Πυθαγόρειο: $(4+\sqrt2)^2 + (4-\sqrt2)^2$. Τα «διπλά γινόμενα» φεύγουν!
Λύση: $(16 + 8\sqrt2 + 2) + (16 - 8\sqrt2 + 2) = 36$, άρα υποτείνουσα $= \sqrt{36} = 6$ μ — φυσικός αριθμός.
Άσκηση 11Απαιτητική
Να υπολογίσετε το $x^3$, αν $x - 3\sqrt[3]{7} = 4\sqrt[3]{7}$.
Υπόδειξη: $x = 7\sqrt[3]{7}$, και $\left(\sqrt[3]{7}\right)^3 = 7$.
Λύση: $x = 7\sqrt[3]{7} \Rightarrow x^3 = 7^3\cdot\left(\sqrt[3]{7}\right)^3 = 343\cdot 7 = 2401$.

♾️ Γεννήτρια — ρίζες και δυνάμεις

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε χωρίς υπολογιστική μηχανή: $27^{-\frac{1}{3}}$.
Λύση: $27^{-\frac{1}{3}} = \left(\sqrt[3]{27}\right)^{-1} = 3^{-1} = \frac{1}{3}$.
