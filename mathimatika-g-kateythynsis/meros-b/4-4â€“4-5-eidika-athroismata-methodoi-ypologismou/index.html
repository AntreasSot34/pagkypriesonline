4.4–4.5

Ειδικά αθροίσματα – Μέθοδοι υπολογισμού

📘 Β΄ Τεύχος §4.4–4.5 · Δραστηριότητες σελ. 75, 80 · Ενότητας σελ. 81

Θεωρία

Βασικά αθροίσματα

$$S_1 = \sum_{\kappa=1}^{\nu}\kappa = \frac{\nu(\nu+1)}{2}, \qquad S_2 = \sum_{\kappa=1}^{\nu}\kappa^2 = \frac{\nu(\nu+1)(2\nu+1)}{6}, \qquad S_3 = \sum_{\kappa=1}^{\nu}\kappa^3 = \left(\frac{\nu(\nu+1)}{2}\right)^2$$

Μέθοδος διαφορών (τηλεσκοπικά αθροίσματα)

Αν $\alpha_\kappa = f(\kappa) - f(\kappa+1)$, τότε σχεδόν όλοι οι όροι διαγράφονται:

$$\sum_{\kappa=1}^{\nu}\alpha_\kappa = f(1) - f(\nu+1)$$

Π.χ. $\frac{1}{\kappa(\kappa+1)} = \frac1\kappa - \frac{1}{\kappa+1}$ ⇒ $\sum_{\kappa=1}^{\nu} = 1 - \frac{1}{\nu+1}$ (απλά κλάσματα!).

Συνδυασμός

$\sum\kappa(\kappa+1) = \sum\kappa^2 + \sum\kappa = S_2 + S_1$. Πάντα σπάμε σε βασικά αθροίσματα.

Πειραματίσου

Μερικό άθροισμα $s_{12} = 0{,}999756$ → άθροισμα σειράς 1 (κόκκινη γραμμή) · απόκλιση 2.44e-4

Ασκήσεις — 0/5 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε: $\displaystyle\sum_{\kappa=1}^{20}\kappa$, $\;\displaystyle\sum_{\kappa=1}^{10}\kappa^2$, $\;\displaystyle\sum_{\kappa=1}^{5}\kappa^3$.
Υπόδειξη: Τύποι $S_1, S_2, S_3$.
Λύση: $\frac{20\cdot21}{2} = 210$ · $\;\frac{10\cdot11\cdot21}{6} = 385$ · $\;\left(\frac{5\cdot6}{2}\right)^2 = 225$.
Άσκηση 2Μέτρια
Να βρείτε σε κλειστή μορφή το $\displaystyle\sum_{\kappa=1}^{\nu}(2\kappa - 1)$ (άθροισμα των $\nu$ πρώτων περιττών). $\;=$
Υπόδειξη: $2S_1 - \nu$.
Λύση: $2\cdot\frac{\nu(\nu+1)}{2} - \nu = \nu^2 + \nu - \nu = \nu^2$.
Άσκηση 3Μέτρια
Να βρείτε σε κλειστή μορφή το $\displaystyle\sum_{\kappa=1}^{\nu}\kappa(\kappa+1)$. $\;=$
Υπόδειξη: $S_2 + S_1$, κοινός παράγοντας $\frac{\nu(\nu+1)}{6}$.
Λύση: $\frac{\nu(\nu+1)(2\nu+1)}{6} + \frac{\nu(\nu+1)}{2} = \frac{\nu(\nu+1)}{6}(2\nu + 1 + 3) = \frac{\nu(\nu+1)(\nu+2)}{3}$.
Άσκηση 4Μέτρια
Για τη σειρά $\displaystyle\sum_{\kappa=1}^{\infty}\frac{1}{\kappa(\kappa+1)}$ να βρείτε το μερικό άθροισμα $s_9$ και το άθροισμα της σειράς.
Υπόδειξη: Τηλεσκοπικό: $s_\nu = 1 - \frac{1}{\nu+1}$.
Λύση: $s_9 = 1 - \frac{1}{10} = \frac{9}{10}$, $\;\lim s_\nu = 1$.
Άσκηση 5Απαιτητική
Να βρείτε το άθροισμα $\displaystyle\sum_{\kappa=1}^{\infty}\frac{1}{(2\kappa-1)(2\kappa+1)}$.
Υπόδειξη: $\frac{1}{(2\kappa-1)(2\kappa+1)} = \frac12\left(\frac{1}{2\kappa-1} - \frac{1}{2\kappa+1}\right)$.
Λύση: $s_\nu = \frac12\left(1 - \frac{1}{2\nu+1}\right) \to \frac12$.

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε $\displaystyle\sum_{\kappa=1}^{16}\kappa$.
Λύση: $\frac{16\cdot17}{2} = 136$.
