1.10

Προβλήματα μεγίστων – ελαχίστων

📘 Α΄ Τεύχος §1.10 · Δραστηριότητες σελ. 105 · Ενότητας σελ. 107

Θεωρία

Μέθοδος

  1. Σχήμα, μεταβλητές, και η σχέση που τις συνδέει (περιορισμός).
  2. Η ποσότητα προς βελτιστοποίηση ως συνάρτηση μίας μεταβλητής.
  3. Πεδίο ορισμού από το νόημα του προβλήματος.
  4. $f'(x) = 0$ ⇒ κρίσιμα σημεία μέσα στο πεδίο· πίνακας προσήμων ή $f''$.
  5. Απάντηση με μονάδες.

Κόλπο: απόσταση

Για ελάχιστη απόσταση $d = \sqrt{\dots}$, ελαχιστοποιούμε το $d^2$ — έχει το ελάχιστο στο ίδιο σημείο και γλιτώνουμε τη ρίζα.

Πειραματίσου

V(x) = x(12 − 2x)² = 100 cm³. Βρες με το slider το x που δίνει τον μεγαλύτερο όγκο — μετά επιβεβαίωσέ το με V′(x) = 0.

Ασκήσεις — 0/5 λυμένες

Άσκηση 1Βασική
Δύο θετικοί αριθμοί έχουν γινόμενο $16$. Ποιο είναι το ελάχιστο άθροισμά τους;
Υπόδειξη: $S(x) = x + \frac{16}{x}$, $x > 0$.
Λύση: $S'(x) = 1 - \frac{16}{x^2} = 0 \Rightarrow x = 4$ ($-\to+$). Άρα $4 + 4 = 8$.
Άσκηση 2Μέτρια
Ορθογώνιο είναι εγγεγραμμένο σε ημικύκλιο ακτίνας $2$ (η μία πλευρά του πάνω στη διάμετρο). Ποιο είναι το μέγιστο εμβαδόν του;
Υπόδειξη: Αν η βάση είναι $2x$, το ύψος είναι $\sqrt{4 - x^2}$. Μεγιστοποίησε το $E^2$.
Λύση: $E(x) = 2x\sqrt{4-x^2}$, $0 < x < 2$. $E^2 = 4x^2(4 - x^2) = 16x^2 - 4x^4$, $(E^2)' = 32x - 16x^3 = 0 \Rightarrow x = \sqrt2$.
$E(\sqrt2) = 2\sqrt2\cdot\sqrt2 = 4$.
Άσκηση 3Μέτρια
Κουτί χωρίς καπάκι με τετράγωνη βάση έχει όγκο $32$ cm³. Ποιες διαστάσεις ελαχιστοποιούν το υλικό (επιφάνεια);
Υπόδειξη: $x^2 h = 32$ ⇒ $E = x^2 + 4xh = x^2 + \frac{128}{x}$.
Λύση: $E'(x) = 2x - \frac{128}{x^2} = 0 \Rightarrow x^3 = 64 \Rightarrow x = 4$, $h = \frac{32}{16} = 2$. $E = 16 + 32 = 48$ cm².
Άσκηση 4Απαιτητική
Να βρείτε το σημείο της καμπύλης $y = \sqrt{x}$ που είναι πλησιέστερο στο $A(3, 0)$ και την ελάχιστη απόσταση.
Υπόδειξη: $d^2 = (x-3)^2 + x$.
Λύση: $D(x) = d^2 = (x-3)^2 + x$, $D'(x) = 2(x-3) + 1 = 0 \Rightarrow x = \frac52$.
$D(\frac52) = \frac14 + \frac52 = \frac{11}{4}$ ⇒ $d = \frac{\sqrt{11}}{2}$. Σημείο $\left(\frac52, \sqrt{\frac52}\right)$.
Άσκηση 5Απαιτητική
Κυλινδρικό κουτί (με καπάκι) πρέπει να έχει όγκο $54\pi$ cm³. Ποια ακτίνα και ποιο ύψος ελαχιστοποιούν την ολική επιφάνεια;
Υπόδειξη: $\pi r^2 h = 54\pi$ ⇒ $h = \frac{54}{r^2}$, $E = 2\pi r^2 + 2\pi r h$.
Λύση: $E(r) = 2\pi r^2 + \frac{108\pi}{r}$, $E'(r) = 4\pi r - \frac{108\pi}{r^2} = 0 \Rightarrow r^3 = 27 \Rightarrow r = 3$, $h = 6$. (Το βέλτιστο κουτί έχει ύψος = διάμετρο!)
