1.8

Ασύμπτωτες

📘 Α΄ Τεύχος §1.8 · Δραστηριότητες σελ. 83

Θεωρία

Κατακόρυφη ασύμπτωτη $x = x_0$

Αν ένα τουλάχιστον από τα πλευρικά όρια $\lim_{x\to x_0^\pm} f(x)$ είναι $+\infty$ ή $-\infty$. Υποψήφια σημεία: όπου μηδενίζεται ο παρονομαστής, άκρα πεδίου ορισμού.

Οριζόντια ασύμπτωτη $y = \beta$

Αν $\lim_{x\to+\infty} f(x) = \beta$ (ή αντίστοιχα στο $-\infty$).

Πλάγια ασύμπτωτη $y = \lambda x + \beta$

$$\lambda = \lim_{x\to\pm\infty}\frac{f(x)}{x}, \qquad \beta = \lim_{x\to\pm\infty}\big(f(x) - \lambda x\big)$$

Η οριζόντια είναι η ειδική περίπτωση $\lambda = 0$.

Ρητές συναρτήσεις — γρήγορα

Βαθμός αριθμητή = βαθμός παρονομαστή ⇒ οριζόντια (λόγος μεγιστοβάθμιων)· αριθμητής κατά 1 μεγαλύτερος ⇒ πλάγια, που βρίσκεται με διαίρεση πολυωνύμων: $f(x) = \lambda x + \beta + \frac{\upsilon(x)}{\delta(x)}$.

Πειραματίσου

Κατακόρυφες: x = 3  ·  x→±∞: οριζόντια y = 2
Οι κόκκινες διακεκομμένες είναι οι ασύμπτωτες: η καμπύλη τις πλησιάζει όσο θέλουμε, χωρίς απαραίτητα να τις αγγίζει.

Ασκήσεις — 0/5 λυμένες

Άσκηση 1Βασική
Να βρείτε τις ασύμπτωτες της $f(x) = \dfrac{2x+1}{x-3}$.
Υπόδειξη: Παρονομαστής μηδενίζεται στο 3· στο άπειρο κράτα τους μεγιστοβάθμιους όρους.
Λύση: $\lim_{x\to3^\pm} f(x) = \pm\infty$ ⇒ $x = 3$. $\lim_{x\to\pm\infty}\frac{2x+1}{x-3} = 2$ ⇒ $y = 2$.
Άσκηση 2Βασική
Να βρείτε την πλάγια ασύμπτωτη $y = \lambda x + \beta$ της $f(x) = \dfrac{x^2 + 1}{x}$.
Υπόδειξη: $f(x) = x + \frac1x$.
Λύση: $f(x) = x + \frac1x$ και $\frac1x \to 0$ ⇒ πλάγια $y = x$ ($\lambda = 1$, $\beta = 0$). Και κατακόρυφη $x = 0$.
Άσκηση 3Μέτρια
Να βρείτε την πλάγια ασύμπτωτη της $f(x) = \dfrac{x^2 - 3x + 1}{x - 2}$.
Υπόδειξη: Διαίρεση: $x^2 - 3x + 1 = (x-2)(x-1) - 1$.
Λύση: $f(x) = x - 1 - \frac{1}{x-2}$, και $\frac{1}{x-2} \to 0$ ⇒ πλάγια ασύμπτωτη $y = x - 1$.
(Ή: $\lambda = \lim\frac{f(x)}{x} = 1$, $\beta = \lim(f(x) - x) = \lim\frac{-x+1}{x-2} = -1$.)
Άσκηση 4Μέτρια
Πόσες κατακόρυφες ασύμπτωτες έχει η $f(x) = \dfrac{x}{x^2 - 4}$ και ποια είναι η οριζόντια;
Υπόδειξη: $x^2 - 4 = 0 \Leftrightarrow x = \pm2$.
Λύση: Κατακόρυφες $x = -2$ και $x = 2$ (ο αριθμητής δεν μηδενίζεται εκεί). Βαθμός παρονομαστή μεγαλύτερος ⇒ $\lim_{x\to\pm\infty} f(x) = 0$, οριζόντια $y = 0$.
Άσκηση 5Απαιτητική
Η $f(x) = \sqrt{x^2 + 1}$ έχει δύο πλάγιες ασύμπτωτες. Να βρείτε την κλίση $\lambda$ καθεμιάς.
Υπόδειξη: $\frac{\sqrt{x^2+1}}{x} = \frac{|x|\sqrt{1 + 1/x^2}}{x}$ — προσοχή στο πρόσημο του $x$!
Λύση: Για $x \to +\infty$: $\lambda = 1$, $\beta = \lim(\sqrt{x^2+1} - x) = \lim\frac{1}{\sqrt{x^2+1}+x} = 0$ ⇒ $y = x$.
Για $x \to -\infty$: $|x| = -x$ ⇒ $\lambda = -1$, $\beta = 0$ ⇒ $y = -x$.
