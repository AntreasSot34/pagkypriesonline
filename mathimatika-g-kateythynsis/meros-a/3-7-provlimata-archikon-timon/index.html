Προβλήματα αρχικών τιμών

📘 Β΄ Τεύχος §3.7 · Δραστηριότητες σελ. 56 · Ενότητας σελ. 57

Θεωρία

Πρόβλημα αρχικών τιμών

Γνωρίζουμε την $f'$ (ή την $f''$) και αρχικές συνθήκες. Ολοκληρώνουμε και βρίσκουμε τη σταθερά από τη συνθήκη.

  • Με $f''$: δύο ολοκληρώσεις → δύο σταθερές → χρειάζονται δύο συνθήκες.
  • «Η ευθεία $\varepsilon$ εφάπτεται της $C_f$ στο $x_0$» ⇒ δύο πληροφορίες: $f(x_0)$ = τιμή της ευθείας, $f'(x_0)$ = κλίση της.
  • Κίνηση: $v = s'$, $a = v' = s''$.

Πειραματίσου

Όλες οι γκρι καμπύλες έχουν την ίδια παράγωγο — διαφέρουν μόνο κατά μια κατακόρυφη μετατόπιση. Βρες το c ώστε η μπλε καμπύλη να περνά από το σημείο (0, 2).

Ασκήσεις — 0/6 λυμένες

Άσκηση 1Βασική
Να βρείτε την $f$ με $f'(x) = e^x + 1$ και $f(0) = 3$. $\;f(x) =$
Υπόδειξη: $f(x) = e^x + x + c$.
Λύση: $f(0) = 1 + c = 3 \Rightarrow c = 2$: $f(x) = e^x + x + 2$.
Άσκηση 2Βασική
Να βρείτε την $f$, $x>0$, με $f'(x) = \frac1x$ και $f(1) = 2$. $\;f(x) =$
Υπόδειξη: $\ln 1 = 0$.
Λύση: $f(x) = \ln x + c$, $f(1) = c = 2$: $f(x) = \ln x + 2$.
Άσκηση 3Μέτρια
Για τη $f$ ισχύει $f''(x) = \text{συν}x$, $f'(0) = 1$ και $f(0) = 0$. $\;f(x) =$
Υπόδειξη: $f'(x) = \text{ημ}x + c_1$, μετά ξανά ολοκλήρωση.
Λύση: $f'(x) = \text{ημ}x + c_1$, $f'(0) = c_1 = 1$. $f(x) = -\text{συν}x + x + c_2$, $f(0) = -1 + c_2 = 0 \Rightarrow c_2 = 1$.
$f(x) = -\text{συν}x + x + 1$.
Άσκηση 4Μέτρια
Η κλίση της $C_f$ σε κάθε σημείο της είναι $2x\,e^{x^2}$ και η $C_f$ περνά από το $(0,1)$. $\;f(x) =$
Υπόδειξη: Αντικατάσταση $u = x^2$.
Λύση: $f(x) = e^{x^2} + c$, $f(0) = 1 + c = 1 \Rightarrow c = 0$: $f(x) = e^{x^2}$.
Άσκηση 5Μέτρια
Ένα σώμα κινείται με ταχύτητα $v(t) = 3t^2 - 2t$ και $s(1) = 4$. Να βρείτε το $s(2)$.
Υπόδειξη: $s(t) = t^3 - t^2 + c$.
Λύση: $s(1) = 1 - 1 + c = 4 \Rightarrow c = 4$. $s(2) = 8 - 4 + 4 = 8$.
Άσκηση 6Απαιτητική
Για τη $f$ ισχύει $f'(x) = 6x - 4$ και η ευθεία $y = 2x$ εφάπτεται της $C_f$ στο σημείο με $x = 1$. $\;f(x) =$
Υπόδειξη: Εφάπτεται στο $x = 1$ ⇒ $f(1) = 2\cdot1$. (Έλεγξε και ότι $f'(1) = 2$.)
Λύση: $f(x) = 3x^2 - 4x + c$. Επαφή στο $x = 1$: $f(1) = 2 \Rightarrow -1 + c = 2 \Rightarrow c = 3$ (και $f'(1) = 2$ ✓). $\;f(x) = 3x^2 - 4x + 3$.
