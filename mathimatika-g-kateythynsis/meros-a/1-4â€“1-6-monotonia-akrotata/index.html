1.4–1.6

Μονοτονία – Ακρότατα

📘 Α΄ Τεύχος §1.4–1.6 · Δραστηριότητες σελ. 36, 43, 58

Θεωρία

Μονοτονία με την παράγωγο

Αν η $f$ είναι συνεχής στο $\Delta$ και $f'(x) > 0$ στο εσωτερικό του ⇒ $f$ γνησίως αύξουσα στο $\Delta$· αν $f'(x) < 0$ ⇒ γνησίως φθίνουσα.

Ακρότατα

Fermat: αν η $f$ έχει τοπικό ακρότατο σε εσωτερικό σημείο $x_0$ και είναι παραγωγίσιμη εκεί, τότε $f'(x_0) = 0$.

Κριτήριο 1ης παραγώγου: $f'$: $+\to-$ τοπικό μέγιστο, $-\to+$ τοπικό ελάχιστο.

Κριτήριο 2ης παραγώγου: αν $f'(x_0) = 0$ και $f''(x_0) < 0$ ⇒ τοπικό μέγιστο· $f''(x_0) > 0$ ⇒ τοπικό ελάχιστο.

Ολικά ακρότατα σε $[\alpha,\beta]$: συγκρίνουμε τις τιμές στα κρίσιμα σημεία και στα άκρα.

Ανισότητες με μονοτονία

Για να δείξουμε $f(x) \ge g(x)$: θέτουμε $h = f - g$ και δείχνουμε ότι το ολικό ελάχιστο της $h$ είναι $\ge 0$. Π.χ. $e^x \ge 1 + x$ για κάθε $x$.

Πειραματίσου

Γραφική της f — πράσινο: η f ανεβαίνει, κόκκινο: κατεβαίνει
Γραφική της f′ — πάνω από τον άξονα ⇔ πράσινο
τοπ. μέγιστο στο x ≈ -1 · τοπ. ελάχιστο στο x ≈ 1
Δοκίμασε a = 1, b = 0, c = 0 (η f(x) = x³): η f′ αγγίζει τον άξονα αλλά δεν τον περνά.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Να βρείτε το ακρότατο της $f(x) = x\,e^{-x}$.
Υπόδειξη: $f'(x) = (1 - x)e^{-x}$. Το $e^{-x} > 0$ πάντα.
Λύση: $f'(x) = e^{-x} - xe^{-x} = (1-x)e^{-x}$: $+$ για $x<1$, $-$ για $x>1$ ⇒ ολικό μέγιστο $f(1) = \frac1e$.
Άσκηση 2Βασική
Να βρείτε το ακρότατο της $f(x) = x - \ln x$, $x > 0$.
Υπόδειξη: $f'(x) = 1 - \frac1x = \frac{x-1}{x}$.
Λύση: $f'(x) = \frac{x-1}{x}$: $-$ στο $(0,1)$, $+$ στο $(1,\infty)$ ⇒ ολικό ελάχιστο $f(1) = 1$.
Άσκηση 3Μέτρια
Να βρείτε τα ολικά ακρότατα της $f(x) = x^3 - 3x^2 - 9x + 1$ στο $[-2, 4]$.
Υπόδειξη: Κρίσιμα σημεία $-1$ και $3$. Σύγκρινε με $f(-2)$ και $f(4)$.
Λύση: $f'(x) = 3(x+1)(x-3)$. Τιμές: $f(-2) = -1$, $f(-1) = 6$, $f(3) = -26$, $f(4) = -19$.
Ολικό μέγιστο 6, ολικό ελάχιστο −26.
Άσκηση 4Μέτρια
Να βρείτε τα τοπικά ακρότατα της $f(x) = \dfrac{x^2}{x-1}$, $x \ne 1$.
Υπόδειξη: $f'(x) = \frac{x(x-2)}{(x-1)^2}$.
Λύση: $f'(x) = \frac{2x(x-1) - x^2}{(x-1)^2} = \frac{x(x-2)}{(x-1)^2}$. Πρόσημα: $+$ στο $(-\infty,0)$, $-$ στο $(0,1)$ και $(1,2)$, $+$ στο $(2,\infty)$.
Τοπ. μέγιστο $f(0) = 0$, τοπ. ελάχιστο $f(2) = 4$. (Το τοπικό μέγιστο είναι μικρότερο από το τοπικό ελάχιστο!)
Άσκηση 5Απαιτητική
Να βρείτε το ολικό ελάχιστο της $g(x) = e^x - x - 1$ και να συμπεράνετε ποια ανισότητα ισχύει.
Υπόδειξη: $g'(x) = e^x - 1$ μηδενίζεται στο $0$.
Λύση: $g'(x) = e^x - 1$: $-$ για $x<0$, $+$ για $x>0$ ⇒ ολικό ελάχιστο $g(0) = 0$.
Άρα $g(x) \ge 0$, δηλαδή $e^x \ge x + 1$ για κάθε $x \in \mathbb{R}$, με ισότητα μόνο για $x = 0$.
Άσκηση 6Απαιτητική
Να βρείτε το ολικό μέγιστο της $f(x) = \text{ημ}x + \text{συν}x$ στο $[0, 2\pi]$.
Υπόδειξη: $f'(x) = \text{συν}x - \text{ημ}x = 0 \Leftrightarrow \text{εφ}x = 1$.
Λύση: Κρίσιμα σημεία: $x = \frac\pi4$ και $x = \frac{5\pi}{4}$. $f(\frac\pi4) = \sqrt2$, $f(\frac{5\pi}4) = -\sqrt2$, $f(0) = f(2\pi) = 1$.
Ολικό μέγιστο $\sqrt2$ στο $\frac\pi4$ (και ολικό ελάχιστο $-\sqrt2$ στο $\frac{5\pi}{4}$).
Άσκηση 7Βασική
Η $f$ είναι γνησίως αύξουσα στο $\mathbb{R}$ και ισχύει $f(2\alpha - 1) < f(\alpha + 3)$. Να βρείτε για ποια $\alpha$ ισχύει: $\alpha < \kappa$, $\kappa = ;$
Υπόδειξη: Ορισμός: για γνησίως αύξουσα, $f(x_1) < f(x_2) \iff x_1 < x_2$.
Λύση: $f(2\alpha - 1) < f(\alpha + 3) \iff 2\alpha - 1 < \alpha + 3 \iff \alpha < 4$.
Άσκηση 8Βασική
Αν $f'(x_0) = 0$, τότε η $f$ έχει οπωσδήποτε τοπικό ακρότατο στο $x_0$.
Υπόδειξη: Σκέψου την $f(x) = x^3$ στο $0$.
Λύση: Λάθος: η $f(x) = x^3$ έχει $f'(0) = 0$ αλλά είναι γνησίως αύξουσα, χωρίς ακρότατο. Το θεώρημα Fermat δίνει μόνο αναγκαία συνθήκη.
Άσκηση 9Μέτρια
Θεωρούμε $g(x) = \ln x - x + 1$, $x > 0$. Να βρείτε το ολικό μέγιστο της $g$ και να συμπεράνετε την ανισότητα $\ln x \le x - 1$.
Υπόδειξη: $g'(x) = \frac1x - 1$.
Λύση: $g'(x) > 0$ στο $(0, 1)$, $< 0$ στο $(1, +\infty)$: ολικό μέγιστο $g(1) = 0$. Άρα $g(x) \le 0$, δηλαδή $\ln x \le x - 1$ για κάθε $x > 0$, με ισότητα μόνο για $x = 1$.
Άσκηση 10Απαιτητική
Πόσες πραγματικές ρίζες έχει η εξίσωση $x^3 - 3x + 1 = 0$; Δώστε και τις τιμές των τοπικών ακροτάτων της $f(x) = x^3 - 3x + 1$.
Υπόδειξη: $f'(x) = 3x^2 - 3$· μελέτησε μονοτονία και εφάρμοσε Bolzano σε κάθε διάστημα μονοτονίας.
Λύση: Η $f$ αυξάνει στο $(-\infty, -1]$, φθίνει στο $[-1, 1]$, αυξάνει στο $[1, +\infty)$, με $f(-1) = 3 > 0$, $f(1) = -1 < 0$. Επειδή $\lim_{-\infty} f = -\infty$, $\lim_{+\infty} f = +\infty$, σε κάθε διάστημα μονοτονίας υπάρχει ακριβώς μία ρίζα: $3$ ρίζες.

♾️ Γεννήτρια εξάσκησης — τοπικά ακρότατα

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε τα τοπικά ακρότατα της $f(x) = - x^{3} + 27x + 1$.
Λύση: $f'(x) = -3(x + 3)(x - 3)$, ρίζες $-3$ και $3$, πρόσημα $-,\,+,\,-$.
Τοπικό μέγιστο $f(3) = 55$, τοπικό ελάχιστο $f(-3) = -53$.
