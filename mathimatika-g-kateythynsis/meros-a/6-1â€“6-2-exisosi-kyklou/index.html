6.1–6.2

Εξίσωση κύκλου

📘 Γ΄ Τεύχος §6.1–6.2 · Δραστηριότητες σελ. 19

Θεωρία

Κύκλος με κέντρο $K(\alpha,\beta)$ και ακτίνα $R$

$$(x-\alpha)^2 + (y-\beta)^2 = R^2$$

Ειδικά, με κέντρο την αρχή: $x^2 + y^2 = R^2$.

Γενική μορφή

$$x^2 + y^2 + 2gx + 2fy + c = 0$$

Παριστάνει κύκλο αν και μόνον αν $g^2 + f^2 - c > 0$, με κέντρο $K(-g, -f)$ και ακτίνα $R = \sqrt{g^2 + f^2 - c}$.

Αν $= 0$: ένα σημείο· αν $< 0$: κανένα σημείο.

⚠ Πρώτα συντελεστές 1!

Αν η εξίσωση είναι $2x^2 + 2y^2 + \dots$, διαιρούμε πρώτα με το 2. Και οι συντελεστές των $x^2$, $y^2$ πρέπει να είναι ίσοι και να μην υπάρχει όρος $xy$.

Εισαγωγή: κωνικές τομές

Αν κόψουμε την επιφάνεια ενός διπλού κώνου με επίπεδο, παίρνουμε τις κωνικές τομές: τον κύκλο (επίπεδο κάθετο στον άξονα), την έλλειψη (πλάγιο επίπεδο που τέμνει όλες τις γενέτειρες), την παραβολή (επίπεδο παράλληλο σε μια γενέτειρα) και την υπερβολή (επίπεδο που τέμνει και τα δύο φύλλα). Όλες έχουν εξίσωση 2ου βαθμού ως προς $x$, $y$. Στο πρόγραμμα μελετάμε τον κύκλο (Ενότητα 6) και την παραβολή (Ενότητα 7).

Πειραματίσου

$(x -2)^2 +(y +1)^2 = 9$  ⇔  $x^2 +y^2 -4x +2y -4 = 0$
$g = -2, f = 1, c = -4$ ⇒ $g^2 +f^2 - c = 9 = R^2$

Ασκήσεις — 0/5 λυμένες

Άσκηση 1Βασική
Ο κύκλος με κέντρο $K(2, -3)$ και ακτίνα $4$ γράφεται $x^2 + y^2 + 2gx + 2fy + c = 0$. Να βρείτε τα $g, f, c$.
Υπόδειξη: Ανάπτυξε $(x-2)^2 + (y+3)^2 = 16$.
Λύση: $x^2 - 4x + 4 + y^2 + 6y + 9 = 16 \Rightarrow x^2 + y^2 - 4x + 6y - 3 = 0$. Άρα $g = -2$, $f = 3$, $c = -3$.
Άσκηση 2Βασική
Να βρείτε το κέντρο και την ακτίνα του κύκλου $x^2 + y^2 - 6x + 8y = 0$.
Υπόδειξη: $g = -3$, $f = 4$, $c = 0$.
Λύση: $K(-g,-f) = (3, -4)$, $R = \sqrt{9 + 16 - 0} = 5$. (Ο κύκλος περνά από την αρχή, αφού $c = 0$.)
Άσκηση 3Μέτρια
Να βρείτε τον κύκλο με διάμετρο το τμήμα με άκρα $A(1, 2)$ και $B(5, 6)$.
Υπόδειξη: Κέντρο = μέσο του $AB$, ακτίνα = $\frac{AB}{2}$.
Λύση: Κέντρο $K(3, 4)$, $R = \frac12\sqrt{16 + 16} = 2\sqrt2$, $R^2 = 8$. Εξίσωση: $(x-3)^2 + (y-4)^2 = 8$.
Άσκηση 4Μέτρια
Για ποιες τιμές του $k$ η εξίσωση $x^2 + y^2 + 4x - 2y + k = 0$ παριστάνει κύκλο; $\;k < \;?$
Υπόδειξη: $g^2 + f^2 - c > 0$ με $g = 2$, $f = -1$, $c = k$.
Λύση: $4 + 1 - k > 0 \Leftrightarrow k < 5$.
Άσκηση 5Απαιτητική
Να βρείτε τον κύκλο που διέρχεται από τα σημεία $O(0,0)$, $A(4,0)$ και $B(0,6)$.
Υπόδειξη: Αντικατάσταση στη γενική μορφή. Από το $O$: $c = 0$.
Λύση: $O$: $c = 0$. $A$: $16 + 8g = 0 \Rightarrow g = -2$. $B$: $36 + 12f = 0 \Rightarrow f = -3$.
Κέντρο $(2, 3)$, $R = \sqrt{4 + 9} = \sqrt{13}$. (Η γωνία $\hat{O} = 90°$, άρα το $AB$ είναι διάμετρος!)

♾️ Γεννήτρια — κέντρο & ακτίνα κύκλου

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε το κέντρο και την ακτίνα του κύκλου $x^2 + y^2 +10x -6y +30 = 0$.
Λύση: $g = 5,\ f = -3,\ c = 30$ ⇒ $K(-g, -f) = (-5, 3)$, $\;R = \sqrt{25 + 9 - 30} = \sqrt{4} = 2$.
