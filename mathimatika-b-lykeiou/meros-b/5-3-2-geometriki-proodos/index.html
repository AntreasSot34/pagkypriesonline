5.3.2

Γεωμετρική πρόοδος

📘 Βιβλίο §5.3.2 · Δραστηριότητες σελ. 183–184

Θεωρία

Ορισμός και γενικός όρος

Γεωμετρική πρόοδος (Γ.Π.): ακολουθία μη μηδενικών όρων όπου κάθε όρος προκύπτει από τον προηγούμενο πολλαπλασιάζοντας με τον ίδιο αριθμό $\lambda \ne 0$ (λόγος): $\alpha_{\nu+1} = \lambda\alpha_\nu$, δηλαδή $\frac{\alpha_{\nu+1}}{\alpha_\nu} = \lambda$.

$$\alpha_\nu = \alpha_1\lambda^{\nu - 1}$$

Γεωμετρικός μέσος

Οι μη μηδενικοί $\alpha, \beta, \gamma$ είναι διαδοχικοί όροι Γ.Π. $\iff \beta^2 = \alpha\gamma$.

Αθροίσματα

$$\Sigma_\nu = \alpha_1\frac{\lambda^\nu - 1}{\lambda - 1}\quad(\lambda \ne 1) \qquad \Sigma_\nu = \nu\alpha_1\quad(\lambda = 1)$$

Άθροισμα άπειρων όρων: αν $|\lambda| < 1$, οι όροι τείνουν στο $0$ και

$$\Sigma_\infty = \frac{\alpha_1}{1 - \lambda}$$

Για $|\lambda| \ge 1$ (και $\alpha_1 \ne 0$) δεν ορίζεται άθροισμα άπειρων όρων.

Πειραματίσου

Όροι: 2, 1, 0,5, 0,25, 0,13, 0,06, …
αν+1 = αν·0,5  ·  αν = α₁·λν−1 = 2·(0,5)ν−1  ·  Σ10 = α₁(λ10 − 1)/(λ − 1) = 4
|λ| < 1: οι όροι πλησιάζουν το 0 και το άθροισμα των άπειρων όρων είναι Σ∞ = α₁/(1 − λ) = 4.

Ασκήσεις — 0/11 λυμένες

Άσκηση 1Βασική
Σε Γ.Π. είναι $\alpha_1 = -1$ και $\lambda = 3$. Να βρείτε τους $\alpha_5$ και $\alpha_{10}$.
Υπόδειξη: $\alpha_\nu = \alpha_1\lambda^{\nu - 1}$.
Λύση: $\alpha_5 = -3^4 = -81$, $\ \alpha_{10} = -3^9 = -19683$.
Άσκηση 2Μέτρια
Γ.Π. έχει $\alpha_2 = 1$ και $\alpha_4 = 16$. Αν ο λόγος είναι θετικός, να βρείτε τα $\lambda$ και $\alpha_1$.
Υπόδειξη: $\frac{\alpha_4}{\alpha_2} = \lambda^2$.
Λύση: $\lambda^2 = 16 \Rightarrow \lambda = 4$ (θετικός), $\alpha_1 = \frac{\alpha_2}{\lambda} = \frac14$. (Με $\lambda = -4$ θα είχαμε $\alpha_1 = -\frac14$.)
Άσκηση 3Μέτρια
Να βρείτε το $\kappa$ ώστε οι $\kappa$, $\kappa + 4$, $18$ να είναι διαδοχικοί όροι Γ.Π.
Υπόδειξη: $(\kappa + 4)^2 = 18\kappa$.
Λύση: $\kappa^2 + 8\kappa + 16 = 18\kappa \Rightarrow \kappa^2 - 10\kappa + 16 = 0 \Rightarrow \kappa = 2$ ($2, 6, 18$) ή $\kappa = 8$ ($8, 12, 18$).
Άσκηση 4Μέτρια
Ποιον αριθμό πρέπει να προσθέσουμε σε καθέναν από τους $-1$, $1$, $7$ ώστε να γίνουν διαδοχικοί όροι Γ.Π.;
Υπόδειξη: $(1 + x)^2 = (x - 1)(x + 7)$.
Λύση: $1 + 2x + x^2 = x^2 + 6x - 7 \Rightarrow x = 2$. Όροι: $1, 3, 9$.
Άσκηση 5Βασική
Να υπολογίσετε το άθροισμα των $7$ πρώτων όρων της Γ.Π. $2, 6, 18, 54, \dots$
Υπόδειξη: $\alpha_1 = 2$, $\lambda = 3$.
Λύση: $\Sigma_7 = 2\cdot\frac{3^7 - 1}{3 - 1} = 3^7 - 1 = 2186$.
Άσκηση 6Μέτρια
Γ.Π. έχει $\lambda = 5$ και $\Sigma_4 = 468$. Να βρείτε τον $\alpha_1$.
Υπόδειξη: $\Sigma_4 = \alpha_1\frac{5^4 - 1}{4} = 156\alpha_1$.
Λύση: $156\alpha_1 = 468 \Rightarrow \alpha_1 = 3$.
Άσκηση 7Μέτρια
Να υπολογίσετε το άθροισμα $3 + 6 + 12 + 24 + \dots + 192$.
Υπόδειξη: $192 = 3\cdot 2^{\nu - 1}$.
Λύση: $2^{\nu - 1} = 64 \Rightarrow \nu = 7$. $\Sigma_7 = 3(2^7 - 1) = 381$.
Άσκηση 8Μέτρια
Να υπολογίσετε τα αθροίσματα των άπειρων όρων: (α) $\frac13 + \frac19 + \frac{1}{27} + \dots$, (β) $2 + \frac65 + \frac{18}{25} + \frac{54}{125} + \dots$
Υπόδειξη: (α) $\lambda = \frac13$, (β) $\lambda = \frac35$.
Λύση: (α) $\frac{1/3}{1 - 1/3} = \frac12$. (β) $\frac{2}{1 - 3/5} = 5$.
Άσκηση 9Μέτρια
Γ.Π. έχει άθροισμα άπειρων όρων διπλάσιο από τον πρώτο της όρο. Να βρείτε τον λόγο της.
Υπόδειξη: $\frac{\alpha_1}{1 - \lambda} = 2\alpha_1$.
Λύση: $\frac{1}{1 - \lambda} = 2 \Rightarrow \lambda = \frac12$ (και $|\lambda| < 1$ ✓).
Άσκηση 10Απαιτητική
Σε Γ.Π. με θετικό λόγο ισχύουν $\alpha_1 + \alpha_2 = 3$ και $\alpha_3 + \alpha_4 = 6$. Να βρείτε τον λόγο και το $\Sigma_7$.
Υπόδειξη: $\alpha_3 + \alpha_4 = \lambda^2(\alpha_1 + \alpha_2)$.
Λύση: $\lambda^2 = 2 \Rightarrow \lambda = \sqrt2$. $\alpha_1(1 + \sqrt2) = 3$. $\Sigma_7 = \alpha_1\frac{\lambda^7 - 1}{\lambda - 1} = \frac{3}{1 + \sqrt2}\cdot\frac{8\sqrt2 - 1}{\sqrt2 - 1} = 3(8\sqrt2 - 1) = 24\sqrt2 - 3$ (αφού $(\sqrt2 + 1)(\sqrt2 - 1) = 1$).
Άσκηση 11Βασική
Η σταθερή ακολουθία $2, 2, 2, 2, \dots$:
Υπόδειξη: Τι προσθέτουμε/με τι πολλαπλασιάζουμε κάθε φορά;
Λύση: $\alpha_{\nu+1} = \alpha_\nu + 0$ και $\alpha_{\nu+1} = 1\cdot\alpha_\nu$ (μη μηδενικοί όροι): και τα δύο.

♾️ Γεννήτρια — γεωμετρική πρόοδος

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Σε γεωμετρική πρόοδο είναι $\alpha_1 = 5$ και $\lambda = 3$. Να υπολογίσετε τον $\alpha_{6}$ και το άθροισμα $\Sigma_{6}$.
Λύση: $\alpha_{6} = \alpha_1\lambda^{5} = 5\cdot(3)^{5} = 1215$. $\Sigma_{6} = \alpha_1\frac{\lambda^{6} - 1}{\lambda - 1} = 5\cdot\frac{729 - 1}{2} = 1820$.
