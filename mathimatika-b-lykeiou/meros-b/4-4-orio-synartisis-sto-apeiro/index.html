4.4

Όριο συνάρτησης στο άπειρο

📘 Βιβλίο §4.4 · Δραστηριότητες σελ. 136, 157

Θεωρία

Το $\pm\infty$

$\lim_{x\to +\infty} f(x) = +\infty$ σημαίνει ότι, καθώς το $x$ αυξάνεται απεριόριστα, οι τιμές $f(x)$ ξεπερνούν οποιονδήποτε αριθμό. Ανάλογα για $-\infty$. Τα $\pm\infty$ δεν είναι πραγματικοί αριθμοί.

Βασικά όρια: $\lim_{x\to\pm\infty} c = c$, $\ \lim_{x\to +\infty} x = +\infty$, $\ \lim_{x\to -\infty} x = -\infty$, $\ \lim_{x\to\pm\infty}\frac1x = 0$.

$\lim_{x\to +\infty} x^\nu = +\infty$· $\ \lim_{x\to -\infty} x^\nu = +\infty$ αν $\nu$ άρτιος, $-\infty$ αν $\nu$ περιττός.

Πολυώνυμο στο άπειρο

Μετράει μόνο ο μεγιστοβάθμιος όρος:

$$\lim_{x\to\pm\infty}(\alpha_\nu x^\nu + \dots + \alpha_0) = \lim_{x\to\pm\infty}\alpha_\nu x^\nu$$

Π.χ. $\lim_{x\to -\infty}(-7x^3 + 5x^2 + 2x - 4) = \lim_{x\to -\infty}(-7x^3) = -7\cdot(-\infty) = +\infty$.

Πειραματίσου

P(x) = −2x3 + 4x² − 6x + 2  ·  γκρι: μόνο ο μεγιστοβάθμιος όρος −2x3
limx→+∞ P(x) = limx→+∞ −2x3 = −∞  ·  limx→−∞ P(x) = limx→−∞ −2x3 = +∞
Μεγάλωσε το παράθυρο: όσο απομακρυνόμαστε, οι δύο καμπύλες «συμπίπτουν» — στο ±∞ μετράει μόνο ο όρος με τον μεγαλύτερο βαθμό.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
$\lim_{x\to -\infty} x^4 = $
Υπόδειξη: Άρτια δύναμη αρνητικού αριθμού.
Λύση: Ο εκθέτης $4$ είναι άρτιος, άρα $x^4 > 0$ και μεγαλώνει απεριόριστα: $+\infty$.
Άσκηση 2Βασική
$\lim_{x\to -\infty} x^5 = $
Υπόδειξη: Περιττή δύναμη κρατά το πρόσημο.
Λύση: Περιττός εκθέτης: $x^5 < 0$ για $x < 0$, άρα $-\infty$.
Άσκηση 3Βασική
$\lim_{x\to -\infty}(5x^4 + 3x^2 - 4x - 3) = $
Υπόδειξη: Μεγιστοβάθμιος όρος: $5x^4$.
Λύση: $\lim_{x\to -\infty} 5x^4 = 5\cdot(+\infty) = +\infty$.
Άσκηση 4Βασική
$\lim_{x\to +\infty}(2x - 3x^4) = $
Υπόδειξη: Ο μεγιστοβάθμιος όρος είναι ο $-3x^4$ (παρόλο που είναι γραμμένος τελευταίος).
Λύση: $\lim_{x\to +\infty}(-3x^4) = -3\cdot(+\infty) = -\infty$.
Άσκηση 5Μέτρια
$\lim_{x\to -\infty}(-2x^2 + x - 7) = $
Υπόδειξη: $x^2 \to +\infty$, επί $-2$.
Λύση: $\lim_{x\to -\infty}(-2x^2) = -2\cdot(+\infty) = -\infty$.
Άσκηση 6Μέτρια
$\lim_{x\to +\infty}(-3x^3 + x^2 - 5x + 2) = $
Υπόδειξη: Μεγιστοβάθμιος: $-3x^3$.
Λύση: $\lim_{x\to +\infty}(-3x^3) = -\infty$.
Άσκηση 7Μέτρια
$\lim_{x\to -\infty}(-7x^3 + 5x^2 + 2x - 4) = $
Υπόδειξη: $x^3 \to -\infty$ για $x \to -\infty$.
Λύση: $\lim_{x\to -\infty}(-7x^3) = -7\cdot(-\infty) = +\infty$.
Άσκηση 8Βασική
Να υπολογίσετε: (α) $\lim_{x\to +\infty}\left(3 + \dfrac1x\right)$, (β) $\lim_{x\to -\infty}\dfrac{5}{x}$.
Υπόδειξη: $\frac1x \to 0$ στο $\pm\infty$.
Λύση: (α) $3 + 0 = 3$. (β) $5\cdot 0 = 0$.

♾️ Γεννήτρια — όρια στο άπειρο

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε το όριο $\lim_{x\to -\infty} (4x^{5} - 2x^{4} + 4)$.
Λύση: Στο άπειρο μετράει ο μεγιστοβάθμιος όρος: $\lim_{x\to -\infty} 4x^{5}$. Για $x \to -\infty$ είναι $x^{5} \to -\infty$, επί $4$: το όριο είναι $-\infty$.
