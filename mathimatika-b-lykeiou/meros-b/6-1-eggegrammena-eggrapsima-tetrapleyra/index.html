6.1

Εγγεγραμμένα – Εγγράψιμα τετράπλευρα

📘 Βιβλίο §6.1 · Δραστηριότητες σελ. 196

Θεωρία

Εγγεγραμμένο τετράπλευρο — ιδιότητες

Αν οι κορυφές του $AB\Gamma\Delta$ είναι σημεία κύκλου:

  1. Οι απέναντι γωνίες είναι παραπληρωματικές: $\hat A + \hat\Gamma = \hat B + \hat\Delta = 180^\circ$.
  2. Κάθε εξωτερική γωνία ισούται με την απέναντι εσωτερική.
  3. Κάθε πλευρά φαίνεται από τις δύο απέναντι κορυφές υπό ίσες γωνίες (π.χ. $\angle BA\Gamma = \angle B\Delta\Gamma$, εγγεγραμμένες στο ίδιο τόξο).

Κριτήρια — πότε ένα τετράπλευρο είναι εγγράψιμο

Ένα τετράπλευρο είναι εγγράψιμο (περνά κύκλος από τις κορυφές του) αν ισχύει ένα από τα:

  • οι μεσοκάθετοι των πλευρών του περνούν από το ίδιο σημείο·
  • δύο απέναντι γωνίες του είναι παραπληρωματικές·
  • μια εξωτερική γωνία ισούται με την απέναντι εσωτερική·
  • μια πλευρά φαίνεται από τις απέναντι κορυφές υπό ίσες γωνίες.

Παραδείγματα

Ορθογώνιο, τετράγωνο, ισοσκελές τραπέζιο: εγγράψιμα. Παραλληλόγραμμο εγγράψιμο ⇔ ορθογώνιο. Ρόμβος εγγράψιμος ⇔ τετράγωνο.

Πειραματίσου

Α + Γ = 87,5° + 92,5° = 180°  ·  Β + Δ = 75° + 105° = 180°
Όπως κι αν μετακινήσεις τις κορυφές πάνω στον κύκλο, οι απέναντι γωνίες είναι παραπληρωματικές.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Σε εγγράψιμο τετράπλευρο $AB\Gamma\Delta$ είναι $\hat A = 120^\circ$ και η εξωτερική γωνία στο $B$ είναι $80^\circ$. Να βρείτε τις γωνίες του.
Υπόδειξη: $\hat B = 180^\circ - 80^\circ$. Μετά απέναντι γωνίες παραπληρωματικές.
Λύση: $\hat B = 100^\circ$, $\hat\Gamma = 180^\circ - 120^\circ = 60^\circ$, $\hat\Delta = 180^\circ - 100^\circ = 80^\circ$ (ίση με την εξωτερική στο $B$ ✓).
Άσκηση 2Μέτρια
Το $AB\Gamma\Delta$ είναι εγγεγραμμένο σε κύκλο ακτίνας $2$ cm με $\angle BA\Delta = \frac23x$ και $\angle B\Gamma\Delta = x - 45^\circ$. Να βρείτε το $x$ και το μήκος της διαγωνίου $B\Delta$.
Υπόδειξη: Απέναντι γωνίες: άθροισμα $180^\circ$. Η $\hat A$ τότε είναι ορθή.
Λύση: $\frac23x + x - 45 = 180 \Rightarrow \frac53x = 225 \Rightarrow x = 135$. Τότε $\hat A = 90^\circ$, άρα η $B\Delta$ είναι διάμετρος: $B\Delta = 4$ cm.
Άσκηση 3Βασική
Το $AB\Gamma\Delta$ είναι εγγεγραμμένο σε κύκλο και $\angle BA\Gamma = 35^\circ$. Να βρείτε τη γωνία $\angle B\Delta\Gamma$.
Υπόδειξη: Εγγεγραμμένες γωνίες στο ίδιο τόξο $B\Gamma$.
Λύση: Η πλευρά $B\Gamma$ φαίνεται από τα $A$ και $\Delta$ υπό ίσες γωνίες: $35^\circ$.
Άσκηση 4Βασική
Ποιο από τα πιο κάτω τετράπλευρα (με γωνίες $\hat A, \hat B, \hat\Gamma, \hat\Delta$ στη σειρά) είναι εγγράψιμο;
Υπόδειξη: Έλεγξε $\hat A + \hat\Gamma$.
Λύση: $70^\circ + 110^\circ = 180^\circ$ (και $95^\circ + 85^\circ = 180^\circ$). Στα άλλα $\hat A + \hat\Gamma \ne 180^\circ$.
Άσκηση 5Βασική
Σε εγγεγραμμένο τετράπλευρο $AB\Gamma\Delta$ η εξωτερική γωνία στην κορυφή $\Gamma$ είναι $75^\circ$. Να βρείτε τις $\hat A$ και $\hat\Gamma$.
Υπόδειξη: Εξωτερική = απέναντι εσωτερική.
Λύση: $\hat A = 75^\circ$, $\hat\Gamma = 180^\circ - 75^\circ = 105^\circ$.
Άσκηση 6Μέτρια
Κάθε ρόμβος εγγεγραμμένος σε κύκλο είναι τετράγωνο. Γιατί;
Υπόδειξη: Στον ρόμβο $\hat A = \hat\Gamma$.
Λύση: Ρόμβος: $\hat A = \hat\Gamma$. Εγγεγραμμένος: $\hat A + \hat\Gamma = 180^\circ$. Άρα $\hat A = \hat\Gamma = 90^\circ$ (ομοίως $\hat B = \hat\Delta = 90^\circ$): τετράγωνο.
Άσκηση 7Βασική
Κάθε ισοσκελές τραπέζιο είναι εγγράψιμο σε κύκλο.
Υπόδειξη: Οι γωνίες της βάσης είναι ίσες, και οι γωνίες που πρόσκεινται σε μία μη παράλληλη πλευρά είναι παραπληρωματικές.
Λύση: Σε ισοσκελές τραπέζιο $AB\Gamma\Delta$ ($AB \parallel \Gamma\Delta$): $\hat A = \hat B$ και $\hat A + \hat\Delta = 180^\circ$, άρα $\hat B + \hat\Delta = 180^\circ$: απέναντι γωνίες παραπληρωματικές — εγγράψιμο.
Άσκηση 8Μέτρια
Ένα παραλληλόγραμμο είναι εγγράψιμο σε κύκλο:
Υπόδειξη: Στο παραλληλόγραμμο οι απέναντι γωνίες είναι ίσες.
Λύση: Πρέπει $\hat A = \hat\Gamma$ και $\hat A + \hat\Gamma = 180^\circ$, άρα όλες οι γωνίες ορθές: ορθογώνιο.

♾️ Γεννήτρια — εγγεγραμμένο τετράπλευρο

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Το τετράπλευρο $AB\Gamma\Delta$ είναι εγγεγραμμένο σε κύκλο με $\hat A = 50^\circ$ και $\hat B = 108^\circ$. Να υπολογίσετε τις γωνίες $\hat\Gamma$ και $\hat\Delta$.
Λύση: Στο εγγεγραμμένο τετράπλευρο οι απέναντι γωνίες είναι παραπληρωματικές: $\hat\Gamma = 180^\circ - 50^\circ = 130^\circ$, $\hat\Delta = 180^\circ - 108^\circ = 72^\circ$.
