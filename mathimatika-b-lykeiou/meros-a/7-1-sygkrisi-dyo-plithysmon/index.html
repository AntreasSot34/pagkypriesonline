7.1

Σύγκριση δύο πληθυσμών

📘 Βιβλίο §7.1 · Δραστηριότητες σελ. 233

Θεωρία

Μέση τιμή και τυπική απόκλιση

$$\bar x = \frac{x_1 + x_2 + \dots + x_\nu}{\nu} \qquad s = \sqrt{\frac{(x_1 - \bar x)^2 + \dots + (x_\nu - \bar x)^2}{\nu}}$$

Η μέση τιμή δείχνει το «κέντρο», η τυπική απόκλιση πόσο διασκορπισμένες είναι οι τιμές γύρω της. Μικρότερη $s$ ⇒ πιο σταθερά/ομοιόμορφα αποτελέσματα.

Συντελεστής μεταβολής (μεταβλητότητας)

$$CV = \frac{s}{|\bar x|}\cdot 100\%$$

Χρησιμοποιείται για σύγκριση της διασποράς ομάδων με πολύ διαφορετικές μέσες τιμές ή διαφορετικές μονάδες. Το δείγμα θεωρείται ομοιογενές όταν $CV < 10\%$. Μικρότερος CV ⇒ μεγαλύτερη ομοιογένεια.

Πώς συγκρίνουμε

Πρώτα τις μέσες τιμές (ποιος «πετυχαίνει» περισσότερο ή λιγότερο, ανάλογα με το πρόβλημα), μετά τη διασπορά (ποιος είναι πιο σταθερός). Π.χ. σε αγώνα δρόμου μικρότερος χρόνος είναι καλύτερος.

Πειραματίσου

νx̄sCV = s/|x̄|ομοιογενές (CV < 10%);

Οι κόκκινες γραμμές δείχνουν τις μέσες τιμές. Μικρότερη τυπική απόκλιση ⇒ μικρότερη διασπορά. Για δείγματα με πολύ διαφορετικές μέσες τιμές ή μονάδες συγκρίνουμε τον συντελεστή μεταβολής CV.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Μέτρια
Οι ώρες λειτουργίας $9$ λαμπτήρων του είδους Α είναι: $140, 150, 160, 130, 150, 170, 150, 140, 160$. Να υπολογίσετε τη μέση τιμή και την τυπική απόκλιση (2 δεκαδικά).
Υπόδειξη: Αποκλίσεις από το $150$: $-10, 0, 10, -20, 0, 20, 0, -10, 10$.
Λύση: $\bar x = \frac{1350}{9} = 150$. $s = \sqrt{\frac{100 + 0 + 100 + 400 + 0 + 400 + 0 + 100 + 100}{9}} = \sqrt{\frac{1200}{9}} \approx 11{,}55$ ώρες.
Άσκηση 2Βασική
Δύο είδη λαμπτήρων έχουν την ίδια μέση διάρκεια $150$ ώρες, με τυπικές αποκλίσεις $s_A = 11{,}55$ και $s_B = 44{,}47$. Ποιο είδος είναι προτιμότερο;
Υπόδειξη: Ίδια μέση τιμή — κοίτα τη σταθερότητα.
Λύση: Με ίδιο μέσο όρο, προτιμούμε το είδος με τις πιο σταθερές διάρκειες: το Α ($s_A < s_B$).
Άσκηση 3Βασική
Σε δύο δείγματα δίνονται $\bar x_A = 50$, $s_A = 4$, $\bar x_B = 70$, $s_B = 6$. Να υπολογίσετε τους συντελεστές μεταβολής (σε %, 2 δεκαδικά).
Υπόδειξη: $CV = \frac{s}{\bar x}\cdot 100\%$.
Λύση: $CV_A = \frac{4}{50} = 8\%$, $\ CV_B = \frac{6}{70} \approx 8{,}57\%$. Μεγαλύτερη ομοιογένεια έχει το Α (και τα δύο είναι ομοιογενή).
Άσκηση 4Μέτρια
Τέσσερα τμήματα έχουν (μέση τιμή, τυπική απόκλιση): Β1 $(14{,}1;\ 1{,}5)$, Β2 $(14{,}2;\ 2{,}3)$, Β3 $(12{,}9;\ 1{,}2)$, Β4 $(13{,}7;\ 2{,}7)$. Ποιο τμήμα παρουσιάζει τη μεγαλύτερη ομοιογένεια;
Υπόδειξη: Υπολόγισε τους CV.
Λύση: $CV$: Β1 $\approx 10{,}6\%$, Β2 $\approx 16{,}2\%$, Β3 $\approx 9{,}3\%$, Β4 $\approx 19{,}7\%$. Μικρότερος ο CV του Β3 (και μόνο αυτό είναι ομοιογενές, $< 10\%$).
Άσκηση 5Βασική
Σε δέκα αγώνες $100$ m ο αθλητής Α έχει μέσο χρόνο $10{,}5$ s ($s = 0{,}055$) και ο Β $10{,}2$ s ($s = 0{,}2$). Ποιος είναι ο καλύτερος αθλητής;
Υπόδειξη: Στο τρέξιμο μικρότερος χρόνος = καλύτερη επίδοση.
Λύση: Ο Β τρέχει κατά μέσο όρο $0{,}3$ s γρηγορότερα — διαφορά μεγαλύτερη από τις τυπικές αποκλίσεις τους. Καλύτερος ο Β, παρότι ο Α είναι λίγο πιο σταθερός.
Άσκηση 6Μέτρια
Τα ύψη μιας ομάδας μαθητών έχουν $\bar x = 170$ cm, $s = 8{,}5$ cm και τα βάρη τους $\bar x = 65$ kg, $s = 9{,}1$ kg. Να υπολογίσετε τους δύο συντελεστές μεταβολής (%).
Υπόδειξη: Διαφορετικές μονάδες: συγκρίνουμε μόνο με τον CV.
Λύση: $CV_{ύψ} = \frac{8{,}5}{170} = 5\%$, $\ CV_{βάρ} = \frac{9{,}1}{65} = 14\%$. Τα ύψη είναι ομοιογενή, τα βάρη όχι.
Άσκηση 7Μέτρια
Να υπολογίσετε τη μέση τιμή και την τυπική απόκλιση των τιμών $2, 4, 4, 4, 5, 5, 7, 9$.
Υπόδειξη: Άθροισμα τετραγώνων αποκλίσεων: $9 + 1 + 1 + 1 + 0 + 0 + 4 + 16$.
Λύση: $\bar x = \frac{40}{8} = 5$. $s^2 = \frac{32}{8} = 4 \Rightarrow s = 2$.
Άσκηση 8Μέτρια
Οι τιμές ενός προϊόντος σε δέκα καταστήματα έχουν $\bar x = 8{,}1$ € και $s = 0{,}677$ €. Να υπολογίσετε τον συντελεστή μεταβολής (%, 2 δεκαδικά).
Υπόδειξη: $\frac{0{,}677}{8{,}1}$.
Λύση: $CV = \frac{0{,}677}{8{,}1} \approx 0{,}0836 = 8{,}36\% < 10\%$: οι τιμές είναι ομοιογενείς.

♾️ Γεννήτρια — συντελεστής μεταβολής

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Για δύο δείγματα Α και Β δίνονται $\bar x_A = 73$, $s_A = 12$ και $\bar x_B = 24$, $s_B = 14$. Να υπολογίσετε τους συντελεστές μεταβολής (σε %, 2 δεκαδικά).
Λύση: $CV_A = \frac{12}{73} \approx 16{,}44\%$, $\ CV_B = \frac{14}{24} \approx 58{,}33\%$. Πιο ομοιογενές είναι το Α (μικρότερος CV).
