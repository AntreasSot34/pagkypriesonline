2.6

Πράξεις συναρτήσεων

📘 Βιβλίο §2.6 · Δραστηριότητες σελ. 56

Θεωρία

Άθροισμα, διαφορά, γινόμενο, πηλίκο

Αν $f: A \to \mathbb{R}$ και $g: B \to \mathbb{R}$ με $A \cap B \ne \varnothing$:

$$(f \pm g)(x) = f(x) \pm g(x) \qquad (f\cdot g)(x) = f(x)\cdot g(x), \quad x \in A \cap B$$ $$\left(\frac fg\right)(x) = \frac{f(x)}{g(x)}, \quad x \in A \cap B \ \text{ με } \ g(x) \ne 0$$

Προσοχή

  • Αν $A \cap B = \varnothing$, οι πράξεις δεν ορίζονται.
  • Το πεδίο ορισμού το βρίσκουμε από τις αρχικές συναρτήσεις, όχι από τον απλοποιημένο τύπο. Π.χ. $f(x) = \sqrt x$, $g(x) = \frac{1}{\sqrt x}$: το $f\cdot g = 1$ ορίζεται μόνο για $x > 0$.

Πειραματίσου

(f + g)(x) = (x^2) + (x - 1)  ·  γκρι: f, μωβ: g
Πεδίο ορισμού: A ∩ B — ορίζεται μόνο όπου ορίζονται και οι δύο συναρτήσεις.
Δοκίμασε f(x) = √x και g(x) = √(1 − x): το f + g ορίζεται μόνο στο [0, 1].

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Αν $f(x) = 2x - 5$ και $g(x) = x + 3$, να γράψετε τις $f + g$ και $f - g$ στη μορφή $\alpha x + \beta$.
Υπόδειξη: Προσοχή στην παρένθεση: $(2x - 5) - (x + 3)$.
Λύση: $(f + g)(x) = 3x - 2$, $\ (f - g)(x) = 2x - 5 - x - 3 = x - 8$, και οι δύο με πεδίο ορισμού $\mathbb{R}$.
Άσκηση 2Μέτρια
Ορίζεται το άθροισμα των $f(x) = \sqrt x$ και $g(x) = \sqrt{-1 - x}$;
Υπόδειξη: Βρες τα δύο πεδία ορισμού.
Λύση: $A = [0, +\infty)$, $\ B$: $-1 - x \ge 0 \iff x \le -1$, $B = (-\infty, -1]$. Η τομή είναι κενή: δεν ορίζεται.
Άσκηση 3Βασική
Αν $f(x) = x^2$ και $g(x) = x - 1$, να υπολογίσετε τα $(f\cdot g)(2)$ και $\left(\frac fg\right)(3)$.
Υπόδειξη: $(f\cdot g)(2) = f(2)\cdot g(2)$.
Λύση: $(f\cdot g)(2) = 4\cdot 1 = 4$, $\ \left(\frac fg\right)(3) = \frac{9}{2}$.
Άσκηση 4Μέτρια
Αν $f(x) = \sqrt{x - 1}$ και $g(x) = \sqrt{5 - x}$, το πεδίο ορισμού της $f + g$ είναι $[\kappa, \lambda]$. Να βρείτε τα $\kappa$, $\lambda$.
Υπόδειξη: $A \cap B$.
Λύση: $A = [1, +\infty)$, $B = (-\infty, 5]$, $A \cap B = [1, 5]$.
Άσκηση 5Μέτρια
Αν $f(x) = \frac1x$ και $g(x) = x - 2$, το πεδίο ορισμού της $\frac fg$ είναι:
Υπόδειξη: $x \in A \cap B$ και $g(x) \ne 0$.
Λύση: $A \cap B = \mathbb{R} - \{0\}$ και $g(x) \ne 0 \iff x \ne 2$. Άρα $\mathbb{R} - \{0, 2\}$.
Άσκηση 6Απαιτητική
Δίνονται $f(x) = \dfrac{4x}{x^2 - 25}$ και $g(x) = 1 - \dfrac{7}{x + 2}$. Το πεδίο ορισμού της $\frac fg$ είναι:
Υπόδειξη: $g(x) = \frac{x - 5}{x + 2}$. Πότε μηδενίζεται;
Λύση: $A = \mathbb{R} - \{\pm 5\}$, $B = \mathbb{R} - \{-2\}$. $g(x) = 0 \iff x = 5$ (ήδη εξαιρείται). Άρα $\mathbb{R} - \{-5, -2, 5\}$, και εκεί $\left(\frac fg\right)(x) = \frac{4x(x + 2)}{(x - 5)^2(x + 5)}$.
Άσκηση 7Μέτρια
Αν $f(x) = 2x + 4$, $x \in [0, 3]$ και $g(x) = 3x$, $x \in [4, 7]$, τότε η $f + g$:
Υπόδειξη: Τομή πεδίων ορισμού.
Λύση: $[0, 3] \cap [4, 7] = \varnothing$, άρα ούτε η $f + g$ ούτε η $\frac fg$ ορίζονται.
Άσκηση 8Βασική
Οι συναρτήσεις $f - g$ και $f\cdot g$ έχουν πάντα το ίδιο πεδίο ορισμού.
Υπόδειξη: Ποιο είναι το πεδίο ορισμού καθεμιάς;
Λύση: Και οι δύο ορίζονται στο $A \cap B$. (Το πηλίκο είναι αυτό που μπορεί να έχει μικρότερο πεδίο ορισμού.)
