2.7

Συναρτήσεις 1–1

📘 Βιβλίο §2.7 · Δραστηριότητες σελ. 60–61

Θεωρία

Ορισμός

Μια συνάρτηση $f: A \to \mathbb{R}$ λέγεται 1–1 (ένα προς ένα) όταν διαφορετικά $x$ δίνουν διαφορετικές τιμές:

$$x_1 \ne x_2 \Rightarrow f(x_1) \ne f(x_2) \qquad\text{ισοδύναμα}\qquad f(x_1) = f(x_2) \Rightarrow x_1 = x_2$$

Πώς το ελέγχουμε

  • Αλγεβρικά: υποθέτουμε $f(x_1) = f(x_2)$ και δείχνουμε $x_1 = x_2$. Π.χ. $3x_1 - 2 = 3x_2 - 2 \Rightarrow x_1 = x_2$.
  • Γραφικά: κάθε οριζόντια ευθεία τέμνει τη γραφική παράσταση σε το πολύ ένα σημείο.
  • Αντιπαράδειγμα για να δείξουμε ότι δεν είναι 1–1: δύο διαφορετικά $x$ με ίδια τιμή, π.χ. $f(x) = x^2$: $f(-1) = f(1)$.
  • Κάθε γνησίως μονότονη συνάρτηση είναι 1–1.

Το πεδίο ορισμού μετράει

Η $f(x) = x^2$ δεν είναι 1–1 στο $\mathbb{R}$, είναι όμως 1–1 στο $[0, +\infty)$ (εκεί είναι γνησίως αύξουσα).

Πειραματίσου

Στο διάστημα [−5, 5] η ευθεία y = 1 έχει 1 κοινό σημείο με τη γραφική παράσταση.
Κάθε οριζόντια ευθεία τέμνει τη γραφική παράσταση σε το πολύ ένα σημείο ⇒ η συνάρτηση είναι 1–1.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Η συνάρτηση $f(x) = 3x - 2$, $x \in \mathbb{R}$, είναι 1–1;
Υπόδειξη: Υπόθεσε $f(x_1) = f(x_2)$.
Λύση: $3x_1 - 2 = 3x_2 - 2 \Rightarrow 3x_1 = 3x_2 \Rightarrow x_1 = x_2$. Είναι 1–1.
Άσκηση 2Βασική
Η συνάρτηση $g(x) = x^2 + 2$, $x \in \mathbb{R}$, είναι 1–1;
Υπόδειξη: Δοκίμασε αντίθετους αριθμούς.
Λύση: $g(-1) = g(1) = 3$ με $-1 \ne 1$: δεν είναι 1–1.
Άσκηση 3Βασική
Η $f(x) = x^2$ με πεδίο ορισμού το $(0, 3]$ είναι 1–1.
Υπόδειξη: Στο $(0, 3]$ υπάρχουν αντίθετοι αριθμοί;
Λύση: Για $0 < x_1 < x_2$ ισχύει $x_1^2 < x_2^2$: γνησίως αύξουσα, άρα 1–1.
Άσκηση 4Βασική
Η $f(x) = x^2$ με πεδίο ορισμού το $(-3, 3]$ είναι 1–1.
Υπόδειξη: Τώρα το διάστημα περιέχει αντίθετους αριθμούς.
Λύση: $f(-2) = f(2) = 4$, άρα δεν είναι 1–1.
Άσκηση 5Μέτρια
Η συνάρτηση $f(x) = x^3 - x$, $x \in \mathbb{R}$:
Υπόδειξη: Βρες τις ρίζες της $f(x) = 0$.
Λύση: $x^3 - x = x(x - 1)(x + 1)$: $f(-1) = f(0) = f(1) = 0$. Τρία διαφορετικά $x$ με την ίδια τιμή — δεν είναι 1–1.
Άσκηση 6Μέτρια
Η $f(x) = \dfrac{2x + 1}{x - 3}$, $x \ne 3$, είναι 1–1. Να βρείτε το μοναδικό $x$ για το οποίο $f(x) = 3$.
Υπόδειξη: $2x + 1 = 3(x - 3)$.
Λύση: $2x + 1 = 3x - 9 \Rightarrow x = 10$ (και $10 \ne 3$).
Άσκηση 7Μέτρια
Η $f$ είναι 1–1 και ισχύει $f(2\alpha - 1) = f(5)$. Να βρείτε το $\alpha$.
Υπόδειξη: $f(x_1) = f(x_2) \Rightarrow x_1 = x_2$.
Λύση: Αφού η $f$ είναι 1–1: $2\alpha - 1 = 5 \Rightarrow \alpha = 3$.
Άσκηση 8Απαιτητική
Ποια από τις πιο κάτω συναρτήσεις δεν είναι 1–1;
Υπόδειξη: Η συνάρτηση $\text{ημ}x$ είναι περιοδική.
Λύση: $\text{ημ}0 = \text{ημ}\pi = 0$: δεν είναι 1–1. Οι $\frac1x$, $x^3$, $2x + 5$ περνούν το κριτήριο οριζόντιας ευθείας.

♾️ Γεννήτρια — συναρτήσεις 1–1

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Ποια από τις πιο κάτω συναρτήσεις είναι 1–1;
Λύση: Η f(x) = x², x ≥ 0 είναι 1–1: από $f(x_1) = f(x_2)$ προκύπτει $x_1 = x_2$ (κάθε οριζόντια ευθεία τέμνει τη γραφική της παράσταση το πολύ σε ένα σημείο). Οι άλλες δεν είναι: f(x) = ημx (ημ0 = ημπ = 0)· f(x) = (x − 1)² (f(0) = f(2) = 1)· f(x) = x⁴ (f(−1) = f(1) = 1).
