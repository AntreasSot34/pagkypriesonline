3.4

Δομές επανάληψης στη C++: βρόχοι for, while και do…while

📘 Βιβλίο Γ΄ Λυκείου: Γ7.1 §5 Δομή Επανάληψης (σ. 80–84)

Πώς κάνουμε τον υπολογιστή να εκτελεί τις ίδιες εντολές πολλές φορές με for, while και do…while — και πώς βρίσκουμε τι θα εμφανίσει ένας βρόχος χωρίς να τον τρέξουμε;

Θεωρία

Δομές επανάληψης ή βρόχοι (loops) ονομάζονται τα μέρη του κώδικα που εκτελούνται περισσότερες από μία φορές, όσο μια λογική συνθήκη είναι αληθής. Όταν η συνθήκη γίνει ψευδής, ο βρόχος τελειώνει και η εκτέλεση συνεχίζει με την επόμενη εντολή. Η C++ έχει τρεις βρόχους: for, while και do…while.

Ο βρόχος for

Τον χρησιμοποιούμε όταν γνωρίζουμε από πριν τον αριθμό των επαναλήψεων. Μια μεταβλητή-μετρητής παίρνει αρχική τιμή (μόνο την πρώτη φορά), ελέγχεται η συνθήκη πριν από κάθε επανάληψη και στο τέλος κάθε επανάληψης γίνεται η μεταβολή του μετρητή. Ο μετρητής μπορεί να είναι ακέραιος, δεκαδικός ή χαρακτήρας και μπορεί να δηλωθεί και να αρχικοποιηθεί μέσα στον βρόχο (π.χ. for (char c = 'a'; c <= 'e'; c++)).

for (μετρητής = αρχική τιμή; συνθήκη; μεταβολή μετρητή) {    εντολές;}
Παράδειγμα 1.8 — άθροισμα 1 + 2 + … + N
1int N, sum = 0;2cin >> N;3for (int i = 1; i <= N; i++)4    sum += i;5cout << sum;

Ο βρόχος while

Τον χρησιμοποιούμε όταν δεν ξέρουμε τον ακριβή αριθμό επαναλήψεων. Η συνθήκη ελέγχεται στην αρχή· αν είναι ψευδής από την αρχή, το σώμα δεν εκτελείται ούτε μία φορά.

Παράδειγμα 1.10 — ΕΚΠ δύο αριθμών
1int a, b, ekp;2cin >> a >> b;3ekp = a;4while (ekp % a != 0 || ekp % b != 0)5    ekp++;6cout << ekp;

Ο βρόχος do…while

Η συνθήκη ελέγχεται στο τέλος, άρα το σώμα εκτελείται τουλάχιστον μία φορά. Προσοχή στο ; μετά το while (συνθήκη).

do {    εντολές;} while (συνθήκη);

Ίχνος (πίνακας τιμών): while ή do;

Και τα δύο τμήματα υπολογίζουν το άθροισμα των περιττών 1 έως 11:

sum = 0;arithmos = 1;while (arithmos <= 11) {    sum = sum + arithmos;    arithmos = arithmos + 2;}
sum = 0;arithmos = 1;do {    sum = sum + arithmos;    arithmos = arithmos + 2;} while (arithmos <= 11);

Ένθετοι βρόχοι

Για κάθε επανάληψη του εξωτερικού βρόχου, ο εσωτερικός εκτελεί όλες τις δικές του επαναλήψεις. Ο πίνακας της προπαίδειας 9×9 εκτελεί την εντολή του εσωτερικού βρόχου $9 \cdot 9 = 81$ φορές:

Παράδειγμα 1.9
1for (i = 1; i <= 9; i++) {2    for (j = 1; j <= 9; j++) {3        cout << i * j << " ";4    }5    cout << endl;6}

Ποιον βρόχο να διαλέξω;

for: γνωστός αριθμός επαναλήψεων (μετρητής). while: επανάληψη «όσο ισχύει κάτι», ίσως καμία φορά (π.χ. «μέχρι να δοθεί 0»). do…while: τουλάχιστον μία φορά — ιδανικό για έλεγχο εγκυρότητας εισόδου:

do {    cin >> x;} while (x < 1 || x > 100);

Κάθε βρόχος μπορεί να ξαναγραφτεί με τους άλλους δύο (θέμα που ζητείται συχνά).

Συχνά λάθη στις Παγκύπριες

Ατέρμων βρόχος: ξεχνάμε να αλλάξουμε τη μεταβλητή της συνθήκης μέσα στο while · ; αμέσως μετά το for (…) ή το while (…) (κενό σώμα!) · λάθος κατά ένα (< αντί <=) · ξεχνάμε την αρχικοποίηση του αθροιστή (sum = 0) ή του γινομένου (p = 1) · ξεχνάμε το ; στο τέλος του do…while.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Τι θα εμφανίσει το πρόγραμμα;
for (int i = 2; i < 10; i += 3)    cout << i << " ";
Υπόδειξη: Ξεκίνα από i = 2 και πρόσθετε 3 όσο i < 10.
Λύση: i = 2, 5, 8 (το 11 δεν ικανοποιεί τη συνθήκη).
Οθόνη (έξοδος)
2 5 8
Άσκηση 2Βασική
Πόσες φορές εκτελείται το σώμα του βρόχου for (int k = 10; k > 0; k -= 2);
Υπόδειξη: Γράψε τις τιμές του k.
Λύση: k = 10, 8, 6, 4, 2 → 5 φορές (για k = 0 η συνθήκη είναι ψευδής).
Άσκηση 3Βασική
Ο βρόχος do…while εκτελεί το σώμα του τουλάχιστον μία φορά, ακόμη κι αν η συνθήκη είναι ψευδής από την αρχή.
Υπόδειξη: Πού ελέγχεται η συνθήκη;
Λύση: ΣΩΣΤΟ. Η συνθήκη ελέγχεται μετά το σώμα.
Άσκηση 4Μέτρια
Τι θα εμφανίσει το πρόγραμμα του ΕΚΠ με είσοδο 4 6;
1int a, b, ekp;2cin >> a >> b;3ekp = a;4while (ekp % a != 0 || ekp % b != 0)5    ekp++;6cout << ekp;
Υπόδειξη: Ο βρόχος σταματά στον πρώτο αριθμό ≥ a που διαιρείται και με τους δύο.
Λύση: ekp = 4, 5, …: ο πρώτος αριθμός που διαιρείται με 4 και 6 είναι το 12.
Οθόνη (έξοδος)
12
Άσκηση 5Μέτρια
Ένα ασανσέρ σηκώνει έως 600 κιλά ή 8 άτομα. Ποιες τιμές θα τυπώσει το πρόγραμμα αν δοθούν με τη σειρά τα βάρη 120 150 130 140 100 90;
1int weight, people = 0, total = 0;2cin >> weight;3do {4    total += weight;5    people++;6    cin >> weight;7} while (people != 8 && total + weight <= 600);8cout << "Total=" << total << endl;9cout << "Persons=" << people << endl;
Υπόδειξη: Πριν από κάθε νέα επανάληψη ελέγχεται αν χωρά και το επόμενο άτομο.
Λύση: total: 120 → 270 → 400 → 540 (people = 4). Το επόμενο βάρος είναι 100 και 540 + 100 = 640 > 600 → Ψ.
Οθόνη (έξοδος)
Total=540
Persons=4
Άσκηση 6Μέτρια
Στα δύο τμήματα η αρχική τιμή είναι arithmos = 13. Ποια τιμή θα έχει το sum στο τέλος του καθενός;
// Τμήμα Αsum = 0;arithmos = 13;while (arithmos <= 11) {    sum = sum + arithmos;    arithmos = arithmos + 2;}// Τμήμα Βsum = 0;arithmos = 13;do {    sum = sum + arithmos;    arithmos = arithmos + 2;} while (arithmos <= 11);
Υπόδειξη: Το while ελέγχει πριν, το do ελέγχει μετά.
Λύση: Α: 13 ≤ 11 → Ψ, το σώμα δεν εκτελείται → 0. Β: το σώμα εκτελείται μία φορά (sum = 13) και μετά 15 ≤ 11 → Ψ → 13.

Πόσους αστερίσκους θα εμφανίσει συνολικά το πρόγραμμα;

Υπόδειξη: Στη γραμμή i τυπώνονται i αστερίσκοι.
Λύση: $1 + 2 + 3 + 4 = $ 10.

Άσκηση 8Απαιτητική
Τι θα εμφανίσει το πρόγραμμα αν δοθεί x = 9;
1int x, sum = 0;2cin >> x;3for (int i = 0; i <= x; i += 2)4    sum += i;5cout << sum;
Υπόδειξη: Το i παίρνει τις άρτιες τιμές 0, 2, 4, … όσο i ≤ 9.
Λύση: $0 + 2 + 4 + 6 + 8 = $ 20.
Οθόνη (έξοδος)
20
Άσκηση 9Απαιτητική
Ποιο τμήμα με while είναι ισοδύναμο με το for (int i = 0; i <= x; i += 2) sum += i;;
Υπόδειξη: Η μεταβολή του μετρητή γίνεται στο τέλος κάθε επανάληψης· η συνθήκη μένει η ίδια.
Λύση: Σωστό: αρχικοποίηση πριν από το while, ίδια συνθήκη i <= x, και i += 2 μετά το sum += i, μέσα στα άγκιστρα. Αν η αύξηση γίνει πριν από την πρόσθεση αθροίζονται 2, 4, …, x+1· με < χάνεται το x όταν είναι άρτιος· χωρίς άγκιστρα το i += 2 είναι εκτός βρόχου → ατέρμων βρόχος.
Άσκηση 10Απαιτητική
Τι θα εμφανίσει το πρόγραμμα για n = 6;
1int n, steps = 0;2cin >> n;3while (n > 1) {4    if (n % 2 == 0)5        n = n / 2;6    else7        n = 3 * n + 1;8    steps++;9}10cout << steps;
Υπόδειξη: Κάνε πίνακα τιμών για το n μέχρι να γίνει 1.
Λύση: n: 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1, δηλαδή 8 βήματα.
Οθόνη (έξοδος)
8

♾️ Γεννήτρια — δομές επανάληψης

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Τι θα εμφανίσει το πιο κάτω τμήμα προγράμματος;
int x = 1, k = 0;while (x <= 162) {    x = x * 3;    k++;}cout << k << " " << x;
Υπόδειξη: Το x πολλαπλασιάζεται με 3 σε κάθε επανάληψη· σταματά μόλις ξεπεράσει το 162.
Λύση: Τιμές του x: 1 → 3 → 9 → 27 → 81 → 243. Μετά από 5 επαναλήψεις x = 243 > 162, άρα η συνθήκη γίνεται ψευδής.
Οθόνη (έξοδος)
5 243
