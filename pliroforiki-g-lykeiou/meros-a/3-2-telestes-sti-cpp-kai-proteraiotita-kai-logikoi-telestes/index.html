3.2

Τελεστές στη C++: / και %, προτεραιότητα, ++ και --, λογικοί τελεστές και έτοιμες συναρτήσεις cmath

📘 Βιβλίο Γ΄ Λυκείου: Γ7.1 §2 Τελεστές, Όρια και Συναρτήσεις (σ. 74–76)

Γιατί στη C++ το 7 / 2 κάνει 3, τι είναι ο τελεστής %, και πώς υπολογίζουμε εκφράσεις με sqrt, pow, trunc, round όπως στις Παγκύπριες;

Θεωρία

Οι τελεστές της C++ και οι έτοιμες συναρτήσεις της βιβλιοθήκης cmath εμφανίζονται σχεδόν σε κάθε δοκίμιο των Παγκυπρίων: «να γράψετε το αποτέλεσμα της εντολής…», «να γράψετε τις τιμές των λογικών μεταβλητών…». Το κλειδί είναι να ξέρουμε τον τύπο κάθε τιμής (ακέραιος ή πραγματικός) και τη σειρά με την οποία γίνονται οι πράξεις.

Αριθμητικοί τελεστές

ΤελεστήςΠράξηΠαράδειγμα
+ - *πρόσθεση, αφαίρεση, πολλαπλασιασμός3 * 4 → 12
/διαίρεση — ακέραια αν και οι δύο τελεστέοι είναι ακέραιοι17 / 5 → 3 · 17.0 / 5 → 3.4
%υπόλοιπο ακέραιας διαίρεσης (μόνο ακέραιοι)17 % 5 → 2

Στην ακέραια διαίρεση το δεκαδικό μέρος αποκόπτεται (στρογγυλοποίηση προς το μηδέν): -17 / 5 → −3 και το υπόλοιπο έχει το πρόσημο του διαιρετέου: -17 % 5 → −2. Ισχύει πάντα (a / b) * b + a % b == a.

$$\text{ψηφίο μονάδων} = n \,\%\, 10, \qquad \text{ψηφίο δεκάδων} = n / 10 \,\%\, 10$$

Προτεραιότητα τελεστών

1) παρενθέσεις () → 2) * / % → 3) + -. Τελεστές με ίδια προτεραιότητα εκτελούνται από αριστερά προς τα δεξιά. Παράδειγμα: 2 + 3 * 4 % 5 = 2 + (12 % 5) = 2 + 2 = 4.

Μετατροπή τύπου (type casting)

Για να γίνει πραγματική διαίρεση δύο ακεραίων μετατρέπουμε τον έναν σε πραγματικό: U = float(X) / T; ή mesos = (float) sum / metritis;. Προσοχή: η float(X / T) είναι λάθος — η ακέραια διαίρεση έχει ήδη γίνει!

Τελεστές αύξησης/μείωσης και σύνθετης εκχώρησης

a++; a += 1; a = a + 1; είναι ισοδύναμα. Επίσης b *= a; ≡ b = b * a; και x /= y; ≡ x = x / y;. Σε μια έκφραση όμως έχει σημασία αν ο τελεστής είναι πρόθεμα ή επίθεμα:

1int a, b, c, d;2a = 4;3b = ++a;                        // πρώτα αυξάνεται το a, μετά εκχωρείται4cout << a << " " << b << endl;  // 5 55c = 4;6d = c++;                        // πρώτα εκχωρείται, μετά αυξάνεται το c7cout << c << " " << d << endl;  // 5 4

Συγκρίσεις: == != > < >= <= (η ισότητα είναι ==, όχι =). Λογικοί: AND &&, OR ||, NOT !, με προτεραιότητα ! → && → ||.

Η cout τυπώνει μια λογική τιμή ως 1 (true) ή 0 (false). Επειδή ο << έχει μεγαλύτερη προτεραιότητα από τους συγκριτικούς και τους λογικούς τελεστές, γράφουμε τη λογική έκφραση μέσα σε παρένθεση: cout << (x > 0 && y > 0);

Έτοιμες συναρτήσεις της βιβλιοθήκης <cmath>

ΣυνάρτησηΕπιστρέφειΠαράδειγμα
sqrt(x)τετραγωνική ρίζα (πραγματικός)sqrt(9) = 3.0
abs(x)απόλυτη τιμή (ίδιου τύπου με το x)abs(-2) = 2 · abs(-3.1) = 3.1
pow(x, y)δύναμη $x^y$ (πραγματικός)pow(2.0, 3.0) = 8.0 · pow(2.0, -1.0) = 0.5
trunc(x)ακέραιο μέρος, αποκόπτοντας τα δεκαδικάtrunc(1.7) = 1.0 · trunc(-2.1) = −2.0

Η βιβλιοθήκη <climits> ορίζει τις σταθερές INT_MAX (2147483647) και INT_MIN (−2147483648), τα όρια του τύπου int. (Στο σχόλιο του βιβλίου γράφεται −2147483647, όμως η πραγματική τιμή που τυπώνεται είναι −2147483648.)

Σημείωση: οι round και trunc (όπως και οι εκδοχές των pow/sqrt με ακέραια ορίσματα) προέρχονται τυπικά από τα πρότυπα C99/C++11. Περιλαμβάνονται όμως στο βιβλίο (σ. 76) και ο g++ τις δέχεται κανονικά με τη <cmath>, οπότε τις χρησιμοποιούμε όπως το βιβλίο.

Θέμα τύπου Παγκυπρίων

Να γράψετε το αποτέλεσμα της εντολής cout << trunc(-6.5 + pow(2, 2)) + abs(round(-sqrt(67)));

Λύση βήμα-βήμα

pow(2, 2) = 4 → -6.5 + 4 = −2.5 → trunc(-2.5) = −2.
sqrt(67) ≈ 8.185 → round(-8.185) = −8 → abs(-8) = 8.
Άθροισμα: −2 + 8 = 6.

Οθόνη (έξοδος)
6

Συχνά λάθη στις Παγκύπριες

Ξεχνάμε ότι 7 / 2 = 3 · χρησιμοποιούμε % σε πραγματικούς · γράφουμε 1 <= x <= 100 αντί για x >= 1 && x <= 100 (η πρώτη είναι πάντα αληθής!) · συγχέουμε trunc με round στους αρνητικούς · ξεχνάμε τη σειρά ! → && → ||.

Πειραματίσου

int a = 17, b = 5;double x = 4.5;cout << (a / b * b + a % b);
  1. 17 / 5 → 3 (ακέραια διαίρεση (αποκόπτεται το δεκαδικό μέρος))
  2. 3 * 5 → 15
  3. 17 % 5 → 2 (υπόλοιπο ακέραιας διαίρεσης)
  4. 15 + 2 → 17
Τύπος αποτελέσματος: int · η cout τυπώνει: 17

Ασκήσεις — 0/11 λυμένες

Άσκηση 1Βασική
Ποιες τιμές θα εμφανίσουν οι εντολές cout << 17 / 5; και cout << 17 % 5;;
Υπόδειξη: Και οι δύο τελεστέοι είναι ακέραιοι.
Λύση: $17 = 3 \cdot 5 + 2$: ακέραιο πηλίκο 3, υπόλοιπο 2.
Άσκηση 2Βασική
Τι θα εμφανίσει κάθε cout; (μία γραμμή ανά πεδίο)
1int a, b, c, d;2a = 4;3b = ++a;4cout << a << " " << b << endl;5c = 4;6d = c++;7cout << c << " " << d << endl;
Υπόδειξη: Πρόθεμα (++a): αύξηση και μετά χρήση. Επίθεμα (c++): χρήση και μετά αύξηση.
Λύση: b = ++a: το a γίνεται 5 και το b παίρνει 5. d = c++: το d παίρνει την παλιά τιμή 4 και μετά το c γίνεται 5.
Οθόνη (έξοδος)
5 5
5 4
Άσκηση 3Μέτρια
Ποιες τιμές θα εμφανίσουν οι εντολές cout << -17 / 5; και cout << -17 % 5;;
Υπόδειξη: Η ακέραια διαίρεση αποκόπτει προς το μηδέν· το υπόλοιπο έχει το πρόσημο του διαιρετέου.
Λύση: $-17/5 = -3{,}4$ → αποκοπή → −3. Υπόλοιπο: $-17 - (-3)\cdot 5 = -2$.
Άσκηση 4Μέτρια
Υπολόγισε τις τιμές των εκφράσεων 2 + 3 * 4 % 5 και (2 + 3) * 4 % 5.
Υπόδειξη: Οι * και % έχουν την ίδια προτεραιότητα και εκτελούνται από αριστερά προς δεξιά.
Λύση: 1η: $3 \cdot 4 = 12$, $12 \% 5 = 2$, $2 + 2 = $ 4. 2η: $(2+3) = 5$, $5 \cdot 4 = 20$, $20 \% 5 = $ 0.
Άσκηση 5Μέτρια
Τι θα εμφανίσει το πιο κάτω τμήμα;
int n = 12348889;cout << n / 10 % 10;
Υπόδειξη: Το n / 10 «κόβει» το τελευταίο ψηφίο.
Λύση: $12348889 / 10 = 1234888$ και $1234888 \% 10 = 8$: είναι το ψηφίο των δεκάδων.
Οθόνη (έξοδος)
8
Άσκηση 6Μέτρια
Ποια λογική έκφραση της C++ ελέγχει αν η ακέραια μεταβλητή grade είναι μεταξύ 1 και 100, συμπεριλαμβανομένων;
Υπόδειξη: Χρειάζονται δύο συγκρίσεις που πρέπει να ισχύουν ταυτόχρονα.
Λύση: Σωστό: grade >= 1 && grade <= 100. Η 1 <= grade <= 100 υπολογίζεται ως (1 <= grade) <= 100, δηλαδή 0 ή 1 ≤ 100 → πάντα αληθής. Με || είναι επίσης πάντα αληθής, και με γνήσιες ανισότητες αποκλείονται τα 1 και 100.
Άσκηση 7Απαιτητική
Να γράψετε το αποτέλεσμα της εντολής (θέμα Παγκυπρίων):
cout << trunc(-6.5 + pow(2, 2)) + abs(round(-sqrt(67)));
Υπόδειξη: Υπολόγισε χωριστά τα δύο μέρη: trunc(…) και abs(round(…)).
Λύση: pow(2,2) = 4, −6.5 + 4 = −2.5, trunc(-2.5) = −2. sqrt(67) ≈ 8.185, round(-8.185) = −8, abs(-8) = 8. Σύνολο −2 + 8 = 6.
Οθόνη (έξοδος)
6
Άσκηση 8Απαιτητική
Οι ακέραιες μεταβλητές έχουν τιμές a = -3, b = 2, c = 4. Ποιες τιμές θα πάρουν οι λογικές μεταβλητές x και y; (γράψε 1 για true, 0 για false)
x = (b != (3 * pow(a, 2) - 1)) && ((abs(a) + trunc((float) b / c)) == b);y = !((b + c) >= a) || (sqrt(b * 8) <= round(a + 7.3));
Υπόδειξη: Υπολόγισε κάθε παρένθεση χωριστά. Θυμήσου: (float) b / c = 0.5.
Λύση: x: $3 \cdot (-3)^2 - 1 = 26$, άρα $2 \ne 26$ → true. abs(-3) + trunc(0.5) = 3 + 0 = 3, και $3 == 2$ → false. true && false → x = 0.
y: $(2+4) \ge -3$ → true, άρα ! → false. sqrt(16) = 4, round(4.3) = 4, $4 \le 4$ → true. false || true → y = 1.
Άσκηση 9Μέτρια
Αν X = 10, Y = 5 και Z = -2, γράψε το αποτέλεσμα (1 ή 0) κάθε λογικής έκφρασης:
(α) (X > Y) || (X > Z) && (Y > X)
(β) !(X == (2 * Y)) && !(Z == 2)
(γ) (Y == (X / 2)) && (Z > 0)
Υπόδειξη: Το && εκτελείται πριν από το ||.
Λύση: (α) $(X>Z) \,\&\&\, (Y>X)$ = true && false = false· μετά true || false = 1.
(β) $X == 10$ → true, ! → false· άρα όλη η σύζευξη 0.
(γ) $5 == 5$ → true, $Z > 0$ → false → 0.
Άσκηση 10Βασική
Η μεταβλητή N είναι τύπου double (π.χ. 56.78). Ποια έκφραση δίνει το δεκαδικό μέρος της (0.78);
Υπόδειξη: Η trunc δίνει το ακέραιο μέρος.
Λύση: trunc(56.78) = 56, άρα N - trunc(N) = 0.78 (βιβλίο, Παράδειγμα 1.4). Ο % δεν επιτρέπεται σε πραγματικούς, η trunc(N) - N δίνει −0.78 και η round(N) - N δίνει 0.22.
Άσκηση 11Μέτρια
Ποιες τιμές θα πάρουν οι μεταβλητές x και y;
int x = 7 / 2 * 2.0;double y = 7 / 2.0 * 2;
Υπόδειξη: Πρόσεξε ποια διαίρεση είναι ακέραια.
Λύση: x: $7/2 = 3$ (ακέραια), $3 \cdot 2.0 = 6.0$ → 6. y: $7/2.0 = 3.5$ (πραγματική), $3.5 \cdot 2 = $ 7.

♾️ Γεννήτρια — τελεστές και έτοιμες συναρτήσεις

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Τι θα εμφανίσει το πιο κάτω τμήμα προγράμματος;
int a = 7, b;b = ++a * 2;cout << a << " " << b;
Υπόδειξη: Πρόθεμα ++a: πρώτα αυξάνεται το a και μετά χρησιμοποιείται.
Λύση: Το a γίνεται 8 και μετά b = 8·2 = 16.
