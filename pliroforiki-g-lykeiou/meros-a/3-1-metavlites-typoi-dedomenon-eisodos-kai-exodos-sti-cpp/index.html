3.1

Μεταβλητές, τύποι δεδομένων, είσοδος και έξοδος στη C++ (cin, cout, setw, setprecision)

📘 Βιβλίο Γ΄ Λυκείου: Γ7.1 §2 Απλά προγράμματα (σ. 71–74)

Πώς δηλώνουμε μεταβλητές και σταθερές στη C++, πώς διαβάζουμε τιμές με cin και πώς τυπώνουμε αποτελέσματα με cout, setw και setprecision;

Θεωρία

Κάθε πρόγραμμα της C++ που γράφουμε για τις Παγκύπριες έχει την ίδια βασική δομή: δηλώνουμε τις βιβλιοθήκες που χρειαζόμαστε, γράφουμε τη συνάρτηση main και μέσα σε αυτήν δηλώνουμε μεταβλητές, διαβάζουμε δεδομένα με την cin, κάνουμε υπολογισμούς και εμφανίζουμε τα αποτελέσματα με την cout. Σε αυτή την ενότητα κάνουμε επανάληψη της ύλης της Β΄ Λυκείου: τύποι δεδομένων, δήλωση μεταβλητών και σταθερών, είσοδος/έξοδος και μορφοποίηση εξόδου.

Ένα απλό πρόγραμμα C++

Το πρόγραμμα διαβάζει δύο ακέραιους και τυπώνει το άθροισμά τους.

sum.cpp
1#include <iostream>2using namespace std;3int main() {4    int a, b, sum;5    cin >> a >> b;6    sum = a + b;7    cout << "SUM=" << sum;8    return 0;9}

Με είσοδο 4 7:

Οθόνη (έξοδος)
SUM=11

  • #include <iostream>: η βιβλιοθήκη για είσοδο από πληκτρολόγιο και έξοδο στην οθόνη. Άλλες βιβλιοθήκες που χρησιμοποιούμε: <iomanip> (μορφοποίηση), <cmath> (μαθηματικές συναρτήσεις), <string>.
  • int a, b, sum;: δήλωση τριών μεταβλητών ακέραιου τύπου.
  • cin >> a >> b;: είσοδος — πριν από κάθε μεταβλητή μπαίνει ο τελεστής >>.
  • cout << "SUM=" << sum;: έξοδος — ό,τι είναι σε διπλά εισαγωγικά τυπώνεται αυτούσιο.

Μια μεταβλητή είναι μια θέση μνήμης με όνομα, στην οποία αποθηκεύεται μια τιμή συγκεκριμένου τύπου. Τη δηλώνουμε οπουδήποτε μέσα στη main, πριν τη χρησιμοποιήσουμε, και μπορούμε να της δώσουμε αρχική τιμή κατά τη δήλωση:

int num = 10;int kpak = 4, jpak = kpak + 2;double ratio = 25.56;bool check = false;char alpha = 'A', beta = 'B';

Το όνομα μιας μεταβλητής γράφεται με λατινικούς χαρακτήρες, ψηφία και _, δεν αρχίζει με ψηφίο, δεν είναι δεσμευμένη λέξη (π.χ. int, for) και η C++ ξεχωρίζει κεφαλαία από μικρά (sum ≠ Sum).

Σταθερές: const και #define

Μια σταθερά έχει τιμή που δεν μπορεί να αλλάξει μετά την αρχικοποίηση. Δηλώνεται με τη λέξη const μπροστά από τη δήλωση ή με την οδηγία #define:

#define p 3.14              // σταθερά με #define (χωρίς = και ;)const float fpa = 0.23;     // σταθερά με const

Η ορθότητα μιας δήλωσης const ελέγχεται αμέσως από τον μεταγλωττιστή, ενώ το #define είναι απλή αντικατάσταση κειμένου: ένα λάθος εμφανίζεται στη γραμμή όπου χρησιμοποιείται η σταθερά και όχι στη δήλωσή της.

Μορφοποίηση εξόδου: endl, setw, fixed, setprecision

  • endl: αλλαγή γραμμής (end line).
  • setw(n) (βιβλιοθήκη <iomanip>): η αμέσως επόμενη τιμή τυπώνεται σε πλάτος n θέσεων, στοιχισμένη δεξιά· οι κενές θέσεις συμπληρώνονται με κενά.
  • fixed << setprecision(n): οι πραγματικοί αριθμοί τυπώνονται με ακριβώς n δεκαδικά ψηφία, με στρογγυλοποίηση. Χωρίς το fixed η setprecision μετρά σημαντικά ψηφία — γι' αυτό γράφουμε πάντα πρώτα το fixed.
cout << "Long" << setw(5) << "live" << setw(4) << "and" << setw(8) << "prosper";
Οθόνη (έξοδος)
Long live and prosper

Το «live» έχει 4 χαρακτήρες σε πλάτος 5 → 1 κενό· το «and» 3 σε πλάτος 4 → 1 κενό· το «prosper» 7 σε πλάτος 8 → 1 κενό.

Τελική τιμή με ΦΠΑ 23% (βιβλίο, Παράδειγμα 1.2)

fpa.cpp
1#include <iostream>2#include <iomanip>3using namespace std;4int main() {5    const float fpa = 0.23;6    float cost;7    cin >> cost;8    cout << fixed << setprecision(2) << cost + cost * fpa;9    return 0;10}
Λύση βήμα-βήμα για είσοδο 80

cost = 80 → cost + cost·fpa = 80 + 18,4 = 98,4 → με fixed και 2 δεκαδικά:

Οθόνη (έξοδος)
98.40

Συχνά λάθη στις Παγκύπριες

cin >> a, b; (σωστό: cin >> a >> b;) · cout >> x; (σωστό: cout << x;) · παράλειψη του ; · χρήση μεταβλητής που δεν δηλώθηκε · ξεχνάμε τη βιβλιοθήκη <iomanip> όταν χρησιμοποιούμε setw/setprecision · ξεχνάμε το fixed πριν από τη setprecision.

Πειραματίσου

#include <iomanip>   // για setw, setprecision, fixed...cout << setw(10) << fixed << setprecision(2) << 3.14159 << "|";
Οθόνη — κάθε κουτάκι είναι ένας χαρακτήρας (τα σκούρα είναι κενά):
␣␣␣␣␣␣3.14|
Τυπώνονται 4 χαρακτήρες «3.14» σε πλάτος 10 → 6 κενά αριστερά (δεξιά στοίχιση).
Με fixed η setprecision(2) ορίζει ακριβώς 2 δεκαδικά ψηφία, με στρογγυλοποίηση.
Η setw ισχύει μόνο για την αμέσως επόμενη τιμή· οι fixed και setprecision ισχύουν για όλες τις επόμενες.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Ποιον τύπο δεδομένων πρέπει να έχει η μεταβλητή στην οποία θα αποθηκεύσουμε τον μέσο όρο των βαθμών μιας τάξης;
Υπόδειξη: Ο μέσος όρος μπορεί να έχει δεκαδικά ψηφία.
Λύση: Ο μέσος όρος (π.χ. 15,75) είναι πραγματικός αριθμός, άρα float (ή double). Ο int θα έχανε το δεκαδικό μέρος.
Άσκηση 2Βασική
Η τιμή μιας σταθεράς που δηλώθηκε με const μπορεί να αλλάξει αργότερα στο πρόγραμμα με μια εντολή εκχώρησης.
Υπόδειξη: Τι σημαίνει «σταθερά»;
Λύση: ΛΑΘΟΣ. Ούτε με const ούτε με #define επιτρέπεται αλλαγή της τιμής μετά την αρχικοποίηση· μια εντολή όπως fpa = 0.19; δίνει συντακτικό λάθος.
Άσκηση 3Βασική
Τι θα εμφανίσει το πιο κάτω τμήμα προγράμματος;
int a = 7, b = 3;cout << "SUM=" << a + b << endl;
Υπόδειξη: Το κείμενο στα εισαγωγικά τυπώνεται όπως είναι· μετά τυπώνεται η τιμή της παράστασης.
Λύση: Τυπώνεται το «SUM=» και μετά η τιμή του a + b = 10 (χωρίς κενό ανάμεσα):
Οθόνη (έξοδος)
SUM=10
Άσκηση 4Βασική
Πόσα bytes μνήμης καταλαμβάνει μια μεταβλητή τύπου int (σύμφωνα με τον πίνακα του βιβλίου);
Υπόδειξη: Δες τον πίνακα τύπων δεδομένων.
Λύση: Ο int καταλαμβάνει 4 bytes (εμβέλεια −2 147 483 648 έως 2 147 483 647).
Άσκηση 5Μέτρια
Τι θα εμφανίσει η πιο κάτω εντολή;
cout << fixed << setprecision(2) << 10.0 / 4 + 1;
Υπόδειξη: Το 10.0 είναι πραγματικός, άρα η διαίρεση είναι πραγματική.
Λύση: $10.0 / 4 = 2.5$ και $2.5 + 1 = 3.5$. Με fixed και setprecision(2) τυπώνονται ακριβώς δύο δεκαδικά:
Οθόνη (έξοδος)
3.50
Άσκηση 6Μέτρια
Πόσα κενά διαστήματα συνολικά θα εμφανίσει η εντολή;
cout << "Long" << setw(5) << "live" << setw(4) << "and" << setw(8) << "prosper";
Υπόδειξη: Για κάθε setw: κενά = πλάτος − πλήθος χαρακτήρων της τιμής που ακολουθεί.
Λύση: «live»: $5 - 4 = 1$ · «and»: $4 - 3 = 1$ · «prosper»: $8 - 7 = 1$ → συνολικά 3 κενά.
Οθόνη (έξοδος)
Long live and prosper
Άσκηση 7Μέτρια
Τι θα εμφανίσει το πρόγραμμα αν ο χρήστης δώσει την τιμή 100;
1#include <iostream>2#include <iomanip>3using namespace std;4int main() {5    const float fpa = 0.23;6    float cost;7    cin >> cost;8    cout << fixed << setprecision(2) << cost + cost * fpa;9    return 0;10}
Υπόδειξη: Υπολόγισε $100 + 100 \cdot 0{,}23$.
Λύση: $100 + 100 \cdot 0.23 = 123$, που τυπώνεται με δύο δεκαδικά:
Οθόνη (έξοδος)
123.00
Άσκηση 8Μέτρια
Ποια από τις πιο κάτω δηλώσεις είναι λανθασμένη;
Υπόδειξη: Θυμήσου τους κανόνες για τα ονόματα μεταβλητών.
Λύση: Το όνομα μεταβλητής δεν μπορεί να αρχίζει με ψηφίο, άρα η int 2x = 5; είναι λανθασμένη. Οι άλλες τρεις είναι σωστές δηλώσεις με αρχική τιμή.
Άσκηση 9Απαιτητική
Το πιο κάτω πρόγραμμα πρέπει να διαβάζει δύο ακέραιους και να τυπώνει τον μέσο όρο των ψηφίων των μονάδων τους (π.χ. για 123 και 56 → 4.5). Υπάρχουν 4 λάθη (συντακτικά ή λογικά). Γράψε τους αριθμούς των γραμμών τους σε αύξουσα σειρά.
1#include <iostream>2using namespace std;3int main() {4    int a, b, m1, m2;5    float mesos;6    cin >> a, b;7    m1 = a % 10;8    m2 = a % 10;9    mesos = (m1 + m2) / 2;10    cout >> mesos;11    return 0;12}
Υπόδειξη: Έλεγξε: την είσοδο, ποια μεταβλητή χρησιμοποιείται για το m2, τη διαίρεση ακεραίων και την έξοδο.
Λύση:
  • Γραμμή 6: cin >> a >> b; — λογικό λάθος: το cin >> a, b; μεταγλωττίζεται (τελεστής κόμματος), αλλά το b δεν διαβάζεται.
  • Γραμμή 8: m2 = b % 10; (λογικό).
  • Γραμμή 9: mesos = (m1 + m2) / 2.0; — αλλιώς γίνεται ακέραια διαίρεση και το 4.5 γίνεται 4 (λογικό).
  • Γραμμή 10: cout << mesos; (συντακτικό).
1#include <iostream>2using namespace std;3int main() {4    int a, b, m1, m2;5    float mesos;6    cin >> a >> b;7    m1 = a % 10;8    m2 = b % 10;9    mesos = (m1 + m2) / 2.0;10    cout << mesos;11    return 0;12}
Για είσοδο 123 56:
Οθόνη (έξοδος)
4.5
Άσκηση 10Απαιτητική
Το πρόγραμμα υπολογίζει τον όγκο κυλίνδρου $V = h \cdot \pi \cdot R^2$. Τι θα εμφανίσει για R = 2 και h = 5;
1#include <iostream>2#define p 3.143using namespace std;4int main() {5    float R, V, h;6    cout << "R=";7    cin >> R;8    cout << "h=";9    cin >> h;10    V = h * p * R * R;11    cout << "V=" << V;12    return 0;13}
Γράψε μόνο την τελευταία έξοδο (μετά τα μηνύματα R= και h=).
Υπόδειξη: Η σταθερά p αντικαθίσταται με 3.14. Η cout χωρίς fixed δεν τυπώνει περιττά μηδενικά.
Λύση: $V = 5 \cdot 3.14 \cdot 2 \cdot 2 = 62.8$. Χωρίς fixed/setprecision η cout τυπώνει τον αριθμό χωρίς περιττά μηδενικά:
Οθόνη (έξοδος)
R=h=V=62.8
(τα «R=» και «h=» είναι τα μηνύματα εισόδου· οι τιμές 2 και 5 που πληκτρολογεί ο χρήστης εμφανίζονται κι αυτές στην οθόνη.)

♾️ Γεννήτρια — μορφοποίηση εξόδου (setw, setprecision)

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Τι θα εμφανίσει το πιο κάτω τμήμα προγράμματος;
int a = 12, b = 5;float m;m = a / b;cout << fixed << setprecision(2) << m;
Υπόδειξη: Και οι δύο τελεστέοι της διαίρεσης είναι int.
Λύση: Η a / b είναι ακέραια διαίρεση: 12 / 5 = 2 (αποκόπτεται το δεκαδικό μέρος). Η τιμή 2 αποθηκεύεται στη float m και τυπώνεται με 2 δεκαδικά ψηφία:
Οθόνη (έξοδος)
2.00
Για πραγματική διαίρεση θέλει float(a) / b.
