3.3

Δομή διακλάδωσης στη C++: if, else, ένθετα if και η εντολή switch

📘 Βιβλίο Γ΄ Λυκείου: Γ7.1 §3 Δομή Διακλάδωσης, §4 Περιπτωσιακή Δομή – switch (σ. 77–80)

Πώς παίρνει αποφάσεις ένα πρόγραμμα C++ με την εντολή if, πότε χρησιμοποιούμε switch και τι γίνεται όταν ξεχάσουμε το break;

Θεωρία

Στη δομή διακλάδωσης το πρόγραμμα εκτελεί μια εντολή ή μια ομάδα εντολών ανάλογα με το αποτέλεσμα μιας λογικής έκφρασης (συνθήκης). Στη C++ η δομή διακλάδωσης υλοποιείται με την εντολή if … else, ενώ η περιπτωσιακή δομή με την εντολή switch. Είναι από τα πιο συχνά θέματα των Παγκυπρίων: ίχνος με δοσμένη είσοδο, μετατροπή if ↔ switch, εντοπισμός λαθών.

Η εντολή if … else

if (λογική έκφραση) {    εντολές που εκτελούνται αν ισχύει η συνθήκη}else {    εντολές που εκτελούνται αν ΔΕΝ ισχύει η συνθήκη}
  • Το else μπορεί να λείπει: αν η συνθήκη είναι ψευδής δεν εκτελείται τίποτα.
  • Τα άγκιστρα { } μπορούν να παραλειφθούν όταν ο κλάδος έχει μία μόνο εντολή.
  • Για ισότητα χρησιμοποιούμε == και όχι =.

Ωρομίσθιος υπάλληλος (βιβλίο, Παράδειγμα 1.5)

15 ευρώ την ώρα· αν ο μισθός ξεπερνά τα 1000 ευρώ, αφαιρείται φόρος 13%.

1#include <iostream>2#define tax 0.133#define amount 154using namespace std;5int main() {6    int h;7    float salary;8    cin >> h;9    salary = h * amount;10    if (salary > 1000)11        salary -= salary * tax;12    cout << salary;13    return 0;14}
Λύση βήμα-βήμα για h = 80

salary = 80 · 15 = 1200 → 1200 > 1000 → Α → salary = 1200 − 156 = 1044.

Οθόνη (έξοδος)
1044

Ένθετες εντολές if — η κλίμακα else if

Μέσα σε έναν κλάδο μπορεί να υπάρχει άλλη if. Το else ανήκει πάντα στο πλησιέστερο προηγούμενο if που δεν έχει ήδη else. Όταν έχουμε πολλές περιπτώσεις χρησιμοποιούμε την κλίμακα if … else if … else: οι συνθήκες ελέγχονται με τη σειρά και εκτελείται μόνο ο πρώτος κλάδος με αληθή συνθήκη.

Παράδειγμα 1.6
1if (c == 'Y' || c == 'y')2    cout << "Yes";3else if (c == 'N' || c == 'n')4    cout << "No";5else6    cout << "Wrong Input";

Η εντολή switch (περιπτωσιακή δομή)

Η switch δεν εξετάζει λογική έκφραση αλλά τις τιμές μιας μεταβλητής ελέγχου, η οποία πρέπει να είναι διακριτού τύπου (int ή char — όχι float ή string).

Παράδειγμα 1.7 (απόσπασμα)
1switch (code) {2    case 1:3        price = 4.0;4        break;5    case 2:6    case 3:7    case 4:8        price = 4.5;9        break;10    default:11        cout << "Wrong input" << endl;12}
  • Η εκτέλεση ξεκινά από την case που ταιριάζει και συνεχίζει μέχρι το πρώτο break ή το τέλος της switch. Έτσι οι case 2: case 3: case 4: μοιράζονται την ίδια εντολή.
  • Αν λείπει το break, εκτελούνται και οι εντολές των επόμενων περιπτώσεων («πέφτει» η εκτέλεση).
  • Το default εκτελείται όταν καμία περίπτωση δεν είναι ίση με τη μεταβλητή ελέγχου.

Μετατροπή if → switch

Η κλίμακα if (flag == 'Z') … else if (flag == 'X') … else … γράφεται ως:

1switch (flag) {2    case 'Z':3        cout << "HOT" << endl;4        break;5    case 'X':6        cout << "WARM" << endl;7        break;8    case 'K':9        cout << "COLD" << endl;10        break;11    default:12        cout << "Wrong value" << endl;13}

Η μετατροπή switch → if είναι πάντα δυνατή· η αντίστροφη μόνο όταν οι συνθήκες είναι ισότητες με σταθερές τιμές ακέραιας/χαρακτήρα μεταβλητής (π.χ. το epid >= 1 && epid <= 3 γίνεται case 1: case 2: case 3:).

Συχνά λάθη στις Παγκύπριες

if (x = 0) αντί για if (x == 0) (εκχωρεί 0 και η συνθήκη είναι πάντα ψευδής!) · ξεχασμένο break στη switch · case "Z": με διπλά εισαγωγικά (σωστό: 'Z') · ; αμέσως μετά το if (…) · δύο εντολές σε κλάδο χωρίς άγκιστρα.

Πειραματίσου

βήμα 0 / 5
1char sex;2int age, asfalistra;3cin >> sex >> age;4if (sex == 'M')5    if (age < 25)6        asfalistra = 300;7    else8        asfalistra = 250;9else if (age < 21)10    asfalistra = 200;11else12    asfalistra = 150;13cout << "Asfalistra: " << asfalistra;

Το πρόγραμμα του Παραδείγματος 1.7 (τιμές προϊόντων) εκτελείται δύο φορές. Τι θα εμφανίσει με είσοδο 3 10 και τι με είσοδο 10 3;

Λύση: code = 3 → price = 4.5 → total = 45 → 45.00. code = 10 → price = 5.0 → total = 15 → 15.00.
Άσκηση 5Μέτρια
Τι θα εμφανίσει το πιο κάτω τμήμα;
1int k = 2;2switch (k) {3    case 1:4        cout << "A";5    case 2:6        cout << "B";7    case 3:8        cout << "C";9        break;10    default:11        cout << "D";12}

Λύση: Η εκτέλεση ξεκινά από την case 2, τυπώνει B, δεν βρίσκει break και συνεχίζει στην case 3 (C) όπου υπάρχει break.

Άσκηση 6Μέτρια
Σε μια βιβλιοθήκη, το γινόμενο των δύο τελευταίων ψηφίων του αριθμού μητρώου ενός βιβλίου καθορίζει το είδος δανεισμού. Τι θα τυπώσει το πρόγραμμα για τους αριθμούς 123, 178 και 105;
1int am, d1, d2, g;2cin >> am;3d1 = am % 10;4d2 = am / 10 % 10;5g = d1 * d2;6if (g == 0)7    cout << "never";8else if (g < 10)9    cout << "week";10else11    cout << "month";
Υπόδειξη: d1 = μονάδες, d2 = δεκάδες.
Λύση: 123: 3·2 = 6 < 10 → week. 178: 8·7 = 56 → month. 105: 5·0 = 0 → never. Προσοχή: η περίπτωση 0 ελέγχεται πρώτη, αλλιώς το 0 θα έπιανε τον κλάδο «< 10».

Άσκηση 8Απαιτητική
Ποια switch είναι ισοδύναμη με το τμήμα:
if (flag == 'Z')    cout << "HOT";else if (flag == 'X')    cout << "WARM";else    cout << "Wrong";
Υπόδειξη: Χρειάζονται break, χαρακτήρες σε απλά εισαγωγικά και μία case για κάθε τιμή.
Λύση: Σωστή είναι η switch με case 'Z':, case 'X':, break σε κάθε περίπτωση και default. Χωρίς break για flag = 'Z' θα τυπωνόταν «HOTWARMWrong»· τα "Z" είναι συμβολοσειρές (συντακτικό λάθος)· το 'Z' || 'X' είναι λογική έκφραση με τιμή 1 και όχι δύο περιπτώσεις.
Άσκηση 9Απαιτητική
Η εταιρεία κρατά από τον μισθό δύο ποσά: για μισθό ≤ 800 κρατήσεις 2% και 2,5%, για 801–1200 κρατήσεις 2,5% και 3%, και για μισθό > 1200 κρατήσεις 3% και 4%. Τι θα εμφανίσει το πρόγραμμα με είσοδο 1500; (μία γραμμή ανά πεδίο)
1float misthos, k1, k2;2cin >> misthos;3if (misthos <= 800) {4    k1 = misthos * 0.02;5    k2 = misthos * 0.025;6}7else if (misthos <= 1200) {8    k1 = misthos * 0.025;9    k2 = misthos * 0.03;10}11else {12    k1 = misthos * 0.03;13    k2 = misthos * 0.04;14}15cout << fixed << setprecision(2) << k1 << endl;16cout << k2 << endl;17cout << misthos - k1 - k2 << endl;
Υπόδειξη: 1500 > 1200: εκτελείται ο κλάδος else. Οι fixed/setprecision ισχύουν και για τις επόμενες cout.
Λύση: 1500 ≤ 800 → Ψ, 1500 ≤ 1200 → Ψ → else: k1 = 1500·0,03 = 45, k2 = 1500·0,04 = 60, καθαρός 1500 − 45 − 60 = 1395.
