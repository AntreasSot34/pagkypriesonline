10.3

Εγγραφές και συναρτήσεις: αναζήτηση και ταξινόμηση εγγραφών σε C++

📘 Βιβλίο Γ΄ Λυκείου: Γ7.8 §8–9 (σ. 252–257) · Παραδείγματα 8.5–8.8

Πώς περνάμε μια εγγραφή σε συνάρτηση (με τιμή ή με αναφορά) και πώς κάνουμε αναζήτηση και ταξινόμηση σε πίνακα εγγραφών με βάση ένα πεδίο;

Θεωρία

Οι εγγραφές συνεργάζονται φυσικά με τις συναρτήσεις: μια εγγραφή μπορεί να δοθεί ως παράμετρος τιμής (η συνάρτηση παίρνει αντίγραφο) ή ως παράμετρος αναφοράς (με &, η συνάρτηση αλλάζει την πρωτότυπη). Επίσης, οι αλγόριθμοι σειριακής αναζήτησης και ταξινόμησης (φυσαλίδας, εισαγωγής) εφαρμόζονται αυτούσιοι σε πίνακα εγγραφών: συγκρίνουμε ένα πεδίο (το «κλειδί», π.χ. code ή F) αλλά μετακινούμε ολόκληρη την εγγραφή.

Εγγραφή ως παράμετρος αναφοράς και τιμής (Παράδειγμα 8.5)

1struct book {2    string title;3    string author;4    string isbn;5    int quantity;6};7void readBook(book &bk) {          // αναφορά (&): γεμίζει την πρωτότυπη8    getline(cin, bk.title);        // όλη η γραμμή, π.χ. Edgar Allan Poe9    getline(cin, bk.author);10    getline(cin, bk.isbn);11    cin >> bk.quantity;12}13void printBook(book bk) {          // τιμή: αρκεί αντίγραφο για εμφάνιση14    cout << "Book title : " << bk.title << endl;15    cout << "Book quantity : " << bk.quantity << endl;16}

Κανόνας: αν η συνάρτηση πρέπει να τροποποιήσει την εγγραφή (π.χ. να τη γεμίσει), τη δίνουμε με αναφορά. Αν μόνο τη διαβάζει (εμφάνιση, υπολογισμός), αρκεί η παράμετρος τιμής. Μια συνάρτηση μπορεί να επιστρέφει αποτέλεσμα από τα μέλη, π.χ. double calculate(advertising ad){ return ad.total * ad.pct / 100 * ad.amount; }.

Ταξινόμηση εγγραφών με εισαγωγή (Παράδειγμα 8.8)

Ο τελικός βαθμός είναι ο μέσος όρος δύο τετραμήνων στρογγυλοποιημένος: A3[i].F = round((A3[i].t1 + A3[i].t2) / 2.0); (βιβλιοθήκη cmath, το 2.0 αποφεύγει την ακέραια διαίρεση). Η ταξινόμηση σε φθίνουσα σειρά με βάση το F:

1void sort_struct( ) {2    student temp;                    // μεταβλητή τύπου εγγραφής3    int j;4    for (int i=1; i<N; i++){5        temp = A3[i];                // κρατάμε ολόκληρη την εγγραφή6        j = i - 1;7        while (j>=0 && A3[j].F<temp.F){8            A3[j+1] = A3[j];         // μετακίνηση εγγραφής δεξιά9            j--;10        }11        A3[j+1] = temp;12    }13}

Για αύξουσα σειρά αλλάζουμε τη σύγκριση σε A3[j].F > temp.F. Η ταξινόμηση με εισαγωγή είναι ευσταθής: εγγραφές με ίσο κλειδί κρατούν τη σχετική τους σειρά.

Αν ο πίνακας είναι καθολικός

Στο Παράδειγμα 8.8 ο πίνακας A3[N] δηλώνεται εκτός της main, γι’ αυτό η sort_struct() δεν έχει παραμέτρους. Εναλλακτικά: void sort_struct(student A[], int n) — ο πίνακας εγγραφών, όπως κάθε πίνακας, περνά πάντα «με αναφορά».

Συχνά λάθη στις Παγκύπριες

Δηλώνουμε int temp; αντί για student temp; · μετακινούμε μόνο το πεδίο-κλειδί (A3[j+1].F = A3[j].F) και «χαλάμε» τις εγγραφές · παράμετρος τιμής σε συνάρτηση που πρέπει να γεμίσει την εγγραφή · (t1 + t2) / 2 με ακέραια διαίρεση πριν από τη round.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Μια εγγραφή μπορεί να δοθεί σε συνάρτηση τόσο ως παράμετρος τιμής όσο και ως παράμετρος αναφοράς.
Υπόδειξη: Θυμήσου τις readBook και printBook.
Λύση: Σωστό: void readBook(book &bk) (αναφορά) και void printBook(book bk) (τιμή).
Άσκηση 2Βασική
Η συνάρτηση readBook διαβάζει από το πληκτρολόγιο τα μέλη μιας εγγραφής book, ώστε να χρησιμοποιηθούν στη main. Ποια επικεφαλίδα είναι κατάλληλη;
Υπόδειξη: Η συνάρτηση πρέπει να αλλάξει την πρωτότυπη μεταβλητή.
Λύση: Χρειάζεται παράμετρος αναφοράς: book &bk. Με παράμετρο τιμής θα γέμιζε ένα αντίγραφο και η μεταβλητή της main θα έμενε ανέπαφη.
Άσκηση 3Μέτρια
Η συνάρτηση calculate (Παράδειγμα 8.6) επιστρέφει ad.total * ad.pct / 100 * ad.amount και το αποτέλεσμα εμφανίζεται με fixed << setprecision(2). Τι εμφανίζεται για τις εισόδους 60 25.0 2.50 και 80 40 1.25;
Υπόδειξη: 60 διαφημίσεις, 25% προβάλλονται, 2.50 ανά προβολή.
Λύση: $60 \cdot 25 / 100 \cdot 2.5 = 37.5$ → 37.50· $80 \cdot 40/100 \cdot 1.25 = 40$ → 40.00 (η setprecision(2) με fixed δίνει ακριβώς 2 δεκαδικά).

Άσκηση 7Απαιτητική
Ποιος είναι ο τελικός βαθμός F = round((t1 + t2) / 2.0) για τα ζεύγη βαθμών (14, 15) και (18, 18); Τι θα έδινε για το (14, 15) η λανθασμένη έκφραση round((t1 + t2) / 2);
Υπόδειξη: (t1 + t2)/2 με ακέραιους κάνει ακέραια διαίρεση.
Λύση: $29/2.0 = 14.5 \to 15$· $36/2.0 = 18$. Με / 2 η ακέραια διαίρεση δίνει $29/2 = 14$ πριν τη στρογγυλοποίηση, άρα 14.
Άσκηση 8Απαιτητική
