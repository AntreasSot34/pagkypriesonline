9.1

Δισδιάστατοι πίνακες (2D arrays) στη C++: δήλωση, αρχικές τιμές, εισαγωγή και εμφάνιση

📘 Βιβλίο Γ΄ Λυκείου: Γ7.7 §1, §3–5 (σ. 211–215) · Παραδείγματα 7.1, 7.2, 7.5, 7.7

Πώς αποθηκεύουμε έναν πίνακα με γραμμές και στήλες στη C++ — και πώς τον γεμίζουμε και τον εμφανίζουμε με δύο εμφωλευμένους βρόχους for;

Θεωρία

Ο δισδιάστατος πίνακας (2D array) στη C++ αποθηκεύει στοιχεία ίδιου τύπου σε ένα ορθογώνιο πλέγμα κελιών με γραμμές (rows) και στήλες (columns). Κάθε στοιχείο χαρακτηρίζεται από δύο δείκτες: τον δείκτη γραμμής (στο πρώτο ζεύγος αγκυλών) και τον δείκτη στήλης (στο δεύτερο). Είναι η φυσική επιλογή όταν τα δεδομένα έχουν μορφή πίνακα: βαθμοί μαθητών ανά μάθημα, θερμοκρασίες ανά ημέρα και ώρα, ένα ταμπλό παιχνιδιού, ο πίνακας της προπαίδειας.

Δήλωση δισδιάστατου πίνακα

Η δήλωση int arr[5][3]; δεσμεύει μνήμη για $5 \times 3 = 15$ ακέραιους, σε 5 γραμμές και 3 στήλες. Η αρίθμηση και των δύο δεικτών ξεκινά από το 0: οι γραμμές είναι $0..4$ και οι στήλες $0..2$.

Το στοιχείο arr[1][2] βρίσκεται στη 2η γραμμή και στην 3η στήλη.
[0][0][0][1][0][2]
[1][0][1][1][1][2]
[2][0][2][1][2][2]
[3][0][3][1][3][2]
[4][0][4][1][4][2]

Σε πίνακα arr διαστάσεων $N \times M$: πάνω αριστερά είναι το arr[0][0], πάνω δεξιά το arr[0][M-1], κάτω αριστερά το arr[N-1][0] και κάτω δεξιά το arr[N-1][M-1]. Οι διαστάσεις δηλώνονται ως σταθερές: const int ROWS = 3; και const int COLS = 4; — το μέγεθος ενός πίνακα πρέπει να είναι πάντα σταθερά, όχι μεταβλητή που διαβάζεται. (Το βιβλίο γράφει #define ROWS 3 — ισοδύναμο.)

Απόδοση αρχικών τιμών σε δισδιάστατο πίνακα

Εισαγωγή και εμφάνιση με εμφωλευμένους βρόχους for

Ο εξωτερικός βρόχος διατρέχει τις γραμμές (i) και ο εσωτερικός τις στήλες (j). Έτσι τα στοιχεία διαβάζονται «γραμμή προς γραμμή». Στην εμφάνιση, μετά από κάθε εσωτερικό βρόχο αλλάζουμε γραμμή με endl, ενώ η setw(n) (βιβλιοθήκη iomanip) δίνει δεξιά στοίχιση σε $n$ χαρακτήρες.

Παράδειγμα 7.2 — fill_array / print_array
1#include <iostream>2#include <iomanip>        // Για τη χρήση της setw3using namespace std;4const int ROWS = 3;5const int COLS = 4;6void fill_array(int arr[][COLS]){        // μόνο το πλήθος των στηλών7    for (int i=0; i<ROWS; i++)8        for (int j=0; j<COLS; j++)9            cin >> arr[i][j];10}11void print_array(int arr[][COLS]){12    for (int i=0; i<ROWS; i++){13        for (int j=0; j<COLS; j++)14            cout << setw(8) << arr[i][j];  // δεξιά στοίχιση 8 χαρακτήρων15        cout << endl;                      // αλλαγή γραμμής16    }17}18int main(){19    int my_array[ROWS][COLS];20    fill_array(my_array);21    print_array(my_array);22    return 0;23}

Ένας δισδιάστατος πίνακας περνά σε συνάρτηση πάντα ως παράμετρος αναφοράς, χωρίς τον τελεστή &. Στην επικεφαλίδα απαιτείται υποχρεωτικά η διάσταση των στηλών (σταθερά): int arr[][COLS]· επιτρέπεται να δοθούν και οι δύο διαστάσεις.

Πίνακας προπαίδειας (Παράδειγμα 7.5)

Η εντολή arr[i][j] = (i+1)*(j+1); μέσα σε δύο βρόχους $0..9$ γεμίζει τον πίνακα της προπαίδειας: το κελί arr[2][4] παίρνει $3 \cdot 5 = 15$.

Λύση βήμα-βήμα: ανάστροφος πίνακας (Παράδειγμα 7.7)

Ο ανάστροφος $A^T$ προκύπτει αν οι γραμμές γίνουν στήλες. Αρκεί, καθώς διαβάζουμε το A[i][j], να το τοποθετούμε στο AT[j][i]:

cin >> N >> M;for (int i=0; i<N; i++)    for (int j=0; j<M; j++){        cin >> A[i][j];        AT[j][i] = A[i][j];    }for (int i=0; i<M; i++){          // ο AT έχει M γραμμές    for (int j=0; j<N; j++)       // και N στήλες        cout << setw(5) << AT[i][j];    cout << endl;}

Πίνακες εκτός main

Αν ένας πίνακας δηλωθεί εκτός της main (καθολικός), όλα του τα στοιχεία παίρνουν αυτόματα τιμή 0. Αν δηλωθεί μέσα σε συνάρτηση χωρίς αρχικές τιμές, περιέχει «σκουπίδια» και πρέπει να τον αρχικοποιήσουμε εμείς.

Συχνά λάθη στις Παγκύπριες

Γράφουμε arr[i,j] αντί για arr[i][j] · χρησιμοποιούμε i <= ROWS (εκτός ορίων!) · μπερδεύουμε γραμμές και στήλες στον ανάστροφο · ξεχνάμε το endl μετά τον εσωτερικό βρόχο · στην επικεφαλίδα γράφουμε int arr[][] χωρίς τη διάσταση των στηλών.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Πόσα στοιχεία (ακέραιους) αποθηκεύει ο πίνακας που δηλώνεται με int arr[5][3]; και ποιος είναι ο μεγαλύτερος επιτρεπτός δείκτης γραμμής;
Υπόδειξη: Γραμμές × στήλες. Οι δείκτες ξεκινούν από το 0.
Λύση: $5 \times 3 = 15$ στοιχεία. Οι γραμμές αριθμούνται $0, 1, 2, 3, 4$, άρα ο μέγιστος δείκτης γραμμής είναι 4.
Άσκηση 2Βασική
Σε δισδιάστατο πίνακα arr διαστάσεων $N \times M$, ποιο είναι το στοιχείο στην κάτω δεξιά γωνία;
Υπόδειξη: Κάτω = μεγαλύτερος δείκτης γραμμής, δεξιά = μεγαλύτερος δείκτης στήλης· οι δείκτες ξεκινούν από το 0.
Λύση: Η κάτω γραμμή έχει δείκτη $N-1$ και η δεξιά στήλη $M-1$: arr[N-1][M-1]. Το arr[N][M] είναι εκτός ορίων και το arr[N-1][0] είναι η κάτω αριστερή γωνία.

Άσκηση 9Απαιτητική
Ποια επικεφαλίδα συνάρτησης δέχεται σωστά ως παράμετρο τον πίνακα int my_array[ROWS][COLS]; (όπου ROWS, COLS σταθερές, π.χ. const int COLS = 4;);
Υπόδειξη: Ποια διάσταση είναι υποχρεωτική; Χρειάζεται &;
