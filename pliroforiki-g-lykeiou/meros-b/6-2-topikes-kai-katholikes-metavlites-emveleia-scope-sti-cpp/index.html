6.2

Τοπικές και καθολικές μεταβλητές – εμβέλεια (scope) στη C++

📘 Βιβλίο Γ΄ Λυκείου: Γ7.4 §5 Τοπικές (local) και καθολικές (global) μεταβλητές (σ. 134–136)

Ποια είναι η διαφορά ανάμεσα σε τοπική και καθολική μεταβλητή και ποια μεταβλητή «βλέπει» κάθε συνάρτηση όταν δύο μεταβλητές έχουν το ίδιο όνομα;

Θεωρία

Κάθε μεταβλητή έχει εμβέλεια (scope) ή πεδίο εφαρμογής: το τμήμα του προγράμματος μέσα στο οποίο είναι γνωστή και μπορεί να χρησιμοποιηθεί. Στη C++ διακρίνουμε τις τοπικές μεταβλητές (local variables), που δηλώνονται μέσα σε μια συνάρτηση, και τις καθολικές μεταβλητές (global variables), που δηλώνονται έξω από όλες τις συναρτήσεις — συνήθως αμέσως μετά το using namespace std;.

Τοπική μεταβλητή (local)

Δηλώνεται μέσα στο σώμα μιας συνάρτησης (και η main είναι συνάρτηση!) και είναι προσβάσιμη μόνο εκεί. Δημιουργείται όταν καλείται η συνάρτηση και «χάνεται» όταν αυτή τερματίσει. Οι τυπικές παράμετροι συμπεριφέρονται επίσης ως τοπικές μεταβλητές της συνάρτησης. Δύο διαφορετικές συναρτήσεις μπορούν να έχουν τοπικές μεταβλητές με το ίδιο όνομα χωρίς καμία σχέση μεταξύ τους.

Καθολική μεταβλητή (global)

Δηλώνεται εκτός της main και των άλλων συναρτήσεων και είναι προσβάσιμη από την κύρια συνάρτηση και από όλες τις συναρτήσεις που ορίζονται μετά τη δήλωσή της. Μια αλλαγή της τιμής της μέσα σε μια συνάρτηση φαίνεται παντού. Αν δεν δοθεί αρχική τιμή, μια καθολική μεταβλητή τύπου int ξεκινά με 0.

Παράδειγμα του βιβλίου: άθροισμα ψηφίων με καθολικό μετρητή

digits.cpp
1#include <iostream>2using namespace std;3int cnt = 0;                       // καθολική μεταβλητή - μετρητής4int sum_of_digits(int x) {5    int temp = x, sum = 0;         // τοπικές μεταβλητές6    while (temp > 0) {7        sum += temp % 10;8        temp /= 10;9    }10    cnt++;                         // αλλάζει την καθολική cnt11    return sum;12}13int main() {14    int num, total = 0;            // τοπικές της main15    cin >> num;16    while (num != 0) {17        total += sum_of_digits(num);18        cin >> num;19    }20    cout << total << " " << cnt;21    return 0;22}
Λύση βήμα-βήμα (είσοδος 25 103 7 0)

Η cnt είναι καθολική: η sum_of_digits την αυξάνει και η main βλέπει την ίδια μεταβλητή. Οι temp, sum δεν είναι προσβάσιμες από τη main.

Ίδιο όνομα: η τοπική «κρύβει» την καθολική

Αν μέσα σε μια συνάρτηση δηλωθεί τοπική μεταβλητή με το ίδιο όνομα με μια καθολική, τότε μέσα σε εκείνη τη συνάρτηση το όνομα αναφέρεται στην τοπική (η καθολική «επισκιάζεται» – shadowing). Η καθολική δεν αλλάζει.

scope.cpp
1#include <iostream>2using namespace std;3int x = 10;                  // καθολική x4void f() {5    int x = 3;               // τοπική x της f: κρύβει την καθολική6    x++;7    cout << x << " ";8}9void g() {10    x++;                     // δεν υπάρχει τοπική x: αλλάζει η καθολική11    cout << x << " ";12}13int main() {14    f();15    g();16    cout << x << endl;17    return 0;18}
Οθόνη (έξοδος)
4 11 11

Πότε καθολική;

Οι καθολικές μεταβλητές βολεύουν για τιμές που μοιράζονται πολλές συναρτήσεις (μετρητές, το πλήθος στοιχείων ενός πίνακα, ροές αρχείων ifstream/ofstream). Όμως κάνουν το πρόγραμμα δυσκολότερο στον έλεγχο: όποια συνάρτηση τις αλλάξει, επηρεάζει όλες τις υπόλοιπες. Γενικά προτιμάμε παραμέτρους και τοπικές μεταβλητές.

Συχνά λάθη στις Παγκύπριες

  • Χρήση στη main μιας μεταβλητής που δηλώθηκε μόνο μέσα σε συνάρτηση → σφάλμα μεταγλώττισης «not declared in this scope».
  • Στην προκαταρκτική εκτέλεση ξεχνάμε ότι η καθολική κρατά την τιμή της από κλήση σε κλήση, ενώ οι τοπικές ξαναπαίρνουν αρχική τιμή σε κάθε κλήση.
  • Με τοπική μεταβλητή ίδιου ονόματος αλλάζουμε κατά λάθος την καθολική στον πίνακα τιμών — η καθολική μένει ίδια.
  • Σύνθετες συνθήκες: στο if (a > 3 && f(a)) η f δεν καλείται όταν το a > 3 είναι ψευδές (βραχυκύκλωμα), άρα δεν αλλάζει καμία καθολική.

Πειραματίσου

scope.cpp
1#include <iostream>2using namespace std;3int x = 10;4void f() {5    int x = 3;6    x++;7    cout << x << " ";8}9void g() {10    x++;11    cout << x << " ";12}13int main() {14    f();15    g();16    f();17    cout << x << endl;18    return 0;19}

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Μια τοπική μεταβλητή που δηλώνεται μέσα σε μια συνάρτηση είναι προσβάσιμη και από την κύρια συνάρτηση main.
Υπόδειξη: Πού είναι γνωστή μια τοπική μεταβλητή;
Λύση: ΛΑΘΟΣ. Η τοπική μεταβλητή είναι γνωστή μόνο μέσα στη συνάρτηση όπου δηλώθηκε.
Άσκηση 2Βασική
Μια καθολική μεταβλητή δηλώνεται έξω από όλες τις συναρτήσεις και είναι προσβάσιμη τόσο από τη main όσο και από τις συναρτήσεις του προγράμματος.
Υπόδειξη: Global = …
Λύση: ΣΩΣΤΟ. Αυτός είναι ακριβώς ο ορισμός της καθολικής (global) μεταβλητής.
Άσκηση 3Βασική
Στη συνάρτηση int sum_of_digits(int x) { int temp = x, sum = 0; … cnt++; return sum; }, όπου η cnt δηλώνεται πριν από τη συνάρτηση έξω από τη main, ποιες είναι οι τοπικές μεταβλητές της συνάρτησης;
Υπόδειξη: Η cnt δηλώθηκε έξω από τις συναρτήσεις.
Λύση: Οι temp, sum δηλώνονται στο σώμα της συνάρτησης → τοπικές· η τυπική παράμετρος x είναι επίσης τοπική. Η cnt είναι καθολική.
Άσκηση 4Μέτρια
Τι θα εμφανίσει το πρόγραμμα με είσοδο 25 103 7 0;
1#include <iostream>2using namespace std;3int cnt = 0;4int sum_of_digits(int x) {5    int temp = x, sum = 0;6    while (temp > 0) {7        sum += temp % 10;8        temp /= 10;9    }10    cnt++;11    return sum;12}13int main() {14    int num, total = 0;15    cin >> num;16    while (num != 0) {17        total += sum_of_digits(num);18        cin >> num;19    }20    cout << total << " " << cnt;21    return 0;22}
Υπόδειξη: Αθροίσματα ψηφίων: 25 → 7, 103 → 4, 7 → 7. Η cnt αυξάνεται σε κάθε κλήση.
Λύση: $total = 7 + 4 + 7 = 18$ και η καθολική cnt έγινε 3 (τρεις κλήσεις· για το 0 ο βρόχος σταματά χωρίς κλήση).
Οθόνη (έξοδος)
18 3
Άσκηση 5Μέτρια
Τι θα εμφανίσει το πρόγραμμα;
1#include <iostream>2using namespace std;3int x = 10;4void f() {5    int x = 3;6    x++;7    cout << x << " ";8}9void g() {10    x++;11    cout << x << " ";12}13int main() {14    f();15    g();16    f();17    cout << x << endl;18    return 0;19}
Υπόδειξη: Η f έχει δική της τοπική x που ξαναγίνεται 3 σε κάθε κλήση.
Λύση: f(): τοπική x = 3 → 4, εμφανίζει 4. g(): καθολική x = 10 → 11, εμφανίζει 11. f(): ξανά τοπική 3 → 4. Τέλος η main εμφανίζει την καθολική 11.
Οθόνη (έξοδος)
4 11 4 11
Άσκηση 6Μέτρια
Τι θα συμβεί κατά τη μεταγλώττιση;
1#include <iostream>2using namespace std;3void calc() {4    int result = 5 * 4;5}6int main() {7    calc();8    cout << result;9    return 0;10}
Υπόδειξη: Πού δηλώθηκε η result;
Λύση: Η result ζει μόνο μέσα στην calc· στη main είναι άγνωστη («'result' was not declared in this scope»). Λύση: η calc να επιστρέφει την τιμή (int calc() { return 5 * 4; } και cout << calc();).
Άσκηση 7Απαιτητική
Τι θα εμφανίσει το πρόγραμμα;
1#include <iostream>2using namespace std;3int total = 0;4void add(int v) {5    total += v;6}7int twice(int v) {8    int total = v * 2;9    return total;10}11int main() {12    add(4);13    add(twice(3));14    cout << total << " " << twice(total) << endl;15    return 0;16}
Υπόδειξη: Η twice έχει τοπική total· η add αλλάζει την καθολική.
Λύση:
εντολήκαθολική totalεπιστρέφει
add(4)4
twice(3)4 (η τοπική total = 6)6
add(6)10
twice(10)1020

Άσκηση 8Απαιτητική
Τι θα εμφανίσει το πρόγραμμα; Προσοχή στη σύνθετη συνθήκη.
1#include <iostream>2using namespace std;3int cnt = 0;4bool even(int n) {5    cnt++;6    return n % 2 == 0;7}8int main() {9    int p = 0;10    for (int i = 1; i <= 7; i++)11        if (i > 3 && even(i))12            p++;13    cout << p << " " << cnt << endl;14    return 0;15}
Υπόδειξη: Στο &&, αν το πρώτο σκέλος είναι ψευδές, το δεύτερο (η κλήση) δεν υπολογίζεται.
Λύση: Για $i = 1, 2, 3$ το i > 3 είναι ψευδές, άρα η even δεν καλείται. Για $i = 4, 5, 6, 7$ καλείται 4 φορές (cnt = 4) και επιστρέφει true για 4 και 6 (p = 2).

2 4
Άσκηση 9Βασική
Τι ονομάζουμε εμβέλεια (scope) ή πεδίο εφαρμογής μιας μεταβλητής;
Υπόδειξη: Scope = «πού είναι ορατή».
Λύση: Εμβέλεια είναι η περιοχή του κώδικα όπου το όνομα της μεταβλητής είναι ορατό: για μια τοπική, το σώμα της συνάρτησης· για μια καθολική, όλο το πρόγραμμα μετά τη δήλωσή της.

1#include <iostream>2using namespace std;3int c = 1;4int f(int x) {5    c = c + 6;6    return x * 3 + c;7}8int main() {9    int a = f(8);10    int b = f(8);11    cout << a << " " << b << " " << c << endl;12    return 0;13}
