11.1

Στοίβα (stack) στη C++: push, pop, top – υλοποίηση με πίνακα και STL

📘 Βιβλίο Γ΄ Λυκείου: Γ7.9 §1–6 Αφηρημένοι τύποι δεδομένων – Στοίβα (σ. 273–288)

Τι είναι η στοίβα (stack) και η αρχή LIFO, και πώς υλοποιούμε τις λειτουργίες push, pop, top σε C++ με πίνακα ή με τη βιβλιοθήκη STL;

Θεωρία

Εκτός εξεταστέας ύλης Παγκυπρίων 2025-26

Το κεφάλαιο Γ7.9 (στοίβα και ουρά) δεν περιλαμβάνεται στην ύλη των Παγκυπρίων Εξετάσεων 2025-26 — είναι χρήσιμο για τις σχολικές εξετάσεις και ως εξάσκηση σε συναρτήσεις και πίνακες.

Ένας αφηρημένος τύπος δεδομένων (abstract data type) είναι ένα σύνολο στοιχείων μαζί με τις λειτουργίες που εφαρμόζονται σε αυτά. Για να τον υλοποιήσουμε χρησιμοποιούμε μια δομή δεδομένων: μια δομή αποθήκευσης (π.χ. πίνακα) και συναρτήσεις, μία για κάθε λειτουργία. Η πιο γνωστή τέτοια δομή είναι η στοίβα (stack).

Στοίβα – αρχή LIFO

Στοίβα είναι μια συλλογή στοιχείων στην οποία τα νέα στοιχεία προστίθενται και αφαιρούνται μόνο από τη μία άκρη, την κορυφή (top) — όπως μια στοίβα από πιάτα. Είναι δομή LIFO (Last-In-First-Out): το στοιχείο που μπήκε τελευταίο βγαίνει πρώτο.

Λειτουργίες: δημιουργία (κενή στοίβα), Push(X) εισαγωγή του X στην κορυφή, Pop() εξαγωγή του στοιχείου της κορυφής, Empty() true αν είναι κενή, Top() επιστρέφει το στοιχείο της κορυφής χωρίς να το αφαιρεί, Size() το πλήθος των στοιχείων.

Υλοποίηση στοίβας με πίνακα και συναρτήσεις

Χρησιμοποιούμε έναν πίνακα σταθερού μεγέθους και μια καθολική μεταβλητή top με τη θέση της κορυφής· αρχικά top = -1 (κενή στοίβα). Αν η στοίβα είναι γεμάτη (top == N-1) έχουμε υπερχείλιση· αν είναι άδεια και ζητηθεί Pop, κατάσταση εξαίρεσης.

stack_array.cpp
1#include <iostream>2using namespace std;3const int ARR_SIZE = 5;4int top = -1;                          // θέση κορυφής: -1 = κενή στοίβα5void Push(int arr[], int X, int N) {6    if (top == N - 1)7        cout << "Stack is full" << endl;8    else {9        top++;10        arr[top] = X;11        cout << "Pushed item " << X << endl;12    }13}14bool Empty() {15    if (top == -1)16        return true;17    else18        return false;19}20void Pop() {21    if (Empty())22        cout << "Stack is empty" << endl;23    else24        top--;25}26int Size() {27    return top + 1;28}29int Top(int arr[]) {30    return arr[top];31}32int main() {33    int mystack[ARR_SIZE];34    for (int x = 10; x <= 60; x += 10)35        Push(mystack, x, ARR_SIZE);36    Pop();37    Pop();38    cout << "Top: " << Top(mystack) << " Size: " << Size() << endl;39    return 0;40}

Το Pop απλώς μειώνει το top: το στοιχείο μένει στον πίνακα, αλλά θεωρείται «αφαιρεμένο».

Στοίβα μέσω της βιβλιοθήκης STL

Με #include <stack> δηλώνουμε στοίβα οποιουδήποτε βασικού τύπου (stack<int> S;, stack<char>, stack<string>) και χρησιμοποιούμε τις μεθόδους push(item), pop(), top(), empty(), size() με τελεία: S.push(5);.

binary_stack.cpp
1#include <iostream>2#include <stack>3using namespace std;4int main() {5    stack<int> binary;6    int num = 35;7    while (num > 0) {              // δεκαδικό → δυαδικό με στοίβα8        binary.push(num % 2);9        num /= 2;10    }11    while (!binary.empty()) {      // τα υπόλοιπα βγαίνουν ανάποδα12        cout << binary.top();13        binary.pop();14    }15    return 0;16}
Οθόνη (έξοδος)
100011

Σημείωση για τη βιβλιοθήκη <stack>

Η βιβλιοθήκη <stack> (STL) παρουσιάζεται εδώ μόνο επειδή υπάρχει στο κεφάλαιο Γ7.9, που είναι εκτός εξεταστέας ύλης. Στις λύσεις των θεμάτων των Παγκυπρίων χρησιμοποιούμε μόνο τις βιβλιοθήκες iostream, fstream, string, iomanip, cmath, climits.

Η STL στοίβα δεν εμφανίζει μήνυμα όταν κάνουμε pop() σε άδεια στοίβα, και το top() σε άδεια στοίβα είναι σφάλμα· γι' αυτό ελέγχουμε πάντα πρώτα με empty(). Άλλες κλασικές εφαρμογές: αντιστροφή λέξεων, έλεγχος ισορροπημένων παρενθέσεων.

Ασκήσεις — 0/6 λυμένες

Άσκηση 1Βασική
Η στοίβα είναι δομή τύπου:
Υπόδειξη: Στοίβα από πιάτα.
Λύση: LIFO (Last-In-First-Out): προσθέτουμε και αφαιρούμε μόνο από την κορυφή.
Άσκηση 2Βασική
Μια στοίβα περιέχει (από κάτω προς τα πάνω) 3, 7, 6. Εκτελούνται με τη σειρά: Push(5), Push(4), Pop(), Push(9), Pop(), Pop(), Push(2). Ποιο είναι το στοιχείο της κορυφής και το μέγεθος;
Υπόδειξη: Κάθε Pop αφαιρεί το πιο πρόσφατο στοιχείο.
Λύση: 3,7,6 → 3,7,6,5 → 3,7,6,5,4 → 3,7,6,5 → 3,7,6,5,9 → 3,7,6,5 → 3,7,6 → 3,7,6,2. Κορυφή 2, μέγεθος 4.
Άσκηση 3Μέτρια
Τι θα εμφανίσει το πρόγραμμα; (σε μία γραμμή)
1#include <iostream>2#include <stack>3using namespace std;4int main() {5    stack<char> mystack;6    mystack.push('A');7    mystack.push('B');8    mystack.push('C');9    cout << mystack.top() << endl;10    mystack.pop();11    cout << mystack.top() << " " << mystack.size() << endl;12    return 0;13}
Υπόδειξη: Το top() δεν αφαιρεί το στοιχείο.
Λύση: Κορυφή C· μετά το pop η κορυφή είναι B και το μέγεθος 2.

1#include <iostream>2#include <stack>3using namespace std;4int main() {5    stack<int> binary;6    int num = 44;7    while (num > 0) {8        binary.push(num % 2);9        num /= 2;10    }11    while (!binary.empty()) {12        cout << binary.top();13        binary.pop();14    }15    return 0;16}
Υπόδειξη: Υπόλοιπα διαίρεσης με το 2: 0, 0, 1, 1, 0, 1 — βγαίνουν ανάποδα.
Λύση: 44 → υπόλοιπα 0, 0, 1, 1, 0, 1 (push με αυτή τη σειρά). Η στοίβα τα βγάζει αντίστροφα: 101100 = $44_{10}$ στο δυαδικό.

Άσκηση 5Απαιτητική
Τι θα εμφανίσει το πρόγραμμα; (γράψτε όλες τις γραμμές σε μία)
1#include <iostream>2using namespace std;3const int ARR_SIZE = 3;4int top = -1;5void Push(int arr[], int X, int N) {6    if (top == N - 1)7        cout << "Stack is full" << endl;8    else {9        top++;10        arr[top] = X;11        cout << "Pushed item " << X << endl;12    }13}14void Pop() {15    if (top == -1)16        cout << "Stack is empty" << endl;17    else18        top--;19}20int main() {21    int s[ARR_SIZE];22    Push(s, 7, ARR_SIZE);23    Pop();24    Pop();25    Push(s, 8, ARR_SIZE);26    Push(s, 9, ARR_SIZE);27    cout << s[top] << " " << top + 1 << endl;28    return 0;29}
Υπόδειξη: Μετά το πρώτο Pop η στοίβα είναι άδεια (top = −1).
Λύση: top: −1 → 0 (7) → −1 → (άδεια: μήνυμα) → 0 (8) → 1 (9). Κορυφή 9, μέγεθος 2.

Άσκηση 6Μέτρια
Η λειτουργία Top() μιας στοίβας αφαιρεί το στοιχείο της κορυφής και το επιστρέφει.
Υπόδειξη: Ποια λειτουργία αφαιρεί;
Λύση: ΛΑΘΟΣ. Η Top() επιστρέφει το στοιχείο της κορυφής χωρίς να το αφαιρέσει· την αφαίρεση την κάνει η Pop().
