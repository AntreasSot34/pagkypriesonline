10.2

Πίνακες εγγραφών και ένθετες εγγραφές στη C++

📘 Βιβλίο Γ΄ Λυκείου: Γ7.8 §6–7 (σ. 248–252) · Παραδείγματα 8.1–8.4

Πώς αποθηκεύουμε τα στοιχεία 20 μαθητών ή 200 προϊόντων — με έναν πίνακα εγγραφών αντί για πολλούς παράλληλους πίνακες;

Θεωρία

Μία μεταβλητή εγγραφής κρατά τα στοιχεία ενός αντικειμένου. Για πολλά αντικείμενα ορίζουμε έναν πίνακα εγγραφών: κάθε θέση του πίνακα είναι μια ολόκληρη εγγραφή. Έτσι αντικαθιστούμε πολλούς παράλληλους πίνακες (κωδικοί, ονόματα, τιμές…) με έναν, και ο κώδικας γίνεται πιο σύντομος και καθαρός — ιδιαίτερα στην ταξινόμηση. Επιπλέον, μια εγγραφή μπορεί να περιέχει ως μέλος άλλη εγγραφή: πρόκειται για τις ένθετες εγγραφές.

Πίνακας εγγραφών

struct product {    int code, quantity;    string description;    double price;} fruit[3];               // πίνακας 3 εγγραφών τύπου product// ή, μετά τον ορισμό:  product fruit[3];

Η αναφορά σε μέλος γίνεται με δείκτη και τελεία: fruit[i].price (η τιμή του προϊόντος στη θέση i). Προσοχή: ο δείκτης μπαίνει μετά το όνομα του πίνακα, όχι μετά το μέλος.

Καταχώριση με δομή επανάληψης (Παράδειγμα 8.1)

Ένθετες εγγραφές

Μια εγγραφή μπορεί να είναι μέλος άλλης εγγραφής. Η ένθετη εγγραφή πρέπει να έχει οριστεί πρώτα. Η πρόσβαση γίνεται ιεραρχικά, με επιπρόσθετη τελεία, και δεν υπάρχει όριο στο βάθος ένθεσης.

struct date {          // πρώτα η ένθετη εγγραφή    int dd;    int mm;    int yy;};struct member {    int code;    string email;    date dob;          // μέλος τύπου date} mem[50];
mem[i] : member
.code11
.emailnikos@mail.com
dob : date
.dd5
.mm9
.yy2005

Η ημέρα γέννησης του μέλους στη θέση i είναι mem[i].dob.dd.

Λύση βήμα-βήμα: email όσων γεννήθηκαν στις 5/9/2005 (Παράδειγμα 8.4) 
for (int i=0; i<50; i++){    cin >> mem[i].code >> mem[i].email;    cin >> mem[i].dob.dd >> mem[i].dob.mm >> mem[i].dob.yy;}for (int i=0; i<50; i++)    if (mem[i].dob.dd==5 && mem[i].dob.mm==9 && mem[i].dob.yy==2005)        cout << mem[i].email << endl;

Πρώτα καταχωρίζονται όλα τα δεδομένα και μετά γίνεται ένα δεύτερο πέρασμα με τη σύνθετη συνθήκη (τρία &&).

Συχνά λάθη στις Παγκύπριες

B3.am[i] αντί για B3[i].am · ορισμός της ένθετης εγγραφής μετά την εγγραφή που την περιέχει · mem[i].dd αντί για mem[i].dob.dd · σύγκριση συμβολοσειράς με μονά εισαγωγικά ('Nicosia') αντί για διπλά.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Με τις εγγραφές date και member της θεωρίας, ποια έκφραση δίνει τον μήνα γέννησης του τρίτου μέλους του πίνακα mem;
Υπόδειξη: Οι δείκτες ξεκινούν από το 0· ο μήνας είναι μέλος της ένθετης dob.
Λύση: mem[2] = το μέλος με δείκτη 2, .dob = η ένθετη εγγραφή, .mm = ο μήνας: mem[2].dob.mm.
Άσκηση 2Βασική
Η ένθετη εγγραφή (π.χ. date) πρέπει να έχει οριστεί πριν από την εγγραφή που τη χρησιμοποιεί ως μέλος (π.χ. member).
Υπόδειξη: Μπορεί ο μεταγλωττιστής να χρησιμοποιήσει έναν τύπο που δεν γνωρίζει ακόμη;
Λύση: Σωστό: ο τύπος date πρέπει να είναι ήδη γνωστός όταν δηλώνεται το μέλος date dob;.
Άσκηση 3Βασική
Ποια εντολή διαβάζει σωστά τον αριθμό μητρώου του μαθητή i στον πίνακα εγγραφών student B3[20];
Υπόδειξη: πίνακας[δείκτης].μέλος
Λύση: Ο δείκτης ακολουθεί το όνομα του πίνακα και μετά η τελεία με το μέλος: B3[i].am.

Άσκηση 8Απαιτητική
Πρόγραμμα (Παράδειγμα 8.2) διαβάζει τις διαστάσεις 3 ορθογωνίων στον πίνακα εγγραφών rectangle[3] (μέλη height, width) και εμφανίζει εμβαδόν (E) και περίμετρο (P). Για είσοδο 2 5, 3.5 4, 6 1.5, τι εμφανίζεται για το Rectangle 2;
1cout << "E: " << rectangle[i].height*rectangle[i].width << " ";2cout << "P: " << (rectangle[i].height+rectangle[i].width)*2;
Υπόδειξη: Το Rectangle 2 είναι το rectangle[1] (εμφανίζεται i+1).
Λύση: rectangle[1]: height = 3.5, width = 4 → E = 14, P = (3.5 + 4)·2 = 15.
Οθόνη (έξοδος)
Rectangle 2
E: 14 P: 15
Άσκηση 9Απαιτητική
Ποιο είναι το κύριο πλεονέκτημα ενός πίνακα εγγραφών έναντι πολλών παράλληλων πινάκων;
Υπόδειξη: Σκέψου τι γίνεται όταν ανταλλάσσουμε δύο αντικείμενα.
Λύση: Με παράλληλους πίνακες, κάθε ανταλλαγή πρέπει να γίνει σε όλους τους πίνακες. Με πίνακα εγγραφών αρκεί temp = A[j]; A[j] = A[j+1]; A[j+1] = temp;. Το βιβλίο σημειώνει ότι έτσι «μειώνεται κατά πολύ η έκταση του κώδικα».
