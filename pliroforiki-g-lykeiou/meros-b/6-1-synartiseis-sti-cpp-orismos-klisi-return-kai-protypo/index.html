Συναρτήσεις στη C++: ορισμός, κλήση, return και πρότυπο συνάρτησης

📘 Βιβλίο Γ΄ Λυκείου: Γ7.4 §1–4 Τμηματικός προγραμματισμός, ορισμός και κλήση, εναλλακτικός ορισμός (σ. 131–134)

Τι είναι μια συνάρτηση (function) στη C++, πώς τη γράφουμε, πώς την καλούμε από τη main και τι ακριβώς κάνει η εντολή return;

Θεωρία

Στις συναρτήσεις στη C++ στηρίζεται ο τμηματικός προγραμματισμός (modular programming): ένα μεγάλο πρόβλημα το «σπάμε» σε μικρότερα, αυτόνομα κομμάτια κώδικα, τα υποπρογράμματα, που το καθένα εκτελεί ένα συγκεκριμένο έργο και ορίζεται ξεχωριστά από την κύρια συνάρτηση main. Έτσι αποφεύγουμε να γράφουμε τις ίδιες εντολές πολλές φορές, ο κώδικας γίνεται πιο σύντομος και κατανοητός, και η αποσφαλμάτωση (debugging) γίνεται ευκολότερα, αφού ελέγχουμε κάθε κομμάτι χωριστά. Για παράδειγμα, ένα πρόγραμμα βαθμολογίας χωρίζεται φυσικά σε τρία υποπρογράμματα: καταχώριση δεδομένων, επεξεργασία και εμφάνιση αποτελεσμάτων.

Συνάρτηση (function)

Συνάρτηση είναι ένας τύπος υποπρογράμματος που δέχεται (προαιρετικά) τιμές μέσω παραμέτρων, εκτελεί τις εντολές του σώματός της και επιστρέφει μία τιμή με την εντολή return σε αυτόν που την κάλεσε. Για κάθε συνάρτηση ορίζουμε:

  • Τύπο επιστρεφόμενης τιμής: int, double, float, char, bool, string… ή void αν δεν επιστρέφει τιμή.
  • Όνομα (αναγνωριστικό): ίδιοι κανόνες ονοματολογίας με τις μεταβλητές.
  • Τυπικές παραμέτρους: μεταβλητές με τον τύπο τους, μέσα στις παρενθέσεις· μπορεί να είναι μηδέν ή περισσότερες.
add.cpp
1#include <iostream>2using namespace std;3int add_2_nums(int a, int b) {     // επικεφαλίδα: τύπος, όνομα, τυπικές παράμετροι4    return a + b;                  // επιστροφή του αθροίσματος5}6int main() {7    cout << add_2_nums(65, 97);    // κλήση με πραγματικές παραμέτρους 65, 978    return 0;9}
Οθόνη (έξοδος)
162

Επικεφαλίδα, σώμα και κλήση

Από την επικεφαλίδα int add_2_nums(int a, int b) καταλαβαίνουμε ότι η συνάρτηση επιστρέφει ακέραιο, λέγεται add_2_nums και δέχεται δύο ακέραιες τυπικές παραμέτρους a, b. Το σώμα είναι οι εντολές μέσα στα άγκιστρα.

Στην κλήση add_2_nums(65, 97) οι πραγματικές παράμετροι (ορίσματα) 65 και 97 αντιστοιχίζονται με τη σειρά στις τυπικές: a = 65, b = 97. Η εκτέλεση «πηδά» στο σώμα της συνάρτησης, υπολογίζει την τιμή, την επιστρέφει και η main συνεχίζει από το σημείο της κλήσης. Η κλήση πρέπει να έχει το ίδιο όνομα, το ίδιο πλήθος και τον ίδιο τύπο παραμέτρων με τον ορισμό.

Η εντολή return τερματίζει τη συνάρτηση

Μόλις εκτελεστεί ένα return, η συνάρτηση τερματίζει αμέσως και επιστρέφει την τιμή. Αν υπάρχουν πολλά return, θα εκτελεστεί μόνο ένα. Γι' αυτό στο παρακάτω παράδειγμα (Παράδειγμα 4.1 του βιβλίου) το else μπορεί να παραλειφθεί:

max_num
1int max_num(int a, int b) {2    if (a > b)3        return a;      // αν a>b, επιστρέφει a και ΤΕΡΜΑΤΙΖΕΙ4    return b;          // εκτελείται μόνο αν a<=b5}

Συνάρτηση τύπου void δεν επιστρέφει τιμή (δεν χρειάζεται return με τιμή) — π.χ. μια συνάρτηση που απλώς τυπώνει μηνύματα. Μια τέτοια συνάρτηση καλείται ως αυτόνομη εντολή: say_hello();.

Εναλλακτικός ορισμός: πρότυπο (prototype) συνάρτησης

Μια συνάρτηση πρέπει να είναι γνωστή στον μεταγλωττιστή πριν κληθεί. Δύο τρόποι: (α) γράφουμε ολόκληρο τον ορισμό πάνω από τη main, ή (β) δηλώνουμε μόνο το πρότυπο (την επικεφαλίδα με ;) πριν από τη main και γράφουμε τον ορισμό μετά τη main.

prototype.cpp
1#include <iostream>2using namespace std;3int max_num(int a, int b);            // πρότυπο συνάρτησης (τελειώνει με ;)4int main() {5    int num1, num2;6    cin >> num1 >> num2;7    cout << max_num(num1, num2);8    return 0;9}10int max_num(int a, int b) {           // ορισμός μετά τη main11    if (a > b)12        return a;13    return b;14}
Οθόνη (είσοδος: 8 13)
13

Παραγοντικό με συνάρτηση: x = y! + z!

Χωρίς συνάρτηση θα γράφαμε δύο φορές τον ίδιο βρόχο. Με τη συνάρτηση factorial τον γράφουμε μία φορά και τον «καλούμε» όσες φορές θέλουμε (Παράδειγμα 4.2).

factorial.cpp
1#include <iostream>2using namespace std;3int factorial(int N) {4    int ans = 1;                  // τοπική μεταβλητή5    for (int i = 1; i <= N; i++)6        ans *= i;7    return ans;8}9int main() {10    int y, z;11    cin >> y >> z;12    int x = factorial(y) + factorial(z);13    cout << x << endl;14    return 0;15}
Λύση βήμα-βήμα (είσοδος 3 4)
κλήσηNiansεπιστρέφει
factorial(3)31, 2, 31 → 1 → 2 → 66
factorial(4)41, 2, 3, 41 → 1 → 2 → 6 → 2424

$x = 6 + 24 = 30$.

Οθόνη (έξοδος)
30

Συχνά λάθη στις Παγκύπριες

  • Κλήση με λάθος πλήθος/τύπο παραμέτρων ή με int μέσα στην κλήση: max_num(int a, int b) ✗ → max_num(a, b) ✓.
  • Ξεχνάμε το ; στο πρότυπο ή το βάζουμε στην επικεφαλίδα του ορισμού (int f(int x); { ✗).
  • Νομίζουμε ότι εκτελούνται όλα τα return: το πρώτο που συναντάμε τερματίζει τη συνάρτηση.
  • Συνάρτηση μη-void που σε κάποια διαδρομή δεν επιστρέφει τιμή.
  • Η τιμή που επιστρέφεται δεν τυπώνεται μόνη της: πρέπει να την εμφανίσουμε (cout << f(3);) ή να την αποθηκεύσουμε (x = f(3);).

Πειραματίσου

max_num.cpp
1#include <iostream>2using namespace std;3int max_num(int a, int b) {4    if (a > b)5        return a;6    return b;7}8int main() {9    int num1, num2;10    cin >> num1 >> num2;11    cout << max_num(num1, num2);12    return 0;13}
Βήμα 1/9. Η εκτέλεση ξεκινά πάντα από τη main — οι ορισμοί συναρτήσεων πάνω από αυτήν δεν εκτελούνται μέχρι να κληθούν.

Άσκηση 1Βασική
Δίνεται η επικεφαλίδα double avg(int a, int b, int c). Ποια πρόταση είναι σωστή;
Υπόδειξη: Ο τύπος πριν από το όνομα είναι ο τύπος της επιστρεφόμενης τιμής.
Λύση: Το double μπροστά από το όνομα δηλώνει ότι επιστρέφεται ένας πραγματικός αριθμός· μέσα στις παρενθέσεις υπάρχουν τρεις τυπικές παράμετροι τύπου int. Μια συνάρτηση με return επιστρέφει πάντα μία τιμή.
Άσκηση 2Βασική
Όταν μια συνάρτηση περιέχει περισσότερες από μία εντολές return, κατά την εκτέλεσή της εκτελούνται όλες με τη σειρά.
Υπόδειξη: Τι γίνεται αμέσως μόλις εκτελεστεί ένα return;
Λύση: ΛΑΘΟΣ. Με την εκτέλεση της εντολής return η συνάρτηση τερματίζει, άρα σε κάθε κλήση εκτελείται μόνο ένα return.
Άσκηση 3Βασική
Τι θα εμφανίσει το πρόγραμμα;
1#include <iostream>2using namespace std;3int add_2_nums(int a, int b) {4    return a + b;5}6int main() {7    cout << add_2_nums(23, 19) * 2;8    return 0;9}
Υπόδειξη: Πρώτα υπολογίζεται η κλήση, μετά ο πολλαπλασιασμός.
Λύση: $a = 23$, $b = 19$, η συνάρτηση επιστρέφει $42$ και η main εμφανίζει $42 \cdot 2 = 84$.

Για $x = 250$ το πρώτο return τερματίζει τη συνάρτηση, οπότε ο δεύτερος έλεγχος δεν γίνεται καν.
Άσκηση 5Μέτρια
Θέλουμε συνάρτηση caps που δέχεται έναν χαρακτήρα και επιστρέφει true αν είναι κεφαλαίο γράμμα, αλλιώς false. Ποιο είναι το σωστό πρότυπο;
Υπόδειξη: Τι τύπου είναι η τιμή που επιστρέφεται και τι τύπου η παράμετρος;
Λύση: Επιστρέφει λογική τιμή → bool· δέχεται χαρακτήρα → char letter· το πρότυπο τελειώνει με ;. Το void δεν επιστρέφει τιμή και στο caps(letter) λείπει ο τύπος της παραμέτρου.
Άσκηση 6Μέτρια
Συμπληρώστε το κενό μέσα στη main, ώστε να κληθεί η FirstLetter και ο πρώτος χαρακτήρας της s να αποθηκευτεί στη c.

Λύση: c = FirstLetter(s); — η πραγματική παράμετρος είναι η s της main και η επιστρεφόμενη τιμή αποθηκεύεται στη c.

Συμπληρώστε τις τυπικές παραμέτρους της συνάρτησης ώστε το πρόγραμμα να υπολογίζει τον μέσο όρο των ψηφίων των μονάδων τριών ακεραίων.
1float AverageLastDigit(_________________) {2    int d1, d2, d3, sum;3    d1 = x % 10;4    d2 = y % 10;5    d3 = z % 10;6    sum = d1 + d2 + d3;7    return sum / 3.0;8}9int main() {10    int a, b, c;11    cin >> a >> b >> c;12    cout << AverageLastDigit(a, b, c);13    return 0;14}

Άσκηση 9Απαιτητική
Τι θα συμβεί αν μεταγλωττίσουμε το πρόγραμμα;
1#include <iostream>2using namespace std;3int main() {4    cout << triple(5);5    return 0;6}7int triple(int x) {8    return 3 * x;9}
Υπόδειξη: Ο μεταγλωττιστής διαβάζει το αρχείο από πάνω προς τα κάτω.
Λύση: Στη γραμμή της κλήσης ο μεταγλωττιστής δεν γνωρίζει ακόμη τη triple («was not declared in this scope»). Διόρθωση: πρότυπο int triple(int x); πριν από τη main (ή μεταφορά του ορισμού πάνω από τη main). Τότε θα εμφανιζόταν 15.
Άσκηση 10Βασική
Ποια συνάρτηση πρέπει να δηλωθεί με τύπο void;
Υπόδειξη: void = καμία επιστρεφόμενη τιμή.
Λύση: Η συνάρτηση που μόνο εμφανίζει μήνυμα δεν επιστρέφει τιμή → void say_hello(). Οι άλλες επιστρέφουν int, bool, double αντίστοιχα.
