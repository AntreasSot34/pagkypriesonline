Ουρά (queue) στη C++: push, pop, front – υλοποίηση με πίνακα και STL

📘 Βιβλίο Γ΄ Λυκείου: Γ7.9 §7–11 Αφηρημένος τύπος δεδομένων – Ουρά (σ. 288–297)

Πώς λειτουργεί η ουρά (queue) με την αρχή FIFO και πώς την υλοποιούμε σε C++ με πίνακα, δείκτες front/back ή με την STL;

Θεωρία

Εκτός εξεταστέας ύλης Παγκυπρίων 2025-26

Η ουρά (κεφάλαιο Γ7.9) δεν εξετάζεται στις Παγκύπριες 2025-26 — χρήσιμη για τις σχολικές εξετάσεις.

Ουρά – αρχή FIFO

Ουρά (queue) είναι μια συλλογή στοιχείων όπου τα νέα στοιχεία προστίθενται από την πίσω άκρη (back) και αφαιρούνται μόνο από τη μπροστινή (front) — όπως οι πελάτες στο ταμείο μιας τράπεζας. Είναι δομή FIFO (First-In-First-Out): ό,τι μπαίνει πρώτο, βγαίνει πρώτο.

Λειτουργίες: δημιουργία κενής ουράς, Push(X) εισαγωγή στο τέλος, Pop() εξαγωγή του πρώτου, Empty(), Front() το πρώτο στοιχείο χωρίς αφαίρεση, Size() το πλήθος.

Υλοποίηση ουράς με πίνακα και συναρτήσεις

Χρησιμοποιούμε δύο καθολικούς δείκτες: front (θέση του πρώτου στοιχείου) και back (η επόμενη ελεύθερη θέση), αρχικά και οι δύο 0. Το μέγεθος είναι back - front και η ουρά είναι κενή όταν front == back.

queue_array.cpp
1#include <iostream>2using namespace std;3const int ARR_SIZE = 5;4int front = 0, back = 0;5void Push(int arr[], int X, int N) {6    if (back == N)7        cout << "Queue is full" << endl;8    else {9        arr[back] = X;10        back++;11        cout << "Pushed item " << X << endl;12    }13}14bool Empty() {15    return (front == back);16}17void Pop(int arr[]) {18    if (Empty())19        cout << "Queue is empty" << endl;20    else {21        arr[front] = 0;22        front++;23    }24}25int Front(int arr[]) {26    return arr[front];27}28int Size() {29    return (back - front);30}31int main() {32    int myqueue[ARR_SIZE];33    for (int num = 10; num <= 15; num++)34        Push(myqueue, num, ARR_SIZE);35    cout << "Front: " << Front(myqueue) << " Size: " << Size() << endl;36    Pop(myqueue);37    Pop(myqueue);38    cout << "Front: " << Front(myqueue) << " Size: " << Size() << endl;39    for (int i = front; i < back; i++)40        cout << myqueue[i] << " ";41    return 0;42}

Περιορισμός της απλής υλοποίησης

Αφού το back μόνο αυξάνεται, όταν φτάσει στο N η ουρά δηλώνει «γεμάτη» ακόμη κι αν έχουν βγει στοιχεία από μπροστά και υπάρχουν κενές θέσεις στην αρχή του πίνακα. (Η «κυκλική ουρά» λύνει το πρόβλημα, αλλά δεν περιλαμβάνεται στο βιβλίο.)

Ουρά μέσω της βιβλιοθήκης STL

Η βιβλιοθήκη <queue> (STL) αναφέρεται μόνο επειδή είναι στο κεφάλαιο Γ7.9 (εκτός εξεταστέας ύλης)· στις λύσεις των Παγκυπρίων δεν χρησιμοποιείται. Με #include <queue>: queue<int> Q; και μέθοδοι push(item) (στο πίσω μέρος), pop() (από μπροστά), front(), back(), empty(), size().

queue_stl.cpp
1#include <iostream>2#include <queue>3using namespace std;4int main() {5    queue<int> Q;6    for (int i = 1; i <= 4; i++)7        Q.push(i * 10);                       // 10 20 30 408    Q.pop();9    cout << Q.front() << " " << Q.back() << " " << Q.size() << endl;10    while (!Q.empty()) {11        cout << Q.front() << " ";12        Q.pop();13    }14    return 0;15}

Ασκήσεις — 0/5 λυμένες

Άσκηση 1Βασική
Η ουρά είναι δομή τύπου:
Υπόδειξη: Ουρά στο ταμείο.
Λύση: FIFO (First-In-First-Out): εισαγωγή πίσω, εξαγωγή μπροστά.
Άσκηση 2Βασική
Μια ουρά περιέχει (από μπροστά προς τα πίσω) 4, 8, 1. Εκτελούνται: Push(5), Pop(), Pop(), Push(2). Ποια είναι τα Front(), Size() και το τελευταίο στοιχείο (back);
Υπόδειξη: Τα Pop αφαιρούν από μπροστά.
Λύση: 4,8,1 → 4,8,1,5 → 8,1,5 → 1,5 → 1,5,2. Front 1, Size 3, τελευταίο 2.

Άσκηση 4Απαιτητική
Τι θα εμφανίσει το πρόγραμμα; (όλες οι γραμμές σε μία)
1#include <iostream>2using namespace std;3const int ARR_SIZE = 4;4int front = 0, back = 0;5void Push(int arr[], int X, int N) {6    if (back == N)7        cout << "Queue is full" << endl;8    else {9        arr[back] = X;10        back++;11    }12}13void Pop(int arr[]) {14    if (front == back)15        cout << "Queue is empty" << endl;16    else {17        arr[front] = 0;18        front++;19    }20}21int main() {22    int q[ARR_SIZE];23    for (int x = 1; x <= 4; x++)24        Push(q, x * 3, ARR_SIZE);25    Pop(q);26    Pop(q);27    Push(q, 20, ARR_SIZE);28    cout << q[front] << " " << back - front << endl;29    return 0;30}
Υπόδειξη: Μετά τα 4 Push, back = 4 = N. Τα Pop αυξάνουν μόνο το front.
Λύση: Μπαίνουν 3, 6, 9, 12 (back = 4). Δύο Pop → front = 2. Το Push(20) βρίσκει back == N και εμφανίζει «Queue is full», παρότι οι θέσεις 0 και 1 είναι ελεύθερες — περιορισμός της απλής υλοποίησης. Πρώτο στοιχείο q[2] = 9, μέγεθος 4 − 2 = 2.

Άσκηση 5Μέτρια
Στην υλοποίηση ουράς με πίνακα και δείκτες front, back (αρχικά 0), πότε η ουρά είναι κενή;
Υπόδειξη: Μέγεθος = back − front.
Λύση: Το πλήθος των στοιχείων είναι back - front, άρα η ουρά είναι κενή όταν front == back. Το back == N σημαίνει ότι δεν χωρά άλλο στοιχείο.
