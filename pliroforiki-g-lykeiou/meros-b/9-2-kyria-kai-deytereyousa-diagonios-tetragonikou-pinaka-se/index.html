9.2

Κύρια και δευτερεύουσα διαγώνιος τετραγωνικού πίνακα σε C++

📘 Βιβλίο Γ΄ Λυκείου: Γ7.7 §2 (σ. 212–213) · Παράδειγμα 7.8 (Παγκύπριες 2016)

Ποια στοιχεία ενός τετραγωνικού πίνακα βρίσκονται πάνω στην κύρια ή στη δευτερεύουσα διαγώνιο — και ποια συνθήκη των δεικτών i, j τα ξεχωρίζει;

Θεωρία

Ένας πίνακας με ίσο αριθμό γραμμών και στηλών ($N \times N$) λέγεται τετραγωνικός πίνακας. Έχει δύο διαγωνίους: την κύρια διαγώνιο και τη δευτερεύουσα διαγώνιο. Στις Παγκύπριες ζητείται πολύ συχνά να υπολογίσουμε αθροίσματα ή πλήθη στοιχείων πάνω, κάτω ή επάνω σε μια διαγώνιο. Το κλειδί είναι μία απλή συνθήκη στους δείκτες i (γραμμή) και j (στήλη).

Κύρια διαγώνιος: i == j

Η κύρια διαγώνιος ξεκινά από την πάνω αριστερή γωνία και καταλήγει στην κάτω δεξιά. Τα στοιχεία της έχουν ίσους δείκτες: i == j. Πάνω από αυτήν ισχύει j > i (ή i < j) και κάτω από αυτήν i > j.

Κίτρινο: i == j · γαλάζιο: πάνω (i < j)
[0][0][0][1][0][2][0][3][0][4]
[1][0][1][1][1][2][1][3][1][4]
[2][0][2][1][2][2][2][3][2][4]
[3][0][3][1][3][2][3][3][3][4]
[4][0][4][1][4][2][4][3][4][4]

Δευτερεύουσα διαγώνιος: i + j == N − 1

Η δευτερεύουσα διαγώνιος ξεκινά από την πάνω δεξιά γωνία και καταλήγει στην κάτω αριστερή. Για τα στοιχεία της ισχύει i == N-j-1, δηλαδή ισοδύναμα i + j == N - 1. Πάνω από αυτήν: i + j < N - 1· κάτω από αυτήν: i + j > N - 1.

Πράσινο: i + j == 4 (N = 5) · γαλάζιο: κάτω (i + j > N − 1)
[0][0][0][1][0][2][0][3][0][4]
[1][0][1][1][1][2][1][3][1][4]
[2][0][2][1][2][2][2][3][2][4]
[3][0][3][1][3][2][3][3][3][4]
[4][0][4][1][4][2][4][3][4][4]

Συνοπτικός πίνακας συνθηκών

Πάνω από την κύριαi < j$\frac{N(N-1)}{2}$
Κάτω από την κύριαi > j$\frac{N(N-1)}{2}$
Δευτερεύουσα διαγώνιοςi + j == N-1$N$

Κάτω από τη δευτερεύουσαi + j > N-1$\frac{N(N-1)}{2}$

Όταν το $N$ είναι περιττό, το κεντρικό στοιχείο a[N/2][N/2] ανήκει και στις δύο διαγωνίους.

Αθροίσματα διαγωνίων με έναν βρόχο

Αφού στην κύρια διαγώνιο $j = i$ και στη δευτερεύουσα $j = N-1-i$, αρκεί ένας βρόχος:

int s1 = 0, s2 = 0;for (int i = 0; i < N; i++){    s1 += a[i][i];          // κύρια διαγώνιος    s2 += a[i][N-1-i];      // δευτερεύουσα διαγώνιος}

Με δύο εμφωλευμένους βρόχους και if λύνουμε το γενικό πρόβλημα (π.χ. άθροισμα των στοιχείων κάτω από την κύρια διαγώνιο: if (i > j) s += a[i][j];).

Το κωδικοποιημένο μήνυμα (Παγκύπριες 2016)

Ένας πίνακας code[10][10] περιέχει τους χαρακτήρες A και B. «Κίνδυνος» υπάρχει αν η κύρια διαγώνιος έχει ακριβώς 5 χαρακτήρες A και τα B πάνω από την κύρια διαγώνιο είναι περισσότερα από τα A κάτω από αυτήν.

Λύση βήμα-βήμα 
1char code[10][10];2int sum_on = 0, sum_over = 0, sum_below = 0;3for (int i=0; i<10; i++)4    for (int j=0; j<10; j++){5        cin >> code[i][j];6        if (code[i][j] == 'A'){7            if (i == j)8                sum_on++;          // A στην κύρια διαγώνιο9            else10                if (i > j)11                    sum_below++;   // A κάτω από τη διαγώνιο12        }13        else14            if (i < j)15                sum_over++;        // B πάνω από τη διαγώνιο16    }17if (sum_over > sum_below && sum_on == 5)18    cout << "Danger";19else20    cout << "No Danger";

Παρατήρησε ότι η καταμέτρηση γίνεται την ώρα που διαβάζονται τα στοιχεία, χωρίς δεύτερο πέρασμα του πίνακα.

Συχνά λάθη στις Παγκύπριες

Γράφουμε i + j == N αντί για i + j == N - 1 · στο άθροισμα και των δύο διαγωνίων μετράμε δύο φορές το κεντρικό στοιχείο (περιττό N) · χρησιμοποιούμε = αντί για == στη συνθήκη · θεωρούμε ότι «πάνω» σημαίνει i > j (είναι το αντίθετο!).

Συνθήκη i == j → 5 στοιχεία · άθροισμα s = 3 + 7 + 6 + 2 + 4 = 22.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Σε τετραγωνικό πίνακα 5×5, το στοιχείο a[2][2] ανήκει και στην κύρια και στη δευτερεύουσα διαγώνιο.
Υπόδειξη: Έλεγξε τις δύο συνθήκες i == j και i + j == N − 1.
Λύση: $i = j = 2$ ✓ και $i + j = 4 = N - 1$ ✓. Είναι το κεντρικό στοιχείο, που ανήκει και στις δύο διαγωνίους.
Άσκηση 2Βασική
Ποια συνθήκη ισχύει για τα στοιχεία a[i][j] της δευτερεύουσας διαγωνίου πίνακα $N \times N$;
Υπόδειξη: Το στοιχείο πάνω δεξιά είναι το a[0][N−1].
Λύση: Για το a[0][N-1] ισχύει $0 + (N-1) = N-1$. Γενικά i + j == N - 1 (ισοδύναμα i == N-j-1). Η i == j αφορά την κύρια διαγώνιο.
Άσκηση 3Βασική
Ποια συνθήκη επιλέγει τα στοιχεία που βρίσκονται πάνω από την κύρια διαγώνιο;
Υπόδειξη: Πάρε για παράδειγμα το a[0][3].
Λύση: Πάνω από την κύρια διαγώνιο ο δείκτης στήλης είναι μεγαλύτερος από τον δείκτη γραμμής: j > i, δηλαδή i < j. Η i + j < N - 1 αφορά τη δευτερεύουσα διαγώνιο.
Άσκηση 4Μέτρια
Πόσα στοιχεία ενός πίνακα 6×6 βρίσκονται αυστηρά πάνω από την κύρια διαγώνιο; Πόσα βρίσκονται πάνω ή στη δευτερεύουσα διαγώνιο (i + j <= N - 1);
Υπόδειξη: Σύνολο 36 στοιχεία, 6 στη διαγώνιο, τα υπόλοιπα μοιράζονται εξίσου.
Λύση: $(36 - 6)/2 = 15$ πάνω από την κύρια διαγώνιο. Πάνω από τη δευτερεύουσα επίσης 15, συν τα 6 στοιχεία της: 21.
