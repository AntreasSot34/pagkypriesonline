7.2

Χρονική πολυπλοκότητα αλγορίθμων — συμβολισμός Ο (Big-O)

📘 Βιβλίο Γ΄ Λυκείου: Γ7.5 §3–4 Χρονική πολυπλοκότητα, Ανάλυση χρονικής πολυπλοκότητας (σ. 158–160) · Παράδειγμα 5.2 · Ασκήσεις 5.24–5.25

Πόσο πιο αργά θα τρέξει ένα πρόγραμμα αν διπλασιαστούν τα δεδομένα; Η χρονική πολυπλοκότητα O(1), O(N), O(N²), O(log N) απαντά μετρώντας βρόχους.

Θεωρία

Η χρονική πολυπλοκότητα (time complexity) ενός αλγορίθμου περιγράφει πώς αυξάνεται ο χρόνος εκτέλεσής του σε σχέση με το μέγεθος των δεδομένων εισόδου $N$. Συμβολίζεται με το γράμμα Ο (συμβολισμός «Big-O»): $O(1)$, $O(N)$, $O(N^2)$, $O(\log_2 N)$ κ.λπ. Στις Παγκύπριες ζητείται να βρίσκουμε την πολυπλοκότητα απλών αλγορίθμων μετρώντας τους εμφωλευμένους βρόχους (μέχρι $O(N^3)$) και να υπολογίζουμε πόσα «βήματα» εκτελούνται.

Χρονική πολυπλοκότητα και βασικές πράξεις

Η χρονική πολυπλοκότητα ενός αλγορίθμου αφορά στο μέγιστο κόστος εκτέλεσής του, δηλαδή στη χειρότερη περίπτωση. Το κόστος μετριέται με το πλήθος των βασικών πράξεων που εκτελεί ο αλγόριθμος:

  • (α) ανάθεση τιμής, π.χ. a = 10;
  • (β) σύγκριση μεταξύ μεταβλητών, π.χ. if (a==b)
  • (γ) εκτέλεση πράξεων, π.χ. a = b + 5;

Παράδειγμα: η σειριακή αναζήτηση έχει πολυπλοκότητα $O(N)$ — στη χειρότερη περίπτωση χρειάζεται $N$ βήματα.

Οι κατηγορίες πολυπλοκότητας του βιβλίου

Ο καθηγητής ψάχνει ποιος από τους $N$ μαθητές έχει το απουσιολόγιο. Το πλήθος των ερωτήσεων είναι η πολυπλοκότητα:

Παράδειγμα 5.2 — τρεις εμφωλευμένοι βρόχοι

1int N = 5, steps = 0;2for (int i = 1; i <= N; i++)3    for (int j = N; j >= 1; j--)4        for (int k = 1; k <= N; k++)5            steps++;6cout << steps << endl;
Λύση βήμα-βήμα

Κάθε βρόχος εκτελείται $N$ φορές (ο δεύτερος μετρά προς τα κάτω, αλλά πάλι $N$ φορές). Τα συνολικά βήματα είναι $N\cdot N\cdot N = N^3$, άρα κυβική πολυπλοκότητα $O(N^3)$. Για $N = 5$: $5^3 = 125$.

Οθόνη (έξοδος)
125

Λογαριθμική πολυπλοκότητα: διαίρεση με το 2

1int ans = 0;2while (N > 0) {3    N /= 2;4    ans++;5}

Στον κώδικα αυτό το $N$ υποδιπλασιάζεται (ακέραια διαίρεση) σε κάθε επανάληψη. Για $N = 100$: $100 \to 50 \to 25 \to 12 \to 6 \to 3 \to 1 \to 0$, άρα ans = 7. Γενικά ο βρόχος εκτελείται $\lfloor \log_2 N \rfloor + 1$ φορές, δηλαδή $O(\log_2 N)$.

Γιατί ο λογάριθμος μεγαλώνει τόσο αργά;
$N$$\log_2 N$ (περίπου)$N^2$

1 000101 000 000

Ένας αλγόριθμος $O(\log_2 N)$ σε ένα εκατομμύριο στοιχεία χρειάζεται περίπου 20 βήματα, ενώ ένας $O(N^2)$ ένα τρισεκατομμύριο!

Πώς μετράμε βήματα σε βρόχους

  • Διαδοχικοί (όχι εμφωλευμένοι) βρόχοι προστίθενται: ένας βρόχος $x$ φορές και μετά ένας $y$ φορές δίνουν $x + y$ βήματα.
  • Εμφωλευμένοι βρόχοι πολλαπλασιάζονται: $N$ επαναλήψεις του εξωτερικού × $N$ του εσωτερικού $= N^2$.
  • Αν ο εσωτερικός βρόχος εξαρτάται από τον εξωτερικό (π.χ. for (j=i; j<N; j++)), αθροίζουμε: $N + (N-1) + \dots + 1 = \frac{N(N+1)}{2}$ — πάλι $O(N^2)$.
  • Στον συμβολισμό Ο κρατάμε τον μεγαλύτερο όρο χωρίς σταθερές: $\frac{N^2}{2} + 3N + 7 \to O(N^2)$.

Συχνά λάθη στις Παγκύπριες

✗ Δύο βρόχοι ο ένας μετά τον άλλο δεν δίνουν $O(N^2)$ αλλά $O(N)$. ✗ Ο βρόχος for (int j=N; j>=1; j--) εκτελείται κι αυτός $N$ φορές. ✗ Στο N /= 2 η διαίρεση ακεραίων κόβει το δεκαδικό: $25/2 = 12$.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Ποια είναι η χρονική πολυπλοκότητα της σειριακής αναζήτησης σε πίνακα $N$ στοιχείων;
Υπόδειξη: Πόσα στοιχεία ελέγχονται στη χειρότερη περίπτωση;
Λύση: Στη χειρότερη περίπτωση ελέγχονται και τα $N$ στοιχεία: $O(N)$, γραμμική πολυπλοκότητα.
Άσκηση 2Βασική
Η χρονική πολυπλοκότητα ενός αλγορίθμου αφορά στο μέγιστο κόστος εκτέλεσής του, δηλαδή στη χειρότερη περίπτωση.
Υπόδειξη: Ορισμός του βιβλίου.
Λύση: ΣΩΣΤΟ. Σύμφωνα με το βιβλίο, η χρονική πολυπλοκότητα αφορά στο μέγιστο κόστος εκτέλεσης, που μετριέται με το πλήθος των βασικών πράξεων στη χειρότερη περίπτωση.
Άσκηση 3Βασική
Τι θα εμφανίσει ο κώδικας;
1int N = 4, steps = 0;2for (int i = 1; i <= N; i++)3    for (int j = N; j >= 1; j--)4        for (int k = 1; k <= N; k++)5            steps++;6cout << steps;
Υπόδειξη: Τρεις εμφωλευμένοι βρόχοι, ο καθένας N φορές.
Λύση: $N \cdot N \cdot N = 4^3 = 64$ (πολυπλοκότητα $O(N^3)$).

64
Άσκηση 4Μέτρια
Τι θα εμφανίσει ο κώδικας για $N = 6$;
1int steps = 0;2for (int i = 0; i < N; i++)3    for (int j = i; j < N; j++)4        steps++;5cout << steps;
Υπόδειξη: Για i = 0 ο εσωτερικός εκτελείται 6 φορές, για i = 1 πέντε, …
Λύση: $6 + 5 + 4 + 3 + 2 + 1 = \frac{6\cdot 7}{2} = 21$. Η πολυπλοκότητα παραμένει $O(N^2)$.
Οθόνη (έξοδος)
21
Άσκηση 5Μέτρια
Τι τιμή θα έχει η ans μετά την εκτέλεση του κώδικα, για $N = 100$ και για $N = 1000$;
1int ans = 0;2while (N > 0) {3    N /= 2;4    ans++;5}
Υπόδειξη: Ακέραια διαίρεση με το 2 μέχρι να γίνει 0.
Λύση: $100 \to 50 \to 25 \to 12 \to 6 \to 3 \to 1 \to 0$: 7 επαναλήψεις. $1000 \to 500 \to 250 \to 125 \to 62 \to 31 \to 15 \to 7 \to 3 \to 1 \to 0$: 10 επαναλήψεις. Λογαριθμική πολυπλοκότητα $O(\log_2 N)$.
Άσκηση 6Μέτρια
Ποια είναι η χρονική πολυπλοκότητα της συνάρτησης;
1void f2(int N){2    for(int i=0; i<N; i++){3        for(int j=0; j<N; j++)4            cout << i * j << " ";5        cout << endl;6    }7}
Υπόδειξη: Μέτρησε εμφωλευμένους βρόχους.
Λύση: Δύο εμφωλευμένοι βρόχοι των $N$ επαναλήψεων: η εντολή cout << i*j εκτελείται $N^2$ φορές, άρα $O(N^2)$. Η cout << endl εκτελείται $N$ φορές, όρος που δεν επηρεάζει την πολυπλοκότητα.
Άσκηση 7Μέτρια
Τι επιστρέφει η κλήση my_function(4096);
1int my_function(int N) {2    int ans = 0;3    while (N > 0){4        ans += N % 10;5        N /= 10;6    }7    return ans;8}
Υπόδειξη: Το N % 10 είναι το τελευταίο ψηφίο.
Λύση: Η συνάρτηση αθροίζει τα ψηφία: $6 + 9 + 0 + 4 = 19$. Ο βρόχος εκτελείται τόσες φορές όσα τα ψηφία του $N$ (εδώ 4), δηλαδή περίπου $\log_{10} N$ φορές — λογαριθμική πολυπλοκότητα.
Άσκηση 8Απαιτητική
Δίνεται η συνάρτηση:
1int f3(int x, int y){2    int s = 0;3    for(int i=1; i<=x; i++)4        s += i;5    for(int j=1; j<=y; j++)6        s += j;7    return s;8}
Τι επιστρέφει η κλήση f3(3, 4) και πόσες φορές συνολικά εκτελούνται οι εντολές s += … για την κλήση f3(100, 50);
Υπόδειξη: Οι δύο βρόχοι είναι διαδοχικοί, όχι εμφωλευμένοι.
Λύση: $f3(3,4) = (1+2+3) + (1+2+3+4) = 6 + 10 = 16$. Οι βρόχοι είναι διαδοχικοί, άρα τα βήματα προστίθενται: $100 + 50 = 150$. Η πολυπλοκότητα είναι $O(x + y)$ — γραμμική.
Άσκηση 9Απαιτητική
Τι θα εμφανίσει ο κώδικας για $N = 8$;
1int steps = 0;2for (int i = 1; i <= N; i *= 2)3    for (int j = 0; j < N; j++)4        steps++;5cout << steps;
Υπόδειξη: Ποιες τιμές παίρνει το i;
Λύση: Το i παίρνει τις τιμές 1, 2, 4, 8 (4 τιμές) και για καθεμία ο εσωτερικός βρόχος εκτελείται 8 φορές: $4 \cdot 8 = 32$.
Οθόνη (έξοδος)
32
Άσκηση 10Βασική
Ποια πολυπλοκότητα χαρακτηρίζεται ως «σταθερή» (constant);
Υπόδειξη: Ο χρόνος δεν εξαρτάται από το N.
Λύση: $O(1)$: ο αλγόριθμος χρειάζεται τον ίδιο χρόνο ανεξάρτητα από τα δεδομένα (π.χ. μία ερώτηση σε όλη την τάξη).

Εξάσκηση #1
Ποια είναι η χρονική πολυπλοκότητα του κώδικα (ως προς το μέγεθος των δεδομένων);
1int steps = 0, N = 9;2for (int i = 1; i <= N; i++)3    for (int j = i; j <= N; j++)4        steps++;
Υπόδειξη: Μέτρησε τους εμφωλευμένους βρόχους και το πώς μεταβάλλεται ο μετρητής.
Λύση: Για $i = 1$ ο εσωτερικός εκτελείται $9$ φορές, για $i = 2$ $8$, …: $9 + 8 + \dots + 1 = \frac{9\cdot 10}{2} = 45$. Πολυπλοκότητα: $O(N^2)$.
