6.4

Πίνακες και αρχεία σε συναρτήσεις C++

📘 Βιβλίο Γ΄ Λυκείου: Γ7.4 §7 Πίνακες και συναρτήσεις, §8 Αρχεία και συναρτήσεις (σ. 140–143)

Πώς περνάμε έναν πίνακα σε μια συνάρτηση C++, γιατί οι αλλαγές του φαίνονται στη main χωρίς &, και πώς χρησιμοποιούμε αρχεία μέσα σε συναρτήσεις;

Θεωρία

Στα προβλήματα των Παγκυπρίων οι συναρτήσεις με πίνακες είναι πολύ συχνές: μια συνάρτηση fill γεμίζει τον πίνακα, μια print τον εμφανίζει, μια average ή max_grade υπολογίζει κάτι από αυτόν. Επίσης, τα αρχεία σε συναρτήσεις χρησιμοποιούνται με ροές ifstream/ofstream δηλωμένες ως καθολικές.

Πίνακας ως παράμετρος

Ένας πίνακας έχει πολλές τιμές, γι' αυτό περνά πάντα ως παράμετρος αναφοράς: η συνάρτηση παίρνει τη διεύθυνση του πίνακα και δουλεύει πάνω στον ίδιο πίνακα της main. Ιδιαιτερότητες:

  • Στην επικεφαλίδα γράφουμε int arr[] — χωρίς & και συνήθως χωρίς μέγεθος.
  • Στην κλήση γράφουμε μόνο το όνομα του πίνακα: fill(A); (όχι fill(A[]); ή fill(A[N]);).
  • Το μέγεθος το δίνουμε με σταθερά const int N = 20;, με καθολική μεταβλητή ή με επιπλέον παράμετρο int n.
  • Κάθε αλλαγή στα στοιχεία μέσα στη συνάρτηση φαίνεται στη main.
fill_print.cpp
1#include <iostream>2using namespace std;3const int N = 20;4void fill(int arr[]);        // πρότυπα συναρτήσεων5void print(int arr[]);6int main() {7    int A[N];8    fill(A);                 // μόνο το όνομα του πίνακα9    print(A);10    return 0;11}12void fill(int arr[]) {13    for (int i = 0; i < N; i++)14        cin >> arr[i];15}16void print(int arr[]) {17    for (int i = 0; i < N; i++)18        cout << arr[i] << " ";19}

const int N ή #define N;

Το βιβλίο δηλώνει συχνά το μέγεθος με την οδηγία #define N 20. Εδώ γράφουμε const int N = 20; (σταθερά της C++). Και οι δύο τρόποι είναι σωστοί και γίνονται δεκτοί στις εξετάσεις.

grades.cpp
1#include <iostream>2#include <iomanip>3#include <string>4using namespace std;5const int N = 25;6void read(int grades[], string names[]) {7    for (int i = 0; i < N; i++)8        cin >> grades[i] >> names[i];9}10double average(int grades[]) {11    int sum = 0;12    for (int i = 0; i < N; i++)13        sum += grades[i];14    return (double) sum / N;           // μετατροπή για πραγματική διαίρεση15}16string max_grade(int grades[], string names[]) {17    int maxg = grades[0];18    string maxn = names[0];19    for (int i = 1; i < N; i++)20        if (grades[i] > maxg) {21            maxg = grades[i];22            maxn = names[i];23        }24    return maxn;25}26int main() {27    int vathmoi[N];28    string onomata[N];29    read(vathmoi, onomata);30    cout << "Avg=" << fixed << setprecision(1) << average(vathmoi) << endl;31    cout << "Best student=" << max_grade(vathmoi, onomata) << endl;32    return 0;33}

Η average επιστρέφει double· το (double) sum / N χρειάζεται, αλλιώς η sum / N θα ήταν ακέραια διαίρεση. Μια συνάρτηση μπορεί να επιστρέψει και string (εδώ το όνομα του καλύτερου μαθητή).

Αρχεία και συναρτήσεις

Για να χρησιμοποιούν πολλές συναρτήσεις το ίδιο αρχείο, δηλώνουμε τις ροές ifstream / ofstream έξω από τη main (καθολικές). Παράδειγμα 4.9: η fill διαβάζει ακεραίους από το numbers.txt, η square ελέγχει αν ένας αριθμός είναι τέλειο τετράγωνο και η print γράφει τα τέλεια τετράγωνα στο squares.txt.

squares.cpp
1#include <iostream>2#include <fstream>3#include <cmath>4using namespace std;5ifstream fin("numbers.txt");       // ροές δηλωμένες εκτός main6ofstream fout("squares.txt");7int cnt = 0;                       // πλήθος ακεραίων (καθολική)8void fill(int nums[]) {9    int x;10    fin >> x;                      // πρώτη ανάγνωση (πριν από τον βρόχο)11    while (!fin.eof()) {12        nums[cnt] = x;13        cnt++;14        fin >> x;                  // επόμενη ανάγνωση στο τέλος του βρόχου15    }16}17bool square(int n) {18    int x = (int)(sqrt(n) + 0.5);19    if (x * x == n)20        return true;21    return false;22}23void print(int nums[]) {24    for (int i = 0; i < cnt; i++)25        if (square(nums[i]))26            fout << nums[i] << " ";27}28int main() {29    int numbers[100];30    fill(numbers);31    print(numbers);32    fin.close();33    fout.close();34    return 0;35}
numbers.txt (με Enter στο τέλος)
13 19 25 41 82 16 49 54 112 90
squares.txt
25 16 49

Διαφορά από το βιβλίο

Στο Παράδειγμα 4.9 το βιβλίο γράφει τη fill με την ανάγνωση μέσα στον βρόχο (while (!fin.eof()) { fin >> nums[cnt]; cnt++; }). Αν το αρχείο τελειώνει με Enter, αυτή η εκδοχή μετρά ένα στοιχείο παραπάνω (η τελευταία, αποτυχημένη ανάγνωση αυξάνει κι αυτή το cnt). Εδώ χρησιμοποιούμε τη μορφή «ανάγνωση πριν από τον βρόχο – νέα ανάγνωση στο τέλος», που είναι η πρότυπη μορφή για τις εξετάσεις.

Η fill ακολουθεί το γνωστό σχήμα ανάγνωσης αρχείου: μία ανάγνωση πριν από τον βρόχο, επεξεργασία, και νέα ανάγνωση στο τέλος του σώματος του while (!fin.eof()). Η print καλεί μέσα της την square: μια συνάρτηση μπορεί να καλεί άλλη συνάρτηση.

Συχνά λάθη στις Παγκύπριες

  • void f(int &arr[]) ✗ — ο πίνακας περνά ήδη με αναφορά: void f(int arr[]) ✓.
  • Κλήση f(A[]); ή f(A[N]); ✗ → f(A); ✓ (το A[N] θα ήταν ένα στοιχείο — και μάλιστα εκτός ορίων).
  • Μέσα στη συνάρτηση χρησιμοποιούμε το όνομα του πίνακα της main αντί για το όνομα της παραμέτρου.
  • return sum / N; με ακέραια sum → ακέραια διαίρεση· χρειάζεται (double) sum / N.

Άσκηση 1Βασική
Για να περάσουμε έναν πίνακα σε συνάρτηση ως παράμετρο αναφοράς, γράφουμε τον τελεστή & πριν από το όνομά του στην επικεφαλίδα.
Υπόδειξη: Πώς είναι γραμμένη η void fill(int arr[]);
Λύση: ΛΑΘΟΣ. Ο πίνακας περνά πάντα με αναφορά (περνά η διεύθυνσή του), αλλά δεν χρησιμοποιείται ο τελεστής &: void fill(int arr[]).
Άσκηση 2Βασική
Δίνεται η συνάρτηση void print(int arr[]) και ο πίνακας int A[N]; της main. Ποια κλήση είναι σωστή;
Υπόδειξη: Στην κλήση δηλώνουμε μόνο το όνομα του πίνακα.
Λύση: print(A);. Το A[N] θα ήταν ένα (ανύπαρκτο) στοιχείο, και ο τύπος int δεν γράφεται στην κλήση.
Άσκηση 3Μέτρια
Συμπληρώστε την επικεφαλίδα (Α) της συνάρτησης που υπολογίζει το άθροισμα των στοιχείων του πίνακα.
1#include <iostream>2using namespace std;3const int N = 30;4______________________________ {        // Α5    int sum = 0, i;6    for (i = 0; i < N; i++)7        sum += b[i];8    return sum;9}10int main() {11    int arr[N];12    /* ... γέμισμα του πίνακα ... */13    cout << "Sum of array = " << sumArray(arr);14    return 0;15}
Υπόδειξη: Τι επιστρέφει; Πώς λέγεται στην κλήση; Ποιο όνομα έχει ο πίνακας στο σώμα;
Λύση: int sumArray(int b[]): επιστρέφει ακέραιο (return sum), το όνομα προκύπτει από την κλήση και η παράμετρος πρέπει να λέγεται b, όπως στο σώμα.

Άσκηση 5Μέτρια
Το παρακάτω τμήμα προγράμματος υπολογίζει το πλήθος των άρτιων στοιχείων. Πώς διορθώνεται η γραμμή με την κλήση;
1int even(int B[]);2int main() {3    int A[N];4    cout << "Even numbers:" << even(A[]) << endl;5    return 0;6}
Υπόδειξη: Ο πίνακας της main λέγεται A· στην κλήση γράφουμε μόνο το όνομα.
Λύση: Σωστό: even(A). Το B είναι το όνομα της τυπικής παραμέτρου (άγνωστο στη main), ενώ τα A[], &A, A[N] δεν είναι σωστές πραγματικές παράμετροι για int B[].
Άσκηση 6Απαιτητική
Τι θα εμφανίσει το πρόγραμμα; (σε μία γραμμή)
1#include <iostream>2using namespace std;3int posMax(int a[], int n) {4    int p = 0;5    for (int i = 1; i < n; i++)6        if (a[i] >= a[p])7            p = i;8    return p;9}10int main() {11    int A[6] = {4, 9, 2, 9, 7, 1};12    int p = posMax(A, 6);13    cout << p << " " << A[p] << " ";14    A[p] = 0;15    cout << posMax(A, 6) << endl;16    return 0;17}

Λύση: 1η κλήση: p γίνεται 1 (9 ≥ 4), μετά 3 (9 ≥ 9) → επιστρέφει 3, εμφανίζει 3 9. Μετά A[3] = 0, οπότε το μοναδικό 9 είναι στη θέση 1 → 1.
