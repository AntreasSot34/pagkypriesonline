4.1

Διερεύνηση εξίσωσης α΄ βαθμού με μία μεταβλητή

📘 Β΄ Τεύχος §4 · σελ. 9 · Δραστηριότητες σελ. 12

Θεωρία

Σημείωση

Η παράγραφος διδάσκεται κανονικά, αλλά δεν περιλαμβάνεται στην εξεταστέα ύλη της τελικής γραπτής εξέτασης (2025–26). Είναι όμως βάση για όσα ακολουθούν.

Η εξίσωση $\alpha x = \beta$

Κάθε εξίσωση της μορφής $\alpha x = \beta$ είναι εξίσωση πρώτου βαθμού με άγνωστο τον $x$. Μετά την απαλοιφή παρονομαστών και παρενθέσεων, τον χωρισμό γνωστών από αγνώστους και την αναγωγή ομοίων όρων, κάθε εξίσωση α΄ βαθμού παίρνει αυτή τη μορφή.

Διερεύνηση

  • Αν $\alpha \ne 0$: μοναδική λύση $x = \dfrac{\beta}{\alpha}$. Π.χ. $2x = -4 \iff x = -2$.
  • Αν $\alpha = 0$ και $\beta \ne 0$: η εξίσωση $0x = \beta$ δεν έχει λύση, είναι αδύνατη. Π.χ. $0x = -3$.
  • Αν $\alpha = 0$ και $\beta = 0$: η εξίσωση $0x = 0$ έχει ως λύση κάθε πραγματικό αριθμό, είναι αόριστη.

Εξισώσεις με παράμετρο

Για να βρούμε την παράμετρο $\lambda$ ώστε η $3(x - 1) = \lambda x - 1$ να είναι αδύνατη: $3x - \lambda x = 3 - 1 \iff (3 - \lambda)x = 2$. Πρέπει ο συντελεστής του $x$ να είναι μηδέν: $3 - \lambda = 0 \iff \lambda = 3$ (τότε $0x = 2$, αδύνατη).

Προσοχή: όταν ο συντελεστής του αγνώστου είναι $0$, δεν διαιρούμε με αυτόν.

Πειραματίσου

Εξίσωση: 2x+1=2x−32x + 1 = 2x - 32x+1=2x−3  ⇔  0x=−40x = -40x=−4. Αδύνατη (0x=−40x = -40x=−4): οι ευθείες είναι παράλληλες, δεν συναντιούνται ποτέ.
Μπλε: το 1ο μέλος y=2x+1y = 2x + 1y=2x+1, πορτοκαλί: το 2ο μέλος y=2x−3y = 2x - 3y=2x−3.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να λύσετε την εξίσωση $2x - 6 = 4x - 2$.
Υπόδειξη: $2x - 4x = -2 + 6$.
Λύση: $-2x = 4 \iff x = -2$. Μοναδική λύση, αφού ο συντελεστής $-2 \ne 0$.
Άσκηση 2Βασική
Η εξίσωση $3x + 5 = 3x - 3 + 8$:
Υπόδειξη: Χώρισε γνωστούς από αγνώστους.
Λύση: $3x - 3x = -3 + 8 - 5 \iff 0x = 0$: κάθε αριθμός την επαληθεύει, είναι αόριστη.
Άσκηση 3Βασική
Η εξίσωση $5(x + 3) = 5x + 3$:
Υπόδειξη: Απαλοιφή παρένθεσης: $5x + 15 = 5x + 3$.
Λύση: $5x - 5x = 3 - 15 \iff 0x = -12$: κανένας αριθμός δεν την επαληθεύει, είναι αδύνατη.
Άσκηση 4Βασική
Η εξίσωση $-3x = 0$ είναι αδύνατη.
Υπόδειξη: Ο συντελεστής του $x$ είναι $-3 \ne 0$.
Λύση: Λάθος: έχει μοναδική λύση $x = \frac{0}{-3} = 0$.
Άσκηση 5Μέτρια
Να βρείτε τον $\lambda$ ώστε να είναι αδύνατες οι εξισώσεις: (α) $(\lambda - 3)x = 7$, (β) $(\lambda + 2)x = -2014$.
Υπόδειξη: Μηδενίζουμε τον συντελεστή του $x$ (το β΄ μέλος είναι μη μηδενικό).
Λύση: (α) $\lambda - 3 = 0 \iff \lambda = 3$, οπότε $0x = 7$. (β) $\lambda + 2 = 0 \iff \lambda = -2$, οπότε $0x = -2014$.
Άσκηση 6Μέτρια
Να βρείτε τον $\lambda$ ώστε η εξίσωση $3x + \lambda x + 6 = 15 - 6x$ να είναι αδύνατη.
Υπόδειξη: Φέρε την εξίσωση στη μορφή $(\dots)x = \dots$
Λύση: $3x + \lambda x + 6x = 15 - 6 \iff (9 + \lambda)x = 9$. Αδύνατη όταν $9 + \lambda = 0$, δηλαδή $\lambda = -9$ (τότε $0x = 9$).
Άσκηση 7Μέτρια
Να βρείτε τον $\alpha$ ώστε να είναι αόριστες οι εξισώσεις: (α) $\alpha x = 6x$, (β) $13x + 5 = 13x + \alpha$.
Υπόδειξη: Αόριστη: μορφή $0x = 0$.
Λύση: (α) $(\alpha - 6)x = 0$, αόριστη για $\alpha = 6$. (β) $0x = \alpha - 5$, αόριστη για $\alpha = 5$.
Άσκηση 8Βασική
Η εξίσωση $\alpha x + 3 = 0$ δεν έχει λύση, αν:
Υπόδειξη: $\alpha x = -3$.
Λύση: $\alpha x = -3$: για $\alpha = 0$ γίνεται $0x = -3$, αδύνατη. Για κάθε άλλη τιμή έχει τη λύση $x = -\frac{3}{\alpha}$.
Άσκηση 9Απαιτητική
Να βρείτε τους αριθμούς $\alpha$ και $\beta$ ώστε η εξίσωση $(\alpha - 4)x + 1 = 2\beta + 5$ να είναι αόριστη.
Υπόδειξη: $(\alpha - 4)x = 2\beta + 4$· και οι δύο πλευρές μηδέν.
Λύση: $(\alpha - 4)x = 2\beta + 4$. Αόριστη όταν $\alpha - 4 = 0$ και $2\beta + 4 = 0$: $\alpha = 4$, $\beta = -2$.

♾️ Γεννήτρια — διερεύνηση εξίσωσης

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε τον αριθμό $\alpha$ ώστε η εξίσωση $\alpha x + 4 = -4x + 4$ να είναι αόριστη.
Λύση: $\alpha x - (-4x) = 4 - 4 \Rightarrow (\alpha + 4)x = 0$. Αόριστη όταν $\alpha + 4 = 0$, δηλαδή $\alpha = -4$.
