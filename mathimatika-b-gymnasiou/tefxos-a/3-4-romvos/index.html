Ρόμβος

📘 Α΄ Τεύχος §3 · σελ. 121 · Δραστηριότητες σελ. 124

Θεωρία

✓ Εξεταστέα ύλη

Η παράγραφος περιλαμβάνεται στην εξεταστέα ύλη της ενιαίας τελικής γραπτής εξέτασης της Β΄ Γυμνασίου (2025–26).

Ορισμός

Ρόμβος ονομάζεται το τετράπλευρο που έχει και τις τέσσερις πλευρές του ίσες. Κάθε ρόμβος είναι και παραλληλόγραμμο.

Ιδιότητες

  • Όλες οι ιδιότητες του παραλληλογράμμου.
  • Οι διαγώνιοί του είναι κάθετες: $A\Gamma \perp B\Delta$.
  • Οι διαγώνιοί του διχοτομούν τις γωνίες του: π.χ. $\Gamma\hat AB = \Gamma\hat A\Delta = \frac{\hat A}{2}$.

Π.χ. αν $\hat A = 40^\circ$, τότε $\hat B = 140^\circ$, $\Gamma\hat AB = 20^\circ$, $A\hat B\Delta = 70^\circ$ και $A\hat OB = 180^\circ - (20^\circ + 70^\circ) = 90^\circ$.

Εμβαδόν – περίμετρος

$E = \frac{\delta_1\cdot\delta_2}{2}$ (ημιγινόμενο των διαγωνίων) ή $E = \alpha\cdot\upsilon$ (ως παραλληλόγραμμο), και $\Pi = 4\alpha$.

Οι μισές διαγώνιοι και η πλευρά σχηματίζουν ορθογώνιο τρίγωνο: $\alpha^2 = \left(\frac{\delta_1}{2}\right)^2 + \left(\frac{\delta_2}{2}\right)^2$. Π.χ. $\alpha = 5$, $\delta_1 = 8$: $OB^2 = 25 - 16 = 9$, $OB = 3$, $\delta_2 = 6$, $E = 24$.

Πειραματίσου

Ρόμβος ΑΒΓΔ
Απέναντι πλευρές ίσες: ΑΒ = ΓΔ = 6, ΑΔ = ΒΓ = 6
Απέναντι γωνίες ίσες: ∠Α = ∠Γ = 60°, ∠Β = ∠Δ = 120° (διαδοχικές γωνίες παραπληρωματικές)
Οι διαγώνιοι διχοτομούνται: ΟΑ = ΟΓ = 5,2, ΟΒ = ΟΔ = 3
Διαγώνιοι: ΑΓ = 10,39, ΒΔ = 6 (όχι ίσες)
Οι διαγώνιοι είναι κάθετες και διχοτομούν τις γωνίες (π.χ. η ΑΓ χωρίζει την ∠Α σε 30° + 30°)
E = δ₁·δ₂/2 = 10,39·6/2 ≈ 31,18 (= α·υ = 31,18) · Π = 2(6 + 6) = 24

Ασκήσεις — 0/7 λυμένες

Άσκηση 1Βασική
Ρόμβος έχει διαγωνίους $16$ cm και $12$ cm. Να βρείτε το εμβαδόν, την πλευρά και την περίμετρό του.
Υπόδειξη: Μισές διαγώνιοι $8$ και $6$.
Λύση: $E = \frac{16\cdot 12}{2} = 96$ cm². $\alpha^2 = 8^2 + 6^2 = 100 \Rightarrow \alpha = 10$ cm, $\Pi = 40$ cm.
Άσκηση 2Μέτρια
Ρόμβος $AB\Gamma\Delta$ με κέντρο $O$ έχει πλευρά $13$ cm και διαγώνιο $A\Gamma = 24$ cm. Να βρείτε τη διαγώνιο $B\Delta$, το εμβαδόν και την περίμετρο.
Υπόδειξη: Στο ορθογώνιο τρίγωνο $OAB$: $OA = 12$.
Λύση: $OB^2 = 13^2 - 12^2 = 25 \Rightarrow OB = 5$, $B\Delta = 10$ cm. $E = \frac{24\cdot 10}{2} = 120$ cm², $\Pi = 4\cdot 13 = 52$ cm.
Άσκηση 3Βασική
Στον ρόμβο $AB\Gamma\Delta$ είναι $\hat A = 50^\circ$. Να βρείτε τις γωνίες $\hat B$, $\Gamma\hat AB$ και $A\hat B\Delta$.
Υπόδειξη: Οι διαγώνιοι διχοτομούν τις γωνίες.
Λύση: $\hat B = 180^\circ - 50^\circ = 130^\circ$. $\Gamma\hat AB = 25^\circ$, $A\hat B\Delta = \frac{130^\circ}{2} = 65^\circ$.
Άσκηση 4Βασική
Ρόμβος έχει εμβαδόν $60$ cm² και η μία διαγώνιός του είναι $12$ cm. Να βρείτε την άλλη διαγώνιο.
Υπόδειξη: $\frac{12\cdot\delta_2}{2} = 60$.
Λύση: $6\,\delta_2 = 60 \Rightarrow \delta_2 = 10$ cm.
Άσκηση 5Μέτρια
Η μία διαγώνιος ενός ρόμβου είναι τριπλάσια από την άλλη και το εμβαδόν του είναι $54$ cm². Να βρείτε τις διαγωνίους.
Υπόδειξη: $\frac{x\cdot 3x}{2} = 54$.
Λύση: $3x^2 = 108 \Rightarrow x^2 = 36 \Rightarrow x = 6$ cm, η άλλη $18$ cm.
Άσκηση 6Απαιτητική
Ορθογώνιο με διαστάσεις $12$ cm και $18$ cm είναι ισοδύναμο με ρόμβο, του οποίου η μία διαγώνιος είναι $18$ cm. Να βρείτε την άλλη διαγώνιο, την πλευρά και την περίμετρο του ρόμβου.
Υπόδειξη: $E = 12\cdot 18 = 216$. Μισές διαγώνιοι $9$ και $12$.
Λύση: $\frac{18\cdot\delta_2}{2} = 216 \Rightarrow \delta_2 = 24$ cm. $\alpha^2 = 9^2 + 12^2 = 225 \Rightarrow \alpha = 15$ cm, $\Pi = 60$ cm.
Άσκηση 7Βασική
Οι διαγώνιοι κάθε ρόμβου είναι:
Υπόδειξη: Δες το διαδραστικό σχήμα.
Λύση: Οι διαγώνιοι του ρόμβου τέμνονται κάθετα και διχοτομούνται· γενικά δεν είναι ίσες (ίσες είναι μόνο στο τετράγωνο).

♾️ Γεννήτρια — ρόμβος

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Ρόμβος $AB\Gamma\Delta$ έχει $\hat A = 146^\circ$. Να βρείτε τη $\hat B$ και τη γωνία $\Gamma\hat A B$ που σχηματίζει η διαγώνιος $A\Gamma$ με την πλευρά $AB$.
Λύση: $\hat B = 180^\circ - 146^\circ = 34^\circ$. Οι διαγώνιοι του ρόμβου διχοτομούν τις γωνίες του: $\Gamma\hat AB = \frac{146^\circ}{2} = 73^\circ$.
