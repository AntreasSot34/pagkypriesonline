3.5

Τετράγωνο

📘 Α΄ Τεύχος §3 · σελ. 126 · Δραστηριότητες σελ. 129

Θεωρία

✓ Εξεταστέα ύλη

Η παράγραφος περιλαμβάνεται στην εξεταστέα ύλη της ενιαίας τελικής γραπτής εξέτασης της Β΄ Γυμνασίου (2025–26).

Ορισμός

Τετράγωνο ονομάζεται το τετράπλευρο που έχει τις πλευρές του ίσες και τις γωνίες του ορθές. Κάθε τετράγωνο είναι παραλληλόγραμμο, ορθογώνιο και ρόμβος.

Ιδιότητες

Έχει όλες τις ιδιότητες του παραλληλογράμμου, του ορθογωνίου και του ρόμβου. Οι διαγώνιοί του:

  • είναι κάθετες,
  • είναι ίσες και διχοτομούνται, άρα $OA = OB = O\Gamma = O\Delta$,
  • διχοτομούν τις γωνίες του, άρα σχηματίζουν με τις πλευρές γωνίες $45^\circ$.

Υπολογισμοί

$E = \alpha^2$, $\Pi = 4\alpha$. Με το Πυθαγόρειο: $\delta^2 = \alpha^2 + \alpha^2 = 2\alpha^2$, δηλαδή $\delta = \alpha\sqrt2$. Π.χ. $\alpha = 10$: $\delta = \sqrt{200} = \sqrt{100\cdot 2} = 10\sqrt2$, $OA = 5\sqrt2$.

Ως ρόμβος: $E = \frac{\delta\cdot\delta}{2} = \frac{\delta^2}{2}$.

Πειραματίσου

Τετράγωνο ΑΒΓΔ
Απέναντι πλευρές ίσες: ΑΒ = ΓΔ = 6, ΑΔ = ΒΓ = 6
Απέναντι γωνίες ίσες: ∠Α = ∠Γ = 90°, ∠Β = ∠Δ = 90° (διαδοχικές γωνίες παραπληρωματικές)
Οι διαγώνιοι διχοτομούνται: ΟΑ = ΟΓ = 4,24, ΟΒ = ΟΔ = 4,24
Οι διαγώνιοι είναι ίσες: ΑΓ = ΒΔ = 8,49
Οι διαγώνιοι είναι κάθετες και διχοτομούν τις γωνίες (π.χ. η ΑΓ χωρίζει την ∠Α σε 45° + 45°)
E = δ₁·δ₂/2 = 8,49·8,49/2 ≈ 36 (= α·υ = 36) · Π = 2(6 + 6) = 24

Ασκήσεις — 0/7 λυμένες

Άσκηση 1Βασική
Τετράγωνο $AB\Gamma\Delta$ με κέντρο $O$ έχει πλευρά $6$ cm. Η διαγώνιος γράφεται $B\Delta = \kappa\sqrt2$ cm και $OA = \lambda\sqrt2$ cm. Να βρείτε τα $\kappa$, $\lambda$ και τη γωνία $A\hat B\Delta$.
Υπόδειξη: $B\Delta^2 = 6^2 + 6^2$.
Λύση: $B\Delta^2 = 72 \Rightarrow B\Delta = \sqrt{36\cdot 2} = 6\sqrt2$. $OA = \frac{6\sqrt2}{2} = 3\sqrt2$. Η διαγώνιος διχοτομεί την ορθή γωνία: $45^\circ$.
Άσκηση 2Μέτρια
Η διαγώνιος ενός τετραγώνου είναι $\sqrt{50}$ cm. Να βρείτε την πλευρά και το εμβαδόν του.
Υπόδειξη: $2\alpha^2 = 50$.
Λύση: $\alpha^2 + \alpha^2 = 50 \Rightarrow \alpha^2 = 25 \Rightarrow \alpha = 5$ cm, $E = 25$ cm².
Άσκηση 3Μέτρια
Ένα τετράγωνο είναι ισεμβαδικό με ορθογώνιο που έχει περίμετρο $40$ cm και μήκος τετραπλάσιο του πλάτους του. Να βρείτε το εμβαδόν και την πλευρά του τετραγώνου.
Υπόδειξη: $2(4\beta + \beta) = 40$.
Λύση: $10\beta = 40 \Rightarrow \beta = 4$, μήκος $16$, $E = 64$ cm². $\alpha^2 = 64 \Rightarrow \alpha = 8$ cm.
Άσκηση 4Μέτρια
Η πλευρά ενός τετραγώνου είναι ίση με τη διαγώνιο ορθογωνίου με διαστάσεις $5$ cm και $12$ cm. Να βρείτε το εμβαδόν του τετραγώνου.
Υπόδειξη: Διαγώνιος: $\sqrt{25 + 144}$.
Λύση: $\delta^2 = 25 + 144 = 169 \Rightarrow \delta = 13$ cm, άρα $E = 13^2 = 169$ cm² (ή κατευθείαν $E = \delta^2 = 169$).
Άσκηση 5Μέτρια
Αν δεκαπλασιαστεί η πλευρά ενός τετραγώνου, πόσες φορές μεγαλώνει (α) η περίμετρός του, (β) το εμβαδόν του;
Υπόδειξη: $\Pi = 4\alpha$, $E = \alpha^2$.
Λύση: $4\cdot 10\alpha = 10\cdot 4\alpha$: δεκαπλάσια. $(10\alpha)^2 = 100\alpha^2$: εκατονταπλάσιο.
Άσκηση 6Βασική
Κάθε ορθογώνιο είναι και τετράγωνο.
Υπόδειξη: Πρέπει και οι πλευρές να είναι ίσες.
Λύση: Λάθος: ένα ορθογώνιο $6\times 4$ δεν έχει ίσες πλευρές. Αντίθετα, κάθε τετράγωνο είναι ορθογώνιο.
Άσκηση 7Μέτρια
Ποια ιδιότητα έχει κάθε τετράγωνο, αλλά όχι κάθε ορθογώνιο;
Υπόδειξη: Ιδιότητα του ρόμβου.
Λύση: Η καθετότητα των διαγωνίων είναι ιδιότητα του ρόμβου· το τετράγωνο την έχει, ενώ ένα μη τετράγωνο ορθογώνιο όχι.

♾️ Γεννήτρια — τετράγωνο

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Τετράγωνο έχει περίμετρο $32$ m. Να βρείτε την πλευρά και το εμβαδόν του.
Λύση: $4\alpha = 32 \Rightarrow \alpha = 8$ m, $E = 8^2 = 64$ m².
