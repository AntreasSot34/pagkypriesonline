Διαίρεση πολυωνύμων

📘 Α΄ Τεύχος §2 · σελ. 91 · Δραστηριότητες σελ. 94 · Ενότητας σελ. 96

Θεωρία

✓ Εξεταστέα ύλη

Η παράγραφος περιλαμβάνεται στην εξεταστέα ύλη της ενιαίας τελικής γραπτής εξέτασης της Β΄ Γυμνασίου (2025–26).

Πολυώνυμο διά μονώνυμο

Διαιρούμε κάθε όρο του πολυωνύμου με το μονώνυμο και προσθέτουμε τα πηλίκα:

$$(12x^5 - 6x^3) : (2x^3) = 6x^2 - 3, \qquad \frac{24x^4y^2 - 30x^3y}{-6x^2y} = -4x^2y + 5x.$$

Πολυώνυμο διά πολυώνυμο

Για τη διαίρεση $\Delta(x) : \delta(x)$ (διαιρετέος, διαιρέτης $\delta(x) \ne 0$) υπάρχει μοναδικό ζεύγος πολυωνύμων $\pi(x)$ (πηλίκο) και $\upsilon(x)$ (υπόλοιπο) ώστε

$$\Delta(x) = \delta(x)\cdot\pi(x) + \upsilon(x) \quad\text{(ταυτότητα της ευκλείδειας διαίρεσης)},$$

όπου $\upsilon(x) = 0$ ή έχει βαθμό μικρότερο από τον βαθμό του $\delta(x)$. Ο βαθμός του $\Delta(x)$ ισούται με το άθροισμα των βαθμών του $\delta(x)$ και του $\pi(x)$. Αν $\upsilon(x) = 0$ η διαίρεση είναι τέλεια και το $\delta(x)$ είναι παράγοντας του $\Delta(x)$.

Ο αλγόριθμος

  1. Γράφουμε διαιρετέο και διαιρέτη κατά τις φθίνουσες δυνάμεις.
  2. Διαιρούμε τον πρώτο όρο του διαιρετέου με τον πρώτο όρο του διαιρέτη: βρίσκουμε τον πρώτο όρο του πηλίκου.
  3. Πολλαπλασιάζουμε τον όρο αυτό με τον διαιρέτη και προσθέτουμε το αντίθετο του γινομένου στον διαιρετέο: προκύπτει το μερικό υπόλοιπο.
  4. Επαναλαμβάνουμε με το μερικό υπόλοιπο, μέχρι να έχει μικρότερο βαθμό από τον διαιρέτη.

Π.χ. $(6x^2 + 5x + 3) : (2x + 1)$: πηλίκο $3x + 1$, υπόλοιπο $2$, και πράγματι $(2x + 1)(3x + 1) + 2 = 6x^2 + 5x + 3$.

Πειραματίσου

$6x^{2} + 5x + 3$$2x + 1$
$-6x^{2} - 3x$$3x + 1$
$2x + 3$
$-2x - 1$
$2$
Πηλίκο $\pi(x) = 3x + 1$, υπόλοιπο $\upsilon(x) = 2$.
Ταυτότητα της ευκλείδειας διαίρεσης: $6x^{2} + 5x + 3 = (2x + 1)(3x + 1) + 2$
Η διαδικασία σταματά όταν το μερικό υπόλοιπο έχει μικρότερο βαθμό από τον διαιρέτη. Κάθε φορά διαιρούμε τον πρώτο όρο του (μερικού) διαιρετέου με τον πρώτο όρο του διαιρέτη, πολλαπλασιάζουμε και προσθέτουμε το αντίθετο.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Να κάνετε τη διαίρεση $(12x^4 - 8x^3 + 4x^2) : (4x^2)$.
Υπόδειξη: Κάθε όρος διά $4x^2$· προσοχή στο $4x^2 : 4x^2$.
Λύση: $3x^2 - 2x + 1$ (το $4x^2 : 4x^2 = 1$, όχι $0$).
Άσκηση 2Βασική
Να κάνετε τη διαίρεση $(15x^3 - 10x^2) : (-5x)$.
Υπόδειξη: Διαιρέτης αρνητικός: αλλάζουν τα πρόσημα.
Λύση: $\frac{15x^3}{-5x} - \frac{10x^2}{-5x} = -3x^2 + 2x$.
Άσκηση 3Βασική
Να κάνετε τη διαίρεση $(x^2 - 7x + 10) : (x - 2)$. Το πηλίκο είναι της μορφής $x + \kappa$· να βρείτε το $\kappa$ και το υπόλοιπο.
Υπόδειξη: $x^2 : x = x$, μετά προσθέτουμε $-x^2 + 2x$.
Λύση: $x^2 - 7x + 10 - (x^2 - 2x) = -5x + 10$, και $-5x : x = -5$, $-5x + 10 - (-5x + 10) = 0$. Πηλίκο $x - 5$, υπόλοιπο $0$ (τέλεια διαίρεση).
Άσκηση 4Μέτρια
Να κάνετε τη διαίρεση $(2x^2 + 5x - 1) : (x + 3)$. Το πηλίκο είναι $\alpha x + \beta$· να βρείτε τα $\alpha$, $\beta$ και το υπόλοιπο $\upsilon$.
Υπόδειξη: Πρώτος όρος πηλίκου: $2x^2 : x$.
Λύση: $2x^2 : x = 2x$· $2x(x + 3) = 2x^2 + 6x$, μερικό υπόλοιπο $-x - 1$. Μετά $-x : x = -1$· $-1(x + 3) = -x - 3$, υπόλοιπο $-x - 1 + x + 3 = 2$. Πηλίκο $2x - 1$, υπόλοιπο $2$. Έλεγχος: $(x + 3)(2x - 1) + 2 = 2x^2 + 5x - 1$.
Άσκηση 5Μέτρια
Να κάνετε τη διαίρεση $(6x^2 - x - 2) : (2x + 1)$. Το πηλίκο είναι $\alpha x + \beta$· να βρείτε τα $\alpha$, $\beta$ και το υπόλοιπο $\upsilon$.
Υπόδειξη: $6x^2 : 2x = 3x$.
Λύση: $3x(2x + 1) = 6x^2 + 3x$, μερικό υπόλοιπο $-4x - 2$· $-4x : 2x = -2$, $-2(2x + 1) = -4x - 2$, υπόλοιπο $0$. Πηλίκο $3x - 2$, τέλεια διαίρεση.
Άσκηση 6Μέτρια
Να βρείτε το πολυώνυμο το οποίο, όταν διαιρεθεί με το $x - 2$, δίνει πηλίκο $2x + 3$ και υπόλοιπο $4$.
Υπόδειξη: $\Delta = \delta\cdot\pi + \upsilon$.
Λύση: $\Delta(x) = (x - 2)(2x + 3) + 4 = 2x^2 + 3x - 4x - 6 + 4 = 2x^2 - x - 2$.
Άσκηση 7Μέτρια
Είναι το $x - 3$ παράγοντας του πολυωνύμου $x^2 - 5x + 6$;
Υπόδειξη: Κάνε τη διαίρεση $(x^2 - 5x + 6) : (x - 3)$.
Λύση: Πηλίκο $x - 2$, υπόλοιπο $0$: $(x - 3)(x - 2) = x^2 - 5x + 6$. Άρα είναι παράγοντας.
Άσκηση 8Απαιτητική
Να βρείτε την τιμή του $\alpha$, ώστε η διαίρεση $(x^2 + 2x + \alpha) : (x - 3)$ να είναι τέλεια.
Υπόδειξη: Κάνε τη διαίρεση: το υπόλοιπο βγαίνει $\alpha + 15$.
Λύση: $x^2 : x = x$, μερικό υπόλοιπο $5x + \alpha$· $5x : x = 5$, $5(x - 3) = 5x - 15$, υπόλοιπο $\alpha + 15$. Τέλεια διαίρεση: $\alpha + 15 = 0 \Rightarrow \alpha = -15$.
Άσκηση 9Βασική
Ένα πολυώνυμο 3ου βαθμού διαιρείται με ένα πολυώνυμο 1ου βαθμού. Το πηλίκο είναι:
Υπόδειξη: Βαθμός $\Delta$ = βαθμός $\delta$ + βαθμός $\pi$.
Λύση: $3 = 1 + \text{βαθμός } \pi$, άρα το πηλίκο είναι 2ου βαθμού.

♾️ Γεννήτρια — διαίρεση πολυωνύμων

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να κάνετε τη διαίρεση $(2x^{2} - 10x + 16) : (x - 3)$. Το πηλίκο είναι της μορφής $\alpha x + \beta$· να βρείτε τα $\alpha$, $\beta$ και το υπόλοιπο $\upsilon$.
Λύση: $\frac{2x^{2}}{x} = 2x$, πολλαπλασιάζουμε και αφαιρούμε: μένει $-4x + 16$. Μετά $\frac{-4x}{x} = -4$ και υπόλοιπο $4$. Άρα πηλίκο $2x - 4$, υπόλοιπο $4$. Έλεγχος: $(x - 3)(2x - 4) + 4 = 2x^{2} - 10x + 16$.
