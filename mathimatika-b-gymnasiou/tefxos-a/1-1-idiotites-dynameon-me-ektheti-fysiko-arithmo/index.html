1.1

Ιδιότητες δυνάμεων με εκθέτη φυσικό αριθμό

📘 Α΄ Τεύχος §1 · σελ. 18 · Δραστηριότητες σελ. 23

Θεωρία

✓ Εξεταστέα ύλη

Η παράγραφος περιλαμβάνεται στην εξεταστέα ύλη της ενιαίας τελικής γραπτής εξέτασης της Β΄ Γυμνασίου (2025–26).

Δύναμη

Το γινόμενο $\underbrace{\alpha\cdot\alpha\cdots\alpha}_{\nu\ \text{παράγοντες}}$ ($\nu > 1$) συμβολίζεται $\alpha^\nu$: βάση $\alpha$, εκθέτης $\nu$. Ορίζεται $\alpha^1 = \alpha$ και $\alpha^0 = 1$ ($\alpha \ne 0$). Προτεραιότητα: δυνάμεις → πολλαπλασιασμοί/διαιρέσεις → προσθέσεις/αφαιρέσεις (πρώτα οι παρενθέσεις).

Ιδιότητες ($\mu, \nu$ φυσικοί)

  • $\alpha^\mu\cdot\alpha^\nu = \alpha^{\mu+\nu}$   π.χ. $(+3)^2\cdot(+3)^4 = (+3)^6$
  • $\alpha^\mu : \alpha^\nu = \dfrac{\alpha^\mu}{\alpha^\nu} = \alpha^{\mu-\nu}$ ($\mu > \nu$, $\alpha \ne 0$)   π.χ. $(-2)^6 : (-2)^3 = (-2)^3$
  • $(\alpha^\mu)^\nu = \alpha^{\mu\cdot\nu}$   π.χ. $(2^5)^4 = 2^{20}$
  • $(\alpha\cdot\beta)^\nu = \alpha^\nu\cdot\beta^\nu$   και   $\left(\dfrac\alpha\beta\right)^\nu = \dfrac{\alpha^\nu}{\beta^\nu}$ ($\beta \ne 0$)
  • $\alpha^\mu = \alpha^\nu \iff \mu = \nu$ ($\alpha \ne 0, \pm 1$)   π.χ. $5^x = 5^2 \iff x = 2$

Προσοχή

Δεν υπάρχει ιδιότητα για το άθροισμα: $2^3 + 2^3 \ne 2^6$. Μπορούμε όμως να βγάλουμε κοινό παράγοντα: $2^3 + 2^3 + 2^3 + 2^3 = 4\cdot 2^3 = 2^2\cdot 2^3 = 2^5$.
Για να εφαρμόσουμε τις ιδιότητες, γράφουμε τους αριθμούς ως δυνάμεις με την ίδια βάση: $3\cdot 9\cdot 81 = 3^1\cdot 3^2\cdot 3^4 = 3^7$ και $(-3)^2\cdot(+3)^3 = 3^2\cdot 3^3 = 3^5$.

Πειραματίσου

24 · 22 = 24+2 = 26 = 64
Κάθε κουτάκι είναι ένας παράγοντας ίσος με τη βάση. Στο γινόμενο οι παράγοντες «μαζεύονται» (προσθέτουμε εκθέτες), στο πηλίκο απλοποιούνται (αφαιρούμε εκθέτες), στη δύναμη δύναμης επαναλαμβάνονται (πολλαπλασιάζουμε εκθέτες).

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Να γράψετε κάθε παράσταση ως μία δύναμη και να δώσετε τον εκθέτη: (α) $5^3\cdot 5^6$, (β) $(-7)^5 : (-7)^3$, (γ) $(11^5 : 11^2)\cdot 11^3$.
Υπόδειξη: Γινόμενο: προσθέτουμε εκθέτες· πηλίκο: αφαιρούμε.
Λύση: (α) $5^{3+6} = 5^9$. (β) $(-7)^{5-3} = (-7)^2$. (γ) $11^{3}\cdot 11^3 = 11^6$.
Άσκηση 2Μέτρια
Να γράψετε ως μία δύναμη με βάση το $3$ ή το $2$ και να δώσετε τον εκθέτη: (α) $3\cdot 9\cdot 81 = 3^{?}$, (β) $2^3 + 2^3 + 2^3 + 2^3 = 2^{?}$.
Υπόδειξη: $9 = 3^2$, $81 = 3^4$· στο (β) κοινός παράγοντας $2^3$.
Λύση: (α) $3^1\cdot 3^2\cdot 3^4 = 3^7$. (β) $4\cdot 2^3 = 2^2\cdot 2^3 = 2^5$.
Άσκηση 3Βασική
Να γράψετε ως μία δύναμη με βάση το $5$ και να δώσετε τον εκθέτη: (α) $(5^4)^2$, (β) $(25\cdot 5)^4$.
Υπόδειξη: $(\alpha^\mu)^\nu = \alpha^{\mu\nu}$, $25 = 5^2$.
Λύση: (α) $5^{4\cdot 2} = 5^8$. (β) $(5^2\cdot 5)^4 = (5^3)^4 = 5^{12}$.
Άσκηση 4Μέτρια
Να υπολογίσετε χωρίς υπολογιστική μηχανή: (α) $\dfrac{20^3}{5^3}$, (β) $(-2)^5\cdot(-5)^5$.
Υπόδειξη: $\frac{\alpha^\nu}{\beta^\nu} = \left(\frac\alpha\beta\right)^\nu$ και $\alpha^\nu\beta^\nu = (\alpha\beta)^\nu$.
Λύση: (α) $\left(\frac{20}{5}\right)^3 = 4^3 = 64$. (β) $[(-2)(-5)]^5 = 10^5 = 100\,000$.
Άσκηση 5Βασική
Ισχύει $(-2)^5 + (-2)^3 = (-2)^8$.
Υπόδειξη: Υπάρχει ιδιότητα για το άθροισμα δυνάμεων;
Λύση: Λάθος: $(-2)^5 + (-2)^3 = -32 - 8 = -40$, ενώ $(-2)^8 = 256$. Οι εκθέτες προστίθενται μόνο στο γινόμενο.
Άσκηση 6Μέτρια
Να βρείτε την τιμή του $x$ ώστε να ισχύει: (α) $2^{x - 1} = 2^8$, (β) $25^{x + 1} = 5^6$.
Υπόδειξη: Ίσες δυνάμεις με ίδια βάση ⇒ ίσοι εκθέτες· $25 = 5^2$.
Λύση: (α) $x - 1 = 8 \iff x = 9$. (β) $5^{2(x+1)} = 5^6 \iff 2x + 2 = 6 \iff x = 2$.
Άσκηση 7Μέτρια
Για κάθε μονάδα που μειώνεται το pH ενός διαλύματος, η οξύτητά του δεκαπλασιάζεται. Το αποσταγμένο νερό έχει pH $7$ και ο χυμός λεμονιού pH $3$. Πόσες φορές πιο όξινος είναι ο χυμός λεμονιού;
Υπόδειξη: Διαφορά $4$ μονάδων: $10\cdot 10\cdot 10\cdot 10$.
Λύση: $10^{7-3} = 10^4 = 10\,000$ φορές.
Άσκηση 8Απαιτητική
Ένας ιός τριπλασιάζει κάθε μέρα τα μολυσμένα αρχεία ενός υπολογιστή. Σήμερα τα μολυσμένα αρχεία είναι $3^7$. Πόσα ήταν πριν από $4$ μέρες;
Υπόδειξη: Πηγαίνοντας μία μέρα πίσω διαιρούμε με $3$.
Λύση: $3^7 : 3^4 = 3^3 = 27$ αρχεία.

♾️ Γεννήτρια — ιδιότητες δυνάμεων

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να γράψετε ως μία δύναμη: $\left((-3)^{2}\right)^{4}$. Ποιος είναι ο εκθέτης;
Λύση: $(\alpha^\mu)^\nu = \alpha^{\mu\nu}$: $\ \left((-3)^{2}\right)^{4} = (-3)^{8}$.
