5.1

Η παραβολή y = α(x + κ)² + λ

📘 Β΄ Τεύχος §5.1.1–5.1.3 · Δραστηριότητες σελ. 14, 20, 28

Θεωρία

$y = \alpha x^2$, $\alpha \ne 0$

Πεδίο ορισμού $\mathbb{R}$, κορυφή $O(0, 0)$, άξονας συμμετρίας ο $y'y$ ($x = 0$).

  • $\alpha > 0$: «ανοίγει» προς τα πάνω, ελάχιστη τιμή $0$, σύνολο τιμών $[0, +\infty)$.
  • $\alpha < 0$: «ανοίγει» προς τα κάτω, μέγιστη τιμή $0$, σύνολο τιμών $(-\infty, 0]$.
  • Όσο μεγαλώνει το $|\alpha|$, τόσο η παραβολή «κλείνει» (πλησιάζει τον $y'y$).

Μετατοπίσεις

$y = \alpha x^2 + \lambda$: κατακόρυφη μετατόπιση κατά $|\lambda|$ — πάνω αν $\lambda > 0$, κάτω αν $\lambda < 0$. Κορυφή $(0, \lambda)$.

$y = \alpha(x + \kappa)^2$: οριζόντια μετατόπιση κατά $|\kappa|$ — αριστερά αν $\kappa > 0$, δεξιά αν $\kappa < 0$. Κορυφή $(-\kappa, 0)$.

$$y = \alpha(x + \kappa)^2 + \lambda: \quad \text{κορυφή } K(-\kappa, \lambda), \quad \text{άξονας } x = -\kappa$$

Για $\alpha > 0$ ελάχιστη τιμή $\lambda$· για $\alpha < 0$ μέγιστη τιμή $\lambda$.

Προσοχή στο πρόσημο

Η $y = (x - 3)^2$ μετατοπίζεται δεξιά κατά 3 (κορυφή $(3, 0)$), όχι αριστερά!

Πειραματίσου

y = (x − 2)² − 3
Κορυφή (2, -3) · άξονας συμμετρίας x = 2 · ελάχιστη τιμή -3, σύνολο τιμών [-3, +∞)
Γκρι: y = x². Το α «ανοίγει/κλείνει» και αναποδογυρίζει την παραβολή, το κ τη μετατοπίζει οριζόντια (κ > 0 ⇒ αριστερά!), το λ κατακόρυφα.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Ποια από τις παραβολές παρουσιάζει ελάχιστη τιμή;
Υπόδειξη: Ελάχιστη τιμή έχει όταν $\alpha > 0$.
Λύση: Μόνο η $f(x) = \frac13x^2$ έχει $\alpha = \frac13 > 0$: ελάχιστη τιμή $0$ στο $x = 0$. Οι υπόλοιπες έχουν μέγιστη.
Άσκηση 2Βασική
Για ποια τιμή του $\lambda$ η παραβολή $y = (\lambda - 3)x^2$ διέρχεται από το σημείο $(-1, 2)$; Για ποια $\lambda$ παρουσιάζει ελάχιστη τιμή;
Υπόδειξη: Αντικατάστησε $x = -1$, $y = 2$. Ελάχιστη όταν ο συντελεστής του $x^2$ είναι θετικός.
Λύση: $2 = (\lambda - 3)(-1)^2 \Rightarrow \lambda = 5$. Ελάχιστη όταν $\lambda - 3 > 0$, δηλαδή $\lambda > 3$.
Άσκηση 3Βασική
Για ποια τιμή του $\kappa$ η παραβολή $y = (\kappa + 2)x^2$, $\kappa \ne -2$, διέρχεται από το σημείο $(2, -4)$;
Υπόδειξη: $-4 = (\kappa + 2)\cdot 4$.
Λύση: $-4 = 4(\kappa + 2) \Rightarrow \kappa + 2 = -1 \Rightarrow \kappa = -3$.
Άσκηση 4Βασική
Να γράψετε την εξίσωση της παραβολής που προκύπτει αν μετατοπίσουμε την $y = x^2$ κατά $1$ μονάδα αριστερά και $2$ μονάδες πάνω.
Υπόδειξη: Αριστερά κατά 1 ⇒ $x \to x + 1$. Πάνω κατά 2 ⇒ $+2$.
Λύση: $y = (x + 1)^2 + 2$, με κορυφή $(-1, 2)$.
Άσκηση 5Μέτρια
Να γράψετε την εξίσωση της παραβολής που προκύπτει αν μετατοπίσουμε την $y = -2x^2$ κατά $2$ μονάδες δεξιά.
Υπόδειξη: Δεξιά κατά 2 ⇒ $x \to x - 2$.
Λύση: $y = -2(x - 2)^2$, κορυφή $(2, 0)$, μέγιστη τιμή $0$.
Άσκηση 6Μέτρια
Δίνεται η $f(x) = 2(x + 4)^2 - 3$. Να βρείτε την κορυφή και το ακρότατο.
Υπόδειξη: Κορυφή $(-\kappa, \lambda)$ με $\kappa = 4$, $\lambda = -3$.
Λύση: Κορυφή $K(-4, -3)$, άξονας $x = -4$. Αφού $\alpha = 2 > 0$: ελάχιστη τιμή $-3$, σύνολο τιμών $[-3, +\infty)$.
Άσκηση 7Μέτρια
Η $g(x) = -3(x - 2)^2 + 1$ έχει:
Υπόδειξη: $\alpha = -3 < 0$ και κορυφή $(2, 1)$.
Λύση: Κορυφή $(2, 1)$ και $\alpha < 0$ ⇒ μέγιστη τιμή $1$ στο $x = 2$, σύνολο τιμών $(-\infty, 1]$.
Άσκηση 8Μέτρια
Να βρείτε τον άξονα συμμετρίας και την κορυφή της $h(x) = x^2 - 2x + 1$.
Υπόδειξη: Αναγνώρισε ταυτότητα: $x^2 - 2x + 1 = (x - 1)^2$.
Λύση: $h(x) = (x - 1)^2$: άξονας $x = 1$, κορυφή $(1, 0)$.

Εξάσκηση #1
Δίνεται η συνάρτηση $f(x) = -2x^2 + 20x - 51$. Να βρείτε την κορυφή της παραβολής και την μέγιστη τιμή της $f$.
Λύση: $x_K = -\frac{\beta}{2\alpha} = -\frac{20}{-4} = 5$, $\;y_K = f(5) = -1$.
Αφού $\alpha = -2 < 0$, η $f$ έχει μέγιστη τιμή $-1$ στο $x = 5$. Σε μορφή κορυφής: $f(x) = -2(x - 5)^2 - 1$.
