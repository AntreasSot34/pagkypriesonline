3.3

Εγγεγραμμένα τετράπλευρα σε κύκλο

📘 Α΄ Τεύχος §3.3 · Δραστηριότητες σελ. 122

Θεωρία

Ορισμός και θεώρημα

Ένα τετράπλευρο είναι εγγεγραμμένο σε κύκλο όταν και οι τέσσερις κορυφές του είναι σημεία του κύκλου.

Θεώρημα: Κάθε εγγεγραμμένο τετράπλευρο έχει τις απέναντι γωνίες παραπληρωματικές:

$$\hat A + \hat\Gamma = 180^\circ \qquad \hat B + \hat\Delta = 180^\circ$$

Γιατί; Οι $\hat A$ και $\hat\Gamma$ βαίνουν σε δύο τόξα που μαζί κάνουν ολόκληρο τον κύκλο: $\frac{360^\circ}{2} = 180^\circ$.

Χρήσιμα

  • Κάθε εξωτερική γωνία εγγεγραμμένου τετραπλεύρου ισούται με την απέναντι εσωτερική.
  • Κάθε γωνία είναι το μισό του τόξου στο οποίο βαίνει: π.χ. $\hat A = \frac{\overset{\frown}{B\Gamma} + \overset{\frown}{\Gamma\Delta}}{2}$.
  • Από τα παραλληλόγραμμα, μόνο το ορθογώνιο (και το τετράγωνο) εγγράφεται σε κύκλο.

Πειραματίσου

Α + Γ = 87,5° + 92,5° = 180°  ·  Β + Δ = 75° + 105° = 180°
Όπως κι αν μετακινήσεις τις κορυφές πάνω στον κύκλο, οι απέναντι γωνίες είναι παραπληρωματικές.

Ασκήσεις — 0/7 λυμένες

Άσκηση 1Βασική
Το τετράπλευρο $AB\Gamma\Delta$ είναι εγγεγραμμένο σε κύκλο, με $\hat A = 70^\circ$ και $\hat B = 95^\circ$. Να βρείτε τις $\hat\Gamma$ και $\hat\Delta$.
Υπόδειξη: Απέναντι γωνίες: $A$ με $\Gamma$, $B$ με $\Delta$.
Λύση: $\hat\Gamma = 180^\circ - 70^\circ = 110^\circ$, $\hat\Delta = 180^\circ - 95^\circ = 85^\circ$.
Άσκηση 2Βασική
Σε εγγεγραμμένο τετράπλευρο $AB\Gamma\Delta$ ισχύει $\hat A = 2\hat\Gamma$. Να βρείτε τις $\hat A$, $\hat\Gamma$.
Υπόδειξη: $\hat A + \hat\Gamma = 180^\circ$.
Λύση: $2\hat\Gamma + \hat\Gamma = 180^\circ \Rightarrow \hat\Gamma = 60^\circ$, $\hat A = 120^\circ$.
Άσκηση 3Μέτρια
Σε κύκλο θεωρούμε τα διαδοχικά τόξα $\overset{\frown}{AB} = 90^\circ$, $\overset{\frown}{B\Gamma} = 140^\circ$, $\overset{\frown}{\Gamma\Delta} = 100^\circ$. Να βρείτε τις γωνίες του τετραπλεύρου $AB\Gamma\Delta$.
Υπόδειξη: Το τέταρτο τόξο: $\overset{\frown}{\Delta A} = 360^\circ - 330^\circ = 30^\circ$. Κάθε γωνία = μισό του τόξου που «βλέπει» απέναντι.
Λύση: $\overset{\frown}{\Delta A} = 30^\circ$. $\hat A = \frac{140 + 100}{2} = 120^\circ$, $\hat B = \frac{100 + 30}{2} = 65^\circ$, $\hat\Gamma = \frac{30 + 90}{2} = 60^\circ$, $\hat\Delta = \frac{90 + 140}{2} = 115^\circ$. Έλεγχος: $120 + 60 = 65 + 115 = 180$ ✓.
Άσκηση 4Μέτρια
Στο σχήμα, η $AB$ είναι διάμετρος, η χορδή $\Delta\Gamma \parallel AB$ και το τόξο $\overset{\frown}{B\Gamma} = 60^\circ$. Να βρείτε τη γωνία $\widehat{AB\Gamma}$.
Υπόδειξη: Τόξα ανάμεσα σε παράλληλες χορδές είναι ίσα: $\overset{\frown}{A\Delta} = 60^\circ$. Η $\widehat{AB\Gamma}$ βαίνει στο τόξο $A\Delta\Gamma$.
Λύση: $\overset{\frown}{A\Delta} = \overset{\frown}{B\Gamma} = 60^\circ$, άρα $\overset{\frown}{\Delta\Gamma} = 180^\circ - 120^\circ = 60^\circ$. $\widehat{AB\Gamma} = \frac{60^\circ + 60^\circ}{2} = 60^\circ$. Το $AB\Gamma\Delta$ είναι ισοσκελές τραπέζιο.
Άσκηση 5Μέτρια
Σε εγγεγραμμένο τετράπλευρο $AB\Gamma\Delta$ είναι $\hat A = 3x$ και $\hat\Gamma = x + 20^\circ$. Να βρείτε το $x$ και τη γωνία $\hat A$.
Υπόδειξη: $3x + x + 20 = 180$.
Λύση: $4x = 160 \Rightarrow x = 40^\circ$, $\hat A = 120^\circ$, $\hat\Gamma = 60^\circ$.
Άσκηση 6Βασική
Ποιο τετράπλευρο μπορεί να εγγραφεί σε κύκλο;
Υπόδειξη: Έλεγξε αν οι απέναντι γωνίες έχουν άθροισμα $180^\circ$.
Λύση: Στο ορθογώνιο όλες οι γωνίες είναι $90^\circ$: $90 + 90 = 180$ ✓. Στο πρώτο $80 + 95 = 175 \ne 180$. Σε ρόμβο ή παραλληλόγραμμο (μη ορθογώνιο) οι απέναντι γωνίες είναι ίσες και όχι $90^\circ$, άρα δεν είναι παραπληρωματικές.
Άσκηση 7Μέτρια
Σε εγγεγραμμένο τετράπλευρο $AB\Gamma\Delta$ είναι $\hat\Delta = 80^\circ$. Προεκτείνουμε την πλευρά $AB$ πέρα από το $B$. Πόση είναι η εξωτερική γωνία στην κορυφή $B$;
Υπόδειξη: Εξωτερική $= 180^\circ - \hat B$, και $\hat B = 180^\circ - \hat\Delta$.
Λύση: $\hat B = 100^\circ$, εξωτερική $= 180^\circ - 100^\circ = 80^\circ = \hat\Delta$ — η εξωτερική ισούται με την απέναντι εσωτερική.

♾️ Γεννήτρια — γωνίες στον κύκλο

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Επίκεντρη γωνία $\widehat{AOB} = 76^\circ$. Πόση είναι κάθε εγγεγραμμένη γωνία που βαίνει στο ίδιο τόξο $\overset{\frown}{AB}$;
Λύση: Εγγεγραμμένη = μισό της αντίστοιχης επίκεντρης: $\frac{76^\circ}{2} = 38^\circ$.
