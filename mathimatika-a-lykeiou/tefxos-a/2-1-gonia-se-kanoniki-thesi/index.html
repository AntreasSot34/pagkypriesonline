2.1

Γωνία σε κανονική θέση

📘 Α΄ Τεύχος §2.1 · Δραστηριότητες σελ. 56

Θεωρία

Κανονική θέση

Μια γωνία είναι σε κανονική θέση όταν η κορυφή της είναι η αρχή $O$ των αξόνων και η αρχική πλευρά της είναι ο θετικός ημιάξονας $Ox$. Τη δημιουργεί η περιστροφή της αρχικής πλευράς μέχρι την τελική πλευρά.

  • Θετική γωνία: περιστροφή αντίθετα από τους δείκτες του ρολογιού.
  • Αρνητική γωνία: περιστροφή όπως οι δείκτες του ρολογιού.
  • Γωνίες μεγαλύτερες από $360^\circ$: περισσότερες από μία πλήρεις στροφές.

Ίδια τελική πλευρά

Οι γωνίες $\theta$ και $\theta + \kappa\cdot 360^\circ$, $\kappa \in \mathbb{Z}$, έχουν την ίδια τελική πλευρά.

π.χ. η $120^\circ$ και η $-240^\circ = 120^\circ - 360^\circ$ · η $315^\circ$ και η $675^\circ = 315^\circ + 360^\circ$.

Τεταρτημόρια

Η τελική πλευρά βρίσκεται στο 1ο τεταρτημόριο για $0^\circ < \theta < 90^\circ$, στο 2ο για $90^\circ < \theta < 180^\circ$, στο 3ο για $180^\circ < \theta < 270^\circ$, στο 4ο για $270^\circ < \theta < 360^\circ$. Για άλλες γωνίες, πρώτα «φέρνουμε» τη γωνία στο $[0^\circ, 360^\circ)$.

Πειραματίσου

θ = 135° (θετική — αντίθετα από τους δείκτες του ρολογιού)
Ίδια τελική πλευρά με 135°  ·  τελική πλευρά στο 2ο τεταρτημόριο

Ασκήσεις — 0/7 λυμένες

Άσκηση 1Βασική
Σε ποιο τεταρτημόριο βρίσκεται η τελική πλευρά των γωνιών (α) $236^\circ$, (β) $-52^\circ$, (γ) $370^\circ$, (δ) $-150^\circ$;
Υπόδειξη: Πρόσθεσε ή αφαίρεσε $360^\circ$ ώστε η γωνία να πέσει στο $[0^\circ, 360^\circ)$.
Λύση: (α) $180^\circ < 236^\circ < 270^\circ$: 3ο. (β) $-52^\circ + 360^\circ = 308^\circ$: 4ο. (γ) $370^\circ - 360^\circ = 10^\circ$: 1ο. (δ) $-150^\circ + 360^\circ = 210^\circ$: 3ο.
Άσκηση 2Βασική
Να βρείτε τη γωνία $\theta \in [0^\circ, 360^\circ)$ που έχει την ίδια τελική πλευρά με: (α) $-20^\circ$, (β) $1110^\circ$, (γ) $-1000^\circ$.
Υπόδειξη: $1110 = 3\cdot 360 + 30$. Για αρνητικές, πρόσθεσε $360^\circ$ όσες φορές χρειάζεται.
Λύση: (α) $-20^\circ + 360^\circ = 340^\circ$. (β) $1110^\circ - 3\cdot 360^\circ = 30^\circ$. (γ) $-1000^\circ + 3\cdot 360^\circ = 80^\circ$.
Άσκηση 3Βασική
Ποια γωνία δεν έχει την ίδια τελική πλευρά με τη γωνία $45^\circ$;
Υπόδειξη: Η διαφορά από τη $45^\circ$ πρέπει να είναι ακέραιο πολλαπλάσιο του $360^\circ$.
Λύση: $405 - 45 = 360$ ✓, $-315 - 45 = -360$ ✓, $765 - 45 = 720$ ✓. Αλλά $-45 - 45 = -90$, δεν είναι πολλαπλάσιο του $360$: η $-45^\circ$ έχει τελική πλευρά στο 4ο τεταρτημόριο.
Άσκηση 4Μέτρια
Δύο θετικές γωνίες $x, y < 720^\circ$ σε κανονική θέση έχουν την ίδια τελική πλευρά και η μία είναι τετραπλάσια της άλλης. Να βρείτε τα μέτρα τους.
Υπόδειξη: $x = 4y$ και, αφού διαφέρουν κατά μία στροφή, $x = y + 360^\circ$.
Λύση: $4y = y + 360^\circ \Rightarrow 3y = 360^\circ \Rightarrow y = 120^\circ$, $x = 480^\circ$. (Δύο στροφές θα έδιναν $3y = 720^\circ$, $y = 240^\circ$, $x = 960^\circ > 720^\circ$ — απορρίπτεται.)
Άσκηση 5Μέτρια
Δύο θετικές γωνίες $x, y < 720^\circ$ σε κανονική θέση έχουν την ίδια τελική πλευρά και η μία είναι τριπλάσια της άλλης. Να βρείτε τα μέτρα τους.
Υπόδειξη: $x = 3y$ και $x = y + 360^\circ$.
Λύση: $3y = y + 360^\circ \Rightarrow y = 180^\circ$, $x = 540^\circ$.
Άσκηση 6Μέτρια
Δύο γωνίες $\alpha$ και $\beta$ σε κανονική θέση έχουν την ίδια τελική πλευρά. Ποιο από τα πιο κάτω ισχύει πάντα;
Υπόδειξη: Δοκίμασε $\alpha = 30^\circ$ και $\beta = 390^\circ$.
Λύση: Ίδια τελική πλευρά σημαίνει ότι διαφέρουν κατά ακέραιο αριθμό πλήρων στροφών: $\alpha - \beta = \kappa\cdot 360^\circ$. Το $\alpha + \beta = 360^\circ$ ισχύει μόνο σε ειδικές περιπτώσεις (π.χ. $120^\circ$ και $240^\circ$ δεν έχουν καν ίδια τελική πλευρά).
Άσκηση 7Απαιτητική
Η γωνία $\theta$ έχει την ίδια τελική πλευρά με τη $70^\circ$ και ισχύει $1000^\circ < \theta < 1500^\circ$. Να βρείτε την $\theta$.
Υπόδειξη: $\theta = 70^\circ + \kappa\cdot 360^\circ$. Δοκίμασε $\kappa = 2, 3, 4$.
Λύση: $70 + 2\cdot 360 = 790$, $70 + 3\cdot 360 = 1150$, $70 + 4\cdot 360 = 1510$. Μόνο η $\theta = 1150^\circ$ είναι στο διάστημα.

♾️ Γεννήτρια — τεταρτημόρια και τελική πλευρά

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε τη γωνία $\theta$ με $0^\circ \le \theta < 360^\circ$ που έχει την ίδια τελική πλευρά με τη γωνία $810^\circ$.
Λύση: Προσθέτουμε/αφαιρούμε ακέραια πολλαπλάσια του $360^\circ$: $810^\circ - 2\cdot 360^\circ = 90^\circ$.
