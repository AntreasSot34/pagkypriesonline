1.3

Δυνάμεις με ρητό εκθέτη

📘 Α΄ Τεύχος §1.3 · Δραστηριότητες σελ. 37

Θεωρία

Ορισμός

Για $\alpha > 0$, $\mu \in \mathbb{Z}$, $\nu \in \mathbb{N}$:

$$\alpha^{\frac{\mu}{\nu}} = \sqrt[\nu]{\alpha^\mu} = \left(\sqrt[\nu]{\alpha}\right)^\mu \qquad\text{ειδικά}\qquad \alpha^{\frac1\nu} = \sqrt[\nu]{\alpha}$$

Αρνητικός εκθέτης: $\alpha^{-\frac{\mu}{\nu}} = \dfrac{1}{\sqrt[\nu]{\alpha^\mu}}$. Επίσης ορίζουμε $0^{\frac{\mu}{\nu}} = 0$ για $\mu, \nu \in \mathbb{N}$.

Όλες οι γνωστές ιδιότητες δυνάμεων ισχύουν

$$\alpha^{x}\alpha^{y} = \alpha^{x+y} \qquad \frac{\alpha^x}{\alpha^y} = \alpha^{x-y} \qquad (\alpha^x)^y = \alpha^{xy} \qquad (\alpha\beta)^x = \alpha^x\beta^x$$

π.χ. $16^{\frac34} = \left(\sqrt[4]{16}\right)^3 = 2^3 = 8$ · $\;9^{-\frac12} = \frac13$ · $\;\sqrt5 + 5^{\frac32} = \sqrt5 + 5\sqrt5 = 6\sqrt5$.

Εξισώσεις με ρητό εκθέτη

Υψώνουμε και τα δύο μέλη στον αντίστροφο εκθέτη:

$$x^{\frac23} = 9 \Rightarrow x = 9^{\frac32} = 27 \qquad y^{-\frac32} = 8 \Rightarrow y = 8^{-\frac23} = \tfrac14$$

Η $(x+1)^{\frac12} = -5$ είναι αδύνατη: μια δύναμη θετικής βάσης με ρητό εκθέτη είναι πάντα θετική.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Χωρίς υπολογιστική μηχανή: $8^{\frac13}$, $\;16^{\frac12}$, $\;81^{\frac14}$, $\;4^{\frac32}$.
Υπόδειξη: $\alpha^{\frac{\mu}{\nu}} = \left(\sqrt[\nu]{\alpha}\right)^\mu$: πρώτα η ρίζα, μετά η δύναμη.
Λύση: $\sqrt[3]8 = 2$, $\sqrt{16} = 4$, $\sqrt[4]{81} = 3$, $\left(\sqrt4\right)^3 = 8$.
Άσκηση 2Βασική
Χωρίς υπολογιστική μηχανή: (α) $25^{-\frac12}$, (β) $8^{\frac{10}{6}}$, (γ) $\left(\frac18\right)^{-\frac23}$, (δ) $1^{\frac{1}{20}}$.
Υπόδειξη: (β) Απλοποίησε: $\frac{10}{6} = \frac53$. (γ) Αρνητικός εκθέτης ⇒ αντιστρέφουμε τη βάση: $8^{\frac23}$.
Λύση: (α) $\frac{1}{\sqrt{25}} = \frac15$. (β) $8^{\frac53} = (\sqrt[3]8)^5 = 2^5 = 32$. (γ) $8^{\frac23} = 2^2 = 4$. (δ) $1$.
Άσκηση 3Βασική
Να μετατρέψετε το $\sqrt[3]{5^2}$ σε δύναμη με ρητό εκθέτη:
Υπόδειξη: $\sqrt[\nu]{\alpha^\mu} = \alpha^{\frac{\mu}{\nu}}$: ο δείκτης πάει στον παρονομαστή.
Λύση: $\sqrt[3]{5^2} = 5^{\frac23}$.
Άσκηση 4Μέτρια
Να λύσετε τις εξισώσεις (όπου ορίζονται οι δυνάμεις): (α) $x^{\frac13} = 2$, (β) $x^{\frac23} = 9$, (γ) $x^{-\frac12} = 4$, (δ) $(x + 1)^{\frac13} = 2$.
Υπόδειξη: Ύψωσε στον αντίστροφο εκθέτη: στην 3, στην $\frac32$, στην $-2$, στην 3.
Λύση: (α) $x = 2^3 = 8$. (β) $x = 9^{\frac32} = 3^3 = 27$. (γ) $x = 4^{-2} = \frac1{16}$. (δ) $x + 1 = 2^3 = 8 \Rightarrow x = 7$.
Άσκηση 5Μέτρια
Χωρίς υπολογιστική μηχανή: (α) $2^{\frac43} : \sqrt[3]{2}$, (β) $\sqrt5 + 5^{\frac32}$ (γράψτε στη μορφή $\kappa\sqrt5$), (γ) $25^{\frac14}\cdot 5^{-\frac12}$.
Υπόδειξη: Όλα σε δυνάμεις της ίδιας βάσης: $\sqrt[3]2 = 2^{\frac13}$, $25^{\frac14} = 5^{\frac12}$.
Λύση: (α) $2^{\frac43 - \frac13} = 2^1 = 2$. (β) $5^{\frac32} = 5\sqrt5$, άρα $\sqrt5 + 5\sqrt5 = 6\sqrt5$. (γ) $5^{\frac12}\cdot 5^{-\frac12} = 5^0 = 1$.
Άσκηση 6Μέτρια
Για $x > 0$, να απλοποιήσετε την παράσταση $(8x^6)^{\frac13}$.
Υπόδειξη: $(\alpha\beta)^{\frac13} = \alpha^{\frac13}\beta^{\frac13}$ και $(x^6)^{\frac13} = x^{6\cdot\frac13}$.
Λύση: $8^{\frac13}\cdot x^{6\cdot\frac13} = 2x^2$.
Άσκηση 7Απαιτητική
Για $x > 0$, να απλοποιήσετε την παράσταση $(64x^6)^{-\frac23}$.
Υπόδειξη: $64^{\frac23} = (\sqrt[3]{64})^2 = 16$ και $(x^6)^{\frac23} = x^4$· ο αρνητικός εκθέτης στέλνει όλο το αποτέλεσμα στον παρονομαστή.
Λύση: $(64x^6)^{-\frac23} = \dfrac{1}{(64x^6)^{\frac23}} = \dfrac{1}{16x^4}$.
Άσκηση 8Μέτρια
Η απόσταση (σε m) που διανύει ένα αυτοκίνητο που επιταχύνει δίνεται από τη σχέση $d(t) = 10\,t^{\frac32}$, όπου $t$ ο χρόνος σε s. Πόσο χρόνο κινήθηκε, αν διένυσε $640$ m;
Υπόδειξη: $t^{\frac32} = 64$ ⇒ ύψωσε στην $\frac23$.
Λύση: $10t^{\frac32} = 640 \Rightarrow t^{\frac32} = 64 \Rightarrow t = 64^{\frac23} = (\sqrt[3]{64})^2 = 16$ s.
Άσκηση 9Βασική
Η εξίσωση $(x + 1)^{\frac12} = -5$, $x \ge -1$:
Υπόδειξη: Τι πρόσημο έχει το $(x+1)^{\frac12} = \sqrt{x+1}$;
Λύση: $(x+1)^{\frac12} = \sqrt{x + 1} \ge 0$, άρα δεν μπορεί να ισούται με $-5$. Αδύνατη. (Το $x = 24$ δίνει $\sqrt{25} = +5$, όχι $-5$.)
Άσκηση 10Απαιτητική
Να υπολογίσετε: $\sqrt{\left(\frac{81}{64}\right)^3}$.
Υπόδειξη: $\sqrt{\left(\frac{81}{64}\right)^3} = \left(\frac{81}{64}\right)^{\frac32} = \left(\frac98\right)^3$.
Λύση: $\left(\sqrt{\frac{81}{64}}\right)^3 = \left(\frac98\right)^3 = \frac{729}{512}$.

♾️ Γεννήτρια — ρίζες και δυνάμεις

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να γράψετε τη $\sqrt{28}$ στη μορφή $\alpha\sqrt{7}$.
Λύση: $\sqrt{28} = \sqrt{4\cdot 7} = \sqrt{4}\cdot\sqrt{7} = 2\sqrt{7}$.
