2.4

Αναγωγή σε οξεία γωνία

📘 Α΄ Τεύχος §2.4 · Δραστηριότητες σελ. 79

Θεωρία

Παραπληρωματικές γωνίες: $180^\circ - \theta$

Τα σημεία του τριγωνομετρικού κύκλου για $\theta$ και $180^\circ - \theta$ είναι συμμετρικά ως προς τον άξονα $y'y$: ίδιο $y$, αντίθετο $x$.

$$\text{ημ}(180^\circ - \theta) = \text{ημ}\theta \qquad \text{συν}(180^\circ - \theta) = -\text{συν}\theta$$ $$\text{εφ}(180^\circ - \theta) = -\text{εφ}\theta \qquad \text{σφ}(180^\circ - \theta) = -\text{σφ}\theta$$

π.χ. $\text{ημ}150^\circ = \text{ημ}30^\circ = \frac12$, $\;\text{συν}135^\circ = -\text{συν}45^\circ = -\frac{\sqrt2}{2}$.

Συμπληρωματικές γωνίες: $90^\circ - \theta$

Τα σημεία είναι συμμετρικά ως προς τη διχοτόμο $y = x$: οι συντεταγμένες ανταλλάσσονται.

$$\text{ημ}(90^\circ - \theta) = \text{συν}\theta \qquad \text{συν}(90^\circ - \theta) = \text{ημ}\theta \qquad \text{εφ}(90^\circ - \theta) = \text{σφ}\theta$$

π.χ. $\text{ημ}85^\circ = \text{συν}5^\circ$, $\;\text{συν}45^\circ = \text{ημ}45^\circ$.

Σε τρίγωνο

Αφού $\hat A + \hat B + \hat\Gamma = 180^\circ$: $\;\text{ημ}(B + \Gamma) = \text{ημ}A$ και $\text{συν}(B + \Gamma) = -\text{συν}A$.

Πειραματίσου

Τα σημεία είναι συμμετρικά ως προς τον άξονα y′y: ίδιο y, αντίθετο x.
ημ(145°) = ημ35° = 0,57  ·  συν(145°) = −συν35° = -0,82  ·  εφ(145°) = −εφ35° = -0,7

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Χωρίς υπολογιστική μηχανή: (α) $\text{ημ}150^\circ$, (β) $\text{συν}135^\circ$, (γ) $\text{εφ}120^\circ$, (δ) $\text{συν}150^\circ$.
Υπόδειξη: Γράψε κάθε γωνία ως $180^\circ - $ (οξεία).
Λύση: (α) $\text{ημ}30^\circ = \frac12$. (β) $-\text{συν}45^\circ = -\frac{\sqrt2}{2}$. (γ) $-\text{εφ}60^\circ = -\sqrt3$. (δ) $-\text{συν}30^\circ = -\frac{\sqrt3}{2}$.
Άσκηση 2Βασική
Το $\text{ημ}110^\circ$ είναι ίσο με:
Υπόδειξη: $110^\circ = 180^\circ - 70^\circ$.
Λύση: $\text{ημ}110^\circ = \text{ημ}(180^\circ - 70^\circ) = \text{ημ}70^\circ$. (Ισούται επίσης με $\text{συν}20^\circ$, όχι με $-\text{συν}20^\circ$.)
Άσκηση 3Βασική
Το $\text{συν}140^\circ$ είναι ίσο με:
Υπόδειξη: $140^\circ = 180^\circ - 40^\circ$, και στο 2ο τεταρτημόριο το συνημίτονο είναι αρνητικό.
Λύση: $\text{συν}(180^\circ - 40^\circ) = -\text{συν}40^\circ$.
Άσκηση 4Μέτρια
Να υπολογίσετε: (α) $\dfrac{\text{ημ}160^\circ}{\text{ημ}20^\circ} + \dfrac{\text{συν}160^\circ}{\text{συν}20^\circ}$, (β) $\text{ημ}^2 120^\circ + \text{συν}^2 150^\circ$.
Υπόδειξη: $\text{ημ}160^\circ = \text{ημ}20^\circ$ και $\text{συν}160^\circ = -\text{συν}20^\circ$.
Λύση: (α) $1 + (-1) = 0$. (β) $\text{ημ}120^\circ = \frac{\sqrt3}{2}$, $\text{συν}150^\circ = -\frac{\sqrt3}{2}$: $\frac34 + \frac34 = \frac32$.
Άσκηση 5Μέτρια
Δίνεται ότι $\text{ημ}25^\circ \approx 0{,}4226$. Χωρίς υπολογιστική μηχανή, να βρείτε: (α) $\text{ημ}155^\circ$, (β) $\text{συν}65^\circ$, (γ) $\text{συν}115^\circ$.
Υπόδειξη: $155 = 180 - 25$, $\;65 = 90 - 25$, $\;115 = 180 - 65$.
Λύση: (α) $\text{ημ}155^\circ = \text{ημ}25^\circ \approx 0{,}4226$. (β) $\text{συν}65^\circ = \text{ημ}25^\circ \approx 0{,}4226$. (γ) $\text{συν}115^\circ = -\text{συν}65^\circ \approx -0{,}4226$.
Άσκηση 6Μέτρια
Σε κάθε τρίγωνο $AB\Gamma$ ισχύει:
Υπόδειξη: $B + \Gamma = 180^\circ - A$.
Λύση: $\text{ημ}(B + \Gamma) = \text{ημ}(180^\circ - A) = \text{ημ}A$. (Αντίθετα $\text{συν}(B+\Gamma) = -\text{συν}A$ και $\text{εφ}(B+\Gamma) = -\text{εφ}A$.)
Άσκηση 7Απαιτητική
Να υπολογίσετε την παράσταση $\Pi = \text{ημ}(90^\circ - \alpha) - \text{συν}(90^\circ - \alpha) + \text{ημ}\alpha - \text{συν}\alpha$.
Υπόδειξη: $\text{ημ}(90^\circ - \alpha) = \text{συν}\alpha$, $\;\text{συν}(90^\circ - \alpha) = \text{ημ}\alpha$.
Λύση: $\Pi = \text{συν}\alpha - \text{ημ}\alpha + \text{ημ}\alpha - \text{συν}\alpha = 0$.
Άσκηση 8Μέτρια
Να βρείτε τις γωνίες $x$ με $0^\circ \le x \le 180^\circ$ για τις οποίες $\text{ημ}x = \frac12$ (σε αύξουσα σειρά).
Υπόδειξη: Το ημίτονο είναι θετικό στο 1ο και στο 2ο τεταρτημόριο: $\text{ημ}(180^\circ - \theta) = \text{ημ}\theta$.
Λύση: $\text{ημ}30^\circ = \frac12$ και $\text{ημ}150^\circ = \text{ημ}(180^\circ - 30^\circ) = \frac12$. Λύσεις: $30^\circ$ και $150^\circ$.
Άσκηση 9Μέτρια
Να βρείτε τη γωνία $x$ με $0^\circ \le x \le 180^\circ$ για την οποία $\text{συν}x = -\frac{\sqrt3}{2}$.
Υπόδειξη: Αρνητικό συνημίτονο ⇒ αμβλεία γωνία: $\text{συν}(180^\circ - \theta) = -\text{συν}\theta$.
Λύση: $\text{συν}30^\circ = \frac{\sqrt3}{2}$, άρα $\text{συν}150^\circ = -\frac{\sqrt3}{2}$. Στο $[0^\circ, 180^\circ]$ το συνημίτονο παίρνει κάθε τιμή μία φορά: $x = 150^\circ$.

♾️ Γεννήτρια — τριγωνομετρικοί αριθμοί βασικών γωνιών

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε χωρίς υπολογιστική μηχανή: $\text{ημ}\,150^\circ$.
Λύση: $150^\circ = 180^\circ - 30^\circ$ ⇒ $\text{ημ}150^\circ = \text{ημ}30^\circ = \frac{1}{2}$.
