2.5

Τριγωνομετρικές ταυτότητες

📘 Α΄ Τεύχος §2.5 · Δραστηριότητες σελ. 86, 89

Θεωρία

Βασικές ταυτότητες

$$\text{ημ}^2\theta + \text{συν}^2\theta = 1 \qquad \text{εφ}\theta = \frac{\text{ημ}\theta}{\text{συν}\theta} \qquad \text{σφ}\theta = \frac{\text{συν}\theta}{\text{ημ}\theta} \qquad \text{εφ}\theta\cdot\text{σφ}\theta = 1$$

Η πρώτη προκύπτει από το Πυθαγόρειο θεώρημα στον τριγωνομετρικό κύκλο: $x^2 + y^2 = 1$. Γράφεται και $\text{ημ}^2\theta = 1 - \text{συν}^2\theta$, $\;\text{συν}^2\theta = 1 - \text{ημ}^2\theta$.

Από έναν αριθμό σε όλους

Αν $\text{συν}\varphi = \frac{12}{13}$ και $0^\circ < \varphi < 90^\circ$: $\;\text{ημ}^2\varphi = 1 - \frac{144}{169} = \frac{25}{169}$ ⇒ $\text{ημ}\varphi = \pm\frac{5}{13}$.

Το τεταρτημόριο αποφασίζει το πρόσημο: στο 1ο, $\text{ημ}\varphi = \frac{5}{13}$. Μετά $\text{εφ}\varphi = \frac{5}{12}$, $\text{σφ}\varphi = \frac{12}{5}$.

Απόδειξη ταυτοτήτων

Ξεκινάμε από το πιο «σύνθετο» μέλος και καταλήγουμε στο άλλο: γράφουμε εφ, σφ με ημ, συν και χρησιμοποιούμε $\text{ημ}^2 + \text{συν}^2 = 1$.

π.χ. $\text{συν}^2\theta + \text{συν}^2\theta\,\text{εφ}^2\theta = \text{συν}^2\theta + \text{συν}^2\theta\cdot\frac{\text{ημ}^2\theta}{\text{συν}^2\theta} = \text{συν}^2\theta + \text{ημ}^2\theta = 1$.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Αν $\text{συν}\varphi = \frac{12}{13}$ και $0^\circ < \varphi < 90^\circ$, να υπολογίσετε τους άλλους τριγωνομετρικούς αριθμούς της $\varphi$.
Υπόδειξη: $\text{ημ}^2\varphi = 1 - \text{συν}^2\varphi$, και στο 1ο τεταρτημόριο όλοι είναι θετικοί.
Λύση: $\text{ημ}^2\varphi = 1 - \frac{144}{169} = \frac{25}{169} \Rightarrow \text{ημ}\varphi = \frac{5}{13}$. $\text{εφ}\varphi = \frac{5/13}{12/13} = \frac{5}{12}$, $\text{σφ}\varphi = \frac{12}{5}$.
Άσκηση 2Μέτρια
Αν $\text{ημ}\varphi = -\frac{8}{17}$ και $180^\circ < \varphi < 270^\circ$, να υπολογίσετε τους άλλους τριγωνομετρικούς αριθμούς της $\varphi$.
Υπόδειξη: Στο 3ο τεταρτημόριο το συνημίτονο είναι αρνητικό και η εφαπτομένη θετική.
Λύση: $\text{συν}^2\varphi = 1 - \frac{64}{289} = \frac{225}{289} \Rightarrow \text{συν}\varphi = -\frac{15}{17}$ (3ο τεταρτημόριο). $\text{εφ}\varphi = \frac{-8/17}{-15/17} = \frac{8}{15}$, $\text{σφ}\varphi = \frac{15}{8}$.
Άσκηση 3Απαιτητική
Δίνεται ότι $\text{συν}\theta = -\frac{8}{17}$ και $\text{ημ}\theta > 0$. Να υπολογίσετε την τιμή της παράστασης $A = \dfrac{34\,\text{ημ}\theta + 17\,\text{συν}\theta}{8\,\text{εφ}\theta - 15\,\text{σφ}\theta}$.
Υπόδειξη: Η $\theta$ είναι στο 2ο τεταρτημόριο. Βρες ημ, εφ, σφ και αντικατάστησε.
Λύση: $\text{ημ}\theta = \frac{15}{17}$, $\text{εφ}\theta = -\frac{15}{8}$, $\text{σφ}\theta = -\frac{8}{15}$.
Αριθμητής: $34\cdot\frac{15}{17} + 17\cdot\left(-\frac{8}{17}\right) = 30 - 8 = 22$. Παρονομαστής: $8\cdot\left(-\frac{15}{8}\right) - 15\cdot\left(-\frac{8}{15}\right) = -15 + 8 = -7$. $A = -\frac{22}{7}$.
Άσκηση 4Βασική
Αν $\text{ημ}x = \alpha$ και $0^\circ < x < 90^\circ$, τότε:
Υπόδειξη: $\text{συν}^2 x = 1 - \alpha^2$ και στο 1ο τεταρτημόριο $\text{συν}x > 0$.
Λύση: $\text{συν}^2x = 1 - \text{ημ}^2x = 1 - \alpha^2$ και $\text{συν}x > 0$ ⇒ $\text{συν}x = \sqrt{1 - \alpha^2}$.
Άσκηση 5Βασική
Ποια ισότητα είναι λάθος;
Υπόδειξη: Η εφ και η σφ είναι αντίστροφες.
Λύση: $\text{εφ}x\cdot\text{σφ}x = 1$, όχι $-1$. Οι άλλες ισχύουν: η τελευταία επειδή $\text{ημ}80^\circ = \text{συν}10^\circ$.
Άσκηση 6Μέτρια
Η παράσταση $(\text{ημ}\varphi + \text{συν}\varphi)^2 + (\text{ημ}\varphi - \text{συν}\varphi)^2$ ισούται με:
Υπόδειξη: Ανάπτυξε τα δύο τετράγωνα: τα διπλά γινόμενα αλληλοαναιρούνται.
Λύση: $(\text{ημ}^2 + 2\text{ημ}\,\text{συν} + \text{συν}^2) + (\text{ημ}^2 - 2\text{ημ}\,\text{συν} + \text{συν}^2) = 2(\text{ημ}^2\varphi + \text{συν}^2\varphi) = 2$.
Άσκηση 7Μέτρια
Η παράσταση $\text{ημ}\theta - \text{ημ}\theta\,\text{συν}^2\theta$ ισούται με:
Υπόδειξη: Βγάλε κοινό παράγοντα το $\text{ημ}\theta$.
Λύση: $\text{ημ}\theta(1 - \text{συν}^2\theta) = \text{ημ}\theta\cdot\text{ημ}^2\theta = \text{ημ}^3\theta$.
Άσκηση 8Απαιτητική
Αν $\text{εφ}\theta = 2$ και $180^\circ < \theta < 270^\circ$, να υπολογίσετε τα $\text{συν}\theta$ και $\text{ημ}\theta$.
Υπόδειξη: $\text{ημ}\theta = 2\,\text{συν}\theta$. Αντικατάστησε στην $\text{ημ}^2\theta + \text{συν}^2\theta = 1$.
Λύση: $4\text{συν}^2\theta + \text{συν}^2\theta = 1 \Rightarrow \text{συν}^2\theta = \frac15$. Στο 3ο τεταρτημόριο $\text{συν}\theta = -\frac{1}{\sqrt5} = -\frac{\sqrt5}{5}$ και $\text{ημ}\theta = 2\,\text{συν}\theta = -\frac{2\sqrt5}{5}$.

♾️ Γεννήτρια — από έναν τριγωνομετρικό αριθμό στους άλλους

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Αν $\text{συν}\theta = -\frac{7}{25}$ και $90^\circ < \theta < 180^\circ$, να υπολογίσετε τους άλλους τριγωνομετρικούς αριθμούς της $\theta$.
Λύση: Από $\text{ημ}^2\theta + \text{συν}^2\theta = 1$: $\text{ημ}^2\theta = 1 - \frac{49}{625} = \frac{576}{625}$ ⇒ $\text{ημ}\theta = \pm\frac{24}{25}$.
Στο 2ο τεταρτημόριο το ημίτονο είναι θετικό ⇒ $\text{ημ}\theta = \frac{24}{25}$.
$\text{εφ}\theta = \frac{\text{ημ}\theta}{\text{συν}\theta} = -\frac{24}{7}$, $\;\text{σφ}\theta = \frac{1}{\text{εφ}\theta} = -\frac{7}{24}$.
