10.10

Παράγωγος αντίστροφης συνάρτησης – Λογαριθμική

📘 Γ΄ Τεύχος §10.10 · Δραστηριότητες σελ. 133–134

Θεωρία

Θεώρημα

Αν η $f$ είναι 1–1 και παραγωγίσιμη, με $f'(x_0) \ne 0$, τότε η $f^{-1}$ είναι παραγωγίσιμη στο $y_0 = f(x_0)$ και

$$\left(f^{-1}\right)'(y_0) = \frac{1}{f'(x_0)}$$

Γεωμετρικά: οι εφαπτομένες των $C_f$ και $C_{f^{-1}}$ σε συμμετρικά σημεία (ως προς $y = x$) έχουν αντίστροφες κλίσεις.

Λογαριθμική και εκθετική

$$(\ln x)' = \frac1x,\ x > 0 \qquad (\ln u)' = \frac{u'}{u} \qquad (\log_\alpha x)' = \frac{1}{x\ln\alpha} \qquad (\alpha^x)' = \alpha^x\ln\alpha$$

Π.χ. $(\ln 3x)' = \frac{3}{3x} = \frac1x$, $(\ln(x^2 + 1))' = \frac{2x}{x^2 + 1}$, $(2^x)' = 2^x\ln 2$.

Βήματα για $(f^{-1})'(y_0)$

(1) Λύνουμε $f(x_0) = y_0$ για να βρούμε το $x_0$. (2) Υπολογίζουμε $f'(x_0)$. (3) Αντιστρέφουμε. Π.χ. $f(x) = \frac{x^2}{x + 1}$, $y_0 = \frac12$: $x_0 = 1$, $f'(1) = \frac34$, άρα $(f^{-1})'\left(\frac12\right) = \frac43$.

Πειραματίσου

f(x) = eˣ: f'(0,5) = e0,5 = 1,65  ·  f⁻¹(x) = ln x: (ln x)' στο 1,65 = 1/1,65 = 0,61
(f⁻¹)'(y₀) = 1 / f'(x₀), όπου y₀ = f(x₀)  ⇒  (ln x)' = 1/x
Οι εφαπτομένες σε συμμετρικά σημεία είναι συμμετρικές ως προς την y = x, άρα οι κλίσεις τους είναι αντίστροφοι αριθμοί.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Μέτρια
Η $f: (0, +\infty) \to (0, +\infty)$, $f(x) = \dfrac{x^2}{x + 1}$ αντιστρέφεται. Να υπολογίσετε το $(f^{-1})'\left(\frac12\right)$.
Υπόδειξη: $f(1) = \frac12$, $f'(x) = \frac{x^2 + 2x}{(x + 1)^2}$.
Λύση: $f'(1) = \frac34$, άρα $(f^{-1})'\left(\frac12\right) = \frac43$.
Άσκηση 2Μέτρια
Η $C_f$ μιας αντιστρέψιμης παραγωγίσιμης $f$ περνά από το $A(-1, 3)$ με κλίση $-\frac14$ στο $A$. Να βρείτε την κλίση της εφαπτομένης της $C_{f^{-1}}$ στο $x = 3$ και την τεταγμένη του σημείου επαφής.
Υπόδειξη: $(f^{-1})'(3) = \frac{1}{f'(-1)}$.
Λύση: $(f^{-1})'(3) = \frac{1}{-1/4} = -4$, σημείο $(3, -1)$: εφαπτομένη $y + 1 = -4(x - 3)$.
Άσκηση 3Βασική
Να βρείτε την παράγωγο της $f(x) = \ln(3x)$, $x > 0$.
Υπόδειξη: $\frac{u'}{u}$.
Λύση: $f'(x) = \frac{3}{3x} = \frac1x$ (αφού $\ln 3x = \ln 3 + \ln x$).
Άσκηση 4Βασική
Να βρείτε την παράγωγο της $f(x) = \ln^4 x$, $x > 0$.
Υπόδειξη: $u^4$ με $u = \ln x$.
Λύση: $f'(x) = 4\ln^3x\cdot\frac1x$.
Άσκηση 5Μέτρια
Να βρείτε την παράγωγο της $f(x) = x^2\ln(x + 8)$, $x > -8$.
Υπόδειξη: Γινόμενο.
Λύση: $f'(x) = 2x\ln(x + 8) + \frac{x^2}{x + 8}$.
Άσκηση 6Μέτρια
Να βρείτε την παράγωγο της $f(x) = \ln(e^x + e^{-x})$.
Υπόδειξη: $\frac{u'}{u}$.
Λύση: $f'(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$.
Άσκηση 7Μέτρια
Να βρείτε την παράγωγο της $y = \dfrac{1 + \ln x}{x^2}$, $x > 0$.
Υπόδειξη: Πηλίκο.
Λύση: $y' = \frac{\frac1x x^2 - 2x(1 + \ln x)}{x^4} = \frac{-1 - 2\ln x}{x^3}$.
Άσκηση 8Μέτρια
Να βρείτε την παράγωγο της $y = 2^{x^2 + 1}$.
Υπόδειξη: $(\alpha^u)' = \alpha^u\ln\alpha\cdot u'$.
Λύση: $y' = 2^{x^2 + 1}\ln 2\cdot 2x$.
Άσκηση 9Απαιτητική
Να βρείτε το σημείο της $f(x) = \dfrac{\ln^2 x}{x}$, $x > 0$, με $x > 1$ στο οποίο η εφαπτομένη είναι οριζόντια (γράψε π.χ. e^2).
Υπόδειξη: $f'(x) = \frac{\ln x(2 - \ln x)}{x^2}$.
Λύση: $f'(x) = 0 \Rightarrow \ln x = 0$ ($x = 1$) ή $\ln x = 2$ ($x = e^2$). Για $x = e^2$: $f = \frac{4}{e^2}$.
Άσκηση 10Βασική
$(\log x)' = $ (δεκαδικός λογάριθμος)
Υπόδειξη: $\log x = \frac{\ln x}{\ln 10}$.
Λύση: $(\log x)' = \frac{1}{x\ln 10}$.

♾️ Γεννήτρια — παράγωγος αντίστροφης συνάρτησης

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Η $f(x) = x^3 + 3x + 4$ είναι γνησίως αύξουσα, άρα αντιστρέφεται. Αφού $f(-2) = -10$, να βρείτε το $(f^{-1})'(-10)$.
Λύση: $f'(x) = 3x^2 + 3$, $f'(-2) = 15$. Άρα $(f^{-1})'(-10) = \frac{1}{f'(-2)} = \frac{1}{15}$.
