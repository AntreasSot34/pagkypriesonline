10.4

Παράγωγος βασικών συναρτήσεων – Κανόνες

📘 Γ΄ Τεύχος §10.4 · Δραστηριότητες σελ. 89–90

Θεωρία

Βασικές παράγωγοι

$f(x)$$c$$x$$x^\nu$
$f'(x)$$0$$1$$\nu x^{\nu - 1}$

Ο τύπος $(x^r)' = r x^{r - 1}$ ισχύει για κάθε πραγματικό εκθέτη (για $x > 0$ όταν ο εκθέτης δεν είναι ακέραιος): $\left(\frac1x\right)' = (x^{-1})' = -\frac{1}{x^2}$, $\ (x^\pi)' = \pi x^{\pi - 1}$.

Κανόνες

$$(f \pm g)' = f' \pm g' \qquad (c\cdot f)' = c\cdot f'$$ $$(f\cdot g)' = f'g + fg' \qquad \left(\frac fg\right)' = \frac{f'g - fg'}{g^2}$$

Προσοχή

  • Η παράγωγος γινομένου δεν είναι το γινόμενο των παραγώγων.
  • Στο πηλίκο: «παράγωγος αριθμητή επί παρονομαστή μείον αριθμητής επί παράγωγο παρονομαστή, προς παρονομαστή στο τετράγωνο».
  • Συχνά είναι πιο γρήγορο να κάνουμε πρώτα τις πράξεις: $(x - 4)(x + 5) = x^2 + x - 20$, άρα $f'(x) = 2x + 1$.

Παράγωγος της $e^x$

$\left(e^x\right)' = e^x$ για κάθε $x \in \mathbb{R}$: η $e^x$ (και κάθε $c\,e^x$) ισούται με την παράγωγό της. Π.χ. $(3e^x)' = 3e^x$, $(x^e)' = e\,x^{e - 1}$.

Πειραματίσου

μπλε: f  ·  μωβ: f'  ·  f'(1,5) ≈ 3,75 = κλίση της εφαπτομένης (κόκκινη) στο (1,5, -1,12)
✓ Ο τύπος σου ταιριάζει με την παράγωγο!
Όπου η f' είναι θετική, η f ανεβαίνει· όπου είναι αρνητική, κατεβαίνει. Γράψε π.χ. (x-2)(x-3) ή x/(x-2).

Ασκήσεις — 0/16 λυμένες

Άσκηση 1Βασική
Να βρείτε την παράγωγο της $f(x) = x^3 + x - 4$.
Υπόδειξη: Όρο-όρο.
Λύση: $f'(x) = 3x^2 + 1$.
Άσκηση 2Βασική
Να βρείτε την παράγωγο της $f(x) = 3x^2 + x - 7$.
Υπόδειξη: $(3x^2)' = 6x$.
Λύση: $f'(x) = 6x + 1$.
Άσκηση 3Βασική
Να βρείτε την παράγωγο της $f(x) = x^{-6}$.
Υπόδειξη: $(x^r)' = rx^{r - 1}$.
Λύση: $f'(x) = -6x^{-7} = -\frac{6}{x^7}$.
Άσκηση 4Μέτρια
Να βρείτε την παράγωγο της $f(x) = x^\pi$, $x > 0$.
Υπόδειξη: Ο $\pi$ είναι απλώς ένας πραγματικός εκθέτης.
Λύση: $f'(x) = \pi x^{\pi - 1}$.
Άσκηση 5Μέτρια
Να βρείτε την παράγωγο της $f(x) = (x - 4)(x + 5)$.
Υπόδειξη: Κανόνας γινομένου ή πρώτα επιμεριστική.
Λύση: $f'(x) = 1\cdot(x + 5) + (x - 4)\cdot 1 = 2x + 1$.
Άσκηση 6Μέτρια
Να βρείτε την παράγωγο της $f(x) = 4x^7(x^2 + 2x - 3)$.
Υπόδειξη: $f(x) = 4x^9 + 8x^8 - 12x^7$.
Λύση: $f'(x) = 36x^8 + 64x^7 - 84x^6$.
Άσκηση 7Μέτρια
Να βρείτε την παράγωγο της $f(x) = \dfrac{x}{x - 1}$, $x \ne 1$.
Υπόδειξη: Κανόνας πηλίκου.
Λύση: $f'(x) = \frac{1\cdot(x - 1) - x\cdot 1}{(x - 1)^2} = -\frac{1}{(x - 1)^2}$.
Άσκηση 8Απαιτητική
Να βρείτε την παράγωγο της $f(x) = \dfrac{x^2 - 2x + 2}{x - 4}$, $x \ne 4$.
Υπόδειξη: Αριθμητής: $(2x - 2)(x - 4) - (x^2 - 2x + 2)$.
Λύση: $f'(x) = \frac{(2x - 2)(x - 4) - (x^2 - 2x + 2)}{(x - 4)^2} = \frac{x^2 - 8x + 6}{(x - 4)^2}$.
Άσκηση 9Μέτρια
Αν $f(x) = x^3(x^4 - 2x)$, τότε $f'(x) = 3x^2(4x^3 - 2)$.
Υπόδειξη: Η παράγωγος γινομένου δεν είναι γινόμενο παραγώγων.
Λύση: Λάθος. $f(x) = x^7 - 2x^4$, άρα $f'(x) = 7x^6 - 8x^3$, ενώ $3x^2(4x^3 - 2) = 12x^5 - 6x^2$.
Άσκηση 10Μέτρια
Αν $f'(1) = 4$, να υπολογίσετε την παράγωγο της $g(x) = 4f(x) - 1$ στο $x = 1$.
Υπόδειξη: $(c\cdot f)' = c\cdot f'$ και η παράγωγος σταθεράς είναι $0$.
Λύση: $g'(x) = 4f'(x)$, άρα $g'(1) = 16$.
Άσκηση 11Βασική
Για την $f(x) = 3e^x$ να υπολογίσετε το $f'(\ln 2)$.
Υπόδειξη: $e^{\ln 2} = 2$.
Λύση: $f'(x) = 3e^x$, $f'(\ln 2) = 3\cdot 2 = 6$.
Άσκηση 12Βασική
Να βρείτε την παράγωγο της $f(x) = e^x + \dfrac{1}{x^2}$, $x \ne 0$.
Υπόδειξη: $\frac{1}{x^2} = x^{-2}$.
Λύση: $f'(x) = e^x - 2x^{-3} = e^x - \frac{2}{x^3}$.
Άσκηση 13Μέτρια
Να βρείτε την παράγωγο της $f(x) = x^2 e^x$.
Υπόδειξη: Κανόνας γινομένου.
Λύση: $f'(x) = 2x e^x + x^2 e^x = e^x(x^2 + 2x)$.
Άσκηση 14Μέτρια
Να βρείτε την παράγωγο της $f(x) = e^x(2e^x - 3)$.
Υπόδειξη: Πρώτα πράξεις: $2e^{2x} - 3e^x$, ή κανόνας γινομένου.
Λύση: $f'(x) = e^x(2e^x - 3) + e^x\cdot 2e^x = 4e^{2x} - 3e^x$.
Άσκηση 15Μέτρια
Να βρείτε την παράγωγο της $f(x) = \dfrac{x}{e^x}$.
Υπόδειξη: Κανόνας πηλίκου.
Λύση: $f'(x) = \frac{e^x - xe^x}{e^{2x}} = \frac{1 - x}{e^x}$.
Άσκηση 16Απαιτητική
Αν $f(x) = \alpha x^3 + \beta x^2 + \gamma x + \delta$ και $f(1) = f'(1) = f''(1) = f'''(1) = 2$, να βρείτε τα $\alpha, \beta, \gamma, \delta$.
Υπόδειξη: $f''' = 6\alpha$, $f''(1) = 6\alpha + 2\beta$, $f'(1) = 3\alpha + 2\beta + \gamma$.
Λύση: $6\alpha = 2 \Rightarrow \alpha = \frac13$. $2 + 2\beta = 2 \Rightarrow \beta = 0$. $1 + \gamma = 2 \Rightarrow \gamma = 1$. $\frac13 + 1 + \delta = 2 \Rightarrow \delta = \frac23$.

♾️ Γεννήτρια — κανόνες παραγώγισης

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε την παράγωγο της $f(x) = (x - 1)(x^2 + 3)$ με τον κανόνα του γινομένου.
Λύση: $f'(x) = 1\cdot(x^2 + 3) + (x - 1)\cdot 2x = 3x^{2} - 2x + 3$.
