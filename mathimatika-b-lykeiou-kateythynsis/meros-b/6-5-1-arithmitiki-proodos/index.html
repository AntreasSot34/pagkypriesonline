6.5.1

Αριθμητική πρόοδος

📘 Β΄ Τεύχος §6.5.1 · Δραστηριότητες σελ. 101

Θεωρία

Ορισμός και γενικός όρος

Αριθμητική πρόοδος (Α.Π.): κάθε όρος προκύπτει από τον προηγούμενο προσθέτοντας τον ίδιο αριθμό $\delta$ (διαφορά): $\alpha_{\nu+1} = \alpha_\nu + \delta$, δηλαδή $\alpha_{\nu+1} - \alpha_\nu = \delta$.

$$\alpha_\nu = \alpha_1 + (\nu - 1)\delta$$

$\delta > 0$: γνησίως αύξουσα, $\delta < 0$: γνησίως φθίνουσα, $\delta = 0$: σταθερή.

Αριθμητικός μέσος

Οι $\alpha, \beta, \gamma$ είναι διαδοχικοί όροι Α.Π. $\iff 2\beta = \alpha + \gamma$, δηλαδή $\beta = \frac{\alpha + \gamma}{2}$.

Άθροισμα των $\nu$ πρώτων όρων

$$\Sigma_\nu = \frac{\nu}{2}(\alpha_1 + \alpha_\nu) = \frac{\nu}{2}\big[2\alpha_1 + (\nu - 1)\delta\big]$$

Για δύο όρους $\alpha_\kappa$, $\alpha_\lambda$: $\ \alpha_\lambda - \alpha_\kappa = (\lambda - \kappa)\delta$ — έτσι βρίσκουμε γρήγορα το $\delta$.

Πειραματίσου

Όροι: 2, 3,5, 5, 6,5, 8, 9,5, …
αν+1 = αν + 1,5  ·  αν = α₁ + (ν − 1)δ = 2 + (ν − 1)·1,5  ·  Σ10 = 10/2·(α₁ + α10) = 87,5
Τα σημεία είναι πάνω σε ευθεία — η αριθμητική πρόοδος «μεγαλώνει» κατά σταθερό βήμα δ.

Ασκήσεις — 0/11 λυμένες

Άσκηση 1Βασική
Σε Α.Π. είναι $\alpha_1 = -2$ και $\delta = 3$. Να βρείτε τους $\alpha_{10}$ και $\alpha_{101}$.
Υπόδειξη: $\alpha_\nu = \alpha_1 + (\nu - 1)\delta$.
Λύση: $\alpha_{10} = -2 + 9\cdot 3 = 25$, $\ \alpha_{101} = -2 + 100\cdot 3 = 298$.
Άσκηση 2Βασική
Να βρείτε τον $18$ο όρο της Α.Π. $3, -2, -7, -12, \dots$
Υπόδειξη: $\delta = -5$.
Λύση: $\alpha_{18} = 3 + 17\cdot(-5) = -82$.
Άσκηση 3Μέτρια
Α.Π. έχει τρίτο όρο $13$ και όγδοο όρο $43$. Να βρείτε τα $\delta$ και $\alpha_1$.
Υπόδειξη: $\alpha_8 - \alpha_3 = 5\delta$.
Λύση: $5\delta = 30 \Rightarrow \delta = 6$, $\alpha_1 = 13 - 2\cdot 6 = 1$. Πρόοδος: $1, 7, 13, 19, 25, \dots$
Άσκηση 4Μέτρια
Να παρεμβάλετε μεταξύ των $10$ και $108$ δεκατρείς αριθμούς ώστε όλοι μαζί να αποτελούν Α.Π. Ποια είναι η διαφορά;
Υπόδειξη: Συνολικά $15$ όροι: $\alpha_1 = 10$, $\alpha_{15} = 108$.
Λύση: $108 = 10 + 14\delta \Rightarrow \delta = 7$: $10, 17, 24, \dots, 108$.
Άσκηση 5Βασική
Να βρείτε τον αριθμητικό μέσο των $-3$ και $26$.
Υπόδειξη: $\beta = \frac{\alpha + \gamma}{2}$.
Λύση: $\beta = \frac{-3 + 26}{2} = \frac{23}{2}$.
Άσκηση 6Μέτρια
Να βρείτε το $x$ ώστε οι $x - 4$, $2x - 3$, $4x + 5$ να είναι διαδοχικοί όροι Α.Π.
Υπόδειξη: $2(2x - 3) = (x - 4) + (4x + 5)$.
Λύση: $4x - 6 = 5x + 1 \Rightarrow x = -7$. Όροι: $-11, -17, -23$ ($\delta = -6$).
Άσκηση 7Βασική
Να υπολογίσετε το άθροισμα των $12$ πρώτων όρων Α.Π. με $\alpha_1 = 5$ και $\delta = 6$.
Υπόδειξη: $\Sigma_\nu = \frac\nu2[2\alpha_1 + (\nu - 1)\delta]$.
Λύση: $\Sigma_{12} = 6(10 + 66) = 456$.
Άσκηση 8Μέτρια
Να υπολογίσετε το άθροισμα των $20$ πρώτων όρων Α.Π. με $\alpha_1 = -2$ και $\alpha_8 = 19$.
Υπόδειξη: Πρώτα $\delta$: $19 = -2 + 7\delta$.
Λύση: $\delta = 3$, $\alpha_{20} = -2 + 57 = 55$, $\Sigma_{20} = 10(-2 + 55) = 530$.
Άσκηση 9Μέτρια
Να υπολογίσετε το άθροισμα $8 + 11 + 14 + \dots + 158$.
Υπόδειξη: $158 = 8 + (\nu - 1)\cdot 3$.
Λύση: $\nu - 1 = 50 \Rightarrow \nu = 51$. $\Sigma = \frac{51}{2}(8 + 158) = 51\cdot 83 = 4233$.
Άσκηση 10Απαιτητική
Μαθητές παρατάσσονται σε τρίγωνο: $1$ μαθητής στην πρώτη σειρά και κάθε επόμενη σειρά έχει $2$ περισσότερους. Στην τελευταία σειρά είναι $99$ μαθητές. Πόσες σειρές σχηματίστηκαν και πόσοι είναι όλοι οι μαθητές;
Υπόδειξη: Α.Π. $1, 3, 5, \dots, 99$.
Λύση: $99 = 1 + 2(\nu - 1) \Rightarrow \nu = 50$. $\Sigma_{50} = 25(1 + 99) = 2500$.
Άσκηση 11Απαιτητική
Σε Α.Π. ισχύουν $\alpha_1 + \alpha_2 + \alpha_3 = 9$ και $\alpha_6 - \alpha_5 - \alpha_4 = 2$. Να βρείτε τα $\alpha_1$ και $\delta$.
Υπόδειξη: Γράψε όλους τους όρους με $\alpha_1$ και $\delta$.
Λύση: $3\alpha_1 + 3\delta = 9 \Rightarrow \alpha_1 + \delta = 3$. $\ \alpha_6 - \alpha_5 - \alpha_4 = \delta - (\alpha_1 + 3\delta) = -\alpha_1 - 2\delta = 2$. Προσθέτοντας: $-\delta = 5 \Rightarrow \delta = -5$, $\alpha_1 = 8$. Πρόοδος: $8, 3, -2, -7, -12, -17, \dots$

♾️ Γεννήτρια — αριθμητική πρόοδος

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Σε αριθμητική πρόοδο είναι $\alpha_1 = 5$ και $\delta = -2$. Να υπολογίσετε τον $\alpha_{26}$ και το άθροισμα $\Sigma_{26}$ των 26 πρώτων όρων.
Λύση: $\alpha_{26} = \alpha_1 + (26 - 1)\delta = 5 + 25\cdot(-2) = -45$. $\Sigma_{26} = \frac{26}{2}(\alpha_1 + \alpha_{26}) = \frac{26}{2}(5 + (-45)) = -520$.
