10.8

Πεπλεγμένη συνάρτηση

📘 Γ΄ Τεύχος §10.8 · Δραστηριότητες σελ. 119

Θεωρία

Η ιδέα

Μια εξίσωση $F(x, y) = 0$ (π.χ. $x^2 + y^2 = 25$) μπορεί να ορίζει το $y$ ως συνάρτηση του $x$ χωρίς να μπορούμε (ή να χρειάζεται) να λύσουμε ως προς $y$. Λέμε ότι η $y$ ορίζεται πεπλεγμένα.

Πεπλεγμένη παραγώγιση

Παραγωγίζουμε και τα δύο μέλη ως προς $x$, θεωρώντας το $y$ συνάρτηση του $x$ (άρα $(y^2)' = 2y\,y'$, $(xy)' = y + xy'$), και λύνουμε ως προς $y' = \frac{dy}{dx}$.

Π.χ. $x^2 + y^2 = 25$: $2x + 2yy' = 0 \Rightarrow y' = -\frac{x}{y}$. Στο $(3, 4)$: $y' = -\frac34$, εφαπτομένη $y - 4 = -\frac34(x - 3)$.

Οριζόντιες – κατακόρυφες εφαπτομένες

Αν $y' = \frac{A}{B}$: οριζόντια όπου $A = 0$ (και $B \ne 0$), κατακόρυφη όπου $B = 0$ (και $A \ne 0$) — μαζί με την εξίσωση της καμπύλης. Η κάθετη στην εφαπτομένη έχει κλίση $-\frac{1}{y'}$.

Πειραματίσου

Καμπύλη x²/9 + y²/4 = 1. Παραγωγίζουμε και τα δύο μέλη ως προς x (το y είναι συνάρτηση του x):
2x/9 + 2y·y'/4 = 0 ⇒ dy/dx = −β²x/(α²y) = −4·2,3/(9·1,29) = -0,79
Κόκκινη διακεκομμένη: η εφαπτομένη στο σημείο.

Ασκήσεις — 0/7 λυμένες

Άσκηση 1Βασική
Για την καμπύλη $x^2 + y^2 = 25$ να βρείτε την κλίση της εφαπτομένης στο σημείο $(3, 4)$ και στο $(3, -4)$.
Υπόδειξη: $y' = -\frac xy$.
Λύση: $-\frac34$ και $-\frac{3}{-4} = \frac34$.
Άσκηση 2Μέτρια
Η $x^2 + 2yx - y^2 = 0$ ορίζει πεπλεγμένα την $y$. Να υπολογίσετε το $y'$ στο σημείο $(1, 1 + \sqrt2)$ (3 δεκαδικά).
Υπόδειξη: $2x + 2y + 2xy' - 2yy' = 0 \Rightarrow y' = \frac{x + y}{y - x}$.
Λύση: $y' = \frac{1 + 1 + \sqrt2}{\sqrt2} = \frac{2 + \sqrt2}{\sqrt2} = \sqrt2 + 1 \approx 2{,}414$.
Άσκηση 3Μέτρια
Για την καμπύλη $y^2 = 4x$ στο σημείο της με $x = 4$ και θετική τεταγμένη, να βρείτε την κλίση της εφαπτομένης και την κλίση της κάθετης ευθείας.
Υπόδειξη: $y = 4$, $2yy' = 4$.
Λύση: $y' = \frac2y = \frac12$. Κάθετη: $-2$. (Εφαπτομένη $y = \frac12x + 2$, κάθετη $y = -2x + 12$.)
Άσκηση 4Βασική
Για την καμπύλη $xy = 6$ να βρείτε το $y'$ στο σημείο $(2, 3)$.
Υπόδειξη: $y + xy' = 0$.
Λύση: $y' = -\frac yx = -\frac32$.
Άσκηση 5Απαιτητική
Να βρείτε τα σημεία της καμπύλης $x^2 + y^2 - 2y = 1$ στα οποία η κλίση της εφαπτομένης είναι $-1$ (το σημείο με θετικό $x$).
Υπόδειξη: $2x + 2yy' - 2y' = 0 \Rightarrow y' = \frac{x}{1 - y}$. Θέσε $= -1$: $x = y - 1$.
Λύση: Με $x = y - 1$ στην καμπύλη: $(y - 1)^2 + y^2 - 2y - 1 = 0 \Rightarrow 2y^2 - 4y = 0 \Rightarrow y = 0$ ή $y = 2$. Σημεία $(-1, 0)$ και $(1, 2)$.
Άσκηση 6Απαιτητική
Στην καμπύλη $x^2 - xy + y^2 = 9$ η εφαπτομένη είναι κατακόρυφη σε δύο σημεία. Να βρείτε το σημείο με θετικό $y$ (ακριβείς τιμές, π.χ. √3).
Υπόδειξη: Παραγώγισε: $y' = \frac{y - 2x}{2y - x}$· κατακόρυφη όταν ο παρονομαστής μηδενίζεται.
Λύση: $2x - y - xy' + 2yy' = 0 \Rightarrow y' = \frac{y - 2x}{2y - x}$. Κατακόρυφη: $x = 2y$. Τότε $4y^2 - 2y^2 + y^2 = 9 \Rightarrow y^2 = 3$. Με $y > 0$: $y = \sqrt3$, $x = 2\sqrt3$.
Άσκηση 7Μέτρια
Αν $\text{ημ}x + \text{ημ}y = 1$, τότε $\frac{dy}{dx} = $
Υπόδειξη: $\text{συν}x + \text{συν}y\cdot y' = 0$.
Λύση: $y' = -\frac{\text{συν}x}{\text{συν}y}$ (όπου $\text{συν}y \ne 0$).

♾️ Γεννήτρια — παράγωγος πεπλεγμένης συνάρτησης

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε την κλίση $\frac{dy}{dx}$ της καμπύλης $x^2 + y^2 = 25$ στο σημείο της $(-3, -4)$.
Λύση: $2x + 2y\,y' = 0 \Rightarrow y' = -\frac{x}{y} = -\frac{-3}{-4} = -\frac{3}{4}$.
