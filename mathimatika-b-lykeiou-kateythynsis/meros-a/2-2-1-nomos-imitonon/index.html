2.2.1

Νόμος ημιτόνων

📘 Α΄ Τεύχος §2.2.1

Θεωρία

Συμβολισμοί

Σε τρίγωνο $AB\Gamma$ γράφουμε $\alpha = B\Gamma$, $\beta = A\Gamma$, $\gamma = AB$ (κάθε πλευρά απέναντι από την ομώνυμη γωνία) και $R$ την ακτίνα του περιγεγραμμένου κύκλου. Πάντα $\hat A + \hat B + \hat\Gamma = 180^\circ$.

Νόμος ημιτόνων

$$\frac{\alpha}{\text{ημ}A} = \frac{\beta}{\text{ημ}B} = \frac{\gamma}{\text{ημ}\Gamma} = 2R$$

Ισοδύναμα: $\alpha = 2R\,\text{ημ}A$, $\ \beta = 2R\,\text{ημ}B$, $\ \gamma = 2R\,\text{ημ}\Gamma$.

Πότε τον χρησιμοποιούμε

  • Ξέρουμε δύο γωνίες και μία πλευρά: βρίσκουμε την τρίτη γωνία ($180^\circ$ − …) και μετά τις πλευρές.
  • Ξέρουμε δύο πλευρές και τη γωνία απέναντι από μία τους: βρίσκουμε το ημίτονο άλλης γωνίας. Προσοχή: η εξίσωση $\text{ημ}x = \kappa$ ($0 < \kappa < 1$) δίνει δύο γωνίες, $x$ και $180^\circ - x$ — κρατάμε όσες δίνουν άθροισμα γωνιών μικρότερο από $180^\circ$.
  • Συνδέουμε πλευρές με την ακτίνα $R$.

Επίλυση τριγώνου σημαίνει να βρούμε όλες τις πλευρές και όλες τις γωνίες του.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
Σε τρίγωνο $AB\Gamma$ είναι $\hat B = 150^\circ$ και $R = 2$ cm. Να υπολογίσετε την πλευρά $\beta$.
Υπόδειξη: $\beta = 2R\,\text{ημ}B$ και $\text{ημ}150^\circ = \text{ημ}30^\circ$.
Λύση: $\beta = 2\cdot 2\cdot\text{ημ}150^\circ = 4\cdot\frac12 = 2$ cm.
Άσκηση 2Βασική
Σε τρίγωνο $AB\Gamma$ είναι $\gamma = 7$ cm και $R = 21$ cm. Να υπολογίσετε το $\text{ημ}\Gamma$.
Υπόδειξη: $\frac{\gamma}{\text{ημ}\Gamma} = 2R$.
Λύση: $\text{ημ}\Gamma = \frac{\gamma}{2R} = \frac{7}{42} = \frac16$.
Άσκηση 3Μέτρια
Να υπολογίσετε τα μήκη των πλευρών τριγώνου $AB\Gamma$ με $\hat A = 30^\circ$, $\hat B = 45^\circ$ και $R = 3$ cm.
Υπόδειξη: $\hat\Gamma = 105^\circ$ και $\text{ημ}105^\circ = \text{ημ}(60^\circ + 45^\circ) = \frac{\sqrt6 + \sqrt2}{4}$ (ή υπολογιστική: $\approx 0{,}966$).
Λύση: $\alpha = 2R\,\text{ημ}30^\circ = 3$, $\ \beta = 6\,\text{ημ}45^\circ = 3\sqrt2$, $\ \gamma = 6\,\text{ημ}105^\circ = \frac{3(\sqrt6 + \sqrt2)}{2} \approx 5{,}80$ cm.
Άσκηση 4Βασική
Να υπολογίσετε το μήκος της πλευράς $\alpha$ τριγώνου $AB\Gamma$ με $\hat A = 60^\circ$, $\hat B = 40^\circ$ και $\beta = 4$ cm (2 δεκαδικά).
Υπόδειξη: $\frac{\alpha}{\text{ημ}60^\circ} = \frac{4}{\text{ημ}40^\circ}$.
Λύση: $\alpha = \frac{4\,\text{ημ}60^\circ}{\text{ημ}40^\circ} \approx \frac{4\cdot 0{,}866}{0{,}643} \approx 5{,}39$ cm.
Άσκηση 5Μέτρια
Σε τρίγωνο $AB\Gamma$ είναι $\alpha = 1$, $\gamma = \sqrt3$ και $\hat\Gamma = 60^\circ$. Η γωνία $\hat A$ είναι:
Υπόδειξη: Βρες το $\text{ημ}A$ και έλεγξε και τις δύο γωνίες με αυτό το ημίτονο.
Λύση: $\text{ημ}A = \frac{\alpha\,\text{ημ}\Gamma}{\gamma} = \frac{1\cdot\frac{\sqrt3}{2}}{\sqrt3} = \frac12$, άρα $\hat A = 30^\circ$ ή $150^\circ$. Η $150^\circ$ απορρίπτεται γιατί $150^\circ + 60^\circ > 180^\circ$. Άρα $\hat A = 30^\circ$ (και τότε $\hat B = 90^\circ$, $\beta = 2$).
Άσκηση 6Απαιτητική
Να επιλύσετε το τρίγωνο $AB\Gamma$ με $\alpha = 4$ cm, $\beta = 2\sqrt2$ cm και $\hat B = 30^\circ$. (Υπάρχουν δύο τρίγωνα· γράψτε τη γωνία $\hat A$ και την πλευρά $\gamma$ για καθένα.)
Υπόδειξη: $\text{ημ}A = \frac{\alpha\,\text{ημ}B}{\beta} = \frac{\sqrt2}{2}$. Και οι δύο γωνίες $45^\circ$, $135^\circ$ δίνουν άθροισμα με την $\hat B$ μικρότερο από $180^\circ$.
Λύση: $\text{ημ}A = \frac{4\cdot\frac12}{2\sqrt2} = \frac{\sqrt2}{2}$, άρα $\hat A = 45^\circ$ ή $135^\circ$.
• $\hat A = 45^\circ$: $\hat\Gamma = 105^\circ$, $\gamma = \frac{\beta\,\text{ημ}\Gamma}{\text{ημ}B} = 4\sqrt2\cdot\frac{\sqrt6 + \sqrt2}{4} = 2\sqrt3 + 2 \approx 5{,}46$.
• $\hat A = 135^\circ$: $\hat\Gamma = 15^\circ$, $\gamma = 4\sqrt2\,\text{ημ}15^\circ = 4\sqrt2\cdot\frac{\sqrt6 - \sqrt2}{4} = 2\sqrt3 - 2 \approx 1{,}46$.
Άσκηση 7Μέτρια
Δύο πλοία βρίσκονται στις θέσεις $A$ και $B$ σε απόσταση $500$ m, ενώ στη θέση $\Sigma$ βρίσκεται ένα λιμάνι. Οι γωνίες $\Sigma AB$ και $\Sigma BA$ είναι $75^\circ$ και $64^\circ$. Να υπολογίσετε την απόσταση $A\Sigma$ (στο πλησιέστερο μέτρο).
Υπόδειξη: $\hat\Sigma = 180^\circ - 75^\circ - 64^\circ$. Η $A\Sigma$ είναι απέναντι από τη γωνία $B$.
Λύση: $\hat\Sigma = 41^\circ$. $\frac{A\Sigma}{\text{ημ}64^\circ} = \frac{500}{\text{ημ}41^\circ} \Rightarrow A\Sigma = \frac{500\,\text{ημ}64^\circ}{\text{ημ}41^\circ} \approx 685$ m.
Άσκηση 8Βασική
Σε τρίγωνο $AB\Gamma$ είναι $\hat A = 30^\circ$ και $\alpha = 3$ cm. Να βρείτε την ακτίνα $R$ του περιγεγραμμένου κύκλου.
Υπόδειξη: $2R = \frac{\alpha}{\text{ημ}A}$.
Λύση: $2R = \frac{3}{\text{ημ}30^\circ} = 6 \Rightarrow R = 3$ cm.
Άσκηση 9Μέτρια
Σε τρίγωνο $AB\Gamma$ είναι $\beta = 10$ cm και $R = 5$ cm. Τότε η γωνία $\hat B$ είναι:
Υπόδειξη: $\text{ημ}B = \frac{\beta}{2R}$.
Λύση: $\text{ημ}B = \frac{10}{10} = 1 \Rightarrow \hat B = 90^\circ$ — η $\beta$ είναι διάμετρος του περιγεγραμμένου κύκλου.

♾️ Γεννήτρια — νόμος ημιτόνων

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Σε τρίγωνο $AB\Gamma$ είναι $\hat B = 48^\circ$, $\hat\Gamma = 79^\circ$ και $\alpha = 15$ cm. Να υπολογίσετε τη γωνία $\hat A$ και την πλευρά $\beta$ (2 δεκαδικά).
Λύση: $\hat A = 180^\circ - 48^\circ - 79^\circ = 53^\circ$. Νόμος ημιτόνων: $\frac{\beta}{\text{ημ}48^\circ} = \frac{15}{\text{ημ}53^\circ} \Rightarrow \beta = \frac{15\,\text{ημ}48^\circ}{\text{ημ}53^\circ} \approx 13{,}96$ cm.
