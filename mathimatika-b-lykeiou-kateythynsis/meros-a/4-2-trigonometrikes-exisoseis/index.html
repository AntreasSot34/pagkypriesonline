4.2

Τριγωνομετρικές εξισώσεις

📘 Α΄ Τεύχος §4.2 · Δραστηριότητες σελ. 194–195

Θεωρία

Γενικές λύσεις ($\kappa \in \mathbb{Z}$, $\theta$ σε ακτίνια)

εξίσωσηλύσεις
$\text{ημ}x = \text{ημ}\theta$$x = 2\kappa\pi + \theta$ ή $x = 2\kappa\pi + \pi - \theta$
$\text{συν}x = \text{συν}\theta$$x = 2\kappa\pi \pm \theta$
$\text{εφ}x = \text{εφ}\theta$$x = \kappa\pi + \theta$
$\text{σφ}x = \text{σφ}\theta$$x = \kappa\pi + \theta$

Οι $\text{ημ}x = c$, $\text{συν}x = c$ έχουν λύση μόνο αν $-1 \le c \le 1$· οι $\text{εφ}x = c$, $\text{σφ}x = c$ για κάθε $c$.

Μέθοδος

  • Γράφουμε τον αριθμό ως τριγωνομετρικό αριθμό γνωστής γωνίας: $\text{ημ}x = -\frac{\sqrt3}{2} = \text{ημ}\left(-\frac\pi3\right)$.
  • Με όρισμα $\alpha x + \beta$: λύνουμε πρώτα για το όρισμα, μετά για το $x$. Π.χ. $\text{ημ}3x = \frac12 \Rightarrow 3x = 2\kappa\pi + \frac\pi6$ ή $3x = 2\kappa\pi + \frac{5\pi}{6}$.
  • Δευτεροβάθμιες: αντικατάσταση $y = \text{ημ}x$ (απορρίπτουμε $|y| > 1$).
  • Λύσεις σε διάστημα: δίνουμε τιμές στο $\kappa$.

Πειραματίσου

ημx = 0,5  ·  θ ∈ [−π/2, π/2] με ημθ = 0,5: θ ≈ 0,52 rad (30°)
Γενική λύση: x = 2κπ + θ ή x = 2κπ + π − θ, κ ∈ ℤ
Λύσεις στο [0, 2π): 0,52, 2,62 rad (30°, 150°)
Σε ειδικές τιμές (0, ±½, ±√2/2, ±√3/2, ±1) δίνουμε τη θ ακριβώς: π.χ. ημx = ½ ⇒ θ = π/6.

Ασκήσεις — 0/10 λυμένες

Άσκηση 1Βασική
Οι λύσεις της εξίσωσης $\text{ημ}x = \text{ημ}\frac\pi5$ είναι ($\kappa \in \mathbb{Z}$):
Υπόδειξη: $\pi - \frac\pi5 = \frac{4\pi}{5}$.
Λύση: $x = 2\kappa\pi + \frac\pi5$ ή $x = 2\kappa\pi + \pi - \frac\pi5 = 2\kappa\pi + \frac{4\pi}{5}$.
Άσκηση 2Βασική
Να λύσετε την εξίσωση $2\,\text{ημ}x + \sqrt3 = 0$ στο $[0, 2\pi)$.
Υπόδειξη: $\text{ημ}x = -\frac{\sqrt3}{2}$.
Λύση: $\text{ημ}x = -\frac{\sqrt3}{2}$: στο 3ο και 4ο τεταρτημόριο, $x = \pi + \frac\pi3 = \frac{4\pi}{3}$ και $x = 2\pi - \frac\pi3 = \frac{5\pi}{3}$.
Άσκηση 3Μέτρια
Να βρείτε τις λύσεις της $\text{ημ}3x = \frac12$ στο $\left[0, \frac\pi2\right)$.
Υπόδειξη: $3x = 2\kappa\pi + \frac\pi6$ ή $3x = 2\kappa\pi + \frac{5\pi}{6}$.
Λύση: $x = \frac{2\kappa\pi}{3} + \frac{\pi}{18}$ ή $x = \frac{2\kappa\pi}{3} + \frac{5\pi}{18}$. Για $\kappa = 0$: $\frac\pi{18}$, $\frac{5\pi}{18}$· για $\kappa = 1$ ξεπερνάμε το $\frac\pi2$.
Άσκηση 4Μέτρια
Να βρείτε τις λύσεις της $\text{συν}2x = \frac{\sqrt2}{2}$ στο $[0, \pi)$.
Υπόδειξη: $2x = 2\kappa\pi \pm \frac\pi4$.
Λύση: $x = \kappa\pi \pm \frac\pi8$: στο $[0, \pi)$ οι $\frac\pi8$ ($\kappa = 0$) και $\pi - \frac\pi8 = \frac{7\pi}{8}$ ($\kappa = 1$).
Άσκηση 5Βασική
Η εξίσωση $\text{συν}4x = 3$:
Υπόδειξη: $-1 \le \text{συν}\theta \le 1$.
Λύση: Αδύνατη, αφού $3 > 1$.
Άσκηση 6Μέτρια
Να βρείτε τις λύσεις της $\text{εφ}3x = 1$ στο $[0, \pi)$.
Υπόδειξη: $3x = \kappa\pi + \frac\pi4$.
Λύση: $x = \frac{\kappa\pi}{3} + \frac{\pi}{12}$: για $\kappa = 0, 1, 2$ παίρνουμε $\frac\pi{12}$, $\frac{5\pi}{12}$, $\frac{9\pi}{12} = \frac{3\pi}{4}$.
Άσκηση 7Μέτρια
Να λύσετε την $2\,\text{ημ}^2x + \text{ημ}x - 1 = 0$ στο $[0, 2\pi)$ (τρεις λύσεις).
Υπόδειξη: Θέσε $y = \text{ημ}x$: $2y^2 + y - 1 = 0$.
Λύση: $y = \frac12$ ή $y = -1$. $\text{ημ}x = \frac12$: $\frac\pi6$, $\frac{5\pi}{6}$· $\ \text{ημ}x = -1$: $\frac{3\pi}{2}$.
Άσκηση 8Μέτρια
Να λύσετε την $2\,\text{συν}^2x + 5\,\text{συν}x - 3 = 0$ στο $[0, 2\pi)$.
Υπόδειξη: $y = \text{συν}x$: $2y^2 + 5y - 3 = 0$.
Λύση: $y = \frac12$ ή $y = -3$ (απορρίπτεται). $\text{συν}x = \frac12$: $x = \frac\pi3$ ή $x = \frac{5\pi}{3}$.
Άσκηση 9Μέτρια
Να λύσετε την $\text{εφ}x = \text{σφ}x$ στο $[0, \pi)$.
Υπόδειξη: $\text{εφ}^2x = 1$.
Λύση: $\text{εφ}x = \frac{1}{\text{εφ}x} \Rightarrow \text{εφ}x = \pm 1$: $x = \frac\pi4$, $\frac{3\pi}{4}$.
Άσκηση 10Βασική
Η εξίσωση $\text{ημ}x = 0$ είναι αδύνατη.
Υπόδειξη: Π.χ. $x = 0$.
Λύση: Λάθος: $\text{ημ}x = 0 \iff x = \kappa\pi$, $\kappa \in \mathbb{Z}$.

♾️ Γεννήτρια — τριγωνομετρικές εξισώσεις στο [0, 2π)

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να βρείτε τις λύσεις της εξίσωσης $\text{εφ}x = \sqrt3$ στο διάστημα $[0, 2\pi)$, σε αύξουσα σειρά (γράψτε π.χ. 5π/6).
Λύση: Μία λύση: $\theta = \frac{\pi}{3}$. Γενική λύση: $x = \kappa\pi + \frac{\pi}{3}$, $\kappa \in \mathbb{Z}$. Στο $[0, 2\pi)$: $\frac{\pi}{3},\ \frac{4\pi}{3}$.
