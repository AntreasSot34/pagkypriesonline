5.8

Συνέχεια συνάρτησης

📘 Β΄ Τεύχος §5.8 · Δραστηριότητες σελ. 61

Θεωρία

Ορισμός

Η $f$ είναι συνεχής στο $x_0$ του πεδίου ορισμού της όταν

$$\lim_{x\to x_0} f(x) = f(x_0)$$

Είναι συνεχής σε ένα σύνολο όταν είναι συνεχής σε κάθε σημείο του· σε κλειστό διάστημα $[\alpha, \beta]$ ζητάμε στα άκρα $\lim_{x\to\alpha^+} f(x) = f(\alpha)$ και $\lim_{x\to\beta^-} f(x) = f(\beta)$.

Γνωστές συνεχείς συναρτήσεις

Πολυωνυμικές, ρητές, $\sqrt[\nu]{x}$, $|x|$, $\text{ημ}x$, $\text{συν}x$, $\text{εφ}x$ — στο πεδίο ορισμού τους. Αθροίσματα, γινόμενα, πηλίκα (όπου ορίζονται) και συνθέσεις συνεχών είναι συνεχείς.

Συνάρτηση πολλαπλού τύπου

Σε κάθε κομμάτι συνήθως είναι συνεχής. Ελέγχουμε τα σημεία «αλλαγής» τύπου: πλευρικά όρια και τιμή πρέπει να είναι ίσα. Γραφικά: η γραμμή σχεδιάζεται χωρίς να σηκώσουμε το μολύβι.

Πειραματίσου

limx→1⁻ f(x) = 1² + 1 = 2  ·  limx→1⁺ f(x) = κ + 1 = 3  ·  f(1) = 3
Τα πλευρικά όρια διαφέρουν ⇒ η f δεν είναι συνεχής στο 1 (άλμα). Βρες το κ που «ενώνει» τα κομμάτια.
Συνέχεια στο x₀: υπάρχει το limx→x₀ f(x) και ισούται με f(x₀).

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Αν οι $f$, $g$ είναι συνεχείς στο $\mathbb{R}$, τότε και η $f + g$ είναι συνεχής στο $\mathbb{R}$.
Υπόδειξη: Ιδιότητες ορίων.
Λύση: Σωστό: $\lim(f + g) = \lim f + \lim g = f(x_0) + g(x_0)$.
Άσκηση 2Μέτρια
Αν η $f + g$ είναι συνεχής στο $\mathbb{R}$, τότε και οι $f$, $g$ είναι συνεχείς στο $\mathbb{R}$.
Υπόδειξη: Βρες δύο ασυνεχείς με συνεχές άθροισμα.
Λύση: Λάθος: π.χ. $f(x) = 1$ για $x \ge 0$, $0$ για $x < 0$ και $g = -f$· καμία συνεχής στο $0$, αλλά $f + g = 0$ συνεχής.
Άσκηση 3Βασική
Η $f(x) = \begin{cases} x^2 - 2, & x < 0 \\ x + 1, & x \ge 0\end{cases}$ στο $x_0 = 0$:
Υπόδειξη: Πλευρικά όρια.
Λύση: $\lim_{0^-} = -2 \ne \lim_{0^+} = 1 = f(0)$: ασυνεχής.
Άσκηση 4Μέτρια
Η $g(x) = \begin{cases} \sqrt{-16x}, & x < -1 \\ 4, & x = -1 \\ |x - 3|, & x > -1\end{cases}$ στο $x_0 = -1$:
Υπόδειξη: Υπολόγισε $\sqrt{16}$ και $|-4|$.
Λύση: $\lim_{-1^-} = \sqrt{16} = 4$, $\lim_{-1^+} = |-4| = 4$, $g(-1) = 4$: συνεχής.
Άσκηση 5Απαιτητική
Να βρείτε τα $\alpha$, $\beta$ ώστε η $f(x) = \begin{cases} \alpha x, & x \le -5 \\ x^2 + 2x, & -5 < x < 2 \\ \frac{\beta x}{2} - \alpha, & x \ge 2\end{cases}$ να είναι συνεχής στο $\mathbb{R}$.
Υπόδειξη: Συνθήκες στο $-5$ και στο $2$.
Λύση: Στο $-5$: $-5\alpha = 25 - 10 = 15 \Rightarrow \alpha = -3$. Στο $2$: $4 + 4 = \beta - \alpha \Rightarrow \beta = 8 + \alpha = 5$.
Άσκηση 6Βασική
Η $f(x) = \dfrac{x^2 - 4}{x - 2}$ για $x \ne 2$ και $f(2) = \kappa$. Για ποιο $\kappa$ είναι συνεχής στο $2$;
Υπόδειξη: $\lim_{x\to 2}(x + 2)$.
Λύση: $\kappa = \lim_{x\to 2}(x + 2) = 4$.
Άσκηση 7Μέτρια
Η $f(x) = \dfrac{\text{ημ}3x}{x}$ για $x \ne 0$ και $f(0) = \kappa$. Για ποιο $\kappa$ είναι συνεχής στο $0$;
Υπόδειξη: Βασικό τριγωνομετρικό όριο.
Λύση: $\kappa = \lim_{x\to 0}\frac{\text{ημ}3x}{x} = 3$.
Άσκηση 8Βασική
Η $f(x) = \dfrac{x}{\text{ημ}x}$, $x \ne \kappa\pi$:
Υπόδειξη: Πηλίκο συνεχών.
Λύση: Πηλίκο συνεχών με μη μηδενικό παρονομαστή στο πεδίο ορισμού: συνεχής σε αυτό.

♾️ Γεννήτρια — συνέχεια συνάρτησης πολλαπλού τύπου

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Δίνεται $f(x) = \begin{cases} x + \kappa, & x < 0 \\ x^{2} - 1, & x \ge 0\end{cases}$. Να βρείτε το $\kappa$ ώστε η $f$ να είναι συνεχής στο $\mathbb{R}$.
Λύση: Σε κάθε κομμάτι η $f$ είναι πολυωνυμική, άρα συνεχής. Στο $0$: $\lim_{x\to 0^-} f(x) = 0 + \kappa$ και $\lim_{x\to 0^+} f(x) = f(0) = -1$. Πρέπει $0 + \kappa = -1 \Rightarrow \kappa = -1$.
