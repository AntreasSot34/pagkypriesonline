3.2

Ιδιότητες απόλυτων τιμών – Εξισώσεις, ανισώσεις

📘 Α΄ Τεύχος §3.2 (εκτός συστημάτων) · Δραστηριότητες σελ. 90–91

Θεωρία

Ιδιότητες

  • $|x| \ge 0$, $\ |{-x}| = |x|$, $\ |x|^2 = x^2$, $\ \sqrt{x^2} = |x|$.
  • $|x| = |\alpha| \iff x = \pm\alpha$.
  • Για $\varepsilon > 0$: $\ |x| \le \varepsilon \iff -\varepsilon \le x \le \varepsilon$ · $\ |x| \ge \varepsilon \iff x \le -\varepsilon$ ή $x \ge \varepsilon$.
  • $|\alpha\beta| = |\alpha||\beta|$, $\ \left|\frac\alpha\beta\right| = \frac{|\alpha|}{|\beta|}$, $\ |\alpha + \beta| \le |\alpha| + |\beta|$ (τριγωνική ανισότητα· ισότητα όταν $\alpha\beta \ge 0$).

Εξίσωση $|A(x)| = B(x)$

Πρέπει $B(x) \ge 0$ (περιορισμός). Λύνουμε $A(x) = \pm B(x)$ και κρατάμε μόνο τις λύσεις που ικανοποιούν τον περιορισμό. Π.χ. $|x + 4| = 3x - 8$: $x \ge \frac83$, $x = 6$ ή $x = 1$ — δεκτή μόνο η $x = 6$.

Πειραματίσου

x − α = ±ε ⇒ x = -1 ή x = 3
Το |x − α| είναι η απόσταση του x από το α πάνω στον άξονα. Μπλε: y = |x − 1|, κόκκινη: y = 2.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Μέτρια
Να λύσετε την εξίσωση $|x + 4| = 3x - 8$.
Υπόδειξη: Περιορισμός $3x - 8 \ge 0$.
Λύση: $x \ge \frac83$. $x + 4 = 3x - 8 \Rightarrow x = 6$ ✓, $\ x + 4 = -3x + 8 \Rightarrow x = 1$ (απορρίπτεται).
Άσκηση 2Βασική
Να λύσετε την ανίσωση $|x - 3| \le 2$. Η λύση είναι $[\kappa, \lambda]$.
Υπόδειξη: $-2 \le x - 3 \le 2$.
Λύση: $1 \le x \le 5$: σημεία σε απόσταση το πολύ $2$ από το $3$.
Άσκηση 3Βασική
Να λύσετε την ανίσωση $|2x - 1| > 5$: η λύση είναι $x < \kappa$ ή $x > \lambda$.
Υπόδειξη: $2x - 1 < -5$ ή $2x - 1 > 5$.
Λύση: $x < -2$ ή $x > 3$.
Άσκηση 4Μέτρια
Να λύσετε την εξίσωση $|x - 1| = |2x + 3|$.
Υπόδειξη: $x - 1 = \pm(2x + 3)$.
Λύση: $x - 1 = 2x + 3 \Rightarrow x = -4$· $\ x - 1 = -2x - 3 \Rightarrow 3x = -2 \Rightarrow x = -\frac23$.
Άσκηση 5Μέτρια
Να λύσετε την εξίσωση $|x|^2 - 5|x| + 6 = 0$. Πόσες λύσεις έχει και ποια είναι η μεγαλύτερη;
Υπόδειξη: Θέσε $y = |x| \ge 0$.
Λύση: $y^2 - 5y + 6 = 0 \Rightarrow y = 2$ ή $y = 3$. Άρα $x = \pm 2, \pm 3$: τέσσερις λύσεις, μεγαλύτερη $3$.
Άσκηση 6Βασική
Αν $|x - 2| < 0{,}1$, τότε $|3x - 6| < \varepsilon$. Ποιο είναι το μικρότερο τέτοιο $\varepsilon$;
Υπόδειξη: $|3x - 6| = 3|x - 2|$.
Λύση: $|3x - 6| = 3|x - 2| < 3\cdot 0{,}1 = 0{,}3$.
Άσκηση 7Βασική

Υπόδειξη: $x^2 - 6x + 9 = (x - 3)^2$ και $\sqrt{y^2} = |y|$.
Λύση: $\sqrt{(x - 3)^2} = |x - 3|$ — όχι απλώς $x - 3$!
Άσκηση 8Μέτρια
Η τριγωνική ανισότητα $|\alpha + \beta| \le |\alpha| + |\beta|$ ισχύει ως ισότητα όταν:
Υπόδειξη: Δοκίμασε $\alpha = 2, \beta = -3$.
Λύση: Ισότητα όταν οι $\alpha$, $\beta$ είναι ομόσημοι ή κάποιος είναι $0$, δηλαδή $\alpha\beta \ge 0$. Π.χ. $|2 + (-3)| = 1 < 5$.
