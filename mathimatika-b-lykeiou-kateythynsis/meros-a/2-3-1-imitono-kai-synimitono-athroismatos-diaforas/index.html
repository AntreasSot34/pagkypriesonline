2.3.1

Ημίτονο και συνημίτονο αθροίσματος – διαφοράς

📘 Α΄ Τεύχος §2.3.1 · Δραστηριότητες σελ. 50

Θεωρία

Τύποι

$$\text{συν}(\alpha - \beta) = \text{συν}\alpha\,\text{συν}\beta + \text{ημ}\alpha\,\text{ημ}\beta \qquad \text{συν}(\alpha + \beta) = \text{συν}\alpha\,\text{συν}\beta - \text{ημ}\alpha\,\text{ημ}\beta$$ $$\text{ημ}(\alpha + \beta) = \text{ημ}\alpha\,\text{συν}\beta + \text{συν}\alpha\,\text{ημ}\beta \qquad \text{ημ}(\alpha - \beta) = \text{ημ}\alpha\,\text{συν}\beta - \text{συν}\alpha\,\text{ημ}\beta$$

Προσοχή: $\text{ημ}(\alpha + \beta) \ne \text{ημ}\alpha + \text{ημ}\beta$!

Εφαρμογές

  • Ακριβείς τιμές: $\text{ημ}75^\circ = \text{ημ}(45^\circ + 30^\circ) = \frac{\sqrt6 + \sqrt2}{4}$, $\ \text{συν}15^\circ = \frac{\sqrt6 + \sqrt2}{4}$.
  • «Αντίστροφη» χρήση: $\text{ημ}107^\circ\text{συν}17^\circ - \text{συν}107^\circ\text{ημ}17^\circ = \text{ημ}90^\circ = 1$.
  • Αν δίνονται $\text{ημ}\alpha$ και το τεταρτημόριο, βρίσκουμε το $\text{συν}\alpha$ από $\text{ημ}^2\alpha + \text{συν}^2\alpha = 1$ με το σωστό πρόσημο.

Πειραματίσου

α + β = 75°
ημ(α + β) = ημα·συνβ + συνα·ημβ = 0,71·0,87 + 0,71·0,5 = 0,97
συν(α + β) = συνα·συνβ − ημα·ημβ = 0,71·0,87 − 0,71·0,5 = 0,26
Οι τύποι δίνουν ακριβώς τις συντεταγμένες του κόκκινου σημείου. Προσοχή: ημ(α + β) ≠ ημα + ημβ = 1,21.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε χωρίς υπολογιστική μηχανή: (α) $A = \text{ημ}107^\circ\text{συν}17^\circ - \text{συν}107^\circ\text{ημ}17^\circ$, (β) $B = \text{συν}24^\circ\text{συν}66^\circ - \text{ημ}66^\circ\text{ημ}24^\circ$.
Υπόδειξη: Αναγνώρισε τους τύπους $\text{ημ}(\alpha - \beta)$ και $\text{συν}(\alpha + \beta)$.
Λύση: $A = \text{ημ}(107^\circ - 17^\circ) = \text{ημ}90^\circ = 1$, $\ B = \text{συν}(24^\circ + 66^\circ) = \text{συν}90^\circ = 0$.
Άσκηση 2Βασική
$\text{ημ}5x\,\text{συν}3x + \text{συν}5x\,\text{ημ}3x = $
Υπόδειξη: $\text{ημ}(\alpha + \beta)$.
Λύση: $\text{ημ}(5x + 3x) = \text{ημ}8x$.
Άσκηση 3Μέτρια
Σε τρίγωνο $AB\Gamma$ ισχύει $\text{συν}A\,\text{συν}B - \text{ημ}A\,\text{ημ}B = 0$. Τότε:
Υπόδειξη: $\text{συν}(A + B) = 0$ και $A + B < \pi$.
Λύση: $\text{συν}(A + B) = 0 \Rightarrow A + B = \frac\pi2 \Rightarrow \hat\Gamma = \pi - \frac\pi2 = \frac\pi2$.
Άσκηση 4Μέτρια
Αν $\text{συν}\alpha = \frac45$, $0 < \alpha < \frac\pi2$ και $\text{ημ}\beta = -\frac{5}{13}$, $\pi < \beta < \frac{3\pi}{2}$, να υπολογίσετε τα $\text{ημ}(\alpha + \beta)$ και $\text{συν}(\alpha + \beta)$.
Υπόδειξη: $\text{ημ}\alpha = \frac35$, $\text{συν}\beta = -\frac{12}{13}$ (3ο τεταρτημόριο).
Λύση: $\text{ημ}(\alpha + \beta) = \frac35\cdot\left(-\frac{12}{13}\right) + \frac45\cdot\left(-\frac{5}{13}\right) = -\frac{56}{65}$. $\ \text{συν}(\alpha + \beta) = \frac45\cdot\left(-\frac{12}{13}\right) - \frac35\cdot\left(-\frac{5}{13}\right) = -\frac{33}{65}$.
Άσκηση 5Βασική
Να υπολογίσετε την ακριβή τιμή του $\text{συν}15^\circ$ (γράψτε π.χ. (√6+√2)/4).
Υπόδειξη: $15^\circ = 45^\circ - 30^\circ$.
Λύση: $\text{συν}45^\circ\text{συν}30^\circ + \text{ημ}45^\circ\text{ημ}30^\circ = \frac{\sqrt2}{2}\cdot\frac{\sqrt3}{2} + \frac{\sqrt2}{2}\cdot\frac12 = \frac{\sqrt6 + \sqrt2}{4}$.
Άσκηση 6Μέτρια
$\text{ημ}\left(\frac\pi6 + \alpha\right)\text{συν}\left(\alpha - \frac\pi6\right) - \text{συν}\left(\frac\pi6 + \alpha\right)\text{ημ}\left(\alpha - \frac\pi6\right) = $
Υπόδειξη: $\text{ημ}(x - y)$ με $x = \frac\pi6 + \alpha$, $y = \alpha - \frac\pi6$.
Λύση: $\text{ημ}\left[\left(\frac\pi6 + \alpha\right) - \left(\alpha - \frac\pi6\right)\right] = \text{ημ}\frac\pi3 = \frac{\sqrt3}{2}$.
Άσκηση 7Μέτρια
Αν $T = \text{συν}\alpha\,\text{συν}\beta - \text{ημ}\alpha\,\text{ημ}\beta$ με $\frac\pi4 < \alpha, \beta < \frac\pi2$, τότε:
Υπόδειξη: $T = \text{συν}(\alpha + \beta)$ και $\frac\pi2 < \alpha + \beta < \pi$.
Λύση: $\alpha + \beta \in \left(\frac\pi2, \pi\right)$, όπου το συνημίτονο είναι αρνητικό: $T < 0$.
Άσκηση 8Απαιτητική
Ισχύει $\text{ημ}(\alpha + \beta)\,\text{ημ}(\alpha - \beta) = \text{ημ}^2\alpha - \text{ημ}^2\beta$. Με αυτό, να υπολογίσετε το $\text{ημ}75^\circ\cdot\text{ημ}15^\circ$.
Υπόδειξη: $\alpha = 45^\circ$, $\beta = 30^\circ$.
Λύση: $\text{ημ}(45^\circ + 30^\circ)\text{ημ}(45^\circ - 30^\circ) = \text{ημ}^2 45^\circ - \text{ημ}^2 30^\circ = \frac12 - \frac14 = \frac14$.

♾️ Γεννήτρια — ημ, συν αθροίσματος και διαφοράς

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Αν $\text{ημ}\alpha = \frac{3}{5}$ με $0 < \alpha < \frac{\pi}{2}$ και $\text{συν}\beta = -\frac{3}{5}$ με $\pi < \beta < \frac{3\pi}{2}$, να υπολογίσετε τα $\text{ημ}(\alpha - \beta)$ και $\text{συν}(\alpha - \beta)$.
Λύση: $\text{συν}\alpha = \frac{4}{5}$ (πρόσημο από το τεταρτημόριο), $\text{ημ}\beta = -\frac{4}{5}$.
$\text{ημ}(\alpha - \beta) = \text{ημ}\alpha\,\text{συν}\beta - \text{συν}\alpha\,\text{ημ}\beta = \frac{-9 + 16}{25} = \frac{7}{25}$.
$\text{συν}(\alpha - \beta) = \text{συν}\alpha\,\text{συν}\beta + \text{ημ}\alpha\,\text{ημ}\beta = \frac{-12 - 12}{25} = -\frac{24}{25}$.
