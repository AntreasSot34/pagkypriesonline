3.10

Σύνθεση συναρτήσεων

📘 Α΄ Τεύχος §3.10 · Δραστηριότητες σελ. 148–149

Θεωρία

Ορισμός

Αν $f: A \to \mathbb{R}$ και $g: B \to \mathbb{R}$, η σύνθεση $g\circ f$ είναι η συνάρτηση

$$(g\circ f)(x) = g(f(x)), \qquad x \in A \text{ με } f(x) \in B$$

«Πρώτα εφαρμόζουμε την $f$, μετά την $g$». Ορίζεται μόνο αν το σύνολο αυτό δεν είναι κενό.

Προσοχή

  • Γενικά $f\circ g \ne g\circ f$ (η σύνθεση δεν είναι αντιμεταθετική). Π.χ. $f(x) = x^2 + 1$, $g(x) = 3x - 4$: $(f\circ g)(x) = (3x - 4)^2 + 1$, $(g\circ f)(x) = 3x^2 - 1$.
  • Πεδίο ορισμού της $g\circ f$: οι περιορισμοί της $f$ και ότι το $f(x)$ ανήκει στο πεδίο ορισμού της $g$. Π.χ. $f(x) = 2x - 1$, $g(x) = \sqrt x$: $(g\circ f)(x) = \sqrt{2x - 1}$, $x \ge \frac12$.
  • Αν $f$ με πεδίο ορισμού $A$, τότε η $f(x + 1)$ ορίζεται όταν $x + 1 \in A$.

Πειραματίσου

(f∘g)(1) = f(g(1)) = f(-1) = 2
(g∘f)(1) = g(f(1)) = g(2) = 2
Μπλε: f∘g, μωβ: g∘f, γκρι: f. Γενικά f∘g ≠ g∘f. Η f∘g ορίζεται για τα x του πεδίου ορισμού της g με g(x) στο πεδίο ορισμού της f.

Ασκήσεις — 0/9 λυμένες

Άσκηση 1Βασική
(α) Αν $f(x) = x + 5$ και $g(x) = |x|$, να υπολογίσετε το $(g\circ f)(-6)$. (β) Αν $f(x) = \text{ημ}x$ και $g(x) = 3x^2$, να υπολογίσετε τα $(g\circ f)\left(\frac\pi4\right)$ και $(f\circ g)(0)$.
Υπόδειξη: Πρώτα η εσωτερική συνάρτηση.
Λύση: (α) $g(f(-6)) = g(-1) = 1$. (β) $g\left(\frac{\sqrt2}{2}\right) = 3\cdot\frac12 = \frac32$, $\ f(g(0)) = \text{ημ}0 = 0$.
Άσκηση 2Μέτρια
Δίνονται $f(x) = x^2 + 1$ και $g(x) = 3x - 4$. Να βρείτε την $f\circ g$.
Υπόδειξη: Βάλε το $g(x)$ στη θέση του $x$ στον τύπο της $f$.
Λύση: $(f\circ g)(x) = (3x - 4)^2 + 1 = 9x^2 - 24x + 17$. (Ενώ $(g\circ f)(x) = 3x^2 - 1$: διαφορετικές.)
Άσκηση 3Βασική
Αν $f(x) = 2x - 1$ και $g(x) = \sqrt x$, το πεδίο ορισμού της $g\circ f$ είναι $[\kappa, +\infty)$. Να βρείτε το $\kappa$.
Υπόδειξη: Πρέπει $f(x) \ge 0$.
Λύση: $2x - 1 \ge 0 \iff x \ge \frac12$, και $(g\circ f)(x) = \sqrt{2x - 1}$.
Άσκηση 4Μέτρια
Αν $f(x) = \sqrt{1 - x}$ και $g(x) = 3x^2 + 2$, η $f\circ g$:
Υπόδειξη: Πρέπει $g(x) \le 1$.
Λύση: $1 - (3x^2 + 2) = -1 - 3x^2 < 0$ για κάθε $x$, άρα η $f(g(x))$ δεν ορίζεται πουθενά.
Άσκηση 5Βασική
Αν $f(x) = \frac1x$, $x \ne 0$, τότε $(f\circ f)(x) = $
Υπόδειξη: $f\left(\frac1x\right)$.
Λύση: $f\left(\frac1x\right) = \frac{1}{1/x} = x$, για $x \ne 0$.
Άσκηση 6Απαιτητική
Αν $f(x) = 2x - 1$ και $(f\circ g)(x) = x^2 - 2x + 3$, να βρείτε τον τύπο της $g$.
Υπόδειξη: $2g(x) - 1 = x^2 - 2x + 3$.
Λύση: $f(g(x)) = 2g(x) - 1 = x^2 - 2x + 3 \Rightarrow g(x) = \frac{x^2 - 2x + 4}{2}$.
Άσκηση 7Βασική
Για $f(x) = 2x + 3$ και $g(x) = 4x + 9$ ισχύει $f\circ g = g\circ f$.
Υπόδειξη: Υπολόγισε και τις δύο.
Λύση: $(f\circ g)(x) = 2(4x + 9) + 3 = 8x + 21$, $\ (g\circ f)(x) = 4(2x + 3) + 9 = 8x + 21$. Ίσες (ειδική περίπτωση).
Άσκηση 8Μέτρια
Δίνεται $f(x) = 3x + 4$, $x \in [1, 16)$. Η $g(x) = f(x + 1)$ έχει πεδίο ορισμού $[\kappa, \lambda)$. Να βρείτε τα $\kappa$, $\lambda$.
Υπόδειξη: $1 \le x + 1 < 16$.
Λύση: $0 \le x < 15$ και $g(x) = 3(x + 1) + 4 = 3x + 7$.
Άσκηση 9Απαιτητική
Αν η $f$ έχει πεδίο ορισμού $[1, 6)$, η $f(x^2 - 3)$ έχει πεδίο ορισμού:
Υπόδειξη: $1 \le x^2 - 3 < 6$.
Λύση: $4 \le x^2 < 9 \iff 2 \le |x| < 3 \iff x \in (-3, -2] \cup [2, 3)$.

Εξάσκηση #1
Δίνονται $f(x) = -3x$ και $g(x) = x^{2} + 3$. Να υπολογίσετε τα $(f\circ g)(0)$ και $(g\circ f)(0)$.
Λύση: $(f\circ g)(0) = f(g(0)) = f(3) = -9$. $\ (g\circ f)(0) = g(f(0)) = g(0) = 3$.
