3.7

Πεδίο ορισμού – Σύνολο τιμών

📘 Α΄ Τεύχος §3.7

Θεωρία

Πεδίο ορισμού συνάρτησης με τύπο

Όταν δίνεται μόνο ο τύπος, πεδίο ορισμού είναι το ευρύτερο υποσύνολο του $\mathbb{R}$ για το οποίο ο τύπος έχει νόημα:

  • Πολυωνυμική: $A = \mathbb{R}$.
  • Κλάσμα $\frac{P(x)}{Q(x)}$: παρονομαστής $Q(x) \ne 0$.
  • Τετραγωνική ρίζα $\sqrt{g(x)}$: υπόρριζο $g(x) \ge 0$.
  • Ρίζα σε παρονομαστή $\frac{1}{\sqrt{g(x)}}$: $g(x) > 0$.
  • Όταν συνυπάρχουν περιορισμοί, παίρνουμε την τομή τους.

Σύνολο τιμών

Λύνουμε την $y = f(x)$ ως προς $x$: το $y$ είναι τιμή της $f$ όταν η εξίσωση έχει λύση μέσα στο πεδίο ορισμού. Π.χ. $y = \frac{x + 2}{3x - 1} \Rightarrow x = \frac{y + 2}{3y - 1}$, που ορίζεται για $y \ne \frac13$: σύνολο τιμών $\mathbb{R} - \{\frac13\}$.

Για γνησίως αύξουσα πολυωνυμική συνάρτηση (π.χ. $y = 7x - 4$) σε διάστημα $[\alpha, \beta]$, οι τιμές είναι από $f(\alpha)$ έως $f(\beta)$.

Πειραματίσου

Περιορισμός: Παρονομαστής ≠ 0
Πεδίο ορισμού: A = ℝ − {1}  ·  σύνολο τιμών: f(A) = ℝ − {0}
Η πράσινη λωρίδα δείχνει το πεδίο ορισμού πάνω στον άξονα x'x· το σύνολο τιμών το «διαβάζουμε» στον άξονα y'y.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Το πεδίο ορισμού της $g(x) = \dfrac{2x}{x^2 - 16}$ είναι:
Υπόδειξη: $x^2 - 16 \ne 0$.
Λύση: $x^2 - 16 = 0 \iff x = \pm 4$, άρα $A = \mathbb{R} - \{-4, 4\}$.
Άσκηση 2Μέτρια
Το πεδίο ορισμού της $h(x) = \dfrac{1}{x^3 - 4x}$ είναι:
Υπόδειξη: $x^3 - 4x = x(x - 2)(x + 2)$.
Λύση: $x(x - 2)(x + 2) \ne 0 \iff x \ne 0, \pm 2$.
Άσκηση 3Βασική
Το πεδίο ορισμού της $f(x) = \sqrt{x + 2}$ είναι:
Υπόδειξη: $x + 2 \ge 0$.
Λύση: $x + 2 \ge 0 \iff x \ge -2$: $A = [-2, +\infty)$.
Άσκηση 4Μέτρια
Το πεδίο ορισμού της $g(x) = \sqrt{x^2 - 25}$ είναι:
Υπόδειξη: $x^2 \ge 25$.
Λύση: $x^2 - 25 \ge 0 \iff x \le -5$ ή $x \ge 5$.
Άσκηση 5Βασική
Το πεδίο ορισμού της $g(x) = \sqrt{4 - 8x}$ είναι $(-\infty, \kappa]$. Να βρείτε το $\kappa$.
Υπόδειξη: $4 - 8x \ge 0$.
Λύση: $4 - 8x \ge 0 \iff x \le \frac12$, άρα $\kappa = \frac12$.
Άσκηση 6Μέτρια
Το πεδίο ορισμού της $h(x) = \dfrac{\sqrt{x + 3}}{x - 1}$ είναι:
Υπόδειξη: Δύο περιορισμοί: υπόρριζο $\ge 0$ και παρονομαστής $\ne 0$.
Λύση: $x + 3 \ge 0 \iff x \ge -3$ και $x \ne 1$: $A = [-3, 1) \cup (1, +\infty)$.
Άσκηση 7Μέτρια
Να βρείτε το σύνολο τιμών της $y = 7x - 4$, $x \in [3, 31]$, στη μορφή $[m, M]$.
Υπόδειξη: Η $y = 7x - 4$ είναι γνησίως αύξουσα.
Λύση: $3 \le x \le 31 \Rightarrow 21 \le 7x \le 217 \Rightarrow 17 \le 7x - 4 \le 213$: σύνολο τιμών $[17, 213]$.
Άσκηση 8Απαιτητική
Το σύνολο τιμών της $y = \dfrac{x + 2}{3x - 1}$ είναι $\mathbb{R} - \{\kappa\}$. Να βρείτε το $\kappa$.
Υπόδειξη: Λύσε ως προς $x$: $y(3x - 1) = x + 2$.
Λύση: $3xy - y = x + 2 \Rightarrow x(3y - 1) = y + 2 \Rightarrow x = \frac{y + 2}{3y - 1}$, που ορίζεται για $y \ne \frac13$ (και πάντα $x \ne \frac13$, αφού $\frac{y + 2}{3y - 1} = \frac13$ είναι αδύνατη). Άρα $\kappa = \frac13$.

Λύση: $x^2 - 9 \ge 0 \iff x^2 \ge 9 \iff x \le -3$ ή $x \ge 3$.
