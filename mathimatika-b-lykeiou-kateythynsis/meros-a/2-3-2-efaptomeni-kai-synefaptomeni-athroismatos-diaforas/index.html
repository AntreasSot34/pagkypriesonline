2.3.2

Εφαπτομένη και συνεφαπτομένη αθροίσματος – διαφοράς

📘 Α΄ Τεύχος §2.3.2 · Δραστηριότητες σελ. 55

Θεωρία

Τύποι

$$\text{εφ}(\alpha + \beta) = \frac{\text{εφ}\alpha + \text{εφ}\beta}{1 - \text{εφ}\alpha\,\text{εφ}\beta} \qquad \text{εφ}(\alpha - \beta) = \frac{\text{εφ}\alpha - \text{εφ}\beta}{1 + \text{εφ}\alpha\,\text{εφ}\beta}$$ $$\text{σφ}(\alpha + \beta) = \frac{\text{σφ}\alpha\,\text{σφ}\beta - 1}{\text{σφ}\alpha + \text{σφ}\beta} \qquad \text{σφ}(\alpha - \beta) = \frac{\text{σφ}\alpha\,\text{σφ}\beta + 1}{\text{σφ}\beta - \text{σφ}\alpha}$$

(όπου ορίζονται όλοι οι αριθμοί και οι παρονομαστές είναι μη μηδενικοί)

Χρήσιμα

$\text{εφ}75^\circ = 2 + \sqrt3$, $\ \text{εφ}15^\circ = 2 - \sqrt3$. Αν $\alpha + \beta = \frac\pi4$, τότε $(1 + \text{εφ}\alpha)(1 + \text{εφ}\beta) = 2$.

Ασκήσεις — 0/8 λυμένες

Άσκηση 1Βασική
Να υπολογίσετε την τιμή της παράστασης $A = \dfrac{\text{εφ}165^\circ + \text{εφ}15^\circ}{1 - \text{εφ}165^\circ\,\text{εφ}15^\circ}$.
Υπόδειξη: $\text{εφ}(165^\circ + 15^\circ)$.
Λύση: $A = \text{εφ}180^\circ = 0$.
Άσκηση 2Μέτρια
Αν $\alpha - \beta = \frac\pi4$ και $\text{εφ}\beta = 2$, να βρείτε την $\text{εφ}\alpha$.
Υπόδειξη: $\alpha = \beta + \frac\pi4$.
Λύση: $\text{εφ}\alpha = \frac{2 + 1}{1 - 2\cdot 1} = -3$.
Άσκηση 3Μέτρια
Αν $\text{ημ}\alpha = \frac45$, $0 < \alpha < \frac\pi2$ και $\text{συν}\beta = -\frac{8}{17}$, $\pi < \beta < \frac{3\pi}{2}$, να υπολογίσετε τα $\text{εφ}(\alpha + \beta)$ και $\text{σφ}(\alpha + \beta)$.
Υπόδειξη: $\text{εφ}\alpha = \frac43$, $\text{ημ}\beta = -\frac{15}{17}$, $\text{εφ}\beta = \frac{15}{8}$.
Λύση: $\text{εφ}(\alpha + \beta) = \frac{\frac43 + \frac{15}{8}}{1 - \frac43\cdot\frac{15}{8}} = \frac{\frac{77}{24}}{-\frac{36}{24}} = -\frac{77}{36}$, $\ \text{σφ}(\alpha + \beta) = -\frac{36}{77}$.
Άσκηση 4Βασική
Να υπολογίσετε τις ακριβείς τιμές της $\text{εφ}75^\circ$ και της $\text{εφ}15^\circ$.
Υπόδειξη: $\text{εφ}(45^\circ \pm 30^\circ)$, $\text{εφ}30^\circ = \frac{\sqrt3}{3}$.
Λύση: $\text{εφ}75^\circ = \frac{1 + \frac{\sqrt3}{3}}{1 - \frac{\sqrt3}{3}} = \frac{3 + \sqrt3}{3 - \sqrt3} = \frac{(3 + \sqrt3)^2}{6} = 2 + \sqrt3$, ανάλογα $\text{εφ}15^\circ = 2 - \sqrt3$.
Άσκηση 5Μέτρια
$\text{σφ}\left(\alpha - \frac\pi4\right) = $
Υπόδειξη: $\text{σφ}(\alpha - \beta) = \frac{\text{σφ}\alpha\,\text{σφ}\beta + 1}{\text{σφ}\beta - \text{σφ}\alpha}$ με $\text{σφ}\frac\pi4 = 1$.
Λύση: $\frac{\text{σφ}\alpha\cdot 1 + 1}{1 - \text{σφ}\alpha} = \frac{1 + \text{σφ}\alpha}{1 - \text{σφ}\alpha}$.
Άσκηση 6Μέτρια
Αν $\alpha + \beta = \frac\pi4$, να υπολογίσετε την τιμή του γινομένου $(1 + \text{εφ}\alpha)(1 + \text{εφ}\beta)$.
Υπόδειξη: $\text{εφ}(\alpha + \beta) = 1 \Rightarrow \text{εφ}\alpha + \text{εφ}\beta = 1 - \text{εφ}\alpha\,\text{εφ}\beta$.
Λύση: $(1 + \text{εφ}\alpha)(1 + \text{εφ}\beta) = 1 + (\text{εφ}\alpha + \text{εφ}\beta) + \text{εφ}\alpha\,\text{εφ}\beta = 1 + 1 = 2$.
Άσκηση 7Μέτρια
Να υπολογίσετε την $B = \dfrac{\text{σφ}\frac{7\pi}{4}\,\text{σφ}\frac{5\pi}{4} + 1}{\text{σφ}\frac{7\pi}{4} - \text{σφ}\frac{5\pi}{4}}$.
Υπόδειξη: $\text{σφ}\frac{7\pi}{4} = -1$, $\text{σφ}\frac{5\pi}{4} = 1$.
Λύση: $B = \frac{-1 + 1}{-1 - 1} = 0$ (είναι η $\text{σφ}\left(\frac{5\pi}{4} - \frac{7\pi}{4}\right) = \text{σφ}\left(-\frac\pi2\right) = 0$).
Άσκηση 8Μέτρια
Ποια ισότητα ισχύει (όπου ορίζονται οι παραστάσεις);
Υπόδειξη: Υπολόγισε $\frac{t + 1}{1 - t} + \frac{t - 1}{1 + t}$ με $t = \text{εφ}\theta$.
Λύση: $\frac{(1 + t)^2 - (1 - t)^2}{1 - t^2} = \frac{4t}{1 - t^2} = 2\cdot\frac{2t}{1 - t^2} = 2\,\text{εφ}2\theta$. Οι άλλες είναι λάθος (π.χ. $\text{εφ}(\pi - \theta) = -\text{εφ}\theta$).

Κάθε φορά καινούργια άσκηση — εξάσκηση χωρίς τέλος.

Εξάσκηση #1
Να υπολογίσετε, χωρίς υπολογιστική μηχανή, την ακριβή τιμή της $\text{σφ}15^\circ$ (γράψτε π.χ. 2+√3).
Λύση: $\text{σφ}15^\circ = \frac{1}{\text{εφ}15^\circ} = \frac{1}{2 - \sqrt3} = 2 + \sqrt3$.
